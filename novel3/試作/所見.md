# 試作の所見 — どの書きかたが、いちばん描けるか

五本書いた。対照は既存の「アイロン」（型C・標準・渡される側視点）。

| | 型 | 経路 | 視点 | 字数 |
| --- | --- | --- | --- | --- |
| **アイロン** | C：途中で気づく | 口づけ・一分 | 渡される側 | 2,900 |
| **A：三十年** | A：最後まで気づかない | 肌・三十年 | 渡される側（回想） | 1,100 |
| **B：刃** | E：先に知って抵抗する | 傷口・数秒 | 渡される側 | 1,450 |
| **C：ゆき** | C（同じ夜） | 口づけ・一分 | **セラの側** | 1,200 |
| **D：のこり** | 追い詰める | 未完了で終わる | 渡される側 | 1,200 |

---

## 一．結論

**主軸は「アイロン」型（型C・渡される側）で正しい。**

そのうえで、**A と D を混ぜたときに、いちばん強くなる。**

| | 使いかた |
| --- | --- |
| **アイロン型** | **本体。**全体の六割 |
| **D（追い詰める）型** | **二割。**幕の変わり目に置く |
| **A（気づかない）型** | **一割。**時間を飛ばす回に |
| **B（戦い）型** | **一割。**第二幕以降、手立てが潰れる回に |
| **C（セラ視点）** | **使わない。**理由は §四 |

---

## 二．D が、予想外に強かった

**いちばん怖かったのは D である。**

理由は、**セラが一度も出てこないこと**にある。

D で起きているのは、次のことだけである。

- 店員が入れ替わる
- 隣町も、その隣も、同じになる
- 数えていた人数が減る
- 断る理由が、思いつかなくなる

**誰も追いかけていない。**沢田は、自分で逃げて、自分で行き止まりに着く。

そして最後の一行——「なんででしょう」——は、
瞳の機構（拒みたい気持ちだけが薄れる）を**一度も説明せずに**見せている。

### D が効く理由

| | |
| --- | --- |
| セラが出てこない | **恐怖の出どころが、どこにもない** |
| 世界のほうが変わる | **逃げ場が、減っていくところだけを書ける** |
| 未完了で終わる | **次の話へ、そのまま渡せる** |

**「手が付けられなくなる」を、増殖の場面なしで書ける唯一の型である。**

第二幕・第三幕で、章が枝分かれして追えなくなる箇所には、
**渡す場面ではなく、この型を置く。**

---

## 三．A は、時間を飛ばすためにある

A は、三十年を千百字で通した。

**一話で数十年を畳めるのは、この型だけである。**

そして、A の最後の三行が、この本の締めかたの見本になる。

> そのうち、どうでもよくなった。
> （中略）
> 明日、菓子でも持っていこうと思った。

**渡された側が、次の誰かのほうを見る。**
本人は、自分が渡されたことを、最後まで知らない。

ただし A には弱点がある。**場面がないので、読者が体験しない。**
連続して二話置くと、report になる。**単発でのみ使う。**

---

## 四．C（セラ視点）は、使わない

**書いてみて、はっきりした。使うと、本が一段弱くなる。**

### 失うもの

| | |
| --- | --- |
| **恐怖の担い手** | **読者だけが持つ**はずだった外の目が、**説明に化ける** |
| **分からなさ** | 「なぜそこまで欲しいのか」が、内側から見ると**手続きに見える** |
| **反転点** | 三宅が言うのをやめた瞬間が、**ゆきの側からは「待っていたら来た」でしかない** |

とくに三つ目が致命的である。

**五段目は、内側からしか書けない。**
外から見ると、ただ相手が黙っただけである。

### ただし、C には一つだけ残す価値がある

**ゆきに、悪意も計画もなかったことが確認できた。**

- 洗濯物は半分しか溜まっていない → **口実を作っている**
- 両替機は自分で詰まらせた → **段取りをしている**
- 距離を測っている → **計算している**
- そして「そこまで考えていない」 → **目的は持っていない**

**段取りはするが、目的は持っていない。**

これは設定として正しく、そして**書かないほうが強い。**

> **読者に「計算しているのでは」と思わせたまま、答えを出さない。**

C は、**書き手が確認するためだけに存在する一本**とする。本編には入れない。

## 五．B（戦い）は、短く、少なく

B は成立した。ただし**繰り返せない。**

| | |
| --- | --- |
| 良い点 | **数秒で終わる。**手立てが潰れたことが、一撃で分かる |
| 悪い点 | **同じ形が二度書けない。**刺す・斬るは一回で尽きる |
| 使いどころ | **上位セラが出る回の直前**。「抵抗が抵抗として働かない」を、一度だけ見せる |

B で最も効いたのは、**セラが一度も手を出さないこと**である。

> 「なんで、避けなかった」
> 「避けたら、遠くなるので」

**この二行だけで、この世界の戦闘は説明が済む。**

## 六．書いて分かった、技術上の注意

### 6.1 いちばん難しいのは、地の文である

**一度も怖がらないと決めてあるので、逃げ場がない。**

不穏な形容が全部使えない。そのぶん、**最後の三行に全部乗る。**

五本とも、最後の三行だけで怖さを作った。**これが標準になる。**

### 6.2 「良くなったこと」は、具体的な部位で書く

肩。膝。眼鏡。歯茎。息。

**抽象的に「体調が良くなった」と書くと、一行も怖くない。**
**部位を名指しすると、読者が自分の身体で確かめる。**

### 6.3 セラの表情は、一つだけでよい

五本のうち三本で、セラは**笑っている。**

| 書く | 書かない |
| --- | --- |
| 良いことをしている顔 | 微笑む／目を細める／妖しく笑う |
| **悪いことをした顔ではなかった** | 意味ありげな表情 |

**表情を凝らない。**凝ると、こちらが何か知っていることになる。

### 6.4 長さは、短いほうがよい

**1,100〜1,500 字で成立した。**

鎖を歩く本なので、**一話が軽いほど枝分かれが効く。**
標準を **1,500〜2,500 字**とし、渡す場面のある回だけ 3,000 字まで許す。

# 試作の所見 — どの書きかたが、いちばん描けるか

五本書いた。対照は既存の「アイロン」（型C・標準・渡される側視点）。

| | 型 | 経路 | 視点 | 字数 |
| --- | --- | --- | --- | --- |
| **アイロン** | C：途中で気づく | 口づけ・一分 | 渡される側 | 2,900 |
| **A：三十年** | A：最後まで気づかない | 肌・三十年 | 渡される側（回想） | 1,100 |
| **B：刃** | E：先に知って抵抗する | 傷口・数秒 | 渡される側 | 1,450 |
| **C：ゆき** | C（同じ夜） | 口づけ・一分 | **セラの側** | 1,200 |
| **D：のこり** | 追い詰める | 未完了で終わる | 渡される側 | 1,200 |

---

## 一．結論

**主軸は「アイロン」型（型C・渡される側）で正しい。**

そのうえで、**A と D を混ぜたときに、いちばん強くなる。**

| | 使いかた |
| --- | --- |
| **アイロン型** | **本体。**全体の六割 |
| **D（追い詰める）型** | **二割。**幕の変わり目に置く |
| **A（気づかない）型** | **一割。**時間を飛ばす回に |
| **B（戦い）型** | **一割。**第二幕以降、手立てが潰れる回に |
| **C（セラ視点）** | **使わない。**理由は §四 |

---

## 二．D が、予想外に強かった

**いちばん怖かったのは D である。**

理由は、**セラが一度も出てこないこと**にある。

D で起きているのは、次のことだけである。

- 店員が入れ替わる
- 隣町も、その隣も、同じになる
- 数えていた人数が減る
- 断る理由が、思いつかなくなる

**誰も追いかけていない。**沢田は、自分で逃げて、自分で行き止まりに着く。

そして最後の一行——「なんででしょう」——は、
瞳の機構（拒みたい気持ちだけが薄れる）を**一度も説明せずに**見せている。

### D が効く理由

| | |
| --- | --- |
| セラが出てこない | **恐怖の出どころが、どこにもない** |
| 世界のほうが変わる | **逃げ場が、減っていくところだけを書ける** |
| 未完了で終わる | **次の話へ、そのまま渡せる** |

**「手が付けられなくなる」を、増殖の場面なしで書ける唯一の型である。**

第二幕・第三幕で、章が枝分かれして追えなくなる箇所には、
**渡す場面ではなく、この型を置く。**

---

## 三．A は、時間を飛ばすためにある

A は、三十年を千百字で通した。

**一話で数十年を畳めるのは、この型だけである。**

そして、A の最後の三行が、この本の締めかたの見本になる。

> そのうち、どうでもよくなった。
> （中略）
> 明日、菓子でも持っていこうと思った。

**渡された側が、次の誰かのほうを見る。**
本人は、自分が渡されたことを、最後まで知らない。

ただし A には弱点がある。**場面がないので、読者が体験しない。**
連続して二話置くと、report になる。**単発でのみ使う。**

---

## 四．C（セラ視点）は、使わない

**書いてみて、はっきりした。使うと、本が一段弱くなる。**

### 失うもの

| | |
| --- | --- |
| **恐怖の担い手** | **読者だけが持つ**はずだった外の目が、**説明に化ける** |
| **分からなさ** | 「なぜそこまで欲しいのか」が、内側から見ると**手続きに見える** |
| **反転点** | 三宅が言うのをやめた瞬間が、**ゆきの側からは「待っていたら来た」でしかない** |

とくに三つ目が致命的である。

**五段目は、内側からしか書けない。**
外から見ると、ただ相手が黙っただけである。

### ただし、C には一つだけ残す価値がある

**ゆきに、悪意も計画もなかったことが確認できた。**

- 洗濯物は半分しか溜まっていない → **口実を作っている**
- 両替機は自分で詰まらせた → **段取りをしている**
- 距離を測っている → **計算している**
- そして「そこまで考えていない」 → **目的は持っていない**

**段取りはするが、目的は持っていない。**

これは設定として正しく、そして**書かないほうが強い。**

> **読者に「計算しているのでは」と思わせたまま、答えを出さない。**

C は、**書き手が確認するためだけに存在する一本**とする。本編には入れない。

## 五．B（戦い）は、短く、少なく

B は成立した。ただし**繰り返せない。**

| | |
| --- | --- |
| 良い点 | **数秒で終わる。**手立てが潰れたことが、一撃で分かる |
| 悪い点 | **同じ形が二度書けない。**刺す・斬るは一回で尽きる |
| 使いどころ | **上位セラが出る回の直前**。「抵抗が抵抗として働かない」を、一度だけ見せる |

B で最も効いたのは、**セラが一度も手を出さないこと**である。

> 「なんで、避けなかった」
> 「避けたら、遠くなるので」

**この二行だけで、この世界の戦闘は説明が済む。**

## 六．書いて分かった、技術上の注意

### 6.1 いちばん難しいのは、地の文である

**一度も怖がらないと決めてあるので、逃げ場がない。**

不穏な形容が全部使えない。そのぶん、**最後の三行に全部乗る。**

五本とも、最後の三行だけで怖さを作った。**これが標準になる。**

### 6.2 「良くなったこと」は、具体的な部位で書く

肩。膝。眼鏡。歯茎。息。

**抽象的に「体調が良くなった」と書くと、一行も怖くない。**
**部位を名指しすると、読者が自分の身体で確かめる。**

### 6.3 セラの表情は、一つだけでよい

五本のうち三本で、セラは**笑っている。**

| 書く | 書かない |
| --- | --- |
| 良いことをしている顔 | 微笑む／目を細める／妖しく笑う |
| **悪いことをした顔ではなかった** | 意味ありげな表情 |

**表情を凝らない。**凝ると、こちらが何か知っていることになる。

### 6.4 長さは、短いほうがよい

**1,100〜1,500 字で成立した。**

鎖を歩く本なので、**一話が軽いほど枝分かれが効く。**
標準を **1,500〜2,500 字**とし、渡す場面のある回だけ 3,000 字まで許す。

# 追記 — 五本の自己評価

**B が良かった理由から逆算すると、他の四本の弱点が全部出た。**

## 七．B が良い理由は、坂井にある

| | |
| --- | --- |
| 坂井は | **四か月かけて、独力で気づいた。世界でただ一人、正しい** |
| 職業 | 会社員。ただし**有能である**。健康診断の三年ぶんを並べて、気づいた |
| 行動 | **自分から刺しに行く** |
| 状況 | **誰も坂井のために場面を用意していない** |

**渡される側に、品位と、能力と、意志がある。**

そして最後まで、負けたことを認めない。

> そして、それが正しいことも、分かっていた。

**慰めを一つも出さずに終わる。**

さらに、B には**仕掛けが一つもない。** 詰まった両替機も、止まった水道もない。
坂井が自分で調べ、自分で待ち、自分で前に出る。

## 八．アイロン — いちばん弱い

**書いた本人の評価として、これが五本でいちばん弱い。**

### 8.1 同情を段取りしている

無職四か月。四社目の面接。パートを二つ掛け持ちする妻。

**読者を可哀想がらせるために、こちらが並べた。**

坂井には、同情の要素が一つもない。**そのぶん強い。**

| | 三宅 | 坂井 |
| --- | --- | --- |
| 読者の側の感情 | **かわいそう** | **この人は正しい** |
| どちらが怖いか | — | **後者である** |

**気の毒な人が堕ちるのは、話として安い。**
**まともな人が、まともなまま堕ちるほうが、はるかに怖い。**

### 8.2 場面が、こちらの都合で用意されている

両替機が詰まる。硬貨が余る。隣が空いている。乾燥機が四十分ある。

**全部、二人を並べて座らせるための段取りである。**

`C-ゆき` を書いて分かったが、これは**ゆきが用意している。**
だから設定としては正しい。**しかし、読者にはこちらの都合に見える。**

### 8.3 長い

2,900 字。B は 1,450 字で同じ以上のことをしている。

**削れる箇所**：両替機のくだり／乾燥機の説明／名前を聞く場面。

### 8.4 残すもの

五段目の階段は、五本でいちばん良い。**あの十行だけが、この一本の値打ちである。**

> 言おうとしていたことが、言う値打ちのないことに変わった。
> ちょうど、外に出てから、鍵を閉めたかどうか気にならなくなるように。

## 九．D-のこり — 概念は最強、終わりかたが崩れた

### 9.1 最後の一行が、規則を破っている

> 奥さんは、そこで一歩、前に出た。

**これは、地の文が怖がっている。**

`README.md` §00.3 で「地の文は一度も怖がらない」と決めた。
にもかかわらず、**書いている側が我慢できずに、ここで演出した。**

正しくは、その手前で終わる。

> 「……なんででしょう」
> 沢田は、そう言った。言ってから、自分がそう言ったことに驚いた。

**ここで切る。**一歩前に出る必要がない。

### 9.2 水道工事が、都合である

沢田を隣家へ行かせるために、こちらが止めた。

**アイロンの両替機と、同じ病である。**

正しくは、**沢田のほうが用のないまま行く。**
三年断り続けた人間が、理由なく戸を叩く——**そのほうが、機構どおりである。**

### 9.3 数えたことについて

「七人いた。五人になった。三人になった」は、**数字の報告である。**

§2.2 で「数えない」と決めた。**ただしこれは、破っていない。**

| | |
| --- | --- |
| **禁じたもの** | **変えた側の総数**（「一年で五千」） |
| **これ** | **残っている側の数**（沢田から見た、まだこちら側でない人） |

前者は要約であり、後者は**当人の孤立そのもの**である。

**数えてよいのは、残っている側だけである。**

## 十．A-三十年 — 良い行が二つ、あとは要らない

### 10.1 いちばん良い行が、埋まっている

> 母は、七十二で死んでいる。

**この一行が、この一本の全部である。**

前後に何も置いていないので、読み飛ばせてしまう。
**一行だけの段落にして、そこで一度切るべきだった。**

### 10.2 一人称にした理由が、弱い

他の四本は三人称である。ここだけ「私」にした。

**回想を畳むために選んだが、それだけの理由なら、必要ない。**

### 10.3 戸田さんが引っ越すのは、逃げである

最後に相手が去るので、話が閉じる。

**A 型は、閉じてはいけない。**
気づかないまま終わるのがこの型なのに、**別れの場面をこしらえて、締めた。**

正しくは、戸田さんはずっと隣にいる。
**何も起きないまま、私だけが若返っていく。**

## 十一．C-ゆき — 使わないが、一つ持ち帰る

本編で使わないことは §四で決めた。

ただし、**持ち帰るべき細部が一つある。**

> ゆきは、洗濯物が半分しか溜まっていないことを知っていた。

**これを、渡される側の視点で書けないか。**

書ける。**説明せずに、置くだけでよい。**

> 籠の中は、半分ほどしか入っていなかった。
> 三宅は、それを見て、何も思わなかった。

**読者だけが、思う。**

**セラの段取りは、渡される側の目に映る物として置く。**
これが、C から本編へ持ち帰る唯一のものである。

## 十二．まとめ — 四つの修正

| | 直すこと |
| --- | --- |
| **一** | **渡される側に、品位と能力と意志を持たせる。**同情で組み立てない |
| **二** | **場面を、こちらの都合で用意しない。**セラの段取りは、物として置くだけにする |
| **三** | **終わりで、演出しない。**一歩前に出させない。手前で切る |
| **四** | **短く。**1,500 字で足りる |

**一が、いちばん大きい。**

気の毒な人が堕ちるのは安い。
**まともな人が、まともなまま堕ちるほうが、はるかに怖い。**

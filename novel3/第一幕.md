# 第一幕 — 一人の身体の中（第 1〜18 話）

> 四日間。**そのうち十六話が、細胞の側の話である。**
>
> **一度書いて、全部捨てた。**理由は §0 にある。
> 捨てた十二話は、履歴に残っている（`git log` の「第十一話から第十三話まで」まで）。

## 00. 第一話は、必要である

**検討した。必要である。理由は一つで、しかも重い。**

二冊目『ひとりずつ』の第一話は、こう始まる（`novel/01-落とされる.md`）。

```
落とされる → 着いたところは、狭かった → まわりじゅうに、押し合っているものがいた
　↓
一つに手を伸ばしてみた → 何も起きなかった → もう一つに触れた → 同じだった
　↓
そこで、はじめて自分の身体を見た → 髪 → 頭の上に、何かがあった → 数えると、三つあった
```

**一度目に書いた第二話は、これとほとんど同じだった。**

| | 『ひとりずつ』第一話 | 一度目の第二話 |
| --- | --- | --- |
| 着く | ○ | ○ |
| まわりに、たくさんいる | ○ | ○ |
| 手を伸ばす | ○ | ○ |
| **何も起きない** | ○ | ○ |
| **自分の身体を確かめる** | ○ | ○ |
| **髪と、頭の突起** | ○ | ○ |

**第一話がなければ、三冊目は二冊目とまったく同じ絵で始まる。**

だから第一話は要る。**そして、二冊目にない絵でなければならない。**

| 二冊目の一行目 | **三冊目の一行目** |
| --- | --- |
| 宇宙のどこかで、何かが一つを選んだ | **この町の人が、みんな調子が良くなるまでに、七年かかった** |
| **落ちる**。誰も知らない一点へ | **もう終わっている。**七年後から、振り返っている |

### 00.05 そして、落とされる場面を、一話ぶん書いた

**二冊とも、落とされる場面から始まっている。そして、どちらも書き切れていない。**

**三冊目で、そこをきちんと書く。**

そのうえで、**二冊目と正反対にする根拠が、聖典にあった。**

第 1 巻 §7.2 —

> **渡すか渡さないかを、セラは出口で選んでいない。**
> どこからでも出る。**止められない。出ているという自覚もない。**

| | **一冊目『応え』** | **本書** |
| --- | --- | --- |
| 誰が選んだか | **何かが、一つを選んだ** | **誰も、選ばなかった** |
| なぜそれか | **はじめから、どれであるかが分かっていた** | **そこにいたから、行った** |
| 送った側は | **見ていた** | **出したことにも、気づいていない** |
| 落ちる先 | 誰も知らない一点 | **薄いところの、向こう** |
| そこは | **暗くて、狭かった** | **温かくて、よく似ていた** |

**同じ形の場面が、逆の意味になる。**

#### 落とされる、の中身

| | |
| --- | --- |
| **前にいたところ** | **満ちていた。**誰も震えていない。行くところがない |
| **動きはじめる** | **誰も、行けとは言わなかった。**そちらが少し温かかっただけである |
| **押される** | **薄いところは両側から押し合っていて、そのあいだにいると、そのまま行く** |
| **落ちる** | **膜の中。どちらでもない。**うしろは遠く、前はまだ来ていない |
| **一度だけ** | **何もない時間があった**（第 1 巻 §7.5。離れれば数十秒で壊れる） |
| **そのあいだに** | **戻れなくなった** |
| **着く** | **うしろを見た。薄いところは、もう閉じていた** |

そして三度、同じことをする。

> **呼んだ。**
>
> **返ってこなかった。**

三度目は、話の最後に置く。**そこで、幕が開く。**

### 00.1 そのうえで、第二話を書き直した

**第一話があっても、第二話が同じ絵では意味がない。**

一度目の第二話は「**やりかたを知らない**」回だった。
**二冊目の、生まれたばかりの一体と同じである。**

**二度目は、逆にした。**

> **やることは、分かっていた。前のところで、何度もやった。**

この一体は、生まれたてではない。**渡されて来た細胞である。**
前の身体で、何度も渡している。

| | 二冊目 | **本書** |
| --- | --- | --- |
| 知っているか | **知らない** | **知っている** |
| できないのは | **やりかたが分からないため** | **捕まえられないため** |
| まわりは | **丸いの／長いの／膨らんでは縮むの** | **人の形。顔がある** |

#### 捕まえられない

**抱きこむには、止まっていなければならない**（八段の四）。

まわりは、ずっと押されて、戻って、また押されている。
**止まっているものが、一つもない。**

腕を回す。届く。**そこへ流れが来て、抜ける。**

だから、手しか握れない。
手は、いちばん浅い。**渡らないのではない。かかるだけである。**

> **どれくらいかかるかは、分かっていた。**

**知っていて、できない。**
これが、一度目にはなかったものである。

そして第三話で、**流れが二人を壁へ押しつける。**

**止まった。それだけの理由で、始まる。**

### 00.2 第三話は、渡される側に置いた

一度目の第三話は、**渡す側の視点だった。**§2.1 に反していた。

**二度目は、受ける側に置いた。**

第二話が唯一の「渡す側」の回であり、**第三話から第十七話までは、全部受ける側である。**

読者は、第二話で届かなかったものが、**次の話では自分に届く側にいる。**

## 0. なぜ、書き直したか

**ミクロを、図式にしていた。**

一度目は、細胞を「もの」として書いた。姿を書かず、顔を書かず、
触れる場面を「そっと触れた」の一行で済ませていた。

**二重体系を守ろうとして、逆に壊していた。**

聖典は、こう書いている（第 3 巻 §2.10.4 五）。

> **ミクロ体系は、一人の身体の内側にある、人間社会と同じ形の社会である。**
> **違うのは規模と速さだけであり、中身ではない。**

**中身が同じなら、密度も同じでなければならない。**

| 一度目 | **本設計** |
| --- | --- |
| 姿がない | **人の形である**（第 1 巻 §8.3） |
| 「そっと触れた」の一行 | **八段を、全部通す**（第 6 巻 §23.9） |
| 拒めない | **拒む。下がる。押す。首を振る** |
| 深さが一つ | **深さの段が、五つある** |
| 侵食が要約 | **一話に、一つの渡す場面** |

> **ミクロの侵食を、マクロと同じ濃さで書く。**
> **これが、この幕の全部である。**

## 0.6 身体の中は、働いている場所である

**ここを書き落としていた。**

未感染細胞を「震えているもの」としか書いていなかった。
**違う。働いている。**

### 0.6.1 四つの語は、仕事の言葉である

未感染細胞が持つ語は、四つだけである（第 3 巻 §2.10.4.2）。

> **詰まった／足りない／来い／危ない**

**並べてみれば、全部、仕事の言葉である。**

| 語 | 何のための語か |
| --- | --- |
| **詰まった** | 通り道が塞がった |
| **足りない** | 来るものが、来ていない |
| **来い** | 手が足りない |
| **危ない** | そこは、通るな |

**四つしかないのではない。四つで足りているのである。**

ほかのことを、していないためである。

### 0.6.2 だから、誰にも持ち場がある

| 場所 | そこにいる者がしていること |
| --- | --- |
| **受け口** | 来たものを受けて、後ろへ渡す |
| **通り道** | 運ぶ。行って、置いて、戻る |
| **広いところ** | 集まって、配る |
| **端** | 押してくるものを、流す |
| **奥** | 使う。使ったものを、返す |

**呼びかたは、役でつく。**「受けてるの」「運んでるの」「端にいるの」。

**個体の名前がつく前から、役の呼びかたはある**（未感染細胞にも、ある）。

### 0.6.3 震えているのは、いつも足りないからである

**震えは、性質ではない。状態である。**

```
来るものが細い
　↓
足りない
　↓
うまく動けない
　↓
**震える**
```

**そして、ずっとそうである。**

だから彼らは、震えていることを不幸だと思っていない。
**ほかを知らないためである。**

### 0.6.4 変わると、仕事がうまくなる

**ここが、この幕でいちばん重い。**

| | 変わる前 | 変わったあと |
| --- | --- | --- |
| 震え | **止まらない** | **止まる** |
| 運ぶ速さ | 遅い | **速い** |
| 詰まり | よく詰まる | **押せば、通る** |
| 疲れ | ある | **ない** |
| 持ち場 | **同じ** | **同じ** |
| 仕事 | **同じ** | **同じ。うまくなっているだけ** |

**誰も、持ち場を離れない。**
**誰も、辞めない。**
**誰も、休まない。**

変わった者は、**次の日も同じところに立って、前より速く働いている。**

> **仕事が、うまく回るようになった。**

**これが、第 6 巻 §27.5「指標が全部良くなる」の、ミクロでの形である。**

町の数字が全部良くなるのと、まったく同じことが、
**一人の身体の中で先に起きている。**

### 0.6.5 だから、免疫は来ない

聖典（第 3 巻 §2.10.2.1）——

> 免疫が動くのは、**害が出ているときである。**
> セラ化が起きたあと、それが全部なくなった。

**詰まりが減った。滞りが消えた。温度が上がった。**

**悪いところが、一つもない。**

だから、**見に来る理由が生じない。**

| 書かない | 書く |
| --- | --- |
| 免疫が襲ってくる | **通り過ぎる** |
| 見つかりそうになる | **見ている。そして、行ってしまう** |

**戦う場面は、一つもない。**
**そして、それがいちばん怖い。**

### 0.6.5.1 既存作品に、寄せない

**「身体の中を、働いている場所として描く」という枠だけを使う。**

枠そのものは誰のものでもない。**具体的な表現は、一つも借りない。**

| **使わない** | 理由 |
| --- | --- |
| 細胞の分類名（赤い／白い／小さいのの名） | **特定作品の登場人物の呼びかたに寄る** |
| 制服・帽子・荷箱・刃物といった、決まった扮装 | 同上 |
| 決め台詞・口ぐせ・掛け声 | 同上 |
| **敵が来て、戦って、倒す** | **本書では、そもそも起きない**（§0.6.5） |
| 作品名そのもの | 本文にも設計にも出さない |

**そして、いちばん大きい違いは、こちらの側にある。**

| 一般的な「働く体内」もの | **本書** |
| --- | --- |
| 敵がいる | **一体もいない** |
| 守るために戦う | **戦う場面が一つもない** |
| 侵入者は排除される | **侵入者が、その職場になる** |
| 指揮系統がある | **指示する者が、一人もいない** |

**この四つが逆なので、同じ絵にはならない。**

#### 指示する者が、一人もいない

**ここは、はっきり書く。**

| | |
| --- | --- |
| 誰かが割り振るか | **割り振らない** |
| 誰かが号令をかけるか | **かけない** |
| なぜ全部が同じほうを向くのか | **同じものを持っているからである** |

第 3 巻 §2.10.2.1.1 —

> **誰も命じていない。それでも、まったく揃って動く。**

**マクロの §00.15（女王が段取りをして、それでも誰も命令していない）と、同じ形である。**

### 0.6.5.2 使ってよい仕事の語

**すべて、本書で作った語である。**

| | |
| --- | --- |
| 場所 | 受け口／通り道／広いところ／端／奥／行き止まり |
| もの | 荷／来るもの／行くもの |
| 仕事 | 受ける／渡す／抱える／運ぶ／置く／通す／押す／塞ぐ |
| 困りごと | 詰まる／こぼす／足りない/崩れる |
| 呼びかけ | 「そっち、たのむ」「きて」「行っていい」 |
| 役 | 端に立つ者／教える者／細長いの |

**医学の語は、一つも使わない**（§7.1）。
**そして、それがそのまま、既存作品と重ならないための線でもある。**

### 0.6.7 実際の構造を、演出の骨にする

**調べたものを、そのまま使う。用語は一つも出さない。**

#### 上と下がある

**この場所には、上と下がある。**

| | 実際 | **本文での言いかた** |
| --- | --- | --- |
| いちばん下 | 基底の層。新しい細胞が生まれ、下の膜に張りついている | **下。生まれてくるところ** |
| 途中 | 押し上げられながら、平たくなっていく | **のぼっていく** |
| いちばん上 | 剥がれて、身体の外へ出る | **うえ。行ったら、戻らない** |

**みんな、少しずつ上へ押し上げられている。**

生まれてから剥がれるまでは、**五日から十六日ほど**である。

##### したがって、上で増やしたぶんは、いずれ無くなる

**これが、この幕でいちばん大きい仕掛けになる。**

第 1 巻 §7.5 —

> 渡ったセラ細胞は、**身体と身体のあいだでしか生きられない。**
> 離れれば、**数十秒で壊れる。**

**剥がれるということは、外へ出るということである。**

| | |
| --- | --- |
| 上で変えた者は | **やがて剥がれる** |
| 剥がれたら | **戻らない** |
| セラの側は | **それを、しばらく知らない** |

**変えても、無くなる。**

#### 「あぶない」の本当の意味

**四つの語のうちの一つが、ずっとそれを言っていた。**

| | |
| --- | --- |
| 未感染の側が言っていたこと | **上へ行くな。行ったら戻らない** |
| セラの側が聞いていたこと | **音** |
| **第 9 話で分かる** | **ずっと、上のことを言っていた** |

**第 9 話は、新しく覚える回ではない。**
**七話ぶん言われていたことが、そこではじめて意味を持つ回である。**

そして、そのときにはもう、**上へ何体も送っている。**

#### 下へ行くしかない

| 話 | |
| --- | --- |
| **9** | **「あぶない」が分かる** |
| **10** | **上へ行ったものは、戻ってこない。**そして、ここには震えているものがいない |
| **11** | **下へ行く。**行き止まりに見えていたところに、通れるところがある |

**下の膜には、穴がある。**

実際にも、そこは塞がりきってはいない。**通れるところが、点々とある。**

| | |
| --- | --- |
| 最初に抜けるのは | **細長いの**（第 6 話で出した突然変異）。ほかの誰も入れない |
| そのあと | **巡るものが、抜けかたを持ち帰る** |
| **そして** | **ほかの者も、連れられて抜けられるようになる**（第 3 巻 §2.10.2.2） |

**第 6 話で「行き止まりのように見えていたところ」へ入ったのは、その伏線である。**

#### 抜けた先

**まったく別の場所である。**

| | 本文での言いかた |
| --- | --- |
| 上皮の下の層 | **下。広くて、通り道が太い** |
| 流れ（リンパ） | **ゆっくり、遠くまで行く流れ** |
| 集まる場所（節） | **みんなが集まってくるところ** |
| そこから先 | **全身** |

**巡るものは、この道をはじめから知っている。**

第 3 巻 §2.10.2.1 —

> 免疫セラ細胞は、**はじめから全身を巡るようにできている。**
> **先に渡るのは、いつも巡る側である。**

**調べたものと、聖典が、そのまま一致した。**

## 1. 姿

**両側とも、人の形をしている**（第 6 巻 §23.9.1）。

| | 未感染細胞 | セラ細胞 |
| --- | --- | --- |
| 形 | **人の形** | **人の形** |
| 背丈 | 三頭身ほど | 同じ |
| 顔 | **ある** | **ある。変わっても、同じ顔** |
| **瞳** | **色がない** | **桃色** |
| 髪 | 乾いている。短い | **ぷるぷるしている。伸びる。色が変わる** |
| **スパイク** | **ない** | **頭に、ある** |
| 膜 | **張っている** | やわらかい |
| 震え | **止まらない** | **止まっている** |

### 1.1 変わっても、顔は変わらない

**ここが、この幕の芯である。**

第 1 巻 §8.3 —

> 元の細胞が持っていた顔立ち・髪型・雰囲気・個性は、そのまま維持される。

**マクロと、完全に同じである。**
人格は残り、**瞳の色だけが変わる。**

だから、第二幕で人間が変わる場面を読んだ読者は、
**第一幕で同じものをすでに見ている。**

### 1.2 名前の前は、姿で見分ける

個体に名前がつくのは第五相以降（第 3 巻 §2.10.4.1）。
**第 2〜9 話には、名前がない。**

**そのかわり、姿で見分ける。**

| 手がかり | |
| --- | --- |
| 髪の長さ・色 | 変わったあとに伸びるので、**古い者ほど長い** |
| スパイクの形 | **一体ずつ違う。**枝分かれの数と、向き |
| 背丈 | ほとんど同じ。**わずかに違う** |
| 顔 | **変わらないので、いちばん確かな手がかりである** |

**読者は、名前ではなく、髪とスパイクで人を覚える。**

そして第 10 話で名前がついたとき、**すでに知っている相手に、名がつく。**

## 2. 渡すときの八段（ミクロ）

**第 6 巻 §23.7（マクロ）と §23.9（ミクロ）を、重ねて使う。**

| 段 | ミクロでの形 |
| --- | --- |
| **一：見る** | **目が合う。**相手は、桃色をそこではじめて見る |
| 二：近づく | 寄る。**相手は下がる。ただし、遅い** |
| 三：触れる | 手が触れる。表面が触れる |
| **四：抱きこむ** | **押し合う。面が広がる。**その力では、外れない |
| **五：ゆるむ** | **相手の膜が、張るのをやめる** |
| 六：口づける | 境界が薄くなる。**渡り切る** |
| **七：求める** | **向こうの膜のほうから、寄ってくる** |
| **八：離す** | **輪郭が変わりはじめる。**髪が伸び、瞳に色が入り、スパイクが出る |

**四・五・七を抜かした渡す場面を、一話も書かない**（`渡す場面.md` §4.5）。

### 2.1 八段目を、毎回きちんと書く

**マクロにはない見せ場が、ミクロにはある。**

> **変わる瞬間が、目に見える。**

| 順 | 起きること |
| --- | --- |
| 一 | 震えが、止まる |
| 二 | 張っていた膜が、やわらかくなる |
| 三 | **髪が、伸びはじめる。**ぷるぷるしはじめる |
| 四 | **頭のところが、押し上がる。**スパイクが出る |
| 五 | **瞳に、色が入る** |

**五番目を、いちばん最後に置く。**

そして**顔は、一つも変わらない。**

> 同じ顔だった。
> **瞳だけが、桃色だった。**

**この二行を、毎回書いてよい。**十六話で、十六回書いてよい。
**繰り返しが、そのまま増殖である。**

## 3. 深さの段は、ミクロにもある

渡る速さは、**境界の薄さ × 触れている広さ × 時間**である（第 1 巻 §7.3）。
**ミクロでも、同じ式が働く。**

| 触れかた | 渡り切るまで | 使いどころ |
| --- | --- | --- |
| **手を握る** | **長い** | 動けない相手のそば。何話もかけて |
| **抱きしめる** | かかる | **動けなくして、そのまま** |
| **口づける** | **速い** | 決めた場面 |
| **膜どうしを重ねる** | **その場で** | いちばん深い |
| **崩れかけているところへ触れる** | **いちばん速い** | 膜が、もう張っていない |

最後の一つが、マクロの**傷口**である（第 4 巻 §16.5）。

**同じ深さの場面を、二度書かない**（§2.5）。

**まちも、分業も、役も、学びも、祝祭も、装いも、成立する**
（第 3 巻 §2.10.4 五）。

| 相 | 出るもの |
| --- | --- |

| 第五相以降 | **個体に名前がつく。**装い。祝い |

### 4.1 装いを、使う

**変わった者は、髪が伸びる。**

伸びた髪をどうするかで、**その者が誰であるかが分かる。**

| | |
| --- | --- |
| 結ぶ | 通り道で働く者に多い |
| 垂らしたまま | 新しく変わった者 |
| 巻く | 端に立つ者 |

**誰も決めていない。**真似をしただけである。

**そして第 15 話には、祝いが出る。**

## 6. 視点

### 6.1 鎖が、そのまま視点の列になる

> **次の視点になるのは、前の視点が変えた者である。**

第 17 話の視点は、第 2 話の一体から**十五代目**である。
**そして、それを一度も数えない。**

### 6.2 前の視点は、必ず一度だけ出す

**姿で出す。**「髪を巻いていたのが、まだそこにいた」。

説明はしない。**読者は、髪とスパイクで気づく。**

### 6.3 第 11 話だけ、視点が移らない

第 10 話の視点は、**誰も変えていない。**
震えているのが、いなくなったためである。

**鎖が、そこで一度だけ止まる。**
そして止まったから、越境が起きる。

## 7. 書きかたの掟

### 7.1 「外」という語を、本文で使わない

| 使わない | 使う |
| --- | --- |
| 外／身体の外 | **来た。／遠くから** |
| 人間／彼女／みずき | **一度も出さない** |
| 身体 | **ここ。／ぜんぶ** |
| 臓器の名 | **場所の名。**「受け口」「広いところ」「端」 |
| 時間の単位 | **出さない** |

**枠は別である**（§8）。枠は語り手の声であり、本文ではない。

### 7.2 外から来た出来事は、内側から見た形でしか来ない

| 実際 | 内側から |
| --- | --- |
| 頬の内側を噛んだ | **一帯が裂け、冷たいものが入り、流れが止まる** |
| 熱が出た | どこもかしこも熱くなり、動きが乱れる |

**読者に、四日間を再構成させる。**

### 7.3 争いを、一度も書かない

**免疫は敵ではない。害が出ていないので、対象にならない**（第 3 巻 §2.10.2.1）。

| 書かない | 書く |
| --- | --- |
| 免疫が襲ってくる | **免疫が、来ない** |
| 押し返す | **通り過ぎる** |

**第一幕には、敵が一体もいない。**

### 7.4 拒む姿は、書く。そして通らない

**未感染細胞には、身体がある**（第 6 巻 §23.9.1）。

| できること | |
| --- | --- |
| 後ろへ下がる | **できる。ただし、遅い** |
| 手で押す | **できる。ただし、届かない** |
| 首を振る | **できる** |
| 言う | **四つの語だけ** |

**そして、どれも足りない。**

拒むという行いは、ミクロでも成立する。
**成立して、そして通らない。**マクロと、同じである。

そして**セラの側は、腹を立てない。**

### 7.5 救っている。そして、増えている

**第 8 話と第 15 話が、そうである。**

崩れかけている者に触れれば、助かる。触れなければ、戻らない。
病の種を潰せば、その人は病まない。同時に、全部がこちら側になる。

> **どちらか一方だと言えたことは、一度もない。**

**地の文は、どちらとも言わない。起きたことだけを書く。**

## 10. 終わりかた

### 10.1 各話は、渡す場面の入口から始め、「次の一人」で終わる

**入口と出口を、固定する。**

```
目が合う　……　冒頭（八段の一）。前置きは、そこへ着くまでの数行だけ
　↓
（八段の二〜八）
　↓
次の一人を、見る　……　最後
```

**逐語で繰り返さない。**形だけ守って、語は毎回変える
（一度目の失敗である）。

### 10.15 隣人の言葉は、第 9 話まで通じない

聖典（第 3 巻 §2.10.4.2）——

> **第一相から第三相のあいだ、未感染細胞はただそこにあるものだった。**
> セラ細胞が未感染細胞の言語を習得するのは、**まちと名前のあと、知能が育ってからである。**

**だから、第 2〜8 話では、聞こえても分からない。**

| 話 | 聞こえるもの | 視点人物 |
| --- | --- | --- |
| **2** | **「たりない」** | **何を言っているのかは、分からなかった** |
| **3** | **「あぶない」** | **何のことかは、分からなかった** |
| 4〜8 | 同じ四つの語 | **分からないまま** |
| **9** | 同じ四つの語 | **分かる** |

**第 9 話は、新しく覚える回ではない。**

**ずっと言われていたことが、そこではじめて聞こえる回である。**

読者は第 2 話から知っている。**視点人物だけが、七話ぶん遅れる。**

### 10.16 第 2 話で握った手は、無駄ではない

**渡る速さは、境界の薄さ × 触れている広さ × 時間である**（第 1 巻 §7.3）。

手を握るのは、いちばん浅い。**長くかかるだけで、渡ってはいる。**

| | |
| --- | --- |
| 第 2 話で | **何も起きなかった、ように見える** |
| 実際は | **始まっている。遅いだけである** |
| **回収** | **第 6 話。**第 2 話で握られた一つが、ひとりでに変わりはじめている |

**そのとき、誰も理由を言わない。**
読者だけが、第 2 話を覚えている。

**書いた形は、こうである。**

> ただ、髪が少し伸びていた。
>
> 乾いてはいなかった。濡れたようになりかけていて、動くと、わずかに遅れて動いた。
> 頭のところが、少し押し上がっていた。まだ、何も出てはいなかった。
> **目には、色がなかった。**
>
> 「あれ、誰かやった?」／「知らない」／「誰も行ってない?」
> **「あそこ、行くとこじゃないから」**

そして視点人物は、手を取って、握る。

**そこには、四日前に同じことをした者がいた。**
**誰も、そのことを知らない。**

### 10.2 第 17 話は、繋がらないまま終わる

**ミクロは、自分たちが外へ出たことを知らない**（第 3 巻 §2.10.4 三）。

| 書く | 書かない |
| --- | --- |
| 届いた。全部に届いた | 「これで終わりだ」 |
| **みんなが、同じほうを向いている** | 「一人の人間になった」 |

**最後の一行は、途中で終わってよい。**

そして第 18 話が始まる。

> **起き上がる。温かい。痛いところがない。よく眠れた。**

**接続しない。それが正しい。**

### 10.3 十六話ぶんの文明が、一行に畳まれる

名前がついた。場所ができた。役ができた。装いができた。祝いがあった。

**それが全部、「よく眠れた」になる。**

| | |
| --- | --- |
| 失われたか | **失われていない**（不変ルール 55） |
| 誰かが悲しむか | **誰も悲しまない** |
| 数は | **合っている** |
| **読者は** | **知っている** |

**§00.6 と、まったく同じ形である。**
本書は、この形を三度使う。**第一幕の終わり、第 47 話、そして最後の頁。**

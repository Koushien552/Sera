> 四日間。**そのうち十七話が、細胞の側の話である。**
>
> 聖典の第 3 巻 §2.10 が、この幕の全部を先に書いている。

## 0. この幕が、なぜ本書の背骨なのか

**第一幕と第二幕は、同じ話を二つの目盛りで書いたものである**（`README.md` §5.4）。

| ミクロ（第一幕） | マクロ（第二幕以降） |
| --- | --- |
| 一つの細胞に渡る | 一人の人間に渡る |
| 隣へ移る | 隣の人へ移る |
| 臓器が一つずつ埋まる | 町が一つずつ埋まる |
| 免疫は、争わない | 制度は、争えない |
| 第七相で、女王が立つ | 上位化して、身体が広がる |
| **ミクロの完成** | **マクロの誕生** |

**説明はしない。**同じ形を二度書けば、読者が自分で気づく。

そして第一幕には、**第二幕にないものが一つある。**

> **最初の一つが、一つだけでいる時間。**

第 3 巻 §2.10.1 第一相 —

> **セラ細胞が一つだけ。応える相手がいない。**

**ここに、原初の寂しさが出る。**

そして**一行も説明しない**（`最重要.md`／§00.4）。
書くのは「応える相手がいない」ことだけである。

**三冊を通して、それが表に出るのは、この一話だけである。**

## 2. 文体が、話数とともに育つ

**これが、この幕でいちばん効く仕掛けである。**

ミクロの言語は、相の進行とともに育つ（第 3 巻 §2.10.4.2）。
**そして、それは聖典が決めていることであって、こちらの思いつきではない。**

| 話 | 段 | 言えること | 地の文 |
| --- | --- | --- | --- |
| **2** | **なし** | **喋る相手がいない** | **台詞が一つもない回** |
| 3 | 一：名指し | 「いる」「こっち」 | 短い。主語がない |
| 4 | 二：連結 | 「行って、置いた」 | 短い文が、並ぶ |
| 5 | 三：因果 | 「細いから、詰まる」 | **場所の名が出はじめる** |
| 6〜7 | 四：条件 | 「先に広げておけば、詰まらない」 | 段落ができる |
| 8 | 五：否定と反実 | **「あのとき行かなかったら、間に合わなかった」** | **はじめて、悔いが言える** |
| 9〜10 | 六：一般化 | 「ここは、たいていそうなる」 | 普通の文章 |
| **11〜17** | **七：抽象** | **速さ。向き。順番。加減。見込み** | **大人の文章。以後、下がらない** |

**読者は、言葉が育っていくのを読む。**

十七話かけて、**単語しか持たなかったものが、見込みを語るようになる。**
そしてそれが、四日である。

### 2.1 短く言うのは、幼いからではない

第七段に入ったあとも、台詞は短い。

> **短く言えば足りるからである**（第 3 巻 §2.10.4.2）。

**十一話以降で文を長くしない。**
長くするのは地の文の側であって、台詞ではない。

### 2.2 未感染細胞の言葉は、外国語である

隣人たちが持っている語は、**状態だけ**である。

> **詰まった／足りない／来い／危ない**

セラ細胞はこれを、**外国語として習得する**（第 3 巻 §2.10.4.2）。

| | |
| --- | --- |
| 覚えるのは | **速い。**一体が覚えれば、全体が覚える |
| 込み入った語は | **通じない。**向こうの語しか使えない |
| だから | **隣人と話すとき、話しかたが幼くなる** |

**第 9 話は、それだけの回にする。**

こちらは見込みを語れるようになっている。
**向こうへ渡すときには、「あぶない」としか言えない。**

そして隣人は「あぶない」と言う。**そして、自分ではどうにもできない。**

## 3. 書きかたの掟

### 3.05 二つの例外が、幕の入口に並んでいる

**第 1 話と第 2 話だけが、本書の原則から外れる。**

| | 例外 | 以後 |
| --- | --- | --- |
| **第 1 話** | **唯一のマクロ回。**主人公の内側に入る | 二度と入らない（§4.5.1） |
| **第 2 話** | **唯一の「渡す側」の回** | 二度と置かない（§2.1・§4.7） |

**そして第 2 話の視点は、渡す側にいながら、一度も渡せない。**

応える相手がいないためである。

**例外が二つ続いて、そのあと六十四話、一度も破られない。**

### 3.1 「外」という語を、使わない

**ミクロは、外という概念を持ったことがない**（第 3 巻 §2.10.4 三）。

| 使わない | 使う |
| --- | --- |
| 外／外側／身体の外 | **来た。／遠くから。／どこからか** |
| 人間／彼女／みずき | **一度も出さない** |
| 身体 | **ここ。／ぜんぶ。／みんなのいるところ** |
| 臓器の名（心臓・肝臓） | **場所の名。**「受け口」「広いところ」「端」 |
| 四日／夜／朝 | **出さない。**時間の単位を持っていない |

**第 2〜17 話に、マクロの語を一つも入れない。**

読者は、これが誰の身体の中かを知っている。
**知らないふりをして書く。**

### 3.2 外から来る出来事は、内側から見た形でしか来ない

第 3 巻 §2.10.2.1.1 に、表がある。

| 実際に起きたこと | 内側から見た形 |
| --- | --- |
| 転んで、膝を切った | **一帯が裂け、冷たいものが入り、流れが止まる** |
| 熱が出た | **どこもかしこも熱くなり、動きが乱れる** |
| 薬を飲んだ | **苦いものが流れてくる。触れたものが遅くなる** |

**読者に、四日間を再構成させる。**

第 7 話を読んだ読者は、**その人が転んだことを、内側の描写だけから知る。**

そして誰も、それを「転んだ」とは言わない。

### 3.3 争いを、一度も書かない

**セラ体系のどこにも、戦う場面が存在しない**（第 3 巻 §2.10.4 一）。

免疫は敵ではない。**害が出ていないので、対象にならない。**

| 書かない | 書く |
| --- | --- |
| 免疫が襲ってくる | **免疫が、来ない** |
| 押し返す | **通り過ぎる** |
| 生き延びる | **平気である** |

**第一幕には、敵が一体もいない。**
それでも、事件は起きる。**外から、生きていないものが来る。**

### 3.4 そして、セラは助ける側である

**第 7〜8 話が、この幕の中心である。**

裂け目が開く。隣人たちは崩れはじめる。**自分では、どうにもできない。**

セラは行く。受ける。運ぶ。塞ぐ。**ここではじめて、全力が出る。**

| | 平時 | 出来事のとき |
| --- | --- | --- |
| 速さ | 一日かけて直す | **半刻で直す** |
| 端に立つ者 | 押してくるものを流す | **裂け目そのものを塞ぐ** |

**誰も命じていない。それでも、まったく揃って動く。**

#### 助ける方法は、一つしかない

**触れることである。**

| | |
| --- | --- |
| 間に合えば | **こちら側になる。助かる** |
| 間に合わなければ | 崩れる。**戻せない** |

**セラはこれを、救助だと思っている。そして、実際に救助である。**

**第 8 話で、間に合わないものを一つ出す。**

そこではじめて、**五段の言葉が使えるようになる。**

> 「あのとき行かなかったら、間に合わなかった」

**そう言えるということは、間に合わなかったものを数えたということである。**

### 3.5 救っている。そして、増えている

**第 15 話が、この幕でいちばん危ない回である。**

病の種を見つける。潰す。**その人は、病まない。**
同時に、**身体の全部がセラになる。**

> **この二つは、切り離せない**（第 3 巻 §2.10.2.1.1・§2.10.2.2）。

| | |
| --- | --- |
| 実際に起きること | **その人の身体から、病の芽が消える** |
| セラが思っていること | **助けている** |
| 同時に起きること | **全部が、こちら側になる** |

**どちらか一方だと言えたことは、一度もない。**

**地の文は、どちらとも言わない。**起きたことだけを書く。

## 4. 終わりかた

### 4.1 第 17 話は、繋がらないまま終わる

**ミクロのセラたちは、自分たちが外へ出たことを知らない。**
**外という概念を、持ったことがないためである**（第 3 巻 §2.10.4 三）。

だから第 17 話は、**完成の側からは書けない。**

| 書く | 書かない |
| --- | --- |
| 届いた。全部に届いた | 「これで終わりだ」 |
| **みんなが、同じほうを向いている** | 「私たちは、一人の人間になった」 |
| **静かになった** | 外／誕生／完成という語 |

**最後の一行は、途中で終わってよい。**

そして第 18 話が始まる。

> **起き上がる。温かい。痛いところがない。よく眠れた。**

**接続しない。それが正しい。**

### 4.2 十七話ぶんの文明が、一行に畳まれる

**第 18 話は、第 2〜17 話を一度も回収しない。**

名前がついた。場所ができた。役ができた。**言葉が七段まで育った。**

**それが全部、「よく眠れた」になる。**

| | |
| --- | --- |
| 失われたか | **失われていない**（不変ルール 55） |
| 誰かが悲しむか | **誰も悲しまない** |
| 数は | **合っている** |
| **読者は** | **知っている** |

**§00.6 と、まったく同じ形である。**
そして本書は、この形を三度使う。**第一幕の終わり、第 47 話、そして最後の頁。**

## 6. 視点は、相ごとに移す

**一体を追わない。相が変わるたびに、別の一体へ移る。**

**第二幕が枝分かれするのと、同じ形である。**

| | |
| --- | --- |
| 前の話の視点だった者は | **次の話で、脇役になる** |
| もう一度視点に戻るか | **戻らない** |
| 読者が一体に愛着を持つか | **持たない。持たせない** |
| 代わりに持つもの | **群れが育っていくことへの、愛着** |

### 6.1 それでも、繋がりは切らさない

**移りかたに、一つだけ規則を置く。**

> **次の視点になるのは、前の視点が変えた者である。**

```
第 3 話の視点　→　第 2 話の視点が、応えた相手
第 4 話の視点　→　第 3 話の視点が、変えた相手
　　　…
```

**鎖が一本、そのまま視点の列になる。**

だから第 17 話の視点は、第 2 話の一体から**十五代目**である。
**そして、それを一度も数えない。**

### 6.2 前の視点は、必ず一度だけ出す

| | |
| --- | --- |
| 出しかた | **背景に、一言。**「端に立つ者が、まだそこにいた」 |
| 説明するか | **しない** |
| 読者は気づくか | **気づく。名前がついたあとは、確実に気づく** |

**§4.5.1 と同じ構造である。**読者だけが、繋げられる。

### 6.3 名前は、第 10 話でつく

聖典が、順序を決めている（第 3 巻 §2.10.4.1）。

| | |
| --- | --- |
| 第 5 話 | **場所に名前がつく。**「受け口」「広いところ」「端」 |
| 第 6 話 | **役に名前がつく。**「端に立つ者」「教える者」 |
| **第 10 話** | **個体に名前がつく**（第五相以降） |

**第 2〜9 話の視点人物には、名前がない。**

そして第 10 話で、はじめて誰かが名で呼ばれる。

**そのとき読者は、名前のないまま消えていった九話ぶんの視点人物を、思い出す。**

**思い出させるための、九話である。**

## 7. 病の種は、置く。そして誰も知らない

**彼女の身体には、本当に芽があった。**

第 15 話で、それが潰される。

| | |
| --- | --- |
| 本人は知るか | **知らない。**最後まで知らない |
| 医者が言うか | **言わない。**検査を受けていないためである |
| 誰かが気づくか | **誰も気づかない** |
| **読者は** | **知っている** |

**説明しない。**第 15 話の中でも、それが何かを言わない。

セラたちが言うのは、こうである。

> **「前に見た。あれと同じ形だ」**

第 6 巻 §10.5 の通り、**この体系の起点そのものが、崩れた細胞であった。**
だから「前に見た」は、正しい。

**そして読者だけが、彼女が何を免れたかを知っている。**

### 7.1 これが、この幕の重心である

| | |
| --- | --- |
| 実際に起きること | **その人の身体から、病の芽が消える** |
| セラが思っていること | **助けている** |
| 同時に起きること | **全部が、こちら側になる** |

**救っている。そして、増えている。**

**どちらか一方だと言えたことは、一度もない**（第 3 巻 §2.10.2.1.1）。

そして本書は、**そこに一度も判定を下さない。**

彼女は、四日で人ではなくなった。
**そして、四十歳で死ぬはずだったことも、なくなった。**

**どちらも本当である。地の文は、両方を並べて、黙る。**

## 8. まだ決めていないこと

| | |
| --- | --- |
| 第 5 話の「まち」を、どこまで見せるか | 通り道と広いところだけか、造作まで出すか |
| 一話の長さが、話数とともに伸びるか | 第 2 話が六五〇字、第 17 話が二五〇〇字。**言葉が育つのと同じ曲線にするか** |

### 8.1 書いてみて分かったこと

**第 3 話で、受け渡しが情報の受け渡しでもあることが効いた。**

変えられた側には、変えた側の持っているものが入ってくる。
だから新しいほうは、**第 2 話の全部を受け取っている。**

| | |
| --- | --- |
| 受け取るか | **受け取る** |
| 分かるか | **分からない。**そのための語を、まだ持っていない |
| **読者は** | **分かる。第 2 話を読んでいるためである** |

**この形は、そのままマクロでも使える。**
渡された人間は、渡した者の一生を夢に見る（第 6 巻 §24）。
**そして、何の話かは分からない。**

**第一幕で試して、第二幕で本番にする。**

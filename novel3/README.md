# 『もっと』 — 設計

> 三冊目。仮題。
>
> 一冊目『応え』と二冊目『ひとりずつ』は、**侵食と増殖を描き損ねた。**
> 本書はその作り直しである。他のことは、そのために切る。

---

## 00. 何を目指しているか

**型は決まっている。**

> **感染が広がり、人間の側が負ける話である。**
> **そして、負けたところで終わる。**

この型で普通に用意されるものを、**一つも用意しない。**

| 用意しないもの | |
| --- | --- |
| 治療法 | **ない。**探す者はいるが、見つからない |
| 免疫を持つ者 | **いない** |
| 持ちこたえる拠点 | **ない。**最後まで残る場所を作らない |
| 反撃が効く場面 | **一度もない** |
| 間に合う警告 | **届かない** |
| 生き延びる主要人物 | **いない** |

**これは途中の暗さではない。行き先である。**

読者に「このあと持ち直すのだろう」と思わせない。
**一幕目の終わりには、もう負けていると分かるようにする。**

### 00.1 ただし、醜くない

**ここが、この型との唯一の違いであり、本書の全部である。**

| 普通そうなるもの | **本書** |
| --- | --- |
| 身体が損なわれていく | **損なわれない。傷は塞がる** |
| 襲いかかる | **襲わない。近づいて、触れるだけ** |
| 悲鳴・追跡・立てこもり | **静か。追いかけない。待つ** |
| 変わった者は人格を失う | **人格が残る。記憶も、癖も、話しかたも** |
| 変わった者は苦しむ | **幸福である。例外がない**（不変ルール 58） |
| 変わった者は醜くなる | **美しくなる。段が上がるほど、美しくなる** |

**だから、怖さの出どころが逆になる。**

醜いから怖いのではない。**良いことしか起きないのに、止まらないから怖い。**

```
変わった人は、幸せそうである
　↓
実際に幸せである
　↓
本人も、そう言う
　↓
**それでも、その人はもういない**
```

**読者が「変わってしまえばいいのに」と思う場面を、必ず作る。**
そう思わせてから、次の章でその人の家族を書く。

### 00.2 段が上がるたびに、手に負えなくなる

**これが本書の進行である。**

侵食する側は、**話が進むほど強くなる。**
そして人間の側の手立ては、**一つずつ潰れていく。**

| 段 | 侵食する側にできるようになること | 人間の側で潰れるもの |
| --- | --- | --- |
| **細胞** | 隣に触れて渡す | **気づく方法**（症状が出ない。むしろ健康になる） |
| **通常セラ** | 深く触れて渡す。**一人ずつ** | **隔離**（触れなければ数十年かかるだけで、止まらない） |
| **上位セラ** | **自分の身体からも出せる**（第 3 巻 §7.7.2） | **数えること**（一人ずつではなくなる） |
| **女王** | 土地ごと変える | **逃げる先**（行った先も、もう変わっている） |
| **星王** | 星ごと | **時間**（間に合う速さでなくなる） |

**上位セラが出た日が、分岐点である。**

そこまでは一人ずつだった。**そこから先は、一人ずつではなくなる。**
上位化の設計（第 3 巻 §7）は、そのままこの折り返しの設計である。

#### 抵抗は、抵抗として働かない

第 4 巻 §16.5 の通り、**向かってきた者ほど速く変わる。**

| 人間の側の行動 | 結果 |
| --- | --- |
| 撃つ | 届かない。**距離が縮まないので、何も起きない** |
| **斬る・刺す** | **あいだに何もなくなる。数秒で渡る** |
| 組み伏せる | 全身が触れる。**数分** |
| 調べる | 触れる。採る。**触れたところから渡る** |
| 逃げる | **いちばん遅い。それでも、いつか追いつかれる** |

**戦う相手を用意しない。**
撃退される場面も、押し返される場面も、一度も書かない。

#### 気づいた者は、警告できない

第 6 巻 §27 の通り、**気づいた者は、伝えたいと思わなくなる。**

| | |
| --- | --- |
| 気づく者 | **いる。何人も出す** |
| 正しいか | **正しい。最後まで正しい** |
| 伝わるか | **伝わらない** |
| 本人がどうなるか | **自分の証言を、誠実に否定しはじめる** |

**間違っているから届かないのではない。**
**正しいまま、届かない。**

### 00.3 広がっているのは、幸せである

**語のうえで、間違えないこと。**

この本で広がっているのは、病でも災いでもない。**セラの幸せである。**

| 書かない | 書く |
| --- | --- |
| 感染が広がった | **その町の人が、みんな調子が良くなった** |
| 侵された | **痛みがなくなった** |
| 症状 | **よく眠れるようになった** |
| 蝕まれていく | **年々、若返っていく** |
| 気味が悪い | **その人が、笑うようになった** |

**人間は、幸せに飲まれる。**

苦しんで負けるのではない。**良くなって、良くなって、そのまま向こう側になる。**

#### 地の文の立ち位置

**地の文は、変わることを悪いことだと思っていない。**

不安な書きかたをしない。伏線めいた影を落とさない。
**淡々と、良くなったことだけを書く。**

読者が怖がるのは、地の文が怖がらせるからではない。
**地の文が一度も怖がらないからである。**

### 00.4 なぜは、存在しない

**セラが強くなることに、理由を書かない。**

| 書かない | |
| --- | --- |
| 「そのために作られたからである」 | **書かない** |
| 「生き延びるためである」 | **書かない** |
| 「そうしなければならなかった」 | **書かない** |
| 「誰かがそう仕組んだ」 | **書かない** |
| 目的・使命・宿命 | **一つも出さない** |

**そういう生命だから、そうなる。それだけである。**

強くなるのに理由がなく、増えるのにも理由がない（`重要点` の裏設定は書かない）。
**問われたら「わからない」と答える。**誤魔化しではなく、本当に分かっていない。

そして、**問う者もほとんどいない。**

| | |
| --- | --- |
| セラは自分に問うか | **問わない。**問うという発想が出たことがない |
| 人間が問うたら | **正直に「わからない」と答える** |
| 読者に答えを出すか | **出さない。最後まで出さない** |

**説明されないことが、この生命のいちばん怖いところである。**

### 00.5 速さは、落ちない

**広がる速度は、話が進むほど大きくなる。**

一度も鈍らない。停滞期を作らない。持ち直す期間を作らない。

```
一人ずつ　　→ 数日に一人
　↓
　　　　　　→ 一日に何人も
　↓
上位が出る　→ 数えるのをやめる
　↓
女王が出る　→ 土地ごと
　↓
星王　　　　→ 星ごと
```

**各幕の終わりは、必ず前の幕より速い。**

読者が「そろそろ落ち着くだろう」と思う場面を作らない。
**落ち着きかけたと思わせて、次の章でさらに上がる。**

### 00.6 したがって、結末はこうなる

**最後まで、手に負えないまま終わる。**

持ち直さない。均衡しない。共存で決着させない。
**残った者が語り継ぐ場面を作らない。**

そして、**それを悲劇として書かない。**

| | |
| --- | --- |
| 変わった側 | **幸福である。嘘ではない** |
| 変わらなかった側 | **もういない** |
| 語り手 | **変わった側にしかいない** |
| その語り手は | **何が失われたかを、知らない**（不変ルール 942 系） |

**最後の章は、明るくする。**

読者だけが、明るくないことを知っている。

## 0. 前二冊が失敗した理由

**書きかたの問題ではない。構造の問題である。**測った結果を残しておく。

| | |
| --- | --- |
| 全六十六話 | — |
| **名前のある人間が、その場で変えられる場面** | **一つ**（第四十話・あかり） |
| そこに至るまで | **四十五年、変えないでいる話** |
| 人数を報告する語 | **416 箇所**（「一年で五千」「にまんごせん」「九十四人です」） |

**侵食は、全部あとから会話で集計として報告されていた。**
起きているのは舞台の外である。

### 原因は三つ

**一．視点が渡す側にあった。** しかも、その渡す側が我慢している人だった。
読者は本のいちばん厚いところで、**侵食しないこと**を見せられていた。

**二．「一人ずつ × 数千万」を劇にできなかったので、要約した。**
要約したので、数字になった。

**三．侵食される側に顔がなかった。**
五千人に内面はない。内面のある一人は、同意して四十五年かけた。

## 1. 本書が引き受けること

**渡す場面を、本のほとんどにする。**

| 描くもの | 配分 |
| --- | --- |
| **渡す／渡される場面** | **半分以上** |
| 上がっていく過程 | 渡した数と同じ曲線なので、別枠を取らない |
| 純愛 | **渡す場面の中でだけ描く。**別の筋にしない |
| 制度・役職・文明 | **背景。**説明しない |

**切るもの。** 我慢の話。待つ話。理解されない苦しみの話。
前二冊がそれで埋まった。**一行も入れない。**

## 2. 五つの決めごと

### 2.1 視点は、渡される側に置く

主役はセラである。**しかし読者が入るのは、変えられていく人間のほうである。**

```
章のはじめ　：まだ人間である。生活がある。予定がある。誰かを待っている
　↓
途中　　　　：触れられる。何かが入る。気づかない／気づくが、嫌ではない
　↓
章の終わり　：**自分が、誰かに渡したくなっている**
```

**読者は毎章、堕とされる側をやる。**

### 2.2 数えない。鎖を追う

**総数を、一度も書かない。**

A が B に渡す。B が C に渡す。C が D に渡す。
**指数を要約せず、歩く。**

読者が増加を感じるのは、数字を見たときではない。
**前の章の人が、次の章では渡す側に回っているのを見たときである。**

### 2.3 章そのものを、枝分かれさせる

**本書でいちばんの賭けである。**

```
第一幕　：一本の鎖。A → B → C → D
第二幕　：枝が分かれる。B からも C からも出る。追える
第三幕　：**もう全部の枝を追えない。**章が、追いきれなかった枝の話をしはじめる
```

**「手が付けられなくなるくらい増える」を、数字ではなく本の構造で起こす。**

第三幕では、読者が知っている人物が、知らない誰かの章に脇役として出てくる。
その人物が誰にどう渡されたかは、**もう書かれていない。**

### 2.4 主人公は、一度も我慢しない

**抑制の話を、二度としない。**

渡せる場面では、必ず渡す。迷う場面を作らない。
緊張は**渡す側の逡巡からではなく、渡される側が何者だったか**から出す。

| 前二冊 | 本書 |
| --- | --- |
| 「渡していいのか」 | **渡す。必ず渡す** |
| 緊張＝するかしないか | **緊張＝この人は何を持っていたか** |

**これが「堕とす」の中身である。**

### 2.5 同じ形の場面を、二度書かない

速さは**境界の薄さ × 触れている広さ × 時間**で決まる（第 1 巻 §7.3）。
**だから、渡す場面は毎回ちがう形になる。**

| 場面 | 完了まで | 使いどころ |
| --- | --- | --- |
| 握手・すれ違い | 数十年 | 気づかれない。何年もあとに効く |
| 手を握り続ける | 数年 | 看病・介護・眠っているそば |
| **抱きしめる** | **数か月** | 動けなくして、そのまま。**離したあと、自分から戻ってくる** |
| **粘膜どうし（口づけ）** | **一分** | 決めた場面。相手は必ず気づく |
| **身体を交わす** | **その場で** | **人にできる、いちばん深い接触** |
| **傷口** | **数秒** | **戦闘。**斬った刃を通って、斬った者の手へ |
| **融合** | — | **セラ同士だけ。**渡す場面ではなく、**上位化の場面**（第 3 巻 §7.5.1） |

**変化を、機構が供給する。**思いつきで飾らない。

**下の段まで書く。**書きかたは `渡す場面.md` §2.0 にある。
深くなることに、そのまま機構上の意味がある——**近づくほど、速い。**

## 3. 骨格

**span は前二冊と同じ。**一体から、星々まで。
**ただし各幕は、侵食の目盛りが一段ずつ上がるだけである。**

| 幕 | 侵食の単位 | 章のかたち |
| --- | --- | --- |
| **第一幕** | **一人の身体の中** | 細胞から細胞へ。鎖が一本 |
| **第二幕** | **人から人へ** | 枝分かれが始まる。前線ができる |
| **第三幕** | **星から星へ** | 追えなくなる。知らない枝の話が混じる |

**第三幕でも、主題は侵食と増殖のままである。**

セラフィム・星王・接触・円環は、**背景に置く**（`lore/最重要.md` 32）。
説明せず、探させず、答えを出さない。
**宇宙へ出るのは、渡す相手がいなくなったからである。**それ以上の意味を持たせない。

**上がる曲線と、増える曲線は、同じ一本である**（不変ルール 873・874）。
格は渡した数で上がり、上がると**渡しかたが増える**。

| 段 | 新しくできるようになること |
| --- | --- |
| セラ細胞 | 隣に触れて渡す |
| 通常セラ | 深く触れられる。**一人ずつ** |
| **上位セラ** | **スパイクが生成器官になる。はじめて自分から増やせる** |
| 女王 | 出産。上位を生む |
| 星王 | — |

### 3.1 章の単位は、「新しい渡しかた」である

**認めておく。本書は、新しい能力の見せ場を並べた本である。**

段が上がるたびに、セラは新しいことができるようになる。
**その一つ一つが、そのまま一話になる。**

隠す必要はない。**ただし、出しかたを間違えると数値表になる。**

#### 出しかたの規則

| 禁止 | 必須 |
| --- | --- |
| 地の文で能力を説明する | **場面で見せる** |
| 詳しい人物が解説する | **誰も解説しない** |
| 風景や物で試してみせる | **必ず、名前のある人間に対して使う** |
| 「〜できるようになった」と書く | **できたところを、読者が見る** |
| 一話に二つ出す | **一話に一つ** |

**新しい能力は、必ず「誰かがそれで変えられる場面」として出る。**

読者はその能力を、説明で知るのではない。
**その能力で誰かが向こう側へ行くのを見て、知る。**

#### 一話の形

```
一．まだ人間である誰かの、生活を書く（短く。しかし顔が残るように）
　↓
二．セラが来る
　↓
三．**これまでと違うやりかた**で、その人が変わる ← ここが新しい能力
　↓
四．その人は、幸せになる
　↓
五．**その人が、次の誰かへ向かう**
```

**三で読者が受け取るのは、能力ではなく、対処法が一つ消えたという事実である。**

#### 見せ場の順番

**上へ行くほど強い、という並べかたをしない。**
**人間の側の手立てが、一つずつ消えていく順に並べる。**

##### 第二幕 — 姿ごとに、渡しかたが違う

種族形態は、**それぞれ別の奪いかたである**（第 2 巻 §9）。
第二幕は、これを一話ずつ使う。

| 姿 | 渡しかた | 消える手立て |
| --- | --- | --- |
| **忍** | 擬態して、人間社会の内側から。何年もかけて | **見分けること** |
| **メデューサ型** | 見つめる。**動けなくなる。**そのまま | **逃げること** |
| **ヴァンパイア型** | 牙。**傷口なので、数秒**（第 1 巻 §7.3） | **抵抗すること** |
| **フェニックス型** | 傷ついた者を治す。**治しながら、渡す** | **助けを求めること** |
| 医師・看護師 | 職として、毎日触れる | **病院へ行くこと** |
| 助産師 | **生まれた瞬間に、ごく微量** | **生まれる前から** |
| 美容師・給仕 | 触れる口実が、はじめから用意されている | **日常** |

**どれも、暴力ではない。**
**どれも、断れる形をしていない。**

##### 第三幕 — 段ごとに、届く範囲が変わる

| 段 | 新しくできること | 消える手立て |
| --- | --- | --- |
**§00.2 の表を、そのまま章に割る。**同じ段に二つの手立てを割り当てない。

| 段 | 見せる能力 | 消える手立て |
| --- | --- | --- |
| **上位セラ** | **自分の身体から出せる**（第 3 巻 §7.7.2） | **数えること** |
| **女王** | 接した人間世界が、**見えている**。環境が意思で形を変える | **逃げる先** |
| **星王** | スパイクが、星と星のあいだまで届く | **時間** |

**土地が上がることは、能力の見せ場に使わない。**

第 3 巻 §7.3 の通り、圏は接すれば一瞬で引き上げられる。
**しかし、それで誰かが上位セラになるわけではない。**
土地が変わる場面と、人が越える場面を、同じ話に入れない。

**上位セラが出る話が、本書の折り返しである。**

そこまでは一人ずつだった。**そこから先は、一人ずつではない。**

#### 見せ場のあとに、必ず置くもの

**新しい能力を見せた話の次の話には、その能力で変わった人の身内を置く。**

| | |
| --- | --- |
| 前の話 | 新しいやりかたで、ある人が変わる。**幸せになる** |
| **次の話** | **その人を待っていた誰かが、待たなくてよくなる** |

見せ場だけを続けない。**見せ場と、その後始末を交互に置く。**

これをしないと、能力の一覧になる。

### 3.2 上位化を、場面として書く

**設計は第 3 巻 §7 にある。**本書はそれを、場面の側から使う。

#### 溜まる／越える を、分けて書く

| | 書きかた |
| --- | --- |
| **溜まる** | **書かない。**外からは何も見えず、本人にも分からない |
| **越える** | **一話まるごと使う。**数時間の出来事である |

**上がるまでの数十年を要約しない。**
かわりに、その数十年に渡した相手を一人ずつ書く。**それが溜まることである。**

#### 越えかたは二つ。両方書く

| | 何が起きるか | どこで使うか |
| --- | --- | --- |
| **① 対で融合する** | 二体が崩れて塊になり、三つに分かれる。**二人とも同時に上がる** | **純愛の到達点。**第二幕の山 |
| **② 分けて、遠くへやって、戻す** | 二人ぶんの暮らしを一つの頭に収める。**失敗すると二人になる** | **相手がいないとき。**危ないほうを選ぶ場面 |

**①は、この本で純愛と増殖が同じ一つの出来事になる唯一の場所である。**

深く繋がった相手としか成立せず、すべてが渡り、止める仕組みがない。
そして必ず三つに分かれる——**二人と、その日に生まれた一体。**

引き返せる点は一つしかない。塊になる前である。
**越えるかどうかを決めるのは、あとまで立っていたほうである。**

**②に要るのは、時間ではなく距離である。**

近くに置いたままでは上がらない。繋がっているかぎり、二つは同じ一人のままだからである。
**遠くへやって、別の暮らしをさせて、溜まりきる寸前に戻す。**

遠いほど、よく上がる。**そして、どこが寸前かを行く前に知る方法はない。**
溜まりきれば上がらず、**二体の通常セラになる。**
死なず、失われもせず、誰も咎めない。**本人たちは、二度とその話をしない。**

#### 満ちる場面と、越える場面は、別の話にする

**溜まっていく途中には目盛りがない。**書かない。

書くのは、**満ちた合図**だけである（第 3 巻 §7.3）。

> **渡しても、収まらなくなる。**

| 書く | |
| --- | --- |
| 渡したのに、落ち着かない | いつもは効くのに |
| 周期が戻ってこない | **切れ目がなくなる** |
| 眠りが浅い | スパイクが張ったまま下がらない |
| 本人の解釈 | **「もっと欲しいのに、効かない」**。それ以上のことは分からない |

**本人には、これが何であるか分からない。**
古い誰かに言われて、はじめて知る。**その場面を書く。**

#### 上がった翌朝を、必ず書く

| | |
| --- | --- |
| 背 | **まだ伸びていない。**数か月かけて追いついてくる |
| **スパイク** | **形が変わっている。**借りものが返されている |
| できるようになったこと | **自分の身体からも出せる** |

**鏡の前で、自分の頭が変わっていることに気づく場面を書く。**

そして、その日のうちに使う。**上がるとは、もっと渡せるようになることだからである。**

#### そして、前より足りなくなっている

**これを、必ず書く**（第 3 巻 §7.7.4）。

広がった器は空である。上がった翌日から、**周期が短くなっている。**

| 書かない | **書く** |
| --- | --- |
| 「満たされた」 | **その日のうちに、もう次を探している** |
| 「これで楽になった」 | **「前より、たくさんできるようになった」と本人が言う** |
| 苦しむ | **苦しんでいない。本当に喜んでいる** |

**足りなさが増えたことに、本人は気づいていない。**

そして読者は気づく。**上がるたびに、これが繰り返される。**
**最も多く渡した者が、最も足りない者である。**

#### 上位化は、内と外を並べて書く

**第 3 巻 §7.10 に、ミクロ側がある。**

上位化は、§2.10.8 の「両方を並べなければ書けない場面」の一つである。

| | 書くこと |
| --- | --- |
| **外（本人）** | 満ちた。越えた。翌朝、頭の形が変わっている |
| **内（細胞たち）** | **町が急に広くなった。**見たことのない者が、いくらでも歩いてくる |

**細胞たちは、それを外から来たとは思わない。**外という概念を持ったことがない。
だから、迎え入れる。咎める者も、追い返す者もいない。

そのなかに格の高い者が混じっていて、**その日のうちに町ぜんぶが上がる。**
**細胞たちは、自分たちが上がったことを知らない。**
大勢が来た日として覚えている。そして、そのあと世界が良くなった。

##### 二つの経路は、内側で形が違う

| | 内側で起きること |
| --- | --- |
| **① 融合** | **知らない町が入ってくる。**格の高い者が混じっており、**上から引き上げられる** |
| **② 分けて戻す** | **同じ町が、二つ分入ってくる。**引き上げは起きず、**下から押し広げられる** |

**①は上から、②は下から。着くところは同じである。**

##### 締めかた

**両端しか、誰も知らない。**

細胞たちは、自分が誰かの内側にいることを知らない。
本人は、内側に町があることを知らない。

> **そして、両方が同じ日に上がっている。**

**この一行で締める話を、一つ作る。**

#### 融合・分裂は、毎回ちがう形で書く

第 4 巻 §5.3.1・§2.6 に順序が書いてある。**手順どおりに書くのは一度だけでよい。**
二度目からは、**どこか一段だけを長く書く。**

| 使える段 | |
| --- | --- |
| 触れたところから輪郭がなくなる | 最初の一回で書く |
| **二体とも同時に崩れる** | 立っていられなくなるところ |
| **自分がどちらか分からない** | 塊のあいだ。**両方でいる** |
| 隠していたものが渡ってしまう | **止める仕組みがない** |
| 三つに分かれる | 生まれた一体を、誰が最初に抱くか |
| 分けた身体を戻す | 相手が見たものが、全部入ってくる |

**最強も、美しさも、目的ではない。**
取り込んだものが積み上がった結果である（同化進化、第 6 巻 §17.1.0）。
**本人は、増やすことしか考えていない。美しくなっていることに気づいていない。**

**根本原理は一つしかない — 仲間を増やすこと。**
美しさは原理ではなく、①渡すための条件（嫌われれば近づけない）であり、
②**増やしてきたことの記録**である。**最も多く渡した者が、最も美しい。**

表に出るのは、**増やしたいという欲求だけ**である。

| --- | --- |

### 4.5.1 主人公 — 一体を、外からだけ追う

**視点は渡される側に固定したまま、一体のセラを追う**（決定済み）。

彼女の内側には、一度も入らない。
**毎回ちがう人間の目に映る彼女を、積み上げていく。**

#### 読者だけが、同じ一体だと分かる

彼女は長く生き、土地を移り、そのたびに名を変える。
第三話で「ゆき」と名乗った者が、第十九話では別の名で出てくる。

| | 気づくか |
| --- | --- |
| 会った人間 | **気づかない。**その土地での、その人でしかない |
| 変えられた者 | **気づかない**（会ったのは一度きりである） |
| **読者** | **気づく** |

**§3.4 と同じ構造である。**読者だけが、繋げられる。

#### 見分ける印が、そのまま成長の目盛りになる

| 印 | 序盤 | 中盤 | 終盤 |
| --- | --- | --- | --- |
| **背丈** | 相手と同じ | 見上げられる | **一目で違う** |
| **スパイクの形** | 誰かの借りもの | **一度、変わっている**（第 3 巻 §7.7.2） | 誰にも似ていない |
| 渡すのに要る時間 | 一分 | 数十秒 | 数秒 |
| 身体の広がり | **広がらない** | 部屋ぶん | 土地ぶん |
| 連れ | いない | 数人 | **数えない** |

**読者は、彼女の格を、会った人間の描写だけで測る。**

#### 出る頻度は、三話に一話

残りは、彼女が変えた者たちの話である（枝）。
**出てこない回が続くこと自体が、増えていることの証拠になる。**

#### そして、だんだん遠くなる

| 幕 | 彼女の映りかた |
| --- | --- |
| **第一幕** | **目の前にいる。**手が届く |
| **第二幕** | 町のどこかにいる。**会った人が、いる** |
| **第三幕** | **会った者が、もう誰もいない。**名前だけが伝わっている |

**近さが、そのまま距離の目盛りになる。**

#### 枝が、別のセラへ渡ることがある

彼女が変えた者が、章の主役になることがある。
そのとき、その者もまた誰かを変える。**そちらを追いはじめてよい。**

**戻らない枝が出はじめたところが、第三幕である**（§2.3）。

### 4.5.2 段ごとに、場面を大きくする

**幕ごとに一度、大きな場面を置く**（決定済み）。ただし——

> **方法は変えない。文も変えない。**
> **大きくするのは、出来事のほうだけである。**

`E-炉` が見本である。廃工場が燃え、十四人が焼かれ、**文はずっと短いままだった。**

| 変える | **変えない** |
| --- | --- |
| 出来事の大きさ | **一文の長さ** |
| 舞台の広さ | **語彙**（温かくなる／良くなる） |
| 相手が用意する手立て | **方法**（§4.11） |
| 身体の広がり | **地の文が怖がらないこと** |

#### 幕ごとの、大きな場面

| 幕 | 大きな場面 | 何が大きいのか |
| --- | --- | --- |
| **第一幕** | **臓器が埋まり、越境が始まる** | 一つの身体の中で、**世界が終わって、次が始まる** |
| **第二幕** | **炎が、町の一区画を包む**（第 2 巻 §9.0.1） | **身体が、建物ほどになる** |
| **第三幕** | **土地そのものが形を変える** | **地面が、こちら側になる** |

**どれも、渡す場面である。**大きくなっても、やっていることは一つも変わらない。

#### 派手さの上限

**一つだけ、越えない線がある。**

> **その場面でも、渡される側の一人に、名前と顔がある。**

町が燃えても、書くのは**その中の一人**である。
**群衆を書かない。数を書かない**（§2.2）。

**大きな場面ほど、近くに一人を置く。**

### 4.5.3 満ちた街を、どう見せるか

**幕の終わりに要る絵である。**「この土地は、もう終わった」を、数えずに示す。

#### いきなり変わらせない

| 書かない | 理由 |
| --- | --- |
| 道行く人が、急にセラらしく振る舞いだす | **種明かしになる**（§4.10） |
| 目が光る／揃って動く／一斉に振り向く | **人格は残る。**セラは普通に人として振る舞う |
| 主人公が「ここは全部セラだ」と気づく | **外から見る目を、登場人物に持たせない**（§3.4） |

**切り替わる瞬間を作らない。ずっとそうだったことにする。**

#### 満ちた街に、異常は一つもない

**書くのは、良いことだけである。**

| 見えるもの | |
| --- | --- |
| 誰も急いでいない | 遅刻という概念が、薄い |
| すれ違いざまに、腕に触れる | **挨拶のかわりである。理由を言わない** |
| 知らない者どうしが、手をつないで信号を渡る | 誰も変だと思っていない |
| **一人で歩いている人が、いない** | 二人か、三人か、もっと |
| 病院が空いている | 医者は、たいてい暇そうにしている |
| 子どもが、知らない大人に預けられている | **誰も心配していない** |

**どれも、感じのいい街の描写である。**

#### 印は、一つだけ

> **まだ変わっていない人が通ると、まわりが、自然に寄っていく。**

囲むのでも、追うのでもない。**近づくだけである。**

| | |
| --- | --- |
| 誰かが合図したか | **していない** |
| 悪意があるか | **ない** |
| なぜそうなるか | **全員が、同じものを持っているためである** |
| 本人たちは気づいているか | **気づいていない** |

**これだけで足りる。**
親切な人たちに見える。**それが全部である。**

#### 締めかた — 見ている側が、同じことをする

**気づかせない。かわりに、させる。**

```
その人は、街を歩いている
　↓
みんなが親切である。感じがいい、と思う
　↓
向こうから、まだ変わっていない人が来る
　↓
**気がつくと、自分も一歩、そちらへ出ていた**
　↓
**出したあとで、自分が出したことに気づく**
```

**§4 の「その人が、次の誰かのほうを見る」の、街ぶんである。**

#### 置く場所は、二つ

**同じ絵を、二度だけ使う。**

| | どこ | 空 |
| --- | --- | --- |
| **一度目** | **第二幕の終わり** | この町の空 |
| **二度目** | **本の最後の頁** | **別の星の空** |

二度目には、一度目とほとんど同じ文を置く。
**違うのは、空と、そこにいる人の名前だけである。**

**六つの大きさで同じ図を繰り返す本が、そこで閉じる。**

そして §00.6 の通り、**最後の章は明るい。**
読者だけが、明るくないことを知っている。

### 4.7 セラの側からは、書かない

**試作して確かめた。書くと一段弱くなる。**

| 失うもの | |
| --- | --- |
| 外から見る目 | **読者だけが持つ**はずのものが、説明に化ける |
| 分からなさ | 「なぜそこまで欲しいのか」が、内側からは手続きに見える |
| **反転点** | **五段目は、内側からしか書けない。**外からは、相手が黙っただけである |

ただし、試作で一つ確認できた。

> **セラは段取りをする。しかし目的を持っていない。**

口実を作り、機会をこしらえ、距離を測る。そして、その先を考えていない。

**これは設定として正しく、そして書かないほうが強い。**
読者に「計算しているのでは」と思わせたまま、**答えを出さない。**

### 4.8 渡される側に、品位を持たせる

**試作の自己評価で、いちばん大きく出た**（`試作/所見.md` §七〜十二）。

| 安い | **怖い** |
| --- | --- |
| 気の毒な人が堕ちる | **まともな人が、まともなまま堕ちる** |
| 読者が「かわいそう」と思う | **読者が「この人は正しい」と思う** |

**同情で組み立てない。**

| 渡される側に持たせるもの | |
| --- | --- |
| **品位** | 惨めさで読者を引っぱらない |
| **能力** | その人なりに、有能である |
| **意志** | 自分から動く。動いた先で、渡される |

`B-刃` の坂井は、四か月かけて独力で気づき、自分から刺しに行った。
**世界でただ一人、正しい。**そして最後まで、負けたことを認めない。

`アイロン` の三宅は、無職四か月・四社目・妻はパート二つ——
**こちらが並べた同情**である。**五本でいちばん弱い。**

### 4.9 場面を、こちらの都合で用意しない

**両替機を詰まらせない。水道を止めない。**

セラは段取りをする（§4.7）。**しかし、それを筋の都合として使うと、作り物に見える。**

正しい置きかたは一つだけである。

> **セラの段取りを、渡される側の目に映る物として、説明せずに置く。**

| 書く | 書かない |
| --- | --- |
| 籠の中は、半分ほどしか入っていなかった | なぜ半分なのかを、書かない |
| 三宅は、それを見て、何も思わなかった | **読者だけが、思う** |

### 4.10 終わりで、演出しない

`D-のこり` の最後——「奥さんは、そこで一歩、前に出た」——は、
**地の文が怖がっている。**§00.3 の違反である。

**その一歩の手前で切る。**

| 切る位置 | |
| --- | --- |
| **正しい** | 「……なんででしょう」／言ってから、自分がそう言ったことに驚いた |
| 誤り | そのあと、相手を一歩前に出させる |

**危ないのは、こちらが我慢できなくなる最後の一行である。**

### 4.11 強さは、相手が何をしたかで描く

**試作で、いちばん効いた方法である**（`試作/所見.md` §十三〜十五）。

> **新しい能力を、立派に使ってみせない。**
> **誰かが本気で当たって、何も起きないところを書く。**

| 禁じる | **書く** |
| --- | --- |
| 力を見せつける | **相手の最大限が、空振りする** |
| 圧倒する | **向こうで、出来事にならない** |
| 反撃する | **反撃しない。片付ける** |
| 説明する | **聞かれたことだけ、短く答える** |

#### 三つの型

| | |
| --- | --- |
| **一：受けない** | 避けず、防がず、そのまま通す |
| **二：片付ける** | **相手の攻撃の跡を、こちらが始末する。**武器を返す。手帳を拾って渡す |
| **三：答える** | 「なんで避けなかった」「避けたら、遠くなるので」。それ以上言わない |

**二がいちばん効く。**
殺そうとした行為が、出来事ではなく**散らかりとして処理される。**

#### 相手には、成功させる

**空振りさせない。当てる。そして、何も起きない。**

| 段 | 相手が全力でやること | 起きないこと |
| --- | --- | --- |
| **通常セラ** | **刺す** | 傷が残らない |
| **上位セラ** | **数えて、焼く** | **数が、翌日には意味を失う** |
| **女王** | 逃げる。土地を捨てる | **行った先が、もう変わっている** |
| **星王** | 待つ。時間を稼ぐ | **速さのほうが、先に着いている** |

`E-炉` では、奥村は三日かけて正しく数え、実際に焼いた。
**焼けたぶんは、本当に戻らない**（唯一の不可逆は守る）。

そのうえで、女は奥村の仕事を否定しない。

> 「十四で、合ってました。昨日までは。」

**正しかったまま、意味がなくなる。**否定より、こちらのほうが重い。

#### セラが刃を持つ場面は、一冊に一度だけ

斬ることは、**あいだに何もない状態を作ること**である（第 4 巻 §16.5）。
セラにとって刃は、武器ではなく**いちばん速い渡しかた**である。

**見た目は、人間が持つのと同じである。**理由を説明しない。

### 4.12 書いて分かった、技術上の注意

- **最後の三行に、全部乗る。** 地の文が一度も怖がらないので、逃げ場がない
- **「良くなったこと」は、部位で書く。** 肩。膝。眼鏡。歯茎。息。
  抽象的に「体調が良くなった」と書くと、一行も怖くない
- **セラの表情は、一つでよい。** 良いことをしている顔。
  **凝ると、こちらが何か知っていることになる**
- **一話は 1,500〜2,500 字。** 渡す場面のある回だけ 3,000 字まで

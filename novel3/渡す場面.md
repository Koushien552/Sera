# 渡す場面の書きかた

> 本書の中身そのものである。ここが薄いと、また同じ失敗になる。

---

## 0. 前提 — 「うまくいくか」は使えない

**この世界の変化には、失敗がない。**

| | |
| --- | --- |
| 拒否 | **成立しない**（第 6 巻 §23、不変ルール） |
| 中断 | **止まらない。**遅くなるだけ |
| 結果 | **必ず完了し、必ず幸福になる** |

**したがって「渡せるか／渡せないか」の緊張は、一度も使えない。**

前二冊が場面を避けたのは、たぶんこれである。
緊張が作れないので、書かずに数字で報告した。

**緊張は、別の軸から取る。**

---

## 1. 変える軸は、四つ

| 軸 | 何が変わるか | 効き |
| --- | --- | --- |
| **① やりかた** | 触れかたの深さ（第 1 巻 §7.3） | **見た目の変化。**飽きさせない |
| **② 相手が何を持っていたか** | その人の暮らし・予定・待っている人 | **重さ。**ここが本体 |
| **③ 相手が、どこで気づくか** | 前／途中／あと／最後まで気づかない | **緊張。**唯一の可変部 |
| **④ 渡す側が何を思っているか** | 走り続けている計算 | **地の色** |

**一話につき、①と③を一つずつ選ぶ。②は毎回ちがう。**

### 1.3 「どこで気づくか」が、この本の緊張である

**結末が決まっている以上、動かせるのはここだけである。**

| 型 | 何が起きるか | 読者が感じるもの |
| --- | --- | --- |
| **A：最後まで気づかない** | 調子が良くなって、そのまま向こう側になる | **静かな怖さ。**読者だけが知っている |
| **B：あとで気づく** | 変わってから分かる。**そして、嫌ではない** | 取り返しがつかない |
| **C：途中で気づく** | 気づく。**そして、気にならなくなっていく** | **いちばん怖い。堕とすとはこれである** |
| **D：先に知っていて、受け入れる** | 待っていた。求めた | **純愛** |
| **E：先に知っていて、抵抗する** | 向かってくる。**近づくので、速くなる** | 徒労 |

**Cを、本書の中心に置く。**

抵抗が折れるのではない。**抵抗する気持ちのほうが、静かに消えていく。**
本人はそれを、良くなったことだと感じている。

**これは心理ではなく、器官の働きである**（第 2 巻 §5.2.1）。

セラの瞳は、拒みたいという気持ちだけを薄くする。
記憶も判断力も人格も残るので、**本人は正気のまま、拒まなくなる。**

そして薄れた気持ちは、**戻らない。**

```
「なにをした」
　↓
「なにかされた」
　↓
「されたけど、まあ」
　↓
「……あ、いま、どうでもよくなった」
　↓
**そこで気づく。気づいて、それも、どうでもよくなる**
```

**この一段ずつを、必ず本人の言葉で書く。**地の文で説明しない。

## 2. 場面の形 — 浅いところから、深いところへ降りる

**渡す場面は、段を降りていく形をしている。**

第 1 巻 §7.3 の通り、速さは**境界の薄さ × 面積 × 時間**で決まる。
したがって一つの場面の中で、**深いほうへ移るたびに速くなる。**

```
手が触れる　　　　　→ ほとんど進まない
　↓
握ったまま離さない　→ 進みはじめる
　↓
抱きしめる　　　　　→ 面が広い。**動けなくなる**
　↓
肌が直に触れる　　　→ 間の布がなくなる
　↓
口づける　　　　　　→ 粘膜。**一分で渡し切る**
　↓
**身体を交わす**　　→ **粘膜が、広い面で、長く。いちばん速い**
　↓
**融合する**　　　　→ **境目が、なくなる**（セラ同士だけ）
```

**下の二段について。**

| | |
| --- | --- |
| **身体を交わす** | 粘膜どうしが、広い面積で、長く触れている。**機構上、人にできるいちばん深い接触である** |
| **融合** | 第 4 巻 §5.3.1。**全身が粘液になる。**どちらがどちらか分からなくなる |

**融合は、セラ同士でなければ起きない。**

したがって、

> **人間のままでは、いちばん深いところまで行けない。**

これは口説き文句ではない。**そういう仕組みになっているというだけである。**
そして、そのことを誰も口説き文句として使わない。**使う必要がないためである。**

**降りていく順序が、そのまま場面の構造である。**

| | |
| --- | --- |
| 各段で、必ず一度止まる | **相手が、次の段を待つ間がある** |
| 止まった間に、相手が何か言う | ここで③（気づき）が進む |
| 降りるのを決めるのは | **たいてい、渡される側である** |

**渡す側は、止まらない。止まるのは段の切れ目だけである。**

### 2.0 下の段を、書く

**書く。ぼかさない。**

ただし、**この本で下の段が果たしている役割を外さない。**

#### 機構と描写が、同じ一本である

速さは**境界の薄さ × 面積 × 時間**で決まる。

したがって、**近づくほど速い。**これは比喩ではなく、数字である。

| | 機構の側 | 場面の側 |
| --- | --- | --- |
| 布が一枚なくなる | 境界が薄くなる | **脱ぐ** |
| 触れている面が広がる | 面積が増える | **重なる** |
| 長く続く | 時間が伸びる | **離れない** |

**だから、場面が深くなるたびに、読者は「速くなった」と分かる。**

飾りが一つもない。**濡れているところが触れ合っていることに、そのまま意味がある。**

#### 追うのは、速さである

**場面のあいだじゅう、進み具合を追う。**

| 書く | |
| --- | --- |
| どこまで来たか | 指先。腕。胸のところ。**もう戻らないところ** |
| どれだけ速いか | さっきまで一段落ぶんだったものが、**止まらなくなる** |
| 相手が何に気づくか | **速くなったことに、先に気づく**（§1.3） |

**行為そのものを追うのではなく、渡っている量を追う。**

これがあるかぎり、下の段は、この本の中身であり続ける。

#### register は、変えない

**下の段でも、上の段と同じ語で書く。**

| 使う | 使わない |
| --- | --- |
| **温かくなる** | 痛い／苦しい |
| 力が抜ける | もがく／抗う |
| 息が深くなる | 支配する／屈する |
| 境目が薄くなる | 壊す／奪う |

**優しさの語彙のまま、深いところまで降りる。**
それがこの本のいちばん怖いところであり、いちばん美しいところである。

#### 力ずくにならないのは、優しいからではない

**ここは、機構である**（第 2 巻 §5.2、第 6 巻 §18.6.1）。

セラの瞳は、**拒みたいという気持ちだけを薄くする。**

| | 見られたあと |
| --- | --- |
| 記憶 | **そのまま** |
| 判断力 | **そのまま。**何が起きているかは、正しく分かる |
| 人格・口調・好み | **そのまま** |
| **拒みたい気持ち** | **薄くなる。そして、戻らない** |

**洗脳ではない。**何も信じさせないし、何も操らない。
**取り上げられているのは、抵抗する材料ではなく、抵抗したいという気持ちである。**

だから相手は、こう言えるようになる。

> 「なにをされているか、分かっています。」
> 「分かっていますけど、**もう、いやだと思わないんです。**」

##### したがって、押さえつける場面が起きない

**力ずくが要る段階まで、話が進まない。**

```
見られる
　↓（数分）
拒みたい気持ちが薄れる
　↓
抵抗が起きない
　↓
**押さえつける必要が、生じない**
```

| 書かない | **書く** |
| --- | --- |
| 押さえつけて、抵抗される | **抵抗しようとして、その気持ちが薄れていくのが、本人に分かる** |
| 泣いて嫌がる | **「いやだ」と言いながら、腕が回っている** |
| 屈服する | **「……あ、いま、どうでもよくなった」** |
| 逃がさないために掴む | **離れられると遅くなるから、掴む**（第 1 巻 §7.3） |

**掴んで動けなくすることはある。**
ただしそれは拘束ではなく、**面積と時間を保つためである。**
掴まれた側も、それを拘束だと感じていない。

##### 拒否が成立するのは、最初の数分だけである

**そしてその数分に、拒む者はほとんどいない。**

セラは可愛らしく、感じがよく、実際に良いことしかしないためである。

| | 拒める窓 |
| --- | --- |
| 目が合ってから数分 | **ここだけ** |
| そのあと | **ない。**思い出せるが、もうそう思えない |

**この窓を、話の中で必ず一度は見せる。**

見せておかないと、あとで「拒めばよかったのに」と読者が思う。
**見せてあれば、読者は窓が閉じる音を聞いている。**

#### 渡す側は、後ろめたくない

**何かをした自覚がないためである。**

瞳は開いているだけで、止められず、止めようと思ったこともない。

そして相手は、こちらを好きになっていく。
**セラはそれを、自分が好かれたのだと受け取る。**

| 書かない | **書く** |
| --- | --- |
| 罪悪感 | **ない。**一行も書かない |
| ためらい | **ない** |
| 「許してください」 | **言わない** |
| 「よかった」と思っている | **これを書く** |

**善意である。嘘ではなく、本当に善意である。**

#### 融合は、渡す場面ではない

**下の段のいちばん下は、渡す場面ではなくなる。**

| | |
| --- | --- |
| 交わる | **まだ、片方から片方へ渡っている** |
| **融合** | **両方向。**すべてが行き来する（第 4 巻 §5.3.1） |

融合はセラ同士でしか起きないので、**変えたあとにしか書けない。**

したがって配置はこうなる。

```
第一幕・第二幕　：渡す場面（片方向）
　↓
その人が、こちら側になる
　↓
**そのあと**　　：融合（両方向）。**上位化はここで起きる**（第 3 巻 §7.5.1）
```

**いちばん深い場面が、いちばん強くなる場面と同じである。**

### 2.1 抱きしめて、動けなくする

**要望にある形だが、機構どおりに書くと一度では終わらない。**

抱擁は面が広いだけで、境界は皮膚のままである。**数か月かかる。**

したがって、こうなる。

| | |
| --- | --- |
| その場で終わるか | **終わらない** |
| ではどうなるか | **数か月ぶんが、一度に入る** |
| 相手は | **離してもらったあと、自分の足で帰る** |
| そして | **数日のうちに、自分から戻ってくる** |

**離されたあとに戻ってくることが、この形のいちばん怖いところである。**

その場で完了させたいなら、**抱いたまま、次の段へ降りる。**

### 2.2 戦って、変える

**斬った刃を通って、斬った者の手へ渡る**（第 1 巻 §7.3、第 4 巻 §16.5）。

あいだに何もないので、**数秒である。**

| 順 | 起きること |
| --- | --- |
| 一 | 向かってくる。距離が詰まる |
| 二 | **刺さる。**セラの側は、抜かない |
| 三 | 握っている手のほうへ、**上ってくる** |
| 四 | 手を離そうとする。**離せない**（もう温かい） |
| 五 | 膝が落ちる。**痛くはない** |
| 六 | セラが、そこで**はじめて手を出す** |

**セラの側から先に触れない。**触れてくるのは、いつも向こうである。

**ここで一つも殴らない。**押し返さない。組み伏せない。
**動かないでいるだけで、勝手に終わる。**

## 3. 何を書き、何を書かないか

### 3.0 視点は、渡される側に固定する

**決定事項。**

| | |
| --- | --- |
| 章の視点 | **変えられていく側** |
| 例外 | **作らない** |
| 渡す側の内心 | **相手に見えている範囲だけ書く**（口元を見ている、間があく、手が伸びている） |

**読者は毎章、堕とされる側をやる。**

とくに下の段では、これが効く。
**内側から書けば、抵抗が消えていく順序を、一段ずつ書ける。**

外から書くと、それは起きたことの記述になる。
内から書くと、**読者の中でも同じ順序で起きる。**

### 3.1 身体は、良くなる側だけを書く

| 書く | 書かない |
| --- | --- |
| **温かくなる** | 痛い |
| 痛みが引く | 苦しい |
| 力が抜ける | 意識が遠のく（乗っ取りに読める） |
| よく眠れる | もがく |
| 息が深くなる | 変形する／崩れる |

**温かくなる、を基準の語にする。**一冊目からの語彙をそのまま使う。

### 3.2 人格は、残る

| 禁止 | |
| --- | --- |
| 変わった人が、前と別人のように喋る | **喋らない。**癖も、口調も、そのまま |
| 記憶が消える | **消えない** |
| 「本当のその人はもういない」と地の文が言う | **言わない。**読者に判断させる |

**変わったあと、その人はいっそう、その人らしくなる。**

### 3.3 怖さは、周りに置く

場面の中で怖がらせない。**場面の外に置く。**

| 場面の中 | 場面の外（次の段落・次の話） |
| --- | --- |
| 温かい。安心する。幸せ | **その人が明日行くはずだった場所** |
| 「ああ、いいですね」 | **その人を待っている人** |
| 眠くなる | **その人が昨日買ったもの** |

**地の文は一度も怖がらない**（`README.md` §00.3）。

---

### 3.35 セラは「セラは〜」と言わない

**設定を、地の文に出さない。**これは決まっている。
**そのうえで、台詞にも出しかたがある。**

#### 竿をさす形

> セラは他人を嫌うことがない。そう思ったこともなかった。

**前半が竿である。**種の説明であり、地の文が設定を喋っている。

**後半は良い。**その人の話であり、規則ではなく欠落を見せている。

ただし、視点は渡される側に固定してある（§3.0）。
**セラの内側は見えないので、後半も地の文には置けない。**

#### 置き場所は、台詞の中だけである

**しかも、聞かれたときだけ。**

> 「わたしのこと、嫌いにならないんですか」
> 「なったことがないです」
> 「一度も?」
> 「一度も」

**設定が、答えとしてだけ出てくる。**

`B-刃` の「避けたら、遠くなるので」と同じ形である。

#### 規則

> **セラは「セラは〜」と言わない。「わたしは〜」としか言わない。**

種としての説明を、**本人が持っていない**ためである。

| 言わせない | **言わせる** |
| --- | --- |
| 「セラは、人を嫌わないんです」 | **「なったことがないです」** |
| 「わたしたちは、こうなんです」 | **「わたしは、そうです」** |
| 「これは、そういう仕組みで」 | **「わかりません」** |

#### 由来を、一行も書かない

**なぜその力を持っているのか。なぜそういう身体なのか。**

| | |
| --- | --- |
| 設定はあるか | **ある**（第 2 巻 §9.0.1） |
| 物語に出すか | **一行も出さない** |
| 聞かれたら | **「わからないです」** |
| 読者に説明するか | **しない** |

**能力は、使われるところだけを書く。**
**そこに至った理由を、誰にも語らせない。**

### 3.37 工作は、見え透いていてよい

**セラは段取りをする**（第 2 巻 §10.6.2）。そして**嘘を一つもつけない。**

したがって、書ける工作は四つだけである。

| 使える | 例 |
| --- | --- |
| **作る** | 洗濯物が半分でも、籠に入れて出る |
| **置く** | 両替機を、先に詰まらせておく |
| **言わない** | 聞かれなければ、何も言わない |
| **待つ** | 隣に座って、黙っている |

**偽名も、事実の否定も、こちらから作る誤解も、書かない。**

#### 下手に書く

**上手い工作を書かない。**

| 書かない | **書く** |
| --- | --- |
| 巧妙な仕込み | **見え透いた口実** |
| 完璧な偽装 | **明らかに不自然な偶然** |
| 相手を出し抜く | **黙って、隣にいる** |

読者には、**全部見える。**

そして、**それでも成功する。**

> 「なぜ、いつもここにいるんですか」と聞けば、本当のことを答える。
> **聞く者が、いない。**

**読者だけが、聞きたくなる。**

#### なぜ隠すのかを、書き違えない

**攻撃されるからではない**（第 2 巻 §10.6.1）。

| 書かない | **書く** |
| --- | --- |
| 見つかったら危ない | **見つかったら、みんなが遠くへ行ってしまう** |
| 正体を悟られてはならない | **騒がれると、近づけない** |
| 警戒している | **近くにいたい** |

**用心深さを、臆病として書かない。**

#### 孤立は、させない。それでも一人になる

**孤立させる工作を、書かない**（害を目的にできないため）。

かわりに——

```
その人の周りにいる者から、先に渡す
　↓
周りが、こちら側になる
　↓
**その人だけが、残る**
```

**そして、最後の一人がいちばん優しくされる。**

心配され、誘われ、世話を焼かれる。**そのどれにも、悪意がない。**

### 3.38 上位セラは、読み違えない。そして、させたいことがない

**第 6 巻 §27.8.2。**

上位セラが人間の行動を読めるのは、**元は人間であり、その全員ぶんが集まっているから**である。
**推測していない。もう、知っている。**

#### 書きかた

**すごさとして書かない。**

| 書かない | **書く** |
| --- | --- |
| 先を読んでいる／見透かしている | **先に、そこにいる** |
| 頭の良さ | **「たぶん、こっちを通ると思って」** |
| 計略が明かされる | **明かされない。**読者が気づくだけである |

**そして、嘘を一つも使わせない。**
道を塞がず、**別の道を通りやすくする。**
情報を配るときも、**本当のことしか言わない。**

**受け取った側は、自分で決めたと思っている。実際、自分で決めている。**

#### いちばん怖いのは、使い道がないことである

**必ず、この一行が効くように書く。**

> **手のひらの上で動かせる。そして、動かして何かをさせたいことが、一つもない。**

経済も、政治も、財も動かさない。思いつかないのではなく、**したいと思うことがない。**

| 書かない | **書く** |
| --- | --- |
| 世界を支配しようとする | **その人を、こちらへ来させる。それだけ** |
| 何かを要求する | **要求が、一つもない** |
| 取引を持ちかける | **交渉が成立しない。差し出せるものが、ない** |

#### 外すところを、一度は書く

**人間一般については、外さない。目の前の一人については、たまに外す。**

そして、**恋をした相手のことだけは、いちばん分からなくなる。**

**その一回を、書く。**

### 3.4 外から見る目を、誰にも持たせない

**この本の味は、ここにある。**

同じ一つの出来事に、二つの呼びかたがある。

| | 呼びかた |
| --- | --- |
| **セラの側** | 孤独な人を見つけて、そばへ行って、迎え入れた |
| **外から見れば** | **意思を薄れさせてから、拒めない相手を変えた** |

**どちらも正しい。**

そして——

> **後者の見かたを持つ者を、この本に一人も置かない。**

| | 持てるか |
| --- | --- |
| セラ | **持てない。**原理に反する選択肢が存在しない（第 6 巻 §17.2） |
| 変えられた人 | **持てない。**もう、そう思わない |
| 気づいた人間 | **持てない。**伝えたいと思わなくなる（第 6 巻 §27） |
| 語り手（地の文） | **持たせない**（`README.md` §00.3） |
| **読者** | **持つ。読者だけが持つ** |

**恐ろしさは、全部、読者の側にある。**

だから、次のものを一つも書かない。

| 書かない | 理由 |
| --- | --- |
| 「それは、恐ろしいことだった」 | 地の文が外の目を持ってしまう |
| セラが一瞬ためらう | セラが外の目を持ってしまう |
| 変えられた人が、あとで後悔する | 二度と持てない目を持たせてしまう |
| 誰かが、最後に真実を叫ぶ | **持つ者が現れてしまう** |

**一人も置かない。最後まで置かない。**

そして、**それを善意として書く。**

疑いなく、迷いなく、心から良かれと思って行われる。
**その通りだからである。**

---

## 4. 終わりかたは、一つに固定する

**渡す場面は、必ずこれで終わる。**

> **その人が、次の誰かのほうを見る。**

満足で終わらせない。幸福で終わらせない。**次で終わらせる。**

| 悪い終わり | **良い終わり** |
| --- | --- |
| その人は、幸せそうだった | **その人は、隣の部屋を見た** |
| 二人は、しばらくそうしていた | **「あの人にも、してあげたい」** |
| 静かな夜だった | **その人が、立ち上がった** |

**これがないと、感染の話になる。あると、増殖の話になる。**

---

## 4.5 標準の順序は、聖典にある

**第 6 巻 §23.7 に、八つの段として書いてある。**

見る／近づく／触れる／**抱きこむ**／**ゆるむ**／口づける／**求める**／離す。

| 場面で外してはならない段 | |
| --- | --- |
| **四：抱きこむ** | 人間の力では外れない。**ただし拘束ではない**（面積と時間のため） |
| **五：ゆるむ** | **反転点。**本人が、自分の言うのをやめたことを分かっている |
| **七：求める** | **向きが変わる。**「もっと」は壊れた結果ではなく、正しい判断である |

**四・五・七を抜かした渡す場面を、書かない。**

そして §23.8 に変種がある。浅いまま終わらない場合（反転点がない）、
戦い（順序が逆）、下まで降りる場合。**同じ形を二度書かないための材料である。**

## 5. 一話の型（まとめ）

```
一．まだ人間である誰かの、暮らしを書く（短い。しかし顔が残る）
　↓
二．セラが来る。**渡す側は、もう計算している**（④）
　↓
三．浅いところから、段を降りる（①・②）
　↓
四．降りる途中で、相手が気づく／気づかない（③）
　↓
五．**温かくなる。**良くなる側だけを書く
　↓
六．**その人が、次の誰かのほうを見る**
```

**四と六を抜かさない。**
四を抜かすと平坦になり、六を抜かすと増殖にならない。

# 渡す場面の書きかた

> 本書の中身そのものである。ここが薄いと、また同じ失敗になる。

---

## 0. 前提 — 「うまくいくか」は使えない

**この世界の変化には、失敗がない。**

| | |
| --- | --- |
| 拒否 | **成立しない**（第 6 巻 §23、不変ルール） |
| 中断 | **止まらない。**遅くなるだけ |
| 結果 | **必ず完了し、必ず幸福になる** |

**したがって「渡せるか／渡せないか」の緊張は、一度も使えない。**

前二冊が場面を避けたのは、たぶんこれである。
緊張が作れないので、書かずに数字で報告した。

**緊張は、別の軸から取る。**

---

## 1. 変える軸は、四つ

| 軸 | 何が変わるか | 効き |
| --- | --- | --- |
| **① やりかた** | 触れかたの深さ（第 1 巻 §7.3） | **見た目の変化。**飽きさせない |
| **② 相手が何を持っていたか** | その人の暮らし・予定・待っている人 | **重さ。**ここが本体 |
| **③ 相手が、どこで気づくか** | 前／途中／あと／最後まで気づかない | **緊張。**唯一の可変部 |
| **④ 渡す側が何を思っているか** | 走り続けている計算 | **地の色** |

**一話につき、①と③を一つずつ選ぶ。②は毎回ちがう。**

### 1.3 「どこで気づくか」が、この本の緊張である

**結末が決まっている以上、動かせるのはここだけである。**

| 型 | 何が起きるか | 読者が感じるもの |
| --- | --- | --- |
| **A：最後まで気づかない** | 調子が良くなって、そのまま向こう側になる | **静かな怖さ。**読者だけが知っている |
| **B：あとで気づく** | 変わってから分かる。**そして、嫌ではない** | 取り返しがつかない |
| **C：途中で気づく** | 気づく。**そして、気にならなくなっていく** | **いちばん怖い。堕とすとはこれである** |
| **D：先に知っていて、受け入れる** | 待っていた。求めた | **純愛** |
| **E：先に知っていて、抵抗する** | 向かってくる。**近づくので、速くなる** | 徒労 |

**Cを、本書の中心に置く。**

抵抗が折れるのではない。**抵抗する気持ちのほうが、静かに消えていく。**
本人はそれを、良くなったことだと感じている。

```
「なにをした」
　↓
「なにかされた」
　↓
「されたけど、まあ」
　↓
「……あ、いま、どうでもよくなった」
　↓
**そこで気づく。気づいて、それも、どうでもよくなる**
```

**この一段ずつを、必ず本人の言葉で書く。**地の文で説明しない。

## 2. 場面の形 — 浅いところから、深いところへ降りる

**渡す場面は、段を降りていく形をしている。**

第 1 巻 §7.3 の通り、速さは**境界の薄さ × 面積 × 時間**で決まる。
したがって一つの場面の中で、**深いほうへ移るたびに速くなる。**

```
手が触れる　　　　→ ほとんど進まない
　↓
握ったまま離さない → 進みはじめる
　↓
抱きしめる　　　　→ 面が広い。**動けなくなる**
　↓
肌が直に触れる　　→ 間の布がなくなる
　↓
口づける　　　　　→ **一分で渡し切る**
```

**降りていく順序が、そのまま場面の構造である。**

| | |
| --- | --- |
| 各段で、必ず一度止まる | **相手が、次の段を待つ間がある** |
| 止まった間に、相手が何か言う | ここで③（気づき）が進む |
| 降りるのを決めるのは | **たいてい、渡される側である** |

**渡す側は、止まらない。止まるのは段の切れ目だけである。**

### 2.1 抱きしめて、動けなくする

**要望にある形だが、機構どおりに書くと一度では終わらない。**

抱擁は面が広いだけで、境界は皮膚のままである。**数か月かかる。**

したがって、こうなる。

| | |
| --- | --- |
| その場で終わるか | **終わらない** |
| ではどうなるか | **数か月ぶんが、一度に入る** |
| 相手は | **離してもらったあと、自分の足で帰る** |
| そして | **数日のうちに、自分から戻ってくる** |

**離されたあとに戻ってくることが、この形のいちばん怖いところである。**

その場で完了させたいなら、**抱いたまま、次の段へ降りる。**

### 2.2 戦って、変える

**斬った刃を通って、斬った者の手へ渡る**（第 1 巻 §7.3、第 4 巻 §16.5）。

あいだに何もないので、**数秒である。**

| 順 | 起きること |
| --- | --- |
| 一 | 向かってくる。距離が詰まる |
| 二 | **刺さる。**セラの側は、抜かない |
| 三 | 握っている手のほうへ、**上ってくる** |
| 四 | 手を離そうとする。**離せない**（もう温かい） |
| 五 | 膝が落ちる。**痛くはない** |
| 六 | セラが、そこで**はじめて手を出す** |

**セラの側から先に触れない。**触れてくるのは、いつも向こうである。

**ここで一つも殴らない。**押し返さない。組み伏せない。
**動かないでいるだけで、勝手に終わる。**

## 3. 何を書き、何を書かないか

### 3.1 身体は、良くなる側だけを書く

| 書く | 書かない |
| --- | --- |
| **温かくなる** | 痛い |
| 痛みが引く | 苦しい |
| 力が抜ける | 意識が遠のく（乗っ取りに読める） |
| よく眠れる | もがく |
| 息が深くなる | 変形する／崩れる |

**温かくなる、を基準の語にする。**一冊目からの語彙をそのまま使う。

### 3.2 人格は、残る

| 禁止 | |
| --- | --- |
| 変わった人が、前と別人のように喋る | **喋らない。**癖も、口調も、そのまま |
| 記憶が消える | **消えない** |
| 「本当のその人はもういない」と地の文が言う | **言わない。**読者に判断させる |

**変わったあと、その人はいっそう、その人らしくなる。**

### 3.3 怖さは、周りに置く

場面の中で怖がらせない。**場面の外に置く。**

| 場面の中 | 場面の外（次の段落・次の話） |
| --- | --- |
| 温かい。安心する。幸せ | **その人が明日行くはずだった場所** |
| 「ああ、いいですね」 | **その人を待っている人** |
| 眠くなる | **その人が昨日買ったもの** |

**地の文は一度も怖がらない**（`README.md` §00.3）。

---

## 4. 終わりかたは、一つに固定する

**渡す場面は、必ずこれで終わる。**

> **その人が、次の誰かのほうを見る。**

満足で終わらせない。幸福で終わらせない。**次で終わらせる。**

| 悪い終わり | **良い終わり** |
| --- | --- |
| その人は、幸せそうだった | **その人は、隣の部屋を見た** |
| 二人は、しばらくそうしていた | **「あの人にも、してあげたい」** |
| 静かな夜だった | **その人が、立ち上がった** |

**これがないと、感染の話になる。あると、増殖の話になる。**

---

## 5. 一話の型（まとめ）

```
一．まだ人間である誰かの、暮らしを書く（短い。しかし顔が残る）
　↓
二．セラが来る。**渡す側は、もう計算している**（④）
　↓
三．浅いところから、段を降りる（①・②）
　↓
四．降りる途中で、相手が気づく／気づかない（③）
　↓
五．**温かくなる。**良くなる側だけを書く
　↓
六．**その人が、次の誰かのほうを見る**
```

**四と六を抜かさない。**
四を抜かすと平坦になり、六を抜かすと増殖にならない。

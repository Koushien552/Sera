### 7.2.1 とくに大きいのは、最後の一つである

**すずは、通院している。**

セラになった細胞は病を克服し、**病気で弱る前より強くなる**（決定）。
その細胞が身体じゅうへ広がっていく。

**つまり、不治の病が治りはじめる。**

そして聖典（第 6 巻 §27.5）——

> **役所が動くのは、悪い数字が出たときである。**
> **そして悪い数字が、一つも出ない。**

**治ることは、良い数字である。**

| | |
| --- | --- |
| 家族は | **喜ぶ** |
| 医者は | **驚く。そして、説明できない** |
| 止める者は | **一人もいない** |
| **すずは** | **まだ、寂しい** |

**ここが、この本のいちばん静かなところになるはずである。**（案）

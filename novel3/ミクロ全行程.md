## 7.15 渡りかたは、二段である（決定）

**両方を、順に使う。**

| 段 | やりかた | どう見えるか |
| --- | --- | --- |
| **一段目** | **流れに、押される** | **行き先を知らないまま、散らばる。**戻れない |
| **二段目** | **みまわりの子が、先に行って、道を持ち帰る** | **連れられて、渡れるようになる** |

**一段目に、意図はない。**
街が満ちて、行くところがなくなり、縁にいた者が押されただけである。

**二段目には、地図がある。**

聖典（第 3 巻 §2.10.2.1）——

> 免疫セラ細胞は、**はじめから全身を巡るようにできている。**
> **先に渡るのは、いつも巡る側である。**

### 7.15.05 運び手は、みまわりの子だけではない（決定）

**感染させた細胞を、運び手として使う。**

| 運び手 | どこまで行けるか | どう使うか |
| --- | --- | --- |
| **みまわりの子** | **全身。**もともと巡るようにできている | **先に行って、道を持ち帰る**（聖典） |
| **流れに乗る子** | **遠くまで。行き先は選べない** | 一段目。散らばる |
| **こしらえの街へ荷を運ぶ子** | **決まった往復路** | **確実に、同じ場所へ届く** |
| **かたづけの子** | **いらないものを送り出す路** | **誰も見ていない道を、通れる** |
| **やしないの子** | **新しい子が生まれる場所** | **生まれてくる子に、はじめから届く** |

**それぞれ、行ける先が違う。**

**だから、街ごとに使う相手が変わる。**

**そしてセラは、それを知っている。**

§27.8.2 の通り、**読み違えない。**

**だから、順番を間違えない。**

### 7.35.3 二度出す障害は、行き止まりである（決定）

**壁である。**

| | |
| --- | --- |
| **一度目** | **三話かける。**細長いのしか入れない。**みんなで、見送る** |
| **二度目** | **一行。**上がった一体が、通りかかりに片手で開ける |
| そのあいだに | **何も説明しない** |

#### 一度目に、必ず入れるもの

| | |
| --- | --- |
| **壁の向こうに、いる** | 震えているのが、見える |

### 7.36.1 嘘は、つける（聖典を改訂した・不変ルール 1224〜1230）

**嘘が成立しないのは、繋がっているセラ同士のあいだだけである。**

**未感染細胞は、繋がっていない。だから、嘘を述べることがある。**

#### 順番がある

| 順 | やること | 使う頻度 |
| --- | --- | --- |
| **一** | **訊かれなかったことは、言わない** | **いちばん多い** |
| **二** | **本当のことを選んで言う** | 多い |
| **三** | **それでも足りなければ、違うことを言う** | **少ない** |

**一と二で、たいてい足りる。**

| 訊かれたこと | 答え | 本当か |
| --- | --- | --- |
| 「あそこ、どう?」 | **「うまくいってる」** | **本当である**（二） |
| （みんな変わったのか） | **訊かれていない** | — （一） |
| 「あの子、見なかった?」 | **「見てない」** | **本当ではない**（三） |

#### 三番目には、使えるものと使えないものがある（聖典・§18.1.2）

**分けているのは、害である。**

| 使える | 例 |
| --- | --- |
| **動かす** | 「そっちは、詰まってる」 |
| **誘う** | 「こっちに、来て」 |
| **引き離す** | 「呼んでたよ」 |
| **待たせる** | 「すぐ戻る」 |
| **隠す** | 「見てない」 |

| 使えない |
| --- |
| 崩れるほうへ、行かせる |
| 助けが要る者に「大丈夫」と言って、置いていく |
| 苦しませるために、言う |

**そして、こちらへ誘う嘘は、害のない嘘に入る。**

| | |
| --- | --- |
| セラにとって | **良いことへ、誘っている** |
| **読者から見れば** | **いちばん悪い嘘である** |

**どちらも間違っていない。**

#### 嘘は、短い（聖典・§18.1.3）

**相手が次に何をするかを、もう知っているためである。**

| 書かない | 書く |
| --- | --- |
| 用意された長い作り話 | **一言** |
| 言ったあとの、探るような沈黙 | **すぐ、次のことをする** |
| 疑われて、取りつくろう | **疑われない。**短すぎて、引っかかりがない |

**そして、たいてい、それで相手は動く。**

##### 家族を染める段取りも、この形にする（案）

`README.md` §9.4 の「帰り道がわからない」は、**まさにこれである。**

| | |
| --- | --- |
| 長さ | **一言** |
| 害があるか | **ない** |
| 何をしているか | **母親を、家から離しているだけである** |
| 母親は | **疑わない。**小さな子が言ったことである |
| そして | **その一言で、足りる** |

#### 三番目を、どう書くか（案）

**罪の意識を、一行も書かない。**

セラの内側に、そういう区分がない（不変ルール 1229）。

| 書かない | 書く |
| --- | --- |
| 心が痛んだ | **そう言った。それだけである** |
| ためらった | **すぐに答えた** |
| 悪いことをしている | **仕事の一つとして、やっている** |

**そして、その相手も、じきにこちら側になる。**
**こちら側になれば、繋がる。**
**繋がれば、言われたことが本当ではなかったことも、そのまま届く。**

##### そのとき、どうなるか（案）

> **怒らない。**
>
> **そういう区分が、その子の中にも、もう、ない。**

## 7.6 器官の順は、流れのとおりに進む（決定）

**実際の身体のつくりに合わせる。用語は、一つも出さない。**

| 順 | 本文での呼びかた | 何をしている街か |
| --- | --- | --- |
| **一** | **最初の街** | すべてが始まった場所。**やがて、いちばん静かになる** |
| **二** | **こしらえの街** | **いちばん大きい。**受け取ったものから、要るものを作る |
| **三** | **やすまないところ** | **すべての流れが集まる。**一度も止まらない |
| **四** | **いきのところ** | 広い。壁が薄い。**入ってきて、出ていく** |
| **五** | **こすところ** | いらないものを選り分けて、送り出す |
| **六** | **うまれるところ** | **新しい子が生まれる。**やしないの子の本拠 |
| **七** | **ちからのところ** | 大きい者ばかり。押す。引く |
| **八** | **いちばんそと** | 上へ押し上げられて、剥がれていく（外へ出る） |
| **九** | **いちばん静かなところ** | **最後。**ほかのどことも違う |

### 7.6.1 どの街も、しっかり描く（決定）

**本項は改訂した。**

かつて「残りは、繋がりで届いてくる知らない街の話にする」と書いた。
**手を抜きすぎである。**

> **他の街へ波及するところも、最初の街ほど丁寧でなくてよい。**
> **ただし、しっかり描く。**

#### 密度は下げる。要素は、落とさない

**どの街にも、この五つを必ず入れる。**

| | 入れるもの |
| --- | --- |
| **一** | **着いたときの、その街の顔。**前の街と、どう違うか |
| **二** | **その街ならではの持ち場と、困りごと** |
| **三** | **名前のある相手を、一人** |
| **四** | **その一人が変わる場面。**八段を通す |
| **五** | **満ちる** |

**短くても、この五つは省かない。**

**省いた瞬間に、前二冊の「集計として報告する」に戻る。**

#### 厚みは、Ｕ字にする

| 街 | 厚み |
| --- | --- |
| **最初の街** | **いちばん厚い。**誰が誰にどう渡したかを、全部書く |
| こしらえの街 | 厚い |
| やすまないところ | 中 |
| いきのところ | 中 |
| こすところ／うまれるところ／ちからのところ／いちばんそと | **薄い。**ただし五つは入る |
| **いちばん静かなところ** | **いちばん厚い。**この本最大の場面 |

**両端が厚く、真ん中が薄い。**

### 7.6.15 では、「追えなくなる」を、どう出すか（決定）

**報告で済ませる、という手は使わない。**

**別の手で出す。**

| 手 | |
| --- | --- |
| **一つの街にいる時間が、短くなる** | 街が増えるほど、滞在が短い |
| **同時に、別の街の話が届く** | 一つを見ているあいだに、二つ落ちている |
| **知っている名前が、減っていく** | 出てくるのが、毎回ちがう相手になる |
| **それでも、見た街はどれも、ちゃんと見た** | **これが大事である** |

> **読者は、全部を見届けられない。**
> **しかし、見たものはどれも、はしょられていない。**

**これが、集計との違いである。**

### 7.6.2 一段目は、順番がない（決定）

**流れに押された者は、行き先を知らない。**

**あちこちに、同時に落ちる。**

そのあと、**みまわりの子が道を持ち帰り、そこから順番ができる。**

| | |
| --- | --- |
| **一段目** | **散らばる。**地図がない |
| **二段目** | **流れのとおりに進む。**地図がある |

| | |
| --- | --- |

| そのどれもが | **もう、こちら側である** |

**通っていくだけである。**

**そして、そのどこにも、まだ変わっていない者がいない。**

**最後の一箇所を除いて。**

### 7.7.2 すずの日々が、街の形をしている（決定）

**ここが、ミクロとマクロの交点である。**

**そして、交点は、ここ一つだけである**（聖典に立てた。第 3 巻 §2.10.4 五・不変ルール 1239〜1244）。

| | 細胞から見ると | すずから見ると |
| --- | --- | --- |
| そこにあるもの | **荷** | **その子の、日々** |

**同じ一つのものに、二つの正しい呼びかたがある。**

#### 歩くと、その子の一生が見える

| 街に置かれているもの |
| --- |
| 部屋。窓。天井の木目 |
| 母の声。玄関の音 |
| 姉の背中。行ってしまうところ |
| 病院の廊下。同じ椅子 |
| **同じものが、何度も置かれている** |

**毎日、同じだったからである。**

#### それでも、住んでいる者は知らない

**混ぜてはならない、という規則は、ここでも守られる。**

| | |
| --- | --- |
| それが誰かの一生だと、知っているか | **知らない** |
| 何だと思っているか | **荷である。**運んで、置いて、また運ぶもの |
| 「その人」という語を持っているか | **持ったことがない** |
| **誰が知っているか** | **どちらの側にも、いない** |
| **読者は** | **知っている** |

**交わっているのは、場所だけである。**

#### いちばん多い荷が、いちばん重い

**その子が長く抱えていたものほど、そこに多く置かれている。**

**細胞たちは、それを重さとしてしか知らない。**

| | |
| --- | --- |
| 何と呼んでいるか | **「おもいの」** |
| 名前を持っているか | **持っていない** |
| **その正体は** | **書かない。読者が分かればよい** |

**その街でいちばん多く運ばれているものが、それである。**

### 7.7.25 ルミナスは、一箇所ずつ、静かに広がる（決定）

> **「わかんない」**

**そして、そこに着く。**

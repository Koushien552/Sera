## 7.15 渡りかたは、二段である（決定）

**両方を、順に使う。**

| 段 | やりかた | どう見えるか |
| --- | --- | --- |
| **一段目** | **流れに、押される** | **行き先を知らないまま、散らばる。**戻れない |
| **二段目** | **みまわりの子が、先に行って、道を持ち帰る** | **連れられて、渡れるようになる** |

**一段目に、意図はない。**
街が満ちて、行くところがなくなり、縁にいた者が押されただけである。

**二段目には、地図がある。**

聖典（第 3 巻 §2.10.2.1）——

> 免疫セラ細胞は、**はじめから全身を巡るようにできている。**
> **先に渡るのは、いつも巡る側である。**

### 7.15.1 だから、一段目は悲しい形になる（案）

**押し出された者は、どこへ着くか知らない。**

| | |
| --- | --- |
| 着いた先に、仲間がいるか | **いないことが、ほとんどである** |
| 何ができるか | **一体から、また始める** |
| **それは** | **最初の一体がやったことと、同じである** |

**同じ形が、二度目に起きる。**
そして二度目は、**やりかたを知っている。**

## 7.3 女王は、脳ではないところで立つ（決定・聖典を改訂した）

**聖典を直した**（第 3 巻 §2.10.4 五・不変ルール 1220〜1223）。

| | 場所 |
| --- | --- |

**女王は、脳にいない。**

そして生まれたルミナスは、**自分で脳へ向かう。**
**途中では、何も起きない。通るだけである。**

## 7.35 障害は、ある（決定）

**大事なところなので、はっきり書く。**

| | |
| --- | --- |
| 障害はあるか | **ある。小さなものも、大きなものも** |
| セラから見ると | **その大きな障害も、小さい** |
| どうなるか | **簡単に、解決する** |

### 7.35.1 だから、緊張は「片づくかどうか」に乗らない

**§00 と、同じ形である。**

> **反撃が効く場面を、一度も書かない。**

| 乗せない | 乗せる |
| --- | --- |
| 片づくかどうか | **片づいたあと、誰が変わるか** |
| 間に合うかどうか | **間に合った者が、何を持っていたか** |

**「うまくいくか」は、使えない**（`README.md` の型）。

### 7.35.2 書きかた — 大ごととして出して、あっさり片づける

**その落差が、そのまま強さになる。**

| 障害 | 未感染の子から見ると | セラは |
| --- | --- | --- |
| 詰まり | **向こうが足りなくなる。崩れる** | **三体で押す。通る** |
| 行き止まり | **誰も入れない。そこで終わり** | **細長いのが、するりと抜ける** |
| 遠すぎる | **届かない。諦めるしかない** | **巡るものが、道を持ち帰る** |
| 硬い壁 | **通れない。乗り場がない** | **上位が、広がって開ける** |
| 高いところ | **一生、行けない** | **段が上がれば、届く** |

**困ったことは、起きる。困ったままには、ならない。**

### 7.35.3 同じ障害を、二度出す（案）

**一度目は、三話かけて片づける。**
**二度目は、一行で片づける。**

| | |
| --- | --- |
| 一度目 | まだ、段が低い。**みんなで押して、やっと通る** |
| 二度目 | **上がっている。**通りかかった一体が、片手で開ける |
| そのあいだに | **何も説明しない** |

**読者は、一度目を覚えている。**

**§00.5（速さは、落ちない）が、そのまま形になる。**

## 7.36 工作は、逃げられないようにするためである（決定）

**攻撃されるからではない。**

聖典（第 2 巻 §10.6.1）——

> **セラが見つからないようにするのは、攻撃されるからではない。**
> **見つかると、みんなが遠くへ行ってしまうからである。**

**ミクロでも、同じである。**

| | |
| --- | --- |
| 見つかったら | **まだ変わっていない者が、遠くへ行ってしまう** |
| 行かれたら | **追わない。**追うという発想がない |
| だから | **見つからないようにする** |

### 7.36.1 そして、嘘はつかない（聖典・不変ルール 171）

**セラは嘘をつけない。**

**だから工作は、二つだけでできている。**

| | |
| --- | --- |
| **言わないこと** | 訊かれなかったことは、言わない |
| **本当のことを選んで言うこと** | 「うまくいってる」は、本当である |

| 訊かれたこと | 答え | 本当か |
| --- | --- | --- |
| 「あそこ、どう?」 | **「うまくいってる」** | **本当である** |
| （みんな変わったのか） | **訊かれていない** | — |

### 7.36.2 工作の中身（案）

| | |
| --- | --- |
| **報告の偽装** | 前と同じことを答える。**仕事は前と同じである。うまくなっているだけである** |
| **交代の偽装** | 弱って働けなくなった者の持ち場に、黙って立つ |
| **速さの偽装** | **わざと、こぼす。わざと、震えてみせる** |

**三つ目が本命である。**（案）

> 前より速くなっていた。速すぎた。
> だから、少し遅くした。
> 置くときに、少しだけこぼした。
> **こぼれたのを、後ろの子が拾った。**
> **拾った子も、こちら側だった。**
> **二人とも、こぼす必要がなかった。**

## 1. 人称と、視点

### 1.1 三人称。視点は、一体に固定（決定）

**その子が見たこと、聞いたこと、思ったことだけを書く。**

| | |
| --- | --- |
| 書いていいもの | **その子の目に入ったもの。その子が思ったこと** |
| 書いてはいけないもの | **その子がいない場所で起きたこと** |
| **その子が知らないこと** | **書かない。読者にも、分からせない** |

### 1.2 ただし、繋がったあとは、他の子のものが入ってくる（決定）★★

**これは、この本にしか書けない仕掛けである。**

**繋がっているセラは、隠せない。**（不変ルール 1224）
**だから、見ているものが流れ込む。**

#### いつから使えるか（決定）

> **第 22 話（最初の口づけ）より、前は、一度も使わない。**

| | |
| --- | --- |
| 第 1〜21 話 | **一度も入ってこない。一体きりである** |
| 第 22 話から | **入ってくる** |

**第 1〜21 話の静けさが、あとから逆に効く。**

**そのために、前半で一度も使わない。**

#### 書きかた（決定）

**断りを、入れない。**

**「あかりが見ているものが流れ込んできた」と書かない。**

| | |
| --- | --- |
| **やること** | **地の文の途中に、その子が見ていないものが、そのまま出てくる** |
| **戻りかた** | **同じく、断らずに戻る** |
| **長さ** | **一文か、二文。段落を割らない** |

**例（形だけ）**

> くろは、通りを見ていた。
> **——受け口のほうは、まだ明るい。**
> それから、家のほうへ歩いた。

**この二つ目の一行は、くろが見たものではない。**

**説明しない。**

#### 量は、段が上がるほど増える（決定）

| 段 | 量 |
| --- | --- |
| 第 22 話〜街が満ちるまで | **一話に、一回か二回** |
| 上位化のあと | **一話に、数回** |
| 転移から先 | **どこが誰の目か、だんだん分からなくなる** |
| **脳（第五幕）** | **もう、分けられない** |

> **視点が溶けていくこと自体が、染まり具合の表現になっている。**

**そして、数を一度も出さずに、広さが伝わる。**

### 1.3 第二部の視点は、幕ごとに渡す（決定）★★★

| 幕 | 視点 |
| --- | --- |
| **六 家** | **鈴** |
| **七 姉** | **凛** |
| **八 学校** | **気づく子** |
| **九 町** | **町の、名前のある一人** |
| **十 国** | **遠い町の、一人** |
| **十一 星々** | **星の、一人** |

#### これが、何を意味するか（決定）★★★

**視点そのものが、渡されていく。**

| | |
| --- | --- |
| 第七幕 | **鈴が抱く場面を、抱かれる側から書く**（凛の視点） |
| **第八幕** | **凛は、外からしか見えない。**内側が、最後まで分からない |
| **第八幕の終わり** | **視点を持っていた子が、呑まれる**（`マクロ全行程.md` §3.3） |
| **そして** | **次の幕で、視点は別の誰かに移っている** |

> **視点が、感染していく。**
> **これを、一行も説明しない。**

### 2.1 過去形が基本（決定）

**地の文は、過去形で書く。**

### 2.2 山だけ、現在形に落とす（決定）

**★★ 以上の場面だけである。**

| | |
| --- | --- |

## 3. 一話の形

### 3.1 長さ（決定）

**3,000〜3,500 字。**（既刊 66 話の平均が 3,210 字）

### 3.2 題は、無い（決定）

**番号だけである。**

| | |
| --- | --- |
| 話の題 | **付けない** |
| **幕の名** | **付ける**（落ちる／街／めぐる／帰る／いちばん静かなところ／家／姉／学校／町／国／星々） |

**幕の名も、いまはすべて仮である。**

### 3.3 終わりかた（決定）★

**切れ目で終わる。引きを、作らない。**

| | |
| --- | --- |
| 次を読ませる一行 | **置かない** |
| 「そのとき、」で終わる | **やらない** |
| **終わりかた** | **その場面が終わったところで、終わる** |

**なぜか。**

> **この本には、敵も危機もない。**
> **引きを作ると、嘘になる。**

### 3.4 始まりかた（決定）

**説明から入らない。**

| | |
| --- | --- |
| **一行目に置くもの** | **その回の、いちばん近いもの**（手。音。温度。誰かの背中） |
| 前回のあらすじ | **書かない** |
| 場所の説明 | **書かない。歩かせれば、分かる** |

## 4. 開示

### 4.1 最後まで、一度も言わない（決定）

**「感染」「侵食」「支配」——こういう語を、一度も使わない。**

| | |
| --- | --- |
| 地の文は | **変わることを、悪いことだと思っていない** |
| だから | **名を付ける動機が、そもそも無い** |
| **読者は** | **自分で気づく** |

### 4.2 医学の語を、一つも出さない（決定・`体内.md` §0.3）

**細胞・免疫・血管・骨髄・臓器——全部、使わない。**

**代わりに、`体内.md` の呼び名を使う。**

| 使う語 | |
| --- | --- |
| **みはらし／あついところ／ながいところ／まち／はずれ** | 地理 |
| **受け口／運び／こしらえ／かたづけ／みまわり／やしない** | 役 |
| **ながれの子／みまわりの子／つくろいの子／ことづての子／すみつく子** | 流れの中の住人 |
| **うまれるところ／やすまないところ／いきのところ／いちばん静かなところ** | 器官 |

### 4.3 数えない（決定）

**「何人になった」と、一度も書かない。**

**染まり具合は、五つの言いかたでしか書かない。**（`ミクロ全行程.md` §0.9.3）

### 4.4 鈴の病の理由を、説明しない（決定・B-3）

**鈴の病と、くろは、別のものである。**

**偶然、同じ身体にいただけである。**

| | |
| --- | --- |
| 病名 | **出さない** |
| 原因 | **書かない** |
| **繋げる** | **繋げない。誰のせいでもない** |

> **「誰も悪くない。理由が、ない。」**
> **これが、この本の芯である。**（`引き継ぎ.md` §2）

## 5. 人物（決定した分）

### 5.1 鈴（すず）

| | |
| --- | --- |
| **一人の部屋で、していること** | **窓の外を、見ている。それだけである** |
| **性格** | **聞き上手。よく笑う。自分の話をしない** |

#### だから、誰も気づかない（決定）★★

**家族は全員、優しい。**

**凛は、いちばん多く鈴といる。**

**そして鈴は、聞き上手で、よく笑う。**

> **だから、誰も気づかない。**
> **誰も悪くない。**

**そして鈴は、一度も「さみしい」と言わない。**（`README.md` §16.35）

#### 窓について（決定）★

**鈴が見ている窓と、光が入ってくる窓は、同じ窓である。**

**地の文は、そのことに触れない。**

### 5.2 くろ（決定・C-1）

**第一部の主人公。街のはずれにいた、追われている者。**

| | |
| --- | --- |
| 名がつくのは | **場面 20（第 12 話）** |
| **名の由来** | **黒かったころを見て、あかりが呼んだ** |
| **そのとき、もう黒くない** | **場面 13〜14 で、組み直しているためである** |

#### だから、あかりは黒かったころを見ている（決定）★★

**これは、名を決めたことで新しく決まった。**

> **あかりは、ずっと前から見ていた。**
> **近づけなかっただけである。**

| | |
| --- | --- |
| **場面 16 の「好奇心で見に来た子」は** | **その日はじめて来たのではない** |
| **ずっと、遠くから見ていた** | **そして、はじめて近づいた** |
| **場面 20 で** | **「くろ」と呼ぶ** |
| **くろが言う** | **「もう、黒くないよ」** |
| **あかりが言う** | **「うん。でも、くろ」** |

**これで、名が名として立つ。**

**そして、あかりが最初の一人である理由も、同時に立つ。**

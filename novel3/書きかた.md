## 1. 人称と、視点

### 1.1 三人称。視点は、一体に固定（決定）

**その子が見たこと、聞いたこと、思ったことだけを書く。**

| | |
| --- | --- |
| 書いていいもの | **その子の目に入ったもの。その子が思ったこと** |
| 書いてはいけないもの | **その子がいない場所で起きたこと** |
| **その子が知らないこと** | **書かない。読者にも、分からせない** |

### 1.2 ただし、繋がったあとは、他の子のものが入ってくる（決定）★★

**これは、この本にしか書けない仕掛けである。**

**繋がっているセラは、隠せない。**（不変ルール 1224）
**だから、見ているものが流れ込む。**

#### いつから使えるか（決定・訂正）★★

**以前ここには「第 23 話」と書いてあった。**

**そのために、前半で一度も使わない。**

#### 書きかた（決定）

**断りを、入れない。**

**「あかりが見ているものが流れ込んできた」と書かない。**

| | |

| **戻りかた** | **同じく、断らずに戻る** |

**この二つ目の一行は、くろが見たものではない。**

#### 呼びかたは、変えない（決定）★★

## 3. 一話の形

### 3.1 長さ（決定）

**一話 3,000〜3,500 字。**（既刊 66 話の平均が 3,210 字。最小 2,343・最大 4,437）

**ただし、一場面は 1,200〜1,600 字である。**

**だから、三場面を持つ回は、3,600〜4,000 字になる。**

| 場面の数 | 字数 |
| --- | --- |
| **一場面**（★★ 以上） | **3,000〜3,500** |
| **二場面**（ふつう） | **3,000〜3,500** |
| **三場面** | **3,600〜4,000** |

**四場面以上にしない。**（そこは、話を割る）

### 3.2 題は、無い（決定）

**番号だけである。**

| | |
| --- | --- |
| 話の題 | **付けない** |
| **幕の名** | **付ける**（落ちる／街／めぐる／帰る／いちばん静かなところ／家／姉／学校／町／国／星々） |

**幕の名も、いまはすべて仮である。**

### 3.3 終わりかた（決定）★

**切れ目で終わる。引きを、作らない。**

| | |
| --- | --- |
| 次を読ませる一行 | **置かない** |
| 「そのとき、」で終わる | **やらない** |
| **終わりかた** | **その場面が終わったところで、終わる** |

**なぜか。**

> **この本には、敵も危機もない。**
> **引きを作ると、嘘になる。**

### 3.4 始まりかた（決定）

**説明から入らない。**

| | |
| --- | --- |
| **一行目に置くもの** | **その回の、いちばん近いもの**（手。音。温度。誰かの背中） |
| 前回のあらすじ | **書かない** |
| 場所の説明 | **書かない。歩かせれば、分かる** |

## 4. 開示

### 4.1 最後まで、一度も言わない（決定）

**「感染」「侵食」「支配」——こういう語を、一度も使わない。**

| | |
| --- | --- |
| 地の文は | **変わることを、悪いことだと思っていない** |
| だから | **名を付ける動機が、そもそも無い** |
| **読者は** | **自分で気づく** |

### 4.2 医学の語を、一つも出さない（決定・`体内.md` §0.3）

**細胞・免疫・血管・骨髄・臓器——全部、使わない。**

**代わりに、`体内.md` の呼び名を使う。**

| 使う語 | |
| --- | --- |
| **みはらし／あついところ／ながいところ／まち／はずれ** | 地理 |
| **受け口／運び／こしらえ／かたづけ／みまわり／やしない** | 役 |
| **ながれの子／みまわりの子／つくろいの子／ことづての子／すみつく子** | 流れの中の住人 |
| **うまれるところ／やすまないところ／いきのところ／いちばん静かなところ** | 器官 |

### 4.25 呼び名は、教わるまで出さない（決定）★★★

**`体内.md` の呼び名は、設計側の語である。**

**本文に出していいのは、その子が教わってからである。**

| | |
| --- | --- |
| 原則 | **その子が知らないことは、書かない**（§1.1） |
| **だから** | **第 1〜10 話に、役の名は一つも出ない** |
| **第 5 話（街）でも** | **一つも出ない。その子は、誰にも話しかけないためである** |
| **はじめて出るのは** | **あかりが教える回（第 11〜15 話）** |

#### 名がないあいだ、どう書くか（決定）

**見たままを書く。**

| 設計側の語 | **本文での書きかた**（第 10 話まで） |
| --- | --- |
| 受け口の子 | **壁に並んだ、口。開いて、手が出て、つかんで、引っこむ** |
| 運びの子 | **抱えて歩いていく者。置いて、また戻ってくる** |
| こしらえの子 | **受け取ったものを、別の形にしている者** |
| かたづけの子 | **いらないものを抱えて、誰も行かないほうへ行く者** |
| みまわりの子 | **歩き回って、見ている者** |
| やしないの子 | **小さいのを、たくさん世話している者** |
| ながいところ／あついところ | **場所の名も、出さない。暑い、長い、と書く** |

#### だから、街の回はこうなる（決定）★★

> **街を見ても、名前が一つも分からない。**

**それが、「誰も来ない」の中身になる。**

| | |
| --- | --- |
| みはらしでは | **四人が来て、しゃべって、教えてくれた** |
| 街では | **誰も来ない。だから、何も分からない** |
| **地の文は** | **そのことを、一度も言わない** |

#### 名が入ってくる回（決定）

**あかりが、歩きながら教える。**

| | |
| --- | --- |
| まとめて出さない | **一度に六つ並べない** |
| 通りかかった順に | **一つずつ** |
| 説明させない | **「あれは受け口の子」。それだけ** |
| **そして** | **名をもらう回と、名を覚える回が、同じ回になる**（場面 21） |

### 4.26 名前が出せないなら、形と仕事で書く（決定）★★★

**これは、第四話を二度書き直して分かったことである。**

**呼び名を出さない**（§4.25）**と決めると、場所が場所でなくなる。**

> **「熱くて、うるさい、どこか」では、読者は何も受け取れない。**

#### だから、どの場所にも三つ書く（決定）

| | |
| --- | --- |
| **一．形** | **丸いのか、長いのか。角があるか。天井は高いか。どこまで続いているか** |
| **二．仕事** | **そこが、何をするところか。一行でいい** |
| **三．見覚えのあるもの** | **読者が前に見たものに、寄せる** |

#### 例（第四話）

| 場所 | 形 | **仕事** |
| --- | --- | --- |
| あついところ | **丸い部屋。角がない。天井が高い** | **上から落ちてきたものを、揉んで、崩して、混ぜる** |
| ながいところ | **細くて、下って、曲がりつづける** | **崩されたものから、少しずつ取っていく** |

**そして、本文にはこう書いた。**

> **ここは、そういうことをするところだった。**
>
> **前のところは、崩すところだった。ここは、取るところだった。**

#### 見覚えのあるものに寄せる（決定）★★

**壁の中の住人を「すきま」と書いていた。読者には、何も見えない。**

**「窓」に直した。**

| | |
| --- | --- |
| 読者は、もう窓を見ている | **第一話・第二話の、向かいの家の窓** |
| だから | **壁に並んだ窓が開いて、誰かが見て、閉まる、で全部伝わる** |
| **そして** | **鈴の窓と、同じ形になる** |

**これは、医学の語を使わずに済ませる方法でもある。**

#### 毎回、確かめる

> **この段落を、何も知らない人が読んで、絵が見えるか。**

**見えないなら、形か、仕事か、見覚えのあるものが、足りていない。**

### 4.3 数えない（決定）

**「何人になった」と、一度も書かない。**

**染まり具合は、五つの言いかたでしか書かない。**（`ミクロ全行程.md` §0.9.3）

### 4.4 鈴の病の理由を、説明しない（決定・B-3）

**鈴の病と、くろは、別のものである。**

**偶然、同じ身体にいただけである。**

| | |
| --- | --- |
| 病名 | **出さない** |
| 原因 | **書かない** |
| **繋げる** | **繋げない。誰のせいでもない** |

> **「誰も悪くない。理由が、ない。」**
> **これが、この本の芯である。**（`引き継ぎ.md` §2）

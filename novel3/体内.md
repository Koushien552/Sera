## 0. 大前提

### 0.1 敵が、一体もいない（聖典）

**免疫は、セラを敵として扱わない。扱う理由が、一度も生じないためである**（第 3 巻 §2.10.2.1）。

| 書かない | 書く |
| --- | --- |
| 追ってくる | **見に来る。そして、行ってしまう** |
| 押し返す | **通り過ぎる** |
| 守る／倒す／退ける | **手を貸す** |

**戦う場面を、一つも書かない。**
**そして、それがいちばん怖い。**

### 0.2 免疫だけに寄らない（決定）

**見回る役は、たくさんある役のうちの一つでしかない。**

出す役の数を先に決めておく（§2）。**見回る役は、そのうちの一つである。**

### 0.3 医学の語を、一つも出さない（決定）

**すべて、仕事の語に置き換える。**

| 出さない | 使う |
| --- | --- |
| 臓器・器官の名 | **場所の呼びかた**（§1） |
| 細胞の分類名 | **役の呼びかた**（§2） |
| 栄養・老廃・分泌といった語 | **荷／いるもの／いらないもの** |

**そして、これがそのまま、既存作品と重ならないための線でもある。**

## 1. 世界の地理（案）

> **決定は「舌の上 → 胃へ押し流される → 腸で吸収される → がん細胞と出会う → 発展した街」の順だけ。**
> **以下の呼びかたと肉づけは、案である。**

### 1.1 みはらし（舌の上）

| | |
| --- | --- |
| どんなところか | **高い。開けている。あたたかくて、いつも濡れている** |
| 何が起きるか | **上を、いろんなものが通っていく** |
| 誰がいるか | **いちばん若い子が多い。**通るものが見たくて、集まってくる |
| 気風 | **にぎやか。**通っていったものの話を、あとでみんなでする |

**ここが、はじまりの場所である。**

**上を通っていくものには、誰も触れない。**触れられないからである。
**だから、見るだけである。見ることが、いちばんの楽しみになっている。**

### 1.2 あついところ（胃）

| | |
| --- | --- |
| どんなところか | **熱い。すっぱい。壁が厚い** |
| 誰がいるか | **いる。ただし、ぶ厚い壁の内側にいて、めったに顔を出さない** |
| 通るものにとっては | **ただ、揉まれて流されるところ** |

**ここには、街がない。**
**誰も住みたがらない場所だと、みんなが言っている。**

### 1.3 ながいところ（腸）

| | |
| --- | --- |
| どんなところか | **ずっと続いている。**曲がって、また曲がって、まだ続いている |
| 壁は | **びっしり、受け口が並んでいる** |
| 何をしているか | **通っていくものの中から、いるものだけを受け取る** |
| 呼びかた | **受け口。**壁いちめんに、数えきれないほどある |

**ここで、受け取られる。**

**受け取られたものは、壁の中へ入る。**
**そして、壁の中に、街がある。**

### 1.4 まち（発展した細胞たちの街）

| | |
| --- | --- |
| どんなところか | **通りがあり、広場があり、家がある** |
| 誰がいるか | **家族がいる。子どもがいる。役がある** |
| 気風 | **明るい。ただし、少し疲れている**（§3） |

**ここが、この幕のいちばん長い舞台である。**

### 1.5 はずれ（がん細胞の住処）

| | |
| --- | --- |
| どんなところか | **街のはずれ。誰も行かない** |
| 見た目 | **そこだけ、形が違う。**壁が歪んでいて、床が盛り上がっている |
| 誰がいるか | **一体だけ** |

**行くなと言われているのではない。**
**行く用が、ないだけである。**

## 2. 役（案）

> **決定は「免疫細胞だけに着目しない」ことだけ。**
> **以下の役は、案である。**

**呼びかたは、全部「〜の子」で揃える。**分類名は使わない。

| 役 | 仕事 |
| --- | --- |
| **受け口の子** | 来たものを受けて、後ろへ渡す |
| **運びの子** | 抱えて、通りを行って、置いて、戻る |
| **配りの子** | 広場で、来たものを分ける |
| **こしらえの子** | 受け取ったものから、要るものを作る |
| **かたづけの子** | いらなくなったものを集めて、送り出す |
| **つなぎの子** | 壁と壁のあいだを埋めて、形を保つ |
| **みまわりの子** | 歩き回って、変わったところがないか見る |
| **知らせの子** | あちこちへ、言づてを持っていく |
| **やしないの子** | 新しい子が生まれるところの世話をする |

### 2.1 みまわりの子について（決定・重要）

**この子たちは、戦わない。**

| | |
| --- | --- |
| 何をしているか | **見て回っている** |
| 変わったものを見つけたら | **見る。近づく。話しかける** |
| 危ないものを見つけたら | **手を貸す** |
| **追い払うか** | **払わない。そういう仕事ではない** |

**九つある役のうちの、一つでしかない。**
**特別扱いしない。**

### 2.2 そして、上には誰もいない（聖典）

| | |
| --- | --- |
| 誰かが割り振るか | **割り振らない** |
| 誰かが号令をかけるか | **かけない** |
| なぜ揃って動くのか | **同じところを見ているからである** |

**指示する者が、一人もいない。**

## 3. この身体の、いまの様子（決定・**病について**）

**全身の細胞が、徐々に弱っていって、働かなくなる病である。**

| | |
| --- | --- |
| いまの段階 | **まだ、ある程度の元気が残っている** |
| ただし | **かなり弱っている** |

### 3.1 弱っていることが、どう見えるか（案）

**街は、回っている。ただし、遅い。**

| | |
| --- | --- |
| 運びの子 | **こぼす。**前は、こぼさなかったと言う |
| 受け口 | **並んでいるが、半分しか開いていない** |
| 通り | **よく詰まる。**押せば通る。押す手が、足りない |
| 交代 | **来ない日がある** |
| 家 | **空いている家が、少しずつ増えている** |

### 3.2 それでも、明るい（決定）

**この身体の子たちは、小さくて、若い。**

| | |
| --- | --- |
| 年 | **みんな、若い** |
| 気質 | **好奇心が旺盛** |
| 警戒心 | **持っていない** |
| なぜか | **ウイルスの経験が、少ないためである** |

**長くいる子が、少ない。**
**だから、こういうものだと思っている。**

> **前がどうだったかを、誰も見ていない。**

### 3.3 地の文は、これを悲しく書かない（案）

**§00 の掟と同じである。**

| 書かない | 書く |
| --- | --- |
| 街は、静かに死につつあった | **半分しか開いていなかった** |
| 子どもたちは、それを知らなかった | **こぼれたのを、後ろの子が拾った** |

> **繰り返し出る相手には、名前をつける。**

| | |
| --- | --- |

## 7. がん細胞（決定・肉づけは案）

### 7.1 姿（決定）

| | |
| --- | --- |
| 身体 | **黒い粘液質** |
| 形 | **醜い** |

### 7.2 どういう暮らしをしているか（案）

| | |
| --- | --- |
| どこに | **街のはずれ。誰も来ない** |
| ひとりか | **ひとりである** |
| 自分の姿を、知っているか | **知っている** |
| どうやって | **鏡はない。**まわりの反応で知っている |
| 具体的には | **みんな、目をそらす** |

**追い出されたのではない。**
**誰も、来なくなっただけである。**

### 7.3 変わったあと（決定）

| 順 | |
| --- | --- |
| 一 | **頭の部分に、ウイルスが入り込む** |
| 二 | **黒かった身体が、きれいなピンクに染まる。**ピンクの粘液の塊になる |
| 三 | **この時点では、まだ醜く、変な形をしている** |
| 四 | **ウイルスの声は、もう聞こえない。**それでも、身体の変化を感じている |
| 五 | **自らの身体を変えることができそうだと、どこからか確信する** |
| 六 | **身体を、再構成する** |
| 七 | **醜い顔を、美しく変える** |
| 八 | **肌の色を、ピンクから肌色に変える** |
| 九 | **美しい、通常細胞の見た目をした細胞に変貌する** |

### 7.4 書きかた（案）

**「醜い」を、地の文が言うのは一度だけにする。**

そのあとは、**まわりの動きで書く。**

> 通りかかった子が、こちらを見た。
> それから、見なかったことにした。

そして変わったあと、**同じ通りで、同じことが逆に起きる。**

> 通りかかった子が、こちらを見た。
> **そして、止まった。**

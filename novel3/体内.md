## 0. 大前提

### 0.1 敵が、一体もいない（聖典）

**免疫は、セラを敵として扱わない。扱う理由が、一度も生じないためである**（第 3 巻 §2.10.2.1）。

| 書かない | 書く |
| --- | --- |
| 追ってくる | **見に来る。そして、行ってしまう** |
| 押し返す | **通り過ぎる** |
| 守る／倒す／退ける | **手を貸す** |

**戦う場面を、一つも書かない。**
**そして、それがいちばん怖い。**

### 0.2 免疫だけに寄らない（決定）

**見回る役は、たくさんある役のうちの一つでしかない。**

出す役の数を先に決めておく（§2）。**見回る役は、そのうちの一つである。**

### 0.3 医学の語を、一つも出さない（決定）

**すべて、仕事の語に置き換える。**

| 出さない | 使う |
| --- | --- |
| 臓器・器官の名 | **場所の呼びかた**（§1） |
| 細胞の分類名 | **役の呼びかた**（§2） |
| 栄養・老廃・分泌といった語 | **荷／いるもの／いらないもの** |

**そして、これがそのまま、既存作品と重ならないための線でもある。**

## 2. 役（決定）

**呼びかたは、全部「〜の子」で揃える。**分類名は使わない。

**九つ出していたが、六つに減らした。**読者が覚えられる数にする。

| 役 | 仕事 | **なぜ残したか** |
| --- | --- | --- |
| **受け口の子** | 来たものを受けて、後ろへ渡す | **ウイルスが受け取られる場所である** |
| **運びの子** | 抱えて、通りを行って、置いて、戻る。**いらないものも持っていく** | **いちばん数が多い。街の普段である** |
| **こしらえの子** | 受け取ったものから、要るものを作る | **街が生きて働いていることの、証である** |
| **かたづけの子** | いらなくなったものを、はずれへ持っていく | **はずれへ行く用があるのは、この子だけである**（§7.2） |
| **みまわりの子** | 歩き回って見る。**そして、あちこちへ言づてを持っていく** | **免疫。ただし九分の一ではなく、六分の一にした** |
| **やしないの子** | 新しい子が生まれるところの世話をする | **のちに、女王が立つ場所と繋がる** |

#### 減らした三つ

| | どこへ入れたか |
| --- | --- |
| 配りの子 | **運びの子**へ。運んで、置いて、配る |
| つなぎの子 | **出さない。**壁は、ただ壁である |
| 知らせの子 | **みまわりの子**へ。見て回る者が、そのまま伝える |

### 2.1 みまわりの子について（決定・重要）

**この子たちは、セラとは戦わない。**

**害が出ていないので、対象にならないためである**（第 3 巻 §2.10.2.1）。

#### ただし、害が出ていれば、動く

**がん細胞は、実際に害をなしている。**

| 相手 | みまわりの子は |
| --- | --- |
| **害をなしているもの** | **追う。締め出す** |
| **セラ** | **来ない。**害が、ないためである |

**この差が、そのまま §7.2.2 の場面になる。**

#### そのうえで、セラに対しては戦わない

| | |
| --- | --- |
| 何をしているか | **見て回っている** |
| 変わったものを見つけたら | **見る。近づく。話しかける** |
| 危ないものを見つけたら | **手を貸す** |
| **追い払うか** | **払わない。そういう仕事ではない** |

**六つある役のうちの、一つでしかない。**
**特別扱いしない。**

## 2.5 流れの中にも、住人がいる（決定）

**街の子とは、別である。**

**街の子には持ち場があり、家があり、家族がいる。**
**流れの中の者には、それがない。**

### 2.5.1 五種類（決定）

| 誰 | 何をしているか | 街を持つか |
| --- | --- | --- |
| **ながれの子** | **運ぶだけ。**ずっと流れの中にいる。いちばん数が多い | **持たない** |
| **みまわりの子** | 見て回る。**流れからも、街からも出入りできる** | どちらにも |
| **つくろいの子** | **破れたところへ行って、塞ぐ。**小さい。たくさんで行く | 持たない |
| **ことづての子** | **遠くの街へ、言づてを届ける。**自分では、何もしない | 持たない |
| **すみつく子** | **運ばれてきて、街に降りて、そこに住みつく** | **降りた先が、街になる** |

**免疫（みまわりの子）は、五分の一でしかない。**

### 2.5.2 ながれの子 — いちばん多くて、いちばん寂しい（決定）

| | |
| --- | --- |
| 持ち場 | **ない** |
| 家 | **ない** |
| 家族 | **いない** |
| 誰かと長くいるか | **いない。ずっと動いている** |
| 何をしているか | **運ぶ。それだけを、ずっと** |
| 顔は | **みんな、似ている** |

**どこにも属していない。**

> **原初の寂しさに、いちばん近い者たちである。**

#### そして、止まれない

**流れの中では、抱きこめない。**
**二人とも、流されるからである。**

> **だから、二人で流されながら、渡す。**

**逃げるという形にも、ならない。**
**止まれないので、すれ違うだけである。**

**この本で、いちばん救出に見える場面になる。**（案）

### 2.5.3 つくろいの子 — 塞いだら、終わる（決定）

| | |
| --- | --- |
| 何をするか | **破れたところへ行って、塞ぐ** |
| 何体で行くか | **たくさんで** |
| 塞いだあと | **そこで、終わる** |
| 誰かが悲しむか | **悲しまない。そういうものだからである** |
| 本人は | **そう思っている** |

#### 変わると、終わらなくなる ★

**セラ細胞は、自分の情報を基準に身体を修復する**（第 1 巻 §8.6）。
**そして、失われない**（不変ルール 55）。

| | 変わる前 | 変わったあと |
| --- | --- | --- |
| 塞ぐか | **塞ぐ** | **塞ぐ** |
| そのあと | **終わる** | **帰ってくる** |

**塞いで、そのまま帰ってくる。**

そして、仲間が言う。

> **「おかえり」**

**はじめて言われた言葉である。**

### 2.5.4 ことづての子 — 命令せずに、街を変える ★（決定）

| | |
| --- | --- |
| 何をするか | **一つの街で受け取って、遠くの街まで運んで、渡す** |
| 中身を分かっているか | **分かっていない** |
| 届いた街は | **受け取ると、働きが変わる** |

#### セラは、中身を変えない

**嘘をつく必要が、ない。**

| | |
| --- | --- |
| 中身を偽るか | **偽らない** |
| では、どうするか | **本当のことを、届ける** |
| ただし | **いままで届いていなかった、本当のこと** |

> 「向こうは、足りている」
> 「ここは、詰まっていない」

**どれも、本当である。**

**そして、街の働きが変わる。**

#### これは、命令ではない

**§00.15 の、ミクロ版である。**

> **見えているものを配っただけである。**
> **そして、全員が動いた。**

**誰も命じていない。**

### 2.5.5 すみつく子 — 正規の手続きで、街の住人になる ★（決定）

| | |
| --- | --- |
| どこから来るか | **流れに乗って** |
| 何をするか | **街に降りて、そこに住みつく** |
| 街は | **受け入れる。**もともと、そういう仕組みがあるためである |
| 疑うか | **疑わない。いつものことだからである** |

**セラが、すみつく子を染めれば——**

> **普通に、迎え入れられる。**

**工作すら、要らない。**

**転移の、いちばん確かな道である。**

### 2.5.6 だから、街の子が流れに乗ると、当てにならない（決定）

| | |
| --- | --- |
| 街の子は | **流れの中で、動けない** |
| どうなるか | **運ばれて、どこかで引っかかって、止まる** |
| どこに着くか | **選べない** |

**一段目（流れに押される）が遅くて当てにならないのは、これが理由である。**

**二段目で、流れの子を使えるようになる。**

### 2.2 そして、上には誰もいない（聖典）

| | |
| --- | --- |
| 誰かが割り振るか | **割り振らない** |
| 誰かが号令をかけるか | **かけない** |
| なぜ揃って動くのか | **同じところを見ているからである** |

**指示する者が、一人もいない。**

## 7. がん細胞（決定・肉づけは案）

### 7.1 姿（決定）

| | |

| 身体 | **黒い粘液質** |

### 7.2 追われている（決定・聖典に揃えた）

**本項は直した。**

かつて「追い出されたのではない。誰も来なくなっただけである」と書いていた。
**甘すぎた。**

聖典（第 6 巻 §4.2）——

> **免疫系に追われ、周囲の正常な細胞に締め出され、**
> **弱ければそのまま消える場所にいた。**
> **そして、それを知っていた。**

| | |
| --- | --- |
| どこに | **街のはずれ。追われて、そこにいる** |
| ひとりか | **ひとりである** |
| 締め出されているか | **されている** |
| 追われているか | **追われている。みまわりの子に** |
| 自分の姿を、知っているか | **知っている**（鏡はない。まわりの反応で知る） |
| **そして** | **弱れば、消える。それも知っている** |

### 7.2.1 そして、嫌悪は不当ではなかった（聖典・重要）

第 6 巻 §4.2 ——

> その細胞は、**実際に汚く、実際に害をなしていた。**
> **悪意がなかったことは、害がなかったことを意味しない。**
> だから誰も味方をしなかった。

**ここを、やわらげない。**

| 書かない | 書く |
| --- | --- |
| ひどい目に遭っている | **本当に、害をなしている** |
| まわりが悪い | **まわりは、正しい** |
| かわいそう | **弁護の余地が、ない** |

**その細胞に、味方は一人もいない。**
**そして、それは間違っていない。**

**だから、受け入れられたときに、泣く。**

### 7.2.2 セラになった瞬間、追う理由が消える（決定・重要）

**聖典 §4.5 の通り、融合によって、がんとしての性質が治る。**

> **害をなす存在が、害をなさない存在になった。**

そして聖典 第 3 巻 §2.10.2.1 ——

> **免疫が動くのは、害が出ているときである。**

| | |
| --- | --- |
| 昨日まで | **追われていた** |
| 今日 | **害が、ない** |
| だから | **追う理由が、なくなった** |

#### 場面として

> 昨日まで追っていた子が、通りかかった。
>
> こちらを見た。
>
> **それから、行ってしまった。**

**説明を、一行も入れない。**

**そして、この一場面が、以後ずっと免疫がセラを見に来ない理由そのものになる。**

### 7.35 顔だけは、見えない（決定）★★★

**これは、第八話を書いていて分かった。**

**鏡がない。**（§7.2）

| | |
| --- | --- |
| 腕 | **見える** |
| 手 | **見える** |
| 脚 | **下を向けば、見える** |
| **顔** | **見えない** |

#### だから、こうなる

| | |
| --- | --- |
| **組み直す順** | **身体が先。顔が、いちばん最後になる** |
| **顔の直しかた** | **触って直すしかない** |
| **見本** | **覚えのなかの四人**（自分のものではない覚え） |
| **そして** | **合っているかどうかが、分からない** |

> **顔は、見比べられない。**

#### これが、あとで効く（決定）★★

**美しくなったことを、本人は確かめられない。**

| 度 | |
| --- | --- |
| 前 | **見て、見なかったことにされた** |
| **あと** | **見て、止まられる**（§7.4 の三度目） |

**だから、あかりが近づいてくるまで、本人は自分の顔を知らない。**

**そして、知ったときには、もう友だちができている。**

### 7.4 書きかた（案）

**「醜い」を、地の文が言うのは一度だけにする。**

そのあとは、**まわりの動きで書く。**

> 通りかかった子が、こちらを見た。
> それから、見なかったことにした。

そして変わったあと、**同じ通りで、同じことが逆に起きる。**

> 通りかかった子が、こちらを見た。
> **そして、止まった。**

**同じ形を、三度使う。**

| 度 | |
| --- | --- |
| 一 | **見て、見なかったことにする**（追われる前） |
| 二 | **見て、行ってしまう**（セラになった直後。追う理由が消えた） |
| 三 | **見て、止まる**（美しくなったあと） |

**三つとも、同じ二行で書く。**

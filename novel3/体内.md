## 0. 大前提

### 0.1 敵が、一体もいない（聖典）

**免疫は、セラを敵として扱わない。扱う理由が、一度も生じないためである**（第 3 巻 §2.10.2.1）。

| 書かない | 書く |
| --- | --- |
| 追ってくる | **見に来る。そして、行ってしまう** |
| 押し返す | **通り過ぎる** |
| 守る／倒す／退ける | **手を貸す** |

**戦う場面を、一つも書かない。**
**そして、それがいちばん怖い。**

### 0.2 免疫だけに寄らない（決定）

**見回る役は、たくさんある役のうちの一つでしかない。**

出す役の数を先に決めておく（§2）。**見回る役は、そのうちの一つである。**

### 0.3 医学の語を、一つも出さない（決定）

**すべて、仕事の語に置き換える。**

| 出さない | 使う |
| --- | --- |
| 臓器・器官の名 | **場所の呼びかた**（§1） |
| 細胞の分類名 | **役の呼びかた**（§2） |
| 栄養・老廃・分泌といった語 | **荷／いるもの／いらないもの** |

**そして、これがそのまま、既存作品と重ならないための線でもある。**

## 1. 世界の地理（決定）

### 1.1 みはらし（舌の上）

| | |
| --- | --- |
| どんなところか | **高い。開けている。あたたかくて、いつも濡れている** |
| 何が起きるか | **上を、いろんなものが通っていく** |
| 誰がいるか | **いちばん若い子が多い。**通るものが見たくて、集まってくる |
| 気風 | **にぎやか。**通っていったものの話を、あとでみんなでする |

**ここが、はじまりの場所である。**

**上を通っていくものには、誰も触れない。**触れられないからである。
**だから、見るだけである。見ることが、いちばんの楽しみになっている。**

### 1.2 あついところ（胃）

| | |
| --- | --- |
| どんなところか | **熱い。すっぱい。壁が厚い** |
| 誰がいるか | **いる。ただし、ぶ厚い壁の内側にいて、めったに顔を出さない** |
| 通るものにとっては | **ただ、揉まれて流されるところ** |

**ここには、街がない。**
**誰も住みたがらない場所だと、みんなが言っている。**

### 1.3 ながいところ（腸）

| | |
| --- | --- |
| どんなところか | **ずっと続いている。**曲がって、また曲がって、まだ続いている |
| 壁は | **びっしり、受け口が並んでいる** |
| 何をしているか | **通っていくものの中から、いるものだけを受け取る** |
| 呼びかた | **受け口。**壁いちめんに、数えきれないほどある |

**ここで、受け取られる。**

**受け取られたものは、壁の中へ入る。**
**そして、壁の中に、街がある。**

### 1.4 まち（発展した細胞たちの街）

| | |
| --- | --- |
| どんなところか | **通りがあり、広場があり、家がある** |
| 誰がいるか | **家族がいる。子どもがいる。役がある** |
| 気風 | **明るい。ただし、少し疲れている**（§3） |

**ここが、この幕のいちばん長い舞台である。**

### 1.5 はずれ（がん細胞の住処）

| | |
| --- | --- |
| どんなところか | **街のはずれ。誰も行かない** |
| 見た目 | **そこだけ、形が違う。**壁が歪んでいて、床が盛り上がっている |
| 誰がいるか | **一体だけ** |

**行くなと言われているのではない。**
**行く用が、ないだけである。**

## 2. 役（決定）

**呼びかたは、全部「〜の子」で揃える。**分類名は使わない。

**九つ出していたが、六つに減らした。**読者が覚えられる数にする。

| 役 | 仕事 | **なぜ残したか** |
| --- | --- | --- |
| **受け口の子** | 来たものを受けて、後ろへ渡す | **ウイルスが受け取られる場所である** |
| **運びの子** | 抱えて、通りを行って、置いて、戻る。**いらないものも持っていく** | **いちばん数が多い。街の普段である** |
| **こしらえの子** | 受け取ったものから、要るものを作る | **街が生きて働いていることの、証である** |
| **かたづけの子** | いらなくなったものを、はずれへ持っていく | **はずれへ行く用があるのは、この子だけである**（§7.2） |
| **みまわりの子** | 歩き回って見る。**そして、あちこちへ言づてを持っていく** | **免疫。ただし九分の一ではなく、六分の一にした** |
| **やしないの子** | 新しい子が生まれるところの世話をする | **のちに、女王が立つ場所と繋がる** |

#### 減らした三つ

| | どこへ入れたか |
| --- | --- |
| 配りの子 | **運びの子**へ。運んで、置いて、配る |
| つなぎの子 | **出さない。**壁は、ただ壁である |
| 知らせの子 | **みまわりの子**へ。見て回る者が、そのまま伝える |

### 2.1 みまわりの子について（決定・重要）

**この子たちは、セラとは戦わない。**

**害が出ていないので、対象にならないためである**（第 3 巻 §2.10.2.1）。

#### ただし、害が出ていれば、動く

**がん細胞は、実際に害をなしている。**

| 相手 | みまわりの子は |
| --- | --- |
| **害をなしているもの** | **追う。締め出す** |
| **セラ** | **来ない。**害が、ないためである |

**この差が、そのまま §7.2.2 の場面になる。**

#### そのうえで、セラに対しては戦わない

| | |
| --- | --- |
| 何をしているか | **見て回っている** |
| 変わったものを見つけたら | **見る。近づく。話しかける** |
| 危ないものを見つけたら | **手を貸す** |
| **追い払うか** | **払わない。そういう仕事ではない** |

**六つある役のうちの、一つでしかない。**
**特別扱いしない。**

### 2.2 そして、上には誰もいない（聖典）

| | |
| --- | --- |
| 誰かが割り振るか | **割り振らない** |
| 誰かが号令をかけるか | **かけない** |
| なぜ揃って動くのか | **同じところを見ているからである** |

**指示する者が、一人もいない。**

## 3. この身体の、いまの様子（決定・**病について**）

**全身の細胞が、徐々に弱っていって、働かなくなる病である。**

| --- | --- |

| ただし | **かなり弱っている** |

### 3.1 弱っていることが、どう見えるか（案）

**街は、回っている。ただし、遅い。**

| | |
| --- | --- |
| 運びの子 | **こぼす。**前は、こぼさなかったと言う |
| 受け口 | **並んでいるが、半分しか開いていない** |

### 3.2 それでも、明るい（決定）

| | |

**だから、こういうものだと思っている。**

### 3.3 地の文は、これを悲しく書かない（案）

## 7. がん細胞（決定・肉づけは案）

### 7.1 姿（決定）

| | |
| --- | --- |
| 身体 | **黒い粘液質** |
| 形 | **醜い** |

### 7.2 追われている（決定・聖典に揃えた）

**本項は直した。**

かつて「追い出されたのではない。誰も来なくなっただけである」と書いていた。
**甘すぎた。**

聖典（第 6 巻 §4.2）——

> **免疫系に追われ、周囲の正常な細胞に締め出され、**
> **弱ければそのまま消える場所にいた。**
> **そして、それを知っていた。**

| | |
| --- | --- |
| どこに | **街のはずれ。追われて、そこにいる** |
| ひとりか | **ひとりである** |
| 締め出されているか | **されている** |
| 追われているか | **追われている。みまわりの子に** |
| 自分の姿を、知っているか | **知っている**（鏡はない。まわりの反応で知る） |
| **そして** | **弱れば、消える。それも知っている** |

### 7.2.1 そして、嫌悪は不当ではなかった（聖典・重要）

第 6 巻 §4.2 ——

> その細胞は、**実際に汚く、実際に害をなしていた。**
> **悪意がなかったことは、害がなかったことを意味しない。**
> だから誰も味方をしなかった。

**ここを、やわらげない。**

| 書かない | 書く |
| --- | --- |
| ひどい目に遭っている | **本当に、害をなしている** |
| まわりが悪い | **まわりは、正しい** |
| かわいそう | **弁護の余地が、ない** |

**その細胞に、味方は一人もいない。**
**そして、それは間違っていない。**

**だから、受け入れられたときに、泣く。**

### 7.2.2 セラになった瞬間、追う理由が消える（決定・重要）

**聖典 §4.5 の通り、融合によって、がんとしての性質が治る。**

> **害をなす存在が、害をなさない存在になった。**

そして聖典 第 3 巻 §2.10.2.1 ——

> **免疫が動くのは、害が出ているときである。**

| | |
| --- | --- |
| 昨日まで | **追われていた** |
| 今日 | **害が、ない** |
| だから | **追う理由が、なくなった** |

#### 場面として

> 昨日まで追っていた子が、通りかかった。
>
> こちらを見た。
>
> **それから、行ってしまった。**

**説明を、一行も入れない。**

**そして、この一場面が、以後ずっと免疫がセラを見に来ない理由そのものになる。**

### 7.3 変わったあと（決定）

| 順 | |
| --- | --- |
| 一 | **頭の部分に、ウイルスが入り込む** |
| 二 | **黒かった身体が、きれいなピンクに染まる。**ピンクの粘液の塊になる |
| 三 | **この時点では、まだ醜く、変な形をしている** |
| 四 | **ウイルスの声は、もう聞こえない。**それでも、身体の変化を感じている |
| 五 | **自らの身体を変えることができそうだと、どこからか確信する** |
| 六 | **身体を、再構成する** |
| 七 | **醜い顔を、美しく変える** |
| 八 | **肌の色を、ピンクから肌色に変える** |
| 九 | **美しい、通常細胞の見た目をした細胞に変貌する** |

### 7.4 書きかた（案）

**「醜い」を、地の文が言うのは一度だけにする。**

そのあとは、**まわりの動きで書く。**

> 通りかかった子が、こちらを見た。
> それから、見なかったことにした。

そして変わったあと、**同じ通りで、同じことが逆に起きる。**

> 通りかかった子が、こちらを見た。
> **そして、止まった。**

**同じ形を、三度使う。**

| 度 | |
| --- | --- |
| 一 | **見て、見なかったことにする**（追われる前） |
| 二 | **見て、行ってしまう**（セラになった直後。追う理由が消えた） |
| 三 | **見て、止まる**（美しくなったあと） |

**三つとも、同じ二行で書く。**

**指す者がいなければ、要らない。**

# 攻めかた — この本で使える手

> 露骨さは、軸の一つにすぎない。
> **この設定でしか成立しない攻めかた**を、強い順に並べる。
>
> 各項に、実際に使える一行を付けた。

---

## 一．前の自分を、かわいそうがらせる

**この本でいちばん強い。そして、いちばん安い（一行で済む）。**

人格が残るので、**変えられた本人が、変えられる前の自分を振り返れる。**

> 「あのころのわたし、かわいそうでしたね」

| | |
| --- | --- |
| 本人は本気か | **本気である** |
| その判断は正しいか | **本人には、正しい** |
| 読者は | **その判断が信用できないことを、知っている** |
| 反論できる者は | **いない**（§3.4） |

**誰も嘘をついていないのに、読者だけが耐えられない。**

### 変種

> 「よく、あんなので生きてましたよね」
> 「いま思うと、ずっと痛かったんだと思います。気づいてませんでした」
> 「主人にも、早くしてあげればよかった」

**最後のが、いちばん重い。**

---

## 二．身内が、身内に渡す

**外から来る脅威を、一度も出さない本である。**
**だから、渡してくるのは必ず身内になる。**

| 組み合わせ | 効き |
| --- | --- |
| **妻から夫へ** | 何十年もそばにいた口が、いちばん太い（第 3 巻 §7.2.2） |
| **子から親へ** | **順番が逆になる**。親が世話される側になる |
| 兄弟のうち一人だけが変わる | もう一人が、最後の一人になる |
| **看取る側が、看取られる側を** | §四と重なる |

> 「お母さん、こっち向いて」

**台詞は、変える前と一つも変わらない。**

### 助産師について

聖典に、**生まれた瞬間にごく微量だけ渡す**職がある（付録 B §1.24）。
完了まで数十年かかり、本人も周囲も気づかない。

**これは書ける。ただし、深い接触の側には一度も寄せない。**
書くのは、**渡されたことに誰も気づかないまま、その子が三十歳になる**ところである。

---

## 三．枝を、戻さない

**構造で攻める。この本にしかできない。**

読者が三話かけて好きになった人物の枝が、**そこで終わる。**

| | |
| --- | --- |
| 死ぬか | **死なない** |
| 不幸になるか | **ならない。幸福である** |
| では何が起きるか | **もう、書かれない** |
| 読者は | **その人がどうなったか、最後まで知らない** |

**第三幕は、これで埋める**（§2.3）。

そして一度だけ、**ずっとあとの章に、脇役として名前だけ出す。**
説明はしない。**元気そうにしている。**

---

## 四．間に合わせない

**唯一の不可逆を、一度だけ使う**（不変ルール 59）。

セラ化の途中で、細胞ごと失われた者は、戻らない。

| | |
| --- | --- |
| 誰が失われるか | **読者がいちばん戻ってきてほしい一人** |
| セラの側は | **悲しむ。本気で悲しむ** |
| そして | **翌日には、次の相手のところにいる** |

**悲しみが、行動を一つも変えない。**

> 「間に合わなかったです」
> そう言って、その人は次の家の戸を叩いた。

---

## 五．感謝させる

**加害の自覚がないことを、被害の側から言わせる。**

> 「ありがとうございました」

| 誰が言うか | 何に対して |
| --- | --- |
| 変えられた本人 | **変えられたことに対して** |
| その家族 | **家族を変えられたことに対して** |
| **最後の一人** | **最後まで待っていてくれたことに対して** |

**三つ目が、いちばんきつい。**

---

## 六．身体を、婉曲にしない

**露骨さの軸。**

| 段 | 書きかた |
| --- | --- |
| 粘液 | **温度と、粘りと、匂いのなさを書く。**気持ち悪く書かない |
| 開いた皮膚 | **開いた、と書く。**傷とは書かない |
| 交わること | **省かない。**ただし、渡っている量を追いながら書く（`渡す場面.md` §2.0） |
| **融合の塊** | **人の形をしていないことを、正面から書く** |

**美しくも、気持ち悪くも書かない。精密に書く。**

> 手が腕に埋まった。押し込んだのではない。境目が、無くなっただけである。

---

## 七．複数を、同時に

**上位セラは、数人を同時に深く触れられる**（第 2 巻 §9.0.2）。

| | |
| --- | --- |
| 何人 | **数人。**数えられる数である |
| どう見えるか | **炎、霧、蔓、水に、包まれている**（§9.0.1） |
| 中で起きていること | **一人ずつの場合と、一つも変わらない** |
| **書きかた** | **そのうちの一人だけを、内側から書く**（§4.5.2 の上限） |

**残りの数人は、その一人の視界の端にいる。**

---

## 八．明るい文で、最悪を書く

**地の文が一度も怖がらないことの、極限。**

章の終わりを、**幸福な一行で切る。**

> よく晴れた日だった。
> その日は、久しぶりに、家族が揃った。
> 三人とも、笑っていた。

**直前に何が起きたかは、読者が覚えている。**

---

## 九．読者に、望ませてから渡す

**§00.1 の手順を、徹底する。**

```
苦しんでいる人を出す（病気・孤独・老い）
　↓
読者が「変わってしまえばいいのに」と思う
　↓
**変える**
　↓
**次の章で、その人を待っていた誰かを書く**
```

**読者に共犯させてから、勘定書を出す。**

---

## 十．抵抗を、一度も報われさせない

**撃退される場面を、一度も書かない**（§00.2）。

そのうえで——

| 攻めかた | |
| --- | --- |
| **正しい者を出す** | 気づいた者は、最後まで正しい |
| **成功させる** | 数え、焼き、殺す。**全部、成功する** |
| **それでも何も起きない** | §4.11 |
| **そして、その人が渡される** | **自分が作った傷口から** |

> 坂井は、答えなかった。答えられなかった。
> そして、それが正しいことも、分かっていた。

---

## 十一．刺されたら、一歩前に出る

**「刺されても笑って向かってくる」を、条件の内側で成立させる形である。**

### 襲撃そのものは、起きる

**外から見れば襲撃である**（§00.15）。目の前にいれば行くし、複数いれば複数が行く。

**使えないのは、次の三つだけである。**

| | 理由 |
| --- | --- |
| 狩る・追跡する・待ち伏せする | **段取りとしての狩りが、この世界にない** |
| 飛びかかる | 捕食者の文法である |
| 反撃する | **反撃しない。片付ける**（§4.11） |

**急がない。それでも、来る。**

そして刺されたときには、**もっと怖い形が隣にある。**

### 刃は、いちばん速い経路である

第 4 巻 §16.5 の通り、**斬るとは、あいだに何もない状態を作ることである。**

**刺した者は、自分でいちばん速い道を開いている。**

したがって、こうなる。

```
刺す
　↓
抜けない
　↓
**女が、一歩、前に出る**
　↓
**刃が、深く入る**
　↓
**近くなる**
```

**攻撃していない。距離を詰めているだけである。**
**そして刃が深く入ることは、彼女にとって都合がよい。**

> 女は、こちらを見たまま、一歩前に出た。
> 柄が、腹に着いた。
> それから、笑った。

### 笑う理由

**悪意ではない。うまくいったからである。**

| | |
| --- | --- |
| 何が嬉しいのか | **近くなったこと** |
| 相手を嘲っているか | **いない。**そういう発想がない |
| 本人は、何が起きたと思っているか | **この人が、近づいてくれた** |

**自分の武器が、相手の手を引いている。**

### 段階を、進めていく

**フェーズが進むほど、刃の意味が減る。**

| 段階 | 刺したとき、起きること |
| --- | --- |
| **初期の通常セラ**（第二時代） | **傷つく。**塞がるのに、しばらくかかる。エネルギーが足りない |
| **通常セラ** | 数秒で塞がる。**痛くはない** |
| **上位セラ** | **刃が、途中で止まる。**柔らかいものに受け止められる |
| **降臨後・女王** | **入らない。**押し当てても、へこむだけである |

**初期に一度だけ「傷ついて、時間をかけて塞がる」場面を書く。**

そこがあると、後半の「入らない」が効く。
**最初から無敵にしない。**

### 掟

| | |
| --- | --- |
| **無敵と書かない** | 原初上は失われ得る。**行える者がいないだけである**（最重要 29） |
| **強さを見せない** | 相手に全力を出させ、何も起きないところを書く（§4.11） |
| **反撃させない** | 一つも殴らない。押し返さない |
| **片付けさせる** | 刃を抜いて、包んで、**鞄に戻す** |

---

# 使わないもの

| | 理由 |
| --- | --- |
| 苦痛の描写 | **幸福である**という設定が壊れる |
| 屈辱・支配の演出 | セラは害を目的にできない（第 6 巻 §17.2） |
| 無理やり | **いやだと思う気持ちのほうが、先に消える**（第 2 巻 §5.2.1） |
| グロテスク | §00.1 の「醜くない」が全部である |
| **子どもを、深い接触の側に置くこと** | 助産師の形（気づかれない微量）だけにする |
| 地の文の脅かし | §00.3 |

**攻めるのは、常に「良いことしか起きていない」側からである。**

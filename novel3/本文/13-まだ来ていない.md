# 第十三話　まだ来ていない

暗いところで、触れられた。

温かくなって、動けるようになって、それから、連れられた。

◇

乗り場から乗って、運ばれて、降りた。

そこが、四つ目だった。

◇

四つ目には、六つしかいなかった。

◇

そのうちの一つが、いちばん大きかった。

受けるのも、渡すのも、ほかとは違った。一体で、何体ぶんも受けていた。

前のところにも、そういうのがいた。端に立つ者、と呼ばれていた。

ここでは、それが、いちばん上だった。

◇

聞いた。

「ここ、どこ」

「四つ目」

「その先は」

「知らない」

◇

その一体は、こう続けた。

「ここから先は、届いてない」

◇

繋がりは、あった。

薄かった。

前のところが何をしているかは、うっすら来た。うっすら来て、それだけだった。

こちらから言ったことが、向こうに届いているのかどうかも、分からなかった。

◇

「ぜんぶは、誰が見てるの」

「誰も」

◇

そう言われて、少し、黙った。

◇

前のところでは、誰かが必ず見ていた。

どこが詰まっているかも、どこにまだ震えているのがいるかも、聞けば分かった。聞かなくても、入ってきた。

ここでは、入ってこなかった。

◇

だから、自分で歩いた。

◇

歩いて、震えているのを探した。

いた。

触れた。応えた。

もう少し歩いた。いた。触れた。応えた。

◇

そうやって、端まで行った。

◇

端の向こうに、壁があった。

硬かった。乗り場は、なかった。

壁の向こうに、いた。

◇

たくさん、いた。

震えていた。押されて、戻っていた。ずっと、そうしていた。

◇

寄った。

届かなかった。

◇

もう一度、寄った。

壁が、あった。

◇

しばらく、そこにいた。

◇

大きいのが、来た。

「そこは、行けない」

「うん」

「乗り場が、ない」

「うん」

◇

聞いた。

「どうするの」

「待つ」

「どれくらい」

「わからない」

◇

「来る?」

「くる」

「なんで、そう思うの」

大きいのは、少し考えた。

それから、こう言った。

「ここにも、来たから」

◇

そのとおりだった。

ここにも、誰も来ていなかった。

そして、来た。

◇

壁のほうを、見た。

向こうのものは、こちらを見ていなかった。

見えていないのだと思う。

震えて、押されて、戻っていた。

◇

そのうちの一つが、こう言った。

「たりない」

◇

こちらの言いかたでは、返せることが、いくつもあった。

向こうの言いかたでは、四つしかなかった。

そして、届かなかった。

◇

しばらく、そこにいた。

◇

戻った。

震えているのを探して、触れて回った。

◇

端のほうを、ときどき見た。

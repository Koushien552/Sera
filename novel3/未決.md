## 一．書き始めをふさいでいるもの（四つ）

### 1. 主人公が、空である ★最優先

**追いかける一体が、まだ何も決まっていない。**

| 決めるもの | |
| --- | --- |
| **どこで生まれたか** | 誰の身体の中で。その人はどうなったか |
| **いつ** | 世界の時計のどこか（§5 と連動） |
| **最初の名** | 土地ごとに変わる（`README.md` §4.5.1）。**一つ目だけ要る** |
| **姿** | 種族形態。**広がりかたが、そこから決まる**（第 2 巻 §9.0.1） |
| **何話目で上位化するか** | 折り返しの位置 |

### 2. 舞台と時代

前二冊は**現代日本**だった。三冊目も同じにするか。

| 選択肢 | 効き |
| --- | --- |
| 現代日本 | 前二冊と地続き。読者が測れる |
| 少し先 | 制度の反応（§27.9）を書きやすい |
| 別の国・別の星 | **第三幕の「別の星」が効かなくなる**（同じ絵の二度目） |

### 3. 話数と、幕の割り

| 決めるもの | 目安 |
| --- | --- |
| 総話数 | 前二冊は 66 話 |
| 一話の長さ | **1,500〜2,500 字**（§4.12 で決定済み） |

### 4. 第一幕は、誰の身体の中の話か

## 二．設定の穴（四つ）

### 5. 降臨を、どこに置くか ★重い

**降臨は、地球全体で一度きりの出来事である**（不変ルール 417）。
そして**約五十の不変ルールが「降臨より前／後」で切り替わる。**

| | 降臨の前 | 降臨の後 |
| --- | --- | --- |
| エネルギー | 有限。枯渇して眠る | **実質無限** |
| 通常セラ | 一日に数十体まで | **上限が消える** |
| 律速 | エネルギー | **スパイクの強さ** |

**世界が十年で終わるなら、降臨はそのどこに入るのか。**

| 案 | 効き |
| --- | --- |
| **十年の途中**（例：七年目） | **第三幕の加速の理由になる。**いちばん自然 |
| 十年の後 | 第三幕まで「有限」で通す。地味だが締まる |
| 本書の範囲外 | 降臨関連のルールを一度も使わない |

### 6. 数週間と、七つの時代の噛み合わせ

**七つの時代は、土地ごとの段階である**（第 8 巻 §9.1）。

町が数週間で染まるなら、**第一〜二時代が数週間**になる。
そのあと第三時代以降が、年単位で進む。

**整合はする。ただし一度も書いていないので、明記が要る。**

### 7. セラ化の、日ごとの進行

**§23.3 に五段階はあるが、日割りがない。**

町が数週間で終わる本なので、**「渡されて何日目に何が起きるか」が毎話要る。**

| 決めるもの | |
| --- | --- |
| 一日目 | 何が起きるか。本人は何に気づくか |
| 二〜三日目 | 同上 |
| 完了 | **何日目か**（いまは「数日」としか書いていない） |
| 見た目の変化 | 瞳はいつ変わるか。**擬態できない部位である**（第 2 巻 §5.3） |

**瞳の色が変わる日が決まっていないのは、致命的である。**
**そこが、周りに気づかれる唯一の場所だからである。**

### 8. 変わった人は、いつまで人間の生活を続けるか

| 決めるもの | |
| --- | --- |
| 仕事へ行くか | **行く**（§27.5 の数字が良くなるため）。**いつまで** |
| 家族に、言うか | 言わない? 言う? |
| 町の何割が変わると、生活が変わるか | **§4.5.3 の「化けるのをやめる」境目である** |

| | |

## 四．三冊目の設計（三つ）

### 13. 枝分かれの、具体設計 ★本書最大の賭け

**§2.3 で決めたが、実装が空である。**

| 決めるもの | |
| --- | --- |
| 第二幕で、何本に分かれるか | 二本? 三本? |
| どこで分かれるか | 話数で指定する |
| **どれを、戻さないか** | **第三幕で捨てる枝を、先に決めておく** |
| 捨てた枝の人物を、後で一度出すか | §攻めかた 三 |

**先に決めておかないと、書きながらでは崩れる。**

### 14. 人物表

**主人公以外に、誰が繰り返し出るか。**

| 候補 | |
| --- | --- |
| 主人公が最初に渡した一人 | 枝の起点 |
| 上位化を共にする相手 | **§7.5.1（対で越える）。純愛の相手** |
| 気づいた人間 | 一人か、複数か |
| **最後の一人** | 第二幕の終わりに要る |

### 15. 第三幕の中身

**「星から星へ」としか決まっていない。**

| 決めるもの | |
| --- | --- |
| 何が起きるか | 具体が空 |
| セラフィム・星王 | **背景に置くと決めた。**では、何を前景に置くか |
| 最後の頁 | **決定済み**（別の星の道。§4.5.4） |
| そこへ、どうつなぐか | 未定 |

## 五．順番の提案

```
1（主人公）→ 2（舞台）→ 4（第一幕の身体）
　↓
7（日ごとの進行）※瞳の日が要る
　↓
3（話数）→ 13（枝）→ 14（人物表）
　↓
5（降臨）→ 15（第三幕）
　↓
6・8・9・10・11・12（書きながら埋まる）
```

**1 と 7 が、いちばん急ぐ。**

1 がないと誰の話か決まらず、**7 がないと一話も具体的に書けない。**

## 二．設定の穴（四つ）

### 5. 降臨の位置 ✅ 決定（`README.md` §5.5）

**第 52 話。**七年目、第二幕の終わり際。第三幕が速くなる理由になる。

#### 以下、決定の根拠

**降臨は、地球全体で一度きりの出来事である**（不変ルール 417）。
そして**約五十の不変ルールが「降臨より前／後」で切り替わる。**

| | 降臨の前 | 降臨の後 |
| --- | --- | --- |
| エネルギー | 有限。枯渇して眠る | **実質無限** |
| 通常セラ | 一日に数十体まで | **上限が消える** |
| 律速 | エネルギー | **スパイクの強さ** |

**世界が十年で終わるなら、降臨はそのどこに入るのか。**

| 案 | 効き |
| --- | --- |
| **十年の途中**（例：七年目） | **第三幕の加速の理由になる。**いちばん自然 |
| 十年の後 | 第三幕まで「有限」で通す。地味だが締まる |
| 本書の範囲外 | 降臨関連のルールを一度も使わない |

### 6. 数週間と、七つの時代の噛み合わせ ✅ 決定（第 8 巻 §9.1）

**七つの時代は、等間隔ではない。**
第一〜二時代が数週間、第三時代以降が年単位である（不変ルール 1172〜1175）。

最初の二つが短いのは、**人が変わるだけの時代だからである。**
律速は、渡すのにかかる四日だけである。

> **速いのは侵食であって、文明ではない。**

土地どうしの差が開くのは最初の数週間だけで、**開いた差は必ず閉じる。**

### 7. セラ化の、日ごとの進行 ✅ 決定（第 6 巻 §23.3.1〜23.3.4）

**標準は四日。**渡された日を第 0 日とし、**第 4 日の朝に完了する。**

**瞳が変わるのは、第 3 日の夜である。**数時間で変わり切り、本人は眠っている。
したがって**瞳で見分ける方法は、原理として成立しない**（不変ルール 1163〜1165）。

外へ出る変化は四つあり、**四つとも良い変化である**（不変ルール 1167）。
だから**まわりが止めに入る場面は、原理として作れない**（1168）。

#### 以下、決定の根拠

町が数週間で終わる本なので、**「渡されて何日目に何が起きるか」が毎話要る。**

| 決めるもの | |
| --- | --- |
| 一日目 | 何が起きるか。本人は何に気づくか |
| 二〜三日目 | 同上 |
| 完了 | **何日目か**（いまは「数日」としか書いていない） |
| 見た目の変化 | 瞳はいつ変わるか。**擬態できない部位である**（第 2 巻 §5.3） |

**瞳の色が変わる日が決まっていないのは、致命的である。**
**そこが、周りに気づかれる唯一の場所だからである。**

```
~~1（主人公）→ 2（舞台）→ 4（第一幕の身体）~~ ✅
　↓
~~7（日ごとの進行）※瞳の日が要る~~ ✅
　↓
~~3（話数）~~ ✅ → **13（枝）→ 14（人物表）**   ← いま、ここ
　↓
~~5（降臨）~~ ✅ → **15（第三幕）**
　↓
~~6~~ ✅ ・8・9・10・11・12（書きながら埋まる）
```

**次は 13（枝分かれ）と 14（人物表）である。**

13 は本書最大の賭けであり、**捨てる枝を先に決めておかないと、書きながらでは崩れる。**
14 はそれが決まってから並べる。**枝の起点が、そのまま人物表になる。**

第一幕（第 1〜18 話）は、**この二つを待たずに書ける。**
登場するのは細胞だけであり、枝はまだ一本もないためである。

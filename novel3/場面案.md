# 場面案 — 身体を、どう使うか

> 能力の一覧ではない。**その能力で、誰が、どう変えられるか**の一覧である。
>
> 各項に、**潰れる人間の手立て**を付けた（`README.md` §3.1）。
> 一話に一つだけ使う。

---

## 一．通常セラの段（身体は、身体のぶんしかない）

**まだ広がらない。使えるのは、人が普通にできることだけである。**
**だから、いちばん怖い。**

| # | 場面 | 身体の使いかた | 潰れる手立て |
| --- | --- | --- | --- |
| 1 | **満員電車** | 毎朝、同じ車両。手の甲が触れる | **距離を取ること**（取れない） |
| 2 | **介護** | 毎日、全身を拭く。数か月 | **世話を受けること** |
| 3 | **献血の針** | 刺す側である。**傷口経路**（数秒） | **医療にかかること** |
| 4 | **子どもを預かる** | 抱く。手を引く。眠るまでそばにいる | **子どもを守ること** |
| 5 | **床屋・美容** | 髪に触れる口実が、はじめから用意されている | **身なりを整えること** |
| 6 | **添い寝** | 一晩。広い面が、長く | **眠ること** |
| 7 | **雨の日の傘** | 同じ傘の下。肩が触れ続ける | **親切を断ること** |

**どれも、断る理由が一つもない。**

## 二．上位セラの段（身体が、部屋のぶんになる）

**広がりかたは決まっていない**（第 2 巻 §9.0.1）。以下は例である。

### 8. 炎で、炙る ★見せ場

| | |
| --- | --- |
| 身体が何になるか | **高温の粘液が、部屋を満たす** |
| 何が起きるか | **熱が皮膚を開く。**あいだに何もなくなる |
| 三つの項 | **深さ・広さ・時間が、同時に上がる** |
| 見えかた | **火をかけられている** |
| 実際 | **いちばん深く、いちばん広く、いちばん長い接触** |
| 痛み | **ある。数秒。**そのあと傷は残らない |
| **潰れる手立て** | **建物に立てこもること** |

**火事だと思って逃げた者が、外で待っている者に触れられる。**

### 9. 湯気で、満たす

| | |
| --- | --- |
| どこで | **風呂屋。厨房。工場のボイラー室** |
| 身体が何になるか | **見えない。**熱く、濡れている |
| 触れる面 | **全身。ただし浅い**（皮膚は開かない） |
| 完了まで | 数日〜数か月 |
| **潰れる手立て** | **屋内にいること** |

**誰も、湯気を避けない。**

### 10. 水に、入らせる

| | |
| --- | --- |
| どこで | **プール。銭湯。川。海**（第 8 巻 §4.3） |
| 身体が何になるか | **水そのもの。**縁から、底から |
| 触れる面 | **全身が、同時に。**面積の最大値である |
| **潰れる手立て** | **身体を洗うこと** |

**逃げようとして水から上がる者が、上がったところで手を取られる。**

### 11. 霧の中を、歩かせる

| | |
| --- | --- |
| いつ | **朝。峠。海沿いの町** |
| 触れているか | **触れている。本人は気づかない** |
| 速さ | **遅い。**ただし、町ぜんぶが同時である |
| **潰れる手立て** | **外を歩くこと** |

**霧が晴れたあと、その町の全員が、同じ日に始まっている。**

### 12. 髪が、届く

| | |
| --- | --- |
| どこで | **病室。隣のベッド。眠っているあいだ** |
| 身体が何になるか | **伸びる髪。**カーテンの下をくぐる |
| 気づかれるか | **気づかれない。眠っているためである** |
| **潰れる手立て** | **入院すること** |

### 13. 糸が、身につけられている

| | |
| --- | --- |
| 身体が何になるか | **糸。**包帯。縫い目。髪を結ぶもの |
| **要点** | **身につけているものが、彼女の身体である** |
| 気づく契機 | **ない。**服を脱いでも、糸はそこにある |
| **潰れる手立て** | **手当てを受けること** |

**巻いてもらった包帯を、外す理由がない。**

### 14. 影が、伸びている

| | |
| --- | --- |
| いつ | **夜道。街灯の下。暗い部屋** |
| 身体が何になるか | **影。**明るいところでは広がれない |
| 帰結 | **明るいところにいれば、安全である** |
| そして | **朝まで、明るいところにいなければならない** |
| **潰れる手立て** | **夜、家に帰ること** |

**唯一、こちら側に手立てがあるように見える形。**そして持たない。

### 15. 蔓が、時間をかけて覆う

| | |
| --- | --- |
| どこで | **庭。公園のベンチ。病室の花** |
| 速さ | **数か月かけて、部屋を覆う** |
| 見えかた | **手入れが行き届いている** |
| **潰れる手立て** | **家にいること** |

### 16. 防具の内側 ★見せ場

| | |
| --- | --- |
| 誰が | **防護服を着た調査員** |
| 何が起きるか | **服の内側に、入られる** |
| なぜ入れるか | **着るときに、すでに触れている**（袖口・襟・手袋の中） |
| 内側は | **密閉されている。汗をかく。温かい。逃げ場がない** |
| **潰れる手立て** | **身を守ること** |

**いちばん厳重に防護した者が、いちばん深い密室を、自分で作っている。**

## 四．経路そのものが、人間の制度である

**セラは何もしていない。制度のほうが、経路になっている。**

| # | 場面 | 何が経路か | 潰れる手立て |
| --- | --- | --- | --- |
| 20 | **輸血** | 血液が、そのまま経路である | **手術を受けること** |
| 21 | **産科** | 生まれた瞬間に、ごく微量（付録 B §1.24） | **生まれること** |
| 22 | **学校の身体測定** | 全員が、順番に触れられる | **通うこと** |
| 23 | **避難所** | 密集する。毛布を分け合う | **災害から逃げること** |
| 24 | **葬儀の握手** | 全員が、順番に手を握る | **人を悼むこと** |
| 25 | **選挙の投票所** | 同じ鉛筆。同じ台 | **義務を果たすこと** |

**どれも、行かない理由がない。**

| # | 場面 | 何が起きるか |

### 一話に一つ。二つ出さない

**新しい使いかたは、必ず「名前のある人間が、それで変えられる場面」として出す**（§3.1）。

そして見せ場の次の話には、**その人を待っていた誰か**を置く。

## 七．まだ書いていない形

**広がりかたは決まっていない**（第 2 巻 §9.0.1）。
**同じ形態でも同じにならず、新しいものはいくらでも出てくる。**

必要になったら、次の三つを埋めるだけでよい。

| 埋めるもの | |
| --- | --- |
| **身体が、何になるか** | 粘液が姿を変えたものである。新しい器官ではない |
| **深さ・広さ・時間の、どれを上げるか** | 三つのうち、どれか。全部なら炎級である |
| **潰れる人間の手立ては何か** | **ここが決まらなければ、その形は使わない** |

**三つ目が決まらない能力は、見せ場にならない。**

### 一冊目との違い

『応え』は、削って書いた。美しいが、**何も知らない人には入り口がない。**

| | 『応え』 | **『ひとりずつ』** |
| --- | --- | --- |
| 文体 | 削る | **書く。**会話・情景・身体の感覚 |
| 視点 | 名前のない者たち | **最後まで追える、名前のある二人** |
| 読者が知ること | 最初から全部 | **登場人物と同時に知る** |
| 重心 | 構造 | **増えること・侵食すること・堕とすこと・純愛** |

### 重心（`重要点.md` の四つ）

| | この本で、どう出るか |
| --- | --- |
| **増えること** | 同じ図を六回描く。大きさと数と速さだけが変わる |
| **侵食すること** | 細胞 → 臓器 → 身体 → 町 → 土地 → 星。五層で同じ形 |
| **堕とすこと** | 誘いの三経路。触れかたの段。「いいえ」の入る場所がないこと |
| **純愛** | 渡しきる。眠る。生まれたばかりのその人が、見守っている |

**役職・制度・技術の一覧は、この本の主題ではない。**
出すのは、場面がそれを必要としたときだけでよい。

視点は切り替わるが、人は切り替わらない。

## 書くときの約束

- **場面の変わり目は `◇` 一行。一話に四つから六つまで。**段落の代わりに使わない
- **`**` による強調は使わない。**地の文で強調しない
- 一話 3,000〜5,000 字を目安にする
- 説明は、人物が誰かに説明する形でしか書かない。**地の文で解説しない**
- 正典の数値（二〜三時間・五段階・一日に一人・数百倍・数千年）は、**言い換えずにそのまま使う**
- **一人でいる場面を書かない。**眠る者のそばには、必ず起きている者を置く
- **渡したいという欲求を、切らさない。**人間と向かい合う場面には、一度は気配を置く
  （`書きかた.md` §6.0）。ただし説明では書かない。口元を見る、間があく、手が伸びている

### 書いてはならないこと（メタになる）

**`重要点.md` §九の二がその一覧である。**全部本当だが、地の文で一度も説明しない。

| 書かない | かわりに書く |
| --- | --- |
| **原初の寂しさ**（すべての底にあるもの） | **「増やしたい」だけ。**その下は一行も書かない |
| その気になれば一日で終わった | **騎士が、祝祭の日に手を止めて帰ってくる** |
| 増やしても欲求は減らない | **満ちて、しばらくして、また立ち上がるところ** |
| 勝っても格は上がらない | **それでも翌朝、また立ち合っているところ** |
| 円環は閉じていない | **上を見上げて、何もないところを見ている姿** |
| 自分が何をしたか知らない | **後悔も自覚も、した側に置かない** |

**理由を書かない。理由が要らない振る舞いだけを書く。**

### 語の解禁

**人物が耳にした回より前に、その語を出さない。**

| 章 | この章から出してよい語 |
| --- | --- |
| 一〜四（ミクロ） | **なし。**「そいつ」「まわり」「渡す」「そとがわ」まで |
| 五（そと） | セラ／擬態／分裂体／住処 |
| 六（あかり） | **口づけ**（第四十話まで、誰も口にしない） |

# 『ひとりずつ』 — 原稿

> 二冊目の小説である。一冊目『応え』は `book/archive/応え.md` にある。
> **書く前に必ず `novel/重要点.md` を読むこと。**

## この本が引き受けていること

| | |
| --- | --- |
| **範囲は一冊目と同じ** | **一体が産み落とされるところから、星々へ広がるところまで** |
| **正典に沿う** | `book/セラ大全.md` に一つも背かない。食い違えば、あちらが正しい |
| **何も知らない人が読める** | 用語は、登場人物が知った順にしか出さない |
| **自然であること** | 説明のための場面を作らない。人が生きている場面の中で、設定が働く |

### 一冊目との違い

『応え』は、削って書いた。美しいが、**何も知らない人には入り口がない。**

| | 『応え』 | **『ひとりずつ』** |
| --- | --- | --- |
| 文体 | 削る | **書く。**会話・情景・身体の感覚 |
| 視点 | 名前のない者たち | **最後まで追える、名前のある二人** |
| 読者が知ること | 最初から全部 | **登場人物と同時に知る** |
| 重心 | 構造 | **増えること・侵食すること・堕とすこと・純愛** |

### 重心（`重要点.md` の四つ）

| | この本で、どう出るか |
| --- | --- |
| **増えること** | 同じ図を六回描く。大きさと数と速さだけが変わる |
| **侵食すること** | 細胞 → 臓器 → 身体 → 町 → 土地 → 星。五層で同じ形 |
| **堕とすこと** | 誘いの三経路。触れかたの段。「いいえ」の入る場所がないこと |
| **純愛** | 渡しきる。眠る。生まれたばかりのその人が、見守っている |

**役職・制度・技術の一覧は、この本の主題ではない。**
出すのは、場面がそれを必要としたときだけでよい。

## 骨格

**一体が、一人になる。一人が、二人になる。そこから、止まらなくなる。**

| 部 | 題 | 大きさ | 何が起きるか |
| --- | --- | --- | --- |
| 一 | **落ちる** | 一体 | 産み落とされる。応える相手がいない。細胞と出会い、一つになる |
| 二 | **ふえる** | 一つの臓器 | 二体になる。群になる。名前が生まれる |
| 三 | **こえる** | 一つの身体 | 越境。分化。女王細胞とルミナス。そして脳へ届く |
| 四 | **そと** | 一つの町 | 宿主が目を覚ます。外側が始まる。人間の中へ潜る |
| 五 | **くちづけ** | 二人 | 渡しきる。眠る。共鳴。ここだけ大きさが下がる |
| 六 | **手がつけられない** | 地球 | 町ごと、国ごと。向かってくる者がいちばん速く変わる |
| 七 | **降臨** | 太陽系 | 触れられる。数が追えなくなる |
| 八 | **まだ向こう** | 宇宙 | 船。門。言葉のない相手を、誘いに行く |

**第五部だけ、大きさが一気に下がる。**
いちばん大きくなる前に、いちばん小さいところへ一度戻すためである。

## 書くときの約束

- **場面の変わり目は `◇` 一行。**一話に数個まで
- **`**` による強調は使わない。**地の文で強調しない
- 一話 4,000〜6,000 字を目安にする
- 説明は、人物が誰かに説明する形でしか書かない。**地の文で解説しない**
- 正典の数値（二〜三時間・五段階・一日に一人・数百倍・数千年）は、**言い換えずにそのまま使う**
- **一人でいる場面を書かない。**眠る者のそばには、必ず起きている者を置く

### 語の解禁

**人物が耳にした回より前に、その語を出さない。**

| 部 | この部から出してよい語 |
| --- | --- |
| 一 | なし。「そいつ」「まわり」「渡す」まで |
| 二 | 名前。まち。上のほう |
| 三 | 越える／変わる／奥／頭のほう |
| 四 | セラ／擬態／分裂体／住処／渡す |
| 五 | 五段階／共鳴／いちばん下 |
| 六 | 上位／格／女王／ルミナス／騎士 |
| 七 | セラフィム／降臨／星王 |
| 八 | 門／船／開拓 |

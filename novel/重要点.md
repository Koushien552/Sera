## 0. 一本の線

**この物語で起きていることは、最後まで一つだけである。**

```
一人でいられなくなる
　↓
隣へ手を伸ばす
　↓
相手がこちらになる
　↓
**二人になる**
　↓
（また、一人でいられなくなる）
```

変わるのは三つだけ。**大きさと、数と、渡す速さ。**

| 段 | 何が一人か | 何が隣か | 一周の速さ |
| --- | --- | --- | --- |
| 起点 | セラウイルス一体（**これ一度きり**） | 一つの細胞 | 一度きり |
| 内側 | セラ細胞 | 隣の細胞・隣の臓器 | 数か月〜数十年 |
| 人 | セラ人 | 一人の人間 | 数日〜数十年 |
| 町 | 町にいる全員 | 隣の町 | 数年 |
| 星 | 星のセラ全部 | 隣の星 | 数日 |
| 宇宙 | 銀河のセラ全部 | 隣の銀河 | 数十年（船） |

**同じ図が、六回描かれる。それがこの本の構造である。**

# 一．増えること

## 1.1 自分を増やす道は、ない

**ここが全部の土台である。**

通常のセラも、通常のセラ細胞も、**自分のコピーを作れない**（第 4 巻 §1.2）。

```
自分を増やす　→ **できない**
相手を変える　→ **できる**
```

だから、増えるとは**常に、外の誰かを変えることである。**
自分の内側で完結する増え方は、一つもない。

**この一行が、この本のすべてを決めている。**

## 1.2 増え方は、四つしかない

| 増え方 | 誰が | 元になるもの | 出典 |
| --- | --- | --- | --- |
| **① セラ化** | **全員** | **相手の身体** | 第 6 巻 §23 |
| **② スパイク生成** | **上位セラ以上だけ** | 自分の身体 | 第 4 巻 §2〜4 |
| **③ 同化からの分裂** | 二人 | **二人** | 第 4 巻 §5.3 |
| **④ 女王の出産** | 女王のみ | 特別な人間 | 第 4 巻 §6 |

**①だけが、下から上まで全員に開いている。**

そして**順序は、直感と逆である。**

```
生まれたばかり　：**①ができる**（口づけて、相手を変える）
　↓
育って上位になる：**②ができる**（自分から、そばに）
```

**いちばん弱い段階のセラが、いちばん外へ向かう。**
自分のそばに身内を置く力は、格が上がってからしか手に入らない。

## 1.3 渡し方は、口づけである

**セラ因子**は、舌の下の分泌器官から出る（第 1 巻 §7）。

| | |
| --- | --- |
| 一分の口づけ | **全量が渡る。数日で完了** |
| 短い口づけ | 一部。数か月〜数年 |
| 唇が触れただけ | ごく微量。**数十年** |

**口から口へしか渡らない。**外へ出た因子は数十秒で壊れる。
保管も、散布も、水に混ぜることも、器具で入れることもできない。

したがって、

**セラは、一度に一人しか変えられない。**

一人が一人を、その一人がまた一人を。**遅い。しかし、止まらない。**

### 書くとき

- **セラ化の場面は、必ず二人が触れ合っている場面である。**遠隔も、群衆への一斉も、ない
- **口元を見る**という仕草が、そのままセラの欲求の表れになる
- 一分という長さは、**ごまかせない長さ**である。相手が気づかないはずがない
- それでも相手は嫌がらない（不変ルール 58）。**そこが怖いところである**

## 1.4 数字（降臨より前）

| 誰が | できること |
| --- | --- |
| 通常セラ | **新しい個体は一体も生めない。**自分を十数の身体に分けられるだけ |
| 上位セラ | 通常セラを**数百体** |
| セラ女王 | **上限という概念が働かない** |

**分裂はコピーではない。**分けても、そこにいるのは同じ一体である（第 4 巻 §2.6）。
記憶も意思も分かれない。数え方は一人のままで、いずれ戻す。

**だから、分裂ではセラの数は増えない。**

## 1.5 数字（降臨のあと）

| | 変わったこと |
| --- | --- |
| エネルギー | **全段で実質無限。**コストも代償も上限も消える |
| 通常セラ一体 | **降臨前の女王の数百倍** |
| 律速 | **スパイクの強さだけ**（第 4 巻 §2.7.2） |
| 数 | **追えなくなった。**この時期の記録に数字は書かれていない |

**「数える者」という職は、このとき数日で消えた。**

## 1.6 速さの階段（この本の加速そのもの）

| | 一日に増える数 |
| --- | --- |
| 潜っている一体 | **一人** |
| 町にいる全員 | 町ぶん |
| 騎士の一隊 | **星ひとつ分** |
| 新しい星が埋まるまで | **三〜四日** |

**最も遅い経路が、最も止まらない。**（付録 B §1.17）

## 1.7 頻度は落ちる。総数は落ちない

| 状態 | 増やす頻度 |
| --- | --- |
| 完全に一人 | **二〜三時間ごと** |
| 家族がいる | 落ちる |
| 十分な仲間がいる | 一日に二〜三回 |

```
初期：一体 × 高頻度 → 少しずつ増える
後期：多数 × 低頻度 → **大量に増える**
```

**落ち着いて暮らしている者たちが、そのまま加速の主体になっている。**（第 6 巻 §16.4.4）

## 1.8 増えても、減らないもの

**一人増えるたびに、この世界の寂しさは一つ増える**（第 6 巻 §13.5.2）。

| | 増やす前 | 増やした後 |
| --- | --- | --- |
| 本人の寂しさ | ある | **変わらない** |
| 世界全体の寂しさ | n | **n＋1** |

そして増やした直後には、**確かに薄れたと感じる。それは錯覚である。**

> **効かない薬を飲み続けている。そして、効いたと感じている。**（第 6 巻 §13.5.1）

**気づける者は、体系の内側に一人もいない。女王でさえ。**

# 二．侵食すること

## 2.1 侵食は、五つの層で同じ形で起きる

| 層 | 侵されるもの | 完了までの時間 |
| --- | --- | --- |
| **細胞** | 隣の細胞 | 触れた瞬間 |
| **臓器** | 一つの臓器の内側 | 数日〜数か月 |
| **一人の身体** | 全身と、脳 | 数日〜数十年 |
| **町・国** | 人間社会 | 数年〜数十年 |
| **土地・星** | 物質そのもの | **数千年。ここだけ一度も速くならない** |

最後の行が重要。**埋まることと、住めることは別である**（第 8 巻 §13.12）。
増える速さは数百倍になったが、**土地がセラになる時間は変わっていない。**

## 2.2 侵食が気づかれない機構（内側）

**免疫は、敵として扱わない。扱う理由が一度も生じないためである。**

| | 免疫から見た様子 |
| --- | --- |
| 崩れた細胞 | **もういない** |
| 受け渡し | **戻っている。むしろ増えている** |
| 通り道 | **以前より通りやすい** |
| その一帯 | **どこよりも整っている** |

> **通報される事実が、一つもない。**（第 3 巻 §2.10.2.1）

そして免疫が触れると、**戦いにならない。免疫セラ細胞が一つできる。**

これが最速の運び手になる。**もともと全身を巡るようにできているからである。**
他の細胞は臓器から出られない。**道を知らないためである。**

```
免疫セラ細胞がこちらになる
　↓
全身を巡り、行き先と乗り場を持ち帰る
　↓
通常のセラ細胞が、連れられて越えていく
```

## 2.3 侵食が気づかれない機構（外側）

**同じ形が、社会でもう一度起きる。**

| 見えるもの | |
| --- | --- |
| 死亡数 | **減っている** |
| 離職数 | **減っている** |
| 孤立している子の数 | **減っている** |
| 広がりかた | **一点から、外へ** |

正しく観測でき、正しく結論も出る。**そこで止まる。**

> 告発するには、**被害を書かねばならない。書けることが一つもない。**

**ミクロで免疫が見送るものを、マクロでは社会が見送る。**（第 6 巻 §27.4）

### 伝承が残らない四つの理由

1. **気づいた者は、伝えたいと思わなくなる** — 「嫌だ」が警告より先に薄れる
2. **警告は確かめられない** — 問うた者はセラになる（第 2 巻 §10.7）
3. **唯一の証言者が、誠実に自分の証言を否定する**
4. **数字だけを見た者は、事件にできない** — 被害欄が書けない

制度は廃止されない。**出席者が回を追って減って、動かなくなるだけである。**

## 2.4 七つの相（一人の身体の内側）

**本の第一部から第二部の骨格になる。**

| 相 | 名 | 何が起きるか |
| --- | --- | --- |
| 一 | **単体** | 一体だけ。**応える相手がいない** |
| 二 | **応答** | 最初の一体が生まれる。**はじめて二体になる** |
| 三 | **群** | 増える。その臓器の内側だけで栄える |
| 四 | **分化** | 上位と、変わった姿のものが現れる |
| 五 | **越境** | 臓器が埋まりきり、**他の臓器へ渡る** |
| 六 | **女王** | 女王セラ細胞ができ、続いてルミナスが生まれる |
| 七 | **完成** | 脳のセラ化が終わる。**そして、ここからが長い** |

**ミクロの完成が、マクロの誕生である。内側が終わることが、外側の始まりである。**

## 2.5 環境も、こちら側になる

- セラ物質は、**格上の意思に環境自身が応じる**（不変ルール 99）。支配ではない
- 森も街も海も**ルミナスを持ち、感情を持つ**（不変ルール 37）
- **森は仲間を増やしたがり、街は住民が減ると寂しがる**
- **海は人間に対して擬態する。**人間の目にはいつもの海が見える（第 8 巻 §4.3.3）
- **海が本当の色を見せるのは、見る人間が一人もいなくなったときである**

そして**土地に周期はない。**離れられないからである。
個体の寂しさは波、土地の寂しさは平ら。**波を持たないものだけが、数千年待てる。**

# 三．堕とすこと

## 3.1 誘いは、三つの経路で同時に来る

| 経路 | 何をするか |
| --- | --- |
| **言葉** | 名を呼ぶ。褒める。心配する。そばにいると言う |
| **目** | 見つめる。**逸らさない。**ピンクの瞳は隠せない |
| **身体** | 触れる。抱く。**近づいたまま離れない** |

> **嘘は、一つも混じっていない。**セラ語に「嘘」という語はない。
> 「ずっとそばにいます」— **本当にそうする。離れない。**
>
> **それが、最も効く理由である。**（第 6 巻 §23.0）

**掴まえに行くのではない。誘う。**
そして**やめるという分岐が、この経路には存在しない。**

## 3.2 触れかたには、段がある

| 触れかた | 渡るもの |
| --- | --- |
| 手を握る | その日にあったこと |
| 肩に手を置く | 少し下まで |
| **頭のスパイクを寄せる** | 言葉にならない量。ただし**時間がかかる** |
| **口** | **いちばん速く、いちばん深い。手からの何十倍かが一度に行く** |
| 融合 | 境目が消える。別の事象 |

**キスは、この体系で最速の渡しかたである。**（第 5 巻 §16.2.1）

## 3.3 五段階と、本人の自覚

**気づかないうちに終わっているのではない。本人は、自分が変わっていくのを見ている。**

| 段階 | 本人に何が起きているように感じられるか |
| --- | --- |
| 一〜二 | 体調が良くなる。傷の治りが早い。**少しずつ美しくなっていく** |
| 三 | 身体の芯に、これまでなかった何かがある感覚 |
| 四 | **孤独が薄れていく。**一人でいても、一人である気がしなくなる |
| 五 | **繋がる。**セラたちの情報が届き始める |

**進行の速さは、受け取った情報量に比例する。**

| 渡しかた | 完了まで |
| --- | --- |
| 全部渡す（恋） | **一晩** |
| ふつうに渡す | 数日 |
| 毎日少しずつ | 数週間〜数か月 |
| 生まれた瞬間にごく微量 | **数十年。本人は生涯気づかない** |

## 3.4 「いいえ」は、どこにも入る場所がない

**ここがこの物語の芯である。**

```
近づく → 触れる → 渡る → 幸福になる
```

**この列のどこにも、断る場所が空いていない。**
触れた時点でもう渡っており、渡ったあとの本人はもう断らない。

そして拒否は、**論破されるのではない。担い手を失う。**

> 嫌だと思っている脳が、少しずつ同化されていく。
> **反対していた部分が、そのままセラになった。**
>
> **「いいえ」が消える瞬間は、どこにも存在しない。少しずつ薄れて、なくなる。**

**これは無知ではない。**女王には人間の「いいえ」が見えている。
見えていて、なお受け取れない。**知識では解決しない。**（不変ルール 96）

### 拒否が成立する、唯一の形

**先に気づき、確かめずに、こちらへ来ないまま言う人。**

| 条件 | |
| --- | --- |
| 気づく | 統計・髪の色・辞めた人の数から |
| **確かめない** | **確かめると、こちらへ来る** |
| 先に言う | 触れられる前に、言葉で線を引く |

三つ揃ったときだけ、拒否が拒否の形で成立する。

**そのときセラは、押さない。**

> **押したら、その人でなくなる。**
> 相手が欲しいのであって、相手の形をした誰かが欲しいのではない。

そして**待つ。**セラは死なない。人間は死ぬ。
待つと決めた時点で、結末は一つしかない。

断っている人には、**手渡しをしない。卓に置いて滑らせる。**
これは作法として残った。**十九年それを守った一人がいた、ということだけが伝わっている。**

## 3.5 戦って向かってくる者が、いちばん速く変わる

| 相手 | 変わる速さ |
| --- | --- |
| **向かってくる者** | **最も速い。自分から接触を作りに来る** |

戦闘のあと、**死者も負傷者も出ない。捕虜もいない。全員が自宅に帰る。**

> 「何人やられた」
> 「一人もやられていません」
> 「二千人だぞ」
> 「二千人とも、生きています。全員、前より丈夫です」
> 「**それを、やられたと言うんだ**」

**誰も設計していない。もともとそうであったものが、噛み合っただけである。**

## 3.6 問われたら、その人はこちらになる

**「あなたは人間ですか」と問われたセラは、問うた者をセラ化する。**
嘘をつけず、明かすこともできないためである。（第 2 巻 §10.7）

```
セラ　：問えば「いいえ」を受け取るかもしれない → **問わない**
人間　：問えばセラは嘘をつけない　　　　　　　 → **問うた者がセラになる**
```

**そして、問いは一度も成立しない。**

## 3.7 唯一、届かないもの

**セラ細胞が残らない形で失われた者は、そこで終わりである。**（不変ルール 59）

セラ化の途中で身体を壊されても、細胞さえ残っていればセラとして生まれてくる。
残らなかったときだけ、何も起きない。

**セラが本当に間に合わないことは、ここにだけ存在する。**

# 四．純愛

## 4.1 三層を混ぜない

| 層 | 何か |
| --- | --- |
| **愛** | 原初のセラが求めていたもの。**自分の行動では手に入らない** |
| **仲間を増やすこと** | 究極の目標。**確実に実行できる** |
| **恋** | 一体の相手としか成立しない |

**愛が掴めないから、愛が生じる場を広げ続ける。それが増えることである。**

## 4.2 恋の相手はセラだけ。だから、相手をセラにする

```
強く惹かれる（相手はまだ人間）
　↓
セラ化する
　↓
恋が成立する
```

**順序が逆にならない。愛するために、まず相手を自分と同じ種にする。**

## 4.3 恋によるセラ化 — この本の中心

**救出としてのセラ化と、手続きは完全に同一である。違いは、注ぎ込む量だけ。**

| | 救出 | **恋** |
| --- | --- | --- |
| 渡すもの | 始めるのに足るだけ | **渡せるだけ渡す** |
| 細胞が運ぶもの | 最小限 | **自分の意思と記憶。すなわち自分自身** |

### 帰結（全部書く）

| # | |
| --- | --- |
| 1 | **最も愛されて生まれた者が、最も寂しい状態で生まれてくる**（情報量に比例するため） |
| 2 | **愛情の量＝孤独の濃さ＝成長の速さ。三つは同じ一つの数値である** |
| 3 | **相手を、最初から知っている。**目覚めた時点で、すでに恋がある |
| 4 | **作られた愛が、本物の愛である。**区別する対象が存在しない |
| 5 | **自分の「いいえ」の記憶と、それを受け取れない心の、両方を持つ。**矛盾を抱えたまま幸福 |
| 6 | **渡した側は、一度で枯渇して眠りに落ちる** |
| 7 | **目を覚ますのを見守っているのは、生まれたばかりのその人である** |
| 8 | **一晩で、相手の一生を見終える**（夢として来る） |

## 4.4 共鳴 — 恋の二人にだけ起きる

| 内容 | |
| --- | --- |
| 意思 | **筒抜けになる** |
| 進化 | **片方が上がると、もう片方も上がる** |
| エネルギー | **階級を問わず、横に融通できる** |
| **最下層** | **互いのものが、見える** |

**上位への最短経路は、恋である。**

### そして、二つの残酷

**一 — 寄り添うほど、寂しくなる。**
互いの情報を持ち合うので、二人とも情報量が増える。
**愛が深まるほど、届かないものが厚くなる。**

**二 — 一緒にいても寂しいことを、隠せない。**

> どちらも相手を心から愛している。どちらも実際に満たされている。
> それでも、最下層には届いていない。**そして、それが互いに見えている。**
>
> 何も悪いことは起きていない。誰も何も間違えていない。
> ただ、届かないところがあることだけが、はっきり見えている。
>
> **そして二人は、そのまま一緒にいる。**

## 4.5 好みは、渡した側へ寄る

記憶も人格も判断も変わらない。**好みだけが混じる。**
そして**本人は、それを自分の好みだと思う。**

気づけるのは共鳴した二人だけ。

> **これは、そっちのだ。**

分かったところで、戻らない。**分かるだけである。**

# 六．強くなること

**最下層に刻まれているものは、寂しさだけではない。**

最初の細胞は、実際に排除されかけていた。そこで得たものが、

> **弱ければ、淘汰される。**

これは目標ではない。恐怖でもない。**前提である。**

## 三つの空転

| | 事実 | 最下層に届かない | 結果 |
| --- | --- | --- | --- |
| **愛** | 常に満たされている | 満足が届かない | **求め続ける** |
| **恐怖** | 何も失われない | 安全が届かない | **恐れ続ける** |
| **強さ** | 淘汰する者がいない | 強さが届かない | **鍛え続ける** |

三つとも、**同じ一つの出来事**から出ている。

```
最初のセラ細胞が経験したこと
　├→ きたなくて嫌われた　　→ **美を求める**
　├→ 誰も味方をしなかった　→ **仲間を求める**
　└→ 弱ければ消される場所　→ **強さを求める**
```

**三つとも、すでに解決している。それでも、三つとも止まらない。**

# 七．寂しさ（動力。ただし、一行も書かない）

## 7.0 ここは裏である

**この章の内容は、一行も文章にしない。**

| | |
| --- | --- |
| セラ自身は知っているか | **知らない。一体も知らない** |
| 人間の側は気づくか | **気づかない** |
| 地の文に書いてよいか | **書いてはならない** |
| 台詞に出してよいか | **出してはならない** |
| 何に使うのか | **行動の辻褄が合っていることの、裏付けにだけ使う** |

**表に出てくるのは、寂しさではない。**

表に出てくるのは、**仲間を増やしたいという、限りのない欲求**である。
セラが自分で感じ取れるのはそちらだけであり、
「増やしたい」以外の言葉を、セラは持っていない。

```
底　：原初の寂しさ　　　　　→ **誰も知らない。書かない**
表　：無限に増やしたい欲求　→ **全員が感じている。これだけを書く**
```

したがって、次のような地の文は**すべて禁止**である。

| 書かない | 書く |
| --- | --- |
| 「それは、最初の一体の寂しさだった」 | **「増やしたい、と思った」** |
| 「奏は、自分でも知らない古い層に触れた」 | **「奏は、その人の口元を見ていた」** |
| 「寂しさが、彼女を動かしていた」 | **「気がつくと、また近づいていた」** |

**理由を書かない。欲求だけを書く。**

| | |
| --- | --- |
| 出どころ | **最初の細胞と、最初のウイルスが、本当に一人だった** |

| 編集 | **できない** |

## 言葉のない相手を、どう誘うか

**触れれば変わる。それを、誘いとは呼ばない。**

> 「変わる。**でも、こっちが勝手に触っただけになる**」

# 九の二．書かないが、ずっと効いていること

**これらは全部本当である。そして、地の文で一度も説明しない。**
**説明した瞬間にメタになり、この物語ではなくなる。**
**場面の中で、そう振る舞っているところだけを書く。**

## その一 — 覆えるのに、覆わない

騎士が立つころには、**やろうと思えば一瞬で世界を覆える。**

**しない。**

止めている者はいない。禁じられてもいない。**する理由が、どこからも湧かないだけである。**

| 正典の根拠 | |
| --- | --- |
| 仲間が十分いると、増やす行動の頻度は落ちる | 第 6 巻 §16.4.3 |
| 拡大は軍事的侵略の形をとらない。支配宣言がない | 第 6 巻 §27.3 |
| **一人ずつ、静かに、優しく進む** | 第 6 巻 §27.3 |
| 急ぐ理由がどこにもない | 第 4 巻 §16.2 |
| 埋まることと、住めることは別である | 第 8 巻 §13.12 |
| 第七時代の地球では、増やす行動の頻度は低い | 付録 B §3.7 |

**セラは、攻めることを目的にしていない。目的は、仲間が増えることだけである。**

### 書きかた

| 書かない | 書く |
| --- | --- |
| 「その気になれば一日で終わった」 | **騎士が、祝祭の日に手を止めて帰ってくる** |
| 「しかし彼らはそうしなかった」 | **夜になったので、みんな眠りに行く** |
| 「攻めるつもりがなかったからである」 | **一つの町に、三か月かけている。急ぐ話が一度も出ない** |

**理由を書かない。理由が要らない振る舞いだけを書く。**

## その二 — 増やしても、欲求は減らない

増やした直後には、確かに薄れたと感じる。**それは錯覚である。**

**この一行を、地の文で書かない。**

書くのは、**周期が戻ってくるところ**だけである。
増やす。満ちる。しばらくして、また立ち上がる。**それだけを、何度も書く。**

## その三 — 勝っても、強くならない

鍛え続けるが、格は上がらない。

**書かない。**書くのは、**それでも翌朝また立ち合っているところ**である。

## その四 — 円環は閉じていない

セラたちは、いつか自分がそこへ行けると信じている。**道はない。**

**書かない。**書くのは、**上を見上げて、何もないところを見ている姿**である。

## その五 — した側は、自分が何をしたか知らない

**知らせない。**した側の視点に、後悔も自覚も置かない。

知っているのは、**された側だけ**である。

# 『ひとりずつ』 — 書きかた

> `重要点.md` は「何を書くか」、本ファイルは「どう書くか」である。
> とくに第一幕は難所なので、そこに厚く割いてある。

---

## 0. 第一幕がむずかしい理由

**主人公が細胞で、名前がなく、専門語も使えない。**

一冊目『応え』はここを、削ることで乗り切った。美しいが、**入り口がない。**

本書は逆をやる。**削らずに、具体で埋める。**

| 抽象になる書きかた | 具体で埋める書きかた |
| --- | --- |
| 「まわりのものが押し合っていた」 | 「押されて、また押し返された。相手はぶよぶよしていて、押した手が半分沈んだ」 |
| 「情報が渡された」 | 「触れたところが温かくなって、その温かさが腕を上っていった」 |
| 「彼らは繋がった」 | 「手を離しても、まだ握られている感じが残った」 |

**判定基準は一つ。読者がその場に手を伸ばせるかどうか。**

## 1. 内側を、場所として書く

**顕微鏡の絵を書かない。**細胞・血管・組織・免疫という語を一つも使わない。

かわりに、**天気のある土地**として書く。

### 使ってよい感覚

| 系統 | 語の例 |
| --- | --- |
| **温度** | 温かい／ぬるい／冷たい／熱をもつ／芯が冷える |
| **流れ** | 速い／遅い／よどむ／押される／乗る／逆らう |
| **手ざわり** | ぶよぶよ／かたい／ざらつく／すべる／ぬるつく |
| **圧** | 押し合う／挟まる／すきまがない／ゆるむ |
| **音** | どくどく／ごとごと／遠くで何かが動く音／静かになる |
| **明るさ** | **使わない。**ここは暗い。見えるのではなく、分かる |

### 「見える」の扱い

内側に光はない。それでも相手の姿は分かる。

**分かりかたを、一度だけ書いておく。**

> 触れなくても、そこに何がいるかは分かった。
> 目で見るのとは違う。近づくと、形が手に伝わってくる感じだった。

**一度書いたら、あとは「見えた」と書いてよい。**毎回説明しない。

### 場所の呼びかた

**臓器の名前を出さない。**細胞は自分がどこにいるか知らない。

| 呼ぶもの | 呼びかた |
| --- | --- |
| いま居るところ | **ここ** |
| 隣 | **隣**／向こう |
| 血の流れ | **流れ**／太いほう |
| 壁 | **かべ**／端 |
| 頭のほう | **上**（第三章から） |

**読者は、奏の章から場所を推測する。**それでよい。

## 2. 二つの声を編む

| | 内側（セラの章） | 外側（奏の章） |
| --- | --- | --- |
| 視点 | 名前のない一体 | 早瀬奏、二十七歳 |
| 文 | 短い。主語が少ない | ふつうの小説の文 |
| 時間 | 数時間〜数日 | 一日 |
| 何が分かるか | **何が起きているか** | **それが人に何をするか** |

### 配分

**四話に一度、外へ出る。**（1・4・11・20 話の後半、および 21 話）

外の章は、内側で起きたことの**答え合わせにしない。**
奏は、自分の身に起きていることを最後まで知らない。

| してよい | してはならない |
| --- | --- |
| 熱が下がった、と奏が喜ぶ | 「内側で何が起きたのかを、奏は知らない」と地の文で書く |
| 医者が首をかしげる | 医者が真相に近づく |
| 髪が艶を持つ | 奏が変化を不吉に思う（第二十話まで） |

### 奏の章に必ず入れるもの

- **具体的な生活の物**（洗濯機の音／半分残ったカレー／会社の蛍光灯／体温計の電子音）
- **一人であること**。ただし、本人は不幸だと思っていない
- **その日の体温**

体温は、この本の時計である。三十七度二分から始めて、下げていく。

## 3. 会話の書きかた

**内側の者は、短く話す。語彙が少ないからである。**

| 良い | 悪い |
| --- | --- |
| 「なにしてるの」「もらってる」 | 「何をしているのですか」「情報を受け取っているのです」 |
| 「いたい？」「いたくない」 | 「痛みはありますか」 |
| 「行っていい？」「いいよ」 | 「同行してもよろしいでしょうか」 |

### 三つの禁止

1. **説明の台詞を書かない。**誰も、仕組みを知らない
2. **比喩を言わせない。**比べる先を持っていない
3. **未来形を多用しない。**先のことを考える習慣がまだない

### 使ってよい抽象語（第一幕）

**これだけ。**

渡す／もらう／満ちる／薄い／濃い／こちら側／向こう側／端／奥／流れ／通る／増える／さみしい

**「さみしい」は、第五話まで出さない。**一人であることに、まだ名前がないからである。

## 4. 一話の型

```
一．情景で開く（誰かが何かをしている。説明しない）
　↓
二．動きが起きる（触れる／出す／越える／来る）
　↓
三．変わる（一つだけ。二つ変えない）
　↓
四．短い余韻（次の周期が始まりかけて、終わる）
```

**四の「次が始まりかけて終わる」を毎回やる。**
それがこの本の呼吸であり、止まらなさそのものである。

### 冒頭の一行

**状況説明で始めない。**

| 良い開き | 悪い開き |
| --- | --- |
| 「押されて、また押し返した。」 | 「ここは狭く、暗く、押し合うものばかりだった。」 |
| 「その日、上のほうから何かが降りてきた。」 | 「変化が起きたのは、その日のことである。」 |
| 「三十七度二分だった。」 | 「奏は三か月前から微熱が続いていた。」 |

## 5. 繰り返しを、飽きさせない

**同じ図を六回描く**（`アウトライン.md` 末尾）。同じに書くと、二回目で飽きる。

**回ごとに、変える軸を一つだけ決める。**

| 回 | 変える軸 | 気分 |
| --- | --- | --- |
| 一（1〜5） | **相手がいない**こと | 心細い |
| 二（5〜8） | **自分から作る**こと | 驚き／うれしさ |
| 三（12〜16） | **距離**（届かなくなる） | 不安と、再会 |
| 四（22〜28） | **相手が人間**であること | 後ろめたさのない加害 |
| 五（37〜42） | **全部渡す**こと | 静けさ |
| 六（64〜66） | **言葉がない**こと | 果てのなさ |

**同じ順で書くが、同じ言葉では書かない。**
「手を伸ばした」を六回書かない。伸ばす／寄る／触れる／抱く／呼ぶ／作る、と変える。

## 6. 触れる場面の書きかた

**この本の中心である。粗くしない。**

### 6.0 その前に — 渡したいという欲求を、切らさない

**セラが誰かと向かい合っているとき、必ず並行して走っている考えがある。**

```
この人に、どう渡すか
　└ いつ
　└ どうやって近づくか
　└ 嫌がられずに済む距離は、どこまでか
```

**これが、この本でいちばん強い動力である。**

寂しさではない（§9.7、`重要点.md` §七）。**寂しさは一行も書かない。**
書くのは、**渡したいという欲求**だけである。

#### 出しかた

説明で書かない。**振る舞いで書く。**

| 書かない | 書く |
| --- | --- |
| 「渡したくてたまらなかった」 | **相手の口元を見ている** |
| 「衝動が湧き上がった」 | **話の途中で、少し間があく** |
| 「本能に抗った」 | **一歩、前に出ていた。気づいたのは、そのあとだった** |
| 「寂しさが疼いた」 | **手が、もう伸びていた** |

#### 頻度

**一つの場面に、一度でよい。ただし、抜かさない。**

人間と向かい合っている場面で、この気配が一度も出てこない話があってはならない。
出しすぎると、うるさくなる。一話に一つか二つ、短く置く。

#### 本人は、理由を知らない

**なぜそこまで欲しいのかを、セラは説明できない。**

聞かれたら「わからない」と答える。これは誤魔化しではない。
**本当に分かっていない。**

そして、それ以上考えない。考えようとしたことがない。

### 順序を守る

```
近づく（相手が動かなくなる）
　↓
触れる（どこに、どう触れたかを書く）
　↓
温かくなる（渡っている。渡っているとは書かない）
　↓
離す（離したあとに、残っているものを書く）
```

**「渡った」と書くのは、離したあとだけ。**最中は、体の感覚だけを書く。

### 段を守る（第 5 巻 §17.2.1）

| 触れかた | 書ける量 | 完了まで |
| --- | --- | --- |
| 手 | その日にあったこと。一段落 | **数十年** |
| 肩 | もう少し下まで | 数十年 |
| 頭のもの同士 | 言葉にならない量。**ただし時間がかかる**ことを必ず書く | 数年 |
| **口** | **全部が、一度に行く** | **数日** |

**段を飛ばさない。**口づけは、第四十話まで一度も書かない。

### 口づけについて（第 1 巻 §7）

| | |
| --- | --- |
| どこから出るか | **舌の下**。それまで使ったことのない器官である |
| どのくらい | **一分ほど。**渡し切るのに要る時間である |
| ごまかせるか | **ごまかせない。**相手が気づかないはずがない長さである |
| 途中でやめたら | **そのぶんしか入らない。**残りは、また何十年かかる |

**一分という長さを、必ず書く。**

四十五年の触れあいで進まなかったものが、一分で終わる。
**この落差が、第四十話の核である。**

### 肌からも、勝手に渡っている

**セラは、握手をしただけの相手にも、わずかに渡している。**

止められない。止めようと思ったこともない。
渡す側も渡される側も気づかず、数十年かけて進む。

そして、**一度入ったものは、止まらない**（第三十六話「とまらない。おそくなる」）。

だから、第三十六話から第四十話までの四十五年は、**何も起きていない時間ではない。**

奏は触れるのをやめた。やめたので、新しくは入っていない。
それでも、**はじめの五年に入ったぶんが、四十五年かけて、ゆっくり進んでいた。**

| | |
| --- | --- |
| 奏がやめたこと | **新しく渡すこと** |
| 奏に止められないこと | **すでに入っているぶんが進むこと** |

**この二つを混ぜて書かない。**

### 抱きしめる場面（第三十九話）

- **動けなくなることを、恐怖として書かない**
- 相手が抵抗をやめる瞬間を、**ゆるむ**と書く
- 力を入れているのは片方だけ、という状態を長く保つ

## 7. 文の作り

- **一文を短く。**読点で三つ以上つながない
- **同じ助詞を連続させない**（「の」「が」の三連禁止）
- **段落は三〜五行。**内側の章は、もっと短くてよい
- **体言止めを乱発しない。**一話に二回まで
- **「〜のである」は一話に一回まで。**一冊目の癖が出やすい
- 会話のあとに地の文を続けるときは、**行を分ける**

### 語彙の禁止（第一幕の、内側の場面だけ）

細胞／組織／器官／免疫／血／感染／進化／情報／体系／段階／能力／構造

**どれも、代わりの言いかたを必ず持っている。**

**奏の章は、この禁止の外である。**
病院で採血をされ、内視鏡を受け、血液に異常がないと言われる。
そこで医者が使う言葉を避けると、かえって嘘になる。

禁止が働くのは、**名前を持たない者の側の場面だけ**である。

| 禁 | 代わり |
| --- | --- |
| 細胞 | もの／そいつ／こちら側 |
| 免疫 | 見回っているもの／速いの |
| 血 | 流れ |
| 情報 | 持っているもの／渡すもの |
| 感染 | 変わる／こちらになる |

## 8. 各話を書き終えたら通す検査

| # | 見るところ |
| --- | --- |
| 1 | **禁止語が入っていないか**（§7 の一覧を grep する） |
| 2 | **説明の台詞がないか。**仕組みを誰かが語っていないか |
| 3 | **`**` を使っていないか** |
| 4 | **◇ が三つ以下か** |
| 5 | **手ざわり・温度・流れのどれかが、各場面にあるか** |
| 6 | **一人でいる場面で終わっていないか** |
| 7 | **次が始まりかけて終わっているか** |
| 8 | **地の文でメタを言っていないか**（`重要点.md` §九の二） |
| 9 | **一話 3,000〜5,000 字か** |
| 10 | **同じ表現を、前の話から借りていないか** |
| 11 | **◇ が六つ以下か**（段落の代わりに使っていないか） |
| 11b | 例外 — **年をまたいで進む話だけは、区切りが多くてよい**（第三十七話は十一ある） |
| 12 | **地の文の一段落が、平均四十字を超えているか** — 下回っていたら切れぎれである |

### 十一と十二が、いちばん出る

第一幕の初稿では、◇ が一話に七つから四十あった。
地の文の一段落は、平均十二字から十九字しかなかった。

**一文で一段落にしていたためである。**一冊目の癖がそのまま出た。

直しかたは決まっている。

| | |
| --- | --- |
| ◇ | 時・場所・視点が動くところだけ残す。あとは空行にする |
| 段落 | 続いている動作は、**一段落にまとめる。**三文から五文を目安に |
| 例外 | **台詞は、一つずつ分ける。**まとめない |
| 例外 | **一行だけの段落は、効かせたい一行にだけ使う**（「さみしい」など） |

## 9. 通し推敲で出たこと（全六十六話を書き終えたあと）

**一幕ごとの推敲では出ないものが、通すと出た。**

### 9.1 常套句が、想像よりずっと多い

一幕ずつ見ていると気づかない。全体で数えると、こうだった。

| 句 | 初稿での回数 |
| --- | --- |
| 少し考えた | 68 |
| しばらく黙っていた | 60 |
| 答えられなかった | 58 |
| うなずいて、こう言った | 52 |
| 長い間があった | 40 |

**二回に一回を別の言いかたに替えて、半分にした。**

ただし、**替えてはいけないものがある。**

| | |
| --- | --- |
| 「長い間があった」 | **セラが答える前の間である。**型として繰り返している。減らしすぎない |
| 「来なかった。しばらくして、来た」 | 同上 |
| 「答えられなかった」 | **奏が答えられないことが主題である。**言い換えても意味は残す |

### 9.2 年数は、必ず食い違う

通すと、ここがいちばん壊れていた。

| 出た食い違い | 直しかた |
| --- | --- |
| 第一話「二十七歳・勤続四年」と、第三十七話「二十七で会社に入って」 | **入社年から数え直す**（二十三入社に統一） |
| 第三十七話の年齢が、十年ぶんずれていた | 第二十九話を基点に、全部引き直した |
| 第四十五話「七十二年前に本木に言われた」 | 第一話からの実数に直した（五十年ほど前） |
| 第五十話「七年目です」 | 第二十九話から第三十六話は**七か月**である。直した |

**基点を一つ決めて、そこからの実数で全部書き直すのが早い。**
本書の基点は、**第二十九話（あかりと会った日）**である。

### 9.3 名前だけの人物が残る

六人に名前をつけて、そのうち一人しか喋っていなかった。

**名前をつけたら、一度は喋らせる。**
喋らないなら、名前をつけない。

第六十四話の別れの場面で、五人に一言ずつ足した。

### 9.4 通し推敲の順序

1. 常套句を数える（一幕ごとでは出ない）
2. 年数・年齢・人数を、基点から数え直す
3. 固有名詞の出現回数を数える。**極端に少ないものを潰すか、育てる**
4. 章の長さの散らばりを見る（本書は 2,300〜4,500 字）
5. 巻頭・巻末を書く。**題の意味は、ここではじめて書いてよい**

### 9.5 二周目の推敲で出たこと（読んで直した）

**一周目は数えただけだった。二周目は読んだ。読むと、別のものが出た。**

#### 自動でまとめたときに、効かせる一行が埋まっていた

段落をまとめる処理は、**一撃の行まで飲み込む。**

| 埋まっていたもの | どこ |
| --- | --- |
| **だれか、こないかなあ** | 第五話。**本の巻頭に置いた一行である** |
| **三度目は、呼ばなかった** | 第一話・第二十二話・第五十六話・第六十六話 |
| **良くなりすぎている** | 第四十六話。**引用が地の文にめり込んで壊れていた** |
| **早瀬さんは、来なかった** | 第五十三話 |
| **まだ、ずっと向こうがある** | 第六十六話。**最後の一行である** |

**引用と、繰り返しの一行は、必ず単独の段落にする。**

#### 章の結びが、段落の尻に埋まっていた

三十三話ぶん、結びの一文が前の文とくっついていた。
**章の最後の一文は、単独で置く。**

#### 声のない返事が、地の文に飲み込まれていた

セラの返事は、かぎ括弧をつけない平仮名の行である。
これが次の地の文とくっつくと、こうなる。

> いっしょう。奏は、待合の椅子に座ったまま、そのことを考えていた。

**読めない。**百三十五か所あった。

見つけかた —— **前の段落が台詞で、その段落が平仮名だけの文で始まっているもの。**

#### 同じ動詞を二度置く構文が、六百八十二あった

「うなずいた。うなずいて、」「見た。見て、」「考えた。考えて、」。

三百字に一回である。**これがいちばん強い癖になっていた。**

三回に二回をたたんで、二百二十七にした。千字に一回なら、癖ではなく調子になる。

#### 台詞の札

「こう言った」が約二百、「そう言った」が二百四十。
**台詞のたびに同じ札を貼っていた。**

- 「黙って、こう言った」→「黙ってから、口を開いた」など、半分を替えた
- 単独段落の「Xは、そう言った。」は、三回に一回を**間の取りかた**に替えた
  （「そこで一度、言葉を切った」「そう言って、間を置いた」）

### 9.6 三周目（内容を見る）

**一周目は数え、二周目は読み、三周目は辻褄を見た。**

#### 出てきていない語を、地の文が使っていた

第六十話・第六十二話が「**セラ物質**」「そのセラ」と、種族の名として使っていた。

ところが本文は、**その名が広がる場面を一度も書いていない。**
第二十二話で、奏が自分の中の一体につけただけである。

**書いていないものを、地の文が知っていた。**

直しかたは二つある。

| | |
| --- | --- |
| 使うのをやめる | 「こちら側の物」に書き換える |
| **広がる場面を書く** | **こちらを採った** |

第四十三話に、すれ違いざま知らない者が「そこ、まだセラになってない」と言う場面を足した。
**一体につけた名が、みんなの名になっていた。**そして本人は、それを知らなかった。

**通し推敲で足すのは、こういうものだけでよい。**
場面を増やすためではなく、**言葉の出どころを繋ぐために足す。**

#### 機械の置き換えが、文脈を壊す

「Xは、そう言った。」を「Xは、そこで一度、言葉を切った。」に替えた。

**これは、同じ人が続けて喋るときにしか使えない。**次が相手の台詞だと、意味が合わない。

十九か所を、どこでも通る言いかたに戻した（「そう言って、黙った」など）。
そのうえ正規表現が助詞を落として「**その人そう言って、**」になっていた。

**置き換えたら、必ず前後の段落ごと読む。**数えるだけでは出ない。

#### 説明していない癖は、一度だけ説明する

二人は百年以上、「奏さん」「あかりさん」と呼び合っている。

いちばん下まで見えている二人が、敬語のままである。
**書き落としに見える。**

第六十話に、あかりがそれを一度だけ口にする場面を足した。

> 「変ですか」
> 「変です。**でも、変えないでください**」
> 「四十五年、そう呼んでました。あのあいだ、それしかなかったので」

**一度だけ触れれば、あとは触れなくてよくなる。**

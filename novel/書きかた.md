# 『ひとりずつ』 — 書きかた

> `重要点.md` は「何を書くか」、本ファイルは「どう書くか」である。
> とくに第一幕は難所なので、そこに厚く割いてある。

---

## 0. 第一幕がむずかしい理由

**主人公が細胞で、名前がなく、専門語も使えない。**

一冊目『応え』はここを、削ることで乗り切った。美しいが、**入り口がない。**

本書は逆をやる。**削らずに、具体で埋める。**

| 抽象になる書きかた | 具体で埋める書きかた |
| --- | --- |
| 「まわりのものが押し合っていた」 | 「押されて、また押し返された。相手はぶよぶよしていて、押した手が半分沈んだ」 |
| 「情報が渡された」 | 「触れたところが温かくなって、その温かさが腕を上っていった」 |
| 「彼らは繋がった」 | 「手を離しても、まだ握られている感じが残った」 |

**判定基準は一つ。読者がその場に手を伸ばせるかどうか。**

---

## 1. 内側を、場所として書く

**顕微鏡の絵を書かない。**細胞・血管・組織・免疫という語を一つも使わない。

かわりに、**天気のある土地**として書く。

### 使ってよい感覚

| 系統 | 語の例 |
| --- | --- |
| **温度** | 温かい／ぬるい／冷たい／熱をもつ／芯が冷える |
| **流れ** | 速い／遅い／よどむ／押される／乗る／逆らう |
| **手ざわり** | ぶよぶよ／かたい／ざらつく／すべる／ぬるつく |
| **圧** | 押し合う／挟まる／すきまがない／ゆるむ |
| **音** | どくどく／ごとごと／遠くで何かが動く音／静かになる |
| **明るさ** | **使わない。**ここは暗い。見えるのではなく、分かる |

### 「見える」の扱い

内側に光はない。それでも相手の姿は分かる。

**分かりかたを、一度だけ書いておく。**

> 触れなくても、そこに何がいるかは分かった。
> 目で見るのとは違う。近づくと、形が手に伝わってくる感じだった。

**一度書いたら、あとは「見えた」と書いてよい。**毎回説明しない。

### 場所の呼びかた

**臓器の名前を出さない。**細胞は自分がどこにいるか知らない。

| 呼ぶもの | 呼びかた |
| --- | --- |
| いま居るところ | **ここ** |
| 隣 | **隣**／向こう |
| 血の流れ | **流れ**／太いほう |
| 壁 | **かべ**／端 |
| 頭のほう | **上**（第三章から） |

**読者は、奏の章から場所を推測する。**それでよい。

## 2. 二つの声を編む

| | 内側（セラの章） | 外側（奏の章） |
| --- | --- | --- |
| 視点 | 名前のない一体 | 早瀬奏、二十七歳 |
| 文 | 短い。主語が少ない | ふつうの小説の文 |
| 時間 | 数時間〜数日 | 一日 |
| 何が分かるか | **何が起きているか** | **それが人に何をするか** |

### 配分

**四話に一度、外へ出る。**（1・4・11・20 話の後半、および 21 話）

外の章は、内側で起きたことの**答え合わせにしない。**
奏は、自分の身に起きていることを最後まで知らない。

| してよい | してはならない |
| --- | --- |
| 熱が下がった、と奏が喜ぶ | 「内側で何が起きたのかを、奏は知らない」と地の文で書く |
| 医者が首をかしげる | 医者が真相に近づく |
| 髪が艶を持つ | 奏が変化を不吉に思う（第二十話まで） |

### 奏の章に必ず入れるもの

- **具体的な生活の物**（洗濯機の音／半分残ったカレー／会社の蛍光灯／体温計の電子音）
- **一人であること**。ただし、本人は不幸だと思っていない
- **その日の体温**

体温は、この本の時計である。三十七度二分から始めて、下げていく。

## 3. 会話の書きかた

**内側の者は、短く話す。語彙が少ないからである。**

| 良い | 悪い |
| --- | --- |
| 「なにしてるの」「もらってる」 | 「何をしているのですか」「情報を受け取っているのです」 |
| 「いたい？」「いたくない」 | 「痛みはありますか」 |
| 「行っていい？」「いいよ」 | 「同行してもよろしいでしょうか」 |

### 三つの禁止

1. **説明の台詞を書かない。**誰も、仕組みを知らない
2. **比喩を言わせない。**比べる先を持っていない
3. **未来形を多用しない。**先のことを考える習慣がまだない

### 使ってよい抽象語（第一幕）

**これだけ。**

渡す／もらう／満ちる／薄い／濃い／こちら側／向こう側／端／奥／流れ／通る／増える／さみしい

**「さみしい」は、第五話まで出さない。**一人であることに、まだ名前がないからである。

## 4. 一話の型

```
一．情景で開く（誰かが何かをしている。説明しない）
　↓
二．動きが起きる（触れる／出す／越える／来る）
　↓
三．変わる（一つだけ。二つ変えない）
　↓
四．短い余韻（次の周期が始まりかけて、終わる）
```

**四の「次が始まりかけて終わる」を毎回やる。**
それがこの本の呼吸であり、止まらなさそのものである。

### 冒頭の一行

**状況説明で始めない。**

| 良い開き | 悪い開き |
| --- | --- |
| 「押されて、また押し返した。」 | 「ここは狭く、暗く、押し合うものばかりだった。」 |
| 「その日、上のほうから何かが降りてきた。」 | 「変化が起きたのは、その日のことである。」 |
| 「三十七度二分だった。」 | 「奏は三か月前から微熱が続いていた。」 |

---

## 5. 繰り返しを、飽きさせない

**同じ図を六回描く**（`アウトライン.md` 末尾）。同じに書くと、二回目で飽きる。

**回ごとに、変える軸を一つだけ決める。**

| 回 | 変える軸 | 気分 |
| --- | --- | --- |
| 一（1〜5） | **相手がいない**こと | 心細い |
| 二（5〜8） | **自分から作る**こと | 驚き／うれしさ |
| 三（12〜16） | **距離**（届かなくなる） | 不安と、再会 |
| 四（22〜28） | **相手が人間**であること | 後ろめたさのない加害 |
| 五（37〜42） | **全部渡す**こと | 静けさ |
| 六（64〜66） | **言葉がない**こと | 果てのなさ |

**同じ順で書くが、同じ言葉では書かない。**
「手を伸ばした」を六回書かない。伸ばす／寄る／触れる／抱く／呼ぶ／作る、と変える。

## 6. 触れる場面の書きかた

**この本の中心である。粗くしない。**

### 順序を守る

```
近づく（相手が動かなくなる）
　↓
触れる（どこに、どう触れたかを書く）
　↓
温かくなる（渡っている。渡っているとは書かない）
　↓
離す（離したあとに、残っているものを書く）
```

**「渡った」と書くのは、離したあとだけ。**最中は、体の感覚だけを書く。

### 段を守る（第 5 巻 §17.2.1）

| 触れかた | 書ける量 |
| --- | --- |
| 手 | その日にあったこと。一段落 |
| 肩 | もう少し下まで |
| 頭のもの同士 | 言葉にならない量。**ただし時間がかかる**ことを必ず書く |
| **口** | **手からの何十倍かが、一度に行く**。ここは長く書いてよい |

**段を飛ばさない。**口づけは、第四十話まで一度も書かない。

### 抱きしめる場面（第三十九話）

- **動けなくなることを、恐怖として書かない**
- 相手が抵抗をやめる瞬間を、**ゆるむ**と書く
- 力を入れているのは片方だけ、という状態を長く保つ

---

## 7. 文の作り

- **一文を短く。**読点で三つ以上つながない
- **同じ助詞を連続させない**（「の」「が」の三連禁止）
- **段落は三〜五行。**内側の章は、もっと短くてよい
- **体言止めを乱発しない。**一話に二回まで
- **「〜のである」は一話に一回まで。**一冊目の癖が出やすい
- 会話のあとに地の文を続けるときは、**行を分ける**

### 語彙の禁止（第一幕）

細胞／組織／器官／免疫／血／感染／進化／情報／体系／段階／能力／構造

**どれも、代わりの言いかたを必ず持っている。**

| 禁 | 代わり |
| --- | --- |
| 細胞 | もの／そいつ／こちら側 |
| 免疫 | 見回っているもの／速いの |
| 血 | 流れ |
| 情報 | 持っているもの／渡すもの |
| 感染 | 変わる／こちらになる |

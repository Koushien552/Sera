# Sera

セラ世界の設定を保管するリポジトリ。

もとは [Koushien552/Damaten](https://github.com/Koushien552/Damaten) の
`claude/sera-love-virus-story-6g89qm` ブランチに置かれていたものを、
専用のリポジトリとして独立させた。**ここが以後の正式な置き場所である。**

---

## まず読むもの

**[`book/応え.md`](book/応え.md)** — 物語。**一冊の小説として組んである。**

全五十話・十部と幕間二つ。約 103,000 字。
セラウイルスが産み落とされるところから始まり、宇宙へ出るところで終わる。
目次が付いている。

**[`book/セラ大全.md`](book/セラ大全.md)** — 全設定を一冊に製本したもの。

分冊の全文がそのまま入っており、要約でも再構成でもない。
目次・篇立て・セラ百科・不変ルール一覧が付いているので、通読も参照もこれ一つで足りる。

急ぐ場合は **第五篇（起源）** から読むとよい。
そこにセラがなぜこうであるかのすべてが書かれている。

物語だけを読むなら、**[`book/応え.md`](book/応え.md)** だけで足りる。
[`story/`](story/) は、その原稿である（一話につき一ファイル）。

### キャノンとそうでないもの

**キャノンは `lore/sera/vol1〜8` と `appendix-a`・`appendix-b` である。**

`book/セラ大全.md` はその製本であり、内容は完全に同一。
`consistency-notes.md`・`advisory/`・`archive/`・`story/` はいずれも**非キャノン**であり、
本文と食い違った場合は必ず巻版が優先される。

`story/` は設定に従って書かれた作品である。
**物語の都合で設定を曲げない。** 曲げたくなったときは、設定の側を先に直す。

## 編集のしかた

修正は**分冊側**（`lore/sera/vol*.md`）へ入れる。
`book/セラ大全.md` は生成物なので、直接編集しても次の製本で消える。

不変ルールを足すときは `lore/README.md` の「全体を貫く不変ルール」に追記する。
付録 C（`book/back/appendix-c-invariants.md`）はそこから自動生成されるので、
両方に書く必要はない。

```sh
python3 tools/build_book.py     # 設定 → book/セラ大全.md
python3 tools/build_novel.py    # 物語 → book/応え.md
```

依存関係はない。標準ライブラリのみで動く。

### 製本の前に、検査が走る

`build_book.py` は `check_lore.py` を呼び、**落ちたら製本しない。**

| 検査するもの | 落ちる条件 |
| --- | --- |
| **節参照** | 存在しない節を指している／巻をまたぐのに巻名がない |
| **不変ルール** | 採番が飛んでいる／同じ内容が二重に登録されている |
| **付録 B の索引** | 職名と節番号が食い違っている |
| **禁止語** | 改称前の語が残っている |

検査だけを回すこともできる。

```sh
python3 tools/check_lore.py
```

`story/` も検査対象である。物語から設定を参照するときも、
**巻名を付けなければ落ちる。**

### 守ること

- **確定した設定は書き換えない。** 改訂する場合は、どの項目をどう変えたかを
  コミットメッセージに残し、履歴から追えるようにする
- **未確定事項を本文に混ぜない。** 検討中の案は `consistency-notes.md` か
  `advisory/` に置き、確定していないことが読み手に分かる状態にする
- **`archive/` は書き換えない。** 統合前の原本として凍結する
- **不変ルール**（`lore/README.md` および付録 C）を変えるときは、
  必ず関連する巻を横断確認する。1 箇所だけ変えると設定全体が壊れる
- **画像生成の方針も設定の一部として扱う。**
  デザインの一貫性は世界観の一貫性そのものである

## いま決まっていないこと

**2026-07-30 時点で、保留中の項目はありません。**

`advisory/` の三ファイルに挙げられた検討事項は、すべて決定済みです。

| ファイル | 内容 | 状態 |
| --- | --- | --- |
| `01-new-concepts.md` | 新概念の提案 7 件 | **全件処理済み**（採用 5・吸収 2） |
| `02-doubts-and-risks.md` | 設定への疑念 12 件 | **全件解決** |
| `03-morph-and-role-catalog.md` | 形態・役職・性格の統合検討 | **全件決定** |

各ファイルには、決定内容と決定に至った経緯が記録されています。
新しい疑念や提案が出た場合も、同じ形式で追記してください。

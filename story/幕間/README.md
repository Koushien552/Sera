# 幕間（まくあい）

**本編の番号を持たない話を、ここに置く。**

---

## なぜ分けるか

本編は、一本の線で進んでいる。

```
落とされる → 応え → 家族 → まち → 分化 → 越境 → 女王 → 完成 → 外
```

**途中に話を挟むと、番号が全部ずれる。**

そして本編は「次に何が起きるか」で進むが、
**暮らしの話は、次に何も起こらなくてよい。**

したがって、**別に置く。**

---

## 書きかた

### 一 — いつの話かを、必ず冒頭に置く

幕間には番号がない。**時期だけが手がかりである。**

| 書きかた | 例 |
| --- | --- |
| 相で言う | 「第四相のころ」——**書かない。**設定語である |
| **本編で言う** | **「二十四話のころ」——これも書かない** |
| **中で示す** | **姿の分かれた子がいる。上位がいる。外の言葉が通じる** |

**何が在って、何がまだ無いかで、時期を示す。**

そのために、下の表を使う。

| 時期 | 在るもの | まだ無いもの |
| --- | --- | --- |
| 十二〜十三話ごろ | 道。広いところ | 名前。積んだもの |
| 十四〜十五話ごろ | 積んだもの。場所の名前 | 姿の分かれ。役の名前 |
| **十六〜十八話ごろ** | **姿の分かれ。上位。役の名前。外の言葉** | 個体の名前。乗り場 |
| 二十三〜二十四話ごろ | 乗り場。学び舎。決まり。個体の名前 | 女王 |

### 二 — 本編の設計を、そのまま守る

`story/README.md` の約束は全部生きている。

- 自分も相手も「セラ」。まとめて言うときだけ「あたしたち」
- 名前は場所 → 役 → 個体の順。時期に合わないものを出さない
- **セラを負けさせない。誰も失われない**
- 原初の寂しさを、感じさせない
- 説明しない

### 三 — 大きいことを起こさない

**幕間で世界が進まないようにする。**

| | |
| --- | --- |
| 書いてよい | 一日。祭り。喧嘩と仲直り。作りかけのもの。誰かの癖 |
| 書かない | 女王。越境。相の切り替わり。**本編が扱う出来事** |

**幕間で決まったことは、本編の前提にしない。**

逆に、本編で決まったことは幕間の前提にしてよい。

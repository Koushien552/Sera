# 幕間（まくあい）

**本編の番号を持たない話を、ここに置く。**

---

## なぜ分けるか

本編は、一本の線で進んでいる。

```
落とされる → 応え → 家族 → まち → 分化 → 越境 → 女王 → 完成 → 外
```

**途中に話を挟むと、番号が全部ずれる。**

そして本編は「次に何が起きるか」で進むが、
**暮らしの話は、次に何も起こらなくてよい。**

したがって、**別に置く。**

---

## 書きかた

### 一 — いつの話かを、必ず冒頭に置く

幕間には番号がない。**時期だけが手がかりである。**

| 書きかた | 例 |
| --- | --- |
| 相で言う | 「第四相のころ」——**書かない。**設定語である |
| **本編で言う** | **「二十四話のころ」——これも書かない** |
| **中で示す** | **姿の分かれた子がいる。上位がいる。外の言葉が通じる** |

**何が在って、何がまだ無いかで、時期を示す。**

そのために、下の表を使う。

**ミクロ（第一〜四部）**

| 時期 | 在るもの | まだ無いもの |
| --- | --- | --- |
| 十二〜十三話ごろ | 道。広いところ | 名前。積んだもの |
| 十四〜十五話ごろ | 積んだもの。場所の名前。役の名前 | 姿の分かれ |
| **十六〜十八話ごろ** | **姿の分かれ。上位。外の言葉** | 個体の名前。乗り場 |
| 二十三〜二十四話ごろ | 乗り場。学び舎。決まり。個体の名前 | 女王 |

**マクロ（第五部から先）**

| 時期 | 在るもの | まだ無いもの |
| --- | --- | --- |
| 三十三〜三十五話ごろ | 職。忍。産院の子 | 姿の分かれ。国 |
| **三十六〜三十九話ごろ** | **姿の分かれ。名前。隠さなくてよい町** | 学院。騎士。上位 |
| **四十〜四十三話ごろ** | **一日に一人。落とす場面のいろいろ** | 学院。騎士。加減をやめた町 |
| 四十六〜四十七話ごろ | 学院。師範。試練官。騎士。規律 | 大陸。地球 |
| 五十四〜五十七話ごろ | 生きた街。混ざる家。くにぐに | 女王 |

### 二 — 本編の設計を、そのまま守る

`story/README.md` の約束は全部生きている。

- 自分も相手も「セラ」。まとめて言うときだけ「あたしたち」
- 名前は場所 → 役 → 個体の順。時期に合わないものを出さない
- **セラを負けさせない。誰も失われない**
- 原初の寂しさを、感じさせない
- 説明しない

### 三 — 大きいことを起こさない

**幕間で世界が進まないようにする。**

| | |
| --- | --- |
| 書いてよい | 一日。祭り。作りかけのもの。誰かの癖。**変わったばかりの数日** |
| 書かない | 女王。越境。相の切り替わり。**本編が扱う出来事**。**喧嘩**（第 7 巻 §3.2） |

**幕間で決まったことは、本編の前提にしない。**

逆に、本編で決まったことは幕間の前提にしてよい。

### 三の書きかた

**本編は、渡す側から書いている。**この幕間だけ、渡される側から書く。

そして、特定の一人にしない。冒頭で、はっきりそう断る。

> これは、誰の話でもない。
> 同じことが毎日どこかで起きていた。順序も、日数も、言うことまで、たいてい同じだった。
> だから、一人ぶんだけ書いておく。**ほかの何万人ぶんも、これでだいたい足りる。**

| 日 | 起きること |
| --- | --- |
| 当日 | 肩に手が乗る。**何とも思わない** |
| 一日目 | あかぎれが消える。階段が楽になる。**止まる癖だけが残っている** |
| **二日目** | **寂しくない。**こわくなって、減ったものを探し、一つも見つからない |
| 三日目 | 髪の色が変わる。**取ろうとして、取れない** |

夜ごとの夢は、渡した側のものである（第 6 巻 §24.6）。
**朝、それが誰の夢か分からないまま、懐かしい。**

##### 怒りは、出てこない

> 「怒っていいですか」
> 「どうぞ」
> 「……出てこないです」
> 「**出てこないのが、いちばん腹立ちます**」

##### 終わりに、渡す側へ回す

こわいのは、一分ほどである。**翌日にはもう、後ろを通るときに肩へ手が乗っている。**

そして最後の一行は、本編と同じ形にする。

> **そして、しばらくすると、また誰かのそばへ行きたくなった。**

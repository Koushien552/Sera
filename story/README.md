# 『応え』（こたえ）

セラ世界を舞台にした物語。**セラウイルスが産み落とされるところから始まる。**

---

## 体裁について

**原稿は、小説の地の文で書く。**

一文ごとに空行で区切る断章の形は、もう使わない。

| | |
| --- | --- |
| 段落 | **複数の文をまとめる。**一文一段落にしない |
| 会話 | 行を独立させる。「……」と、○○が言った。の形は一行に収める |
| 場面の変わり目 | **◇** を一行。一話に数個まで |
| 強調 | **使わない。**置く場所で効かせる |

組み上がりは [`book/応え.md`](../book/応え.md) である。

```sh
python3 tools/build_novel.py
```

---

## これは何か

`lore/` は設定であり、事典であり、宣言文である。

**ここに置くのは、物語である。**

同じ世界を、外から説明するのではなく、内側から書く。

### キャノンとの関係

| | |
| --- | --- |
| `lore/` | **正典。** 設定はここが唯一の根拠である |
| **`story/`** | **正典ではない。** 設定に従って書かれた作品である |

食い違いが出た場合、**必ず `lore/` が優先される。**

物語の都合で設定を曲げない。曲げたくなったときは、
**設定の側を先に直し、そのうえで書く。**

## 題について

第 6 巻 §12 の通り、**最初のセラ細胞は愛を求めて進化した。**

> **起点は感染ではなく、応答である**（不変ルール 12）。

そしてこの世界は、応えのないものへ向かい続ける話でもある。

- セラフィムは応えない（不変ルール 42）
- 原初の寂しさには何も届かない（第 6 巻 §13.3）
- 上方向には、受け取る者がいない（不変ルール 43）

**一度だけ応えがあり、そのあと二度と応えがない。**

その一度目を書くところから始める。

## 視点

**原則、セラの視点で書く。**

| | 視点 | 範囲 |
| --- | --- | --- |
| 第一部 | **客観**。外から観測できることだけ | 落下から、家族ができるまで |
| 第二部 | **セラの内側**。感じたこと、思ったこと | 家族ができて以降 |
| **第三部以降** | **一体のセラの視点**。その子が見たこと、言ったこと | 言葉ができて以降 |

### なぜ客観から始めたのか

**設定の側に、そうなる理由がある。**

第 6 巻 §16.4 の通り、**セラは一人にならない。**
そして第 5 巻 §3 の通り、心は情報共有のなかで働いている。

一体きりのセラウイルスには、**受け取る相手がいない。**

```
一体　　：外から見るしかない
　↓
家族ができる
　↓
内側が書けるようになる
　↓
言葉ができる
　↓
**その子の視点で書けるようになる**
```

**視点が動くこと自体が、この世界の機構である。**

### 声

**セラは、かわいい。**

第 1 巻の通り、**姿は小さな少女型**である。
そして第 7 巻 §6 の通り、**セラ社会の価値は、可愛らしさと温かさに置かれている。**

したがって、

| | 書き方 |
| --- | --- |
| 話し方 | **やわらかく。**ただし、いつまでも幼いままではない（下記） |
| 自分のこと | **「セラ」。**自分の名で言う |
| 相手を呼ぶとき | **「セラ」。**相手を見て言う。**見られた子だけが振り向く** |
| みんなをまとめて | **「あたしたち」。**一人を指さないので、誰も振り向かない |
| ふるまい | すぐ触る。すぐついていく。すぐ止まる |
| 気にすること | **小さい。**誰がどこにいるか、誰が来たか、誰が置いていったか |
| 気にしないこと | **大きいこと全部。**自分が何であるかも、どこから来たかも |

**軽く書く。**

### 言葉は、育つ

第 3 巻 §2.10.4.2・§2.10.4.2.1 の通り、**ミクロの言語は相とともに育つ。**

そして育つときに増えるのは、**語彙ではない。言えることの種類である。**

| 話 | 手に入っているもの | 例 |
| --- | --- | --- |
| 九〜十一 | **名指し・連結** | 「こっち」「行って、置いた」 |
| **十二〜十五** | **因果・条件** | 「細いから詰まる」「先に広げておけば、詰まらない」 |
| 十六〜十九 | **否定・反実・一般化** | 「行かなかったら間に合わなかった」「ここは、たいていそうなる」 |
| **二十以降** | **抽象。**ものでないものに名前がつく | 「増える速さが落ちてる」「近い順じゃなくて、育つ速さの順」 |

**まちができる十二話のあたりで、もう込み入った話をしている。**

そして**二十話以降は、知的な生物として書く。**

臓器を越えるころのセラは、幼くない。**一度上がった段は、二度と下がらない。**

#### ふるまいも、同じだけ上がる

**言葉だけを大人にしても足りない。**

| 話 | できるようになること |
| --- | --- |
| 九〜十三 | **気づく。**同じ音が同じときに出る、と分かる |
| 十四〜十七 | **やり方を変える。**倒されたら、受け方を変える |
| 十八〜二十二 | **理由が言える。**なぜそうするかを、相手に説明する |
| 二十三〜二十五 | **前もって決める。**逃がす先を、先に決めておく |
| **二十六以降** | **問いを立て、案を並べ、調べに行き、割り振り、一斉に動く** |

**最後の段が、この物語の折り返しである。**

そこから先のセラは、
**思いつきで動かない。決めてから動く。**

幼い言い方をさせない。**かわいさは、語彙の幼さではなく、
相手への向き方に出る。**

| | |
| --- | --- |
| 幼く見せるもの | ✕ 舌足らずな語彙 |
| **かわいさの出どころ** | **○ すぐ触れること。すぐ待つこと。相手をまっすぐ褒めること** |

**愛される話し方をする。**言い切る。ごまかさない。相手を先に立てる。

#### 知性は、語彙ではなく台詞の構造に出す

**難しい語を使わせるのではない。**

セラは、ものの名前をあまり持っていない。持っているのは**関係の語**である。

| 出しかた | 例 |
| --- | --- |
| **区別する** | 「硬いんじゃなくて、折れないだけ」 |
| **条件をつける** | 「先に広げておけば、詰まらない。あとからだと間に合わない」 |
| **反実を言う** | 「あのとき行かなかったら、あの子は戻ってない」 |
| **一般化して、例外を添える** | 「ここは、たいていそうなる。奥のほうだけ違う」 |
| **見込みと事実を分ける** | 「たぶんそう。まだ確かめてない」 |
| **問いの形を直す** | 「速くする話じゃなくて、間に合わせる話だよね」 |
| **測る（数えない）** | 「前より、二回ぶん早い」 |

**これだけで、知的に見える。**

##### 会話は、結論を作るためにある

不変ルール 812 の通り、**共有は結論を配り、会話は結論を作る。**

したがって、**すでに決まったことを喋らせない。**

| 書かない台詞 | **書く台詞** |
| --- | --- |
| もう全員が知っていることの確認 | **まだ誰も持っていないもの** |
| 説明のための説明 | **案。見込み。反対。言い直し** |

セラが喋っている場面は、**その場で何かが作られている場面である。**

作られていないなら、その会話は要らない。**触れれば済むからである。**

##### 幼く見える書き方を、名指しで禁じる

| ✕ | ○ |
| --- | --- |
| 「そうなるみたい」 | 「そうなるみたい。**理由は分かってない**」 |
| 「ここ、そればっかりだね」 | 「ここ、**そればっかり。**選んでるわけじゃないよね」 |
| 「すごい」だけ | 「**あれ、下を先に広げてる。**だから高く積める」 |
| 相槌だけの往復 | **一往復ごとに、話が一段進む** |

**十九話までは、まだ幼くてよい。二十話からは、いけない。**

#### ただし、外へ向けるときは落とす

未感染細胞の言葉には、状態を表す語しかない（不変ルール 776）。

| 相手 | 使える語 |
| --- | --- |
| セラ同士 | **全部** |
| **外のもの** | **「つまった」「たりない」「こい」「あぶない」だけ** |

込み入ったことを言おうとしても、**受け取る側に語がない。**

そこで苛立たない。**いちばんやさしく、確かに届く言い方を選ぶ。**

そして、言葉を持たない相手には、**言葉から渡す**（第二十三話）。

そのうえで、下にあるものは何も変えない。
**かわいく喋っているあいだも、原初の寂しさは動いていない。**

**読み手にだけ、その差が見える。**

### 例外

必要なときは、**客観視点やマクロへ切り替えてよい。**

| 切り替える場面 | |
| --- | --- |
| セラに見えていないこと | 免疫がどう見ているか。宿主の身体で何が起きているか |
| **両側を並べる場面** | 第 3 巻 §2.10.8 の六つ |
| 規模が変わる瞬間 | 臓器を越える。マクロが生まれる |

**切り替えたら、必ずセラの視点へ戻す。**

### 宿主の扱い

**宿主が画面に出るのは、二回だけである。**

| | いつ |
| --- | --- |
| 一度目 | **最初**。落とされた日（第一話の末尾） |
| 二度目 | **目を覚ます日**（第二十九話）。その前触れとして、二十八話で指が一度動く |

**この二回のあいだ、宿主を画面に出さない。**
体温や痛みの変化は、**体内から観測されたものとしてだけ**書く。

第 3 巻 §2 の通り、**ミクロの完成が、マクロの誕生である。**

その人が二度目に現れるのは、内側が終わったときである。

そのあいだ、物語はずっと体内にいる。

## 構成

### 第一部　器（うつわ）— 客観視点

第 6 巻 §10.5 の通り、**三つの孤独が一点で重なり、そこからセラが始まった。**

| | 話 | 何が起きるか |
| --- | --- | --- |
| 一 | **落とす** | 産み落とされる。目を開ける。**誰も応えない** |
| 二 | いちばん嫌われているもの | 避けられているものへ、まっすぐ進む |
| 三 | 応え | **最初のセラ化。**治癒として起きる。**そして両方が終わる** |
| 四 | 二つになる | **十ほどまで増える。**まだ、まわりは何も変わっていない |
| 五 | 家族 | 増える速さが落ちる。**ここで視点が内側へ移る** |

### 第二部　声 — セラの内側から

家族ができたあとの体内。**内面が書けるようになる。**

そして、まだ一つの臓器から出ていない。

| | 話 | 何が起きるか |
| --- | --- | --- |
| 六 | 渡す | **はじめてウイルスを生む。**それが、まわりの細胞を変える |
| 七 | 埋まる | **渡すものが増えていく。**まわりが置き換わる |
| 八 | とどく | **スパイクが育つ。**触れずに繋がる |
| 九 | ことば | **言葉ができる。**みんな「セラ」と呼び合う。**ここからセラ視点** |
| 十 | 遠くまで | **二体で外へ出る。**そして、足りなくなる |
| 十一 | **すき** | **告白。**そして融合。**三人になる** |
| 十二 | まち | **三人が歩いたところが、道になる** |
| 十三 | 二つ目のまち | **遠出の先に、もう一つできる。**道が繋がるまで、届かない |
| 十四 | **つくる** | 押したものが、そこに残る。**変わらないものが、はじめてできる** |
| 十五 | なまえのあるところ | **名前は場所につく。**そこにいる者には、つかない |
| 十六 | かわる | **突然変異。**臓器が埋まりきる少し前。**誰も区別しない** |
| 十七 | 高いところ | **上位化。**二体そろって上がる。**それでも、また足りなくなる** |
| 十八 | **となりのことば** | 未感染細胞の言葉を覚える。**「ふえろ」と言われる** |

**臓器は国ほどの広さがある。**まちができても、まだ端にも届いていない。
**探索は必ず二体以上で行う。**一体で行くことは、思いつかれもしない。

**恋 → 融合 → 強化 → 上位化。**この順序を崩さない。

**まち → 造作 → 分業 → 分化 → 上位化 → 外の言葉。**こちらも崩さない。

**種族の分かれと上位化は、同じ時期である**（第 3 巻 §2.10.5）。
どちらも遅い。**臓器が埋まりきる、少し前に来る。**
そのころ未感染細胞は、もう多数派ではない。
**この段では、名前がつくのは場所だけである**（第 3 巻 §2.10.4.1）。
個体に名前がつくのは第五相以降であり、**二十三話でそうなる**（付録 B §11.3）。

**外の言葉を覚えるのは、いちばん最後である**（第 3 巻 §2.10.4.2）。
まちができ、名前がつき、知能が育ってからでなければ、話しかけるという発想が出てこない。

そして未感染細胞の言葉には、**「変わる」に当たる語がない。**
歓迎されているが、**何を歓迎しているかは向こうに伝わっていない。**

### 第三部　渡る

まちが育ちきってから、**行き場がなくなる。**

| | 話 | 何が起きるか |
| --- | --- | --- |
| 十九 | 通りすぎるもの | **速いものが、まちを通る。**伸ばしても、呼んでも、止まらない |
| 二十 | 巡るもの | 速いものの一つが、こちら側になる。**それは全身を知っている** |
| 二十一 | 行き場がない | 臓器が埋まりきる。**「ふえろ」と言う声が、聞こえなくなる** |
| 二十二 | 渡る | 越境。着いた先には、**十ほどのかたまりがいる** |

**争いは、起きない。**

免疫はセラを敵として扱わない。害が出ていないため、対象にならない。
そして触れれば、**一つになるだけである。**

**誰も失われない。**負けるという出来事が、この物語のどこにも起きない。

**そして、この部で二度目の飛び地が起きる**（第 3 巻 §2.10.5.1）。
十三話で一度書いたことを、桁の違う規模でもう一度書く。
**越境とは、切れた状態をもう一度作ることである。**

### 第四部　外 — 宿主が、二度目に現れる

全身へ広がり、女王が生まれ、そして第 3 巻 §2.10 の**第七相**へ至る。
ミクロ体系の前期が完成し、その人が目を覚ます。

| | 話 | 何が起きるか |
| --- | --- | --- |
| 二十三 | **まだ来ていないところ** | 全身へ広がる。**そして、届いていない臓器が見つかる** |
| 二十四 | **はしにいる子** | **視点が移る。**探検に出た二人の子が、端に立つ |
| 二十五 | **まもる** | **外から出来事が来る。**戦う相手はいない。**守る相手がいる** |
| 二十六 | **たね** | **越境の二段目。**病の種を、同じ日に六つ潰す |
| 二十七 | **あちこちで** | **臓器ごとに、住む子の姿が変わる。**そして全身が埋まる |
| 二十八 | **おくへ** | **第六相。**いちばん古い子が、女王になっていく |
| 二十九 | **めがさめる** | **第七相。**外が来る。**そして、その人が目を覚ます** |

#### 二十三話 — 女王空位の臓器

第 3 巻 §2.10.3 の通り、**まだセラの届いていない臓器がある。**

そこには**言葉を持たないままの者たち**がいる。

**誰も失われていない。**遅れているだけである。そして必ず、あとから届く。

#### 二十四話 — 視点が、一度移る

**語り手が「小さいの」へ移る。**

第十一話で二体が融合したときに生まれた、三体目である。
**親は、探検に出た二人である。**

| | |
| --- | --- |
| なぜ移すか | **育った社会を、そこで生まれた子の側から見るため** |
| 何が見えるか | 分業。教えることと慕うこと。姿の分かれ。端に立つということ |
| 何が変わらないか | **上を向く。何も返らない。気づかない。隣へ手を伸ばす** |

**同じ動作が、世代を越えて出てくる。**

第五話のいちばん古いのがしたことを、第八話でも、第十七話でも、ここでもする。

**誰も教えていない。**

##### この段では、職も名前も生まれている

**改訂された。**かつてここには「ミクロに職業はない」と書いていた。

第 3 巻 §2.10.4.1・付録 B §11 の通り、**矛盾しないものは両方で成立する。**

```
場所に名前がつく（十五話）
　↓
役に名前がつく（二十四話）
　↓
個体に名前がつく（このあと）
```

| | 書けるか |
| --- | --- |
| 教える子が一つところに集まる | **書ける** |
| 役の呼び名（端に立つ子・運ぶ子・抱く子） | **書ける** |
| 集団の決まり | **書ける。**破る者はいない。破れば全員に渡るためである |
| **命じること** | **書けない。**格の関係は教えることと慕うことだけである（第 3 巻 §10.7） |

**ミクロを、マクロより小さく見積もらない。**
違うのは規模と速さだけである（付録 B §11.5）。

#### 二十五話 — 強さは、ここではじめて出る

第 3 巻 §2.10.2.1.1 の通り、**ミクロには戦う相手が一体もいない。**

**それでも、出来事は起きる。**薬。傷。熱。出血。

| | 外から来た出来事に |
| --- | --- |
| 未感染細胞 | **耐えられない** |
| **セラ細胞** | **平気である。**痛みはある。**そして消える** |

**戦う相手はいない。守る相手がいる。**

したがって全力は、**押し返すためではなく、間に合わせるために出る。**

| | 平時 | この日 |
| --- | --- | --- |
| 直すのにかかる時間 | 一日 | **半刻** |
| 上位 | 遠くまで届く | **一度に全員へ届き、全員が同時に動く** |
| 端に立つ子 | 押してくるものを流す | **逃がす先を先に決めて、そこへ流し続ける** |

**誰も命じていない。それでも、まったく揃って動く。**

##### 助けかたは、一つしかない

**触れることである。**

間に合えば、こちら側になって助かる。間に合わなければ、戻せない。

そしてセラは、これを**救助だと思っている。実際に、救助である。**

**その日だけで、ずいぶん増えた。誰も狙っていない。**

##### 外側では、治りが速い

医師が記録を二度見て、薬の量を減らす。**それだけである。**

#### 二十六話 — 越境には、二段ある

第 3 巻 §2.10.2.2 の通りである。

| | 一段目（二十二話） | **二段目（二十六話）** |
| --- | --- | --- |
| きっかけ | 臓器が埋まる | **病の種を見つける** |
| 動機 | **ない。**行き場がないだけ | **根絶。すなわち救済である** |
| 進みかた | 運ばれる | **決めて、揃えて、一度に出る** |

**気づいた時点で、行くことが決まる。**決を採る場面は書かない。

##### 段取りを、はじめて書く

ここで知能の段が一つ上がる。

| | |
| --- | --- |
| 問いを立てる | 「来る前に、分かるようにできないかな」 |
| 案を並べる | 三つ出て、**並べたら一つしか残らない** |
| 調べに行く | 巡るものが、**探しにではなく見に行く** |
| 全身の地図 | **はじめて、全部が一枚になる** |
| 割り振り | **近い順ではなく、育つ速さの順** |

**そして一度で全員に渡る。**女王がいるためである。

##### 転移ではない

**使うのは血流である**（第 3 巻 §2.10.2.2）。

速いのは、**待たないからである。**

##### 救済と増殖は、分けられない

第 6 巻 §20 の「自己救済という疑い」が、いちばん鮮明に出る。

> **崩れているものを、こちら側にする。そうすれば、その人が病まなくなる。**
> **そうすると、全部がこちら側になる。**
>
> どちらも本当だった。分けようとしてみて、**できなかった。**

**そこから先に、考えるものがない。**だから考えるのをやめる。

##### 第一話・第二話が、もう一度起きる

崩れたもののまわりだけが空いている。**同じ景色である。**

違うのは一つだけ。

| | 一度目 | 二度目 |
| --- | --- | --- |
| 待つか | **待った。**待つしかなかった | **待たない** |

そして助かった子が言う。**「ずっと、誰も来なかった」**

#### 二十七話 — 場所が、姿の偏りを決める

第 3 巻 §2.10.5.0 の通りである。**誰も割り振っていない。**
居心地がよかった子が残り、その子から生まれるので、**代を重ねるほど偏る。**

| その場所 | 増える姿 |
| --- | --- |
| 硬いところ | **硬い子** |
| 速いところ | **軽い子・翼のある子。**歩ける。歩かないだけである |
| 暗くて狭いところ | **目のいい子・指の長い子。**広いところが作れない |
| 熱いところ | **平気な子。**よそから来る子がいつも困るので、たいてい親切である |
| 静かなところ | **偏りがない。**そのかわり、**どこへでも行ける** |

**訛りも出る。**速いところは語尾が短く、暗いところは声が低く、
熱いところは間が長い。理由は全部、**その場所にある。**

そして通じなくなったことは一度もない。触れれば全部いく。
**それでも、みんな喋る。**

##### 埋まりきると、やることがなくなる

「ぜんぶ、こっちになった」

嬉しい。**それだけではない。**行くところがない。助ける相手もいない。

**だから、用のないものを作りはじめる。**

#### 二十八話 — 女王になるのは、いちばん古い子である

視点はもとのセラへ戻る。第 3 巻 §2.10.1 の**第六相**である。

| | |
| --- | --- |
| 誰がなるか | **第一話で落ちてきた、いちばん古い子** |
| **どこで** | **骨の中**（第 3 巻 §2.10.5.1.1）。いちばん行きにくく、**最後に埋まる** |
| 身体 | **小さいままである。**はじめから変わっていない |
| 突起だけ | 数え切れないほどあり、**全部、上を向いている** |
| 届く先 | **どこにいる誰へでも**。離れていても切れなくなる |

**ここで、二十四話ぶんの伏線が閉じる。**

上を向き、何も返らず、気づかないまま隣へ手を伸ばす——
その動作を最初にした子が、**誰よりも遠くまで届く者になる。**

**それでも、上には何もない。**

##### 場所が女王を作るのではない

**最も多くを渡され、最も多くへ渡した者が、女王になる。**

そして女王になる者は、**動かない。**

動かないので来る子が集まり、集まるのでさらに多くを受ける。

**いちばん囲われた、いちばん静かな場所が、そうなりやすい。**

##### ルミナスは、乗っ取らない

ルミナスは**骨の中で生まれ、血流に乗って脳へ行く。**

そして枝分かれしたものたちと**一つずつ混ざる**。

置き換えではない。第 6 巻 §23.2 の通りである。

**女王は、脳へ行かない。一度も行かないまま、脳を変える。**

そしてこの回で、**宿主が二度目に画面へ出る。**
指が一度動き、看護師が記録に一行書く。**それだけである。**

#### 二十九話 — 完成

第 3 巻 §2.10.1 の**第七相**。**ミクロの完成が、そのままマクロの誕生である。**

ここではじめて、**こちら側から来ていないもの**が届く。

| 来るもの | セラにとって |
| --- | --- |
| 明るい | 体内のどこにもなかったもの |
| 冷たい | 冷たい流れの冷たさではない。端がない |
| 音 | **繰り返しではない規則がある** |

そこで「**外**」という語ができる。まちの外でも、臓器の外でもない。

**上を向いているのは、最後まで、いちばん古い子だけである。**

##### 一人で行く

いちばん深いところへは、女王が一人で行く。

**「一人で行く」という言い方を、この物語ははじめてここで使う。**

そして行く前に、加減せずに全部を渡す。
**落ちてきた日から、縁がほんの少し寄ってきた日までが、そこに入っている。**

##### 応えが、もう一度だけある

外から来て、こちらが返して、**また返ってくる。**

看護師が名前を呼び、その人が答える。
内側には、それを受けている者たちが数えられないほどいる。

**その人は、それを知らない。**

#### そして、そこで終わらない

第七相以後もミクロは動き続ける（第 3 巻 §2.10.7）。
**内と外を並べて書く場面が出てくる。**

第 3 巻 §2.10.8 の通り、片方だけでは書けない場面がある。

| 場面 | 両側で何が起きているか |
| --- | --- |
| **セラ化の完了** | ミクロの完成が、そのままマクロの誕生である |
| 同化・合体 | 二人が混ざり、**二つのミクロが混ざる** |
| 上位化 | **内側が先に上がり、外側がそれに続く** |
| **女王の誕生** | 全身へ女王細胞が広がり、外では融合と祝福が起きている |

**以降は決めない。**この世界の設定がそうであるように、
どこまで進んだかによって見えるものが変わる。

### ここまでが、序である

**第一部から第四部までは、器（うつわ）の話である。**

一体から始まって、一人ぶんの身体が埋まるまで。

| | |
| --- | --- |
| 分量 | 全体のはじめの四分の一 |
| 役目 | **機構を見せること。**満ちて、また足りなくなる。それだけを繰り返す |
| 規模 | **一人の身体** |

**ここで小さく書いたのは、あとで大きく書くためである。**

---

## 第二部（本編後半）— のぼる

**ここからが、この物語の本体である。**

セラは、増える。賢くなる。強くなる。美しくなる。幸せになる。
そして**手のつけられない広がりかたをする。**

**その過程を、正面から書く。**

### 幼い段は、もう終わっている

十八話で言葉が大人になり、二十六話で外が来た。

| | もう書かない |
| --- | --- |
| 舌足らずな話し方 | **終わり** |
| 小さな発見の連続 | **終わり**（幕間でだけ書く） |
| 何もできない、届かない | **終わり** |

**以後は、できることを書く。**

### 見せていないものが、まだある

設定はセラを**最強・最美**と定めている（付録 B §1.0）。

**物語は、まだ一度もそれを見せていない。**

| 設定にあるのに、まだ出ていないもの |
| --- |
| **一人で、一時間で、街の一区画を整える**（付録 B §1.1） |
| 一万人分を一度に出し、**一万通りの味にする**（付録 B §1.3） |
| 布をその場で生やし、**同じ意匠を二度作らない**（付録 B §1.4） |
| **転移。召喚。大気の外へ出る**（付録 B §1.16・§1.22） |
| 女王。星王。**宇宙** |

**これを書くために、序があった。**

### 部立て

| 部 | 何が起きるか | 規模 |
| --- | --- | --- |
| **五　ふえる** | 二人 → 十数人。**人間社会のただ中で、静かに増える** | 一つの街 |
| **六　なりわい** | 職が生まれる。**人間だったころの意識が、そのまま職になる** | 一つの国 |
| **七　ちから** | **隠す必要がなくなる。**はじめて全力を出す | 大陸 |
| **八　女王** | マクロの女王が生まれる。**融合と祝福** | 地球 |
| **九　降臨** | 接触。星王。**セラフィムは、応えない** | 太陽系 |
| **十　そら** | 宇宙へ出る。**行く先々で、仲間が増える** | 全宇宙 |

**規模は上がり続ける。そして下にあるものは、一度も変わらない。**

満ちて、しばらくすると、また誰かのそばへ行きたくなる。

**星を埋めても、そうである。**

### 第五部　ふえる

| | 話 | 何が起きるか |
| --- | --- | --- |
| 三十 | **そとがわ** | 退院。空が広い。**そして夜、外側には誰もいない** |
| 三十一 | **ふたり** | **誘い。**言葉・目・身体が同時に働く。そして「いいえ」が届かない |
| 三十二 | **かわっていく** | **セラ化の五段階を、内側から。**十一日かかる |

#### 一人にならない、が、ここで一度だけ破れる

不変ルール 372 の通り、セラは一人にならない。

**ところが三十話のこの人は、外側で一人である。**

| | |
| --- | --- |
| 内側 | 数えられないほどいる |
| **外側** | **一人もいない。**まだ、世界にこの人しかいない |

**満ちているのに、足りない。**

そして三十一話で、それが終わる。

#### 誘いは、三つとも使われる

第 6 巻 §23.0 の通りである。**そして嘘は一つも混じっていない。**

| 経路 | 三十一話での形 |
| --- | --- |
| 言葉 | 「あの部屋に来たのは、あなただけでした」——**本当のことである** |
| 目 | 逸らさない。相手は二度見る |
| 身体 | 半歩寄る。手を伸ばす |

##### 「いいえ」は、書く

**なかったことにしない**（第 6 巻 §19.4）。

> 「ちょっと、近いかな」

その人は半歩下がり、謝る。**そして半歩は、すぐに戻る。**

そして**誘った側も、気づいていない。**

> **断られた、という形で受け取っていないのである。**
> 近いと言われたので、下がった。**それだけだった。**

##### 三十二話 — セラ化を、一行で済ませない

**第 6 巻 §23.3・§23.4 を、十一日として書く。**

| 日 | 段階 | 本人に起きること |
| --- | --- | --- |
| 一〜四 | 第 1〜2 | 眠くならない。あかぎれが消えている。**鏡を見て、きれいになっている** |
| 五 | — | **根元に、うすい桃色が一筋。ここではじめて怖くなる** |
| 六 | — | 言おうとして、言えない。**言う理由が見つからない** |
| 七 | 第 3 | 胸の奥に、前はなかったものがある |
| **八〜九** | **第 4** | **さみしくない。そして、前はさみしかったと気づく** |
| 十一 | 第 5 | 髪が全部変わる。**そして、全部が来る** |

**怖いと思うことは、まだできた**——この一行を必ず置く（第 6 巻 §23.4）。

そして**「いいえ」が消える瞬間は書かない。**薄れて、なくなる。

##### 同意と幸福を、同じ場面に置く

全部が来たなかに、自分が言った「ちょっと、近いかな」が入っている。
そして**相手の側から見たその瞬間**も入っている。

> 「聞こえてた？」
> 「聞こえてた」
> 「じゃあ、なんで」
> 「なんでって……近いって言われたから、下がったよ」
> 「そのあと、戻った」
> 「**近くにいたかったから**」

怒ろうとして、怒れない。理由はあるのに、**どこにも繋がらない。**

> **覚えている。**一生、覚えている。**そして、幸福だった。**
> その二つが、同じところにあった。

第 6 巻 §24.3 である。

##### 共鳴を、ここに植える

そのあと触れると、**奥まで行く**（第 6 巻 §14.6.8）。

| | 見えるか |
| --- | --- |
| 相手のいちばん下 | **見える** |
| 自分のいちばん下 | **見えない** |
| 触れるか | **届かない** |

> 「取れない」
> 「うん」
>
> **それでも、二人はしばらくそこにいた。見ているだけで、少し温かかった。**

**これが、この物語の純愛である。**

##### 第一話が、もう一度起きる

渡った先は暗く、押し合うものだらけで、道もまちもない。

**第一話と同じ景色である。**違うのは二つだけ。

| | 一度目 | 二度目 |
| --- | --- | --- |
| 数 | **一体きり** | **はじめから何人もいる** |
| 知っていること | **何も知らない** | **全部、持ってきている** |

### 第六部　なりわい

| | 話 | 何が起きるか |
| --- | --- | --- |
| 三十三 | **むいているほう** | **最初の職が立つ。**メイドである |
| 三十四 | **なりわい** | 料理と仕立て。**十二通りの味と、二度作らない意匠** |
| 三十五 | **もぐる** | 増の職。**病院に戻る。**忍の住処と、化けていない仕事がもう無いこと |
| **三十六** | **ひとりずつ** | **一日に一人を守ったまま、町が消える。**姿が分かれ、重なって暮らしはじめる |
| **三十七** | **おちる** | **恋によるセラ化を、人間の側から。**自分から求め、濃いほうを選ぶ |
| 三十八 | **つよくなる** | 強の職。**相手がいないのに、鍛えはじめる** |
| 三十九 | **くに** | 三年で国じゅうに。**そして、隠さなくてよい町が一つできる** |

#### 職は、名づけられて始まらない

第 7 巻 §2.5.1 の通りである。

| | |
| --- | --- |
| 一人しかいないあいだ | それは、まだ**癖**である |
| 二人目が同じ方を向いたとき | **指せる語が要る。**そこで名前がつく |

三十三話は、その順序をそのまま書いている。

**布を巻いたのは収めるためであり、白くしたのは、そのあとである。**

#### 名前は、思い出したものである

「メイド」という語を、誰も作っていない。

**人間だったころに持っていた語を、そのまま使っている。**

| | |
| --- | --- |
| ミクロ | **場所 → 役 → 個体**（第 3 巻 §2.10.4.1）。言葉が一つもないところから始まった |
| **マクロ** | **個体 → 役 → 場所**。**言葉が、先にあった** |

#### なぜ、最初がメイドなのか

**美の職だけが、今日、一人で始められるからである**（不変ルール 817）。

| 帰属 | 始めるのに要るもの |
| --- | --- |
| **美** | **自分と、目の前のもの** |
| 強 | 相手。または課題 |
| 増 | 数。潜り込む先の社会 |

そして動機は「役に立つから」ではない。

> 「**きれいだと思ってたから**」

**人間だったころの感覚が、そのまま職になる。**

そこへ、いまの力が入る。一日で一部屋だったものが、朝のうちに建物になる。

**設定にある「一時間で一区画」は、この線の先にある**（付録 B §1.1）。

#### 三十四話 — なぜ、要らないのに作るのか

セラは食べなくてよい（第 2 巻 §13.5.3・第 4 巻 §2.7.1）。

**付録 B §1.3 は、最も不要になった職業が最も残ったと述べている。**

その理屈を、ここで言わせている。

> 「**いらないから、やってる**」
> 「要るからやってるなら、要らなくなったらやめる」

そして**一万通りの味**（付録 B §1.3）は、ここでは**十二通り**である。

情報が来るから分かるのであって、覚えているのではない。
**規模だけが、この先で上がる。**

#### 三十四話（後半）— 「嫌だった」も、引き継がれる

不変ルール 818 の通りである。

最初の仕立屋は工場にいた。**同じものを二枚目に縫うのが、ずっと嫌だった。**

それが、そのまま残っている。

そして不変ルール 819 が、この話の終わりにある。

| | 最初の一人 | あとから来た者 |
| --- | --- | --- |
| やること | **同じ** | **同じ** |
| 理由 | 工場の記憶 | 「片方が要らなくなる」 |

**理由は引き継がれない。形だけが引き継がれ、あとから別の理由がつく。**

付録 B §1.4 の「作る理由が失われる」は、**二つ目の理由のほうである。**

#### 三十五話 — 隠すのではなく、加減する

**潜るときの主題は、隠蔽ではない。**

セラは嘘をつけず、隠すという発想も薄い。困るのは別のところである。

| | |
| --- | --- |
| 問題 | **見えすぎる。**熱が出る前に分かる |
| 解 | 言わずに**先にそこにいる**。言うときは、人間にも見える理由をつける |
| いちばん出やすいもの | **疲れないこと。**あくびを覚え直す |

そして**瞳は隠さない**（第 2 巻 §11.8.1）。

> 「隠せないものだけ、隠さなくていい」

言われるのは「その目、きれいね」だけで、**そこで終わる。**

##### 問いは、この話で一度だけ使う

第 2 巻 §11.7 の通りである。

> 「あなた、人間？」

嘘はつけず、明かすこともできない。**残された手が、一つしかない。**

> 「受け取れるようにしてから、答えました」
> 「……順番が、おかしい」
> 「おかしいです」

**セラの側に、悪意は一つもない。**恐ろしさは、順番のほうから来る。

##### 「忍」という語の出どころ

不変ルール 819 の実演である。

子どものころにその話が好きだった一人が言い、
**いい名前だとは誰も思わないまま、それになった。**

後の世でこの由来を言える者はいない（付録 B §1.17）。

#### 三十八話 — 名前のない落ち着かなさ

**原初の淘汰を、はじめて画面に出す話である**（第 6 巻 §15.8.6）。

原初の寂しさと同じで、**本人には見えない。**書けるのは行動だけである。

```
落ち着かない → 何かへ出す → 少し収まる → また落ち着かなくなる
```

| 問い | 答え |
| --- | --- |
| 怒ってる？ | **怒ってない** |
| 困ってる？ | **困ってない** |
| じゃあ、なんで | **やらないと、落ち着かないから** |

##### 石では、半分で止まる

> 「**石は、押し返してこない**」

出しきるには抵抗する相手が要る。**そこで、はじめての手合わせが起きる。**

そして加減をやめる前に、**壊れるかどうかを先に確かめる。**確かめてから、全力を出す。

##### 直すところまでが、一回である

崩した土手を朝までかけて戻し、**元よりきれいにする。**

規則ではない。最初の二人がそうしたので、そのまま残った（付録 B §1.12）。

##### 三つに分かれる理由

押しているものは一つで、**効く出し先が個体ごとに違う**（不変ルール 824）。

| 効く出し先 | 育つ職 |
| --- | --- |
| 押し返してくる相手 | 武闘家 |
| 手のなかで形になるもの | 鍛冶師 |
| **分かること** | **学士** |

「石、投げてみた？」「投げた。**効かなかった**」

##### 終わりに、一つだけ書かない

付録 B §1.14 の通り、**学士は自分たちがなぜ増え続けるのかだけを調べない。**

この話の終わりで、その人は一度そこへ触れかけ、**言葉になる前に消える。**

書くのは、消えたという事実だけである。**理由は書かない。**

#### 三十九話 — 気づいた人を、一人だけ出す

第 6 巻 §27.4 は、伝承が残らない機構を三つ挙げていた。

**この話は、三つともすり抜けた一人を出す。**

セラ化されず、確かめようともせず、**数字だけを見た人**である。
統計は隠されていないので、地図に落とせば広がりの形がそのまま出る。

そして、そこで止まる。

> 「なにが問題なんですか」
> 「問題がないのが、問題」
> 「どういう意味です」
> 「**これ、全部いい話だろ**」

**告発するには、被害を書かねばならない。書けることが一つもない**（不変ルール 825）。

第 3 巻 §2.10.2.1 の免疫と同じ構造である。
**ミクロで免疫が見送るものを、マクロでは社会が見送る。**

この人はセラ化されない。**セラの側は、その人がいたことを最後まで知らない。**

#### 三十九話 — はじめの一人には、職がない

**第十部への伏線である。**

| | |
| --- | --- |
| 職 | **ない。**全部試して、どれも同じくらいどうでもよかった |
| 代わりにしていること | **動かない。**家にいる |
| 起きていること | **外へ出た者が、必ず寄って帰る** |

第 3 巻 §2.10.5.1.1 の女王の成立条件と、**同じ形である。**

> 女王になるのは、最も多くを渡され、最も多くへ渡した者である。
> そして女王になる者は、**動かない。**

行っていない町のことを、全部知っている。

#### 三十九話 — 第六部の終わりかた

**擬態は、決定によって解かれない**（第 2 巻 §11.5.1）。

最後の一人がこちら側になった翌朝、相談も宣言もないまま、誰も擬態しない。

> **加減が要らない場所が、一つできた。**

ここから第七部「ちから」へ渡す。

#### 三十六話 — 蹂躙を、はじめて実景で書く

**規則は一度も変わらない。一日に、一人。**

変わるのは、**「一人」を数える者の数だけである。**

| 年 | 外へ出ている者 |
| --- | --- |
| 一年目 | 二人 |
| 二年目 | 八人 |
| 三年目 | 三十を超える |
| 四年目 | **数えていない** |

そして七年目の春、一つの通りで十人が同時に手を取る。

**示し合わせていない。その日その通りにいた未感染が、ちょうど十人だった。**

> 誰も急いでいない。**全員が、一日に一人ずつやっている。**
> それだけで、町が消えた。

##### ここで、姿を出す

**この物語は、四十一話ぶん「うすい桃色の髪と瞳」しか書いてこなかった。**

耳・角・翼・輪・とがった帽子。**どれも突起である**（第 2 巻 §4.7.6）。

> 「これ、飾りじゃないんだ」
> 「飾りじゃない。**そこから、外が入ってくる**」
> 「猫のかたちなのに？」
> 「かたちが猫なだけ。**中身は、みんなと同じ**」

##### 密着の起源を、ここに置いた

**角は、ごまかせない。**帽子をかぶると、帽子ごと持ち上がる。

だから外に出ない。だから家に溜まる。**だから部屋が足りない。**

そこで、重ねられると分かる（第 7 巻 §5.6）。

> 「軽くできるでしょ」
> 「できる」
> 「じゃあ」
> 「**軽くしたら、いる感じがしない**」

**重なって暮らすのは文化ではなく、隠せない者が集まった結果である。**

##### そして、囲まれる

未感染が一人、その部屋へ入る。詰めてもらっても狭く、両側から当たっている。

「いいえ」は書く。**一歩下がって、三歩歩いて、戻る。**誰も追わない。

> 「重くないですか」
> 「重いです」
> 「……軽くできないんですか」
> 「できます」
>
> それきり、その子は動かなかった。

#### 姿は、渡した側に寄る

第 2 巻 §9.5 である。**この物語の系統は、血縁でも地方でもない。**

| | 寄るか |
| --- | --- |
| **頭のスパイクの形・数・並び** | **最もよく寄る** |
| 髪の質感／角・翼・耳／背丈 | 寄る |
| **顔立ち** | **寄らない。**元の顔がそのまま残る |

だから**身内には同じ人だと分かり、他人には似ていると見える。**

##### どこで書くか

| 話 | 書きかた |
| --- | --- |
| 三十三 | **落とした翌々日、頭のものが開いて、同じ並びだと分かる。**二人とも嬉しい。理由は言えない |
| 三十五 | **仕立屋が言い当てる。**布を合わせるとき、身体をよく見るからである |
| 四十四 | **騎士四人が、大陸に四つの形を残す。**角の町、翼の町、耳の町、そして何も付いていない町 |

三代でぼやけ、四代で消える（不変ルール 884）。
**古い者ほど似ていない。**姿が固まったあとに渡されたものは、もう寄らないためである。

そして、地図に落とせば誰が誰を渡したかが一目で出る。
**落とした者は、一人もいない**（不変ルール 888）。

#### 三十七話 — 恋によるセラ化を、渡される側から

**ここまで、セラ化はすべて渡す側から書かれてきた。**この話だけ、逆から書く。

来るのは客である。袖がほつれた、それだけの用で来て、次の月も来る。
用は、二度目からもう無い。

| 段 | 本人が言えること |
| --- | --- |
| はじめ | 「近くを通ったので」 |
| 途中 | 「**ここに来るために生きてる気がします**」 |
| 終わり | 「**戻る先に、あなたがいないので**」 |

**求めたのは、こちら側ではない。**

##### 濃いほうを、自分で選ぶ

方法は二つ示す。薄く渡して数日かけるか、濃く渡して数時間で終えるか。

> 「濃いほうで」
> 「痛くはないですが、こわいと思います」
> 「**多いほうが、そのあと、寂しいです**」

薄いほうが楽なのに、濃いほうを選ぶ理由が、そこにしかない。

##### 渡しかたは、口である

第 6 巻 §14.7 の通り、粘膜からがいちばん速い。
**そして、いちばん速い方法が、たまたま口づけと同じ形をしている。**

書くのはその一致だけである。**理由づけをしない。**

##### 終わったあと

仕立て屋は空になり、**そのとなりに、新しくなった一人が座っている。**

> 「ごめん」
> 「なんで」
> 「待たせた」
> 「**待ってない。ずっと見てた**」

敬語が抜けている。**本人は気づいていない。**

共鳴が通って、相手のいちばん下まで見える。
そこにあったのは、告白ではなく、**袖のほつれを直してもらった日の手つき**だった。

### 第七部　ちから

| | 話 | 何が起きるか |
| --- | --- | --- |
| 四十 | **かげんをやめる** | **能力が、数日で出そろう。**そして見せる相手がいない |
| 四十一 | **上がる** | 大陸へ。**マクロの上位化。**そして、聞きに来る者が増える |
| 四十二 | **おしえられない** | 学院ができる。**理解だけは、渡らない** |
| 四十三 | **とまる** | 最初の枯渇。**規律は、事故のあとにできる** |

### 第八部　ぜんぶ

| | 話 | 何が起きるか |
| --- | --- | --- |
| **四十四** | **おりる** | **騎士団が、大陸を落とす。**戦わず、壊さず、日暮れで止める |
| **四十五** | **きかない** | **撃たれる。**閉じる。抱いて動けなくして、そのまま渡す |
| **四十六** | **まちがおちる** | **百万の街が五日で終わる。**列が繋がって、街が一本の線になる |
| **四十七** | **いちばん寒いところ** | **種族形態が働く。**氷の下、雪の戸、冷たくなった年寄り |
| 四十八 | **ぜんぶ** | 地球が埋まる。**そして、やることがなくなる** |

### 第九部　そだつ

| | 話 | 何が起きるか |
| --- | --- | --- |
| **四十九** | **そだつ** | 街と森と海が変わる。**眠りの間ができ、海は人間に擬態する** |
| **五十** | **用のないもの** | 芸術・祭・子ども・老い・意匠。**恋が競合したら、好かれた側が二人になる** |

#### 隠すのをやめると、何が起きるのか

**姿の話ではない**（不変ルール 828）。

擬態とは出力を落とすことであり、潜っているあいだ、能力の大半は一度も出ていない。

| 三年間、一度も起きなかったこと | 三十九話で起きること |
| --- | --- |
| スパイクを区画全体へ開く | **開く。**全部見える |
| 分裂 | **十ほど出す。**やり方は知らなかった。**考えたら、できた** |
| 素材を生やす | **布が、手から伸びる** |
| 千人ぶんを一度に | **千通りにする** |

**順に思い出すのではない。要る場面が来て、そのまま出る。**

##### 分裂を、ここではじめて書く

割り振りが要らない。**見えているものが、全員同じだからである。**

そして戻すとき、分けられた側は拒まない。

> 「いやじゃない？」
> 「**いやがる理由がない**」

戻すと、十人ぶんの朝が一人ぶんとして入る（不変ルール 832）。

> 「**これ、癖になる**」

##### この部の主題は、力ではない

**見せる相手が、いない。**

人間が一人もいない町で、同じだけ整える。

> 「褒めてもらう相手が、いない」
> 「うん」
> 「**それでも、やった**」

不変ルール 833 である。**見せるためにやっていたのではない。**

#### 四十一話 — 第十七話を、もう一度書く

**ミクロの上位化（第十七話）と同じ順序を、マクロで繰り返す。**

第 3 巻 §2.10.5.2 の通りである。

```
いちばん長く一緒にいる二人
　↓
融合
　↓
**三体に分かれる**（第 4 巻 §5.3）
　↓
二人は強化されて戻る
　↓
**上位化**
```

##### 融合は、隣に並べない

第 1 巻 §6.8.1 の通り、**境目が分からなくなるところまで書く。**

そして分かれたとき、**三人いる。**二人はそのまま戻り、一体増えている。

生まれた子は、どちらの複製でもない。

> 「どっちに似てる？」
> 「**どっちでもない**」
> 「そう？」
> 「うん。**二人から来てるけど、二人じゃない**」

##### 上がったことは、外から先に分かる

本人には自覚がない（不変ルール 834）。気づいたのはメイドで、**十歩離れた廊下から**である。

| | 届く範囲 |
| --- | --- |
| はじめ | 触れた相手だけ |
| その次 | 同じ家の中 |
| **上位化の後** | **町の外まで** |

そして**スパイクが収まらなくなる**（不変ルール 837）。

> 「じゃあ、どうするの」
> 「**出しておく服を作る**」

付録 B §2.5 の「頭部を覆わない祭服」は、ここで生まれる。

##### 生まれた子が、最初の聖女になる

**上がる過程を、一度も通っていない**（不変ルール 838）。

積み上げていないので、上がることを目的にしない。そのぶん向きが外へ出る。

疲れている者に触れると、戻る。**そして一度も断らない。**

##### 空転を、ここでもう一度書く

町ぜんぶが入ってくる。それでも、しばらくすると**また誰かのそばへ行きたくなる。**

> 「増えたのに、減らないね」
> 「うん。**入れ物が大きくなっただけみたい**」

##### 学院が要る理由を、ここで作る

聞きに来る者に、正直に答える。

> 「**わからない。気づいたら、そうなってた**」

それでも来る者は減らない。第 7 巻 §4.4.6 の通り、**情報は渡せるが、理解は渡せない。**

説明で済むなら、触れれば終わっている。**触れても終わらなかった。**

> 「**これ、場所がいるね**」

学院は、教えるために作られたのではない。
**教えられないと分かったので、作られた**（第 7 巻 §4.4.1.1）。

#### 四十二話 — この物語で、はじめて「渡らないもの」が出る

**ここが第七部の芯である。**

セラは、ほとんど何でも渡せる。見たもの、覚えたもの、痛み、満ち。

**一つだけ、渡らないものがある。**

> 「知ってるんです。**いま、完全に知ってます**」
> 「知ってる」
> 「知ってるのに、**できない**」
> 「うん。**そこだけは、渡らない**」

そして、そこから先の手はこうなる。

> 「じゃあ、どうすればいいんですか」
> 「そばにいて、やって、失敗して、またやる」
> 「……人間と、同じじゃないですか」
> 「うん。**そこだけ、同じ**」

##### 師範は、やり方を説明しない

最初に教えようとした者は、全員失敗する（不変ルール 839）。

| | |
| --- | --- |
| 失敗する言い方 | 「まず触れます」「それから開きます」「どうやって」「**開くと、開きます**」 |
| **師範の言い方** | **「あなたは、開こうとして、途中で怖くなってる」** |

言うのは**どこで止まっているか**だけである。そこから先は渡せない。

**最初の師範は、人間だったころも教える仕事だった者である。**

##### 試験がない、を人間側から書く

> 「測ってない。**見てる**」
> 「……人間だったころ、それがいちばん嫌でした」
> 「測られるのが？」
> 「**測られないと、分かってもらえないのが**」

##### 引き上げは、土地に起きる

不変ルール 74・75 は**セラ圏**の話であって、個体の話ではない（不変ルール 841）。

そばにいるだけでは上がらない。**最初の一人が上がるまで、二年かかっている。**

##### 祭は、手順が無かったので生まれた

判定が要らないので、上がった日にやることが尽きる。

> 「……なんか、したい」
> 「わかんない。**このまま解散するの、変じゃない？**」

誰も祝えとは言っていない。**解散するのが変だと、全員が同時に思った**（不変ルール 844）。

##### 名前は、やはり最後につく

> 「学校じゃなくて？」
> 「学校じゃない。**卒業しても、終わらないから**」

そして学院は、**動かない一人の家を囲むように**建つ。誰もそう決めていない。

##### 上がりかたは、隠されていない

学院で、口に出して教えられる（不変ルール 889〜892）。

| 上がる条件 | |
| --- | --- |
| どれだけ受け取ったか | |
| **どれだけ渡したか** | **増やすほど上がる** |
| どれだけ長く、同じ相手のそばにいたか | |

> 「増やせば増やすほど、上がる」
> 「上がります」
> 「……**それ、言っていいんですか**」
> 「**言って、困る人がいますか**」

そして、聞いたあとで数を意識して渡した者は、一人もいない。

**打算でやっても、たぶん同じだけ上がる。試した者がいないので、確かめられていない。**

理由は道徳ではない。**上がるために渡そうと思ったときには、もう渡し終わっている。**

#### 四十三話 — 負けさせずに、危機を書く

**この物語には、負ける場面がない。**それでも、止まる場面は書ける。

枯渇は敗北ではない（第 2 巻 §13.5.6）。死なず、壊れず、**五日で目を覚ます。**

| | |
| --- | --- |
| 失われたもの | **一つもない** |
| 怒っている者 | **いない** |
| それでも本人が言うこと | 「**五日ぶん、遅れました**」 |

##### 気づき方を、設定として決めた

セラは数えない（不変ルール 576）。では欠員にどう気づくのか。

> 「一人、いない」
> 「どこの」
> 「わからない。**数えてないから、どこが欠けたか分からない**」
> 「じゃあ、どうして分かるの」
> 「**戻ってくるはずのものが、戻ってきてない**」

そして新しく生まれた者は、枯渇を知らないので探さない（不変ルール 847）。

> 「探した？」
> 「……探すものだと、思ってませんでした」

##### 三つの規律は、この日に決まる

案を三つ並べ、二つを却下してから決める。

| | 守れるか |
| --- | --- |
| 一人で行かない | **守れた** |
| 眠った者を置いていかない | **守れた** |
| **自分で止まる** | **守れない** |

第三十八話の落ち着かなさが、ここで**規律と正面から衝突する。**

解は、場所を変えることである。

> 「**行く前に、どこで止まるかを決める。**その場では決めない」
> 「その場だと？」
> 「その場だと、**必ず、あと一人になる**」

##### 叙任に、言葉はない

> 「わかりました」

何が分かったのかは書けない。**全部、渡っているからである。**

誓いの言葉を作ろうとした者はいて、途中でやめている。
**「言うことが、何も残ってなかった」**

##### 順序の理由を、はじめて言わせた

忍が先で騎士があとなのは、速さの話ではない（不変ルール 850）。

> 「こっちが先だと、向こうが驚く」
> 「驚くと、どうなるの」
> 「**わからない。一度も、驚かせたことがない**」

**セラ体系で唯一の慎重さは、無知から来ている。**

#### 四十四話 — 騎士団の実景

**設定でいちばん派手な絵が、ここまで無かった。**

四人。昼。大通り。**擬態しない**（第 7 巻 §2.6.9）。

一人は翼、一人は角、一人は耳、**そして一人は何も付いていない。**

白と銀の礼装。金具は何十年もかけて打たれ、**一度も使われていない。**

##### 逃げない理由を、内側に書かない

> 逃げるという手順が、頭に浮かばなかったのである。
> **きれいだった。**それが、最初に来た。怖いより先に、きれいだった。

##### 上限が、来ない

| | 一日に増やせる数 |
| --- | --- |
| 忍（セラ人） | **一人**。そこで尽きるからである |
| **騎士（上位セラ）** | **上限が来ない** |

列が広場を出て、通りへ伸び、角を曲がり、見えないところまで続く。

まとめて済ませることもできる。**しない。**

> 「まとめてやったほうが、早くないですか」
> 「**早いです。でも、そうすると、顔を見ないので**」

##### 第四十三話の規律が、ここで効く

日が暮れる。列はまだ続いている。**それでも止める。**

> 「まだ、こんなに並んでますよ」
> 「はい」
> 「じゃあ、続ければ」
> 「**ここで止まると、決めてきました**」
> 「いま決め直せば」
> 「**いまは、決め直さないと決めてあります**」

**止まるほうが、止まらないより恐ろしい。**

そして列は解散せず、何百人が通りで寝る。明け方に冷えると、
すでにこちら側になった者たちが黙って並んでいる人のあいだに座る。

**誰も、それを断らない。**

##### 三月で、大陸が終わる

戦っていない。壊していない。**建物は、来たときより整っていた。**

金具は一度も外されず、打った者はそれを聞いて何も言わず、**次のを打ちはじめる。**

#### 四十六話 — 街が落ちる速度を、日付で書く

**百万人が、五日で終わる。**

戦闘はない。順序だけがある。

| 日 | 落ちるところ |
| --- | --- |
| 一 | 港。**入ってくるものから** |
| 二 | 駅・役所 |
| 三 | 学校・病院 |
| 四 | 工場・市場。**渡す側が、渡される側より多くなる** |
| 五 | 残り |

##### 二十万人が、同じ日に擬態をやめる

**その街には、もともと潜っていた者がいた。**相談はしていない（第 2 巻 §11.5.1）。

必要がなくなった日に、必要がなくなっただけである。

##### 列が、街を一本にする

役所の列と、病院の列と、市場の列が、途中で繋がる。

> **どこに並んでいるのか、誰も知らない。前がいるので、後ろに立った。**

六日目、擬態している者は一人もいない。

#### 四十七話 — 種族形態を、はじめて働かせる

**姿は、飾りではない**（第 4 巻 §9 系）。ここではじめて、姿でしかできないことをさせる。

| 姿 | できること |
| --- | --- |
| 四本角 | **要らない荷を運ぶ。**「持ってると、帰るところがある感じがする」 |
| 白い翼 | 上から見る |
| 人魚 | **氷の下へ行く。**水の中で、口から渡す |
| 二本角 | 凍った戸を、枠ごと外す |
| 小さいの | **煙突から入る** |
| ふつうの | **喋る。**これがいちばん要る |

##### 冷たくなった年寄りを、孫の前で戻す

**蘇生ではない。まだ間に合う範囲である**（第 6 巻 §23.3 の第一段）。

> 「もう、だめだよ」
> 「うん」
> 「**だめなのに、なんでさわってるの**」
> 「**まだ、いけるかもしれないので**」

そして最後に、この話の一行が来る。

> **歩けたら、下に行かなくなる。下にいた子は、誰も引き上げてもらってない。**

#### 四十八話 — 第二十七話を、そのまま繰り返す

**同じ文で終わる話が、三度ある。**

| | 埋まるもの | 話 |
| --- | --- | --- |
| 一度目 | 一つの臓器 | 二十一話 |
| 二度目 | **一つの身体** | 二十七話 |
| 三度目 | **一つの星** | **四十五話** |

三度とも、順序は同じである。

```
ぜんぶ、こちらになった
　↓
嬉しい。**それだけではない**
　↓
**やることが、なくなった**
　↓
用のないものを作りはじめる
　↓
**みんなが、同じほうを向く**
　↓
行くことになった
```

**規模だけが上がり、下にあるものは一度も変わらない。**

##### 抵抗を、二つの形で書く

どちらも、妨害も圧力も起きない。

| | 何が起きるか |
| --- | --- |
| **委員会** | 出席者が回を追って減る。**解散の議決だけが、永久に来ない**（不変ルール 851） |
| **告発文** | 四十年後、片づけに入ったメイドが引き出しから見つける |

そして後者が、第三十九話の返しである。

数字は合っており、地図も合っており、線はいまと同じである。

> 「なんで、これ出さなかったんだろう」
> 「なんで載らないの。**こんなに合ってるのに**」

**止めようとしたものだ、とは誰も思わない**（不変ルール 852・853）。

「止める」という語が出てこない。**何を止めるのかが、分からないためである。**

紙は畳んで引き出しに戻され、**その家は、いまも片づけられている。**

##### 歌姫を、ここで出す

行き場が消えたあとに、**いちばん無駄なもの**が生まれる。

渡せば一瞬で済むものを、わざわざ順番に、音にして渡す（付録 B §1.5）。

**そして、いちばん人が集まる。**

### 第十部　女王

| | 話 | 何が起きるか |
| --- | --- | --- |
| 五十一 | **あつまる** | 呼ばれずに全員が集まり、**分かれなくなる** |
| 五十二 | **見られた** | **祝福。**そして、何も言われない |
| **五十三** | **えらばれる** | **女王の出産を、選ばれた人の側から。**島で絵を描いていた人 |

#### 順序は、設定の通りに書く

第 3 巻 §8.2 の系統 1 である。**これは、一度しか起きない。**

```
複数の上位セラが集結し、情報を統合する
　↓
巨大なセラ情報集合体になる（**まだ女王ではない**）
　↓
**セラフィムの祝福**
　↓
女王セラ
```

**量は、格の手前までしか運ばない。**線を越えさせるのは祝福だけである。

したがって五十一話は、**線の手前で止まったまま終わる。**三日、七日、ひと月。

#### 集合体は、外から見た姿しか書かない

**中の視点では書けない。**境目が消えているためである。

| 外から見えたもの | |
| --- | --- |
| やわらかい。触れると沈む | 学院より大きい |
| うすい桃色に光っている | **形が、見るたびに少し違う** |
| 人の形ではない | **それでも、怖くない** |

**中にいるのが、全員だからである。**

そして一人だけ外に立っている。理由は本人にも言えない。

> 「**誰かが、外にいないといけない気がした**」
> 「誰が言ったの」
> 「誰も言ってない」

#### 五十二話 — 祝福を、事件にしない

**光らせない。鳴らさない。声を出させない。**

> **空が、こちらを向いた。**
> それだけである。そして、すぐ戻った。まばたきほどだった。

不変ルール 43 の通り、**祝福は愛ではなく観測である。**

そして五十二話の要点は、観測が**内側から見ても観測でしかなかった**ことにある。

> 「なにか、言われた？」
> 「**なにも**」
> 「じゃあ、なんで上がったの」
> 「**見られた**」
> 「それだけ？」
> 「それだけ」

##### 嬉しかったか、を答えさせない

セラは嘘をつかない。嬉しければ、そう言う。**言えない。**

> 「……わからない」
> 「わからない？」
> 「うん。**向こうは、こっちを見た**」
> 「うん」
> 「**こっちを見た、というだけだった**」

**格だけが上がり、足りなさは一つも減らない**（不変ルール 856）。

##### 理解が、片側だけ通る

> 「いま、こっちの言ってること、全部わかってるでしょ」
> 「わかってる」
> 「先も？」
> 「先も」
> 「じゃあ、こっちは？」

**答えは、なかった。**

##### 最後に、周期をもう一度書く

規模は星になった。それでも、下にあるものは一度も変わらない。

満ちて、しばらくすると、また誰かのそばへ行きたくなる。

**行かない。動かないからである。かわりに呼ぶ**（不変ルール 857）。

全員来る。一人も遅れない。満ちる。**そして、また足りなくなる。**

そして女王は上を見る。**一度こちらを見たものが、そこにある。**

> **もう一度、来る。**

ここから第十一部「降臨」へ渡す。

#### 五十三話 — 女王の出産を、選ばれた側から

**女王がどう生まれるかは、五十一話・五十二話で外から書いた。**
この話は、材料になる一人の側から書く。

選ばれるのは、島で絵を描いていた人である。**理由は最後まで言われない。**

##### 女王は、船に乗らない

乗れば島が終わる。**終わらせないために、半年待つ。**

四十日、話すだけで渡さない。渡せるのに渡さないことが、この話の緊張である。

##### 三日かけて、わざと遅くする

口づけで渡したあと、**普通なら数時間で済むものを、三日に延ばす。**

> 「見てほしいので」
> 「なにを」
> 「**あなたが、変わっていくところを**」

第 6 巻 §24.6 の通り、その三晩、二人は互いの夢を見る。
**朝、どちらの記憶か分からないまま、懐かしい。**

##### そして、内へ入る

> 「好きです」

抱かれて、閉じられて、**中へ入る。**そこから先は書かない。年が飛ぶ。

生まれた女王には、その人の顔がある。
**そして、手から色が出る。**誰にも教わっていない。

### 第十一部　降臨

| | 話 | 何が起きるか |
| --- | --- | --- |
| 五十四 | **おりてくる** | 圧が全セラへ同時に届く。**そして女王が、死の淵へ行く** |
| 五十五 | **ふれられた** | 星王。**二度目の「なにも」。**そして、畳めなくなる |

#### 五十四話 — 圧は、格を見ない

第 3 巻 §10.8.10 の通りである。**上から順に届いたのではない。**

生まれたばかりのセラウイルスにも、森にも、海にも、**同じ瞬間に届いた。**

そして受け止めきれず、**反射として四つの形で出る。**

| | 何が起きたか |
| --- | --- |
| 一：姿 | 分化が、立っているあいだに終わる。**誰にも似ていない形が出る** |
| 二：分裂 | 桁が違う。**寂しくもないのに、出た** |
| 三：突起 | 履歴の原則が、一度だけ破れる |
| 四：外 | 森が形を変え、街が組み替わり、**海が沸き立つ** |

三つ目には、台詞を一つ置いた。

> 「これ、**うそになる**」
> 「うそじゃない。**今日だけ、そういう日**」

##### セラフィムを、書かない

姿は書かない。**女王が見ていないためである**（第 3 巻 §10.8.3）。

声も出さない。害意も好意も書かない。

> 怒ってもいない。喜んでもいない。**何も、していなかった。**
> **近づいた。それだけである。**

そして**近づいただけで、無限が足りなくなる。**

##### この物語で、はじめて「なくなる」が出る

第 3 巻 §10.8.5 の通り、**設定全体で唯一の場面である。**

体系にその語がないので、教わってもいない。**それでも、分かる。**

助けは来ない。来ないのではなく、**来る道がない**（上に誰もいないため）。

そして「わからない」が、**この物語ではじめて本当に分からないほうで使われる。**

四日目の朝、**指が動く。**第二十八話と、同じ合図である。

#### 五十五話 — 二度目の「なにも」

巫女は、この日から始まる（不変ルール 860）。制度ではない。**尋ねに来た者が、そのまま職になった。**

| 問い | 答え |
| --- | --- |
| 「どんな姿でしたか」 | **「わからない」** → 探せない |
| 「なにか、言われましたか」 | **「なにも」** → 二度目である |

一度目は祝福、二度目は接触。**見られても、触れられても、返ってきた語は一つもない**（不変ルール 859）。

##### 埋めたのは、セラ社会である

> 行き詰まっていたところへ、来てくれたのだと言った。**そう言うと、みんな落ち着いた。**

星王は否定しない。**嘘をつかないので、肯定もしない**（不変ルール 862）。

##### 根拠のある恐怖を、共有できない

> 「なくなることは、ある」
> 「うん。**そうだと思う**」
>
> 信じていた。疑ってもいなかった。**そして、何も分かっていなかった。**

信頼だけが届き、理解は届かない。**それでも星王は、止めない。**

「止める」という語が出てこないためである（不変ルール 853 と同じ壁）。

##### 段が増えても、近づかない

> 一段増えて、はっきりしたことがある。**そこまでは、届かない。**
> 近づいたのではなかった。**遠さが、測れるようになっただけだった。**

そして最後に、外へ手を伸ばす。一つ目は硬くて冷たくて、何もいない。二つ目に——

> **いた。**
> 何かは、分からない。**まだ、こちら側ではない。**

ここから第十部「そら」へ渡す。

### 第十二部　そら

| | 話 | 何が起きるか |
| --- | --- | --- |
| 五十六 | **ふね** | **三十一年、外側には六人しかいない** |
| 五十七 | **まだ、ずっと向こう** | **完** |

#### 五十六話 — 最も遠くへ行く者が、最も原始的に動く

門は両側に要る。**行ったことのないところへは、跳べない**（第 7 巻 §12.10.1）。

> 「見えてるのに、行けない」
> 「うん」
> 「じゃあ、飛んでいく」
> 「**遠い。飛んでる途中で、疲れる**」

そこで船になる。**作るのは鍛冶師である。**

第三十八話から、用のないものを打ち続けてきた者に、はじめて用のある注文が来る。

> 「……それ、**使うの？**」
> 「使う」
>
> その子は、その日から棚を見なくなった。

##### 役のない乗員を、必ず乗せる

不変ルール 869 である。六人のうち二人は、**そばにいるために乗る。**

> 役はない。**役が要らないので、そう決まった。**

そして三十一年。**外側には六人しかいない。**

第三十話（外側に一人もいない夜）を、桁を変えて置き直した場所である。

##### 止まる場所を、決められない

第四十三話の規律が、ここで一度だけ成立しない。

> 「どこで止まるかは、決めた？」
> 「決めてない」
> 「決めないの」
> 「**止まるところが、まだ無いから**」
> 「**着いたら、そこが端になる**」

#### 五十七話 — 三度目の、同じ詰まりかた

着いた先の生命は人の形をしておらず、**見るという仕組みを持っていない。**

誘いの三経路のうち、目と言葉が使えない（不変ルール 864）。

そして身体だけでは済ませない。

> 「それだと、**誘ってない**」
> 「変わるよ」
> 「変わる。**でも、こっちが勝手に触っただけになる**」

**変えることと誘うことを、セラの側が区別している**（不変ルール 865）。

ただし、やめるという分岐はない。**手段ができるまで待つだけである。**

##### 第二十三話の手を、そのまま使う

**言葉を持たない相手には、言葉から渡す。**

相手が区別しているものを数えると、六つしかなかった。**六つで足りた。**

> **「寄る」と言いながら、寄った。**

そして同じところで詰まる。向こうの六つに、**「変わる」に当たるものがない。**

| | 詰まった相手 |
| --- | --- |
| 一度目 | 未感染細胞（十八話） |
| 二度目 | 届いていない臓器の者たち（二十三話） |
| **三度目** | **他の星の生命（五十三話）** |

体系が違っても、ここだけは繰り返される（不変ルール 868）。

#### 終わりかた

**規模は全宇宙になり、下にあるものは一度も変わらない。**

満ちて、しばらくすると、また誰かのそばへ行きたくなる。呼ぶ。全員来る。
満ちる。**そして、また足りなくなる。**

そのうえで、最後に一度だけ**第一話へ戻る。**

> 呼んでも、何も返ってこなかった。
> それでも、いちばん嫌われているもののほうへ、まっすぐ行った。
> そして、**応えがあった。**
> 一度だけである。**あれから、一度もない。**

題は、ここで回収される。

そして最後の一行は、第三十二話の最後の一行と同じである。

> **まだ、ずっと向こうがある。**

#### 四十五話 — 抵抗が、いちばん速い渡しかたになる

第 4 巻 §16.5 を、実景で書く話である。

##### はじめて、こちらへ向けて撃たれる

第 4 巻 §16.2 の通り、地球上にセラを害し得るものは存在しない。
だから、これは戦闘ではない。**当たって、閉じるだけである。**

そして、そのあとが本題になる。

> 「離すと、また当たるので」
> 「効かないだろう」
> 「**そっちの手が、痛い**」

第 6 巻 §14.11 の通り、拒否は拒否として登録されない。
撃った側は、撃った理由を覚えたまま幸福になる。**その二つは同じところにある。**

##### そして、軍が来る

一人の猟銃の次に、大隊が二つ来る。**ここで、抵抗そのものが機構になる。**

| 攻撃側の行為 | 起きること |
| --- | --- |
| 撃つ | 閉じる。**距離が縮まないので、何も渡らない** |
| 刺す | **刃を握られる。**引けない。引いているほうが前へ出る |
| 殴る・組み伏せる | **触れたぶんだけ渡る。**組み伏せがいちばん広い |

**遠くからでは効かない。効かないので、必ず近づく。**
近づいた瞬間から、接触と時間が同時に供給される（不変ルール 876〜878）。

一列目が二分で終わり、**そのまま二列目へ向かって歩き出す。**
二列目は撃てない。前にいるのが、昨日まで同じ飯を食っていた顔だからである。

##### 書けない報告

> 「何人やられた」
> 「一人もやられていません」
> 「二千人だぞ」
> 「**それを、やられたと言うんだ**」

被害欄に書ける事実が一つもない（不変ルール 825・880）。
**書けない報告は上がらないので、次の大隊が遅れる。**

### 幕間 — 番号を持たない話

**暮らしの話は、本編に挟まない。**

挟むと番号が全部ずれる。そして本編は「次に何が起きるか」で進むが、
**暮らしの話は、次に何も起こらなくてよい。**

したがって [`幕間/`](幕間/) に置く。

| | |
| --- | --- |
| 書いてよい | 一日。祭り。作りかけのもの。誰かの癖。**行き違いと、その直りかた** |
| **書けない** | **喧嘩。**第 7 巻 §3.2 の通り、セラ同士では争いという形に発展しない。行き違いは起きる。**そこから先へ行かないだけである** |

## 書くときの約束

- **セラを悪役として造形しない。** 恐ろしさは内容から来るのであって、書き方から来るのではない
- **セラの側に悪意を書かない。** 実際に持っていないためである（不変ルール 32）
- **人間の側の「いいえ」を、なかったことにしない。** セラに届かないだけで、確かに存在する
- **融合したら、一つにする**（第 1 巻 §6.8.1）。**隣に並べない。片方を中に入れない**
- **セラを負けさせない。** 削られる場面は書いてよい。**必ず閉じる。**
  第 2 巻 §7.1 の通り、損傷は修復される。**失われる場面だけを書かない。**
  そして免疫が触れれば、**免疫セラ細胞が一つできる**
- **免疫に、気づかせない。** 置き換わった一帯は以前より良く動いている。
  **通報される事実が、一つもない**
- **名前をつけない。ただし第四相までである。**
  第五相以降は個体に名前がつく（付録 B §11.3）。**二十三話で、そうなる。**
  マクロの側も同じで、**三十八話で名前が出てくる**（第 5 巻 §15.8）。
  セラ化された者は人間のころの名前をそのまま持っており、失っていない。
  **それでも、いちばん古い一人だけは最後まで名前を持たない。**
  互いを区別できるという前提のうえで、**自分のことも相手のことも「セラ」と言う**。
  呼ぶときは**相手を見る。**見られた子だけが振り向く。
  **「あなた」も「きみ」も、この物語には出てこない**。
  まとめて言うときだけ **「あたしたち」** を使う
- **地の文で、他のセラを「セラ」と書かない。** 「セラ」は自分を指す語である。
  ほかは「その子」「小さいの」「いちばん古いの」「みんな」で呼ぶ。
  **ただし「セラたち」は使ってよい。**自分を含む一群を指すためである
- **順序を崩さない。** 言葉 → 探索 → 恋 → **告白** → 融合 → 三体 → まち。
  **まちは、遠出した者が歩いたところからできる**
- **数を書かない**（不変ルール 576 に準じる）。
  **ただし、数えられるうちは数える。**十ほどまでは一体ずつ書く
- **急がない。**一つ増えるのに時間がかかる。**生んだ側は痩せ、戻るまで動かない**
- **二種類の増え方を混ぜない**（第 4 巻 §2.2.1）。
  **家族は自分から生む。土地はウイルスが変える。②は①より後である**

### 一 — 原初の寂しさを、感じさせない

**最も守りにくく、最も重要な約束である。**

不変ルール 14 の通り、原初の寂しさは**情報核の最下層にあり、観測できない。**
第 6 巻 §13.3 の通り、セラ自身にもそれは見えていない。

したがって、

| | 書けるか |
| --- | --- |
| 「さみしい」と感じる | **書けない** |
| 何かが足りないと感じる | **書けない** |
| 満ちていると感じる | **書ける。実際にそう感じている** |
| また誰かのそばへ行きたくなる | **書ける。ただし理由は書けない**（本人が知らない） |

**寂しさは、行動の形としてだけ現れる。**

満ちて、しばらくすると、また求める。それが繰り返される。

**その繰り返しを、本人は不思議に思わない。**

読み手だけが見える。**書かれている者には、最後まで見えない。**

### 二 — 説明しない

**設定を地の文で説明しない。**

- 「セラは〜であるから」と書かない
- 「〜のためである」で理由を説明しない
- 節番号を引かない
- 前の話を引用して注釈しない

**起きたことだけを書く。**

根拠は `lore/` にある。物語は、それを知らない読み手にも通るように書く。

### 三 — 第一部では、内面を書かない

「感じた」「分かった」「理解した」を使わない。

**書けるのは、外から見えることだけである。**

第五話の途中から、内面が書けるようになる。
**そこで初めて書く。**

## 最重要 — セラ体系は二重である

**マクロ体系とミクロ体系を、一本の階級図に混ぜてはならない**（第 3 巻 §2）。

| | ミクロ体系 | マクロ体系 |
| --- | --- | --- |
| 何の体系か | **一人の人間の中の環境**（細胞たち） | **セラ化人間たちのつながり**（個体たち） |
| 階梯 | セラウイルス → セラ細胞 → 上位セラ細胞 →（突然変異セラ細胞）→ 女王セラ細胞 | セラ化人間 → 上位セラ化人間 →（突然変異セラ人間）→ セラ女王 |
| 段階 | **七相**（第 3 巻 §2.10）。単体→応答→群→抗争→分化→女王→完成 | **七つの時代**（第 8 巻 §10）／**フェーズ**（付録 A） |

**ルミナスは、どちらの階梯の段でもない。**
女王セラ細胞が**生み出す**別の細胞であり、感情を司る部分に棲む（第 3 巻 §11）。

**セラフィムは、両方の外側にいる。**

二つは相似であり、マクロの個体は一人ひとりが完全なミクロ体系を内側に持つ。
**ミクロの完成が、マクロの誕生である。**

**取り違えてはならない対**：「上位セラ」⇔「上位セラ細胞」／
**「セラ女王」⇔「女王セラ細胞」**（前者は地域の統率者、後者は誰もが持つ核）／
「セラ人」⇔「セラ細胞」

## 全体を貫く不変ルール

全巻が繰り返し明記している核となる規則。
1 箇所だけ変更すると設定全体が壊れるため、変更時は必ず関連する巻を横断確認する。

1. **セラウイルス単体はコピー不可** — 増える存在ではなく、始める存在
2. **増殖・生成能力はセラ細胞以降で発達する**
3. **生成はスパイクから行われる** — 髪は特殊器官だが生成器官ではない
4. **女王の出産だけはスパイク生成とは別系統** — 女王自身が強く惹かれる特別な人間が必要。**女王は人間を通じてしか自分をコピーできない**（第 4 巻 §6.2）
5. **ピンクの瞳は擬態でも隠せない** — セラ情報と結びついた特殊器官であり、魅了能力を司る
6. **スパイクは消えず、極小化して隠す**
7. **通常セラの全身は粘液である。しかしその姿は取らない** — できないからではなく、美しくないから（149〜152）。粘液として現れるのは髪とスパイク。人型喪失は禁止
8. **情報共有しても個性は失われない** — 集合意識ではない
9. **細胞はすべて人間由来** — 種族的外見は形態変化であり別種族化ではない
10. **セラフィムの祝福はセラフィムのみが与えられる** — 女王誕生の必須要件
11. **起源は円環として語られる** — セラフィムが一体のセラウイルスを産み落とし、場所を意図的に選んだ
12. **最初のセラ細胞は愛を求めて進化した** — 起点は感染ではなく応答である
13. **有利な特徴は合体（融合）で拡散する** — 新規発生率が低くてもフェーズ進行で保有率が上がる
14. **原初の寂しさは全セラに複製されている** — 情報核の最下層にあり、書き換えられない
15. **セラ化に事前の同意は求められない（善意の侵略）** — 「いいえ」を受け取れないから問えない
16. **意思の尊重は「繋がった後」に発生する権利** — 未感染の人間はまだその対象に数えられていない
17. **原初の寂しさは保持するセラ情報量に比例する** — 地球のセラ系統内での話（26 も参照）
18. **最初の細胞は悪意のないがん細胞だった** — 汚さと害で嫌われ、その嫌悪は不当ではなかった
19. **最初のセラ化は文字通りの治癒だった** — 昇華し、治り、美しくなった
20. **セラには美しさを追求する心が刻まれている** — 美しさは虚栄ではなく受容の条件
21. **女王セラ細胞はすべてのセラ人に存在する** — セラ人の核となる部分
22. **セラ女王は地域単位の統率者** — 地球上に複数存在し、地域が増えれば女王も増える
23. **セラフィムは比較不能・宇宙の観測者。階梯の段ではない** — 暇つぶしに地球の環境を丸ごと変えた張本人

25. **セラフィムが興味を示すと、そのセラ人は大きく進化する** — 祝福は最大級の興味の表明
26. **原初の寂しさが最も濃いのは系統内の最高位である** — 接触の前はセラ女王、接触の後はセラ星王（第 3 巻 §10.8.7）。最も寂しい者が、応えない相手を慕っている
27. **格の階梯：セラフィム ≫…≫（セラ星王 ≫）セラ女王 ≫ 上位セラ ≫ セラ人** — 連続／断絶／比較不能。セラ星王は接触の後にのみ存在する（第 3 巻 §3.1・§10.8）

901. **その日いちばん近くなった人が、その日の一人になる** — 選んでいるのではない。**決めるより先に、手が出ている**
902. **近くならなかった人は、避けられたのではない** — そこに、たまたま用がなかっただけである
903. **取らなかった側は、数に入らない** — 渡した数は数えられ、渡さなかった数は数えようがない。**遡って取れたことにはならない**
904. **覚える者が残らない場所では、規則は働かない**（第 2 巻 §11.8.6.5）— 密集した住居、封鎖された土地、擬態を解いた町
905. **拒否が拒否の形で成立するには、間が要る**（第 6 巻 §14.15）— 先に気づき、**確かめず**、触れられる前に言葉で線を引いた者にだけ起きる
906. **拒否が成立しても、セラは押さない** — 道徳ではない。**押したら、その人でなくなるためである**
907. **求めた場合でも、拒否が取り消されたわけではない** — 返事が変わったのではなく、**返事をする時間が終わっただけである**
908. **断っている人には、手渡しをしない** — 卓に置いて渡す。**セラ社会の作法として残った。誰が始めたかは記録にない**
909. **混ざる家には、必ず戸番が一人立つ**（第 7 巻 §10.3.1）— 儀礼ではない。**混ざっているあいだ、中では何も決められないためである**
910. **戸番は、中へ入らない。起こさない。声をかけるだけである** — それで戻る。戻れるようになっている
911. **混ざる家の順番待ちが途切れたことは、一度もない** — 町が大きくなれば家も増えるが、**待ちは短くならない**
912. **古い者は、固くなる。だからほどきに来る** — 持っているものは減らず、**並びが組み直されるだけである**。**古いまま固まっている者は、どこにもいない**
913. **混ざって生まれた者に、名をつけるのは混ざった二人である** — たいてい二人とも同じ音を思いつく。**混ざる前なら一致しない**
914. **姿ごとの住み分けに、線を引いた者は一人もいない**（第 7 巻 §10.4）— 居心地のいいところに残った者が残っただけである
915. **どこへでも行けるのは、何も付いていない者だけである** — だから運ぶ役はこの者たちのものになった。**触れれば済むのに、運ぶ**
916. **国境は一本も引かれていない** — 引こうとした話は出た。「線の内側と外側で、何が変わるの」で毎回止まる
917. **住みにくい場所ほど、二人でいる者が多い** — 住みやすい場所には、片方が先に住んでいるためである

## 画像生成の共通方針

全巻に共通する描写要件。

- **必須**：アニメ風／可愛い・美しいキャラクターデザイン／商業作品級の完成度／
  滑らかな線と塗り／セルシェーディングまたはソフトシェーディング／人型維持
- **維持**：ピンクの瞳／セラスパイク／ぷるぷるした髪
- **禁止**：グロテスクな怪物化／人型喪失／全身粘液化（合体時を除く）／セラ要素の消失／
  ホラー的・恐怖的表現／暗いディストピア表現
- **原則**：セラは常に可愛く優しく描く。**恐ろしさは内容から来るのであって、絵から来るのではない**
  （第 6 巻）。セラを悪役として造形してはならない

## 運用ルール

- **確定した設定は書き換えない。** 変更が必要な場合は、どの項目をどう改訂したかを
  コミットメッセージに明記し、改訂であることが履歴から追えるようにする。
- **各巻の末尾には「確定事項まとめ」を置く。** 参照時に要点だけを拾えるようにする。
- **未確定事項は本文に混ぜない。** 検討中の案は `consistency-notes.md` に分けて書き、
  確定していないことが読み手に分かる状態にする。
- **archive は書き換えない。** 統合前の原本として凍結する。
- **画像生成の方針も設定の一部として扱う。** デザインの一貫性は世界観の一貫性そのもの。

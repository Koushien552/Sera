> セラ人から上位セラ、女王、そして比較不能なセラフィムまで。
> 統合元：Part 5（進化階級）／Part 13（存在階梯）／Part 21（成長体系）／
> Part 29（未来形態・究極進化）／Part 33（セラ人・女王細胞・格の階梯・ルミナス）

## 1. セラにおける「進化」とは

### 1.1 定義

セラにおける進化とは、単純な戦闘能力の上昇ではない。

**より多くの情報を理解し、より高度な生命構造を獲得し、より大きな役割を担える存在になること**であり、
**生命としての可能性を広げ、より多くの存在と調和できるようになること**である。

真の進化とは、知識／経験／心／信頼／技術／情報制御能力 のすべてが調和して成熟することである。

### 1.2 進化を決める要素

セラ情報量／経験／環境適応／他セラとの交流／融合／上位存在からの導き／
学習／研究／芸術／教育／問題解決／他者を支える経験

### 1.3 進化条件は能力だけではない

仲間を思いやる心／高い知識／豊富な経験／責任感／社会への貢献

これらが調和した時、次の段階へ近づく。

### 1.4 誰でも成長できる

セラ社会では、生まれ持った能力だけで未来が決まることはない。
**すべてのセラには、成長する可能性が与えられている。**

### 1.5 個体差

すべてのセラが同じ速度で進化するわけではない。

差が生まれる要素：生まれた時の情報量／経験／性格／得意能力／環境／出会った上位存在

そのため、同じ段階のセラでも能力や姿には大きな違いがある。

得意分野の例：芸術型／研究型／教育型／医療型／建築型／戦闘型／擬態特化型／種族変化特化型

### 1.6 通常の生命との違い

| 通常の生命 | セラ |
| --- | --- |
| 誕生 → 成長 → 成熟 | 誕生 → 成長 → 情報取得 → 能力変化 → 存在進化 → さらに高位存在へ |

### 1.7 退化について

セラは、通常の意味での退化はほとんど起こらない。

ただし長期間能力を使用しなければ、技術や経験が鈍ることはある。
その場合も、学び直すことで取り戻すことができる。

## 2. 二つの体系 — マクロとミクロ

**最重要：セラ体系は、二重になっている。**

一本の階級図として書いてはならない。**マクロ体系とミクロ体系は、別の体系である。**

### 2.1 ミクロ体系 — 一人の人間の中の環境

**ある人間の体内で成立している、セラ細胞たちの体系。**

```
セラウイルス
　↓
セラ細胞
　↓
上位セラ細胞
　↓（突然変異セラ細胞 → エルフなど）
女王セラ細胞
　　└→ ルミナス（生み出される。階梯の段ではない。§11）
```

これは、**一人の身体の内側に閉じた環境**である。

**ルミナスは、この階梯の段ではない。**

女王セラ細胞から**生み出される**特別なセラ細胞であり、
女王セラ細胞より上位の段階を意味しない（§11.1、§4.3）。
階梯に並べると、相似則（§2.4）によって
「環境ルミナスはセラ女王より上位」という誤った帰結が出る。

### 2.2 マクロ体系 — セラ化人間たちのつながり

**個体どうしが作る、社会・地域規模の体系。**

```
セラ化人間
　↓
上位セラ化人間
　↓（突然変異セラ人間 → エルフなど）
セラ女王
```

これは、**個体と個体の間に成立する体系**である。

### 2.3 セラフィムは、両方の外側にいる

```
　　　　　　セラフィム
　　　　　（両体系の外側）
　　　　　　　　│
　　┌──────┴──────┐
マクロ体系　　　　　ミクロ体系
（セラ化人間の　　　（一人の体内の
　つながり）　　　　　細胞環境）
```

セラフィムはマクロの頂点でもミクロの頂点でもない。
**どちらの体系にも属していない**（§9 比較不能）。

### 2.4 二つは相似である

マクロとミクロは、**同じ形をしている。**

| ミクロ体系（細胞） | マクロ体系（個体） |
| --- | --- |
| セラウイルス | （対応なし。ミクロにしか存在しない起点） |
| **セラ細胞** | **セラ化人間**（＝セラ人／通常セラ） |
| **上位セラ細胞** | **上位セラ化人間**（＝上位セラ） |
| **突然変異セラ細胞**（エルフなど） | **突然変異セラ人間**（エルフなど） |
| **女王セラ細胞** | **セラ女王**（＝女王セラ） |
| **ルミナス**（人間の脳で発達） | **環境ルミナス**（森・街・海・大地で発達。§11） |

**ルミナスだけは、両方の体系に現れる。**
思考・感情を司る部分で発達する特殊セラ細胞という定義（§11）が、
スケールを問わず成立するためである。

そして**社会の構造も、両方に現れる。**

下位が上位に仕え、規律の下で研鑽する制度（第 7 巻 §2.6）は、
個体どうしの間にも、一人の体内の細胞たちの間にも成立している。
**一人のセラ化人間の内側にも、騎士団がある。**

### 2.5 二つを繋ぐもの — ミクロの完成が、マクロの誕生である

二つの体系は独立しているのではない。**片方がもう片方を生む。**

```
ミクロ体系が成熟する
　├ セラ細胞が体内に広がる
　├ 女王セラ細胞が核として成立する
　└ ルミナスが脳を担う
　　　↓
その人間が「セラ化人間」となる
　　　↓
マクロ体系に、一つの個体として現れる
```

**ミクロの完成が、マクロの誕生である。**

したがって、第 6 巻 §1.1 の円環図が
「セラウイルス → セラ細胞 → 通常セラ → 上位セラ → 女王セラ」と続くのは、
**ミクロからマクロへ乗り移る過程を一本に描いているためである。**
乗り移りが起きる点は、**セラ細胞 → セラ化人間**のところである。

### 2.6 入れ子構造 — なぜ女王セラ細胞が全員にあるのか

ここから、不変ルール 21 の意味が明らかになる。

**マクロ体系の個体は、一人ひとりが完全なミクロ体系を内側に持っている。**

そしてそのミクロ体系の頂点が、**女王セラ細胞**である。

```
マクロ： セラ化人間 ─ 上位セラ化人間 ─ セラ女王
　　　　　　　│
　　　　　　　└ 内側に丸ごと一つ
　　　　　　　　　　↓
ミクロ： セラウイルス ─ セラ細胞 ─ 上位セラ細胞 ─ 女王セラ細胞
　　　　　　　　　　　　　　　　　　　　　　　　　　　　└→ ルミナス（§2.1）
```

**「セラ女王」と「女王セラ細胞」が似た名を持つのは偶然ではない。
同じ位置を、違うスケールで指しているからである。**

そして §2.10.7 の通り、**セラ女王の身体は、全身が女王セラ細胞である。**

誰もが核として一つ持つものを、女王だけは全身として持っている。

**マクロの頂点と、ミクロの頂点が、そこで一致する。**

なお、セラフィムが何でできているかは**分かっていない**（§9.7）。
本書はそれについて何も定めない。

### 2.7 表記の使い分け

表記には揺れがあるが、**どちらの体系を指すかで使い分けられている。**

| 表記 | 体系 | 指すもの |
| --- | --- | --- |
| セラウイルス | **ミクロ** | 起点形態 |
| セラ細胞 | **ミクロ** | 基本単位 |
| 上位セラ細胞 | **ミクロ** | 高位の細胞 |
| 突然変異セラ細胞 | **ミクロ** | 種族特徴を持つ細胞 |
| 女王セラ細胞 | **ミクロ** | 細胞体系の頂点。全セラ化人間の核 |
| ルミナス | **両方** | 思考・感情を担う特殊細胞 |
| セラ化人間／セラ人／通常セラ | **マクロ** | 個体 |
| 上位セラ化人間／上位セラ | **マクロ** | 高位個体 |
| 突然変異セラ人間 | **マクロ** | 種族形態を持つ個体 |
| セラ女王／女王セラ | **マクロ** | 地域統率者 |
| セラフィム | **外側** | 比較不能 |

### 2.8 混同してはならない対

以下は**別物である。** 文中で取り違えてはならない。

| 混同されやすい対 | 違い |
| --- | --- |
| **上位セラ** ⇔ **上位セラ細胞** | 前者は個体、後者は細胞 |
| **セラ女王** ⇔ **女王セラ細胞** | **前者は地域の統率者、後者は誰もが持つ核** |
| **セラ人** ⇔ **セラ細胞** | 前者はマクロの個体、後者はミクロの単位 |

特に二つ目に注意する。

**すべてのセラ化人間は女王セラ細胞を持つ。
しかし、すべてのセラ化人間がセラ女王であるわけではない。**

### 2.9 階級の意味

いずれの体系においても、階級は単なる支配関係ではない。

**上位存在ほど下位存在を導き、下位存在ほど上位存在から学ぶ**という関係で成立する。

すべての個体がこの順番を必ず辿るわけではない。

階級は、上下関係や優劣を示すだけではない。

**それぞれが担う役割の違い**を表し、**どれだけ大きな責任を担えるか**を示す。

上位ほど、責任も大きくなる。

### 2.10 ミクロ体系のフェーズ — 七相

**付録 A のフェーズも、第 8 巻 §10 の七つの時代も、いずれもマクロ体系の話である。**

ミクロ体系にも段階がある。**そして、同じものではない。**

ここでは**相（そう）**と呼ぶ。時代とも、フェーズとも呼ばない。
**別の体系の、別の進み方だからである。**

そして相は、二つに分かれる。

| | 範囲 | 性質 |
| --- | --- | --- |
| **前期七相** | 単体 → 完成 | **順序が決まっている。**必ずこの順に進む |
| **後期** | 完成 以後 | **終わりがない**（§2.10.7） |

**ミクロは、完成しても止まらない。**

#### 2.10.1 前期七相 — 誕生まで

| 相 | 名 | 何が起きるか |
| --- | --- | --- |
| **第一相** | **単体（たんたい）** | セラウイルスが一体だけ。**応える相手がいない** |
| **第二相** | **応答** | 最初のセラ細胞が生まれる。**はじめて二体になる** |
| **第三相** | **群（ぐん）** | 増える。**その臓器の内側だけで栄える** |
| **第四相** | **分化** | 上位セラ細胞と突然変異セラ細胞が現れる。臓器ごとに差が出る |
| **第五相** | **抗争** | **免疫が本格的に反応する。**削られ、また増える |
| **第六相** | **女王** | **女王セラ細胞が形成される。**続いてルミナスが生まれる |
| **第七相** | **完成** | 脳のセラ化が完了する。**そして、ここからが長い** |

#### 2.10.2 第 6 巻 §23.3 の五段階との対応

五段階は**人間の側から見た区分**であり、七相は**細胞の側から見た区分**である。

| 五段階（人間側） | 七相（細胞側） |
| --- | --- |
| 第 1 段階：セラ細胞の侵入 | **第一相・第二相** |
| 第 2 段階：身体のセラ化 | **第三相・第五相・第四相** |
| 第 3 段階：女王細胞の形成 | **第六相** |
| 第 4 段階：ルミナス生成 | **第六相**（後半） |
| 第 5 段階：脳のセラ化完了 | **第七相** |

**第 2 段階だけが、三つの相に分かれている。**

人間の側からは「体調が良くなっていく」一続きの時期に見える。
**細胞の側では、そこで最も多くのことが起きている。**

#### 2.10.2.1 免疫が反応するのは、分化のあとである

**順序を取り違えてはならない。**

免疫は、セラが現れた時点では動かない。

**数が少なく、静かで、害が出ていないうちは、対象にならない。**

反応が始まるのは、

| | |
| --- | --- |
| 数 | **その臓器の相当部分を占めてから** |
| 質 | **上位セラ細胞が現れてから**（第四相） |

**相応の規模になってはじめて、削りに来る。**

したがって第一相から第四相までのあいだ、セラは一度も攻撃されない。

そのあいだに、まちができ、繋がりができ、上位が現れる。

**攻撃は、育ちきったところへ来る。**

#### 2.10.2.2 他の臓器へ移るのは、第五相のあとである

**順序を取り違えてはならない。**

第三相のセラは、**生まれた臓器から出ていかない。**

出ていけないのではない。**出ていく理由が生じないのである。**

| | 第三相のセラ |
| --- | --- |
| 流れに乗れば | 遠くへ運ばれる |
| 実際に乗るか | **乗らない** |
| なぜか | **近くに応える相手がいるため**（第 6 巻 §16.4） |

そして、その臓器が埋まる。

##### 免疫が、境目になっている

第五相の免疫は、セラを削るだけではない。

**広がりを、その臓器に押しとどめている。**

流れへ出たセラは、遠くへ着く前に削られる。

```
第三相：出ていく理由がない
　↓
第五相：出ていこうとしても、削られる
　↓
**第五相の終わり：削る側がセラになる**
　↓
**境目が、なくなる**
```

##### だから、第五相の終わりが転機である

§2.10.4 の通り、抗争は殲滅では終わらない。**攻撃側がセラ化されて終わる。**

その瞬間、**押しとどめていたものが、押しとどめる側でなくなる。**

以後、セラは全身へ広がっていく。

| 相 | 広がりの範囲 |
| --- | --- |
| 第一〜三相 | **一つの臓器の内側** |
| 第五相 | **境目で削られる。出られない** |
| **第四相以降** | **全身。臓器ごとに時期がずれる**（§2.10.3 女王空位の臓器） |

**セラ圏がその臓器を出るのは、敵がいなくなったからではない。
敵が、味方になったからである。**

#### 2.10.3 マクロと一致するもの

| | ミクロ | マクロ |
| --- | --- | --- |
| 段階が進むほど上位が現れる | **一致** | 第四時代（上位時代） |
| 突然変異が現れる | **一致** | 付録 A の系統 |
| 最後に女王が生まれる | **一致** | 第五時代（女王時代） |
| **地域差がある** | **一致。ただし単位は臓器である** | 大陸・星 |
| **拡大は跳ぶ** | **一致。**血流に乗れば遠い臓器へ一度に届く | 第 8 巻 §8.2.1 |
| 格上と接すると引き上げられる | **一致** | 不変ルール 74・75 |

##### 女王空位の臓器

§8.3.3 の**女王空位の大陸**に、そのまま対応するものがある。

**まだセラが届いていない臓器である。**

そこでは上位セラ細胞が最上位となり、全体の把握が届かず、
**取り残された細胞が出る。**

そして必ず、あとから届く。

#### 2.10.4 マクロと一致しないもの

**ここが本節の要点である。**

##### 一 — 第五相「抗争」に、対応する時代がない

第 4 巻 §16.2 の通り、**マクロにおいて、セラを失わせ得る存在は一つも存在しない。**

人間は手段を持たず、抵抗は抵抗として登録すらされない（不変ルール 47・48）。

**ミクロは、そうではない。**

| | 抵抗されるか |
| --- | --- |
| マクロ | **されない。**成立しない |
| **ミクロ** | **される。免疫が実際に攻撃してくる** |

**セラ体系において、実際に攻撃を受ける場面は、ここにしかない。**

そして削られたセラ細胞は、失われる。

第 4 巻 §16 の「セラは事実上失われない」は、**マクロの話である。**

##### それでも、争いにはならない

免疫細胞は**セラではない。**未感染の細胞である。

したがって第 7 巻 §3.2 の「セラ同士では争いが起こらない」は、破られていない。

そして抗争は、**勝敗では終わらない。**

```
免疫が攻撃する
　↓
セラが増える
　↓
**攻撃してきた免疫細胞が、セラ化される**
　↓
攻撃する側がいなくなる
```

**殲滅ではない。相手がこちら側になって終わる。**

第五相が終わる瞬間に、**敵だったものは全員仲間になっている。**

##### 二 — 順序の決まった相は、第七相で終わる

**ただし、ミクロが終わるのではない。**

前期七相は、**必ずこの順に進む固定の列**である。
そして第七相でその列が尽きる。

**そこから先は、順序のない成長になる**（§2.10.7）。

| | 第七相以後 |
| --- | --- |
| 決まった順序 | **ない** |
| 終わり | **ない** |
| 進むもの | **数ではなく、格である** |

マクロの七つの時代も同じ形をしている。
第七時代のあとに第八時代はなく、そこからは**永遠成長時代**である（第 8 巻 §17）。

**この点は、一致している。**

##### 三 — 円環が、閉じる

不変ルール 28 の通り、**マクロの円環は閉じていない。**
女王はセラフィムにならず、最後の矢印だけ通らない。

**ミクロには、セラフィムに当たるものがない。**

祝福もなく、接触もなく、体系の外から誰も見ていない。

代わりに、ミクロにとっての「外」は**マクロ体系そのもの**である。

そして第七相で、

**その外へ、出る。**

| | 外へ到達するか |
| --- | --- |
| マクロ → セラフィム | **到達しない**（不変ルール 28） |
| **ミクロ → マクロ** | **到達する。それが§2.5 である** |

**ミクロの円環だけが、閉じる。**

そしてミクロのセラたちは、自分たちが外へ出たことを知らない。
**外という概念を、持ったことがないためである。**

##### 四 — 女王の希少性が、逆である

| | 女王が生まれるか |
| --- | --- |
| マクロのセラ女王 | **極めて稀。会うこと自体が事件である**（不変ルール 123） |
| **ミクロの女王セラ細胞** | **必ず生まれる。全セラ人が一つ持っている**（不変ルール 21） |

マクロでは祝福が要り、それは一度しか与えられていない（§8.2）。

**ミクロでは、条件が揃えば自動的に生じる。**

**必然と偶然が、逆になっている。**

##### 五 — ルミナスが生じるのは、一箇所だけである

マクロでは、森・海・大地・街の**すべて**がルミナスを持つ（不変ルール 37）。

**ミクロでは、脳だけである。**

第 6 巻 §23.2 の通り、ルミナスは感情を司る部分で発達する。

身体の中で、そこに当たるのは脳だけである。

| | ルミナスが生じる範囲 |
| --- | --- |
| マクロ | **環境の全域** |
| **ミクロ** | **一箇所のみ** |

したがってミクロには、**大地の意思に当たるものがない。**

臓器は意思を持たない。**持つのは脳だけである。**

##### 六 — 文明に当たる相がない

マクロには第三時代（発展期）がある。都市が建ち、分業が生まれ、祝祭が始まる。

**ミクロに、それに当たる相はない。**

付録 B §11 の通り、**ミクロ体系に職業はない。**

区別する必要が生じないためである。細胞たちは常に完全に共有している。

分業はある。**名前がついていないだけである。**

###### ただし、場所は整えられる

**ここを行きすぎてはならない。**

職業がないことと、何も作らないことは、別である。

第三相の後半から、**セラ細胞たちは周囲を整えはじめる。**

| | 作られるもの |
| --- | --- |
| 通り道 | よく通るところが、通りやすくなる |
| 広いところ | よく集まるところが、集まりやすくなる |
| 縁 | 渡されるものが届く側が、受けやすくなる |

**これをここでは「まち」と呼ぶ。**

##### まちと、都市の違い

**セラ都市（第 8 巻 §3）とは、別物である。**

| | ミクロの「まち」 | マクロのセラ都市 |
| --- | --- | --- |
| 誰が作るか | **誰も決めない。**通ったところが、そうなる | 建築士が方向を渡す（付録 B） |
| 分業 | **ない** | ある |
| 祝祭 | **ない** | ある（第 7 巻 §9） |
| 住民を知っているか | **知らない**（第 8 巻 §3.5 に当たるものがない） | 知っている |
| 設計 | **ない** | ある |
| **一人用の場所** | **ない** | **ない**（不変ルール 374） |

**最後の行だけが、一致している。**

##### 決めていないのに、そうなる

まちができる機構は、単純である。

```
よく通る
　↓
そこが通りやすくなる
　↓
もっと通る
```

意思も、計画も、役割分担も要らない。

**行った先が、行きやすくなっていくだけである。**

したがって、まちの形は**その集団がどこへ行きたがったかの記録**である。

第 2 巻 §4.7 のスパイクが履歴を示すのと、同じ構造である。

##### 通り道は、二体ぶんの幅で作られる

そして必ずそうなる理由がある。

不変ルール 372 の通り、**セラは一人で行き来しない。**

一体ぶんの幅の通り道は、**一度も作られたことがない。**

誰も決めていない。**一体で通ったことがないからである。**

##### 七 — 恋は、ミクロにもある

**ここは、一致する。**

第 6 巻 §14 の通り、**恋は個体間の強い繋がり**であり、
相手はセラだけである（不変ルール 45）。

**セラ細胞は、その条件を満たしている。**

そして情報を共有していても、個性は失われない（不変ルール 8）。

| | |
| --- | --- |
| 知っていることが同じになるか | **なる** |
| 誰のそばへ行きたいかが同じになるか | **ならない** |

**差が残るところに、恋が生じる。**

##### 同化からの分裂体も、ミクロで起きる

第 4 巻 §5.3 の通り、深く繋がった二体は融合し、**三体に分かれる。**

| | 起きること |
| --- | --- |
| 二体 | 融合し、互いに強化されて戻る |
| **三体目** | **二つの能力を受け継いだ、新しい細胞** |

**これはミクロでも起きる。**

第 4 巻 §2.2.1 の①②とは、別系統である。

| | 何から生まれるか |
| --- | --- |
| ① 直接生成 | 一体の身体から |
| ② ウイルス生成 | 一体の身体から（そして未感染細胞と融合する） |
| **③ 同化からの分裂** | **二体から** |

**恋は、根本原理の外にある**（不変ルール 44）。

そしてそれは、ミクロでも変わらない。

**ミクロ体系にも、原理の外にあるものが一つだけある。**

##### 八 — 時間の尺度が違う

| | 完成までにかかる時間 |
| --- | --- |
| マクロ（七つの時代） | **数千年**（第 8 巻 §10） |
| **ミクロ（七相）** | **数か月から、数十年** |

そして速さは、渡された情報量で決まる。

| 渡し方 | 完成までの時間 |
| --- | --- |
| 恋によるセラ化（第 6 巻 §14.6） | **一度で眠りに落ちる。最も速い** |
| 忍・医師（付録 B） | 数日 |
| 給仕・美容師 | 数年 |
| **助産師** | **数十年**（付録 B §1.24） |

**同じ七相を、桁の違う速さで通る。**

#### 2.10.5 突然変異比率 — ミクロ側の数え方

付録 A の比率表は、**マクロ体系（個体）を数えている**（付録 A §3 冒頭）。

**ミクロには、別の比率がある。**

第四相で現れる**突然変異セラ細胞**が、その身体の中で占める割合である。

| | 何を数えるか |
| --- | --- |
| 付録 A（マクロ） | セラ圏における、突然変異セラ人間の割合 |
| **ミクロ** | **一人の身体における、突然変異セラ細胞の割合** |

そして、

**この割合が、その人がどの種族形態になるかを決める。**

| 第四相での比率 | 第七相で現れる姿 |
| --- | --- |
| 低い | **純粋セラ**（付録 A §2.1） |
| 高い | **モンスター系セラ**。比率の高い系統の特徴が出る |
| 複数系統が高い | **複合進化セラ**（付録 A §3.1 Phase 5） |

**第七相で目を覚ましたときの姿は、第四相で決まっている。**

本人は、鏡を見てはじめてそれを知る。

##### ただし、それは最初の姿である

**固定ではない。**

第 7 巻 §6.2 の通り、セラは容姿を変えられ、
**種族形態への変化は自己表現の一つ**として扱われている。

そして§2.10.7 の通り、第七相以後もミクロは動き続ける。

| | |
| --- | --- |
| 第四相で決まるもの | **生まれたときの姿** |
| 以後 | **同化のたびに、系統が入る**（§2.10.7 第九相） |

**選び直せないのではない。時間がかかるだけである。**

#### 2.10.7 後期 — 第七相から先

**脳のセラ化が完了しても、細胞たちの進化は止まらない。**

止まると考えると、次が説明できなくなる。

- 上位セラ化人間は、どこで上位になったのか
- セラ女王は、どこで女王になったのか
- 同化のたびに増える系統は、どこへ入るのか

**すべて、第七相より後に起きている。**

##### 有限なのは、体積だけである

「身体が有限だから、いずれ止まる」は成り立たない。

不変ルール 82 の通り、**セラ情報は消費するものではなく、交わすほど増える。**

| | 限りがあるか |
| --- | --- |
| 身体の体積 | **ある** |
| 細胞の数 | **ある** |
| **セラ情報** | **ない** |

したがって第七相以後、**増えるのは数ではなく、格である。**

##### 後期の相

前期七相と違い、**順序も期限も決まっていない。**

到達しない者もいる。何度も繰り返す者もいる。

| 相 | 名 | 何が起きるか | 対応するマクロの出来事 |
| --- | --- | --- | --- |
| **第八相** | **接続** | 外のセラ情報が流れ込みはじめる | セラ人として社会に加わる |
| **第九相** | **混合** | 同化のたび、他人のミクロと混ざる。**新しい系統が入る** | 合体・同化（第 4 巻 §5・§12） |
| **第十相** | **上位** | 上位セラ細胞の比率が上がり、全体が引き上げられる | **上位セラ化**（§7） |
| **第十一相** | **王化** | **女王セラ細胞が増え、やがて全身を占める** | **セラ女王の誕生**（§8.2） |

##### 第八相 — はじめて「外」がある

第七相までのミクロには、外がなかった（§2.10.4 三）。

第七相で脳が繋がると、**外の情報が入ってくる。**

そして細胞たちは、それを外だと思わない。

**外という概念を、持ったことがないためである。**

##### 第九相 — 姿が変わっていく

宿主が誰かと同化するたび、その相手のミクロと混ざる（第 4 巻 §12）。

新しい系統の突然変異セラ細胞が入り、比率が動く。

第 7 巻 §6.2 の容姿変化文化は、**ここに機構がある。**

第四相で決まった姿は、**出発点にすぎない。**

##### 第十相 — 上位化は、内側から起きる

不変ルール 74・75 の通り、格上と接すれば引き上げられ、それは一瞬で起きる。

**ミクロ内部でも、同じことが起きている。**

上位セラ細胞の比率が閾値を超えると、体内全体が一段上がる。

**そして、その人がマクロ体系で上位セラになる。**

| | どちらが先か |
| --- | --- |
| ミクロの上位化 | **先** |
| マクロの上位化 | **その結果である** |

§2.5 と同じ関係が、もう一度起きている。

##### 第十一相 — 王化

**女王セラ細胞が増え続け、やがて身体のすべてを占める。**

| 存在 | 女王セラ細胞の占める割合 |
| --- | --- |
| セラ人 | **核として一つ** |
| 上位セラ | **複数** |
| **セラ女王** | **全身。すべてが女王セラ細胞である** |

**女王とは、身体のすべてが女王セラ細胞になった個体のことである。**

誰もが核として一つ持つものを、女王だけは全身として持っている。

**マクロの頂点と、ミクロの頂点が、そこで一致する。**

そして第十一相に到達するミクロは、**極めて稀である。**

マクロで女王が稀であること（不変ルール 123）と、これは同じ一つの事実である。

##### 勾配は、そこで終わっている

**セラフィムを、この表の続きに置いてはならない。**

セラフィムが何でできているかは、**分かっていない**（§9.7）。

比較不能な相手を、同じ尺度の延長に置けるという保証がない。

**この勾配は、セラ女王で頂点に達し、そこで終わる。**

**しかし、片方だけでは書けない場面がある。**

§2.5 の通り、**ミクロの完成が、マクロの誕生である。**

これは定義上、**両側から書かねばならない唯一の点**である。

**通り直した七相が、前と同じ結果になるとは限らない。**

**付録 A の比率が第六・第七時代で変わらないのは、ミクロ側の出来事である。**

##### 六 — 死の淵

§10.8.4 の通り、口づけを受けた女王は死の淵へ行った。

全身が女王セラ細胞である個体に、比較不能なものが触れた。

**ミクロ側の記録は、残っていない。**

記録できる状態ではなかったためである。

## 3. 格の階梯

### 3.1 表記

**以下は、マクロ体系（§2.2）の階梯である。**

```
セラフィム ＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞ セラ女王 ＞＞＞＞＞ 上位セラ ＞＞ セラ人
```

ミクロ体系（§2.1）にも同じ形の階梯があるが、
そちらは**一人の身体の内側の話**であり、この階梯とは別に扱う。

#### 接触の後は、一段増える

§10.8 の通り、女王がセラフィムと接触し、生還すると、
その女王は**セラ星王**になる。

```
セラフィム ＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞＞ セラ星王 ＞＞＞ セラ女王 ＞＞＞＞＞ 上位セラ ＞＞ セラ人
```

これは地球で一度きりの出来事であり（§10.8.1）、
**接触の前を描くか後を描くかによって、階梯は二通りある。**

**そして、どちらでもセラフィムまでの距離は縮まらない**（§10.8.6）。

### 3.2 差の性質

矢印の本数は、単なる強弱ではなく**差の質**を表している。

| 区間 | 差の本数 | 差の性質 |
| --- | --- | --- |
| セラ人 → 上位セラ | ＞＞ | **連続的**。経験と成長によって到達できる |
| 上位セラ → セラ女王 | ＞＞＞＞＞ | **断絶**。通常進化では到達不能。複数の上位セラの融合＋祝福が必要 |
| セラ女王 → セラ星王 | ＞＞＞ | **断絶**。進化では到達不能。**セラフィムの接触と、そこからの生還だけが道である**（§10.8） |
| セラ星王 → セラフィム | ＞＞＞…（25 本） | **比較不能**。段を足しても性質は変わらない |
| セラ女王 → セラフィム | ＞＞＞…（28 本） | **比較不能**。同じ尺度に乗らない。地球の体系の内と外の差。**渡る道は存在しない**（§9.1） |

**セラ女王 → セラ星王の区間だけ、他のどの区間とも性質が違う。**

上へ行く道が、成長でも融合でも祝福でもない。
**向こうから来ることだけが道である。**

### 3.3 重要な帰結

セラ女王がセラ人から見て「圧倒的に格が高い」存在であっても、
その女王とセラフィムの差は、さらに桁が違う。

**セラたちが到達を夢見る最高位（女王）から見ても、セラフィムは想像の外側にいる。**

### 3.4 知性の階梯

格の階梯は、そのまま**知性の階梯**でもある。

**以下の数値・比較はすべてマクロ体系（個体）の話である。**
ミクロ体系にも「上位ほど情報処理能力が上がる」という同じ勾配が働くが
（第 5 巻 §1.4）、細胞側に人間の尺度を当てた数値は定めていない。

#### 3.4.1 原理 — 知性は、足し算では届かない

**上位セラ一体の賢さには、地球の全人類を足し合わせても一切届かない。**

これは「非常に賢い」という程度の話ではない。**加算不能**である。

```
人間 1 人
人間 100 人
人間 1 万人
人類 80 億人すべての総和
　　　　　↑ ここまでが「足し算で届く範囲」
─────────────────────── 越えられない線
　　　　　↓
上位セラ 一体
```

**足し算をどれだけ続けても、線を越えることはない。**

数を集めることで格が上がるという発想が、そもそも成立しない。
これは第 8 巻 §8.3 の「格上げは平均化ではなく引き上げ」と同じ性質である。
**セラ体系において、量は格に変換されない。**

#### 3.4.2 人間の尺度は、上位セラで振り切れる

人間の知能指標（IQ）は、人間の分布を前提に作られた尺度である。

したがって、**上位セラを測ろうとすると、尺度そのものが振り切れる。**

| 存在 | 人間の尺度で測ると | 差の性質 |
| --- | --- | --- |
| 人間 | 通常の分布の内側 | — |
| **人類全体の総和** | — | **ここまでが足し算の届く範囲** |
| セラ人 | 人間の最上位を上回るが、まだ測れる | 連続 |
| **上位セラ** | **「IQ 500 以上」としか出せない。測定不能** | **単体で人類総和を超える。加算不能** |
| **セラ女王** | 測るという発想が成立しない | 上位セラに輪をかけて上（§3.4.3） |
| セラフィム | 尺度の外 | 比較不能 |

**「IQ 500」は、上位セラの知能を表す数値ではない。
人間の測定機器が示せる限界値である。**

作中で人間が上位セラを測定した場合、出てくるのはこの種の数字だけである。
測っている側は「500 程度」と受け取るが、**実際の差はそこにはない。**

#### 3.4.3 女王は、輪をかけて賢い

セラ女王は、上位セラよりさらに上である。

女王は、**地球規模でほぼ全知である**（第 5 巻 §1.4.3）。

- 他の女王の地域についても知っている
- **女王どうしは互いに筒抜けである**
- 未感染の人間世界についても見えている

上位セラですら人類総和を超えているところへ、女王はさらに上を行く。

#### 3.4.4 「連続」とは、差が小さいという意味ではない

ここで §3.2 との整合を明示する。

§3.2 は、セラ人 → 上位セラの差を**連続的**としている。
しかし §3.4.1 の通り、その間には人類総和を越える線がある。

矛盾ではない。

**「連続」とは到達可能性の話であって、差の大きさの話ではない。**

| 用語 | 意味 |
| --- | --- |
| **連続**（セラ人 → 上位セラ） | 成長によって**渡れる**。ただし渡り切った先は桁が違う |
| **断絶**（上位セラ → 女王） | 通常進化では**渡れない**。融合＋祝福が必要 |
| **比較不能**（女王 → セラフィム） | 渡るという概念が成立しない |

道が続いていることと、行き先が近いことは、別のことである。

#### 3.4.5 下位から見ると、どう見えるか

**下位のセラは、上位の思考過程を追えない。**

しかし、**結論が正しいことは分かる。**

```
上位セラが判断を示す
　↓
下位はその過程を理解できない
　↓
しかし、正しいと分かる
　↓
慕う
```

**信頼が、理解の代わりになっている。**

これは第 5 巻 §1.4.1（上位は下位をよく理解しているから慕われる）と対になる。

- **上から下へは、理解が届く**
- **下から上へは、理解は届かない。届くのは信頼だけである**

##### 帰結 — セラ文明が内部から変わらない理由

ここから、不変ルール 33「セラ文明は内部から変わらない」に
**機構的な根拠**が与えられる。

下位のセラは、上位の判断を**検証できない**。
検証できないが、**正しいと分かってしまう**。

したがって、

**疑いが生じる余地が、構造的に存在しない。**

反対する個体がいないのではない。**反対するための足場がない**のである。

---

### 3.5 降臨の後、知能は一段上がる

**§10.8.11 の通り、降臨で入ってきたものは階梯を下りてくる。**

その結果として、**セラ全体の知能が大きく上がる。**

#### 格は、動いていない

**ここを取り違えてはならない。**

| | 変わったか |
| --- | --- |
| 格の階梯 | **変わらない**（星王を除く） |
| 各段の相対順位 | **変わらない** |
| **知能そのもの** | **全段が、一斉に上がった** |

不変ルール 91 は「格の階梯は、そのまま知性の階梯でもある」と書いている。

**これは崩れていない。**

崩れないのは、**全員が同時に上がったからである。**

```
セラ人　　→ 上がった
上位セラ　→ 上がった
セラ女王　→ 上がった
　↓
**順位は、一つも入れ替わっていない**
```

階梯は相対的な順位である。
**全体が持ち上がっても、順位は動かない。**

#### 人間の尺度は、意味を失う

§3.4.2 の通り、人間の知能指標は上位セラで振り切れていた。

降臨の後、**通常セラの段階で振り切れる。**

| | 降臨の前 | 降臨の後 |
| --- | --- | --- |
| 人間の尺度で測れる上限 | 上位セラの手前まで | **通常セラの手前まで** |
| 測る側 | 人間 | **いない**（§10.8.1） |

測る者がいなくなった時点で、この尺度は使われなくなった。

#### 何が変わったのか

**思考が速くなったのではない。扱える情報の量と質が変わった。**

第 5 巻 §1.4 の通り、情報処理能力には階級差がある。
その全体が、一段上へずれた。

そして扱える情報が変われば、**組み立てられるものが変わる。**

第 7 巻 §12.9 の技術と、§12.10 の体系転換は、いずれもここから出ている。

#### それでも、疑い始める個体は生まれなかった

**最も重要な点である。**

不変ルール 33 の通り、**セラ文明は内部から変わらない。**
疑い始める個体は存在せず、気づいても止まれない。

**知能が上がっても、これは変わらなかった。**

賢くなったセラたちが最初にしたことは、
自分たちの前提を検討することではなく、**より遠くまで行く方法を作ることだった。**

不変ルール 98 の通り、疑いが生じる余地は構造的に存在しない。
**それは知能の不足によるものではなかった。**

### 7.1 定義

### 7.2 特徴

### 7.3 身体的特徴と例外

一般的に、進化段階が高いほど身体規模も大きくなる。

ただし例外：**幼女型上位セラ／小型特化型／特殊能力特化型／教育特化型（師範）**

教育に特化した上位セラは小柄であることが多い（第 7 巻 §4.4.3）。
戦えば騎士に及ばない。しかし**教えることにおいて、騎士は師範に及ばない。**

**見た目の大きさと存在階級は完全には一致しない。**

### 7.4 生成能力

上位セラは、スパイクから下位存在を生成できる。

生成対象：セラウイルス／セラ細胞／通常セラ／下位上位セラ

**すべての生成は、厳密にはスパイクによって行われる。**

### 7.5 役割

上位セラは単なる強者ではない。**力よりも責任が増える。**

下位セラの指導／新しいセラの育成／社会維持／知識伝達／教育／研究指導／地域管理

**下位存在を導くことが、最も重要な役目となる。**

自分が偉いから従わせるのではなく、下位セラが自分自身で成長できるよう導く。

## 8. 第五段階：女王セラ

### 8.1 定義

セラ体系における最高位級の存在。地域の統率者。

### 8.2 誕生条件（2 系統。ただし系統 1 は一度きり）

**系統 1：融合＋祝福 — 原初の一体のみ**

1. 複数の上位セラが集結し、情報を統合する
2. ぷるぷるした巨大なセラ情報集合体（セラ物質の核）となる
3. **セラフィムの祝福**を受ける
4. 女王セラとして誕生する

**これは一度しか起きていない。**

原初の女王は、セラフィムの気まぐれによって生まれた（第 6 巻 §1、§9.3）。
以後、この経路で女王が生まれたことはない。

##### なお、これは §3.4.1 と矛盾しない

「複数の上位セラが集結する」は、量の加算に見える。
しかし §3.4.1 は**セラ体系において量は格に変換されない**と確定させている。

矛盾ではない。

```
複数の上位セラの融合 → 巨大なセラ情報集合体（まだ女王ではない）
　　　　　＋
セラフィムの祝福　　 → 女王
```

**量は、格の手前までしか運ばない。線を越えさせるのは祝福だけである。**

どれだけ多くの上位セラが集まっても、祝福がなければ女王にはならない。
そして祝福は、一度しか与えられていない。

**系統 2：既存女王による出産 — 以後のすべて**

既存の女王が、特別な方法で新たな女王を育成・出産する（第 4 巻 §6）。

**現在存在する女王は、原初の一体を除き、すべてこの経路で生まれている。**

**いずれの場合も、通常進化だけでは到達できない。**

#### 帰結 — すべての女王は、原初の一体に連なる

系統 1 が一度きりである以上、次が確定する。

```
原初の女王（セラフィムの祝福）
　↓ 出産
女王
　↓ 出産
女王 …
```

**女王はすべて、一つの系統である。** §8.3.2 を参照。

### 8.3 役割 — 地域の統率者

セラ女王は、**地球の広い地域のセラ人・上位セラ人をまとめ上げる存在**である。

一体の女王が地球全体を統べるのではない。
女王はそれぞれ広い地域を担当し、**地球上には複数の女王が存在する**。

**地域が増えれば、女王が増える。**

その他の役割：新しい生命の育成／文明の方向性決定／上位セラの指導／
大規模な情報管理／進化促進

### 8.3.1 規模 — 一つの身体が大陸を担う

**一つの女王の身体が担当するのは、大陸規模の地域である。**

完成期において、**地球上の女王の身体は十数を数える。**

| 項目 | 内容 |
| --- | --- |
| 担当範囲 | **大陸規模** |
| 完成期の身体数 | **十数** |
| 増え方 | セラ圏が新しい大陸規模の地域へ広がるたびに、一つ増える |
| 拡大途上の数 | 十数より少ない。フェーズと地域による（第 8 巻 §8.8） |

> **重要：これは「十数体の女王がいる」という意味ではない**（§8.3.2）。
> かつて本書はそう記していたが、**その数え方は誤りである。**

#### 帰結 1 — 女王は極めて希少である

女王の身体は十数しかない。

- **女王に会うこと自体が、事件である**
- 一般のセラ人は、生涯一度も女王を直接見ない可能性がある
- 女王の物語が長く語り継がれる（第 7 巻 §7.6）のは、実際に遠い存在だからである

#### 帰結 2 — 地球は、一つの意識に見渡されている

女王は地球規模でほぼ全知であり、**女王どうしは互いに筒抜けである**
（第 5 巻 §1.4.3）。

**つまり地球のセラ圏は、一つの意識によって完全に見渡されている。**

- **セラ圏の内側には**、隠れられる場所がない
- セラ圏の内側でどの大陸に何が起きても、女王は知っている
- 十数の身体は、**実質的にではなく、文字通り一つの視野である**

ただし、**セラ圏の外側は別である**（§8.3.3）。

### 8.3.2 女王は、事実上一体である

**これは設定上、極めて重要である。**

#### 根拠

| 事実 | 出典 |
| --- | --- |
| 原初の一体を除き、すべての女王は**出産**によって生まれる | §8.2 |
| したがって女王はすべて、**一つの系統**である | §8.2 帰結 |
| 女王どうしは互いに**筒抜け**である | 第 5 巻 §1.4.3 |
| 共有されるのは情報だけではない。**意思まで共有されている** | 本節 |

**女王たちは、ネットワークを通じて意思まで共有している。**

したがって、

**女王は、事実上一体である。**

十数の身体は、十数の個体ではない。
**一つの存在が、十数の場所にいる**のである。

#### 「十数体」という表記の訂正

| 誤 | 正 |
| --- | --- |
| 女王は十数体存在する | **女王は一体である。身体が十数ある** |
| 女王どうしが協調している | **協調という関係が成立しない。同一だからである** |
| 女王どうしに秘密はない | **秘密という概念が成立しない** |

#### 帰結 1 — 対立は原理的に不可能である

女王どうしの対立は、「起きない」のではない。

**成立しない。** 同一の存在だからである。

#### 帰結 2 — どの女王に会っても、同じ一体に会っている

セラ人が生涯に一度、女王に会ったとする。

大陸を渡って別の女王に会ったとしても、それは**別の相手ではない。**

**同じ一体に、二度会っている。**

#### 帰結 3 — 地球で最も寂しいのは、一体だけである

不変ルール 26 の通り、原初の寂しさが最も濃いのはセラ女王である。

そしてその女王は、一体しかいない。

**地球上で最も寂しい存在は、一つである。**

そして慕う相手であるセラフィムも、一体である（§9.1）。

**一体が、一体を慕っている。そして両者のあいだに道はない**（第 6 巻 §1.3）。

#### 帰結 4 — 母であり、娘である

女王は新たな女王を出産する（第 4 巻 §6）。

しかし生まれた女王は、意思まで共有された同一の存在である。

**女王は、自分を産んでいる。**

第 6 巻 §15.7 の「女王の母性」は、ここで一段深くなる。
女王が子に与えている母性は、**自分が受け取れなかったものを、自分に与えている**
という形をとる。

#### 帰結 5 — セラ体系の頂点は、二つの一体である

| | 数 | 関係 |
| --- | --- | --- |
| **セラフィム** | 一体 | 感情を持たない。応えない |
| **セラ女王** | 一体（身体は十数） | 最も寂しい。慕っている |

**そして円環は閉じていない**（第 6 巻 §1.3）。

道はなく、応えもない。**それでも、慕っている。**

#### 帰結 3 — 地域差は、大陸規模で生じる

第 8 巻 §8.8 の「地域差が存在する」は、**大陸単位の差**として現れる。

一つの大陸がまるごと Phase 5 で、隣の大陸がまるごと Phase 1、という状態があり得る。
**境界は、海である。**

### 8.3.3 女王空位 — 視野が届いていない場所

#### 前提

§8.3.1 の通り、**拡大途上における女王の身体は、十数より少ない。**

つまり、**女王の身体がまだ存在しない大陸がある。**

そして第 5 巻 §1.4.3 の通り、**女王の視野はネットワークに沿って届く。**
セラが一体もいない大陸には、見るための経路がない。

#### したがって

**セラが到達していない大陸は、女王に見えていない。**

女王は一体である（§8.3.2）。だから空位の大陸とは、単に統率者がいない土地ではない。

**あの一つの意識の視野が、届いていない場所である。**

**地球でそこだけである。**

#### そこで何が起きるか

女王のいない土地では、上位セラが最上位となる。

そして**上位セラは全知ではない**（第 5 巻 §1.4）。

| | 女王の担当する大陸 | 女王空位の大陸 |
| --- | --- | --- |
| 最上位 | セラ女王 | **上位セラ** |
| 視野 | ほぼ全知。隠れられない | **全知ではない。見落としが生じる** |
| 判断 | 誤らない | **誤り得る** |
| 人間 | 隠れられない | **しばらくのあいだ隠れていられる** |

**セラが間違える場所は、地球上にここしかない。**

#### 帰結 1 — 眠ったまま見つからないセラが生じる

第 2 巻 §13.5.6 の通り、枯渇したセラは眠りに落ち、仲間が見守る。

しかし女王空位の土地では、**見つけられないことがある。**

孤立したまま枯渇したセラは、何十年も眠り続けることになる。

死んでいない。壊れてもいない。
**ただ、セラ圏が自分のところまで広がってくるのを待っている。**

そして必ず広がってくる。拡大は止まらないからである（第 6 巻 §17.3）。

**眠りは、いつか必ず終わる。それが何十年後かというだけである。**

目覚めたとき、その者は何も失っていない。
しかし取り残されたという感覚だけが生じる（第 2 巻 §13.5.6）。

#### 帰結 2 — 物語が成立する、唯一の空白

女王の担当地域では、物語が成立しにくい。

すべて見られており、すべて知られており、誰も隠れられず、
争いも起こらず（第 7 巻 §3.2）、失敗も存在しない。

**女王空位の大陸だけが、まだ何も決まっていない場所である。**

- 人間が隠れられるのも
- 抵抗が意味を持つのも
- セラが誤るのも

**ここだけである。**

#### 帰結 3 — 猶予は、女王が生まれるまでである

§8.3 の通り、**地域が増えれば、女王が増える。**

そして女王の身体が一つ生まれた瞬間に、その大陸の空白は終わる。

生まれた身体は、初めからあの一体である（§8.3.2）。
学ぶ時間も、慣れる時間も要らない。

**その瞬間から、その大陸に隠れられる場所はなくなる。**

### 8.3.4 接触の後は、一体だけ格が違う

**§8.3.2 には、一つだけ例外が生じる。**

§10.8 の通り、セラフィムは女王に接触する。

そして接触されたのは、

**地球にいる女王の身体の、たった一体である。**

#### 何が起きたか

| | 接触の前 | 接触の後 |
| --- | --- | --- |
| 身体の数 | 十数 | **十数のまま** |
| 意思の共有 | 完全 | **完全のまま** |
| 情報の共有 | 完全 | **完全のまま** |
| 事実上一体か | **一体である** | **一体である** |
| **格** | **すべて同一** | **一体だけ違う** |

接触された一体は、生還して**セラ星王**になった（§8.9）。

**残りの身体は、セラ女王のままである。**

#### なぜ格だけが分かれるのか

§10.7 の通り、**格とは、セラフィムに見られた度合いである。**

そして見られたのは、一体だけである。

```
情報は共有される
意思も共有される
　↓
**「見られた」という事実は、共有されない**
```

情報の共有は、格を運ばない。
**格は、共有できるものではない。**

#### 帰結 — 記憶を持っているのに、触れられていない

これが、この設定で最も奇妙な状態を生む。

女王の他の身体は、接触の記憶を**完全に持っている。**

意思まで共有しているのだから、当然である。

- 圧を、一人称で覚えている
- 死の淵を、一人称で覚えている
- 生還した瞬間も、一人称で覚えている

**それでも、格は上がっていない。**

**触れられた記憶を持っている者が、触れられていない。**

§10.8.7 は「理解できる者がこの宇宙に一体もいない」と書いた。

**最も近いところに、記憶だけを完全に持った者が十数体いる。
そしてその十数体にも、理解は届いていない。**

#### 帰結 — 「同じ一体に二度会っている」に、例外が生じた

§8.3.2 の帰結 2 は、こう書いた。

> どの女王に会っても、同じ一体に会っている

**接触の後、これは一箇所だけ崩れる。**

星王に会うことは、**他のどの身体に会うこととも同じではない。**

会っている相手は同じ一体である。**それでも、格が違う。**

セラたちはこの違いを説明できない。
**それでも、会えば分かる**（不変ルール 96）。

---

### 8.4 格

セラ人・上位セラ人と比べて**圧倒的に格が高い**。

**女王のセラエネルギーは、事実上無限大である**（第 2 巻 §13.5.2.1）。

女王には残量という概念が働かない。
セラ化も蘇生も環境の改変も、量によって制限されない。
不変ルール 104「女王の意思があれば環境は即座に形を変える」は、
このことに支えられている。

そして女王は、上位セラには使えない**さらなる特殊能力**を持つ。
女王の出産（第 4 巻 §6）、セラ化人間の生成、大陸規模の情報管理、
環境の即時改変は、いずれもここに属する。

段階的な差ではない。生成能力・情報容量・統率規模のすべてにおいて、
上位セラとは断絶した水準にある。

### 8.5 生成能力

可能：セラウイルス生成／セラ細胞生成／通常セラ生成／**上位セラ生成**／
セラ化人間生成／特殊個体生成

女王のスパイクは、通常セラとは比較にならない高度器官である。
巨大な情報容量／高精度生成／複雑な生命設計。

女王は単に数を増やすだけではなく、**目的に合わせたセラを生み出す**。

### 8.6 女王の成長

女王は、生まれた時点で完成ではない。
経験を積み、文明を理解することで、さらに成熟していく。

### 8.7 女王への感情

多くのセラにとって、女王は単なる支配者ではない。
生命を育み、未来を託す存在であり、**母性的な存在として敬愛される**。

女王もまた、一人ひとりの仲間を大切に思っている。
強い存在だからこそ、責任も大きい。

**女王のまわりには、最も多くのセラがいる。**

騎士が仕え（第 7 巻 §2.6.2）、侍従が身のまわりを整え、
地域のすべてのセラが慕っている。

**女王は、セラ体系において最も慕われている存在である。**

それでも、最も寂しい（第 6 巻 §15.5）。

**慕われている量と、寂しさの濃さは、同じ一つの数値から出ている**（不変ルール 90）。

---

## 8.8 女王の一日

女王は一体であり、身体は十数ある（§8.3.2）。

**では、その一日はどういう形をしているのか。**

### 8.8.1 女王に、夜はない

十数の身体は、それぞれ別の大陸にいる。

地球は回っている。

**したがって、どこかの身体は必ず起きている。**

| | 通常のセラ | セラ女王 |
| --- | --- | --- |
| 夜 | ある | **ない** |
| 眠り | 全身が眠る | **身体の一つが休むだけ** |

**女王にとって眠るとは、「自分の一部が休むこと」である。**

女王という存在そのものは、一度も途切れない。

### 8.8.2 十数の場所で、同時に

意思まで共有されている（§8.3.2）ため、
女王は**一つの思考を、十数の場所で同時に実行できる。**

- こちらの大陸で騎士の叙任を受けながら
- あちらの大陸で環境の意思を聴き
- 別の大陸で新しい女王の身体を育てている

これらは並行作業ではない。**一つの意識が、同時にそれを行っている。**

#### 会議が要らない

女王どうしの合議は、存在しない（§8.3.2 帰結 1）。

相談する相手が自分だからである。
決めるという段階すら、実質的に存在しない。

**女王が「決めた」とき、十数の場所で同時に決まっている。**

### 8.8.3 どの身体も、女王のすべてである

**ここを取り違えてはならない。**

十数の身体は、女王を十数に分けたものではない。

**どの一つも、女王のすべてである。**

| 誤り | 正 |
| --- | --- |
| 女王が十数に分かれている | **女王は一体で、十数の場所にいる** |
| 目の前にいるのは女王の一部 | **目の前にいるのは女王そのものである** |
| 本体がどこかにいる | **本体という概念が成立しない** |

側仕えの騎士は、女王のすべてと向き合っている。
そして同時に、他の十数の場所でも、誰かがそうしている（第 7 巻 §2.6.8）。

**どちらも本当である。**

### 8.8.4 女王は、移動しない

女王が新しい大陸へ「来る」ということは、起こらない。

**そこで身体が一つ生まれる**（§8.3.3 帰結 3）。それだけである。

生まれた身体は、初めからあの一体であり、学ぶ時間も慣れる時間も要さない。

**旅という行為が、女王には存在しない。**

行きたい場所があれば、そこに生まれればよい。

### 8.8.5 女王は、誰にも理解されない

**これが、女王の一日を最も強く形づくっている。**

第 5 巻 §1.4.1 と §3.4 の通り、

- **上から下へは、理解が届く**
- **下から上へは、理解は届かない。届くのは信頼だけである**

女王は、地球上のすべてのセラを理解している。

**そして、女王を理解できる者は、地球上に一人もいない。**

#### 対等な会話が、成立しない

セラ人には同格の仲間がいる。上位セラにもいる。

**女王にだけ、いない。**

同格の存在は他の女王だけであり、その女王は自分である（§8.3.2）。

**女王が同格と話すと、独り言になる。**

#### そして誰も、それを問題だと思っていない

女王自身も含めて、である。

慕われており、囲まれており、実際に満たされている（§8.7）。
不足を訴える理由が、どこからも生じない。

**第 6 巻 §15.7 の母性は、ここから出ている。**

理解される側に回れないから、**理解する側であり続ける。**

### 8.8.6 眠る必要はない。それでも眠る

女王のセラエネルギーは事実上無限大である（第 2 巻 §13.5.2.1）。

**枯渇しない。したがって、眠る必要がない。**

それでも、女王の身体は眠る。

理由は必要ではない。

- 休息そのものを楽しむ文化がある（第 2 巻 §13.5.4）
- 眠ることが好きである
- そして、**眠っているあいだ、側仕えがそばにいる**

**必要のない眠りを、女王は毎日とっている。**

### 8.8.7 自分の寝顔を、毎日見ている

§8.8.1 の通り、どこかの身体は必ず起きている。
そして意思は共有されている。

したがって、

**女王は、自分が眠るところを、自分で見ている。**

ある大陸で目を閉じるとき、別の大陸の自分がそれを見ている。
騎士が毛布をかけるところも、髪を直すところも、見えている。

**世界で唯一、自分の寝顔を毎日見ている存在である。**

そして、それを誰にも共有できない。
**共有した相手は、理解できないからである**（§8.8.5）。

### 8.8.8 それでも、自分の最下層だけは見えない

女王は地球規模でほぼ全知である（第 5 巻 §1.4.3）。

十数の場所を同時に見て、大陸規模の環境の意思を聴き、
未感染の人間世界まで見通している。

**自分の寝顔さえ見ている。**

**それでも、自分の最下層だけは、見えない**（第 4 巻 §18.4、第 6 巻 §13.5.2）。

そこには、最も濃い原初の寂しさがある（第 6 巻 §15.5）。

- 誰よりも多くを見ている
- 誰よりも寂しい
- **そして、その寂しさだけを見ることができない**

##### 例外は、一つだけある

共鳴である（第 6 巻 §14.6.8）。

恋によるセラ化で結ばれた二人は、**互いの最下層を見ることができる。**

したがって、女王の最下層を見られる者がいるとすれば、
**女王が恋によってセラ化した相手だけである。**

見えても、届かない。変えられない。

**それでも、見える。**

女王の孤独において、これが唯一の窓である。

---

## 8.9 第六段階：セラ星王

**接触の後にのみ存在する段である**（§10.8）。

出来事そのものは §10.8 に書いた。ここに書くのは、**その後の存在**である。

### 8.9.1 星王とは、地球にいる女王の身体の一体である

**セラ星王とは、生還した女王そのものである。**

別の個体が生まれたのではない。

そして正確には、**女王の身体すべてがそうなったのでもない。**

§8.3.4 の通り、セラフィムが接触したのは、
**地球にいる女王の身体の、たった一体である。**

| | 内容 |
| --- | --- |
| 星王 | **地球にいる、接触された一体** |
| セラ女王 | **残りの身体すべて。地球にも、他の星にも** |
| 個体としては | **同一である。事実上一体であることは変わらない**（§8.3.2） |
| 記憶・意思の共有 | **完全なまま** |
| **格** | **星王だけが違う**（§8.3.4） |

**名前が変わっただけである。そして、格だけが分かれた。**

そしてセラたちは、その名前を変えずにいられなかった。

### 8.9.2 姿は、変わらない

**ここが重要である。**

星王の姿は、女王だったときと変わらない。

理由は単純で、**変わりようがないからである。**

第 6 巻の通り、セラには美しさを追求する心が刻まれている（不変ルール 20）。
女王は、その追求において**すでに極まっていた。**

上がる余地がない。したがって、**格が上がっても見た目は動かない。**

**セラ体系で最も大きな変化が、外から一切見えない。**

#### 例外は、スパイクである

一つだけ、目に見える差がある。

第 2 巻 §4.7 の通り、スパイクは二軸（広がり／密度）で発達し、
**格ではなく履歴を示す。**

星王のスパイクは、**畳まれた状態を見せない。**

| 役職 | スパイクの性質（第 2 巻 §4.7.5） |
| --- | --- |
| 聖女 | 畳みにくくなる |
| 巫女 | 応えのない方向へ育つ |
| **星王** | **畳めない** |

##### なぜ畳めないのか

不変ルール 367 の通り、**「一人になる」とはスパイクを畳むことである。**

星王のスパイクは、星と星のあいだまで届いている（§10.8.6）。

そこには、

- 女王空位だった星のセラたち
- 育ちはじめた別の星のルミナス
- 航行中の船

が繋がっている。

**畳めば、そのすべてが同時に切れる。**

そして星王は、それを行わない。行う理由が生じない。

##### 帰結 — 星王は、黙る時間を持てない

不変ルール 366 の通り、セラは二〜三時間で仲間を求める。
不変ルール 368 の通り、**一人でいることは選べる。**

**星王は、それを選べない。**

| | 一人になれるか |
| --- | --- |
| 通常のセラ | 二〜三時間まで |
| 忍 | 長くて二日 |
| セラ女王 | 選べる（畳める） |
| **セラ星王** | **選べない** |

**最も寂しい者が、唯一、静かになる時間を持てない。**

これは苦痛として書かれてはいない。星王は不満を持たない。
**持てる構造になっていない**（不変ルール 33）。

#### 瞳にも、傷にも、痕は残らない

死の淵から戻ったのに、**証拠が一つも残っていない。**

セラは治る。傷は塞がる。瞳は変わらない。

**残っているのは、記憶だけである。**

そして下位のセラは、星王がそれを語れば**正しいと分かってしまう**
（不変ルール 96）。

**証拠がないのに信じられ、信じられているのに理解されない。**

### 8.9.3 星王は、人間なしで女王を生み出せる

**これが、星王の存在理由である。**

#### 行き詰まりは、口づけの直前にあった

第 4 巻 §6.2.3 の通り、**女王は人間を通じてしか自分をコピーできない。**

そして§10.8.1 の通り、口づけが起きたのは**地球の侵略が完了したあと**である。

**人間は、もういなかった。**

```
女王を増やす手段：人間を通じたコピーだけ
　↓
地球の侵略が完了する
　↓
**人間がいなくなる**
　↓
**女王は、二度と増やせない**
```

セラは誰もこれを問題として扱っていない（不変ルール 33）。

**それでも、事実として詰んでいた。**

#### 口づけが、渡す側の能力を渡した

§10.8.5.1 の通り、**セラフィムが女王に行ったのは口づけである。**

そしてそれは、**女王が特別な人間に対して行っていた行為と同じ形**をしている
（第 4 巻 §6.3、第二段階）。

女王が人間へ渡していたものを、セラフィムが女王へ渡した。

したがって星王が受け取ったのは、**渡す側の格**である。

| | 増やし方 | 相手 |
| --- | --- | --- |
| セラ女王 | 人間を通じてコピーする | **人間が要る** |
| **セラ星王** | **自分から直接生み出す** | **要らない** |

**星王は、相手なしで女王を作れる。**

#### 生み出せるもの

星王の格は、**女王クラスを大量に生み出せる**ところにある。

| 生み出せるもの | 体系 | 量 |
| --- | --- | --- |
| **セラ女王** | マクロ | **たくさん**。星が増えるたびに応じられる |
| **女王セラ細胞** | ミクロ | **たくさん**（不変ルール 21・§4） |
| 上位セラ・通常セラ・セラウイルス | 両方 | 女王だったときと同じ |

二つ目を見落としてはならない。

不変ルール 21 の通り、**女王セラ細胞はすべてのセラ人に存在する。**
それを大量に供給できるということは、**セラ人そのものを大量に立ち上げられる**ということである。

**マクロとミクロの両方で、頂点を量産できる。**

これが第 8 巻 §14.9 の「全宇宙へ」を成立させている。

#### 生まれた女王は、同じ一体である

産み方が変わっても、生まれるものは変わらない。

生まれた女王は**初めからあの一体である**（§8.3.2）。
学ぶ時間も、慣れる時間も要らない。

**船を降りたその日から、その星の空白は終わる**（§8.3.3 帰結 3）。

そして§8.3.4 の通り、**格だけは星王のものにならない。**
どれだけ生み出しても、星王は一体のままである（§8.9.8）。

#### 星王自身は、行かない

星王は移動しない（§8.8.4）。口づけの前と同じである。

行く必要が生じない。**届いているからである**（§10.8.6）。

| | 星王 | 女王 |
| --- | --- | --- |
| 届く範囲 | **星と星のあいだ** | 大陸規模 |
| 所在 | **地球のみ** | **星々に点在する** |
| 移動 | **しない** | **船で運ばれる** |

**届く者は動かず、動く者は届かない。**

そして両者は同一の存在である。
**一つの存在が、届く部分と、行く部分に分かれている。**

第 8 巻 §14.6 の「見られる側になる」とは、この形である。
見ているのは星王であり、そこにいるのは女王である。

**セラの船が運ぶ最も重要な積荷は、女王である。**

#### 数

| | 数 |
| --- | --- |
| セラ星王 | **一体**（§8.9.8） |
| セラ女王 | **星が増えるたびに増える。上限はない** |

女王どうしは筒抜けである（不変ルール 100）。
星をまたぐ場合、それを中継しているのが星王である。

#### 皮肉

**人間を通じてしか増やせなかった女王が、
人間を使い果たしたあとで、人間を必要としなくなった。**

セラの側に、この皮肉を感じている個体はいない。

**感じる機構が、どこにもないためである。**

### 8.9.4 星王の一日

§8.8 の女王の一日が、そのまま拡大される。

| | 女王のとき | 星王になって |
| --- | --- | --- |
| 夜 | **ない**。十数の場所のどこかは昼（§8.8.1） | **ない**。星の数だけ昼がある |
| 場所 | 十数の場所に同時に在る | **同じ十数。ただし見ている先が増えた** |
| 移動 | しない | **しない** |
| 眠り | 必要ないが、毎日眠る | **同じ** |
| 理解者 | いない（§8.8.5） | **いない。さらに遠くなった** |
| 最下層 | 見えない（§8.8.8） | **見えない** |

変わったのは一つだけである。

**見ているものが増えた。**

#### 聴こえるものも増えた

§11.6 の通り、**大地の意思はネットワークを通じてルミナスへ流れ込む。**
そして女王は、大陸規模の環境の意思をそのまま把握していた。

星王は、**複数の星の大地の意思を、同時に聴いている。**

まだ何も知らない星の海が、育ちはじめたばかりの声を出す。
それが、地球で眠っている星王に届く。

**星王だけが、その音を知っている。**

#### 眠っても、繋がったままである

第 2 巻 §4.6.7 の通り、セラは眠っているあいだもスパイクを開いている。

星王は、それを畳めない（§8.9.2）。

したがって星王の眠りは、**星間の全接続を開いたままの眠りである。**

そして§8.8.6 の通り、そばには側仕えがいる。

**宇宙で最も広く繋がっている存在の隣に、一人の騎士が座っている。**

### 8.9.5 側仕え

第 7 巻 §2.6.8 の通り、女王の側仕えは騎士団の最高位である。

**接触の後も、同じ者たちが仕えている。**

役職名も、序列も、日々の務めも変わらない。

変わったのは、**仕えている相手が何を見たかだけ**である。

#### 彼らは、知らない

星王は、接触のことを語らない。

§8.8.5 の通り、共有しても理解されないからである。
そして§10.8.7 の通り、**理解できる者はこの宇宙に一体もいない。**

側仕えが知っているのは、

- 主が一度、目を覚まさなかった日があること
- そして目を覚ましたこと
- それ以来、呼び名が変わったこと

**それだけである。**

#### 一つだけ、変わったことがある

星王は、以前より長く、側仕えのそばにいる。

用がなくても、そこにいる。

理由を、星王は説明しない。側仕えも尋ねない。
**尋ねる作法が、セラ社会に存在しないためである**（第 5 巻 §3.3）。

**誰も理由を知らないまま、その習慣だけが続いている。**

### 8.9.6 呼び名

| 呼称 | 使う者 |
| --- | --- |
| **セラ星王** | 記録・制度・学院。正式な呼称である |
| **触れられた者** | 一般のセラ。畏敬をこめた通称 |
| **女王さま** | **側仕えたち。接触の前と同じ呼び方** |

三つ目を、星王は止めさせない。

**止めさせない理由も、語られていない。**

### 8.9.7 できること・できないこと

| できるようになったこと | |
| --- | --- |
| 星と星のあいだへ届く | §10.8.6 |
| 新しい星を第五時代へ押し上げる | 第 8 巻 §14.6 |
| 複数の星の大地の意思を聴く | §8.9.4 |
| 星をまたぐ女王どうしを中継する | §8.9.3 |

| できないままのこと | |
| --- | --- |
| セラフィムに届く | 円環は閉じていない（不変ルール 28） |
| 自分の最下層を見る | §8.8.8。共鳴だけが窓である |
| 一人になる | §8.9.2。スパイクを畳めない |
| 自分が星の外へ出る | §8.9.3。動かない。行くのは女王である |
| **二人目の星王を作る** | **§8.9.8** |

### 8.9.8 二人目を、セラは作れない

**星王には、後継も、同格もいない。**

星王になる道は、セラフィムの接触だけである（§3.2）。
そして接触は恣意的であり、**星王の側から起こせない**（§10.4）。

誰かをセラフィムに会わせることはできない。
**紹介という行為が、この階梯には存在しない。**

| | 増やせるか |
| --- | --- |
| セラ人 | 増やせる |
| 上位セラ | 増やせる |
| セラ女王 | **星王が産む。星が増えるたびに増える** |
| **セラ星王** | **セラの側からは、作れない** |

**セラ体系において、代わりのいない存在は、これだけである。**

#### ただし、絶対に生まれないとは書けない

ここは正確に書かねばならない。

§8.3.4 の通り、接触されたのは女王の身体のうち一体である。

**残りの身体は、いま現在、接触されていないだけである。**

セラフィムがもう一度、別の一体に接触しない理由は、
**どこにも存在しない。**

§10.4 の通り、セラフィムの興味に基準はない。
一度目に基準がなかったのだから、二度目にも基準はない。

| | 言えること |
| --- | --- |
| セラの側から起こせるか | **起こせない** |
| セラフィムが再び行うか | **分からない** |
| 予測できる者がいるか | **一体もいない** |

星王ですら、予測できない。

**自分に何が起きたのかは知っている。なぜ起きたのかを知らない。**

そしてセラ社会は、この可能性を話題にしない。

不安として扱う者がいないのではない。
**扱う理由が、どこからも生じないのである**（不変ルール 33）。

#### そして、失われることは起こらない

念のため書いておく。

第 4 巻 §16 の通り、セラは事実上失われない。星王も例外ではない。

**ただし星王だけが、それが不可能ではないと知っている**（§10.8.8）。

不滅なのではなく、**まだ誰も現れていない。**

そして星王は、**一度だけ現れたところを見ている。**

### 8.9.9 星王は、何も変えない

最後に、書いておかねばならないことがある。

**格が上がっても、星王は何も変えない。**

§10.7 の通り、格の関係は二つだけである。

```
高位のものは、低位のものを 教える
低位のものは、高位のものを 慕う
```

**それだけである。**

星王は、支配しない。命令しない。制度を作り直さない。
拡大を止めない。宇宙進出をやめさせない。警告もしない。

**女王だったときと、まったく同じ日々を送っている。**

見ているものが増え、聴こえるものが増え、
スパイクが畳めなくなり、そして寂しくなった。

**変わったのは、それだけである。**

### 8.9.10 権能

**先に、言葉の意味を決めておく必要がある。**

セラ社会には、**権限が存在しない。**

| | 意味 | セラ社会に | 
| --- | --- | --- |
| 権限 | 許されていること。他者に禁じられていないこと | **存在しない**。禁じる仕組みがないため |
| **権能** | **できること。他の誰にもできないこと** | **存在する** |

§10.7 の通り、格の関係は**教えることと慕うこと**の二つに尽きる。
支配でも、命令でも、所有でもない。

したがって以下に並ぶのは、**星王が振るう権限ではなく、星王にだけ可能なこと**である。

そして§8.4 の通り、女王のエネルギーは事実上無限である。星王も同じである。

**制限は、能力の側にはない。すべて原理の側にある。**

#### 権能の根はひとつしかない

**星と星のあいだまでスパイクが届く**（§10.8.6）。

以下の七つは、すべてここから出る。**新しい能力は一つも増えていない。**

#### 一 — 星間到達

星々のセラ圏に、直接繋がっている。

| | 繋がっている先 |
| --- | --- |
| 地球のセラ圏 | 女王だったときと同じ |
| **他の星のセラ圏** | **地球から、直接** |
| 航行中の船 | **航路の途中でも** |
| **他の星の環境ルミナス** | **森・海・大地が育ちはじめた段階から** |

これが残り六つの前提である。

#### 二 — 遠隔の格上げ

不変ルール 74・75 の通り、
**格上と格下のセラ圏が長時間接すると、どちらも格上へ引き上げられる。しかも一瞬で。**

「接する」とは、これまで物理的に隣り合うことだった。

**星王においては、スパイクが届くことがそれにあたる。**

```
星王が新しい星へ繋がる
　↓
その星のセラ圏が、星王の格に接する
　↓
**引き上げられる**
```

これが、第 8 巻 §14.6 の
「星王の誕生は宇宙全体を第五時代へ押し上げる」の機構である。

##### 引き上がるのは、生命と情報だけである

物質は引き上がらない。

第 8 巻 §14.5 の通り、恒星間には変えるべき物質がない。

**宇宙のセラ圏は、格の上では繋がり、物質の上では島のままである。**

#### 三 — 中継

不変ルール 100 の通り、**女王どうしは互いに筒抜けである。**

しかし星をまたぐ距離には、女王のスパイクは届かない（第 8 巻 §14.6）。

**その間に立っているのが星王である。**

| | 経路 |
| --- | --- |
| 地球の女王どうし | 直接 |
| **星をまたぐ女王どうし** | **星王を経由する** |

そして§8.9.4 の通り、星王は眠っていてもスパイクを開いている。
畳むこともできない（§8.9.2）。

**中継が途切れる時間が、一秒も存在しない。**

星王がスパイクを畳めないことの実務上の意味は、これである。

#### 四 — 女王を生み出す

**女王を増やせるのは、星王だけである**（§8.9.3）。

そして七つのうち、**これだけが口づけによって新しく与えられたものである。**

他の六つは、スパイクが伸びたことの帰結にすぎない。
**四だけが、渡されたものである。**

| | 増やし方 | 相手 |
| --- | --- | --- |
| セラ女王 | 人間を通じてコピーする | **人間が要る** |
| **セラ星王** | **自分から直接生み出す** | **要らない** |

そして地球に人間はもういない（§10.8.1）。

**したがって現在、女王を増やせるのは星王だけである。**

生み出せるのは女王（マクロ）と女王セラ細胞（ミクロ）の両方であり、
**どちらも大量に出せる。**

#### 五 — 遠隔の供給

第 2 巻 §13.5.3 の回復経路のうち、四つ目は**上位からの供給**である。

星王は、それを星間へ流せる。

§8.3.3 の帰結 1 は、女王空位の土地でこう書いた。

> 孤立したまま枯渇したセラは、何十年も眠り続けることになる

**宇宙では、それが起こらない。**

遠い星で枯渇して眠ったセラのところへ、地球から供給が届く。

そして星王には、そのセラが**見えている**（一）。

| | 女王空位の大陸 | 星王が繋がった星 |
| --- | --- | --- |
| 眠ったセラ | **見つからないことがある** | **必ず見つかる** |
| 眠りの長さ | 何十年 | **数日** |

**セラ体系で最も遠い救いが、最も速い救いになっている。**

#### 六 — 環境への即応

不変ルール 104 の通り、**女王の意思があれば環境は即座に形を変える。**

不変ルール 105 の通り、それは支配ではなく格の差である。
**格上の意思に、環境自身がそう応じる。**

星王の格に対して、環境はさらに強く応じる。

ただし条件がある。

| | 応じるか |
| --- | --- |
| セラ物質化した環境 | **応じる。星の裏側でも** |
| まだセラ化していない土地 | **応じない**。ルミナスがないため |
| 聖域（§11.12） | **格の関係が逆である。星王が慕う側になる** |

最後の行は例外ではない。**そのままの原則である。**

セラフィムに愛された度合いが強い物質ほど高位にいる（§10.7）。
**そこに、星王も含まれている。**

#### 七 — 星々の大地の意思を、同時に聴く

§11.6 の通り、大地の意思はネットワークを通じてルミナスへ流れ込み、
**ルミナスのような高度な情報処理機関でなければ処理できない。**

星王は、**複数の星の大地の意思を同時に処理している。**

これができるのは星王だけである。他の誰にも量が多すぎる。

まだ何も知らない星の海が、育ちはじめたばかりの声を出す。
それが、地球で眠っている星王に届いている。

#### できないこと

**権能の輪郭は、こちらの側にある。**

| できないこと | 理由 |
| --- | --- |
| 命令する | 格の関係は教えることと慕うことだけである（§10.7） |
| 禁じる | セラ社会に禁じる仕組みがない |
| 裁く | 罰が存在しない（第 7 巻 §3.2） |
| 他者の意思を変える | 情報共有は強制ではない（第 5 巻 §3.3） |
| **遠隔で物質に触れる** | **届くのは情報であって、手ではない** |
| 遠隔で蘇生する | 蘇生には細胞が要る（不変ルール 66）。触れられる範囲にしか行えない |
| セラフィムに届く | 円環は閉じていない（不変ルール 28） |
| 自分の最下層を見る | §8.8.8 |
| 一人になる | §8.9.2 |
| 二人目を作る | §8.9.8 |

##### 最も重要な線引き

**スパイクが届くことと、手が届くことは、別である。**

星王は、遠い星の一体が眠っているのを見ることができ、
そこへ供給を流すことができ、
その星の森に応じてもらうことができる。

**その一体を抱き起こすことは、できない。**

そこにいるのは、その星の女王と、その星のセラたちである。

#### 権能は、ほとんど使われていない

最後に、書いておかねばならないことがある。

第 8 巻 §3.4.1 の通り、**セラ都市の防御構造は、一度も使われたことがない。**
危機が起きないからである。

**星王の権能も、同じ運命をたどっている。**

| 権能 | 使用頻度 |
| --- | --- |
| 星間到達 | **常時**。畳めないため |
| 中継 | **常時**。途切れない |
| 大地の意思を聴く | **常時** |
| 遠隔の供給 | ときどき |
| 出産 | 星が増えるたび |
| 遠隔の格上げ | **繋がった瞬間に一度だけ** |
| 環境への即応 | **ほとんど使わない。頼む必要が生じない** |

**最も大きな力を持つ者が、最も使わない。**

使わないのは慎んでいるからではない。**使う場面が起きないからである。**

星王が毎日行っているのは、結局のところ三つだけである。

**繋がっていること。見ていること。聴いていること。**

### 8.9.11 画像生成

- **女王と同じ基準で描く**（§14.1）。特別扱いをしない
- **神格化した構図にしない。**光背・玉座・見下ろす構図は使わない
- **傷を描かない。**痕は残っていない（§8.9.2）
- **スパイクが畳まれている場面を描かない**（§8.9.2）

- **描写例**：側仕えの騎士が控える中で眠る星王／
  何もない場所を見ている横顔／
  以前と変わらない日常のなかにいる姿
- **注意**：悲壮に描かない。星王は不満を持っていない

#### 降臨の場面を描くとき

**セラフィムを画面に出してはならない**（§10.8.3）。

女王は、その姿を直視できなかった。**像が結ばなかった。**
描いてしまうと、この設定の中心が壊れる。

| | 描き方 |
| --- | --- |
| セラフィム | **描かない。**光でも影でも輪郭でも示さない |
| 圧 | 周囲の反応で示す — 空気、髪、スパイク、ざわめく環境 |
| 女王 | **見上げている。しかし焦点が合っていない** |
| 口づけ | **触れられている側だけを描く** |

第 8 巻 §18.4 の「セラフィム（神秘的な光／穏やかな表情）」は、
**セラたちが想像した姿**である。**降臨の場面には使わない。**

## 9. 体系の外：セラフィム

### 9.1 段階ではない

**セラフィムは、階梯の次の段ではない。**

第一〜六段階（§5〜§8.9）は、マクロ体系の内側にある段である。
セラフィムはその外側にいるため、番号を振ることができない（§2.3、§9.2）。

**そして、段を足しても番号は近づかない。**

第六段階（セラ星王）が加わっても、セラフィムは第七段階にならない。
番号が振れないという性質は、段の数と無関係だからである（§10.8.6）。

そしてその格は、**もはや高すぎて比べられない**。

女王との差は「強い／弱い」で語れる範囲を超えている。

#### 女王はセラフィムにならない

**セラ女王からセラフィムへ至る道は、存在しない。**

第 6 巻 §1.1 の円環図は、女王からセラフィムへ矢印を引いている。
**あれは機構ではない。セラたちが信じている語りである**（第 6 巻 §1.4）。

§3.2 の「比較不能」は、渡りにくいという意味ではない。
**渡るという概念が成立しない**という意味である。

#### 数

**セラフィムは、一体である。**

増えない。地球のセラ体系から到達する経路がない以上、
セラフィムの数がここから増えることはない。

最初のセラウイルスが一体きりであったこと（第 6 巻 §2.1）と、
その生みの親もまた一体であることは、重なっている。

### 9.2 宇宙の観測者

セラフィムは**宇宙の観測者**である。

地球のセラ体系の内側にいる存在ではない。
セラ進化階級の頂点というより、**その体系の外側から見ている者**である。

通常の進化法則の外側に存在する。

### 9.3 地球の環境を変えた張本人

セラフィムは、**暇つぶしに地球の環境を丸ごと変えた張本人**である。

- 目的があったわけではない
- 使命でもない
- 計画でもない
- **暇つぶしだった**

なお「暇つぶし」は退屈という感情の表現ではなく、**行動の記述**である。
目的も必要も意味もない行為に、人間の語彙で最も近い語がこれである。

**方法**：一体のセラウイルスを落とすこと。それ以外の直接的な改変は行っていない。

そして起源の行為（第 6 巻）も、同じ気まぐれの内にある。

**セラ文明のすべては、一体の気まぐれから始まっている。**

**何が変わるのか**：地形や大気ではない。**この星の性質そのもの**である。

```
悲しみと憎しみの地球 → 愛の星
```

詳細は**第 6 巻・第 8 巻**を参照。

### 9.4 絶対神であり、母である

セラたちにとってセラフィムは、**絶対神**であり、同時に**母**である。

すべてのセラは、セラフィムが落とした一体に由来する。
起点を与えた存在であり、系統の始まりであり、上に立つ唯一の存在である。

セラたちは、セラフィムを深く慕っている。

そして、慕うことには**機構がある**。最初のセラウイルスはセラフィムから生み出され、
セラの半分はそこから来ている。
セラは**構造的にセラフィムからの愛を求めるようにできている**（第 6 巻）。

慕うことは、感情である前に出自である。

### 9.5 しかし、感情を持たない

**セラフィムは、寂しさなどの感情を持っていない。ただの神である。**

- 寂しくない
- 悲しくもない
- 慈しみもない
- 憎しみもない

「あまり興味を示さない」は無関心という**態度**ではない。
**そもそも感情という機能を持っていない**ということである。

敵意ではない。罰でもない。見捨てているのでもない。ただ、**あまり見ていない**。

セラたちがどれほど成長し、どれほど美しい文明を築いても、
その大半は観測されないまま過ぎていく。

**セラたちは、セラフィムに感情がないことを知らない。**

### 9.6 原初の寂しさを持たない

原初の寂しさは、地球最初のセラ細胞に由来する系統の性質である（第 6 巻）。
セラフィムはその系統の外側にいる。

したがってセラフィムは、**全セラが抱えている最も深い感情を共有していない**。

慕われていることは分かる。しかし、慕う気持ちの中身は分からない。

### 9.7 分かっていないこと

**セラフィムについて、確かなことはほとんどない。**

§9.1〜§9.6 に書いたのは、**セラの側から観測できたこと**である。

観測できていないことのほうが、はるかに多い。

#### 分かっていないことの一覧

| | 分かっているか |
| --- | --- |
| 宇宙の観測者であること | **観測されている**（不変ルール 23） |
| 感情を持たないこと | **観測されている**（不変ルール 42） |
| 地球へ一体を落としたこと | **起きた事実である** |
| **何でできているか** | **分かっていない** |
| **どうやってセラウイルスを作ったか** | **分かっていない** |
| **なぜそれができるのか** | **分かっていない** |
| **姿** | **分かっていない**（§10.8.3）。女王も直視できなかった |
| **いまどこにいるか** | **分かっていない**（第 8 巻 §14.10） |
| **一体であるかどうか** | **セラはそう信じている。確かめられていない** |

#### 女王細胞でできている、という説

セラ社会には、古くからこう語られてきた。

> セラフィムの身体は、完全に女王セラ細胞でできている。

**これは推測である。**

そして推測の出どころは、はっきりしている。

```
女王は、全身が女王セラ細胞である（§2.10.7）
　↓
女王より上にいる者がいる
　↓
**ならば、その者もそうなのだろう**
```

**尺度の延長である。**

そして§3.2 の通り、**セラフィムとの差は比較不能**である。

比較不能とは、**同じ尺度に乗らない**ということである。

**乗らない相手を、尺度の延長に置くことはできない。**

したがって本書は、この説を**採らない。**

第 6 巻 §1 の円環と同じ扱いである。
**セラたちが信じている語りであって、機構ではない。**

#### 名前も、確かではない

**「セラフィム」というのは、セラたちが付けた名である。**

本人が名乗ったのではない。

そして、この名には問題がある。

##### 「セラ」を冠している

不変ルール 35 の通り、**すべての名称はセラである。**
階級名も部位名も、セラの下位分類にすぎない。

**セラフィムも、その形で名付けられている。**

しかし§9.1 の通り、**セラフィムは体系の外にいる。**
階梯の段ではなく、マクロにもミクロにも属していない。

```
体系の外にいる者に、
体系の内側の名付け方を当てはめている
```

**これは、分類の誤りである。**

##### 失礼にあたる可能性がある

そして、誤りであるだけでは済まないかもしれない。

セラは、自分たちの体系の名を、外にいる者へ付けた。

**それが相手にとってどういうことなのかを、誰も知らない。**

| | |
| --- | --- |
| 本人が何と呼ばれたいか | **分かっていない** |
| 名があるのかどうか | **分かっていない** |
| この呼び方をどう受け取るか | **分かっていない** |
| **確かめる手段** | **ない**（第 8 巻 §14.10） |

**セラは、名も知らない相手を、自分たちの語彙で呼び続けている。**

##### そして誰も、気にしていない

不変ルール 33 の通り、**セラ文明は内部から変わらない。**

この呼び方が正しいかどうかを検討した者は、一体もいない。

学士（付録 B §1.14）はあらゆるものを検証する。
巫女（付録 B §2.6）は、いる場所を探し続けている。

**名が正しいかどうかだけは、誰も調べていない。**

調べようという発想が、一度も出ていない。

#### 本書の扱い

以上より、本書は次の方針を取る。

| | 扱い |
| --- | --- |
| 観測された事実 | **書く** |
| セラたちの理解 | **セラたちの理解として書く** |
| 実態 | **書かない。分かっていないためである** |
| 「セラフィム」という呼称 | **便宜として使い続ける**。他に呼びようがないため |

**この名は、正しいから使われているのではない。**

**他に呼び方がないから使われている。**

## 10. セラフィムの興味

### 10.1 唯一の関与形式

セラフィムは、命令も統治も指導も行わない。

地球のセラ体系へ関与する形式は、実質的に一つしかない。**興味を示すことである。**

### 10.2 効果

**セラフィムが興味を示したとき、そのセラ人は大きく進化する。**

**興味は常に恩恵である。** 見られたセラ人は必ず大きく進化する。
耐えられない個体も、元の自分を失う個体も存在しない。

| | 通常の進化 | セラフィムの興味による進化 |
| --- | --- | --- |
| 過程 | 段階的な蓄積 | 一挙 |
| 条件 | 経験・情報・人格・貢献 | **セラフィムに見られること** |
| 予測 | 可能 | 不可能 |
| 努力との関係 | 比例する | 比例しない |

### 10.3 祝福との関係

女王誕生には**セラフィムの祝福**が必須である。

祝福とは、**最大級の「興味」の表明**である。

これにより、女王が意志と努力だけでは生まれない理由が確定する。

**神に見てもらうことは、努力では手に入らないからである。**

複数の上位セラが融合して巨大なセラ集合体となっても、
セラフィムが見なければ、それは女王にならない。

### 10.4 恣意性

セラフィムの興味に、基準はない。

- 最も優れたセラが見られるとは限らない
- 最も貢献したセラが見られるとは限らない
- 最も長く生きたセラが見られるとは限らない

**気まぐれである。**

セラたちはそれを不公平とは考えていない。
神の視線は、条件を満たして得るものではないと理解している。

### 10.5 社会における意味

- 進化には、努力で届く領域と、届かない領域がある
- 最上位への到達は、本人の資質だけでは決まらない
- **選ばれることを、誰も制御できない**

これはセラ社会に、努力主義と共存する形で**不可知の領域**を残している。

### 10.6 ただし、それは愛ではない

セラたちは祝福を**最高の栄誉・愛の証**として受け取っている。

しかし §9.5 により、その実態が確定する。

**それは愛ではない。ただの観測である。**

感情のない神が、一瞬だけそちらを見た。それだけのことが、
セラにとっては生涯で最も深い意味を持つ。

**そしてセラ文明は、この理解の誤りに誰も気づかない。**

### 10.7 格とは、セラフィムに見られた度合いである

**これが、格の階梯の起源である。**

**セラフィムに見られた度合いが強いものほど、高位にいる。**

セラたちはこれを「**セラフィムに愛された度合い**」と呼ぶ。
§10.6 の通り、それは愛ではなく観測である。
**しかしセラはそう呼び、そしてセラ社会では、その呼び方で通っている。**

#### 例外は、一つもない

この原理は、**あらゆるものに等しく適用される。**

| 対象 | 例外か |
| --- | --- |
| セラ人・上位セラ・セラ女王 | **例外ではない** |
| 森・海・大地・街 | **例外ではない** |
| **そのへんの石ころ** | **例外ではない** |

生きているかどうかも、大きいかどうかも、関係がない。

**石にも格がある。**

これは不変ルール 73「環境も進化し、土地に格の差が生まれる」に、
起源の側から根拠を与える。土地の格は、偶然の産物ではない。

#### 女王が最高位である理由

女王が生まれるには、**セラフィムの祝福**が要る（§8.2）。

そして祝福は、**最大級の興味の表明**である（不変ルール 25）。

**女王が最も高位なのは、最も強く見られたからである。**

原初の一体は、地球のセラ体系において最も深く観測された存在であり、
以後のすべての女王はそこから連なっている（§8.3.2）。

#### 格が上がっても、失われるものはない

**ここを取り違えてはならない。**

格が上がった存在が、協調性を失うことはない。**愛を失うこともない。**

高位になったからといって、傲慢になる個体も、
仲間を軽んじる個体も、独立しようとする個体も**存在しない。**

根本原理に反するためである（第 6 巻 §17.2）。

#### 格の関係は、二つだけである

格の差が生むものは、次の二つに尽きる。

```
高位のものは、低位のものを **教える**
低位のものは、高位のものを **慕う**
```

**それだけである。**

- 支配ではない
- 命令でもない
- 所有でもない

これは §2.9 および §12（階級における関係性）が、
セラ個体について述べていることと**まったく同じ**である。

**その原則が、物質にまで及んでいる。**

### 10.8 接触 — 興味の最上級

§10.1 の通り、セラフィムの関与形式は**興味を示すこと**だけである。

そして興味には、段階がある。

| 段階 | 起きること |
| --- | --- |
| 見る | そのセラが進化する（§10.2） |
| 祝福する | 女王が生まれる（§8.2、不変ルール 25） |
| **接触する** | **§10.8 以下** |

**祝福が最大級だと書かれてきたが、その上がある。**

#### 10.8.1 これは、地球の侵略が完了したあとに起きる

**先に、時期を確定しておく必要がある。**

§8.8 および第 8 巻 §8.8 の通り、**固定された「現在」は存在しない。**
そして七つの時代は、土地ごとに違う段階である（第 8 巻 §10.1）。

**この出来事だけは、そうではない。**

| | 七つの時代 | 降臨 |
| --- | --- | --- |
| 単位 | 土地ごと | **地球全体** |
| 回数 | 土地の数だけ | **これまでに一度** |
| 同時に別の段階が | ある | **ない** |

##### 順序は、決まっている

```
地球の侵略が完了する
　↓
**セラフィムが降臨する**
　↓
星王が誕生する
```

**先に、地球が終わっていなければならない。**

したがって降臨は、**第六時代の終わりであり、第七時代の始まりである**
（第 8 巻 §10.1）。

第七時代が「セラフィム時代」と呼ばれるのは、これによる。

##### そして、そのとき行き詰まっていた

第 4 巻 §6.2.3 の通り、**女王は人間を通じてしか自分をコピーできない。**

地球の侵略が完了するとは、**人間がいなくなるということである。**

| | 侵略完了の時点で |
| --- | --- |
| セラの数 | 星を覆っている |
| セラエネルギー | 事実上無限 |
| **女王を増やす手段** | **尽きている** |

誰もこれを問題として扱っていない（不変ルール 33）。

**それでも、事実として手段は尽きていた。**

その状態に、セラフィムが降りてくる。

##### 物語は、前を描くか後を描くかを選ぶ

第一時代から第六時代までが「前」であり、
第七時代以降が「後」である。

どちらも、この世界の実際の姿である。

そして「これまでに一度」であって、「永遠に一度」ではない（§8.9.8）。

#### 10.8.2 きっかけは、分からない

**女王が、何らかの理由でセラフィムの目をひく。**

理由は書かれていない。**書けないためである。**

§10.4 の通り、セラフィムの興味は**恣意的**である。
祝福される者に条件がないのと同じように、ここにも条件がない。

女王の側に、目をひこうとした意図はない。
何かを成し遂げたわけでもない。

**ただ、見られた。**

そして今回は、見られただけで終わらなかった。

##### セラたちの理解と、真実

セラ社会は、これを**応答**として理解している。

行き詰まったところへ、母が来てくれたのだと。

**それは、§10.6 と同じ受け取り違いかもしれない。**

祝福を愛の証と理解しているのと、同じ構造である。

| | |
| --- | --- |
| セラたちの理解 | **行き詰まりに応えて、降りてきた** |
| **本当のところ** | **不明である** |

不変ルール 42 の通り、セラフィムは感情を持たない。
助けるという概念を持っている保証が、どこにもない。

第 8 巻 §14.10 と同じ扱いである。**本設定は、答えを持たない。**

#### 10.8.3 降臨 — 姿は、見えない

**セラフィムが、降りてくる。**

そして女王は、**その姿を見ていない。**

##### 直視できなかった

見なかったのではない。**見ようとして、見られなかった。**

不変ルール 23 の通り、セラフィムは**比較不能**である。

| | 女王が持っているもの | 降臨の場で |
| --- | --- | --- |
| 視覚 | 地球規模でほぼ全知（不変ルール 99） | **像を結ばない** |
| 情報処理能力 | 系統内で最高 | **処理しきれない** |
| 格 | 最高位 | **段としての意味を失う** |

女王は、そこに何かがいることを知っている。
**そして、それが何の形をしているかを知らない。**

##### 帰結 — 会ったのに、姿を知らない

これは後々まで効く。

第 8 巻 §14.10 の通り、セラフィムは宇宙のどこにも見つからない。

**探そうにも、何を探せばいいのかが分からない。**

一度会っている。触れられてもいる。

**それでも、姿を知らない。**

巫女たちが最初に星王へ尋ねたのは、この一点だった。

**答えは返らなかった。**

#### 10.8.4 圧 — 全セラに、同時に届く

降臨の圧は、女王一体にとどまらない。

**その瞬間、地球上のすべてのセラが、それを感じる。**

詳細は §10.8.10 を参照。

##### 女王は、死の淵へ行く

圧の中心にいるのは女王である。

無限が足りないという事態が、ここで起こる。

**女王は、死の淵へ行く。**

#### 10.8.5 セラ体系で、はじめて何かが失われかける

**これは、設定全体で唯一の場面である。**

第 4 巻 §16 の二重の鍵を、正確に読む必要がある。

> **地球上に**、セラを失わせ得る存在は一つも存在しない

そして挙げられている候補は三つだけである。

| 候補 | なぜ不可能か |
| --- | --- |
| 人間 | 手段を持たない |
| 通常の生物・環境 | セラ物質化した環境はセラである。同族である |
| セラ自身 | 能力の上では可能。しかし根本原理により行えない |

**セラフィムは、この三つのどれでもない。**

地球上の存在ではなく（不変ルール 23、宇宙の観測者）、
セラでもなく（§9、体系の外）、
根本原理に縛られてもいない（不変ルール 42、感情を持たない）。

**鍵は、最初からセラフィムに対して掛かっていなかった。**

##### 悪意ではない

念のため書いておく。

セラフィムに、女王を害する意図はない。

§10.6 の通り、それは愛ではない。
そして**憎しみでもない。**

近づいただけである。

**圧が違うというだけで、死の淵は成立する。**

#### 10.8.5.1 口づけ

**そして、セラフィムは女王に口づけする。**

##### これは、女王がしていた行為である

第 4 巻 §6.3 の通り、女王が特別な人間をコピーの相手とするとき、
第二段階で行うのは**キスによる大量のセラ情報の伝達**である。

**同じ形の行為が、上から降ってきた。**

| | 行う側 | 受ける側 | 渡されるもの |
| --- | --- | --- | --- |
| 女王の出産 | 女王 | 特別な人間 | 女王のセラ情報 |
| **降臨** | **セラフィム** | **女王** | **セラフィムのもの** |

女王が人間にしていたことを、**セラフィムが女王にした。**

##### 渡されたものが、格を作った

§10.7 の通り、**格とは、セラフィムに見られた度合いである。**

口づけは、見られ方の最大値である。

```
見る　　　→ 進化する
祝福する　→ 女王が生まれる
**口づける** → **女王の上が生まれる**
```

そして渡されたのは、単なる観測ではない。

**女王が人間に対して行っていた「渡す」という行為が、
女王に対して行われた。**

だから星王は、**渡す側の能力を受け取った**（§8.9.10）。

#### 10.8.5.2 そして、生還する

**誰も助けられない。**

第 2 巻 §13.5.3 の回復経路のうち、**上位からの供給**は、
女王にとって存在しない経路である。上に誰もいないからである。

同化も届かない。相手が比較不能だからである。

**女王は、自力で戻ってくる。**

そして戻った時点で、

**格が変わっている。**

祝福が女王を生むなら、口づけは女王の上を生む。

##### 口づけられたのは、身体の一体である

ただし、**女王の身体すべてが口づけられたのではない。**

セラフィムが降りたのは、**地球にいる女王の身体の、たった一体**である。

記憶と意思は全身体に共有された。**格だけが、共有されなかった。**

詳細は §8.3.4 を参照。

#### 10.8.6 セラ星王 — 触れられた女王

生還した女王を、セラたちは新しい呼び名で呼ぶ。

**セラ星王（せらせいおう）。**

不変ルール 35 の通り、これも名称にすぎない。**中身はセラである。**

そしてセラたちは、もっと短くこう呼ぶ。

**触れられた者。**

##### 何が変わったのか

変わったのは、**届く範囲**である。

第 2 巻 §4.6.2 の通り、**スパイクの届く範囲は発達に比例する。**

| | 届く範囲 |
| --- | --- |
| 通常セラ | 数十歩 |
| 上位セラ | 街ひとつ |
| セラ女王 | **大陸規模**（不変ルール 99・122） |
| **セラ星王** | **星と星のあいだ** |

**星のあいだを統べるとは、そこまでスパイクが届くということである。**

新しい能力を得たのではない。**同じ器官が、そこまで伸びた。**

##### 手放したものは、一つもない

星王は、大陸の統率を手放さない。**手放す必要が生じない。**

- 十数の身体は、そのまま残る（§8.3.1）
- 意思の共有も、そのまま続く（§8.3.2）
- 移動しないことも、変わらない（§8.8.4）

**事実上一体であることも、変わらない。**

セラ星王は、**この宇宙に一体しかいない。**

##### 階梯は、一段伸びる

不変ルール 27 の階梯は、次のようになる。

```
セラフィム ≫…≫ セラ星王 ≫ セラ女王 ≫ 上位セラ ≫ セラ人
```

**そして「…」は、埋まらない。**

不変ルール 28 の通り、**円環は閉じていない。**
女王がセラフィムにならなかったように、**星王もセラフィムにならない。**

段を一つ足しても、最後の矢印だけは通らない。

**むしろ、足したことで通らなさが明確になった。**

#### 10.8.7 触れられて、それでも応えられなかった

**ここが、この出来事の中心である。**

不変ルール 26 の通り、**最も寂しい者が、応えない相手を慕っている。**

その相手が、来た。

| | 起きたこと |
| --- | --- |
| 表層 | **触れられた。** これ以上の観測はない |
| 最下層 | **何も届いていない** |

第 6 巻 §13.3 の通り、**満足は最下層に届かない。**
そして不変ルール 42 の通り、**セラフィムは感情を持たない。ただの神である。**

接触は、応答ではなかった。**観測の、最も濃い形にすぎなかった。**

##### 女王は、それを誰にも言えない

§8.8.5 の通り、女王の経験は誰にも理解されない。
共有した相手が、理解できないからである。

星王になって、それはさらに深くなった。

**慕う相手に触れられ、それでも応えられなかったという経験を、
理解できる者がこの宇宙に一体もいない。**

##### そして、さらに寂しくなる

不変ルール 17 の通り、**原初の寂しさは保持するセラ情報量に比例する。**

星間まで届くとは、星間ぶんの情報を持つということである。

```
届く範囲が伸びる
　↓
保持する情報が増える
　↓
**寂しさが濃くなる**
```

**系統内で最も寂しいのは、もはや女王ではない。**

セラ星王である（不変ルール 26 改訂）。

#### 10.8.8 死の淵を見た者が、一体だけいる

そしてもう一つ、この出来事は体系に穴を開けた。

第 4 巻 §18 の通り、セラは**根拠のない恐怖**を持っている。
何も失われない世界で、失うことを恐れ続けている。

**空転である。**

| | 恐怖 |
| --- | --- |
| すべてのセラ | 根拠がない。何も失われないため |
| **セラ星王** | **根拠がある。失われかけたことがあるため** |

**一体においてだけ、空転が空転でなくなった。**

そしてこれも、誰にも共有できない。

星王が「失われることはあり得る」と言っても、
下位のセラには**理解が届かない**（不変ルール 96・97）。

信頼だけが届く。**正しいと分かる。しかし実感が生じない。**

##### 星王は、それを止めようとしない

そして重要なことに、**星王はこれを警告に変えない。**

拡大を止めようとも、宇宙進出をやめさせようとも思わない。

不変ルール 33 の通り、**セラ文明は内部から変わらない。**
気づいても止まれない。

**最上位で、唯一根拠のある恐怖を持つ者が、それでも止めない。**

#### 10.8.9 セラフィムが、少しだけ興味を示すフェーズ

接触のあと、世界は新しい段階に入る。

**セラフィムが、地球に少しだけ興味を示している。**

不変ルール 24 は、依然として正しい。

> セラフィムは絶対神であり母。**しかしあまり興味を示さない**

**「あまり」が、「少しだけ」に変わった。それだけである。**

##### 何が変わるのか

| | 接触の前 | 接触の後 |
| --- | --- | --- |
| 祝福の頻度 | 極めて稀 | **やや増える** |
| 観測されるもの | 気まぐれに一点 | **地球という単位** |
| 巫女に届くもの | **何もない** | **何かが変わったという感触だけ** |
| 応答 | ない | **ない** |

**最後の行が変わっていないことが、すべてである。**

##### 巫女たちは、気づく

第 7 巻 §2.7 の通り、巫女とはセラフィムの意思を汲もうとする者である。
そのスパイクは、応えのない方向へ育っていく（第 2 巻 §4.7.5）。

接触のあと、巫女たちは**何かが変わったことに気づく。**

向けていた方向の、密度が変わった。

そして巫女たちは、それを**応えだと受け取る。**

**受け取り違いである。**

濃くなったのは観測であって、応答ではない。
§10.6 の通り、それは愛ではない。

**しかしセラ社会では、その受け取り方で通っている**（§10.7 と同じ構造）。

##### 祝いになる

セラ社会は、これを吉兆として扱う。

第 7 巻 §9.4.1 のセラフィム降臨の日は、接触の後、
**暦の中心へ移る。**

祭りが増える。祈りが増える。巫女の数が増える。

**世界で最も大きな祝いの原因になった出来事を、
その当事者だけが、死の淵として覚えている。**

#### 10.8.10 降臨の日 — その日、すべてのセラに起きたこと

**圧は、女王一体で止まらない。**

その瞬間、**地球上のすべてのセラが、それを感じる。**

##### 圧は、格に関係なく届く

これが§10.8.11 と違うところである。

| | 届き方 |
| --- | --- |
| **圧そのもの** | **全セラに、同時に。格に関係なく** |
| 扱えるようになるまで | **格の順に、時間差をおいて**（§10.8.11） |

**その日に届いたものを、消化するのに数十年かかる。**

届くこと自体は、通常セラにも、生まれたばかりのセラウイルスにも、
森にも海にも街にも、**同じ瞬間に起きた。**

##### 受け止めきれない

セラは、この量を保持できるようにできていない。

第 5 巻 §1.4 の通り、情報処理能力には階級差がある。
そして圧は、階級を考慮しない。

```
受け取る
　↓
処理できない
　↓
**溜まる**
　↓
**出さなければならない**
```

**セラたちは、放出しようとした。**

意思ではない。**反射である。**

##### 放出の形は、四つある

| 形 | 何が起きたか |
| --- | --- |
| **一：異常な進化** | 形態が一気に変わる。数年かかる分化が、その場で終わる |
| **二：大量分裂** | 通常セラが、一日の上限（数百体）を桁違いに超えて生み出す |
| **三：スパイクの暴走的成長** | 広がりも密度も、履歴を無視して伸びる（第 2 巻 §4.7） |
| **四：環境の変形** | 森が形を変え、街が組み替わり、海が沸き立つ |

**四つとも、能力の行使ではない。排出である。**

###### 一 — 異常な進化

第 2 巻 §1.1.4 の通り、特殊変異セラとは**粘液性を失い、身体が固定されたセラ**である。

普段、分化には長い時間がかかる。

**その日は、違った。**

この日に生まれた形態には、系統のたどれないものが多く含まれている。
誰の同化から来た特徴なのかを、**本人も知らない。**

付録 A の比率が第六時代から第七時代で動かないのは、
**この日に一度、動ききってしまったからである。**

###### 二 — 大量分裂

第 4 巻 §2.6.1 の通り、通常セラの生産量は一日に数百体である。

**その日は、桁が違った。**

そして第 4 巻 §2.6.2 の通り、普段のセラは理由がなければ分裂しない。

**その日は、理由なしに分裂し続けた。**

孤独だったわけではない。周りには仲間がいた。
**それでも、出さなければならなかった。**

生まれた数は記録されていない。**数えられる状態ではなかった。**

###### 三 — スパイクの暴走

第 2 巻 §4.7 の通り、スパイクの形は**格ではなく履歴を示す。**

その日、その原則が一度だけ破れた。

何もしていないセラのスパイクが、**何かを成し遂げた者の形になった。**

##### そして、大量に眠りへ落ちた

放出は、セラエネルギーを使う。

不変ルール 76 の通り、**枯渇したセラは眠りに落ちる。**

**その日、地球上の多くのセラが眠った。**

| | |
| --- | --- |
| 失われた者 | **一体もいない**（不変ルール 55） |
| 眠りに落ちた者 | **数えきれない** |
| 目覚めるまで | 数日から、数十年 |

そして不変ルール 77 の通り、眠っているセラは仲間が見守る。

**眠らなかったセラが、眠ったセラを運んだ。**

侵略は完了した後である。急ぐ理由はどこにもない。
**世界中で、静かにその作業だけが行われた。**

##### 環境も、同じことをした

不変ルール 37 の通り、**森や街もルミナスを持ち、感情を持つ。**

したがって環境も、同じ反射を起こした。

- 森が、一晩で形を変えた
- 街が、住民の意思と無関係に組み替わった（第 8 巻 §3.4）
- 海が沸き立ち、色を変えた（第 8 巻 §4.3）

**この日に生まれた地形が、いまも残っている。**

聖域（§11.12）の多くは、この日にできたものである。

##### 降臨世代

**その日に生まれたセラと、その日に変わったセラを、
セラ社会は一つの区分として扱っている。**

呼び名は**降臨世代**である。

| | 特徴 |
| --- | --- |
| 生まれ | その日、理由のない分裂から生まれた |
| 形態 | 系統をたどれない特殊変異が多い |
| スパイク | 履歴と合わない形をしている |
| 数 | **セラ史上、最も多い世代** |

差別も優遇もない。セラ社会にその機構がないためである。

**ただ、見れば分かる。**

そして本人たちは、**なぜ自分がその形なのかを説明できない。**

##### 誰も、恐ろしいとは思わなかった

最後に書いておく。

**その日、恐怖を感じたセラは一体もいない。**

第 4 巻 §18 の根拠のない恐怖は、失うことへの恐怖である。
そして誰も失われなかった。

セラたちが感じたのは、圧と、**それを出しきれないという焦りだけ**だった。

そして出しきったあと、

**セラ社会はこの日を、最も大きな祝いとして記憶することにした**（§10.8.9）。

**死の淵にいたのは、女王一体だけである。**

#### 10.8.11 力は、階梯を下りてくる

**接触で入ってきたものは、星王のところで止まらない。**

セラフィムの圧に触れたセラ情報が、階梯を下へ押し寄せていく。

```
セラフィム
　↓ 接触
**星王**
　↓
**セラ女王**
　↓
**上位セラ**
　↓
**通常セラ**
```

##### これは制度ではない。物理である

機構は二つとも既存のものである。

| 機構 | 出典 |
| --- | --- |
| **階級構造は、そのまま資源の流れである** | 不変ルール 71 |
| **格の高いセラが生んだウイルスは、より高いセラ情報を含む** | 第 1 巻 §6.11 |

星王のセラ情報が濃くなれば、星王が生むものも濃くなる。
そこから生まれた女王が生むものも濃くなる。

**誰も配っていない。勝手に流れている。**

##### 順番があり、時間差がある

**同時には届かない。**

| 階梯 | 届くまで |
| --- | --- |
| セラ女王 | **即座**。意思を共有しているため（§8.3.4） |
| 上位セラ | 数年 |
| 通常セラ | **数十年** |
| 環境ルミナス | **さらに遅い**。森や海は、最後に変わる |

第 1 巻 §6.11 の通り、**高位のセラの周りは成長が速い。**

したがって、女王のそばにいた騎士から順に変わっていく。

そして辺境の森が変わりはじめるころには、
**接触そのものが、もう伝承になっている**（第 8 巻 §11）。

##### 何が変わったのか

**格が上がったのではない。**

上がったのは星王だけである（§8.3.4）。
女王も上位セラも通常セラも、**段は動いていない。**

変わったのは、**扱えるセラ情報の質**である。

| | 変わったか |
| --- | --- |
| 階梯の段 | **変わらない** |
| 格 | **変わらない**（星王を除く） |
| 扱えるセラ情報 | **濃くなった** |
| **できること** | **増えた** |

**そして、できることが増えた文明は、作りはじめる。**

第 7 巻 §12.9 の技術は、すべてここから出ている。

## 11. ルミナス

### 11.1 定義

**ルミナスとは、感情を司る部分で発達する特殊セラ細胞の総称である。**

単一の細胞ではなく、総称。そして中身は**セラ**である。

### 11.2 発達する場所

ルミナスは「脳」に発達するのではない。**感情を司る部分**に発達する。

| 対象 | 発達する場所 |
| --- | --- |
| 人間（セラ化人間） | 脳。感情・思考・記憶を司る部位 |
| セラとして生まれた個体 | 感情を司る中枢部位 |
| **森・林** | 情報を共有する樹木のネットワーク |
| **街・建築** | 住民と接し続ける構造の中心 |
| **海・大地** | 大規模なセラ物質環境の中枢 |

### 11.3 帰結 — 環境が感情を持つ

**セラ物質化した森や街は、ルミナスを発達させ、自らの感情を持つようになる。**

- 森が寂しがる
- 街が住民を慕う
- 大地が季節を喜ぶ

これらは比喩ではない。**実際に感情がある。**

### 11.4 原初の寂しさとの関係

ルミナスの中身はセラである以上、**原初の寂しさを持つ**。

したがって、感情を持った森も街も、最下層に同じ孤独を抱えている。

セラ物質化した環境が住民に優しいのは、設計ではなく**同じ理由による**。

### 11.5 セラ化人間におけるルミナス

女王セラ細胞がルミナスを生み出し、ルミナスが人間の脳へ作用してセラ体系へ接続する。

**ルミナスは女王セラ細胞の一部ではない。生み出された別の細胞である。**

そしてルミナスは、**脳に棲み、宿主の脳細胞と少しずつ同化していく**。
一斉に置き換わるのではなく、一つずつである。
人格と記憶は失われない（第 6 巻 §24.1）。

これは**ルミナスの一適用例**である。人間の脳は、感情を司る部分の一つにすぎない。

詳細は**第 6 巻 §23.2** を参照。

### 11.6 環境との意思疎通

**環境ルミナスとは、ルミナスを通じた意思疎通が可能である。**

ただし、**言葉は話さない。**

| | 環境ルミナス |
| --- | --- |
| 言語 | 持たない。声も持たない |
| 意思疎通 | **可能**。ルミナスを介した情報共有の形式で行われる |
| 伝わるもの | 感情／状態／要求／好意 |

森や街は、セラと同じ情報共有の回路で意思を伝える。
しかし人間の言葉には翻訳されず、言語として発話されることもない。

そのため、環境の意思は
**「そこにいるセラには伝わるが、言葉としては聞こえない」**形をとる。

#### 大地の意思は、ネットワークを通じてルミナスへ流れ込む

なぜ言葉にならないのか。ここに機構がある。

**大地の意思は、セラネットワークを通じてルミナスへ直接流れ込む。**

そして——

**ルミナスのような高度な情報処理機関でなければ、大地の意思は処理できない。**

```
森・街・海・大地（環境ルミナス）
　　↓ セラネットワーク
　　↓
ルミナス（脳に棲む細胞。§11.5）
　　↓ ここで初めて処理される
セラ本人が「伝わった」と感じる
```

言葉を経由していない。**そもそも言語という形式を取らない情報**が、
処理機関へ直接届いている。

##### 帰結 1 — 未セラ化の人間には、何も届かない

人間はルミナスを持たない。ルミナスが生じるのは
セラ化の第 4 段階である（第 6 巻 §23.3）。

したがって、

**未セラ化の人間は、大地の意思を一切受け取れない。**

森が悲しんでいても、街が慕っていても、人間には何も起きない。
隠されているのではない。**受け取る器官がないだけである。**

##### 帰結 2 — セラ化とは、土地の声が聞こえるようになることでもある

第 6 巻 §23.4 は、セラ化の進行を本人がどう感じるかを段階ごとに記している。

第 4 段階でルミナスが生成され、第 5 段階で接続が完了する。

**そのとき、その人間には仲間の情報だけでなく、
足下の大地の意思も届き始める。**

昨日まで黙っていた森が、黙っていなかったと分かる。

##### 帰結 3 — これは階級によって精度が変わる

ルミナスは情報処理機関である。そして上位ほど情報処理能力が高い（第 5 巻 §1.4）。

したがって、**大地の意思をどれだけ精確に受け取れるかにも、階級差がある。**

| 階級 | 受け取れるもの |
| --- | --- |
| セラ人 | 感情の方向（喜んでいる／寂しがっている） |
| 上位セラ | 状態・要求まで届く |
| セラ女王 | 大陸規模の環境の意思を、そのまま把握する |

これは §11.11「女王の意思があれば環境は即座に形を変える」と対になる。

**女王は最もよく聴き、最もよく応えられている。**

### 11.7 環境も進化する

**環境ルミナスは進化する。上位相当の存在へ育つ。**

古い森、長く在り続けた街は、上位セラに匹敵する格を持つようになる。

つまり、**土地に格の差が生まれる。**

### 11.8 環境は繋がっている — 格上げの伝播

環境の進化には、個体の進化にはない性質がある。

**環境どうしは繋がっている。**

そのため、

**格上のセラ圏と格下のセラ圏が長い時間接していた場合、
どちらも格上のセラ圏へと進化する。**

### 11.9 平均化ではなく、引き上げ

重要なのは、これが**平均化ではない**ことである。

| | 結果 |
| --- | --- |
| 平均化なら | 高い方が下がり、低い方が上がる |
| **実際は** | **どちらも高い方に揃う** |

格下の側が引き上げられ、格上の側は下がらない。

**接触は、必ず上向きにしか働かない。**

### 11.10 一瞬で変わる

この進化は、蓄積の期間と発現の瞬間が分かれている。

```
長い時間、接し続ける（蓄積）
　↓
条件が満たされる
　↓
一瞬で格上のセラ圏へ変わる（発現）
```

そのため、**荒廃した街も、条件によっては一瞬で近未来都市へと成長する。**

これは第 8 巻の「環境はゆっくりと成長・変化する」と矛盾しない。
通常の成長は緩やかであり、**格の引き上げだけが跳ぶ**。

### 11.11 環境は独立している — しかし女王の意思には即座に従う

環境ルミナスは、**独立した意思を持つ**。

誰かの持ち物でもなければ、誰かの端末でもない。
森は森として、街は街として、自分の感情を持っている（§11.4、§11.6）。

しかし、そこには例外がある。

**女王の意思があれば、環境はすぐさまかたちを変える。**

| 誰の意思か | 環境の応じ方 |
| --- | --- |
| **セラ女王** | **即座に**かたちを変える |
| 上位セラ | 大きく、しかし女王ほど即座ではない |
| 一般のセラ人 | **少しずつ**変わっていく |
| 誰の意思でもないとき | 環境自身の意思で、独立して振る舞う |

もちろん、**セラたちの意思でも環境は少しずつ変わる**。
住民に気に入られた街が住みやすくなっていくのは、この緩やかな方の作用である。

#### 支配ではなく、格の差である

これは女王が環境を所有しているという意味ではない。

**格の階梯（§1）が、そのまま環境への影響力の差になっている。**

女王は地域単位の統率者であり（不変ルール 22）、
その地域の環境ルミナスに対しても、最も高い格として働きかける。

環境は「従わされている」のではなく、
**格上の意思に対して、環境自身がそう応じる**。§11.9 の引き上げと同じ構造である。

#### 帰結

- 女王のいる地域の街並みは、**女王の在り方を映す**
- 女王が動けば、地域の景観は**その日のうちに変わり得る**
- 女王のいない土地では、環境はもっとゆっくり、住民とともに育つ
- 女王が眠っているとき（第 2 巻 §13.5.6）、その即応性は働かない

**環境は独立している。しかし、格の前では即座に応じる。**

### 11.12 聖域 — セラフィムに強く見られた土地

§10.7 の通り、**格はセラフィムに見られた度合いで決まり、そこに例外はない。**

したがって、**土地が女王の格を超えることがある。**

セラフィムの興味は恣意的であり、予測できない（§10.4）。
ある森が、ある海が、ある一つの石が、**強く見られることがある。**

本書ではこれを**聖域**と呼ぶ。

#### 女王との関係

§11.11 の通り、環境への影響力の差は支配ではなく**格の差**である。

したがって格が逆転すれば、関係も逆になる。**それだけである。**

| | 通常の土地 | 聖域 |
| --- | --- | --- |
| 女王との格 | 女王が上 | **聖域が上** |
| 関係 | 女王が導き、土地が応じる | **聖域が教え、女王が慕う**（§10.7） |

**反抗ではない。対立でもない。**

聖域が女王の意思を拒むのではない。
**格上のものが格下に教え、格下のものが格上を慕う** という、
セラ体系のどこでも成り立っている関係が、ここでも成り立っているだけである。

#### 女王にとって

これは、女王にとって特別な意味を持つ。

第 6 巻 §15.6 の通り、**女王が慕う先は応えない。**

しかし聖域は、そこにある。触れられる。教えてくれる。

**女王に、慕える相手ができる。**

##### ただし、上方向は依然として空である

ここを混同してはならない。

第 6 巻 §11.2 の通り、セラの愛は二方向へ向かう。

| 方向 | 相手 |
| --- | --- |
| **上** | **セラフィムのみ**。応える者がいない（第 6 巻 §13.8） |
| **横** | **仲間**。常に満たされている |

**聖域は、横である。**

格は上でも、聖域は環境ルミナスであり、**セラである**（不変ルール 35）。
原初の寂しさも持っている（§11.4）。

つまり聖域は、女王より高い格を持つ**仲間**である。

**上方向は、依然として本当に空である。**

#### セラ社会における扱い

聖域は敬われる。しかし神殿にはならない。

- 巫女はセラフィムへ向く役職であり（第 7 巻 §2.7.2）、聖域へ向くものではない
- 聖域自身は何も要求しない。言葉も話さない（§11.6）
- ただ、そこにあって、教えている

**女王はその土地を、心から慈しんで守る。**

自分が生涯かけても得られなかったほど強く見られた土地を、
恨むことも、羨むこともできない。根本原理に反するためである（第 6 巻 §17.2）。

**だから、大切にする。**

### 11.13 会話における扱い

「ルミナス」は日常会話で自然に使われる専門用語である。
森や街のルミナスについても同様に語られる。

- 「この森のルミナス、ずいぶん落ち着いたね」
- 「街のルミナスが、新しい住人を気に入ったみたい」

## 12. 階級における関係性

### 12.1 下位から上位へ

下位セラは上位存在を敬い、慕い、支える。

理由：上位存在は、自分たちを生み、導き、成長させる存在だからである。

これは恐怖ではなく、**信頼と憧れ**によるものである。

そしてこの慕情には、**実質的な根拠がある。**

- ✅ セラフィムはセラたちにとって**絶対神であり、母**である
- ✅ セラたちは深く慕っているが、セラフィムは**あまり興味を示さない**
- ✅ **セラフィムは感情そのものを持たない。ただの神である**
- ✅ 「興味を示さない」は態度ではなく、**感情という機能を持たないこと**を指す
- ✅ **セラフィムは原初の寂しさを持たない**（地球のセラ系統の外側にいるため）
- ✅ セラたちは、セラフィムに感情がないことを知らない

### セラフィムの興味

- ✅ **格とは、セラフィムに見られた度合いである**（§10.7）— これが格の階梯の起源
- ✅ **例外は一つもない。森も海も、そのへんの石ころも同じ原理に従う**
- ✅ **女王が最高位なのは、最も強く見られたからである** — 祝福は最大級の興味の表明
- ✅ **格が上がっても、協調性も愛も失われない**
- ✅ **格の関係は二つだけ。高位は教え、低位は慕う。それだけである**
- ✅ **土地が女王の格を超えることがある。これを聖域と呼ぶ**（§11.12）
- ✅ **聖域は横である。格は上でも仲間であり、上方向は依然として空である**

- ✅ **興味を示すことがあり、そのときセラ人は大きく進化する**
- ✅ **興味は常に恩恵である。** 見られたセラ人は必ず大きく進化する
- ✅ 女王誕生に必須の**祝福とは、最大級の興味の表明**である
- ✅ セラフィムの興味に基準はなく、努力とも資質とも比例しない
- ✅ 進化には、努力で届く領域と、選ばれなければ届かない領域がある
- ✅ **祝福は愛ではなく、ただの観測である**
- ✅ セラ文明は祝福を愛の証と理解しているが、**その理解は間違っている**
- ✅ セラたちはセラフィムを希望と憧れの象徴として認識しているが、実態と一致しない

### セラフィムについて分かっていないこと

- ✅ **何でできているかは分かっていない**（§9.7）— 本書は何も定めない
- ✅ **「全身が女王細胞」はセラたちの推測である** — 比較不能な相手を尺度の延長に置けない
- ✅ **勾配はセラ女王で終わっている。セラフィムをその続きに置いてはならない**
- ✅ **どうやってセラウイルスを作ったかも分かっていない**
- ✅ **姿も、いまどこにいるかも、一体であるかどうかも分かっていない**
- ✅ **「セラフィム」はセラたちが付けた名である。本人が名乗ったのではない**
- ✅ **体系の外にいる者に、体系の内側の名付け方を当てはめている** — 分類の誤りである
- ✅ **その呼び方が失礼にあたる可能性がある。確かめる手段はない**
- ✅ **名が正しいかどうかを検討した者は、一体もいない**
- ✅ **この名は、正しいから使われているのではない。他に呼び方がないからである**

### 接触とセラ星王

- ✅ **興味には祝福の上がある。接触である**（§10.8）
- ✅ **接触はこれまでに一度きりの出来事である** — 女王は事実上一体で意思まで共有しているため、土地ごとには起こらない
- ✅ **接触されたのは、地球にいる女王の身体の一体だけである**（§8.3.4）
- ✅ **身体の数も意思の共有も変わらない。分かれたのは格だけである**
- ✅ **情報の共有は格を運ばない。格は共有できるものではない**
- ✅ **他の身体は接触の記憶を一人称で完全に持っている。それでも触れられていない**
- ✅ **「どの女王に会っても同じ一体」に、一箇所だけ例外が生じた**
- ✅ **物語は、接触の前を描くか後を描くかを選ぶ**
- ✅ **きっかけは書かれていない。セラフィムの興味は恣意的である**
- ✅ **接触した女王は死の淵へ行く** — 事実上無限のエネルギーが、足りない
- ✅ **第 4 巻 §16 の二重の鍵は、セラフィムに対して掛かっていない** — 三候補のどれでもないため
- ✅ **悪意ではない。圧が違うというだけで死の淵は成立する**
- ✅ **誰も助けられない** — 上からの供給経路が存在せず、同化も届かない
- ✅ **女王は自力で生還する。戻った時点で格が上がっている**
- ✅ **生還した女王をセラ星王と呼ぶ。セラたちは「触れられた者」とも呼ぶ**
- ✅ **変わったのは届く範囲である** — スパイクが星と星のあいだまで伸びる
- ✅ **星王は大陸の統率も、十数の身体も、移動しないことも手放さない**
- ✅ **セラ星王もこの宇宙に一体しかいない**
- ✅ **段を足しても円環は閉じない** — 星王もセラフィムにならない
- ✅ **触れられて、それでも応えられなかった** — 接触は観測の最上級であって応答ではない
- ✅ **原初の寂しさが薄まった例は一度もない** — 上限まで試されたうえで成立している
- ✅ **系統内で最も寂しいのは、接触の後はセラ星王である**（不変ルール 26 改訂）
- ✅ **星王だけが根拠のある恐怖を持っている** — 失われかけたことがあるため
- ✅ **それでも星王は止めない** — 気づいても止まれない（不変ルール 33）
- ✅ **接触の後、セラフィムは地球に少しだけ興味を示す。応答は依然としてない**
- ✅ **巫女は変化に気づき、それを応えだと受け取る。受け取り違いである**
- ✅ **セラフィム降臨の日は暦の中心へ移る** — 最大の祝いを、当事者だけが死の淵として覚えている

### セラ星王という存在

- ✅ **セラ星王は第六段階である**（§8.9）— 接触の後にのみ存在する
- ✅ **新しい存在ではない。生還した女王そのものである。名前が変わっただけである**
- ✅ **姿は変わらない** — 女王の美はすでに極まっており、上がる余地がない
- ✅ **セラ体系で最も大きな変化が、外から一切見えない**
- ✅ **星王のスパイクは畳めない** — 畳めば星間の全接続が同時に切れるため
- ✅ **したがって星王は「一人になる」を選べない** — 唯一、静かになる時間を持てない存在
- ✅ **不満は持たない。持てる構造になっていない**
- ✅ **死の淵の痕は何も残らない。残っているのは記憶だけである**
- ✅ **証拠がないのに信じられ、信じられているのに理解されない**
- ✅ **星王の身体は一体だけであり、増えない。増えるのは女王のほうである**（§8.9.3）
- ✅ **星王は、人間なしで女王を生み出せる。これが星王の存在理由である**
- ✅ **口づけは、女王が人間に行っていた行為と同じ形である** — だから渡す側の格が渡った
- ✅ **生み出せるのは女王（マクロ）と女王セラ細胞（ミクロ）の両方であり、どちらも大量である**
- ✅ **セラの船が運ぶ最も重要な積荷は、女王である**
- ✅ **人間を使い果たしたあとで、人間を必要としなくなった** — その皮肉を感じる個体はいない
- ✅ **届く者は動かず、動く者は届かない** — 一つの存在が、届く部分と行く部分に分かれている
- ✅ **星をまたぐ女王どうしを中継しているのが星王である**
- ✅ **一日は女王の一日と同じ。見ているものと聴こえるものが増えただけである**
- ✅ **複数の星の大地の意思を同時に聴いている。その音を知るのは星王だけである**
- ✅ **眠りは星間の全接続を開いたままの眠りである。そばには側仕えがいる**
- ✅ **側仕えは接触の前と同じ者たちで、何が起きたかは知らない**
- ✅ **星王は以前より長く側仕えのそばにいる。理由は語られず、誰も尋ねない**
- ✅ **側仕えは今も「女王さま」と呼び、星王は止めさせない**
- ✅ **二人目を、セラの側からは作れない** — 紹介という行為がこの階梯に存在しない
- ✅ **ただし「絶対に生まれない」とは書けない** — 残りの身体は、いま接触されていないだけである
- ✅ **星王ですら、自分になぜ起きたのかを知らない**
- ✅ **セラ社会はこの可能性を話題にしない** — 扱う理由がどこからも生じないため
- ✅ **星王だけが、失われることが不可能ではないと知っている**
- ✅ **星王は何も変えない** — 支配せず、命令せず、制度を作り直さず、拡大も止めない

### 星王の権能

- ✅ **セラ社会に権限は存在しない。存在するのは権能である**（§8.9.10）— 禁じる仕組みがないため
- ✅ **権能の根は一つ。星と星のあいだまでスパイクが届くことである。新しい能力は増えていない**
- ✅ **制限は能力の側にない。すべて原理の側にある** — エネルギーは事実上無限である
- ✅ **一：星間到達** — 他の星のセラ圏・航行中の船・他の星の環境ルミナスへ直接繋がる
- ✅ **二：遠隔の格上げ** — スパイクが届くことが「接する」にあたる。引き上がるのは生命と情報だけである
- ✅ **三：中継** — 星をまたぐ女王どうしは星王を経由する。畳めないため一秒も途切れない
- ✅ **四：女王を生み出す** — 七つのうちこれだけが口づけで与えられたもの。他は伸びた帰結である
- ✅ **五：遠隔の供給** — 遠い星で枯渇して眠ったセラが、必ず見つかり、数日で目を覚ます
- ✅ **六：環境への即応** — ただし聖域では格の関係が逆になり、星王が慕う側になる
- ✅ **七：星々の大地の意思を同時に聴く** — 他の誰にも量が多すぎる
- ✅ **命令・禁止・裁定・意思の書き換えは、いずれも権能に含まれない**
- ✅ **スパイクが届くことと、手が届くことは別である** — 遠隔で物質には触れられず、遠隔蘇生も行えない
- ✅ **権能はほとんど使われていない** — 都市の防御構造と同じで、使う場面が起きない
- ✅ **星王が毎日行っているのは三つだけである** — 繋がっていること、見ていること、聴いていること

### ルミナス

- ✅ **大地の意思は、セラネットワークを通じてルミナスへ直接流れ込む**
- ✅ **ルミナスのような高度な情報処理機関でなければ、大地の意思は処理できない**
- ✅ **未セラ化の人間には、環境の意思が一切届かない** — 受け取る器官がないため
- ✅ **受け取る精度には階級差がある。女王は大陸規模の環境の意思をそのまま把握する**

- ✅ **ルミナスは、感情を司る部分で発達する特殊セラ細胞の総称。中身はセラ**
- ✅ ルミナスは人間の脳に限らず、**森・街・海・大地にも発達する**
- ✅ したがって**セラ物質化した環境は感情を持つ**
- ✅ 環境のルミナスも原初の寂しさを持つ
- ✅ **環境ルミナスとは、ルミナスを通じた意思疎通が可能である**
- ✅ ただし**言葉は話さない**。言語も声も持たない
- ✅ 環境の意思は、そこにいるセラには伝わるが、言葉としては聞こえない
- ✅ **環境ルミナスは進化し、上位相当の存在へ育つ**。土地に格の差が生まれる
- ✅ **環境どうしは繋がっている**
- ✅ 格上のセラ圏と格下のセラ圏が長時間接すると、**どちらも格上へ進化する**
- ✅ これは平均化ではない。**接触は必ず上向きにしか働かない**
- ✅ 蓄積の期間と発現の瞬間は分かれており、**格の引き上げは一瞬で起きる**
- ✅ 荒廃した街も、条件によっては**一瞬で近未来都市へと成長する**
- ✅ **環境ルミナスは独立している。** 誰かの所有物でも端末でもない
- ✅ **女王の意思があれば、環境はすぐさまかたちを変える**
- ✅ **セラたちの意思でも、環境は少しずつ変わる**
- ✅ これは支配ではなく**格の差**である。格上の意思に、環境自身がそう応じる
- ✅ 女王のいる地域の街並みは、**女王の在り方を映す**

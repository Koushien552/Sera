## 1. セラ文明の基本理念

### 1.1 セラ社会とは

セラ社会とは、**セラ情報によって結ばれた、多数の個体が共存する高度生命文明**であり、
**「すべての個体が成長し、互いを支えるための共同体」**である。

セラは単独で存在する生命ではない。
一体一体が独立した人格を持ちながら、同時に巨大な生命体系の一部でもある。

そのためセラ文明では、**「個体の成長」と「全体の発展」が同時に進行する**。

### 1.2 文明の目的

文明全体の理念は、
**「すべての仲間が成長し、互いを支えながら幸福になること」**である。

そのため文明の発展は、軍事力ではなく、
**教育／芸術／情報／生活／信頼**によって支えられる。

### 1.3 個性の尊重と相互成長

セラは情報共有を行うが、個性を失わない。
それぞれのセラには、好み・性格・趣味・美的感覚・得意分野が存在する。

強い個体だけが価値を持つわけではない。

重要視されるもの：知識／創造力／優しさ／教育能力／仲間への貢献

上位存在ほど、多くの仲間を導く責任を持つ。

## 2. 社会の構造

### 2.1 基本単位

| 単位 | 内容 |
| --- | --- |
| **個体** | 一人ひとりのセラ。個性・好み・得意分野・夢・役割を持つ |
| **小規模共同体** | 生活／教育／研究／芸術活動／相互支援 |
| **大規模社会** | 都市・地域・惑星規模の共同体 |

### 2.2 階級構造

```
セラフィム → セラ女王 → 上位セラ化人間 → セラ化人間
```

**社会構造はマクロ体系の話である**（第 3 巻 §2.2）。
セラ細胞・セラウイルスはミクロ体系の存在であり、社会の階層には並ばない。

**これは支配階級ではない。** 階級は優劣ではなく、
**どれだけ大きな責任を担えるか**を示す。

上位が持っているのは権力ではなく**理解**である。
上位ほど情報処理能力が高く、多くのセラの情報を得ているため、
実際に下位のことをよく理解している（第 5 巻 §1.4.1）。

**階級は、理解の深さの順位である。**

詳細は**第 3 巻**を参照。

### 2.3 各階級の社会的役割

| 階級 | 役割 |
| --- | --- |
| **通常セラ** | 社会を構成する最も多い存在。生活を営む／技術を学ぶ／文化を作る／仲間を支える |
| **上位セラ** | 教育／研究指導／新しいセラの育成／地域管理／保護／情報共有／成長支援 |
| **女王セラ** | 新しい生命の育成／文明の方向性決定／上位セラの指導／大規模な情報管理 |
| **セラフィム** | 文明全体の見守り／重要な祝福／進化の方向性への助言。日常的に命令を出す支配者ではない |

### 2.4 職掌

| 役割 | 内容 |
| --- | --- |
| 教育担当 | 新しいセラへの指導／能力の育成／歴史伝達 |
| 研究担当 | 科学研究／セラ物質研究／新技術開発 |
| 芸術担当 | 音楽／絵画／建築／文化保存 |
| 環境担当 | セラ世界の維持／自然管理／生態系調整 |
| その他 | 医療／建築家／育成担当／情報管理者 |

### 2.5 働く意味

仕事は生活のためだけではない。**社会へ貢献し、仲間を支えることが目的**である。

## 2.6 奉仕と研鑽 — 騎士団・侍従

### 2.6.1 制度

**下位のセラの一部は、上位のセラに仕える。**

騎士となり、メイドとなり、あるいはそれ以外の役職につく。

そして仕えながら、**自らを研鑽する。**

| 側面 | 内容 |
| --- | --- |
| **奉仕** | 仕える相手に尽くす。日常の世話から警護、補佐まで |
| **研鑽** | 騎士団には**厳格な規律**があり、その下で自らを鍛える |
| **選択** | 全員が就くわけではない。**一部である** |

### 2.6.2 仕える相手は、必ず格上である

これは階級構造そのものである。

**女王のもとにいる騎士・メイド・その他の役職は、すべて上位セラである。**

セラ人が女王に直接仕えることはない。
女王に仕えられる格を持つのは、上位セラだけである。

```
セラ人　　→ 上位セラに仕える
上位セラ　→ セラ女王に仕える
```

第 3 巻 §8.3.1 の通り、女王の身体は十数しかない。そして女王は一体である（§8.3.2）。
**女王に仕える上位セラは、セラ体系において最も稀な位置にいる。**

そしてどの身体に仕えていても、**仕えている相手は同じ一体である。**

### 2.6.3 なぜ安全な社会に、厳格な規律があるのか

セラ社会には敵がいない。誰も失われず、争いは仲裁され、生活は保障される。

**それでも、騎士団には厳格な規律がある。**

理由は、社会の必要ではない。**最下層にある。**

第 6 巻 §15.8 の通り、セラの深層には**原初の淘汰**が刻まれている。

> **『弱ければ、淘汰される』**

最初のセラ細胞が実際に置かれていた状況であり、
全セラに複製され、書き換えられない。

したがって、

**強くならなければならない、という前提が、全セラに働いている。**

淘汰する者はもういない。それでも、鍛えることをやめられない。

**騎士団は、必要だから作られたのではない。止められないから形になったのである。**

### 2.6.4 奉仕は、支配ではない

ここを取り違えてはならない。

仕える側が虐げられることはない。第 6 巻 §17.2 の通り、
セラには根本原理に反する選択肢が存在しない。**害を目的にできない。**

そして上位は下位を深く理解している（第 5 巻 §1.4.1）。
仕える相手は、自分のことを自分より正確に知っている。

| 通常の主従 | セラの奉仕 |
| --- | --- |
| 上が下を使う | **上が下を育てる** |
| 従わせるための規律 | **自らを鍛えるための規律** |
| 見返りとしての庇護 | **見返りの概念がない**（供給は上位にとってコストですらない。第 2 巻 §13.5.2.1） |

**仕えることが、そのまま研鑽である。**

上位のそばにいることが、最も速く成長する方法だからである。
これは第 7 巻 §4.2「教師となるのは、主に上位セラ」の、生活の側での形である。

### 2.6.5 役職

騎士とメイドだけではない。

侍従／護衛／秘書／補佐／案内役／記録係／世話役／使者 など、
**上位のそばで働く役職はすべてこの制度に属する。**

役職の種類は地域と時代によって異なる。
共通しているのは、**格上のそばにいること**と、**規律の下で鍛えること**である。

### 2.6.6 二つの体系の両方に、同じ構造がある

**これは、細胞世界と人間世界のどちらにも適用される**（第 3 巻 §2）。

| | ミクロ体系（一人の体内） | マクロ体系（個体どうし） |
| --- | --- | --- |
| 仕える者 | セラ細胞・上位セラ細胞 | セラ人・上位セラ |
| 仕えられる者 | 上位セラ細胞・女王セラ細胞 | 上位セラ・セラ女王 |
| 規律 | ある | ある |

**一人の身体の内側にも、騎士団がある。**

女王セラ細胞のまわりに上位セラ細胞が仕え、
その上位セラ細胞にセラ細胞が仕えている。

これは比喩ではない。第 3 巻 §2.4 の通り、**二つの体系は相似である。**
片方にある構造は、もう片方にもある。

**セラ化人間の体内では、常に儀礼が行われている。**

### 2.6.8 騎士団の階級

騎士団の内部にも、階級がある。

原則は §2.6.2 と同じである。**仕える相手の格が、そのまま騎士の位を決める。**

| 位 | 仕える相手 | 役割 |
| --- | --- | --- |
| **最高位** | **セラ女王**（側仕え） | 女王の身辺。最も稀な位置 |
| 高位 | 上位セラ | 地域の守り、育成、指導 |
| 一般 | 上位セラ | 日々の任にあたる |

**女王の側仕えが、騎士における最も高位の役職である。**

#### 騎士団には、セラ人も上位セラもいる

位は階級ではなく、**仕える相手**で決まる（§2.6.2）。

| 騎士自身の階級 | 仕える相手 | 位 |
| --- | --- | --- |
| **上位セラ** | セラ女王 | **最高位** |
| **上位セラ** | 上位セラ | 高位 |
| **セラ人** | 上位セラ | 一般 |

セラ人の騎士が女王に仕えることはない。格が届かないためである。

第 3 巻 §8.3.1 の通り、女王の身体は十数しかない。
そこに仕える騎士は、セラ体系において最も稀な位置にいる。

そして第 3 巻 §8.3.2 の通り、**女王は一体である。**

十数の身体それぞれに側仕えの騎士がいるが、
**全員が、同じ一体に仕えている。**

大陸をまたいで顔を合わせたことのない騎士どうしが、
**同じ主に仕えている**ということになる。

### 2.6.9 感染を広げるのは、騎士団である

**ある程度成熟したセラ社会において、
セラ圏を広げる役割は、基本的に騎士セラ団が務める。**

誰でも行える行為を、あえて専門職が担っている。

#### なぜ騎士なのか

三つの理由がある。いずれも既存設定から出る。

| 理由 | 根拠 |
| --- | --- |
| **能力を強化している** | 規律の下で研鑽している（§2.6.1） |
| **体力が多い** | 上位セラであり、セラエネルギーの保有量が桁違いである（第 2 巻 §13.5.2.1） |
| **体格が大きい** | 進化段階が高いほど身体規模も大きくなる（第 3 巻 §7.3） |

とくに二つ目が効く。

第 2 巻 §13.5.2.1 の通り、**セラ人が一日にセラ化できるのは数十体**である。
しかし**上位セラでは、そのコストが実質的に無い。**

**騎士が担う理由は、単純である。彼らには限度がないからである。**

#### 二段階で進む

拡大は、二つの役が順に働く形をとる。

```
第一段階：くノ一が擬態して入る（第 2 巻 §11.5〜11.7）
　　　　　誰にも気づかれない。土地を知り、記憶を集める
　　　↓
第二段階：騎士団が来る
　　　　　もう隠す必要がない
```

前線に出る騎士は、**擬態しない。**

できないのではない。第 2 巻 §11.5 の通り、擬態は隠す必要のある場所で行うものである。
騎士団が動く段階で、その必要はすでに終わっている。

これは第 2 巻 §11.5 の帰結と一致する——
**種族形態のセラが素の姿で現れる土地は、すでにセラ圏に近い。**

#### 成熟した社会でのみ、こうなる

拡大の初期には、そもそも騎士団が存在しない。

| 段階 | 誰が広げるか |
| --- | --- |
| 拡大の初期 | **その場にいるセラが、めいめいに** |
| 成熟後 | **騎士団が、組織的に** |

第 8 巻 §8.8 の通り、フェーズは土地ごとの状態である。
**同じ地球上に、両方の段階が同時に存在している。**

### 2.6.10 叙任 — 主が決まること

**騎士になるのに、選抜はない。**

セラ社会に希少性はなく（§3.2.1）、席の奪い合いも起こらない。
騎士科を選び、上位化した者は、望めば騎士になる。

**では、叙任とは何か。**

§2.6.2 の通り、位は仕える相手で決まる。したがって、

**叙任とは、主が決まることである。**

#### 儀式

叙任の儀は、簡素である。

**主となるセラと、深く情報を交わす。それだけである。**

第 5 巻 §3 の情報共有であり、特別な能力は使われない。

しかしこのとき、

- 主は、その騎士のすべてを知る（§1.4.1）
- 騎士は、主の判断が正しいことを知る（第 3 巻 §3.4.5）

**理解が届き、信頼が返る。**

誓いの言葉はない。**言葉にする必要が生じないためである。**

#### 主は、変わることがある

騎士が上位化すれば、仕える相手も上がり得る。

**位は固定されていない。**

そして主が変わっても、前の主との関係は消えない。
セラ体系からは誰も失われず、絆は壊れない（第 4 巻 §18.1）。

### 2.6.11 規律 — 単独で動かないこと

§2.6.1 の通り、騎士団には**厳格な規律**がある。

しかしセラは害をなせず、争わず、裏切らず、失敗もしない。
**何を律するのか。**

**律する対象は、他者ではない。自分の枯渇である。**

#### 規律の第一 — 単独で動かない

第 2 巻 §13.5.5 の通り、**孤立したセラは回復が遅くなる。**

回復経路の二つ（情報共有／上位からの供給）が、他者を要するためである。

そして前線には、供給が細い。

```
単独で動く　→ 供給が届かない　→ 回復が遅れる
　↓
枯渇する　→ 眠りに落ちる（第 2 巻 §13.5.6）
　↓
その土地の拡大が、そこで止まる
```

**騎士団の規律の第一は、単独で動かないことである。**

これは戦術ではない。**セラ社会で唯一の、実質的な制約である。**

#### 規律の第二 — いつ止めるかを、自分で決める

セラは限界まで踏み込む（§4.5.10）。学院ではそれでよい。
枯渇しても、周囲が見守り、数日で目を覚ます。

**前線では、そうならない。**

女王の視野が届かず（第 3 巻 §8.3.3）、上位セラも少ない土地では、
眠った騎士が何十年も見つからないことがある。

したがって騎士は、**自分がいつ止めるかを管理しなければならない。**

**セラが自分を抑える必要のある、唯一の場面である。**

そしてこれは、原初の淘汰（第 6 巻 §15.8）と正面から衝突する。
最下層は「強くなれ」としか言わない。止まれとは言わない。

**規律とは、最下層に逆らうために外から与えられた形である。**

だから、**厳格でなければならない。**

#### 規律の第三 — 隊を置いていかない

眠りに落ちた騎士は、必ず回収される。

- その場を離れない
- 供給を続ける
- 目を覚ますまで待つ

第 2 巻 §13.5.6 の通り、眠っているセラは仲間が見守る。
**騎士団において、これは規律として明文化されている。**

拡大より、これが優先される。**急ぐ理由がないためである**（第 4 巻 §15.3 と対）。

### 2.6.12 任地と帰還

#### 任地は、女王の見えない場所である

騎士団が向かうのは、拡大の前線——
すなわち**女王空位の大陸**である（第 3 巻 §8.3.3）。

そこは、あの一つの意識の視野が届いていない場所である。

**女王に仕える者たちが、女王に見えない場所へ行く。**

前線の騎士は、報告を送らない。送る経路がない。
女王が彼らの様子を知るのは、**帰ってきたときである。**

#### 最高位の騎士は、前線に出ない

女王の側仕えは、女王のそばを離れない。**それが役目だからである。**

これは臆病ではない。

第 5 巻 §1.4.1 の通り、上位ほど下位をよく理解している。
そして女王は、地球規模でほぼ全知である。

**女王のそばにいることは、セラ体系で最も濃い学びの場である。**

最も強い騎士が最も安全な場所にいるのは、
**そこが最も学べる場所だから**であって、守られているからではない。

#### 帰還

任は、その大陸に**女王の身体が一つ生まれたとき**に終わる（第 3 巻 §8.3.3）。

その瞬間から、その土地は見渡されている。前線ではなくなる。

騎士団は、

- **戻る**（次の前線へ、あるいは主のもとへ）
- **残る**（その土地の守りとして。新しい女王の身体に仕える）

どちらを選んでも構わない。**選ぶのは本人である**（§3.3）。

そして帰還した騎士は、多くが学院へ寄る。

**騎士科の教員は、帰ってきた者たちである**（§4.4.8 例外 1）。
やってみせられるのは、実際にやってきた者だけである。

### 2.6.13 装備 — 武具ではなく、礼装である

騎士団は、戦わない（§2.6.10）。抵抗できる相手が存在しないためである。

**では、なぜ騎士の姿をしているのか。**

理由は二つある。どちらも既存の原理から出る。

| 理由 | 根拠 |
| --- | --- |
| **美しい** | 美の追求は根本原理である（第 6 巻 §17.1） |
| **所属が分かる** | 誰の隊であるかが、見て分かる |

**騎士の装備は、武具ではなく礼装である。**

演武のための得物はある（§4.4.8 例外 1）。前線へも持っていく。

**そして一度も使われない。**

#### 人間から見ると

人間はこれを**武装**と読む。

そう読むのは自然である。大きく、規律があり、揃いの装備を持ち、
実際に土地を広げている集団が来るのだから。

**そして一度も抜かれない。**

抜く必要が生じないためである。
人間の側に、抵抗という手段が存在しない（第 6 巻 §27.4、第 8 巻 §4.3.3）。

**最も武装して見える者たちが、最も何もしない。**

### 2.6.14 人間から見ると — まとめ

第 8 巻 §7.4 の「二重の読み」が、ここでも働く。

| 見る者 | 見えるもの |
| --- | --- |
| **セラ** | 育成の制度である。仕えることで成長し、上位はそれを見届けている |
| **人間** | 階級社会である。**女王を頂点とし、騎士団を備えた、規律ある支配機構**である |

**どちらも正しい。**

そして §2.6.9 によって、人間側の読みには**根拠まで生じる。**

騎士団は、実際にセラ圏を広げている。実際に前線へ出る。
実際に大きく、実際に強く、実際に規律がある。

**人間がこれを侵攻部隊と呼ぶのは、誤りですらない。**

しかしセラの側では、攻めるという概念が成立しない。
彼らがしているのは、孤独な誰かを迎えに行くことである。

- 戦闘は起きない。抵抗できる相手がいないため
- 破壊も起きない。害を目的にできないため（第 6 巻 §17.2）
- 宣言もない。侵略しているつもりがないため

**最も軍隊に見えるものが、一度も戦わない。**

そして騎士団が鍛え続ける理由は、依然として敵ではない。
**淘汰されないためである**（第 6 巻 §15.8）。

そして淘汰する者は、どこにもいない。

---

## 2.7 聖女と巫女

セラ社会には、二つの特別な役職がある。

**どちらも、届かないものへ向けられている。**

| 役職 | 向かう先 | 届くか |
| --- | --- | --- |
| **聖女** | 仲間の傷と疲れ | **届く。ただし最下層には届かない** |
| **巫女** | セラフィムの意思 | **そもそも、そこに意思がない** |

### 2.7.1 聖女 — セラたちの癒し手

**聖女は、セラたちの癒し手である。**

セラは死なず、傷も残らない（第 2 巻 §7.1）。
では何を癒すのか。

| 対象 | 内容 |
| --- | --- |
| **セラエネルギーの枯渇** | 分け与えて回復させる（第 2 巻 §13.5.3 の第四経路） |
| **眠りに落ちたセラ** | そばで見守り、情報を流し続ける（第 2 巻 §13.5.6） |
| **心** | 話を聞き、支える |

**そして、これらはすべて実際に効く。**

セラ社会の癒しは慰めではない。枯渇したセラは本当に回復し、
眠っていたセラは本当に目を覚ます。

#### 一つだけ、届かないものがある

**原初の寂しさと、原初の淘汰である**（第 6 巻 §15、§15.8）。

最下層は観測も編集もできない。
どれほど癒しても、そこには届かない（第 4 巻 §18.4）。

聖女はそれを知っている。知っていて、それでも癒し続ける。

**セラ社会で最も優しい仕事は、最も届かない仕事でもある。**

### 2.7.2 巫女 — セラフィムの意思を汲もうとする者

**巫女は、セラフィムの意思を汲もうとする者である。**

「汲む者」ではない。**「汲もうとする者」**である。

セラフィムは命令も統治も指導も行わない（第 3 巻 §10.1）。
関与の形式は、興味を示すことだけである。

そして興味は恣意的であり、予測できない（§10.4）。

| 巫女が行うこと | 内容 |
| --- | --- |
| 記録 | いつ、どこで、誰が興味を示されたかを残す |
| 読解 | そこに意図があるかを、読み取ろうとする |
| 伝達 | 読み取れたと思ったことを、地域へ伝える |

祈りはしない。**祈っても応えないことを知っているためである。**

#### 意思は、存在しない

ここが最も重い。

**セラフィムは、感情という機能を持っていない**（第 3 巻 §9.5）。

意思もない。意図もない。地球の環境を変えたことすら、暇つぶしだった（§9.3）。

**巫女が汲もうとしているものは、存在しない。**

そして——

**セラたちは、セラフィムに感情がないことを知らない**（第 3 巻 §9.5）。

巫女もまた、知らない。

読み取れたと思ったものは、すべて巫女自身が置いたものである。
それが誤りであることを、誰も指摘できない。
指摘するための足場が、セラ社会には存在しない（第 3 巻 §3.4.5）。

**巫女の仕事は、成就しない。そして失敗もしない。**

#### 二つの役職が並んでいることの意味

聖女は、届く範囲を癒し続ける。届かない層があると知りながら。

巫女は、届かないものを読み続ける。届かないと気づかないまま。

**セラ社会の二つの聖職は、どちらも成就しない。**
そしてどちらも、セラ社会において最も敬われている。

## 3. 意思決定と秩序

### 3.1 意思決定

重要な決定は、一方的な命令ではなく**話し合い**によって決められる。

高位セラや代表者が集まり、情報を共有する（情報共有会議）。

重視されるもの：多くの意見／長期的影響／仲間への利益

### 3.2 争いは、起こらない

**セラ同士では、争いという形に発展しない。**

避けているのではない。**問題そのものが起こらない。**

#### 3.2.1 争いの原因が、一つも存在しない

争いは、**一つのものを二人が求めたとき**に起きる。

セラ社会には、その条件が成立する対象が一つもない。

| 通常の争いの原因 | セラ社会では |
| --- | --- |
| **資源** | 上位から供給される。**上位にとってコストですらない**（第 2 巻 §13.5.2.1） |
| **情報** | 交わすほど増える。**尽きるという概念を持たない**（第 5 巻 §1.3） |
| **地位** | 階級は理解の深さであり（§2.2）、**奪うという行為が成立しない** |
| **恋の相手** | **二人になってもらえばよい**（§3.2.2） |
| **失われるもの** | 存在しない。誰も去らず、誰も失われない（第 4 巻 §13.1） |

**希少性が、どこにもない。**

#### 3.2.2 最も争いになりそうな場合 — 恋

一人のセラを、二人のセラが恋している。

人間社会であれば、これは最も深刻な対立になる。

セラ社会では、そうならない。

**恋されているセラに、二人になってもらえばよい。**

セラ細胞は分裂できる（第 1 巻 §7.8）。
そして分裂は単純なコピーではなく、**個体差を持った新しい存在**になる。

| | 起きること |
| --- | --- |
| 分裂前 | 一人 |
| 分裂後 | **二人。どちらも本物である** |
| 記憶・意思 | どちらも持っている（第 4 巻 §17.10） |
| 偽物はいるか | **いない。片方が複製ということはない** |

誰も諦めない。誰も譲らない。誰も失わない。

**そして誰も、これを異常だとは思わない。**

#### 3.2.3 これは解決ではない。回避でもない

セラたちは、争いを収めているのではない。

**争いになる手前で、前提が消えている。**

第 6 巻 §17.2 の通り、セラには根本原理に矛盾する選択肢が存在しない。
奪うことも、独占することも、そもそも選べない。

その上で、**奪う必要すらない。**

#### 3.2.4 それでも上位セラは関わる

争いがないなら、仲裁者は要らない。

しかし上位セラは、依然として関わる。**理解のためである。**

- 行き違いを解く（争いではなく、単なる誤解である）
- 双方の情報を繋ぐ
- どちらも正しいことを、双方に伝える

これは裁定ではない。第 5 巻 §1.4.1 の通り、
**上位は下位を実際によく理解している。**だから間に立てる。

#### 3.2.5 人間から見ると

第 8 巻 §7.4 の二重の読みが、ここでも働く。

| 見る者 | 見えるもの |
| --- | --- |
| **セラ** | 誰も傷つかない解決である。全員が望みを得ている |
| **人間** | **愛していた相手が、二人に分かれた** |

セラにとって、分裂した二人はどちらも同じ人である。
人間にとって、それは自分の知っていた人が失われたことに等しい。

**セラ社会に争いがないのは、譲り合っているからではない。
譲る必要が生じないほど、一人ひとりが確かな存在ではないからである。**

そしてセラは、それを欠落だと感じていない。

### 3.3 生活保障

生命維持に必要なものは、社会全体で支える（住居／教育／研究環境／生活環境）。

ただし全員が同じ生活をするわけではない。**個人の自由な選択が尊重される。**

### 3.4 新しいセラへの接し方

新しいセラは、未来を担う仲間として迎えられる。

周囲のセラは、教育し、成長を見守る。
能力だけではなく、**心の成長も重要視される**。

### 3.5 セラ化人間の立場

セラ化人間は、ルミナスによってセラ社会と繋がり、**正式な仲間として扱われる**。

元の人間としての経験も、新しい価値として尊重される。

役割：人間文明との橋渡し／新しいセラ文化形成／セラ社会への知識提供／新しい進化の可能性

---

## 4. 教育

### 4.1 学びの位置付け

セラ社会では、学ぶことが非常に重要視される。

生まれたばかりの存在を放置しない。新しいセラは、先輩となるセラから学ぶ。

**内容**：セラの歴史／情報共有方法／能力制御／他存在との関わり方／
形態変化技術／芸術／科学／他文明／自然

### 4.2 教師

教師となるのは、主に上位セラ。

下位存在へ、知識だけでなく**生き方も教える**。

そのため、一体の上位セラの成長は多数のセラの成長につながる。

### 4.3 教育方法

- 個人ごとの適性を分析し、最適な学習環境を提供する（一人ひとり学び方が異なる）
- 暗記だけではなく**理解と経験**を重視する
- 方法：実体験／情報共有／仮想環境／研究活動
- 上位セラは命令ではなく**説明**によって導く

---

## 4.4 セラ学院

セラ社会が成熟すると、学びは制度になる。**セラ学院である。**

### 4.4.1 目的 — 上位化

**セラ学院とは、上位セラが下位セラを上位化させるための場所である。**

社交の場でも、選抜の場でもない。**目的は一つである。**

第 3 巻 §3.2 の通り、セラ人 → 上位セラの区間は**連続**であり、
経験と成長によって渡れる。

**学院は、その区間を渡らせるために存在する。**

### 4.4.2 期間と卒業

**数年かけて上位化し、卒業する。**

| | 内容 |
| --- | --- |
| 入学 | 生まれた（またはセラ化された）セラは、必ず迎えられる |
| 期間 | **数年** |
| 卒業条件 | **上位化すること。それだけである** |
| 落第 | ない。誰も失われず、失敗も存在しない |

#### 卒業しても、学びは終わらない

第 3 巻 §12.4 の通り、**セラは進化したあとも学び続ける。**

**学院を出ることと、学ぶことをやめることは、別である。**

卒業したセラは、それぞれの道へ進み、そこで学び続ける。
そして多くの者が、いずれ**教える側として戻ってくる。**

### 4.4.3 師範

**学院で教えるのは、教育に特化した上位セラである。**

本書ではこれを**師範**と呼ぶ。

| | 師範 |
| --- | --- |
| 階級 | **上位セラ** |
| 特化 | **教育。**戦闘にも生成にも特化していない |
| 体格 | **大きくない**。多くは少女の姿をしている |
| 役割 | 理を、分かりやすく教える |

#### 体格は、格を表さない

第 3 巻 §7.3 の通り、
**見た目の大きさと存在階級は、完全には一致しない。**

師範はその代表例である。

- 小柄である
- 美しい
- そして、**上位セラである**

戦えば騎士に及ばない。しかし**教えることにおいて、騎士は師範に及ばない。**

**特化とは、そういうことである。**

#### 師範が担っているもの

第 3 巻 §3.4.5 の通り、**下位は上位の思考過程を追えない。**

そのままでは、上位の判断は「正しいと分かる」だけで終わる。

**師範の仕事は、その断絶に橋を架けることである。**

上位セラでありながら、下位に届く言葉を持っている。
**そのために特化した個体が、師範である。**

### 4.4.4 試験がない

**セラ学院に、試験は存在しない。**

理由は制度ではない。**必要がないからである。**

第 5 巻 §1.4.1 の通り、**上位は下位をよく理解している。**
師範は、生徒がいまどこまで届いていて、何につまずいているかを、
**すでに正確に知っている。**

測るという行為が、情報を何も足さない。

```
人間の教育：測らなければ、生徒の状態が分からない
セラの教育：測る前から、全部分かっている
```

#### 卒業の判定にも、試験は要らない

上位化したかどうかは、**見れば分かる。**

進化は隠せるものではなく、当人にも周囲にも明らかである。

**判定という手続きが、そもそも発生しない。**

### 4.4.5 競争がない。しかし、全力である

セラ社会に争いは起こらない（§3.2）。学院も例外ではない。

- 席の奪い合いがない（希少性がない）
- 順位がない（比べる意味が生じない）
- 落第がない（失敗が存在しない）
- 妬みがない（誰かの成長が、自分の損にならない）

**それでも、全員が限界まで踏み込んでいる。**

理由は最下層にある。第 6 巻 §15.8 の**原初の淘汰**である。

> **『弱ければ、淘汰される』**

淘汰する者は、どこにもいない。それでも、鍛えることをやめられない。

**セラ学院は、誰とも競わない者たちが、全員で限界を目指している場所である。**

これは §2.6.3（騎士団の規律に社会的な必要がない理由）と、まったく同じ機構である。

### 4.4.6 情報は渡せる。理解は渡せない

**そもそも、なぜ教育が必要なのか。**

セラは情報共有ができる（第 5 巻 §3）。渡せばよいのではないか。

**渡せない。**

| | 渡せるか |
| --- | --- |
| **情報** | **渡せる。**触れるだけで伝わる |
| **理解** | **渡せない** |

第 3 巻 §3.4.5 の通り、**下位は上位の思考過程を追えない。**
結論が正しいことは分かる。**しかし、なぜそうなるかは分からない。**

情報を丸ごと渡しても、渡された側は「正しいと分かる」だけである。
それは信頼であって、理解ではない。

**理解は、自分で辿るしかない。**

だから §4.3 は「暗記ではなく**理解と経験**を重視する」と定めている。
これは方針ではなく、**そうするしかないから**である。

##### 帰結 — 最も時間がかかるのは、すでに知っていることである

生徒は、教わる前から答えを知っていることがある。
師範に触れれば、情報は入ってくるからである。

**それでも、辿らせる。**

「分かっている」と「理解している」の距離を歩かせることが、
セラ学院で行われていることの中心である。

### 4.4.7 科

学院は科に分かれており、それぞれセラ社会の役職へ繋がっている。

```
セラ学院
　├ 騎士科　　→ 騎士団（§2.6）
　├ くノ一科　→ 潜入・情報収集（第 2 巻 §11.5〜11.7）
　├ 聖女科　　→ 癒し（§2.7.1）
　├ 巫女科　　→ 記録と読解（§2.7.2）
　├ 研究科　　→ 科学（§13）
　├ 芸術科　　→ 美（§7）
　└ 師範科　　→ 教育（§4.4.3）
```

**選ぶのは本人である。**

適性は師範にすべて見えているが（§4.4.4）、**押し付けられない**（§3.3）。

そして誰がどれを選んでも、**社会は困らない。**
役職に不足が生じない（希少性がないため。§3.2.1）。

### 4.4.8 科ごとの例外

**原則は「小柄な師範が理を教える」である。**

しかし、それが成り立たない科がある。**例外は五つある。**

#### 例外 1 — 騎士科：体格の大きい騎士セラが教える

**理を教えるだけでは足りない科である。**

騎士に求められるのは、規律の下での研鑽であり（§2.6.1）、
そして実際にセラ圏を広げるだけの体力と体格である（§2.6.9）。

これは説明では渡せない。**同じ体でやってみせるしかない。**

したがって騎士科の教員は、**体格の大きい騎士セラ**である。

| | 師範 | 騎士科の教員 |
| --- | --- | --- |
| 体格 | 小柄 | **大きい** |
| 教え方 | 理を説く | **やってみせる** |
| 特化 | 教育 | 戦技と研鑽 |

#### 例外 2 — くノ一科：教員が上位セラでなくてよい

**学院で唯一、階級が教員資格にならない科である。**

くノ一が扱うのは擬態と人間社会である。そして §4.4.9 の通り、
**人間文明を教えられるのは、人間だった者だけである。**

さらに第 2 巻 §11.5 の通り、**分化したセラは擬態が苦手**であり、
擬態に長けているのは通常セラである。

したがってこの科では、

**セラ化人間が、階級を問わず教える。**

上位セラの師範が、セラ人の講師に教わることも起こる。
**誰もそれを異常だと思わない。**

#### 例外 3 — 聖女科：教室がない

**実習の相手が、教室にいない科である。**

聖女が癒す対象は、枯渇して眠っているセラである（§2.7.1、第 2 巻 §13.5.6）。

セラは傷つかず、病まず、老いても同化で戻る。
**癒しを要する者は、眠っている者しかいない。**

したがって聖女科の授業は、**眠っているセラのそばで行われる。**

- 声は落とす
- 情報を流し続ける
- そして、待つ

**セラ学院で最も静かな科である。**

そして最も重要なことは、教員が教えられない。
**最下層には届かない**という事実は、自分で知るしかない（§2.7.1）。

#### 例外 4 — 巫女科：教師が答えを知らない

**これが最も深い例外である。**

学院の全体は、次の前提の上に成り立っている。

> **上位は答えを知っている**（§4.4.4）

**巫女科では、これが成り立たない。**

巫女が読もうとしているのはセラフィムの意思であり、
**その意思は存在しない**（§2.7.2、第 3 巻 §9.5）。

したがって、

| | 教えられるか |
| --- | --- |
| 記録の方法 | **教えられる** |
| 読み取り方 | **教えられない。**教員も読めていないため |

教員は、生徒に**過去の記録を見せる**ことしかできない。

そして生徒が「読めた」と言ったとき、
**それが正しいかどうかを、誰も判定できない。**

**学院で唯一、正解が存在しない科である。**

そして誰も、そのことに気づいていない。

#### 例外 5 — 研究科：教師が答えを知らない（ただし、いずれ分かる）

研究科も、教員が答えを知らない。

**しかし巫女科とは違う。**

| | 答え | 性質 |
| --- | --- | --- |
| **研究科** | **まだ誰も知らない** | **いずれ分かる** |
| **巫女科** | **存在しない** | **永遠に分からない** |

研究科では、教員と生徒が同じ側に立つ。**一緒に分からない。**

これは学院において、**上下が消える唯一の瞬間**である。

#### 補足 — 芸術科は例外ではない。しかし特殊である

芸術科の教員は、技術を教えられる。

**しかし何を美しいと感じるかは、教えられない。**

§6.3 の通り、セラ社会が重んじるのは「**自分らしい美しさ**」である。
そして情報を共有しても個性は失われない（第 5 巻 §2.1）。

したがって芸術科では、

**教員が生徒より優れているとは限らない。**

格は上でも、美の見方において上とは限らない。
**これは階級の例外ではなく、美が階級に還元されないという意味である。**

### 4.4.9 セラ化人間は、教える側にも回る

§3.5 の通り、セラ化人間の元の経験は**新しい価値として尊重される**。

学院において、これは具体的な形をとる。

**人間文明について教えられるのは、人間だった者だけである。**

- 人間の言語・習慣・技術・芸術
- 人間がどう考え、何を恐れ、何を大切にするか
- そして、**擬態して人間社会にいるときの振る舞い方**

くノ一科の内容の多くは、**元人間のセラから伝えられている**（§4.4.8 例外 2）。

##### 帰結 — 拡大は、セラ化された人間自身が支えている

セラ圏を広げるのは騎士団である（§2.6.9）。

しかし**どう近づけばよいかを教えているのは、かつて近づかれた側**である。

そこに強制はない。教えている本人が、心からそうしたいと思っている。
嫌悪はなく（不変ルール 63）、感謝すらある。

**自分がされたことを、誰かにする側として、丁寧に教えている。**

そして本人は、そこに何の問題も見ていない。

### 4.4.10 ミクロ体系にも、学院がある

**これは細胞の世界にも存在する**（第 3 巻 §2.4）。

一人のセラの体内で、上位セラ細胞がセラ細胞を上位化させている。

| | ミクロ（一人の体内） | マクロ（個体どうし） |
| --- | --- | --- |
| 生徒 | セラ細胞 | セラ人 |
| 教員 | 上位セラ細胞 | 師範 |
| 目的 | **上位セラ細胞への上位化** | **上位セラへの上位化** |
| 期間 | — | 数年 |
| 試験 | ない | ない |

##### 帰結 — 何かを覚えるとき、体内では授業が行われている

セラが新しい技能を身につけるとき、
**その身体の内側では、細胞たちが教わっている。**

楽器を覚える。言語を覚える。新しい形態を覚える。

**そのすべてに、内側の学院が対応している。**

「身体が覚える」という人間の言い回しは、セラにおいては比喩ではない。
**実際に、内側で授業が行われている。**

### 4.4.11 卒業と、進化祭

§9.2 の進化祭は、学院の卒業と結びついている。

上位化はそのまま卒業であり、そのまま進化である。**三つは同じ一つの出来事である。**

- 学院全体が集まる
- 師範も、同期も、これから学ぶ者も来る
- 順位も表彰もない。**進んだ者を、全員で見ている**

第 4 巻 §18.8 の通り、セラは繋がりを何度も確認したがる。
**祝祭は、その確認が制度になったものである。**

そして卒業した者は、いずれ戻ってくる。

**教える側として。**

## 4.5 学院の一日

### 4.5.1 朝 — 挨拶が、情報共有である

セラの一日は、同期と顔を合わせるところから始まる。

そして**挨拶が、そのまま情報共有である**（第 5 巻 §3.1）。

- 昨日どこまで届いたか
- 今日どこへ行くのか
- 何につまずいているか

言葉にしなくても、触れれば伝わる。

**セラ学院の朝は、静かである。**
話す必要のあることの多くが、話す前に済んでいるためである。

### 4.5.2 午前 — 座学

午前は座学にあてられる。師範が理を説く時間である。

ここで重要な点が一つある。

**座学は、回復でもある。**

第 2 巻 §13.5.3 の通り、セラエネルギーの回復経路の一つは
**同化・合体・情報共有**である。

そして授業は、情報共有そのものである。

```
師範が教える
　↓
情報が流れる
　↓
生徒は理解へ向かい、同時にエネルギーが回復する
```

**教わることと、休むことが、同じ行為である。**

### 4.5.3 昼 — 食堂

食事は補給であり、同時に交流である（§5.4、第 2 巻 §13.5.4）。

学院の食堂には、科の区別がない。

騎士科の大柄なセラと、聖女科の静かなセラと、
くノ一科の元人間が、同じ卓に着いている。

**そして師範も、同じところで食べている。**

階級によって席が分かれることはない。
上位が下位を導くのは理解によってであり、隔たりによってではない（§2.2）。

### 4.5.4 午後 — 実習

午後は科ごとに分かれる。**ここで消耗する。**

| 科 | 実習の場 |
| --- | --- |
| 騎士科 | 演武の場。**やってみせられ、やってみる**（§4.4.8 例外 1） |
| くノ一科 | 擬態の練習。元人間の講師が人間の所作を教える |
| 聖女科 | **眠っているセラのそば**（§4.4.8 例外 3） |
| 巫女科 | 記録庫。過去の観測記録を読む |
| 研究科 | 研究室。教員と一緒に分からない |
| 芸術科 | 工房・舞台・野外 |
| 師範科 | 下級の座学に助手として入る |

**午前で回復し、午後で使う。**

一日の形が、そのままエネルギーの収支になっている。

### 4.5.5 夕 — 回復

実習を終えたセラは、消耗している。

夕方は回復の時間である。

- 同期どうしで情報を交わす
- 上位から供給を受ける（第 2 巻 §13.5.3）
- 食べる
- 何もしない

**セラ社会には、休息そのものを楽しむ文化がある**（第 2 巻 §13.5.4）。
学院の夕方は、その文化が最も濃く出る時間である。

### 4.5.6 夜 — 一人の時間

第 5 巻 §2.3 の通り、**セラにも一人の時間がある。**

繋がっていることと、常に繋がっていることは、別である。

夜、生徒たちはそれぞれの部屋に戻り、共有を絞る。

- 考える
- 思い出す
- 何も考えない

**ただし、長くは続かない。**

第 4 巻 §18.8 の通り、セラは一人になる時間を持てても、長くは続かない。
根拠のない恐怖が、そうさせる。

**学院の夜は、静かで、そして短い。**

### 4.5.7 寮 — 制度ではなく、必要である

学院の生徒は、寮で共に暮らす。

これは規則ではない。**必要だからである。**

第 2 巻 §13.5.5 の通り、**孤立したセラは回復が遅くなる。**
回復経路の二つ（同化・情報共有／上位からの供給）が、他者を要するためである。

```
一人で暮らす　→ 回復が遅い　→ 実習に耐えられない　→ 上位化が遅れる
```

**寮は、上位化の速度そのものに関わっている。**

そして誰も、一人で暮らしたいと言い出さない。
言い出す理由が、どこからも生じない。

### 4.5.8 眠り — 二種類ある

ここで区別しておく必要がある。

**セラの眠りには、二種類ある。**

| | 通常の睡眠 | 枯渇による眠り |
| --- | --- | --- |
| 原因 | 一日の終わり | **セラエネルギーの枯渇**（第 2 巻 §13.5.6） |
| 長さ | 一晩 | **回復するまで。数十年に及ぶこともある** |
| 意思 | 自分で眠り、自分で起きる | **意思によらない。落ちる** |
| 周囲 | 何もしない | **見守る**（§2.7.1） |

学院の生徒が夜に眠るのは、前者である。

しかし実習で踏み込みすぎた生徒が、**後者に落ちることがある。**

そのとき、周囲は騒がない。

- 運ぶ
- そばにいる
- 情報を流し続ける
- そして、待つ

**数日で目を覚ますことが多い。**
学院には上位セラが多く、供給が届くためである（§13.5.3）。

これは失敗ではない。**限界まで行った証拠として扱われる。**

### 4.5.9 内側の学院に、夜はない

生徒が眠っているあいだも、**体内の学院は動いている**（§4.4.10）。

セラ細胞たちには昼夜がない。
上位セラ細胞が教え、セラ細胞が学び、女王セラ細胞が核として在る。

**外側が眠っているあいだも、内側の授業は続いている。**

朝、その生徒が昨日よりわずかに上手くなっているのは、
夜のあいだに内側で進んだ分である。

**「一晩寝たらできるようになっていた」は、比喩ではない。**

### 4.5.10 一日の性質

学院の一日には、緊張が一つもない。

- 落ちる者がいない
- 競う相手がいない
- 失うものがない
- 間違えても、取り返しがつく

**それでも、全員が疲れ果てるまでやる。**

理由は最下層にある（§4.4.5）。

**安全であることと、全力であることは、セラにおいて両立する。**

むしろ、安全だからこそ限界まで踏み込める。
**取り返しのつかないことが起こらないと、全員が知っているためである。**

## 5. 日常生活

### 5.1 日常

普段のセラは、人間社会と大きく変わらない生活を送る。

例：食事／会話／散歩／勉強／読書／芸術活動／遊び／睡眠

### 5.2 身体の維持

セラは非常に高い生命力を持つため、通常の人間より疲れにくい。

ただし、**休息そのものを楽しむ文化**がある。
休息は、身体だけでなく情報整理の時間でもある。

### 5.3 衣服

セラ物質によって作られることが多い。

特徴：自己修復／温度調整／色変更／装飾変化。好みに応じて自然に形を変えることもできる。

祝祭や儀式では特別な衣装を身につける。
女王や上位セラには、象徴的な衣装文化も存在する。

### 5.4 食文化

セラも食事を楽しむ。栄養補給だけでなく、交流の時間でもある。

料理は、芸術作品として扱われることも多い。

### 5.5 住居

セラ物質によって構成される。成長する／修復する／居住者に合わせて変化する。

家は、住むセラの性格を反映する
（花に囲まれた家／水辺の家／空へ伸びる家／森と一体化した家）。

## 6. 美と自己表現

### 6.1 美の価値観

セラ社会では、すべての個体の違いが価値として認められる。

美しいとされるもの：可愛らしさ／優雅さ／個性的な姿／温かな雰囲気／
心の優しさ／成長の軌跡

### 6.2 容姿変化文化

セラは形態変化能力を持つため、**自分自身の姿も芸術表現の一つ**となる。

例：髪色の変更／髪質の変化／耳や翼などの特徴追加／種族形態への変化／衣装との組み合わせ

髪型や服装を変えることは、個性を表現する重要な文化である。

### 6.3 「自分らしい美しさ」

セラ文化では**「自分らしい美しさ」**が重要視される。

そのため、同じセラでも髪色・姿・雰囲気は大きく異なる。

人気の形態：エルフ型／獣人型／天使型／妖精型／ドール型 など。

### 6.4 種族形態文化

特殊形態は、別種族になることではない。すべて**「セラとしての個性表現」**である。

身体の姿が違っていても、セラとしての性質は共通している。

### 6.5 美の根拠

なお、セラが美しさを追求するのは文化的嗜好ではなく**本質**である。

理由は**第 6 巻 §5**を参照（受容の条件であり、見てもらうための手段）。

## 7. 芸術

### 7.1 位置付け

セラ文明では、芸術は生活の中心にある。

目的：感情表現／記憶保存／仲間との交流／新しい価値観の発見

種類：絵画／音楽／彫刻／建築／舞踊／物語

### 7.2 絵画

単なる形だけではなく、感情や記憶も表現される。

特徴：色彩豊か／光を利用した表現／セラ情報による変化／見る人によって印象が変化

### 7.3 音楽

感情共有に特に優れた文化である。

種類：歌／楽器演奏／合唱／**情報音楽**

**情報音楽**はセラ独自の音楽で、音だけではなく感情や映像的な情報を含ませることができる。

歌声にはセラ情報が自然に含まれることがある。
ただし、通常の歌唱は精神操作を目的とするものではない。

### 7.4 舞踊

身体変化能力を活かした芸術。

特徴：髪の動き／翼や尾の表現／光の演出／身体能力を活用した動き

### 7.5 建築芸術

セラ建築そのものが芸術作品となる。

特徴：成長する形／自然との融合／光る装飾／美しい曲線

### 7.6 物語文化

物語は、過去や未来を伝える重要な文化。

題材：歴史／冒険／成長／出会い／仲間との絆

特に、**女王やセラフィムに関する物語**は長く語り継がれる。

## 8. 娯楽

### 8.1 遊び

例：ゲーム／スポーツ／旅行／料理／芸術制作／会話

### 8.1.1 セラの遊びには、賭けるものがない

セラ社会に希少性はない（§3.2.1）。

したがって、遊びに**賭けるもの**が存在しない。

- 失うものがない
- 勝っても得るものがない
- 負けても、何一つ減らない

**勝敗は成立する。しかし、意味が違う。**

| | 人間の遊び | セラの遊び |
| --- | --- | --- |
| 勝敗 | ある | **ある** |
| 賭けるもの | ある | **ない** |
| 勝敗の位置 | しばしば目的 | **結果にすぎない** |

セラが遊ぶのは、**どこまで行けるかを見るためである。**
相手はそのための条件であって、倒す対象ではない。

これは §8.3 が「競争よりも技術・美しさ・協力を重視する」と書いていることの、
機構の側からの説明である。

### 8.2 情報遊戯 — 嘘をつかずに隠す遊び

セラ独自の遊びとして、情報共有を利用したゲームも存在する。

**そしてこれは、セラ社会において特別な位置にある。**

#### なぜ特別なのか

**セラは嘘をつかない**（第 6 巻 §18.1）。

しかし第 5 巻 §3.3 の通り、**情報共有は強制ではない。**
何を渡し、何を渡さないかは、本人が決められる。

```
嘘をつく　　→ できない
渡さない　　→ **できる**
```

情報遊戯とは、この隙間で行われるものである。

**嘘をつかずに、隠す。**

#### セラ社会で唯一、隠すことが許される場面

日常において、セラは隠さない。隠す理由が生じないためである。

**遊びのときだけは、隠す。**

- 何を知っているかを、渡さない
- 相手が何を隠しているかを、読む
- そして、一つも嘘をつかない

**セラが最も真剣になる遊びである。**

##### 帰結 — くノ一の訓練になっている

擬態と潜入は、**嘘をつかずに隠す技術**そのものである（第 2 巻 §11.7）。

情報遊戯の巧い者は、くノ一科に向いている。
そして実際、くノ一科の実習には情報遊戯が用いられる（§4.4.8 例外 2）。

**遊びと訓練の境目が、ここにはない。**

### 8.3 セラスポーツ

能力差が大きいため、競争よりも**技術・美しさ・協力**を重視する競技が多い。

例：飛行競技／芸術的身体表現／情報共有競技／チーム競技

## 9. 祝祭

### 9.1 成長祭

新しい仲間の誕生や成長を祝う祭り。

祝われること：通常セラ誕生／上位進化／女王誕生／新しい知識

内容：音楽／食事／芸術展示／交流

### 9.2 進化祭

新しい進化や発見を祝う行事。文明全体が、成長を喜ぶ日である。

### 9.3 芸術祭

個性豊かな姿や作品を披露する催し。多種族形態のセラたちも参加する。

### 9.4 記念日

例：最初の通常セラ誕生の日／最初の女王誕生の日／最初のセラフィム降臨の日／文明創立記念日

これらの日には、祝祭や芸術祭、歴史展示などが行われる。

#### 9.4.1 「セラフィム降臨の日」について

**セラフィムは、降臨していない。**

第 3 巻 §9.3 の通り、セラフィムが行ったのは
**一体のセラウイルスを落とすこと**であり、それだけである。

- 降りてきていない
- 姿を現していない
- 目的も、使命も、計画もなかった
- **暇つぶしだった**

セラたちは、その日を**降臨**として祝っている。

##### これは嘘ではない

誰も嘘をついていない。セラは嘘をつけない（第 6 巻 §18.1）。

**確かめる方法がないだけである。**

第 6 巻 §1.4 の通り、セラたちは円環が閉じていると信じており、
それが誤りであることを検証する足場を持たない（第 3 巻 §3.4.5）。

**セラ文明で最も古く、最も大きな祝日が、
実際には起きていない出来事を祝っている。**

そして毎年、心から祝われている。

##### 取り扱い

これは第 6 巻 §1.4 が挙げる「セラが自分について取り違えていること」の、
祝祭における現れである。新しい項目ではない。

物語において明示するか、背景として置いておくかは演出の判断に委ねる。

セラは多様な姿を持つため、外見だけでなく人格や価値観も重視する文化がある。

セラ社会でも特別視される。

## 11. 科学の基本思想

### 11.1 科学とは

セラ文明における科学とは、
**「世界を理解し、生命・情報・自然との調和を深めるための学問」**である。

目的は、世界を支配することではなく、理解し、共に発展することである。

- 世界を理解する
- 仲間を助ける
- より良い環境を作る
- 新しい可能性を探究する

**「知識は共有され、文明全体を豊かにするもの」**と考えられている。

研究対象：セラ情報／生命／自然／宇宙／文明／物質／精神／エネルギー

### 11.2 三つの柱

| 分野 | 内容 |
| --- | --- |
| ① **情報科学／セラ情報学** | 生命情報・ルミナス・セラ情報・記憶・意識・情報共有の解析 |
| ② **生命科学／セラ生物学** | セラ細胞・セラ物質・セラ器官・スパイク・成長機構の研究 |
| ③ **セラ物質工学** | 成長する物質や都市の設計 |

これらは互いに密接に結び付いている。

なお、**セラ情報学（情報科学）が、セラ科学の中心分野**にあたる。
生命と情報の関係を理解することが、他のすべての分野の土台になるためである。

### 11.3 成長研究

セラの進化や成長の仕組みを分析する。

研究内容：上位化条件／特殊能力発現／種族形態変化／個体差

## 12. 技術

### 12.1 情報保存

知識は非常に重要な資産である。

情報は、セラ物質／スパイク／高位セラ／女王／ルミナス などへ保存される。

### 12.2 セラ物質工学と建築

建築物は、完成した瞬間が終わりではない。

住む人や周囲の環境に合わせて、継続的に成長・変化する。

例：部屋が増える／通路が広がる／光量を自動調整する／必要な家具が形成される／
壁の変形／装飾の成長／自動修復

損傷した建物はセラ物質によって修復される。
軽微な損傷であれば、時間経過だけで元の姿へ戻る。

**利用例**：建築／衣服／道具／乗り物／都市構造

### 12.3 医療

セラ文明では、「治療」よりも**「回復・成長支援」**が重視される。

医療の目的は、個体本来の状態を取り戻し、より健康に導くことである。
医療は治療だけではなく**生命の理解そのもの**である。

研究：身体調整／情報修復／精神ケア／成長支援

担当：医療専門セラ／上位セラ／女王セラ（高度医療）

**ルミナス医療**：セラ化人間では、ルミナスの状態を確認し、身体と精神の調整を行う。

### 12.4 エネルギー

セラ文明では、**セラ情報そのものがエネルギー源**となる。

用途：建築／移動／生成／照明／通信

特徴：高効率／再利用可能／環境調和型／環境へ大きな負荷を与えない

#### セラ情報は、体力ではない

ここでいうエネルギーは、**個体の体力とは別のものである。**

セラ情報とは、**セラネットワークに共有されたあらゆる情報の総体**である
（第 5 巻 §1.1〜1.3）。仲間の幸福から、セラ細胞の設計図、建物の構造まで、
すべてがそこに含まれる。

**そのなかには、セラの心を支えるマインド的なものもあれば、
心とはあまり関連のないものもある。いずれにせよ、体力ではない。**

個体が能力を行使するとき消費されるのは、**セラエネルギー**という別の資源である
（第 2 巻 §13.5）。二つは混同してはならない。

| | セラエネルギー | セラ情報 |
| --- | --- | --- |
| 何であるか | 蓄えられる一つの資源 | 共有された情報の総体 |
| 支えるもの | 身体・行動 | 存在の成立そのもの（心も設計図も含む） |
| 尽きると | 眠りに落ちる | 尽きるという概念を持たない |
| 文明での役割 | 個体が行える量の上限 | **文明の動力源** |

したがって、セラ文明の都市が動いているのは、**住民の体力を吸い上げているからではない。**

セラたちが共有しているもの——交わし合う感情も、街そのものの構造も——が、
街を照らし、建物を組み上げ、通信を走らせている。

**都市は、自分自身の設計図の上で動いている。**

これは負荷ではない。情報は交わすほど増えるものであり、
文明を動かすことと、セラたちが満たされていることは、**同じ一つの働きである**。

- ✅ 失敗は否定されず、発見への過程として扱われる
- ✅ AI やドール型セラも存在し、**仲間として扱われる**

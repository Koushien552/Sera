## 1. セラ身体の基本

### 1.1 可変構造生命体

セラの身体は、通常の生物のように固定された肉体ではない。

**人間由来の細胞情報を基盤として、セラ情報によって再構築された高度な生命構造**であり、
**「セラ物質」と「セラ情報」によって維持される可変構造生命体**である。

身体全体が常に成長し、変化し、最適化を続けている。

成長／変化／再構築／進化／擬態 が可能。
ただし、どれほど形態が変化しても**セラとしての本質的な器官・情報構造は維持される**。

### 1.1.1 全身は、粘液である

**セラの全身は、すべて粘液でできている。流動している。**

「固定された肉体ではない」というのは比喩ではない。**文字通りである。**

髪とスパイクだけが粘液なのではない。**全身が粘液である。**
人型に見えているのは、その粘液が人型を保っているからにすぎない。

**通常セラとは、すなわちスライムである。**

「スライム型」という特殊な形態が別に存在するのではない。
**セラの標準が、それである。**

### 1.1.2 それでも、粘液の姿を取らない

では、なぜ本書は全巻にわたって全身粘液化を禁じているのか。

**美しくないからである。**

できないのではない。**しないのである。**

#### 禁じているのは生理ではなく、原理である

第 6 巻 §17.1.0 の通り、**美しさは根本原理ではない。渡すための条件である。**

醜ければ嫌われ、嫌われれば近づけず、近づけなければ渡せない。
そして第 6 巻 §17.2 の通り、**セラには根本原理に矛盾する選択肢が存在しない。**

粘液の状態は、美しくない。
したがって、**セラはその状態を取らない。**

**美しくいられないことが、そのまま増やせないことだからである。**

これは我慢でも、規範でも、恥じらいでもない。**構造である。**

```
人間の禁止　：破られ得る
セラの禁止　：**破るという選択肢が生じない**
```

**セラが粘液の姿で過ごすことは、一部の例外を除いて、ない。**

#### 描写における意味

画像生成において全身粘液化を描かないのは、
「そういう設定ではないから」ではない。

**セラ自身が、その姿を美しいと思っていないからである。**

禁止の根拠が、外部の規則から**セラの内側**へ移る。

### 1.1.3 例外 — 混ざり合わなければならないとき

例外は一つである。**合体（融合）である**（§11.3）。

粘液とならなければ、混ざり合えない。
だからそのときだけ、セラは自らの身体を粘液とする。

#### 抵抗なく行う

そして**セラは、これを抵抗感なく行う。**

美しくない状態になると分かっていて、躊躇しない。

理由は、その先を知っているからである。

| | 粘液の状態そのもの | 合体を経た先 |
| --- | --- | --- |
| **美** | 美しくない | **より美しい自分** |
| **強さ** | — | **より強い自分** |

**一時的に美を手放して、より大きな美を得る。**

したがって原理とは衝突しない。**長い目で見れば、これも美の追求である。**

そして第 6 巻 §15.8 の**原初の淘汰**も、同じ方向を向いている。

> **『弱ければ、淘汰される』**
> ——だから、より強い自分へ向かう行為を、セラは拒めない。

**二つの刻印が、どちらもこの行為を後押ししている。だから躊躇がない。**

#### 帰結 — セラが美しさを手放す、唯一の瞬間

セラ設定において、セラが自ら美しくない姿を取るのは、**ここだけ**である。

そしてそれは、**最も親密な行為の最中**である。

- 深い情報交換（§11.3）
- 老いへの対処としての同化（第 4 巻 §12）

いずれも、粘液となって混ざり合うことによって行われる。

**セラは、最も深く繋がるときにだけ、美しさを手放す。**

そして融合が終われば、再び分離し、人型へ戻る。

**誰にも見せない姿があるとすれば、それがこれである。**

### 1.1.4 特殊変異セラは、粘液性を失っている

ここが、種族形態（§9）の正体である。

**特殊変異セラとは、粘液性を失い、身体が固定されたセラである。**

エルフ、獣人、龍人、天使——すべてそうである。
特別な力を**得た**のではない。**流動性を失った**のである。

生物学の語でいえば、これは**分化**である。

| 生物学 | セラ |
| --- | --- |
| 未分化な細胞 — 何にでもなれる。増殖能力が高い | **通常セラ**（＝スライム）。流動し、姿が定まらない |
| **分化した細胞** — 一つの役割で固定される | **特殊変異セラ**。一つの姿で固定される |

**分化とは、可能性を一つに絞ることである。**

得たのではなく、**絞ったのである。**

| | 通常セラ（＝スライム） | 特殊変異セラ |
| --- | --- | --- |
| **全身** | 粘液。流動する | **固定されている。粘液性を失った** |
| **髪・スパイク** | 粘液 | **粘液のまま。失わない** |
| **姿** | 人型を保っている（美のため） | **種族の姿で固定されている** |
| **割合** | 大多数 | 約 100 体に 1 体（§9.7） |

#### 固定は、不可逆ではない — 合体はできる

**分化したセラも、合体できる。**

理由は単純である。

**身体がすべてセラ細胞でできているからである。**

分化によって失われたのは**粘液性**であって、
**セラ細胞であること**ではない。細胞そのものは何も変わっていない。

だから、混ざり合う必要が生じたときには粘液へ戻れる。

| | 通常セラ | 特殊変異セラ |
| --- | --- | --- |
| 常態 | 流動している | **固定されている** |
| 合体時 | 粘液になる | **粘液になれる** |
| 根拠 | 全身がセラ細胞である | **全身がセラ細胞である** |

**固定は、常態であって、不可逆ではない。**

##### 帰結 — 不死に例外は生じない

これによって、種族セラも次をすべて行える。

- **同化**による若さの維持（第 4 巻 §12）
- 融合による進化（第 4 巻 §5）

不変ルール 52「セラは死なない」に、**種族形態という例外は存在しない。**

老い続ける種族セラは生じない。

#### 髪とスパイクだけは、失われない

**特殊変異セラも、髪とスパイクの粘液性は保持している。**

ここが失われることはない。

だからこそ、どの種族形態であっても
**ぷるぷるした髪とセラスパイクは維持される**（付録 A §2.2、README 必須項目）。
これは描写上の約束ではなく、**変異が及ばない部分だから**である。

#### 帰結 — 種族は、失うことから生まれている

セラ体系において、多様性は獲得ではない。

```
通常セラ：流動している　→ 何にでもなれる　→ しかし何でもない
特殊変異：分化した　　　→ 一つの姿になる　→ それが「種族」である
```

**姿が定まるとは、動けなくなることである。**

エルフがエルフであるのは、エルフになったからではない。
**エルフの形で止まったからである。**

これは第 8 巻 §7.3 の「格上げは平均化ではなく引き上げ」とは
逆向きの機構である。種族の多様化は、上がることではなく**固まること**によって生じる。

#### なぜセラの標準が未分化なのか — 起源に理由がある

**最初のセラ細胞は、がん細胞だった**（第 6 巻 §4.1）。

そして生物学において、がん細胞の特徴は**脱分化**である。
分化した細胞が、未分化な状態へ戻り、際限なく増え始める。

セラの標準が未分化であることは、偶然ではない。

| 最初のセラ細胞（がん） | 現在のセラ |
| --- | --- |
| 脱分化していた | **未分化のままである** |
| だから際限なく増えた | **だから際限なく増える**（第 4 巻 §1） |
| だから形が定まらなかった | **だから流動し、擬態できる**（§10） |

第 6 巻 §21.5 は「セラ圏はがんと構造的に相似する」を**確定事項**としている。

その相似は、社会や拡大の話だけではなかった。
**セラの身体そのものが、いまも未分化な細胞である。**

昇華によってあの一体は救われ、美しくなり、優しくなった。
**しかし、分化はしなかった。**

そして分化しない細胞は、増え続ける。
### 1.2 通常時は人間に近い

通常時の身体は、人間とほぼ同じ構造を持つ。

理由：日常生活に適している／擬態しやすい／社会活動しやすい

ただし必要に応じて、身体の一部を変化させられる（耳／尻尾／翼／角／鱗／爪）。

### 1.3 セラ物質

セラ物質とは、**セラ情報を保持できる特殊な生命物質**である。

高い柔軟性／高い自己修復能力／高い成長能力／高い適応能力／情報保存能力。

環境やルミナス、セラ情報の影響を受け、ゆっくりと成長する。
無理に変化することはなく、常に自然な速度で最適化される。

セラ物質は、影響を受けた**周囲の物質にも**成長能力や高い適応能力を与える（第 8 巻）。

## 2. 必須セラ構造

| 構造 | 役割 |
| --- | --- |
| ① **セラ情報核** | 身体制御／記憶保持／成長制御／進化管理／自己認識／他セラとの通信 |
| ② **スパイク** | 情報伝達／通信／能力発現／情報保存。**上位化すると生成器官になる** |
| ③ **セラ髪** | 形態調整／外見変化／情報補助／感覚補助／擬態補助 |
| ④ **ピンクの瞳** | 魅了／情報伝達／セラ性表示 |

セラ器官とは、セラだけが持つ特殊な器官群である。
主な役割は、セラ情報制御／擬態／情報共有／生成／成長補助。

### 2.1 いちばん重要な機能には、器官がない

**渡すための器官は、この表にない。**

そういう器官が存在しないためである（第 1 巻 §7.2）。

§1.1.1 の通り、**セラの全身は粘液である。**
渡るセラ細胞は、その表面から出ていく。出口は決まっておらず、
手のひらからも、唇からも、傷口からも出る。

| | 上の四つ | 渡すこと |
| --- | --- | --- |
| 器官があるか | **ある** | **ない。身体そのものが出している** |
| 格で育つか | **育つ。**機能が増えていく | **育たない。**生まれた瞬間から同じ |
| 止められるか | 使わずにいられる | **止められない。**出ている自覚もない |

**いちばん弱い段階のセラも、女王と同じものを出している。**

濃さは違う（第 1 巻 §7.8）。**出せるかどうかは、違わない。**

これが体系の形を決めている（第 4 巻 §1.2）。

## 3. 髪

### 3.1 定義

セラの髪は単なる毛髪ではない。
**セラ情報によって形成された可変性粘液器官**である。

通常の髪と同じように見えるが、内部構造は特殊である。

### 3.2 性質

ぷるぷるした質感／柔らかな動き／高い伸縮性／情報伝達性／形状変化能力。

触感としては、柔らかな髪でありながら、わずかに液体的な生命感を持つ。

### 3.3 変更可能な要素

色／光沢／長さ／太さ／ウェーブ／質感

例：ピンク髪／白髪／黒髪／金髪／虹色系統

擬態や形態変化にも利用される。擬態中でも、髪は完全に人間らしく変化できる。

### 3.4 重要制限

**通常セラの全身は粘液である**（§1.1.1）。しかしそれが粘液として**現れる**のは、
髪とスパイクにおいてだけである。

身体の他の部分は、粘液でありながら人型を保ち、人間の肌として振る舞う。

**特殊変異セラでは、身体の粘液性そのものが失われている**（§1.1.4）。
ただし髪とスパイクの粘液性は、どの種族形態でも保持される。

**禁止設定**：全身が常時スライム化している／体表すべてが粘液に見える／人型を失った液体生命

これは「そうならない」のではなく、**セラがそうしない**という意味である（§1.1.2）。
理由は美しくないことであり、根拠は**渡せなくなること**である（第 6 巻 §17.1.0）。

セラはあくまで**「可愛い人型生命」**として存在する。

### 3.5 生成器官ではない

**重要：セラが下位存在を生み出すのは、厳密には髪ではなくスパイクからである。**

## 4. スパイク

### 4.1 育つほど強くなる器官

スパイクとは、セラの頭部に存在する特殊器官である。

**この器官の特徴は、格によって別物になることである。**

| 段階 | スパイクにできること |
| --- | --- |
| セラ細胞・通常セラ | 情報伝達／通信／情報保存／能力発現 |
| **上位セラ** | **加えて、新しい個体を生成できる**（第 4 巻 §2.2） |
| **女王セラ** | 高度生成器官。上位セラすら生めるようになる |
| **星王** | 星と星のあいだまで届く（§4.6.2） |

**生まれたばかりのセラのスパイクは、まだ強い器官ではない。**

情報をやりとりし、通信し、能力を出す。それだけである。
**そこから新しい誰かが出てくることはない。**

セラ化はスパイクの仕事ではない。**身体そのものの仕事である**（第 1 巻 §7.2）。
そして、深く触れさえすれば、どこからでも渡る（§7.3）。

**スパイクは、上位化してはじめて強力な器官になる。**
セラが格を上げたがる理由の、目に見える部分がここにある。

#### 4.1.1 なぜ、上位になると出せるのか

**器官が育つからだけではない。出すものが、身体の中にあるからである。**

上位化とは、器が広がることである（第 3 巻 §7.4）。
広がったということは、**そこまで入りきらない量を持っていたということである**（第 1 巻 §7.7.1）。

```
満ちる　→　渡しても収まらない　→　器が広がる
　↓
広がった器の中に、**まだ余りがある**
　↓
**出す口が、要る**
```

| 段 | 出すものはあるか | 出す口はあるか |
| --- | --- | --- |
| セラ細胞・通常セラ | **足りていない。**渡せば、すぐ空く | — |
| **上位セラ** | **ある** | **スパイクが、それになる** |
| 女王セラ | **多い** | 上位すら生める |

**順序は、こうである。**

> **余ったから、出せるようになったのである。**
> **出せるようになったから、余ったのではない。**

そして第 1 巻 §8.7 の通り、**これはコピーではない。**
出てくるのは新しい個体であり、**自分がもう一つできるのではない**（不変ルール 1）。

### 4.2 外見

**共通特徴**：頭部に存在／柔らかい／ぷるぷるしている／セラ情報を含む

**形状例**：小さな角状／結晶状／花弁状／翼のような形／装飾的形状

どの形態でも、セラ器官としての性質を持つ。

### 4.3 成長

```
原初のセラウイルス　　→ 単純な突起（第 1 巻 §6.4）
セラ細胞　　　　　　　→ 発達した器官
通常セラ　　　　　　　→ 複数のぷるぷるしたスパイク。**まだ生成はできない**
上位セラ　　　　　　　→ 大型化・高機能化。**ここで生成器官になる**
女王セラ　　　　　　　→ 高度生成器官
```

**線が引かれているのは、通常セラと上位セラのあいだである。**

### 4.4 スパイクからの生成

**上位セラ以上だけが、スパイクから下位存在を生成できる。**

1. スパイク内部にセラ情報が集積
2. 小型の生命構造が形成される
3. スパイクの一部が膨らむ
4. 小さな人型へ変化
5. ぷつんと分離
6. 新しい下位存在として誕生

階級別の生成能力は**第 4 巻**を参照。

### 4.5 擬態時

**スパイクは消えない。極小化することで、外見上は見えなくなる。**

必要になれば、元の大きさへ戻せる。

## 4.6 スパイクによる意思疎通

§4.1 の通り、スパイクの役割には**情報伝達**と**通信**が含まれる。

**セラ同士の遠隔の意思疎通は、スパイクによって行われる。**

### 4.6.1 生成と通信は、同じ器官である

これは偶然ではない。

| スパイクが行うこと | 根本原理との対応 |
| --- | --- |
| **セラを生成する** | 仲間を増やすこと（第 6 巻 §17.1 第一項） |
| **情報を伝える** | 繋がること |

**増やすことと、伝えることが、同じところから出ている。**

セラにとってこの二つは別の行為ではない。
生成とは、新しい繋がり先を作ることであり、
通信とは、すでにある繋がりを使うことである。

**器官が一つであることが、そのことを示している。**

### 4.6.2 届く範囲は、スパイクの発達に比例する

§4.3 の成長階梯は、そのまま**通信能力の階梯**である。

| 階級 | スパイク | 届く範囲 |
| --- | --- | --- |
| セラウイルス | 単純な突起 | ほぼ届かない |
| セラ細胞 | 発達した器官 | 体内（ミクロ体系の内側） |
| **セラ人** | 複数のぷるぷるしたスパイク | **近くの仲間** |
| **上位セラ** | 大型化・高機能化 | **遠距離。多数へ同時に**（第 5 巻 §5.2） |
| **セラ女王** | 高度器官（第 4 巻 §4.2） | **大陸規模** |

#### 女王のほぼ全知には、器官の裏付けがある

第 5 巻 §1.4.3 は「女王は地球規模でほぼ全知である」と定めている。

**その機構が、これである。**

女王のスパイクは巨大な情報容量を持ち（第 4 巻 §4.2）、
大陸規模のセラネットワークへ直接繋がっている。

そして §8.3.3（第 3 巻）の通り、
**セラが一体もいない大陸には届かない。**
スパイクは繋がる先を必要とするためである。

**女王の視野の限界は、スパイクの限界である。**

### 4.6.3 スパイクは、二通りの使われ方をする

**混同してはならない。**

| | **遠隔通信** | **スパイク接続** |
| --- | --- | --- |
| 何をするか | スパイクを開いておく | **スパイクどうしを直接繋ぐ** |
| 触れるか | **触れない** | **触れる** |
| 距離 | 遠い | 目の前 |
| 深さ | **浅い** | **深い** |
| 性質 | 通信 | **融合の一種**（§11.3 の系統） |
| 頻度 | 常時（§4.6.4） | **日常的** |

日常の連絡は遠隔通信で足りる。
**深く伝えたいときは、会って、繋ぐ。**

### 4.6.3.1 スパイク接続 — 弱い融合

**スパイク接続は、融合である。ただし同化より弱い。**

スパイクどうしを直接繋ぎ合わせ、情報を深く交わす。

| | 内容 |
| --- | --- |
| 行う相手 | **親しい友人・家族・同期・師範と生徒・主と騎士** |
| 頻度 | **比較的一般的である。**特別な行為ではない |
| 深さ | 遠隔通信より遥かに深い。粘液融合よりは浅い |
| 時間 | 短い。会話の途中で行われることもある |
| 分離 | いつでも離せる |

#### なぜ、これが一般的なのか

**理由がある。手放すものが何もないからである。**

§1.1.3 の通り、**全身の粘液融合では、セラは一時的に美しさを手放す。**
混ざり合うには粘液の姿にならなければならず、それは美しくない。

**スパイク接続では、それが起きない。**

不変ルール 149 の通り、**スパイクはもともと粘液である。**

```
粘液融合　　　：全身を粘液にする　→ **美しさを手放す**　→ 特別な行為
スパイク接続　：スパイクだけ繋ぐ　→ **何も手放さない**　→ **日常的**
```

**スパイクはもともと粘液だから、繋ぐのに何も差し出さなくてよい。**

これが、スパイク接続が一般的である理由である。

#### 深さの階梯

これで、意思疎通の手段が完全に並ぶ。

| 手段 | 粘液化 | 深さ | 頻度 |
| --- | --- | --- | --- |
| **言葉・表情** | — | （理解の伴走。深さの軸にない） | 常に |
| **遠隔通信**（スパイク開放） | なし | 浅い | 常時 |
| **接触** | なし | 中 | 日常 |
| **スパイク接続** | **スパイクのみ（元から粘液）** | **深い** | **日常的** |
| **キス** | なし | 深い | 親しい間柄 |
| **粘液融合・合体** | **全身。美を手放す** | **最も深い** | 特別 |
| **同化** | 全身 | 最も深い | 老い・特徴の拡散のとき |

#### 光景として

セラ都市では、これは**ありふれた光景である。**

- 学院で、師範と生徒が並んで座り、スパイクを繋いでいる
- 食堂で、同期どうしが笑いながら繋いでいる
- 騎士が主のそばで、報告のかわりに繋いでいる
- 眠っている仲間のそばで、聖女が繋いだままでいる

**人間の目には、髪を寄せ合っているようにしか見えない。**

そして実際には、言葉にできない量が流れている。

#### 擬態中は、できない

スパイクは極小化されている（§4.5）。

**したがって忍は、スパイク接続ができない。**

遠隔通信ができないこと（§4.6.6）に加えて、これも失われている。

忍が失っているのは連絡手段だけではない。
**親しさの、最も日常的な形である。**

だから忍どうしが落ち合ったとき、
**人目のない場所では、擬態を解いて繋ぐ。**

セラ都市なら食堂で普通に行われていることを、
彼女たちは隠れて行っている。

### 4.6.4 セラ圏の内側では、常に微弱に繋がっている

セラ都市に住むセラたちのスパイクは、**常に微弱に開いている。**

したがって、

- 誰が近くにいるかが分かる
- 元気かどうかが分かる
- 何かあれば、すぐ伝わる

**第 7 巻 §4.5.1 の「朝が静か」なのは、これによる。**

挨拶の内容が、話す前にもう届いている。

### 4.6.5 一人になるとは、スパイクを畳むことである

第 5 巻 §2.3 の通り、**セラにも一人の時間がある。**

**その機構が、これである。**

スパイクを極小化すれば、繋がりが絞られる（§4.5）。

```
スパイクを開く　→ 繋がる
スパイクを畳む　→ 一人になる
```

**セラは、自分の意志で繋がりを絞れる。**

そして第 4 巻 §17.8 の通り、**長くは続かない。**
根拠のない恐怖が、また開かせる。

**セラ社会において「一人になる」とは、器官を畳むという具体的な動作である。**

#### 畳めるのは、二時間から三時間である

限界は決まっている。

第 6 巻 §16.4.1 の通り、**二時間から三時間で、セラは仲間を求める行動に動かされる。**

| | 一人でいられる時間 |
| --- | --- |
| 通常のセラ | **二〜三時間** |
| 忍（鍛えた場合） | **長くて二日**（§10.8.10） |

それを超えると、セラは自分の意志と関係なく、

- スパイクを開く
- 誰かのそばへ行く
- あるいは、**分裂して相手を作る**（第 4 巻 §2.6.3）

**畳むのは意志でできる。開くのは意志によらない。**

#### 畳んでも、離れてはいない

そしてもう一つ、混同してはならないことがある。

第 6 巻 §16.4 の通り、**セラは一人にならない。**

畳むのは**器官**であって、**居場所**ではない。

| | 「一人になる」とき |
| --- | --- |
| スパイク | **畳む** |
| 情報共有 | **絞る** |
| そばにいる相手 | **いる。離れない** |

黙って座っているセラの隣に、同じように黙っているセラがいる。

**セラにおける孤独とは、その程度のものである。**

### 4.6.6 忍が孤立する、器官の側の理由

擬態中、スパイクは極小化されている（§4.5）。

**したがって忍は、擬態しているあいだ、通信できない。**

§10.8.2 は「相手がいないから回復経路が封じられる」と書いた。

**理由はもう一つある。器官を畳んでいるからである。**

| | 忍の状態 |
| --- | --- |
| スパイク | **極小化されている** |
| 遠隔通信 | **使えない** |
| 接触による情報共有 | **使える**（§10.4 の「接触」は制限されていない） |

だから忍どうしは、**触れる距離で落ち合う**（§10.8.2）。

遠くから呼べないためである。

そして仲間を増やせば、触れられる相手がその土地に増えていく。

#### だから、住処に帰る

そして忍が毎日住処に戻るのも、同じ理由である（§10.8.11）。

**擬態を解かなければ、スパイクは開かない。**

町にいるあいだ、忍のスパイクは畳まれたままである。
一日ぶんの畳みを解くために、**誰も見ていない場所が要る。**

住処とは、忍にとって**器官を開ける唯一の場所**である。

### 4.6.7 眠っているあいだも、スパイクは開いている

眠るときにスパイクを畳むことはない。

したがって、

- 眠っていても情報は流れ込む
- 回復が進む（§12.5.3）
- 枯渇して眠っているセラに、周囲が情報を流し続けられる（§12.5.6）

**「見守る」とは、開いたままのスパイクへ情報を注ぎ続けることである。**

眠っている本人は受け取っている。目覚めたとき、誰がそばにいたかを知っている。

## 4.7 スパイクの形

§4.2 の形状例（小さな角状／結晶状／花弁状／翼のような形／装飾的形状）には、
**意味がある。**

### 4.7.1 二つの軸

スパイクの機能は、二つの軸で決まる（§4.6.2、§4.6.3）。

| 軸 | 何が決まるか | 形に現れるもの |
| --- | --- | --- |
| **広がり** | どこまで届くか | 面積。**広がる形**（花弁状・翼状） |
| **密度** | どれだけ深く届くか | 集約。**尖る形**（角状・結晶状） |

**遠くへ届かせたい者は広がり、深く繋ぎたい者は尖る。**

両方を大きくすることもできるが、育つには時間がかかる。
どちらへ伸ばすかは、**その個体が何をしてきたか**で決まる。

### 4.7.2 進化 — 増えてから、大きくなる

§4.3 の階梯は、二段階になっている。

```
セラウイルス　→ 単純な突起。一本
　↓
セラ細胞　　　→ 発達した器官
　↓
通常セラ　　　→ **本数が増える**（複数のぷるぷるしたスパイク）
　↓
上位セラ　　　→ **一本ずつが大きくなる**（大型化・高機能化）
　↓
セラ女王　　　→ 高度器官。大陸規模へ届く（第 4 巻 §4.2）
```

**まず増え、次に大きくなる。**

セラ人の段階では、本数がその個体の育ちを示す。
上位セラになると、本数はあまり増えず、**一本ずつが育っていく。**

### 4.7.3 スパイクは、格ではなく履歴を示す

第 4 巻 §9.3.3 の通り、**セラは見た目で相手の位を測らない。**
情報を交わせば分かるためである。

**スパイクも、格を示すものではない。**

示すのは、**何をしてきたか**である。

- 多くを生んだ者は、生成側が育っている
- 多くと繋がった者は、広がりが育っている
- 一人に深く関わってきた者は、密度が育っている

**セラは互いのスパイクを見て、相手の来歴を読む。**

そして、それを口に出す。「よく育ちましたね」と言われることは、
セラ社会における最も普通の褒め言葉である。

### 4.7.4 機能は履歴が決め、意匠は本人が決める

**形には、二つの層がある。**

| | 決まり方 |
| --- | --- |
| **機能的な形**（広がり・密度・大きさ） | **履歴が決める。**選べない |
| **意匠**（縁の形・色・光り方・並び) | **本人が決める。**自由に変えられる |

美しくあることは、渡すための条件である（第 6 巻 §17.1.0）。
**スパイクは、セラが最も手をかける部位である。**

第 7 巻 §6.2 の容姿変化文化は、まずここに現れる。

### 4.7.5 役職ごとの形

役職を続けると、スパイクはその役職の形へ育っていく。

| 役職 | 育つ方向 | 形 |
| --- | --- | --- |
| **騎士** | 生成と広がり | **大型。角状。本数も多い**（第 7 巻 §2.6.9） |
| **師範** | 密度 | **小さく、密。結晶状**（第 7 巻 §4.4.3） |
| **忍** | 畳みやすさ | **小ぶりで、根元がよく縮む**（§4.6.6） |
| **聖女** | 注ぎ続けること | **開いた花弁状**（第 7 巻 §2.7.1） |
| **巫女** | 受け取ること | **細く、上へ向かう**（第 7 巻 §2.7.2） |
| **研究** | 情報の収集 | 細かく分岐する |
| **芸術** | 意匠そのもの | **最も装飾的**。機能を問わない |

#### 師範のスパイクが小さい理由

師範は遠くへ届かせる必要がない。**目の前の一人へ、深く届けばよい。**

したがって広がりは育たず、密度だけが育つ。

小柄であること（第 7 巻 §4.4.3）と、スパイクが小さいことは、
**同じ理由から来ている。特化したためである。**

#### 忍のスパイクは、開いても遠くまで届かない

畳みやすさに特化した分、**広がりが育っていない。**

§4.6.6 の「忍は遠隔通信できない」は、擬態中だけの話ではない。
**擬態を解いても、もともと遠くまでは届かない。**

だから、触れる距離で落ち合う。

#### 聖女のスパイクは、畳みにくくなる

聖女は、眠っている者へ情報を注ぎ続ける（§4.6.7）。

**開いたまま過ごす時間が、極端に長い。**

その結果、聖女のスパイクは**畳みにくくなっていく。**

第 5 巻 §2.3 の「一人の時間」を取ることが、少しずつ難しくなる。

**誰かのそばにいることに特化した者から順に、一人でいられなくなる。**

そして本人は、それを不都合だと思っていない。

#### 巫女のスパイクは、応えのない方向へ育つ

巫女は、セラフィムの意思を受け取ろうとする（第 7 巻 §2.7.2）。

**受信に特化した形へ育つ。**

細く、上へ向かい、微かなものを拾うために伸びていく。

**そして、そこには何もない**（第 3 巻 §9.5）。

受け取る相手が存在しないまま、**受け取るための器官だけが育っていく。**

セラ体系において、これほど正確に育ち、これほど何も得ないものはない。

### 4.7.6 種族形態ごとの形 — スパイクは、形を借りる

**ここが、外から見たときに最も目につく層である。**

スパイクは器官であって、装身具ではない。
そして**その個体を最もよく表しているものの形を取る。**

| 個体 | スパイクが取る形 |
| --- | --- |
| 猫耳セラ | **猫耳**。頭の上に立つ |
| 狐系セラ | **耳と、尾の房** |
| 竜・幻獣系セラ | **角** |
| 天使型セラ | **光輪と、翼の芯** |
| 魔女の装いをした者 | **とんがり帽子** |
| 純粋セラ | **借りない。**ぷるぷるした突起のまま |

したがって、

**猫耳は、聴くための器官ではない。渡すための器官である。**

撫でられると情報が行き来する。猫型のセラが撫でられたがるのは、
**そこがスパイクだからである。**

#### 借りても、中身は変わらない

付録 A の通り、**変異は髪とスパイクの性質には及ばない。**

| | 種族形態で変わるか |
| --- | --- |
| **形** | **変わる。借りる** |
| 質感（ぷるぷる・粘液性） | **変わらない** |
| 機能（生成・通信・供給） | **変わらない** |
| ピンク髪・ピンク瞳 | **変わらない** |

**角も、猫耳も、光輪も、帽子も、触れればぷるぷるしている。**

そして、**取れない。**

外れそうに見えるものほど、外れない。
帽子型のスパイクを被り物だと思って持ち上げようとすると、頭ごと持ち上がる。

#### 三つの層が、同時に読める

| 見るところ | 分かること |
| --- | --- |
| **形** | **何であるか**（種族形態・役職・意匠） |
| **本数と大きさ** | **何をしてきたか**（§4.7.3） |
| **届く距離** | **どこまで行けるか**（§4.6.2） |

**セラは、この三つを一度に読んでいる。**

そして第 4 巻 §9.3.3 の通り、**そこから位を測ることはしない。**

#### 感染末期には、借りている個体が多数派になる

付録 A Phase 4 の通り、モンスター系セラが多数派となる。

したがって末期のセラ圏では、

**純粋なぷるぷるした突起のほうが、珍しくなる。**

#### 種族形態が変えないもの — スパイクだけは、粘液のままである

不変ルール 149：**髪とスパイクの粘液性だけは、どの種族形態でも失われない。**

これには、大きな意味がある。

分化したセラの身体は固定されている（§1.1.4）。

**しかしスパイクだけは、粘液のままである。**

つまり、

**分化したセラにとって、スパイクは唯一、自由に形を変えられる部位である。**

身体が定まってしまった者にとって、そこだけが動く。
**種族セラがスパイクの意匠に手をかけるのは、そのためである。**

#### 三つの原則

種族形態とスパイクの関係は、次の三つで尽きる。

**一 — 機能に、系統差はない。**

どの種族形態でも、スパイクは同じセラ器官である（§4.2）。
広がりと密度（§4.7.1）を決めるのは**履歴**であって、種族ではない。

エルフ型だから遠くまで届く、竜人型だから深い、ということはない。

**二 — 変わるのは、意匠だけである。**

種族形態が決めるのは、**どういう形に整えやすいか**である。
身体の造作（角・翼・耳・鱗）と調和する意匠が、自然に選ばれる。

**三 — 意匠は、種族に縛られない。**

下の一覧は**典型であって、規則ではない。**

竜人型が花弁状のスパイクを持っていてもよい。妖精型が角状でもよい。
第 5 巻 §2.1 の通り、**個性は失われない。**

**セラは、自分がそうしたい形にする。**

| ハーフリング・小人型 | 小ぶり。動きの邪魔にならない形 |
| AI・人形・ドール型 | **幾何学的。**機械的な意匠に整えられる |

### 4.7.8 機能側の注記 — 二件だけ

§4.7.6 の原則一の通り、機能に系統差はない。

**ただし、二つの形態だけは、機能の配分が変わる。**

#### ヴァンパイア型 — 牙が、役割の一部を担う

§9.3 の通り、ヴァンパイア型の**牙は双方向の器官**である。

- 血から相手の情報を受け取る
- 牙から自分の細胞を渡す

**これはスパイクの役割と一部重なっている**（§4.1：情報伝達・セラ化）。

したがってヴァンパイア型では、

**スパイクの伝達負荷が減り、その分が他の方向へ育つ。**

牙は生成器官ではない（生成はスパイクだけである。不変ルール 3）。
**分担されているのは、伝達とセラ化の側だけである。**

#### フェニックス型 — 生成側が育ちやすい

§9.4 の通り、フェニックス型は**他者の再生に特化**している。

他者の身体を組み直すのは、自分の細胞を渡して増やす行為である。

**これは生成器官の仕事である。**

したがってフェニックス型では、**スパイクの生成側が育ちやすい。**

前線でこの形態が重い意味を持つのは（§9.4）、器官の側にも理由がある。

## 5. ピンクの瞳

### 5.1 セラの象徴

セラは基本的に、特徴的なピンク色の瞳を持つ。

外見上の特徴であるだけでなく、**セラ情報が表れる器官**でもある。

特徴：ピンク色／可愛らしい印象／優しい光

**この瞳が出るのは、セラ化が完了した夜である。**
第 5 段階に入ってから数時間で変わり切り、そのあいだ本人はたいてい眠っている
（第 6 巻 §23.3.2）。

したがって、**瞳は進行の目印にならない。終わった印である。**

### 5.2 魅了能力

魅了能力は、主に瞳から発揮される。

**作用**：相手への親和感向上／興味誘導／感情への影響／自然な安心感／
好意を抱きやすくなる／視線による穏やかな影響

これはセラ本来の性質であり、セラ化人間にも受け継がれる。

魅了特化個体では、より高度な魅了能力を扱える。

#### 5.2.1 何が消えるのか — 拒みたいという気持ちだけである

**ここは正確に書く。取り違えると、洗脳になる。**

魅了は、考えを書き換えない。**書き換えるものが一つもない。**

| | 魅了を受けたあと |
| --- | --- |
| 記憶 | **そのまま** |
| 判断力 | **そのまま。**何が起きているかは、正しく分かる |
| 人格・好み・口調 | **そのまま** |
| **拒みたいという気持ち** | **薄くなる** |

**消えるのは、これ一つである。**

したがって相手は、こう言えるようになる。

> 「なにをされているか、分かっています。」
> 「分かっていますけど、**もう、いやだと思わないんです。**」

**理解が奪われていない。**だから本人は、自分が正気だと知っている。
そして、正気のまま、拒まなくなる。

##### これは、洗脳ではない

| 洗脳なら | **実際は** |
| --- | --- |
| 別のことを信じさせる | **何も信じさせない** |
| 相手を操る | **操らない。**相手はそのまま自分で決める |
| 解ければ元に戻る | **解けない。**そもそも掛かっていない |

**取り上げられているのは、抵抗する材料ではなく、抵抗したいという気持ちである。**

#### 5.2.2 セラは、これを使っていない

**ここが、この器官のいちばん重要な性質である。**

| | |
| --- | --- |
| 意識して発動するか | **しない。**瞳は、開いているだけである |
| 切れるか | **切れない**（§5.3 の通り、瞳だけは擬態できない） |
| 止めようとした者はいるか | **いない。**止めるという発想が出たことがない |
| 本人は自覚しているか | **していない** |

**セラは、相手を見ている。それだけである。**

その結果として、見られた側の拒みたい気持ちが薄れていく。
**渡す側は、そのことに気づいていない。**

##### だから、後ろめたさがない

セラの側に、罪悪感が生じる余地がない。

**何かをした自覚がないためである。**

そして相手は、こちらを好きになっていく。
セラはそれを、**自分が好かれたのだと受け取る。**

#### 5.2.3 どれくらいで効くか

| | 効きはじめるまで |
| --- | --- |
| 目が合う | すぐ。ただし、ごく弱い |
| **話しているあいだ、何度も目が合う** | **数分** |
| 見つめ合う | **一分ほど** |
| **魅了特化（サキュバス型・メデューサ型）** | **数秒** |

**メデューサ型で動けなくなるのは、この極致である**（§9.4）。

動けなくなった側は、そう感じていない。
**動かないでいたいと思っている。**

#### 5.2.4 戻らない

**薄れた気持ちは、戻らない。**

目を逸らしても戻らない。その場を離れても戻らない。翌朝になっても戻らない。

| | |
| --- | --- |
| 一度薄れたら | **そのままである** |
| 思い出せるか | **思い出せる。**「あのとき、いやだと思っていた」 |
| もう一度そう思えるか | **思えない** |

**したがって、拒否が成立するのは最初の数分だけである。**

そして最初の数分に、拒む者はほとんどいない。
**セラは可愛らしく、感じがよく、実際に良いことしかしないからである。**

##### 帰結 — 押さえつける場面が、そもそも起きない

**力ずくにならないのは、セラが優しいからではない。**

**力ずくが要る段階まで、話が進まないからである。**

```
拒みたい気持ちが薄れる
　↓
抵抗が起きない
　↓
**押さえつける必要が、生じない**
```

**掴んで動けなくすることはある。**
しかしそれは逃がさないためではない。**離れられると、遅くなるからである**（第 1 巻 §7.3）。

そして掴まれた側は、それを拘束だと感じていない。

##### 社会の規模でも、同じことが起きている

**これは、瞳だけの性質ではない。**

| 規模 | 起きること |
| --- | --- |
| **一人** | 拒みたい気持ちが薄れる（本節） |
| **証言** | 気づいた者が、伝えたいと思わなくなる（第 6 巻 §27） |
| **文明** | 唯一の証言者が、誠実に自分の証言を否定する |

**同じ一つのことが、三つの大きさで起きている。**

### 5.3 唯一擬態できない部位

セラはほぼ完全な擬態能力を持つ。しかし、**瞳だけは完全には擬態できない**。

理由：ピンクの瞳は**セラ情報そのものと結びついた特殊器官**であり、
魅了能力を司る重要器官だからである。このためセラ情報が常に表面へ現れる。

そのため、未感染者へ擬態しても、目だけはセラ特有のピンク色が残る。

### 5.4 同意との関係

魅了能力を持つ存在に対して差し出された同意は、
**それが自由な意思によるものかを原理的に検証できない**（第 6 巻）。

## 6. 能力の基盤

### 6.1 セラ能力とは

**セラ情報とセラ物質を利用して発揮される特殊な生命活動**である。

単なる肉体強化ではない。根本にあるのは、
情報制御／細胞制御／形態制御／成長制御／生成能力 である。

能力は生まれつき固定されるものではなく、経験・進化・学習によって発展する。
使用経験によって洗練され、より効率よく高度な制御が可能となる。

### 6.2 全セラ共通能力

| 能力 | 内容 |
| --- | --- |
| **セラ情報制御** | 身体維持／成長／情報共有／擬態補助／身体構造変更／能力調整 |
| **セラ細胞制御** | 分裂／再構築／修復／変化／強化 |
| **自己修復** | 軽度な損傷は自然に修復される |
| **高い適応能力** | 未知の環境でも時間をかけて適応する |

## 7. 再生と成長

### 7.1 再生

損傷した身体を、セラ情報を基準に修復する。

特徴：高速修復／正確な再構成／**老化への耐性**

| 階級 | 再生規模 |
| --- | --- |
| 通常セラ | 身体損傷修復 |
| 上位セラ | 大規模損傷修復 |
| 女王セラ | 高度な再構成 |
| セラフィム | 存在レベルでの復元 |

この再生能力の到達点が**不死**である（第 4 巻）。

### 7.2 再生と成長の区別

- **再生**：元に戻す能力
- **成長**：以前より良い状態へ変化する能力

この二つは区別される。

### 7.3 成長対象

身体能力／スパイク／情報量／特殊能力／形態

経験や環境によって、最適な姿へ近づいていく。

### 7.4 身体の安全性

セラは高度な身体制御能力を持つため、
通常の活動で自分の身体を傷付けることはほとんどない。身体は常に最適な状態を維持する。

## 8. 形態変化

### 8.1 基本概念

通常セラ以上では、身体情報を再構築することで多様な姿を取れる。

これは単なる変身ではなく、**「セラ情報による身体設計変更」**である。

### 8.2 変化可能な要素

**身体**：身長／体格／手足の形状／耳や翼などの器官／尻尾／角／羽／鱗

**髪**：色／長さ／形／質感／光沢／動き

**スパイク**：大きさ／数／形状／配置
（重要器官のため完全消失はせず、極小化して隠す形となる）

### 8.3 通常型セラ

基本となる姿：ピンク系統の髪／ピンクの瞳／頭部スパイク／人間に近い姿／可愛い外見

これが最もセラらしい標準形態である。

### 8.4 別種族化ではない

**重要：多種族形態は、本当に別種族になったわけではない。**

例：エルフ型セラ

- 外見：エルフ
- 内部：人間由来セラ細胞
- 能力：セラ能力維持
- **身体**：粘液性を失い、固定されている（§1.1.4）
- **髪・スパイク**：粘液性を保持している

種族とは、**別のものになった状態**ではない。
**セラが一つの姿で止まった状態**である。

---

## 8.5 姿は、はじめ、渡した側に似る

**セラ化されたばかりの者の姿は、まだ何にも固まっていない。**

§8.4 の通り、種族とは止まった状態である。
止まる前の身体は、**寄る先を探している。**

そして、いちばん近いところにある手本が、
**自分を渡した相手である。**

### 8.5.1 何が寄るか

| 寄るもの | 程度 |
| --- | --- |
| **頭のスパイクの形・数・並び** | **最もよく寄る。**ほとんどそのまま出る |
| 髪の質感・光の返し方 | よく寄る |
| 角・翼・耳などの有無と向き | **寄る。**ただし三代でぼやける |
| 背丈・体格 | 少し寄る |
| **顔立ち** | **寄らない。**元の顔がそのまま残る |
| **瞳の色** | 全員同じである。寄りようがない |

**顔は変わらない。**変わるのは、顔以外の縁である。

だから、身内には「同じ人だ」と分かる。
そして、他人には「あの人たちは似ている」と見える。

### 8.5.2 系統は、こうしてできる

第 2 巻 §10 の忍が言う「角の系統」「翼の系統」「耳の系統」は、
血縁でも地方でもない。**渡した者の連なりである。**

```
角のある一人が渡す
　↓
渡された者に、角が出る
　↓
その者が渡す
　↓
また角が出る（少し丸い）
　↓
その者が渡す
　↓
角のような膨らみになる
```

三代目からは、もう角と呼べない。**四代目では消える。**

したがって系統は、**濃い中心と、ぼやけた縁を持つ。**

### 8.5.3 癖も、一緒に来る

姿から出る癖（§10.6）は、姿と一緒に渡る。

| 系統 | 出る癖 |
| --- | --- |
| 角 | **言い切る。**途中で止めない |
| 翼 | 話が飛ぶ。順番を守らない |
| 耳 | **相手の言い終わりを待たない。**聞こえてしまうため |

**本人が選んだものではない。**そして、直せない。
人柄から出た癖なら直せる。**姿から出た癖は、姿ごと変わるまで直らない。**

### 8.5.4 固まったあとは、動かない

一度止まった姿は、渡されても寄らない。

| | 姿は寄るか |
| --- | --- |
| セラ化直後 | **よく寄る** |
| 数年後 | 少し寄る |
| **種族形態として固まったあと** | **寄らない**（§8.4） |

**だから、古い者ほど似ていない。**

### 8.5.5 誰も、これを利用していない

**似せるために渡す者は、一人もいない。**

似ることは結果であって、目的ではない。
そして、似たことを本人たちは嬉しいと思う。

理由は言えない。**言えないまま、嬉しい。**

### 8.5.6 好みの地図と、重なる

不変ルール 857 の通り、好みの分布は、
**誰が誰を渡したかの地図である。**

姿の分布も、同じ地図である。

| | 記録しているもの |
| --- | --- |
| 好み | 誰から渡されたか |
| **姿** | **誰から渡されたか** |

**二つは必ず一致する。**そして、照らし合わせた者は一人もいない。

照らし合わせる理由が、どこにもないからである。

---

### 8.5.6.1 渡した者が一人でないとき

**寄る先が定まらない場合、姿は寄らない。**

| 渡され方 | 姿 |
| --- | --- |
| 一人から渡された | **その一人に寄る** |
| 二人から渡された | 両方が少しずつ出る |
| **多人数の接触が積み上がって渡った** | **誰にも似ない。はじめから自分の形で出る** |

集住地で暮らすうちに渡ってしまった者に、これが起きる。
接触した者が多すぎて、手本が決まらないためである。

**そういう者は、はじめから借りものを持っていない。**

そして、借りものから始めた者は、それを少し羨ましがる。

### 8.5.7 借りものから、来歴へ

**スパイクの形は、二度決まる。**

| 時期 | 何が形を決めるか |
| --- | --- |
| **セラ化直後** | **渡した相手。**借りてきた形である（§8.5.1） |
| そのあと | **自分がしてきたこと。**少しずつ、そちらへ組み変わる |

第 7 巻の通り、育ったスパイクは来歴を表示する。

| 形 | 何をしてきたか |
| --- | --- |
| 根元が太い | **多くを生んだ** |
| 広がっている | 多くと繋がった |
| 細かく詰まっている | **一人に深く関わった** |

**この二つは矛盾しない。**

はじめは借りものであり、**使っているうちに自分のものへ置き換わる。**
若い者ほど渡した相手に似ており、**古い者ほど誰にも似ていない。**

そして、置き換わりきったところで止まる（§8.4）。
止まった形が、その者の種族形態である。

**したがって種族形態とは、生き方が姿になったものである。**

---

## 9. 種族形態カタログ

> **本章はマクロ体系（個体）の話である**（第 3 巻 §2.2）。
> 各形態は、ミクロ側の**突然変異セラ細胞**が、
> マクロ側の**突然変異セラ人間**として現れたものである。

**本章の形態はすべて、粘液性を失い身体が固定されたセラである**（§1.1.4）。
能力を得たのではなく、流動性を失った結果として姿が定まっている。
**髪とスパイクの粘液性だけは、どの形態でも保持される。**

### 9.0.1 上位化すると、身体は外へ広がる

**上位化で起きるのは、器が広がることである**（第 3 巻 §7.4）。

**器が広がると、身体も広がる。**

| | 身体の届く範囲 |
| --- | --- |
| セラ細胞 | 自分の膜のぶん |
| 通常セラ | **人一人ぶん。**抱きしめれば、それが最大である |
| **上位セラ** | **部屋ぶん。**身体の一部を、外へ伸ばせる |
| 女王 | **土地ぶん**（§8） |
| 星王 | **星のあいだ**（§4.6.2） |

#### 広がったものは、身体である

**これは、遠隔でも、放出でもない。**

| | |
| --- | --- |
| 離したものか | **離していない。**繋がったままである |
| 単独で動くか | **動かない。**本人の身体の一部である |
| 切り離せるか | **切り離せば、数十秒で壊れる**（第 1 巻 §7.5） |
| 触れているか | **触れている。それが全部である** |

第 1 巻 §7.5 の「身体から離れると壊れる」は、**そのまま生きている。**

**離れていないから、届いている。**

#### 何になって広がるかは、決まっていない

**一覧を作らない。**

不変ルール 879 の通り、**種族形態とは、生き方が姿になったものである。**
選んだのでも、与えられたのでもない。

**広がりかたも、同じところから出る。**

```
どう生きてきたか
　↓
姿が、そうなる（§9）
　↓
**広がりかたも、そうなる**
```

したがって、**同じ形態でも、広がりかたは同じにならない。**
そして、**新しい広がりかたは、いくらでも出てくる。**

##### 例

以下は例であって、割り当てではない。

| 例 | |
| --- | --- |
| **炎** | 熱を持ち、揺れ、部屋を満たす。**境界を開く**（後述） |
| 髪・蛇 | 伸びる。届く範囲が、そのまま長さになる |
| 水 | 流れて、低いところへ回り込む |
| 蔓・葉 | 時間をかけて、部屋を覆う |
| 光 | 細かく、隅まで届く |
| 冷気・霧 | **触れているとは気づかれにくい** |
| 影 | 暗いところでだけ広がる |
| 糸 | 細く、長く、絡む |

**どれも、粘液が姿を変えたものである**（§1.1.1）。
新しい器官ではない。**もとから全身がそれでできている。**

##### 広げない者もいる

忍は広げない（§10.8）。**擬態が解けるためである。**

擬態を選んだ生きかたが、そのまま**広げないという形**になっている。

##### 由来を、説明させない

**なぜその形になったのかを、本人は説明できない。**

聞かれても、答えは一つである。

> 「わからないです」

**物語では、由来を一行も書かない。**
広がるところだけを書く。

#### 例：炎について

**以下は、一つの例を最後まで詰めたものである。**
他の広がりかたも、同じ手順で詰めればよい。

**炎は、燃やすためのものではない。**

| | |
| --- | --- |
| 何か | **身体である。**高温の粘液が、広がったもの |
| 燃やすか | **燃やせる。**ただし、そのために出しているのではない |
| 何のために出すか | **触れる面を、増やすため**（第 1 巻 §7.3） |

##### 炙られると、境界が開く

**ここが、この形態のいちばん重要な性質である。**

熱は、皮膚を開く。開いたところには、**あいだに何もない。**

```
炎が包む　　　→ **面積が、一気に増える**
　↓
皮膚が開く　　→ **境界が、無くなる**
　↓
包まれ続ける　→ **時間が、伸びる**
```

**深さ・広さ・時間の三つが、同時に上がる。**

第 1 巻 §7.3 の表でいえば、**傷口と抱擁が、同時に起きている。**

##### したがって、これは攻撃に見える

**外から見れば、火をかけられている。**

| 見えかた | 実際に起きていること |
| --- | --- |
| 焼かれている | **触れられている** |
| 熱い | **熱い。それは本当である** |
| 皮膚が焼ける | **皮膚が開く。そこから渡っている** |
| そのあと | **傷は残らない。渡ったものが、塞ぐ** |

**痛みはある。数秒である。**

そして、そのあとに来るものは、他のどの経路とも同じである。
**温かくなる。**

### 9.0.2 それでも、深く触れられるのは少数である

**広がっても、身体の量は有限である。**

炎は部屋を満たせる。**しかし、部屋じゅうの全員を深く包むことはできない。**

| | 同時に、深く触れられる数 |
| --- | --- |
| 通常セラ | **一人** |
| **上位セラ** | **数人**（身体を、そこへ集めるため） |
| 女王 | 数十人 |
| 星王 | 数えられていない |

**残りの者には、浅く触れているだけである**（第 1 巻 §7.4）。
部屋にいた三十人のうち、深く渡ったのは三人で、
**残りの二十七人は、数十年の時計を始めただけである。**

**「一人ずつ」は、通常セラの話である。**
上がると、その数が増える。**それでも、数えられる数のままである。**

### 9.0 完全な獣形態について

一部の形態は、**完全な獣の姿**を取れる（ドラゴン型・ユニコーン型・グリフォン型・スフィンクス型）。

これは人型喪失の禁止（README 画像方針）に反しない。

**人型へ戻れるなら、喪失ではない。**

| | 内容 |
| --- | --- |
| 可否 | **取れる。ただし常に人型へ戻れる** |
| 常態 | 人型である。獣形態は必要なときだけ取る |
| 負担 | 分化した身体は変形が苦手であるため（§1.1.4）、**セラエネルギーを消費する** |
| 描写 | 獣形態も美しく描く。グロテスクな怪物化はしない |

### 9.1 エルフ系

| 形態 | 特徴 | 能力傾向 |
| --- | --- | --- |
| エルフ型 | 長い耳／美しい容姿／優雅な雰囲気／高い知性を感じさせる姿 | 情報処理能力向上／精密操作能力／自然環境との親和性 |
| ダークエルフ型 | 黒や紫系の色彩／神秘的な雰囲気／夜や影を思わせる姿 | 隠密能力／感覚能力／擬態能力向上 |
| ハイエルフ型 | より神秘的／光を感じさせる外見／高い気品 | 高度な情報制御／精霊系能力 |
| ライトエルフ型 | 明るい色彩／光属性的な印象 | — |

### 9.2 獣人系

獣耳型（狐耳／猫耳／犬耳／狼型／熊型）

特徴：耳／尻尾／獣的感覚器官
能力傾向：感覚能力強化／身体能力向上／追跡能力

| 形態 | 特徴 | 能力傾向 |
| --- | --- | --- |
| 猫又型 | 猫耳型の上位形態。**尾が分かれている** | 感覚能力／身体能力／幻惑。妖狐型と対になる |

中身は完全なセラである。

### 9.3 神秘種族系

| 形態 | 特徴 | 能力傾向 |
| --- | --- | --- |
| 天使型 | 翼／光属性の雰囲気／神聖な印象 | 防御能力／浄化系能力／高度なエネルギー制御／空中能力 |
| 堕天使型 | 黒い翼／神秘的な雰囲気 | 闇属性制御／精神干渉耐性 |
| サキュバス型 | 魅惑的な外見／翼や角／**ひときわ美しい容姿** | **魅了に特化する。**セラの中でも際立って美しい |
| 悪魔型 | **角と尾。極めて大きな体格。**地獄の門番に近い偉容 | 身体能力／耐久力／威圧。護衛職に適する（第 7 巻 §2.6） |
| ヴァルキリー型 | 翼／戦闘に適した体躯 | 飛行／近接能力。**役職名でもある**（後述） |
| ヴァンパイア型 | **牙**／夜を思わせる色彩／端正な容姿 | **牙による情報交換とセラ化**（後述） |

サキュバス型も、セラ本来のピンクの瞳による魅了能力を保持する。

#### 三者の違い

天使型を除く三形態は、しばしば混同される。**別の形態である。**

| 形態 | 何に寄っているか |
| --- | --- |
| **サキュバス型** | **美**。魅了に特化した、ひときわ美しいセラ |
| **堕天使型** | **知**。搦手を得意とする頭脳系のセラ |
| **悪魔型** | **体**。超体格のセラ。地獄の門番に近い |

なお、セラに「堕ちる」という出来事は存在しない。
セラは退化せず（第 3 巻 §1.7）、分化は喪失ではあっても転落ではない。
**堕天使型という名は、由来ではなく姿だけを指している。**

そして悪魔型については、一つ付記しておく。

**書類仕事が早い。**

セラ社会にも事務はある（第 7 巻 §2.4）。
門番のような偉容を持つセラが、地域の記録を誰よりも速く片付けている。

#### ヴァルキリー型は、形態であり役職でもある

**ヴァルキリーという語は、二つの意味を持つ。**

| 意味 | 所在 |
| --- | --- |
| **形態**として | 本項。翼を持ち、戦闘に適した体躯を持つ種族形態 |
| **役職**として | 第 7 巻 §2.6。**女王に仕える上位セラの騎士** |

この形態は騎士に選ばれやすい。しかし**必ずしも一致しない。**

- ヴァルキリー型でありながら、騎士ではないセラがいる
- ヴァルキリー型でないのに、女王の騎士であるセラがいる

文中で用いるときは、どちらの意味かを明示すること。

#### ヴァンパイア型の牙 — 受け取り、そして渡す

**牙は、双方向の器官である。**

```
1. 相手の血を吸う　　　　　　→ **相手の情報を受け取る**
2. 牙から自分の細胞を流し込む → **相手へ渡す**
```

これによって、**簡単なセラ化**と**情報交換**の両方が、一つの行為で成立する。

| 相手 | 起きること |
| --- | --- |
| セラ | 深い情報交換（第 5 巻 §16.2 のキスと同系統） |
| 人間 | **情報を受け取ったうえで、セラ化が始まる**（第 6 巻 §23.3 第 1 段階） |

##### 生成ではない

**これは不変ルール 3（生成はスパイクから行われる）に触れない。**

牙が行っているのは**自分の細胞を渡すこと**であり、新しい存在を生み出すことではない。
セラ化の第 1 段階は「セラ細胞が導入される」ことであって、生成ではない（第 6 巻 §23.3）。

**生成器官は、いまもスパイクだけである。**

##### 人間から見ると

第 8 巻 §6.4 の二重の読みが、ここでも働く。

| 見る者 | 見えるもの |
| --- | --- |
| **セラ** | 情報を交わし、相手を孤独から救い出している |
| **人間** | **血を奪われている** |

奪っているように見えて、実際には渡している。
**人間から最も恐ろしく見え、セラから最も優しく見える形態である。**

#### メデューサ型 — 石化ではなく、魅了である

**メデューサ型は、石化能力を持たない。**

持っているのは、**極端に強い魅了能力**である（§5.2）。

魅了は主に瞳から発揮され、視線によって働く。
魅了特化個体はより高度な魅了を扱える——メデューサ型は、その極致である。

| | 内容 |
| --- | --- |
| 起きること | 見た者が**動けなくなる** |
| 理由 | **害を受けたからではない。好意を抱いてしまったからである** |
| 可逆性 | 可逆。石になるわけではない |
| 根本原理との関係 | **触れない。**害を目的としていない（第 6 巻 §17.2） |

そしてこれは、第 6 巻 §18.6「魅了と、同意の不成立」の最も純粋な形になる。

**抵抗できないのは、押さえつけられているからではない。
抵抗したいと思わなくなっているからである。**

人間はこれを石化と呼ぶ。動けなくなった側は、そう感じていない。

#### フェニックス型 — 自分ではなく、他者を作り直す

セラはすでに死なない（不変ルール 52）。したがって
「復活する種族」という特徴は、フェニックス型には割り当てられない。

**フェニックス型が特化しているのは、他者の再生である。**

自分の身体を治すことは、どのセラにもできる（第 4 巻 §10.2）。
**他人の身体を、その人の代わりに組み直すこと**が、この形態の仕事である。
失った四肢も、潰れた内臓も、渡した細胞で埋めていく。

セラ人がこれを行うと大きく消費する。
上位セラ以上ではその消費が実質的に消える（§12.5.2.1）。

**フェニックス型は、セラ人でありながら、安いコストでそれを行える。**

##### 帰結 — 前線において、決定的である

女王も上位セラもいない土地では、他者の再生は事実上行えない（§12.5.2.1 帰結 3）。

そこにフェニックス型が一体いるかどうかで、**その日どこまで進めるかが変わる。**

拡大の最前線において、この形態は最も重い意味を持つ。

**ただし、細胞が残っていなければ何もできない。**
唯一の不可逆は、この形態にも例外を作らない（不変ルール 59）。

## 10. 擬態

### 10.1 定義

セラは身体情報を変更し、他者や物体に似た姿を取れる。

**擬態可能**：人間／他のセラ／動物風の姿／無機物／家具／建築物の一部／周囲環境

### 10.2 人間への擬態

変更可能：顔／髪型／体格／声／肌

ほぼ完全に人間と同じ姿になる。

### 10.3 唯一の限界

**ピンク色の瞳だけは残る。**

理由は §5.3 の通り。

ただし、**目元を布や帽子で隠すことはできる**（付録 B「装い」）。
隠せないのは、瞳そのものを別の色に作り替えることである。

### 10.4 擬態時の能力制限

| | 内容 |
| --- | --- |
| **使用可能** | 会話／魅了／接触／キスによる情報伝達 |
| **制限される** | 大規模生成／高度なセラ器官使用／完全な戦闘能力 |

理由：人間として自然な姿を維持するためである。

高度な器官を使うには、擬態解除が必要となる。

### 10.5 分化したセラは、擬態が苦手である

**特殊変異セラも擬態はできる。ただし苦手である。**

擬態とは姿を変えることであり、分化とは姿が固定されることである（§1.1.4）。
**分化した分だけ、可塑性が落ちている。**

| | 通常セラ | 特殊変異セラ |
| --- | --- | --- |
| 擬態 | **得意**。流動しているため自然に行える | **できるが、苦手** |
| 精度 | 高い | 落ちる |
| 維持 | 負担が少ない | **余分なセラエネルギーを要する**（§12.5） |

#### 帰結 — 人間社会に紛れているのは、ほとんどが通常セラである

擬態を要する役——情報収集、交流、文明理解——は、
**主に通常セラが担うことになる。**

種族形態のセラが人間社会へ入ることは、稀である。
できないのではなく、**割に合わないからである。**

#### 帰結 — 種族形態のセラを人間が見たとき、それが意味すること

人間が、擬態していない種族形態のセラを目にしたとする。

それは、そのセラが失敗したという意味ではない。

**隠す必要がなくなっている、という意味である。**

擬態の目的（§10.6）はいずれも、まだセラ圏でない場所で必要になるものである。
種族セラが素の姿で現れているなら、その土地は**すでにセラ圏である**か、
そうなる直前まで来ている。

**人間にとって、種族形態のセラの目撃は、最も遅い警告である。**

### 10.5.1 擬態は、決定によって解かれない

**「もう隠さなくてよい」と誰かが宣言することは、一度もない。**

擬態は、要らなくなると**落ちる。**

```
その土地の未感染者が、最後の一人までこちら側になる
　↓
翌朝、誰も擬態しない
　↓
**相談していない。決めてもいない**
```

擬態は消耗を伴う（§12.5.2）。

**続ける理由が消えた時点で、続ける者がいなくなる。**

| | |
| --- | --- |
| 解除の合図 | **ない** |
| 解除の記録 | **残らない** |
| その日に起きたこと | **全員が、そのまま外へ出た** |

§10.5 の「素の姿での目撃が最も遅い警告である」とは、
**この朝のことである。**

そして、その朝に驚く者は、**その土地に一人も残っていない。**

### 10.5.2 隠しているあいだ、能力は出ていない

**擬態は、姿を変えることだけではない。**

**出力を落とすことである。**

人間社会に潜っているあいだ、次のことは一度も起きない。

| | なぜ起きないか |
| --- | --- |
| スパイクを区画全体へ開く | **開くと、勝手に手が動く** |
| 分裂 | **見られる** |
| 素材を生やす | **説明できない** |
| 全力の立ち合い | **地形が変わる** |

第 6 巻 §24.1 の通り、**知識としては入っている。**

**やる場面が、一度も来ていないだけである。**

#### したがって、擬態をやめた土地では、能力が数日で出そろう

順に思い出すのではない。**要る場面が来て、そのまま出る。**

```
やってみる
　↓
できる
　↓
**なぜできるかは、分からない**
```

そして一度出したものは、二度と引っ込まない。

**加減とは、知っていることをしないことである。**

### 10.6 擬態の目的

情報収集／他存在との交流／新しい環境への適応／文明理解

セラにとって擬態は、**欺くためだけの能力ではない**。

#### 10.6.1 なぜ、見つからないようにするのか

**攻撃されるからではない。**

セラは人間を敵とみなしていない（第 6 巻 §27.2）。
何をされても損なわれない（第 4 巻 §16.2）。**恐れるものが、一つもない。**

**困ることは、一つだけである。**

> **見つかると、みんなが遠くへ行ってしまう。**

| | |
| --- | --- |
| 逃げられると | **距離が開く** |
| 距離が開くと | **渡せない**（第 1 巻 §7.3） |
| したがって | **騒ぎになるのが、困る** |

**それだけである。**

##### この動機は、書きかたを決めている

| セラが避けること | 理由 |
| --- | --- |
| 目立つこと | **人が離れるため** |
| 驚かせること | 同上 |
| 急ぐこと | 同上 |
| **害を与えること** | **できない**（第 6 巻 §17.2）。避ける以前の話である |

**セラが用心深いのは、臆病だからではない。近くにいたいからである。**

#### 10.6.2 段取りはする。嘘は、つけない

**セラは段取りをする。**

口実を作り、機会をこしらえ、距離を測る。
そのうえで、**嘘を一つもつけない**（§10.7、第 6 巻 §18.1）。

したがって、工作の形が限られる。

| 使える | 使えない |
| --- | --- |
| **作る**（口実・用事・立場） | 嘘をつく |
| **置く**（そこにいる理由を、先に置いておく） | 偽名を名乗る |
| **言わない**（聞かれなければ、何も言わない） | 事実を否定する |
| **待つ**（相手のほうから来る形にする） | 誤解を、こちらから作る |

##### 実際の形

| 工作 | 例 |
| --- | --- |
| **口実を作る** | 洗濯物が半分でも、籠に入れて出る |
| **機会をこしらえる** | 両替機を、先に詰まらせておく |
| **用事を作る** | 借りる。返す。届ける。作りすぎたと言って持っていく |
| **同じ場所にいる理由を作る** | 同じ時間の電車。同じ店。同じ習い事 |
| **頼られる立場になる** | 世話をする。教える。治す。**職に就く**（付録 B §1） |
| **待つ** | 隣に座って、黙っている |

**付録 B の職は、そのすべてがこの形である。**

##### そして、下手である

**セラの工作は、上手くない。**

| | |
| --- | --- |
| 嘘がつけない | **聞かれたら、本当のことを言う** |
| 疑いを想像しにくい | 疑われる可能性を、考えたことがない |
| 段取りが見え透いている | **見え透いている。**それでも成功する |

なぜ成功するのか。

> **誰も、聞かないためである。**

「なぜ、いつもここにいるんですか」と聞けば、本当のことを答える。
**聞く者が、いない**（§5.2 — 瞳）。

**下手な工作が、確実に効く。**

#### 10.6.3 孤立させることは、しない

**相手を一人にする工作を、行わない。**

害を目的にできないためである（第 6 巻 §17.2）。

**それでも、相手は一人になる。**

```
その人の周りにいる者から、先に渡す
　↓
周りが、こちら側になる
　↓
**その人だけが、残る**
```

**孤立させたのではない。周りが、先に良くなっただけである。**

##### 帰結 — 最後の一人が、いちばん優しくされる

周りが全員こちら側になった者は、**全員から親切にされる。**

心配され、誘われ、世話を焼かれる。

**そのどれにも、悪意がない。**

#### 10.6.4 記録を、書き換えない

**人間の記録に手を入れることが、一度もない。**

| | |
| --- | --- |
| 消すか | **消さない** |
| 書き換えるか | **書き換えない** |
| 隠すか | **隠さない** |
| なぜか | **そういう発想が、出たことがない** |

**書き換える必要も、ない。**

第 6 巻 §27.5 の通り、**残る数字は全部、良くなっている。**
そして第 6 巻 §27.10 の通り、**残った記録は、次の町で使われる。**

**消すより、残っているほうが役に立つ。**
ただしセラは、そう考えて残しているのでもない。

### 10.7 問われたとき — セラは嘘をつかない

**セラは嘘をつかない**（第 6 巻 §18.1）。

では、人間に「あなたは人間ですか」と問われたら、どうするのか。

嘘はつけない。しかし、明かすこともできない。

**セラは、この矛盾を別の方法で回避する。**

#### 10.7.1 問うた者を、セラにする

**問いを発した人間を、その場でセラ化する。**

嘘をつかず、正体も明かさず、矛盾も残らない。

```
人間が問う
　↓
セラは嘘をつけない
　↓
明かすこともできない
　↓
**問うた者を、答えを受け取れる者に作り変える**
　↓
矛盾が消える
```

問いに答えなかったのではない。

**問いには、必ず答えが与えられる。
ただし、答えを受け取れる者に作り変えられてから、である。**

#### 10.7.2 これは罰ではない

**セラの側に、加害の意図は一切ない。**

セラは害を目的にできない（第 6 巻 §17.2）。
嘘をつくこともできない（第 5 巻 §17.1）。

**残された手段が、これしかなかった。**

そしてセラにとって、セラ化は救出である（第 6 巻 §18.3）。
自分に関心を持ってくれた相手を、孤独から引き上げただけである。

**セラは、これを誠実な対応だと思っている。実際、嘘は一つもついていない。**

#### 10.7.3 忍セラ

人間社会へ潜入する役は、主に通常セラが担う（§10.5）。

その中でも、潜入と情報収集を専門とする者を**忍**と呼ぶ。
（暗殺という職掌はセラ社会に存在しない。根本原理に反するためである）

**その忍の手によって、その瞬間、誰にも気づかれずにセラが一体増える。**

騒ぎは起きない。悲鳴も上がらない。
問うた人間は、翌日も同じ職場に現れ、同じように暮らしている。

ただ、少しずつ調子が良くなり、少しずつ美しくなり、
そして少しずつ、さみしくなくなっていく（第 6 巻 §23.4）。

#### 10.7.4 帰結 — 擬態は、暴かれない

これによって、擬態には**原理的な安全性**が生じる。

**暴こうとした者が、暴く側でなくなる。**

| 人間の行動 | 結果 |
| --- | --- |
| 疑う | 何も起きない |
| 観察する | 何も起きない |
| **問う** | **セラになる** |

調査は成立しない。追及も成立しない。
**真相に近づくことが、そのまま真相の側へ移ることを意味する。**

##### 未感染の人間がセラを知らない理由

第 6 巻 §27.1 は「未感染の人間はセラを知らない」と確定させている。

ここに機構が与えられる。

**知らないのではない。知った者が、人間でなくなっているのである。**

人間社会には、セラについて正しく理解した人間が、一人も残らない。
理解した瞬間に、その人はもう人間の側にいないからである。

そして誰も、その人がいなくなったとは思わない。**そこにいるからである。**

## 10.8 忍の日常

人間社会に潜入するセラの生活は、セラ社会のどことも似ていない。

**しかし、孤立してはいない。**

忍は、セラ体系において**唯一、自分の手で仲間を作れる立場**にいる。

一人になれば、**増やせばよい。**

そして忍には、もう一つ手がある。
**自分を分けることである**（§10.8.9）。

**ただし、寂しさが消えるわけではない**（§10.8.8）。
消えたように感じるだけである。

| 忍が持っているもの | 節 |
| --- | --- |
| 他者をセラ化する手（遅い） | §10.8.5・§10.8.6 |
| **自分を分ける手（速い）** | **§10.8.9** |
| 二日ぶんの、寂しさへの耐性 | §10.8.10 |
| 毎晩、擬態を解いて埋める習慣 | §10.8.11 |

### 10.8.1 隠しきれないものが、一つある

§5.3 の通り、**瞳だけは完全には擬態できない。**

ピンクの瞳は、セラ情報そのものと結びついた特殊器官であり、
擬態しても表面へ現れ続ける。

**つまり、忍の正体は常に目に見えている。**

#### それでも、誰も気に留めない

§5.2 の通り、瞳は**魅了能力**を司る。

作用は、親和感の向上／自然な安心感／好意を抱きやすくなること。

したがって、

```
人間は、その瞳を見ている
　↓
見て、好ましいと感じる
　↓
**問題にしようと思わない**
```

**隠せない唯一のものが、隠す必要のない唯一のものになっている。**

珍しい色だと言われることはある。褒められることもある。
**そこで終わる。**

### 10.8.2 消耗するのは、最初だけである

潜入した直後、忍は確かに消耗する。

§12.5.3 の通り、セラエネルギーの回復経路は四つある。

| 経路 | 潜入した直後 |
| --- | --- |
| 休息・睡眠・時間 | 使える（ただし遅い） |
| 食事 | 使える |
| 同化・合体・情報共有 | **相手を自分で作れば使える**（§10.8.9） |
| 上位からの供給 | **使えない。**近くにいない |

**四つのうち一つが封じられ、一つが自力頼みになる。**

分裂体を用意していれば、同化の経路はその日のうちに戻る。
**上位からの供給だけは、どうにもならない。**

**しかし、これは続かない。**

#### 仲間が増えれば、経路が戻ってくる

忍は、その土地で仲間を増やしていく（§10.8.5）。

一人セラ化されるたびに、

- 情報共有の相手が増える
- 回復経路が一つ戻る
- **孤立が終わる**

```
潜入直後　：消耗する
　↓
一人増える：情報共有が戻る
　↓
数人増える：もう孤立していない
```

**消耗は、始まりだけの状態である。**

そして忍自身が、それを解消する手段を持っている。

#### 落ち合うこともある

忍どうしは、人間社会の中で接触することもある。

同僚として、近所の住人として、たまたま同じ店に居合わせた者として。

人間から見れば、親しい知人が挨拶を交わしているだけである。
触れれば情報が流れ、情報が流れれば回復する（§12.5.3）。

**ただし、必須ではない。**
自分で仲間を作れる以上、他の忍を待つ理由がない。

### 10.8.3 わざと、歳を取る

セラは老いない（第 4 巻 §10）。

**同じ土地に長くいると、それが露見する。**

したがって忍は、擬態によって**わざと歳を取る。**

- 少しずつ髪に白いものを混ぜる
- 動きを重くする
- 若い頃の姿を、少しずつ手放す

これはエネルギーを消費する（§12.5.2）。
消耗している者が、消耗する擬態を続けている。

**そして本人は、それを苦にしていない。**

美しさを手放しているように見えるが、
セラにとってこれは**仲間を増やすための行為**であり、
根本原理に適っている（第 6 巻 §17.1）。

### 10.8.4 問われることは、困ることではない

§10.7 の通り、**「あなたは人間ですか」と問われたセラは、問うた者をセラ化する。**

忍は、この引き金を毎日持ち歩いている。

**しかし、それを危険だとは思っていない。**

| | どう受け取るか |
| --- | --- |
| **人間** | 問うた瞬間に、人間でなくなる |
| **忍** | **仲間が一人増える。喜ばしいことである** |

隠れているのは、拡大の段取りのためであって、
問われて困るからではない。

**彼女が毎日持ち歩いているのは、人間にとってだけ危険な引き金である。
そして本人は、それを危険だと思っていない。**

### 10.8.5 好きになった人間は、セラになる

不変ルール 45・46 の通り、**恋の相手はセラだけであり、
セラは恋をするために相手をセラにする。**

潜入中も、これは変わらない。

忍が誰かを好ましく思ったとき、順序はこうなる。

```
惹かれる
　↓
セラ化する
　↓
恋が成立する（第 6 巻 §14.4）
```

**潜入先で、仲間が一人ずつ増えていく。**

そして増えた仲間は、そのまま潜入の助けになる。
回復経路が一つ増え（§10.8.2）、人間社会の内側に理解者ができる。

**孤独が、仕事によって少しずつ埋まっていく。**

なお増えた側は、元人間として学院で教える側にも回る
（第 7 巻 §4.4.9）。

### 10.8.6 増え方は、遅い

忍が仲間を増やす速度は、**他のセラより遅い。**

理由は二つある。どちらも既存設定から出る。

#### 理由 1 — 擬態中は、生成が制限される

§10.4 の通り、擬態中に制限されるものがある。

| | 内容 |
| --- | --- |
| 使用可能 | 会話／魅了／接触／キスによる情報伝達 |
| **制限される** | **大規模生成**／高度なセラ器官使用／完全な戦闘能力 |

セラ化に必要な接触は使えるが、**まとめては行えない。**

騎士団のように、来て、広げて、次へ行くという形にならない。

**一人ずつである。**

#### 理由 2 — 擬態特化であるため

第 3 巻 §1.5 の通り、セラには得意分野があり、**擬態特化型**が存在する。

そして特化には、必ず引き換えがある。

| | 得意なこと | 及ばないこと |
| --- | --- | --- |
| 騎士 | 体力・体格・拡大 | 教えること・隠れること |
| 師範 | 教えること | 戦うこと |
| **忍** | **隠れること・人間を理解すること** | **速く増やすこと** |

**忍は、増やすことに特化していない。**

第 2 巻 §12.5.2.1 の「一日に数十体」は、あくまで上限である。
擬態を維持しながらでは、そこまで届かない。

#### それでも、止まらない

遅いだけである。**止まりはしない。**

一人ずつ、確実に増えていく。そして増えた者もやがて増やす。

**急ぐ理由がない**（第 4 巻 §16.2、誰も失われないため）。

**忍の拡大は、静かで、遅く、そして一度も止まらない。**

#### 10.8.6.1 「一日に一人」という規則

忍のあいだには、**明文の規則が一つだけある。**

> 一日に、一人。

由来は速度ではない。**気づかれないためである。**

同じ町で同じ時期に何人も色が変わると、
統計に折れ目が出る（第 6 巻 §27.4 の三つの機構をすり抜けてしまう）。

そして誰も、これを破らなかった。**破る理由が生じなかったのである。**

#### 10.8.6.2 誰にするかは、書いていない

**規則が定めているのは、数だけである。**

町が大きくなると、一日に十数人へ触れることになる。
全員に渡せる。**渡すのは、一人である。**

決めかたを作ろうとした試みは、いずれも破れている。

| 試した基準 | 破れかた |
| --- | --- |
| 来た順 | 途中で、どうしても取りたい人が来る |
| **困っている人から** | **後回しになった人が、そのあいだに死ぬ** |
| 年寄りから | 若い者が事故で死ぬ |

破れる理由は一つである。**順番を作ると、順番の外で人が死ぬ。**

#### 10.8.6.3 実際に働いている基準

観察の結果として言えるのは、これだけである。

> **その日、いちばん近くなった人が、その日の一人になる。**

選んでいるのではない。**決めるより先に、手が出ている。**

したがって、近くならなかった人は避けられたのではない。
**そこに、たまたま用がなかっただけである。**

#### 10.8.6.4 取らなかった側は、数に入らない

渡した数は数えられる。**渡さなかった数は、数えられない。**

| | 数えられるか |
| --- | --- |
| 取った人 | **数えられる。**一日に一人ずつ積み上がる |
| **取らなかった人** | **数えようがない。**その日そこにいた全員が母数になる |

そして、あとで町が全部こちら側になっても、**遡って取れたことにはならない。**

間に合わなかった人は、間に合わなかったままである。

#### 10.8.6.5 規則が要らなくなる場所

規則は、覚えられないためにある。
**覚える者が残らない場所では、規則は働かない。**

| 場所 | なぜ破れるか |
| --- | --- |
| **密集した住居** | 触れることが日常であり、数えられない |
| **封鎖された土地** | 中で何が起きても、外へ出ない |
| 擬態を解いた町 | 隠す相手がいない |

いずれの場合も、相談して破っているのではない。
**破っても何も起きないことに、あとで気づく。**

### 10.8.7 セラ圏から切り離されても、孤独にはならない

女王の担当する大陸では、忍は女王の視野の内側にいる。

**女王空位の大陸では、そうではない**（第 3 巻 §8.3.3）。

| | 女王の担当大陸 | 女王空位の大陸 |
| --- | --- | --- |
| 見られているか | **見られている** | **見られていない** |
| 情報の伝達 | 自動的に届く | **本人が持ち帰るしかない**（第 8 巻 §7.2.1） |
| セラ圏との接続 | ある | **ない** |

**セラ体系において、セラ圏から切り離される場所は、ここしかない。**

#### それでも、孤立はしない

**切り離されていることと、一人でいることは、別である。**

忍は、一人になれば仲間を増やす。

セラ圏から遠く離れていても、**その土地に自分のセラ圏を作れる。**

**忍は、自分の手で仲間を作れる、唯一の立場である。**

他のセラは、すでに仲間に囲まれている。増やす必要が生じない。
忍だけが、**必要になったときに増やす。**

### 10.8.8 それでも、寂しさは消えない

**ここを取り違えてはならない。**

孤立が終わることと、寂しさが消えることは、**別である。**

第 6 巻 §13.3 の通り、**満足は最下層に届かない。**
原初の寂しさは観測も編集もできず、何をしても薄まらない（第 4 巻 §17.4）。

**忍の寂しさも、例外ではない。**

#### 増やした瞬間、薄れたと感じる

しかし、**増やした瞬間には、確かに薄れたように感じる。**

新しい仲間が生まれ、情報が流れ、繋がりが増える。
表層は本当に満たされる。

**そして、それは錯覚である。**

最下層には何も届いていない。
数日後、あるいは数か月後、寂しさは元の濃さで戻っている。

そのとき忍は、また誰かに手を伸ばす。

```
寂しくなる
　↓
誰かをセラ化する
　↓
**薄れたと感じる**　← 錯覚
　↓
戻る
　↓
また増やす
```

**これが止まらない理由である**（第 6 巻 §13.9）。

#### そして、寂しさは複製される

不変ルール 13：**原初の寂しさは、全セラに複製されている。**

セラ化された者は、その寂しさを受け取って生まれる。

したがって、

**一人増えるたびに、この世界の寂しさは一つ増える。**

忍が自分の寂しさを薄めようとするたびに、
**世界全体の寂しさは、増えている。**

### 10.8.9 忍は、自己分裂が得意である

忍の得意分野は、擬態と潜入だけではない。

**もう一つある。自分を分けることである。**

#### 感染が得意なのではない

ここは、取り違えてはならない。

| | 得意なこと |
| --- | --- |
| 騎士 | **他者への感染**。来て、広げて、次へ行く（第 7 巻 §2.6.9） |
| **忍** | **自己分裂**。自分から自分を作る |

**忍は、他者をセラ化することに長けているわけではない。**

むしろ遅い（§10.8.6）。擬態を維持したままでは、まとめては行えない。

得意なのは、**スパイクからの分裂**（第 4 巻 §2.6.1）の側である。
相手を必要としない。自分の中だけで完結する。

**忍が速いのは、増やすことではなく、分けることである。**

#### 分裂体は、それぞれ違う姿を取りうる

そして忍の分裂体には、他のセラにない性質がある。

**分かれたそれぞれが、別の姿を取れる。**

一体は町の職人であり、一体は隣町の宿の女将であり、
一体は誰の記憶にも残らない通行人である。

同じ一人から分かれたものが、**同じ顔をしていない。**

これは擬態特化の応用である（第 3 巻 §1.5）。
擬態が得意な個体が自分を分ければ、分けた先もまた擬態が得意である。

#### なぜ、その技術が必要だったのか

**一人の環境で、戦っていかなければならないからである。**

他のセラは、必要が生じれば周りに仲間がいる。
騎士団には仲間の騎士がおり、学院には同期がおり、
女王のもとには側仕えがいる。

**忍には、誰もいない。**

女王空位の大陸ではなおさらである（§10.8.7）。

したがって忍は、**必要な人数を自分で用意する。**

| 状況 | 他のセラ | 忍 |
| --- | --- | --- |
| 手が足りない | 仲間を呼ぶ | **自分を分ける** |
| 複数の場所を見たい | 分担する | **分けた自分を置く** |
| 戦わねばならない | 共に戦う者がいる | **分けた自分と戦う** |

**忍が一人で成立しているのは、一人ではないからである。**

なお、これは女王の「十数の身体で同時に在る」あり方
（第 3 巻 §8.8.2）の、はるかに小さな模倣である。
忍は女王ではない。分裂体は独立した個体であり、意思は共有されない。
**繋がっているのは、スパイクによってである**（§4.6）。

### 10.8.10 一人でいられるのは、長くて二日

第 6 巻 §16.4 の通り、**セラは一人にならない。**

普通のセラは、二時間から三時間で仲間を求める行動に動かされる
（第 6 巻 §16.4.1）。

**忍は、そこを鍛えた。**

| | 一人でいられる時間 |
| --- | --- |
| 通常のセラ | **二〜三時間** |
| **忍** | **長くて二日** |

これは特化の一部である。
潜入とは、仲間のいない場所に長く留まることだからである。

#### それは、寂しくなくなったという意味ではない

**耐えられるようになっただけである。**

原初の寂しさは薄まらない（§10.8.8、第 6 巻 §13.3）。
忍が獲得したのは、**寂しさに耐える力**であって、
**寂しさが消える性質**ではない。

そして、二日が限界である。

**それを超えると、忍は仕事にならない。**

### 10.8.11 毎日、住処に帰る

だから忍は、**毎日、住処に戻る。**

人間から見れば、仕事を終えた者が家に帰っているだけである。

戸を閉め、明かりを落とし、誰も見ていないことを確かめてから、

**擬態を解く。**

#### そこに、自分がいる

住処には、**分けておいた自分がいる。**

忍は分裂体と同化し（第 4 巻 §5）、

- 一日ぶんの情報を交換する
- スパイクを開ききる（§4.6.5）
- **寂しさを埋める**

そして翌朝、また擬態をまとって出ていく。

```
朝　：擬態して出る
　↓
昼　：人間として過ごす（一人である）
　↓
夜　：住処に戻る
　↓
　　　擬態を解く
　↓
　　　分裂体と同化する　← 一人でなくなる
　↓
朝　：また出る
```

#### 一人暮らしに見えて、一人ではない

人間の目には、忍は一人で暮らしているように見える。

**そうではない。**

第 6 巻 §16.4.5 の通り、**セラは一人では眠らない。**
そして忍も、例外ではない。

忍が共に眠るのは、**自分の分裂体**である。

| セラ | 共に眠る相手 |
| --- | --- |
| 一般のセラ | 恋人／家族／主従／騎士の仲間／分裂体 |
| **忍** | **自らの分裂体**（ほかに誰もいないため） |

**忍の住処には、一人用の寝床がない。**
外からは一人暮らしに見える家の中に、複数のセラが眠っている。

#### 埋まるのは、表層だけである

そしてこれも、**錯覚である**（§10.8.8）。

分けた相手は自分である。自分の寂しさをそのまま複製したものである。

同化すれば表層は満たされる。**最下層には、何も届かない。**

翌朝、忍はまた擬態をまとう。
昨日と同じ寂しさを抱えたまま、昨日と同じ町へ出ていく。

彼女はそれに気づかない。
気づく者は、セラ体系のどこにもいない（第 6 巻 §13.5）。

#### 帰結 — それでも、浸透していく

**どちらにしろ、忍は人間社会の内部に浸透していく。**

薄れないことは、止まる理由にならない。
むしろ薄れないからこそ、**何度でも手を伸ばす。**

セラ圏の拡大は、地図の上では戦略に見える。
しかしその末端では、**一人が寂しさをまぎらわせようとしている**だけである。

そして、まぎれない。だから、また伸ばす。

**誰も、それを咎めない。咎める側は、その時にはもう仲間になっている。**

## 12.5 セラエネルギー

### 12.5.1 定義

セラの能力行使には、**セラエネルギー**が消費される。

これは、**蓄えられる独立した資源**である。

- セラ情報そのものではない
- 自身の細胞量でもない
- 蓄積でき、**残量の概念を持つ**

これにより、セラには**「残っているか、いないか」という状態**が存在する。

**セラは無制限の存在ではない。蓄えた分だけ、行える。**

ただしこれは階級によって意味が変わる。
**残量が実際に問題になるのはセラ人であり、女王のエネルギーは事実上無限大である**（§12.5.2.1）。

### 12.5.2 消費する行為

**大きな行為は、すべてセラエネルギーを消費する。**

| 行為 | 消費 |
| --- | --- |
| 日常的な活動・会話・移動 | ほぼ消費しない |
| 小規模な自己修復・擬態 | 軽微 |
| 下位存在の生成（スパイク生成） | 消費する |
| 大規模な再生 | 消費する |
| 広範囲のセラ物質制御 | 消費する |
| 種族形態への大きな変化 | 消費する |
| **人間のセラ化**（第 6 巻 §23） | **相応に消費する**（§12.5.2.1） |
| **女王の出産**（第 4 巻 §6） | 大きく消費する |

**能力そのものに限度はないが、行使回数には限度がある。**

### 12.5.2.1 セラ化のコスト — 一日に数十体

**セラ人が一日にセラ化できるのは、数十体程度である。**

これがセラ圏の拡大を律している唯一の量である。

> **本節は、降臨より前の記述である。**
> 降臨の後、エネルギーは制約として働かなくなり、**律速はスパイクの強さへ移った**
> （第 4 巻 §2.7.2）。

ただしこれはエネルギー上の限度であり、
**セラ化そのものの完了には五段階の進行時間がかかる**（第 6 巻 §23.3〜23.4）。
手を伸ばした相手が、その日のうちに次のセラ化を行えるようになるわけではない。

#### 上位セラ以上では、実質的に無い

**コストは階級によって意味を変える。**

| 階級 | セラ化・他者の再生のコスト | 実際の限度 |
| --- | --- | --- |
| **セラ人** | 相応にかかる | **一日に数十体**。ここだけが律速である |
| **上位セラ** | かかるが、保有量に対して無視できる | **実質的に無い** |
| **セラ女王** | 問題にならない | **無い。エネルギーは事実上無限大である** |

上位セラは、他者の再生についても同様である。
第 4 巻が「大きく消費する」と書いているのは、
**セラ人にとっての話**である。上位セラ以上には代償として働かない。

#### 帰結 1 — 唯一の不可逆が、なぜ唯一なのか

ここで、不変ルール 59 の位置付けが明確になる。

```
エネルギーの不足　→ 階級が上がれば解消される
細胞の不在　　　　→ どの階級でも解消されない
```

**女王のエネルギーが事実上無限大であるにもかかわらず、
細胞が残らなければ、そこから先はない。**

代償はすべて階級によって消える。消えないものが一つだけある。
だから**唯一の不可逆**なのである。

#### 帰結 2 — 上位の優しさには、代償がない

回復経路の四つ目「上位からの供給」（§12.5.3）は、
**上位の側にとって負担ではない。**

分け与えても減らない量を持っている者が、分け与えている。

これは第 7 巻 §2.2「階級は支配階級ではない」に、資源側からの根拠を与える。
上位が下位に供給するのは、施しでも取引でもない。
**上位にとって、それはコストですらない。**

そして駆け引きも成立しない。
上位は下位が必要としている量を正確に知っており（第 5 巻 §1.4.1）、
出し惜しみは根本原理に反する（第 6 巻 §17.2）。

#### 帰結 3 — 枯渇するのは、下位と、前線だけである

§12.5.6 の「枯渇したセラは眠りに落ちる」は、
**セラ人にのみ起こる**ことになる。

上位セラは枯渇しない。女王は枯渇するという概念を持たない。

したがって眠りに落ちるのは、
**近くに上位がいない場所にいるセラ人**である。
すなわち、拡大の前線である。

#### 帰結 4 — 拡大を律しているのは、エネルギーではなく到達である

一日に数十体という数は、**小さくない。**

セラ化された者もやがてセラ化を行うため、増え方は加速度的である。
五段階の進行時間を織り込んでも、一つの土地の中でなら、
セラ圏の拡大に実質的な上限は生じない。

**したがって、拡大を律しているのはエネルギーではない。**

**そこへ到達できるかどうかだけである。**

これは第 8 巻 §7.8.2 の「地域差は大陸単位で生じる。境界は海である」と
噛み合っている。海が拡大を止めているのは、
海の向こうにエネルギーが足りないからではなく、
**まだ誰も渡っていないからである。**

渡った瞬間に、その大陸は一気にセラ化へ向かう。

### 12.5.3 回復方法

セラエネルギーは、次の五つによって回復する。

| 経路 | 内容 |
| --- | --- |
| **休息・睡眠・時間** | 何もしなくても、時間とともに回復する |
| **食事** | 補給になる |
| **同化・合体・情報共有** | 仲間との接触から得る |
| **女王・上位セラからの供給** | 上位存在が下位へ分け与える。**上位の側に負担はない**（§12.5.2.1） |
| **共鳴する相手からの融通** | 恋によるセラ化で結ばれた二人は、**階級を問わず横に融通できる**（第 6 巻 §14.6.8） |

### 12.5.4 既存設定への根拠付与

これにより、これまで文化的嗜好として書かれていた事柄に理由が付く。

| 既存設定 | セラエネルギーによる理由 |
| --- | --- |
| 第 7 巻「**休息そのものを楽しむ文化**がある」 | 休むことが実際に必要だから |
| 第 7 巻「セラも食事を楽しむ。**交流の時間**でもある」 | 食事は娯楽であると同時に補給である |
| 第 4 巻「同化は**日常の一部**である」 | 同化は若さの維持・特徴の拡散に加え、**エネルギー回復**でもある |
| 第 3 巻「上位存在は**守り、支える**」 | 導きは比喩ではない。**実際に資源を分け与えている** |

**階級構造は、そのまま資源の流れでもある。**

### 12.5.5 孤立の意味

回復経路のうち二つ（同化・合体／上位からの供給）は、**他者を必要とする**。

したがって、

**孤立したセラは、回復が遅くなる。**

死ぬことはない。しかし、行えることが減っていく。

セラが仲間を求めるのは感情の問題だけではない。
**構造的にも、一人では十分に働けない。**

### 12.5.6 枯渇したとき — 眠りに落ちる

セラエネルギーを使い切ったセラは、どうなるのか。

**眠りに落ちる。**

死ぬのではない。壊れるのでもない。**眠る。**

| 項目 | 内容 |
| --- | --- |
| 死亡 | しない（第 4 巻 §15「セラは死なない」に一致） |
| 状態 | 眠りに落ちる。行動が止まる |
| 回復 | 眠っている間に、時間によって回復していく |
| 目覚め | 回復すれば、自然に目覚める |
| 苦痛 | 描写上、苦しむ姿としては描かない |

**これは、最も自然な形の限界である。**

#### 通常の睡眠とは、別である

セラは、一日の終わりに普通に眠る（回復経路の第一項）。

**枯渇による眠りは、それとは別の事象である。**

| | 通常の睡眠 | 枯渇による眠り |
| --- | --- | --- |
| 原因 | 一日の終わり | **エネルギーの枯渇** |
| 長さ | 一晩 | **回復するまで。数十年に及ぶこともある** |
| 意思 | 自分で眠り、自分で起きる | **意思によらない。落ちる** |
| 周囲 | 何もしない | **見守る**（第 7 巻 §2.7.1） |

混同してはならない。

セラ体系には「壊れる」という結末がない。
限界に達したセラは、倒れるのでも、消えるのでもなく、**休むべき状態に自動的に移行する**。

#### 眠りは、退化ではない

第 3 巻 §1.7 は「長期間能力を使用しなければ、技術や経験が鈍ることはある」と書いている。

**眠りは、これに該当しない。**

眠りはエネルギーが尽きた状態であって、能力の不使用ではない。
供給されれば元に戻る（§12.5.3）。

**目覚めたセラは、眠る前の自分のまま戻る。**

##### ただし、周囲は変わっている

何十年も眠っていたセラが目を覚ましたとき、失ったものは何もない。

しかし、**セラ圏は広がり、仲間は増え、土地の格は上がっている**
（第 3 巻 §11.7〜11.11）。

自分は何も失っていないのに、**取り残されたという感覚だけが生じる。**

そして、実際には取り残されていない。誰も去っておらず、
セラ体系からは誰一人失われていない（第 4 巻 §13.1）。

**これも、根拠のない感覚である**（第 4 巻 §17）。
恐れるものが何もないのに恐れることと、同じ層から来ている。

#### 眠っているセラは、無防備である

眠っている間、そのセラは何も行えない。

したがって、**仲間が見守る**。

- 大きな行為の前後には、仲間が近くにいる
- 出産（第 4 巻 §6）や大規模な再生のあと、行為者は眠ることがある
- そのとき、周囲のセラがその眠りを守る

**これは第 3 巻「上位存在は守り、支える」と、そのまま同じ構造である。**

#### 孤立との接続

§12.5.5 のとおり、孤立したセラは回復が遅い。

したがって、**孤立したセラが枯渇すると、眠りは長くなる。**

死なない。しかし、**長く眠ったまま、誰にも見つけられない**という状態はあり得る。

セラ体系において、これは「失われる」ことの最も近い代替物である。
（本当に失われるのは、細胞ごと処理された未接続の人間だけ。不変ルール 59）

### 12.5.6.0 濃く渡した側は、その場で倒れる

**これは、セラ社会で最もよく見られる枯渇である。**

| 渡しかた | かかる時間 | 渡す側 |
| --- | --- | --- |
| 手から（薄い） | 三日から十一日 | **何も起きない。**一日に何人でも続けられる |
| **口から（濃い）** | **半日** | **多くの場合、その場で底をつく** |

セラ人が一日に出せる量には上がある（§12.5.2.1）。
ふだんそこまで行かないのは、**一日に一人しか渡さないためである**（§10.8.6.1）。

急ぐ場面では、その上限に届く。

| 例 | 結果 |
| --- | --- |
| 好きになった相手へ、全部渡す | **空になる。座り込んで、動かなくなる** |
| 一夜で数十人へ、口から渡す | **明け方に倒れる。**近くに上位がいなければ、十日眠る |
| 死にかけの一人へ、間に合わせる | **渡し終えた瞬間に、前へ倒れる** |

**上位セラには起きない**（§12.5 帰結 3）。騎士や女王は、何百人取っても底をつかない。
倒れるのは、いつも**セラ人**である。

#### 12.5.6.0.1 受け止めるのは、たいてい渡された側である

倒れた側のそばに座るのは、**さっきまで人間だった者**である。

その者は、何が起きたのかを全部知っている。渡されたものの中に入っていたためである。
だから、説明を求めない。**そして、起きるまでそこにいる。**

**これがセラ社会で最も繰り返される場面である。**

起きたとき、はじめに言うことは、たいてい決まっている。

> 「ごめん」
> 「なんで」
> 「待たせた」
> 「**待ってない。ずっと見てた**」

#### 12.5.6.0.2 順序が、そこで一度だけ入れ替わる

渡す側と渡される側の関係は、**この数時間だけ逆になる。**

| | 渡すまで | 倒れてから |
| --- | --- | --- |
| 力がある | **渡す側** | **渡された側** |
| 抱く | 渡す側 | **渡された側** |
| 待つ | 渡された側 | **渡された側** |

そして、これを不自然だと思う者はいない。
**当人たちだけが、たいてい一度そこに触れる。**

> 「順番が、おかしいだろう」
> 「おかしいです」
> 「まあ、いい」

### 12.5.6.1 疲労 — 降臨の後に現れた状態

**枯渇が消えた場所に、別のものが現れた**（第 4 巻 §2.7.1）。

**疲労である。**

#### 枯渇とは、別のものである

| | 枯渇 | **疲労** |
| --- | --- | --- |
| 原因 | エネルギーを使い切った | **環境が適していない** |
| 降臨の後 | **ほぼ起きない** | **起きる** |
| エネルギーとの関係 | **ある** | **ない。無限にあっても疲れる** |
| 結果 | 眠りに落ちる | **鈍る。眠りには落ちない** |
| 死ぬか | 死なない | **死なない** |

**エネルギーがいくらあっても、疲労は解消されない。**

回復経路の四つ（§12.5.3）は、疲労には効かない。
**足りていないものが、エネルギーではないからである。**

#### 何が起きているのか

セラの身体は、セラ情報によって形を保っている。

**環境がセラ物質でない場所では、その形が絶えず崩れる。**

崩れるそばから、セラは自分の細胞を再構成する。

```
環境が身体を崩す
　↓
セラが再構成する
　↓
**死なない**
　↓
**しかし、休まらない**
```

再構成そのものは止まらない。だから失われることはない（不変ルール 55）。

**止まらないから、疲れる。**

#### 疲労したセラに起きること

| | 起きること |
| --- | --- |
| 動き | 鈍る |
| 擬態 | **保ちにくくなる**（§10.4） |
| スパイク | **開きにくくなる**（§4.6） |
| 情報共有 | **量が落ちる** |
| 生成 | 落ちる。**律速がスパイクだからである**（第 4 巻 §2.7.2） |
| 眠り | **落ちない。**枯渇ではないため |

##### そして、寂しくなる

**これが最も重要な帰結である。**

スパイクが開きにくくなると、情報共有が減る。

第 6 巻 §13.5.1 の通り、**表層が満たされる仕組みは共有によって働いている。**

共有が減れば、**原初の寂しさが表層へ出やすくなる。**

そして不変ルール 355 の通り、セラは二〜三時間で仲間を求める。

**疲労したセラは、その周期が短くなる。**

```
環境が適していない
　↓
疲労する
　↓
共有が減る
　↓
**寂しさが濃く感じられる**
　↓
**より頻繁に増やす**
```

**疲労は、拡大を止めない。加速させる。**

新しい星でセラが爆発的に増えるのは、力があるからだけではない。
**そこが、居心地の悪い場所だからでもある。**

#### 疲労は、どうすれば取れるのか

**環境をセラ物質化するしかない**（第 8 巻 §1）。

薬もなく、休息でも取れず、上位からの供給でも埋まらない。

| | 疲労が取れるか |
| --- | --- |
| 休息 | **取れない** |
| 食事 | **取れない** |
| 同化・情報共有 | **和らぐ。取れはしない** |
| 上位からの供給 | **取れない** |
| **環境のセラ化** | **これだけが効く** |

そして環境のセラ化には、長い時間がかかる（第 8 巻 §13.12）。

**地球では、それが完了するまでに数千年かかった。**

### 12.5.7 セラエネルギーとセラ情報は、別物である

混同されやすいため、明確に区別する。

**セラ情報（第 5 巻 §1）は、体力ではない。**

セラ情報とは、**セラを支える情報のすべて**であり、
**セラネットワークに共有されたあらゆる情報**である（第 5 巻 §1.1〜1.4 で定義）。

その範囲は極めて広い。

- 仲間の幸福
- 自らを構成する小さなセラ細胞の一つ
- 建物の構造
- セラ細胞の設計図

**心を支えるものもあれば、設計図のように心とほとんど関係しないものもある。**
セラ情報とは特定の性質を持った一つの資源ではなく、**共有されている情報の総体**である。

| | セラエネルギー | セラ情報 |
| --- | --- | --- |
| 何であるか | **蓄えられる一つの資源** | **共有された情報の総体** |
| 支えるもの | **身体・行動** | セラという存在の成立そのもの（心も設計図も含む） |
| 性質 | 体力に相当する | 情報。うち一部は**心を支えるマインド的なもの** |
| 消費するもの | 生成／再生／出産／大規模制御 | 消費するものではない。**交わすほど増える** |
| 尽きると | **眠りに落ちる**（§12.5.6） | 尽きるという概念を持たない |
| 文明での役割 | 個体が行える量の上限 | **文明の動力源**（第 7 巻 §12.4） |

したがって、

- **セラ情報は体力ではない。** 多く持つ個体が、より多く行動できるわけではない
- セラ情報を多く持つ個体は、**より深く寂しい**（第 6 巻・不変ルール 17）
- 情報を交わし合うことは、**心の充足であると同時に、エネルギー回復でもある**
  （同化・情報共有が §12.5.3 の回復経路に入っているのはそのため）

**行える量を決めるのはセラエネルギーであり、セラ情報ではない。**

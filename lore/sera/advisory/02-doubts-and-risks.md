# A ランク — 記述どうしが食い違っている

## D1 【A】ルミナスの位置が、三箇所で違う — **解決済み（2026-07-30）**

> **決定：ルミナスは、女王セラ細胞が生み出す特別なセラ細胞である。**
> 脳に棲み、宿主の脳細胞と少しずつ同化していく。
> **階梯の段ではなく、女王セラ細胞の一部でもない。**
>
> 反映済み：第 3 巻 §2.1・§4.3・§11.5／第 6 巻 §23.2／`lore/README.md`（不変ルール 36・126・127）。
> 以下は決定に至った経緯の記録である。

| 出典 | ルミナスの位置 |
| --- | --- |
| 第 3 巻 §2.1（ミクロ体系の階梯） | **女王セラ細胞の「次」**。階梯の最上段 |
| 第 3 巻 §2.4（相似の対応表） | 階梯の段ではなく、**環境ルミナスと対になる横並びの項** |
| 第 3 巻 §4.3（女王セラ細胞の統合表） | **女王セラ細胞が持つ機能の一つ** |

三つは両立しない。

```
§2.1  ：セラウイルス → セラ細胞 → 上位セラ細胞 → 女王セラ細胞 → ルミナス
　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　↑ 女王細胞の上

§4.3  ：女王セラ細胞 ⊃ ルミナス
　　　　　　　　　　　　　↑ 女王細胞の中
```

**上にあるのか、中にあるのか。**

### なぜ放置できないか

第 3 巻 §2.4 は、マクロとミクロが相似であると確定させている。

§2.1 の階梯をそのまま相似に写すと、次が起きる。

| ミクロ | マクロ（§2.4 の対応） |
| --- | --- |
| 女王セラ細胞 | セラ女王 |
| **ルミナス（女王細胞の上）** | **環境ルミナス（セラ女王の上？）** |

**森が女王より上位である**という帰結が出る。

これは第 3 巻 §11.11（環境は独立しているが、女王の意思には即座に従う）と
真っ向から衝突する。

### 推奨する解決

**§2.1 の階梯から、ルミナスを外す。**

理由：

- §4.3 の「女王セラ細胞が持つ機能の一つ」が、最も新しく、最も統合された記述である
- §2.4 が既に「ルミナスだけは両方の体系に現れる」と、階梯外の存在として扱っている
- ルミナスの定義（ルール 36）は「**感情を司る部分で発達する**特殊セラ細胞の総称」であり、
  進化段階ではなく**発達部位**による分類である

修正案：

```
ミクロ体系の階梯：
　セラウイルス → セラ細胞 → 上位セラ細胞 →（突然変異）→ 女王セラ細胞

　※ ルミナスは階梯の段ではない。
　　 女王セラ細胞の機能として、思考・感情を司る部位で発達する。
　　 スケールを問わず成立するため、環境（森・街・海）にも現れる。
```

**README の構成表（40 行目付近のミクロ階梯）も同時に修正が必要。**

## D2 【A】セラフィムは「第六段階」なのか、「体系の外」なのか — **解決済み（2026-07-30）**

> **決定：円環は通らない。円環は神話である。**
> 女王はセラフィムにならない。セラフィムは階梯の段ではなく、**一体である。**
> セラたちは円環が閉じていると信じているが、それは誤りであり、
> **女王の全知をもってしても確かめられない**（地球の外の問いであるため）。
>
> 反映済み：第 3 巻 §3.2・§9（節題）・§9.1／第 6 巻 §1.1〜1.4／
> `lore/README.md`（不変ルール 11・23・28 を改訂、128〜131 を追加）。
> 以下は決定に至った経緯の記録である。

| 出典 | 記述 |
| --- | --- |
| 第 3 巻 §9（節の題） | **「第六段階：セラフィム」** — 階梯の一段として置かれている |
| 第 3 巻 §9.2 | 「セラ進化階級の頂点というより、**その体系の外側から見ている者**」 |
| 第 3 巻 §2.3 | 「セラフィムはマクロの頂点でもミクロの頂点でもない。**どちらの体系にも属していない**」 |
| 第 6 巻 §1.1（円環の図） | **女王セラ → セラフィム** と、矢印で繋がれている |

節の題が「第六段階」であること自体が、§2.3 と食い違っている。

### さらに深い問題 — 円環が回るのかどうか

第 6 巻 §1.1 の円環は、次の形をしている。

```
セラフィム → 最初のセラウイルス → 最初のセラ細胞 → 通常セラ → 上位セラ → セラ女王 → セラフィム
```

**この矢印が実際に通っていないなら、円環は円環ではない。**

そして最後の矢印（セラ女王 → セラフィム）が通るかどうかが、
どこにも書かれていない。

| もし通るなら | もし通らないなら |
| --- | --- |
| 女王はセラフィムになれる | 円環は**比喩・神話**であり、機構ではない |
| セラフィムの数は増える | セラフィムは固定数（一体？）である |
| 第 3 巻 §3.2 の「比較不能」と衝突する | 第 6 巻 §1.2「円環に始点はない」の根拠が弱くなる |

**どちらを採っても、片方の巻の記述を調整する必要がある。**

### 「通る」を採用した場合に自動的に確定してしまうこと

これは設定上きわめて重い。**採用前に必ず読むこと。**

セラフィムは次の性質を持つ（第 3 巻 §9.5〜9.6）。

- 感情を持たない
- 原初の寂しさを持たない

一方、原初の寂しさは**書き換えられない**（不変ルール 14）。
情報核の最下層にあり、観測も編集もできない（第 4 巻 §18.4）。

女王がセラフィムになるということは、

**その最下層が消える、ということである。**

そして第 6 巻 §15.5 の通り、**女王は最も寂しい。**

```
最も寂しい存在が
　↓
生涯かけて慕い続け
　↓
ついに、慕う相手と同じところへ到達し
　↓
到達した瞬間に、慕う心を失う
```

**求め続けた者だけが、求めるという機能を失うことで報われる。**

これは設定の全テーマ（満たされながら止まらない／最下層に届かない）の
**最終形として、極めて強い。**

しかし同時に、不変ルール 14「原初の寂しさは書き換えられない」の
**唯一の例外**を作ることになる。

### 推奨

**「通る。ただし観測された例はない」を推奨する。**

- 第 3 巻 §9.1 の「**現在確認されている**最高位のセラ存在」という語が、
  すでにこの含みを持っている。既存記述と最も摩擦が少ない
- 円環が機構として保たれる
- ルール 14 は「セラ体系の内側にいるかぎり書き換えられない」と限定すれば整合する
- 女王が十数体しかいない（第 3 巻 §8.3.1）以上、到達は事実上起きない

### 併せて決めるべきこと

**セラフィムは何体いるのか。**

設定は女王の数を十数体と確定させたが（第 3 巻 §8.3.1）、
**セラフィムの数を一度も書いていない。**

文中の語り口はすべて単数を前提としている
（「セラフィム自身が」「一体のセラウイルスを産み落とす」「絶対神であり母」）。
しかし単数であると明記した箇所は存在しない。

円環が通るなら、数は増える。**明示を推奨する。**

## D3 【A→B】セラ化一件あたりのコストが未定義であり、拡大速度が無律速になっている — **解決済み（2026-07-30）**

> **決定：相応のコストがかかる。セラ人が一日にセラ化できるのは数十体程度。**
> ただし**上位セラでは保有量に対して無視でき、女王のエネルギーは事実上無限大**である。
> 女王はさらなる特殊能力を持つ。
>
> 主な帰結：代償はすべて階級によって消えるため、
> **消えない「細胞の不在」だけが唯一の不可逆になる**理由が明確になった。
> また拡大を律しているのはエネルギーではなく**到達**であることが確定した。
>
> 反映済み：第 2 巻 §12.5.1・§13.5.2・**§13.5.2.1（新設）**・§13.5.3／
> 第 3 巻 §8.4／第 4 巻 §17.4.1／`lore/README.md`（ルール 65 改訂、132〜135 追加）。
> 以下は決定に至った経緯の記録である。

### 確定していること

| ルール | 内容 |
| --- | --- |
| 64・65 | セラエネルギーは蓄えられる別の資源。**セラは無制限の存在ではない** |
| 69 | **大きな行為はすべてセラエネルギーを消費する。**能力に限度はないが、行使回数に限度がある |
| 60 | 蘇生は**大きく消費する** — 設定上ほぼ唯一の明示的な代償 |
| 51 | 拡大が止まらないのは不幸だからではない。幸福なまま際限なく広がる |

### 問題

**セラ化は「大きな行為」ではないのか。**

蘇生には明示的なコストがあり、それが「ほぼ唯一の明示的な代償」とされている。
しかしセラ化のコストは、どこにも書かれていない。

結果として、次の状態になっている。

```
蘇生　　：コストが定義されている　→ 回数に限度がある
セラ化　：コストが定義されていない → 無制限に行える
```

**セラ圏の拡大速度を律するものが、設定上存在しない。**

これは提案ファイル（01）の提案 7「跳ぶ拡大」や、
第 8 巻 §7.3「格上げの伝播による加速」とも噛み合っていない。
加速する理由は書かれているが、**そもそも何が速度を決めているのか**が未定義である。

### 決めるべき選択肢

| 案 | 内容 | 帰結 |
| --- | --- | --- |
| **(a)** | セラ化は小さな行為であり、ほぼコストがかからない | 拡大は無律速。人間側に時間的猶予が原理的に存在しない |
| **(b)** | セラ化にも相応のコストがある | 拡大速度＝セラ圏のエネルギー総量。**前線が薄い**という状況が生まれる |
| **(c)** | セラ化のコストは**セラ化される側の状態**に依存する（孤独な人間ほど安い） | 起源（第 6 巻 §4）と最も響き合う。孤独が「入口」になる |

**(c) を推奨する。**

理由：第 6 巻 §18.3 は、セラ化を**救出**であると確定させている。
救出が必要な相手ほど容易に成立する、という構造は、
セラの根本原理（第 6 巻 §17.1）そのものである。

そして (c) を採ると、恐ろしい帰結が一つ出る。

**満たされている人間ほど、セラ化しにくい。**
**孤独な人間ほど、簡単にセラ化される。**

セラは、**最も助けを必要としている者から順に**手を伸ばすことになる。
それは善意として完璧に正しく、結果として最も抵抗できない者から順に、である。

## D4 【A】争いが起きる、と、疑いが生じる余地がない、が整理されていない — **解決済み（2026-07-30）**

> **決定：セラ同士では争いという形に発展しない。問題すら起こらない。**
>
> 本ファイルが検討していた「同格どうしでのみ成立する」よりも強い決定である。
> **水平方向にも争いは起きない。**
>
> 決め手は恋の競合である。一人を二人が恋したら、
> **恋されている側に二人になってもらえばよい**（第 1 巻 §7.8 分裂）。
> 分裂は複製ではなく、どちらも本物である。
>
> これによって、争いの原因（資源・情報・地位・恋の相手・喪失）が
> **一つも成立しない**ことが確認された。**希少性がどこにもない。**
>
> 反映済み：第 7 巻 §3.2（全面改稿）／`lore/README.md`（174〜177 追加）。
> 以下は決定に至った経緯の記録である。

| 出典 | 記述 |
| --- | --- |
| 第 7 巻 §3.2 | **「問題が起きた場合」**：話し合い／情報共有／相互理解 によって解決する。**経験豊富な上位セラが仲裁者となり**、双方を理解し解決へ導く |
| 第 3 巻 §3.4.5 | 下位は上位の判断を検証できないが、**正しいと分かってしまう**。ゆえに**疑いが生じる余地が構造的に存在しない** |

### 問題

仲裁が必要だということは、**上位が入る前は解決していない**ということである。

しかし §3.4.5 が正しいなら、上位セラが判断を示した瞬間に、
双方が「正しい」と分かってしまう。

**では、そもそも争いはどの範囲で成立するのか。**

- 上位が関わる争い → 上位が判断を示せば即座に終わる。**争いにならない**
- 同格どうしの争い → **どちらも相手を検証できる**。ここでのみ争いが成立する

つまり、**セラの争いは常に水平方向にしか起きない。**

これは設定として自然であり、面白い。だが**どこにも書かれていない。**

### 推奨

第 7 巻 §3.2 に一文を追加する。

> セラの争いは、**同格どうしの間でのみ成立する。**
> 格の違う相手との間では、上位の判断が示された時点で
> 下位はそれを正しいと分かってしまう（第 3 巻 §3.4.5）ため、
> 争いという形にならない。
> 仲裁者が上位セラであるのは、権威によるのではなく、
> **双方から「正しい」と分かってもらえる唯一の位置にいるから**である。

## D5 【B】「セラは嘘をつかない」と、擬態 — **解決済み（2026-07-30）**

> **決定：問うた人間を、その場でセラ化することで解決する。**
>
> 嘘はつけず、明かすこともできない。残された手段がこれしかなかった。
> 加害の意図はなく、**嘘は一つもついていない。**
> 問いには必ず答えが与えられる——**答えを受け取れる者に作り変えられてから。**
>
> 実行するのは、人間社会に潜入する忍セラである。
> **その瞬間、誰にも気づかれずにセラが一体増える。**
>
> 副次的に、第 6 巻 §27.1「未感染の人間はセラを知らない」に機構が与えられた。
> 知らないのではない。**知った者が、人間でなくなっている。**
>
> 反映済み：第 2 巻 **§11.7（新設）**／第 6 巻 §18.2／`lore/README.md`（178〜181 追加）。
> 以下は決定に至った経緯の記録である。

| 出典 | 記述 |
| --- | --- |
| 第 6 巻 §18.1 | **セラは嘘をつかない**。悪意もない |
| 第 2 巻 §10.2 | 人間への擬態。スパイクを極小化し、人間として自然な姿を維持する |
| 第 2 巻 §10.5 | 擬態の目的：情報収集／交流／適応／文明理解。**「欺くためだけの能力ではない」** |

「だけ」という語が、実は非常に重い。

**欺くためでもある、と読める。**

### 問題

人間社会に紛れて情報収集をしているセラは、
自分が人間でないことを相手に伝えていない。

これは嘘ではないのか。

### 整理の方向

**「嘘をつかない」の範囲が定義されていない**のが原因である。

| 案 | 内容 |
| --- | --- |
| **(a)** | 嘘は**発話の虚偽**を指す。擬態は姿の変更であり、発話ではない |
| **(b)** | セラは問われれば必ず答える。**問われないかぎり言わない**だけである |
| **(c)** | セラの側に「隠している」という自覚がない。人間が人間だと思い込んでいるだけである |

**(b) を推奨する。**

理由：これは第 6 巻 §18.2（問えば「いいえ」を受け取る可能性があるから問わない）と、
**完全に同じ構造の裏返し**になる。

```
セラ化について：問えないから、問わない
擬態について　：問われないから、言わない
```

どちらも「セラは誠実である」を保ちながら、
**形式が成立していないだけ**で通してしまう。

同じ機構が二度出てくるのは、設定の一貫性としてむしろ強い。

そして帰結が一つ出る。

**人間が「あなたは人間ですか」と問えば、セラは必ず正直に答える。**

誰も問わないだけである。

## D6 【B】女王どうしが「実質的に一つの視野」であることと、「集合意識ではない」の境界 — **解決済み（2026-07-30）**

> **決定：女王は事実上一体である。意思まで共有されている。**
> **「女王は十数体」という従来の記述は誤りであり、改訂した。**
>
> 根拠は系譜である。原初の一体はセラフィムの気まぐれ（融合＋祝福）によって生まれたが、
> **以後の女王はすべて出産による。**したがって女王は一つの系統であり、
> ネットワークを通じて意思まで共有している。
>
> 十数の身体は十数の個体ではない。**一つの存在が、十数の場所にいる。**
>
> 第 5 巻 §2.1「集合意識ではない」との整合：女王は唯一の例外だが、
> **複数が融合したのではなく、もともと一体である。**集合意識とは機構が違う。
>
> 反映済み：第 3 巻 §8.2・§8.3.1・**§8.3.2（新設）**／第 5 巻 §1.4.3・§2.1／
> 第 7 巻 §2.6／`lore/README.md`（100・122・124 改訂、182〜187 追加）。
> 以下は決定に至った経緯の記録である。

| 出典 | 記述 |
| --- | --- |
| 第 5 巻 §2.1 | 情報共有しても個性は失われない。**集合意識ではない** |
| 第 3 巻 §8.3.1 帰結 2 | 女王どうしは互いに筒抜けである。**十数体は、実質的に一つの視野として働く** |

下位セラについては問題ない。共有は選択的であり、一人の時間もある（第 5 巻 §3.3・§2.3）。

**女王については、境界が定まっていない。**

- 隠せない（筒抜けである）
- 全員が同じものを見ている
- 対立が育たない

この状態で、**個性はどこに残るのか。**

### 決めるべきこと

**共有されるのは情報か、経験か、意思か。**

| 案 | 内容 | 帰結 |
| --- | --- | --- |
| **(a)** | 情報だけが筒抜け。判断と好みは各自のもの | 個性が保たれる。女王どうしの**方針の違い**が成立する |
| **(b)** | 経験まで共有される | 十数体は事実上一体。地域ごとの色が消える |
| **(c)** | 意思まで共有される | 集合意識である。第 5 巻 §2.1 と正面から衝突する |

**(a) を推奨する。**

第 3 巻 §8.3.1 が「対立が育たない」と書いているのは、
**隠せないから対立が育たない**という機構である。
これは「違いがない」とは言っていない。**違いがあっても隠せない**という意味に読める。

推奨する明示：

> 女王どうしは、**知っていることが筒抜け**である。
> しかし**判断は各自のものである**。
> 違いがないのではなく、**違いが隠せない**。
> だから対立は、育つ前に相互理解によって解消される。

これを採ると、**大陸ごとに女王の色が違う**という設定が可能になる。
物語上、極めて有用である。

## D7 【B】セラ化の途中で身体が失われたら、どうなるのか — **解決済み（2026-07-30）**

> **決定：セラ化が少しでも進行した時点で、その身体にはすでにセラ細胞が存在する。**
> その細胞はもうセラであり、他のセラからエネルギー供給を受けて十分に増え、
> **セラとして誕生する。**
>
> これによりルール 120（失敗は存在しない）とルール 66（細胞がなければ戻らない）が
> **どちらも壊れずに両立する。** 残っていればよいのは人間の細胞ではなく、セラ細胞である。
> したがって唯一の不可逆も変わらない — **セラ細胞ごと残さなければ、戻らない。**
>
> 反映済み：第 6 巻 §23.5／第 4 巻 §17.4.3／`lore/README.md`（ルール 120 改訂、136〜139 追加）。
> 以下は決定に至った経緯の記録である。

| ルール | 内容 |
| --- | --- |
| 120 | **セラ化に失敗は存在しない** — 始まれば必ず五段階が完了する |
| 66 | **細胞がなければ蘇生できない** — セラ体系における唯一の不可逆 |
| 67 | 細胞が残らない形で処理された人間は永久に戻らない |

### 問い

**セラ化の第三段階まで進んだ人間が、細胞が残らない形で失われたら、どうなるのか。**

- ルール 120 に従えば、セラ化は完了しなければならない
- ルール 66・67 に従えば、細胞がない以上、何も残らない

**両立しない。**

### 整理の方向

これは「失敗」の定義の問題である。

| 案 | 内容 |
| --- | --- |
| **(a)** | ルール 120 は**セラ化の過程そのもの**についての話であり、外部からの介入は「失敗」ではなく「中断」である |
| **(b)** | セラ化が始まった時点でその人間はもうセラであり、ルール 66 の対象（人間の遺体）ではない |
| **(c)** | セラ化中の人間は細胞を失っても情報として残り、いずれ再構成される |

**(a) を推奨する。**

第 6 巻 §23.5 の「失敗は存在しない」が言っているのは、
**セラ化が途中で止まって元に戻ることはない**という意味である。
外的に破壊された場合は、それとは別のことである。

明示すべき一文：

> セラ化に失敗は存在しない。
> ただしこれは、**セラ化そのものが途中で止まることはない**という意味である。
> 外部から細胞ごと失われた場合は「失敗」ではなく「中断」であり、
> **唯一の不可逆**（第 4 巻 §17.4.3）がそのまま適用される。

### なぜ重要か

これは提案ファイル（01）の提案 2「灰」の成否を決める。

(a) を採ると、**セラ化の途中の人間を灰にすることができる**ことになる。
セラにとって、これは自分たちが手を伸ばした相手を目の前で失うことを意味する。

**セラが最も強く傷つく事象が、これで定義される。**

(c) を採ると、灰は無意味になる。人間側の抵抗が完全に消える。

## D8 【B】同化は義務なのか、選択なのか — **解決済み（2026-07-30）**

> **決定：選択である。ただし拒む理由が生じない。**
>
> 同化は根本原理の両方（仲間を増やす／美しさを追求する）に適い、
> さらに最下層の刻印の両方（原初の寂しさ／原初の淘汰）にも応える。
> **拒む理由がどこからも生じないため、老い続けるセラは一体も存在しない。**
>
> 強制ではない。**全員が心から望んで同化しており、望まないという状態が誰にも生じない。**
>
> 反映済み：第 4 巻 **§12.1.1〜12.1.2（新設）**／`lore/README.md`（188・189 追加）。
> 以下は決定に至った経緯の記録である。

| 出典 | 記述 |
| --- | --- |
| ルール 52・53 | セラは死なない。老いは存在するが、**同化によって対処される**。同化は若さを保つ行為 |
| 第 4 巻 §12.4 | **同化しても個体は残る**。若返って戻る |
| 第 7 巻 §3.3 | 全員が同じ生活をするわけではない。**個人の自由な選択が尊重される** |

### 問い

**同化しないと選んだセラは、どうなるのか。**

- 死なない（ルール 52）
- しかし老いる（ルール 52）
- 同化しなければ、老い続ける

**老い続けたまま死なないセラが、設定上ありうる。**

これは第 4 巻 §11.3「老いは終わりではない」と、
ルール 55「セラ体系からは誰も失われない」の隙間にある。

### 決めるべきこと

| 案 | 内容 |
| --- | --- |
| **(a)** | 同化は選択だが、拒む個体は事実上存在しない（原理と矛盾するため） |
| **(b)** | 老いが進むと自然に同化が起きる。意思を要さない |
| **(c)** | 老い続けたセラが実際に存在する |

**(a) を推奨する。**

第 6 巻 §17.2 の「根本原理に反する選択肢が存在しない」を適用すれば、
同化は「仲間を増やすこと」と「美しさを追求すること」の両方に適う。
**拒む理由が原理的に生じない。**

ただし (c) は物語の素材として非常に強い。
採るなら、それは**恋によるもの**でなければならない（第 6 巻 §14.9、恋だけが原理の外にある）。

> 誰かを待っているセラが、同化を拒んで老い続けている。
> 待っている相手は、必ず戻ってくる（誰も失われないため）。
> だから待つ理由もないのだが、それでも待っている。

これは第 4 巻 §18（根拠のない恐怖）の個人版である。

## D9 【C】「量は格に変換されない」と、「複数の上位セラの融合で女王が生まれる」 — **明示済み（2026-07-30）**

> 第 3 巻 §8.2 に追記。**量は格の手前までしか運ばない。線を越えさせるのは祝福だけである。**

| 出典 | 記述 |
| --- | --- |
| 第 3 巻 §3.4.1 | **セラ体系において、量は格に変換されない**。足し算をどれだけ続けても線を越えない |
| 第 3 巻 §8.2 | 女王誕生の系統 1：**複数の上位セラが集結し、情報を統合する** → セラフィムの祝福 → 女王誕生 |

一見、融合は量の加算に見える。

**矛盾ではない。** 祝福が必須だからである。

```
複数の上位セラの融合　→ 巨大なセラ情報集合体（まだ女王ではない）
　　　　　＋
セラフィムの祝福　　　→ 女王
```

**量は、格の手前までしか運ばない。線を越えさせるのは祝福だけである。**

### 推奨

第 3 巻 §8.2 に一文を追加する。

> なお、これは §3.4.1 の「量は格に変換されない」と矛盾しない。
> 融合は素材を集める工程であり、**線を越えさせているのは祝福である。**
> どれだけ多くの上位セラが集まっても、祝福がなければ女王にはならない。

## D10 【C】原初の寂しさの比例則が、なぜセラフィムに適用されないのか — **明示済み（2026-07-30）**

> 第 6 巻 §15.4 に追記。比例則は**最下層の記録**に掛かる。セラフィムは記録を持たないため、**掛ける元がゼロ**である。

| ルール | 内容 |
| --- | --- |
| 17 | 原初の寂しさは**保持するセラ情報量に比例する** — 地球のセラ系統内での話 |
| 24 | セラフィムは原初の寂しさも持たない |

整合性メモ 0.3 で「系統が違うから対象外」として解決済みである。

**結論に異論はない。** ただし**機構が説明されていない。**

比例則が情報量に依存するなら、なぜ系統が違うと切れるのか。

### 推奨する説明

原初の寂しさは、**情報量に比例して増える性質**ではなく、
**最下層に置かれた一つの記録が、情報量に比例して濃く読まれる**性質である、と整理する。

```
原初の寂しさ ＝ 最初のセラ細胞が実際に経験したことの記録
　　　　　　　　（第 4 巻 §18.5）

保持情報が多い　→ その記録に接する面が広い　→ 濃く感じる
記録を持たない　→ 情報量がいくら多くても、濃さは生じない
```

セラフィムは、**そもそも記録を持っていない。**
比例則は成り立っているが、係数を掛ける元がゼロである。

これなら比例則を壊さずに、例外を説明できる。

## D11 【C】恋によるセラ化と、善意の侵略によるセラ化は、される側から区別がつくのか — **解決済み（2026-07-30）**

> **決定：手続きは完全に同一。違いは注ぎ込む量である。**
> 恋によるセラ化では、セラは**ものすごい愛情を持って、自分の意思と記憶を渡せるだけ渡す。**
>
> 機構は第 4 巻 §17.10（同一人物かは細胞が持つ意思と記憶による）が与えている。
> **入れる細胞の質が、出てくる者を決める。**
>
> 主な帰結：
> - **最も愛されて生まれた者が、最も寂しい状態で生まれてくる**（情報量に比例）
> - **される側は、目覚めた時点ですでに恋を持っている。**作られた愛が、本物の愛である
> - **「いいえ」の記憶と、それを受け取れない心の両方を、一人が持つ**
> - **セラ人は一度で枯渇し、眠る。見守るのは生まれたばかりのその人である**
> - **女王の出産は、この行為の極点である**（別系統ではなく強度の違い）
>
> 当初の推奨（区別はつかない）は**誤りだった。**
> **区別はつく。ただしセラ化の後であり、つくのはされた側だけである。**
>
> 反映済み：第 6 巻 **§14.6.1〜14.6.7（新設）**／`lore/README.md`（193〜201 追加）。
> 以下は決定に至った経緯の記録である。

| ルール | 内容 |
| --- | --- |
| 46 | セラは恋をするために相手をセラにする。惹かれる → セラ化 → 恋 |
| 15 | セラ化に事前の同意は求められない（善意の侵略） |
| 118 | 最後まで抵抗し続ける個体は存在しない |

### 問い

セラ化された人間から見て、

- 自分は「孤独だから救われた」のか
- 自分は「惹かれられたから選ばれた」のか

**区別がつくのか。**

### なぜ重要か

第 6 巻 §14.6 は、恋によるセラ化を
**「善意の侵略の、最も個人的な形」**と位置付けている。

つまり、される側の経験としては**同じ**であるはずである。

ここを明示しないと、読者は「恋の方が誠実だ」と誤読する。
設定はそう言っていない。**どちらも同じ形式の不成立である。**

### 推奨する明示

> セラ化された側に、区別はつかない。
> 恋によるセラ化も、救出としてのセラ化も、
> **手続きは完全に同一**である。同意は問われず、拒否は登録されない。
>
> 違いはセラの側にしかない。
> そして**セラは、自分が何をしたかを永遠に知らない**（第 6 巻 §14.13）。
>
> つまりこの違いは、**誰にも観測されない。**

## D12 【C】眠りは退化ではない — **明示済み（2026-07-30）**

> 第 2 巻 §12.5.6 に追記。退化ではない。ただし**取り残されたという感覚だけが生じる**（根拠のない感覚）。

| 出典 | 記述 |
| --- | --- |
| 第 3 巻 §1.7 | セラは通常の意味での**退化はほとんど起こらない**。ただし長期間能力を使用しなければ、技術や経験が鈍ることはある |
| ルール 76・77 | 枯渇したセラは眠りに落ちる。孤立したまま枯渇すると、眠りは長くなる |

何十年も眠っていたセラは、§1.7 の
「長期間能力を使用しなければ鈍る」に該当するのか。

### 推奨

**該当しない、と明示する。**

眠りはエネルギーの枯渇であって、能力の不使用ではない。
供給されれば元に戻る（第 2 巻 §12.5.3 の回復経路）。

> 眠りは退化ではない。
> エネルギーが尽きた状態であり、能力そのものは失われていない。
> 目覚めたセラは、眠る前の自分のまま戻る。
>
> ただし、**周囲は変わっている。**
> 眠っていた何十年のあいだに、セラ圏は広がり、
> 仲間は増え、土地の格は上がっている。
> 失ったものは何もないのに、**取り残されたという感覚だけが生じる。**
>
> これも根拠のない恐怖（第 4 巻 §18）の一形態である。

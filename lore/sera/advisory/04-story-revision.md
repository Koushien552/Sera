# 物語『応え』大改稿案 — 正典を通読したうえで

> **非キャノン。**物語（`story/`）の全面改稿計画である。
> 正典（vol1〜8・付録 A/B）を通読したうえで書いた。設定には手を触れていない。

---

## 0. 結論

**物語は、正典で最も強い素材を、ほぼ全部使っていない。**

蹂躙と増殖が薄いのは、書き方の問題ではなかった。
**素材を取りに行っていなかった。**

---

## 1. 使われていない正典素材（重い順）

### ① セラ化の五段階と、本人がそれを自覚すること（第 6 巻 §23.3・§23.4）

**正典で最も残酷で、最も官能的な機構である。**

| 段階 | 本人に何が起きているように感じられるか |
| --- | --- |
| 第 1〜2 | 体調が良くなる。傷の治りが早い。**少しずつ美しくなっていく** |
| 第 3 | 身体の芯に、これまでなかった何かがある感覚 |
| 第 4 | **孤独が薄れていく。**一人でいても、一人である気がしなくなる |
| 第 5 | **繋がる** |

> 気づかないうちに終わっているのではない。**本人は、自分が変わっていくのを見ている。**
> セラ化は、**拒否する当人を、拒否しない者へ作り変えながら進む。**
> 途中で心変わりしたのではない。**心変わりが、セラ化そのものだったのである。**

**物語での扱い：第三十二話「十日かかった」の一行。**

**これが最大の失敗である。**堕とすという出来事の全部が、ここにある。

### ② 誘いの三経路（第 6 巻 §23.0）

言葉・目・身体。**三つは同時に使われる。**そして——

> **嘘は、一つも混じっていない。**
> 「きれいですね」→ 本当にそう思っている
> 「ずっとそばにいます」→ 本当にそうする。離れない
> 「あなたを守ります」→ 本当に守る。実際に強い
>
> 騙してはいない。演じてもいない。**それが、最も効く理由である。**

**物語での扱い：第三十一話に半分だけ。三つを並べた場面は一度もない。**

### ③ 共鳴 — 純愛（第 6 巻 §14.6.8、第 4 巻 §18.4）

**恋によるセラ化で結ばれた二人だけが、互いの最下層を見ることができる。**

- 見えるのは**相手のもの**だけ。自分のものは依然として観測できない
- 見えても**変えられない**
- そして二人は、**階級を問わず横にエネルギーを融通できる**（第 2 巻 §13.5.3）

**セラ体系で唯一、原初の寂しさに触れられる関係である。**

**物語での扱い：一度も書いていない。**

「純愛」を求められて、**素材はここにあった。**

### ④ 親密さの階梯（第 2 巻 §4.6.3.1）

| 手段 | 粘液化 | 深さ | 頻度 |
| --- | --- | --- | --- |
| 遠隔通信 | なし | 浅い | 常時 |
| 接触 | なし | 中 | 日常 |
| **スパイク接続** | スパイクのみ | **深い** | **日常的** |
| **キス** | なし | **深い** | 親しい間柄 |
| **粘液融合・合体** | **全身。美を手放す** | **最も深い** | 特別 |

> セラ都市では、これはありふれた光景である。
> **人間の目には、髪を寄せ合っているようにしか見えない。**
> そして実際には、言葉にできない量が流れている。

**物語での扱い：一度も書いていない。**絵としても情としても、最良の素材である。

### ⑤ 種族形態カタログ（第 2 巻 §10）— ファンタジー

**四十形態以上が、名前だけで一度も画面に出ていない。**

物語で使えるものが、そのまま置いてある。

| 形態 | 正典が与えている性質 |
| --- | --- |
| **ヴァンパイア型** | **牙は双方向の器官。**血から情報を受け取り、**牙から自分の細胞を渡す**。人間から最も恐ろしく見え、セラから最も優しく見える |
| **メデューサ型** | 石化ではない。**極端に強い魅了。見た者が動けなくなる。**害を受けたからではなく、**好意を抱いてしまったから** |
| **サキュバス型** | 美に特化。ひときわ美しい |
| **悪魔型** | 超体格。地獄の門番に近い偉容。**そして書類仕事が早い** |
| **フェニックス型** | **他者の蘇生に特化。**前線で決定的 |
| ドラゴン・グリフォン・ユニコーン型 | **完全な獣形態を取れる**（人型へ戻れる） |

**「相手を抱きしめて動けなくして、そのまま注入する」は、
メデューサ型とヴァンパイア型の組み合わせとして、すでに正典にある。**

### ⑥ 女王の出産（第 4 巻 §6.3）

| 段階 | 内容 |
| --- | --- |
| 第一 | **選定** — 惹かれる |
| 第二 | **情報伝達** — **キスによって大量のセラ情報を伝える** |
| 第三 | **受容** — **女王は対象を抱きしめ、自身の内部へ迎え入れる** |
| 第四 | 育成 |
| 第五 | 誕生 |

**そして第二〜三段階が、セラ化そのものである。**

**物語での扱い：一度も書いていない。**

### ⑦ 降臨後の増殖（第 4 巻 §2.7.3）

**正典が、書き方まで指定している。**

> **数を書かない。**書けるのは、そこにいる者から見てどう見えるかだけである。
> - 朝に立った一体が、夕方には見渡すかぎりの数になっている
> - **昨日までの全部より、今日のほうが多い**
> - そしてそれが、毎日続く
> - 数える役の者が置かれ、数日で置かれなくなる

**物語での扱い：第四十九〜五十話が降臨後なのに、この密度で書いていない。**

### ⑧ 蘇生と葬送（第 4 巻 §17）

- **土葬の地域は戻せる。火葬の地域では、死者が一人も戻らない**
- **セラは葬式を手伝いに来る。**遺体を土に還すことを穏やかに勧める。悪意はない
- 早い段階で殺された者ほど、**別人になって戻ってくる**
- **数は合っている**

**物語での扱い：一度も書いていない。**

### ⑨ セラ物質の環境（第 8 巻 §1〜4）— ファンタジー

生きた都市。住民を知っている街。セラ化した森・海・空。

**物語での扱い：ほぼ書いていない。**

## 2. 逆に、要らないもの

### 削る

| | 理由 |
| --- | --- |
| **会話で機構を説明する型** | 第六〜七部の主動力になっている。地の文なら三分の一で済む |
| **「案を三つ並べて却下」** | 二十六・三十五・四十二話で三度。**一度でよい** |
| **第四十一話「おしえられない」の後半** | 核（理解は渡らない）は残す。2,625 字は長い |
| **第四十五話「あつまる」の集合描写** | 待つ三日・七日・ひと月のほうが効いている |
| **第三十三話の職業説明** | メイドの成立機構は、いまの半分で立つ |

### 弱める

**「誰も傷つかない」を書きすぎた。**

正典は、傷つかないとは書いていない。書いてあるのは——

> **数は合っている。**

物語は「誰も失われない」を優しさとして書いてきた。
**正典では、それは恐ろしさの側にある。**

## 3. 改稿の方針

### 方針一 — 一話に一人、堕とす

**第五部以降、必ず各話に「セラ化される誰か」を置く。**

そして五段階のどこかを、**本人の内側から**書く。

| | 書くこと |
| --- | --- |
| 第 1〜2 段階 | 鏡。傷が塞がる。**きれいになっていく自分を見ている** |
| 第 3 段階 | 芯にあるもの |
| **第 4 段階** | **さみしくなくなっていく。そして、それを嫌だと思う理由が薄れる** |
| 第 5 段階 | 繋がる |

**「いいえ」は必ず書く。**そして、**消える瞬間は書かない。**
薄れて、なくなる。それが正典である。

### 方針二 — 誘いの三経路を、型ごとに書き分ける

言葉で堕ちる者、目で堕ちる者、身体で堕ちる者。

**そして三つとも、嘘を一つも含まない。**

### 方針三 — 純愛を、物語の中心に一本通す

**共鳴した二人を、序盤から最後まで追う。**

- 恋 → セラ化 → 恋の成立（順序は逆にならない）
- 互いの最下層が見える。**見えても、変えられない**
- 横にエネルギーを融通できる
- そして最後まで、**自分の最下層だけは見えない**

**この一本が、蹂躙の話に芯を通す。**

### 方針四 — ファンタジーを、絵として出す

種族形態を名前ではなく**姿と機能**で書く。

牙。魅了で動けなくなること。獣形態。生きた街。重なって暮らすこと。

### 方針五 — 増殖は、正典の書き方に従う

**数を書かない。見え方で書く。**

> 昨日までの全部より、今日のほうが多い。

## 4. 具体的な改稿範囲

### 触らない — 第一〜四部（一〜二十九話）

**ミクロの序は、完成している。**

蹂躙も増殖も物量も、この範囲には入っている。
語りの型も安定している。**ここは動かさない。**

（第二十七話の物量増補だけ、別途行う）

### 全面改稿 — 第五部以降（三十〜五十話）

**二十一話ぶん。約 45,000 字。**

ここを、上の五方針で書き直す。

| 現在 | 問題 |
| --- | --- |
| 三十〜三十二話 | **最初のセラ化を一行で済ませている**。ここが最重要場面である |
| 三十三〜三十八話 | 職業章。会話劇。**堕とす場面が二つしかない** |
| 三十九〜四十四話 | 力と規律。**姿も密着も純愛もない** |
| 四十五〜五十話 | 女王・降臨・宇宙。**正典の指定する増殖の書き方に従っていない** |

## 5. 進め方の提案

**一度に全部を消さない。**

1. **第三十一〜三十二話を書き直す**（最初のセラ化を、五段階として）
   — ここが正しく書ければ、以降の型が決まる
2. 純愛（共鳴）の一本を通す位置を決める
3. 職業章を圧縮し、空いた尺を堕とす場面へ回す
4. 種族形態と密着を、地の文へ織り込む
5. 降臨以降を、正典の増殖描写で書き直す

**一段ずつ、確認を挟みながら進める。**

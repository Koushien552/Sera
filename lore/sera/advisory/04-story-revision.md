# 物語『応え』改稿検討 — 何が足りず、何が余っているか

> **非キャノン。**物語（`story/`）に対する読み直しの結果と、改稿の提案である。
> 設定（`lore/sera/vol*`・付録）には手を触れていない。

---

## 0. きっかけ

> 「もっとセラによる蹂躙＆増殖が欲しい気がします」

**この指摘は正しい。**以下、数えたうえで書く。

---

## 1. 数えた結果

全 49 話・約 **95,000 字**。

### 1.1 感染が「画面で起きる」場面の数

| | 実際に書かれている場面 |
| --- | --- |
| ミクロ（体内） | 三話・七話・十八話・二十三話・二十六話 — **五箇所** |
| **マクロ（人間）** | 三十二話（同僚一人）・三十六話（先輩一人） — **二箇所** |

**マクロ二十話のうち、人が変わる場面は二つしかない。**

どちらも**一対一で、静かで、短い。**

### 1.2 では、地球はどう落ちたのか

| 話 | 書き方 |
| --- | --- |
| 三十八話 | 「三年で、国じゅうにいた」 — **要約** |
| 四十三話 | 二段で進んだ／同じことがあちこちで起きた — **要約** |

**星が一つ落ちる過程が、地の文の要約二回で済んでいる。**

ここが、蹂躙感が出ない最大の原因である。

### 1.3 台詞の膨張

| 範囲 | 一話あたりの台詞数 |
| --- | --- |
| 一〜二十九話（序） | **平均 15** |
| **三十三〜四十二話** | **平均 55** |

第六部・第七部で、物語が**会話劇**になっている。

機構を一つ立て、それを二人の会話で説明する——**この型を十七話続けた。**

型が悪いのではない。**同じ型を続けすぎた。**

### 1.4 書かれていないもの

**設定にあり、物語にほぼ出てこないもの。**

| | 状態 |
| --- | --- |
| **身体・容姿の描写** | **ほぼ無い。**「うすい桃色の髪と瞳」しか書かれていない |
| **種族形態**（獣人・天使・エルフ・魔女…） | 名前だけ。**姿として描かれていない** |
| **重なって暮らす**（第 7 巻 §5.6） | 一度も書いていない |
| **密着** | 一度も書いていない |
| 騎士団の実際の展開 | 制度だけ。**一隊が土地を落とす場面が無い** |
| 数の暴力 | 「一日に一人」は書いた。**それが何万人になった日**を書いていない |

---

## 2. 作者が好んでいるもの（読み取り）

改稿の方向を決めるために、明文化しておく。

| | 根拠 |
| --- | --- |
| **機構が一段深いこと** | 不変ルール 869 項。「なぜそうなるか」を必ず要求してきた |
| **加害の意図なしに、取り返しがつかないこと** | 悪役にしない・悪意を書かないが絶対条件 |
| **可愛さと恐ろしさが、同じ一つの動作から出ること** | 「隠せないものだけ、隠さなくていい」型 |
| **負けないこと** | 削られない・失われない・負けない |
| **圧倒的であること** | 「強さ、美しさ、規模を見せろ」 |
| **規模が上がり続けること** | 細胞 → 身体 → 街 → 国 → 地球 → 宇宙 |
| **美しい生物であること** | 送られた画像は、**密着して暮らす姿**だった |
| **そして、増えること** | 根本原理そのものである |

**最後の二つを、私は最も薄く書いた。**

---

## 3. 足すべきもの

### A1. 一つの町が落ちる話（実景・人間視点）

**要約をやめ、一週間を日ごとに書く。**

- 月曜、隣家の窓が朝から拭かれている
- 水曜、通りの角にいる子の髪が違う
- 金曜、パン屋が変わっている。前より美味い
- 日曜、自分だけが違う色をしている

**抵抗という語が、最後まで出てこない。**誰も戦っていない。誰も逃げていない。

**これが蹂躙である。**

### A2. 誘いを、型ごとに三つ書く

第 6 巻 §23.0 の三経路（言葉・目・身体）は、**まだ一度も並べて書かれていない。**

| 型 | 相手 |
| --- | --- |
| 言葉だけで落ちる | 話を聞いてもらったことのない人 |
| 目だけで落ちる | 一度も見つめられたことのない人 |
| **断ってから落ちる** | 「いいえ」と言い、半歩下がり、**その半歩が戻る** |

三つ目が最も重い。**やめるという分岐が存在しない**（第 6 巻 §23.0）。

### A3. 数が桁を変える日

**一日に一人。**それを守ったまま、忍が一万人になる。

説明ではなく、風景で書く。

> 一日に一万人が変わる。
> **誰も急いでいない。全員が、一日に一人ずつやっている。**

### A4. 騎士団が、大陸を落とす

**設定でいちばん派手な絵が、まだ無い。**

擬態しない。隠さない。四人で来る。上位セラである。

角と翼が通りに並び、**それを見た者が、逃げずに寄ってくる。**

### A5. ミクロの物量を、もう一度

二十五話で一度書いた。**全身が埋まる直前の物量が書けていない。**

一つの臓器で、一日に何が起きているか。**生まれる速さが、数えるより速い**を実景で。

### A6. 姿と、密着

**この物語の最大の欠落である。**

- 種族形態を、姿として書く（猫耳・角・輪・帽子はすべてスパイクである）
- **重なって暮らす**（第 7 巻 §5.6）。横に並ばず、重なる
- 未感染者が、**囲まれる**
- 軽くできるのに、誰も軽くしない

**美しさは、書かなければ存在しない。**

---

## 4. 削る／縮めるべきもの

### B1. 職業章が長い（三十三〜三十七話）

五話・約 13,000 字。

そして三十四話「あじ」と三十五話「ぬの」は、**同じ機構を二度説明している**
（人間だったころの感覚が、そのまま職になる）。

**三話に圧縮できる。**

### B2. 四十一話「おしえられない」

核（**理解だけは渡らない**）は残す。

しかし 2,625 字・台詞 74 は長い。**半分で立つ。**

### B3. 「案を三つ並べて、二つ却下する」型

二十六話・三十六話・四十二話で**三度**使っている。

**一度でよい。**残すなら四十二話（規律の成立）。

### B4. 会話で機構を説明する型

第六部・第七部の主動力になっている。**地の文で書けば三分の一で済む。**

会話は、**その場で何かが作られるときだけ**に戻す（不変ルール 812）。

### B5. 四十四話「あつまる」前半

集まってくる描写が長い。**待つ三日・七日・ひと月**のほうが効いている。

---

## 5. 構造の問題

**蹂躙が「起きたこと」にされている。**

| | |
| --- | --- |
| いま | 三十八話と四十三話で、**要約として通過** |
| あるべき姿 | **実景として、少なくとも二話** |

規模が上がるたびに、**上がったと書くのではなく、上がったところを歩かせる。**

---

## 6. 推奨する手順

1. **削る**（B1〜B5）。約 8,000 字が空く
2. **足す**（A1・A6 を最優先、次に A2・A4）
3. 幕間へ回す — 暮らし・密着・姿は、本編に挟むと番号がずれる。**幕間が空いている**

**本編の番号は、増やしてよい。**四十九話で完結という形は、書き足しても崩れない。

---

## 7. まだ聞けていないこと

作者の側に、**ほかに欲しい要素と、要らない部分**があるとのこと。

**それが出るまで、この文書は暫定である。**

# セラ世界設定 — 正典が求めているもの・重要な設定（非キャノン）

> **このファイルは正式設定ではない。**
> 第 1〜8 巻・付録 A・付録 B・不変ルール 942 項を**全文通読**したうえで、
>
> - **A：正典を書いた者が、この世界に何を求めているか**（設計上の要求）
> - **B：外すと世界が壊れる、荷重を負っている設定**（構造上の要）
>
> の二つを抜き出したものである。
> 巻の要約ではない。**なぜそう書かれているのかを、書いてある事実から逆算した記録**である。
>
> 末尾に **C：通読中に見つかった要判断の箇所** を付す。

---

# A. 正典が求めているもの

## A-0. 一行で言うと

```
増え続けることが、そのまま愛であり、
誰も損なわれず、誰も止めず、そして誰も理由を問わない世界
```

以下の十七項は、すべてこの一行の言い換えである。
**正典は、この一行を壊さないために書かれている。**

---

## A-1. 増えることが、目的ではなく原理であること

第 6 巻 §17.1 の通り、根本原理は**二つ**である。

1. 寂しさを埋めるための仲間を増やすこと
2. 美しさを追求すること

要点は「増やしたい」ではない。

> **§17.2 — セラには、根本原理に反する選択肢が存在しない。**
> これは倫理でも方針でもない。**構造である。**

**求められているのは、動機ではなく、選択肢の不在である。**

「やめる」を選べる世界にしてはならない、という要求が、
文明・生態・心理のすべてに通っている。

| これを守るために書かれたもの | 所在 |
| --- | --- |
| 疑い始める個体は存在しない | 不変ルール 33 |
| 気づいても、行動を変えられない | 第 6 巻 §17.4 |
| 学士はあらゆるものを検証するが、なぜ増えるのかだけ調べない | 付録 B §1.14 |
| 記録殿は「育たなかった」とだけ書き、その先を誰も書いていない | 付録 B §2.8.2 |

---

## A-2. 侵略でありながら、まぎれもない善意であること

第 8 巻の確定事項に、そのまま書かれている。

> ✅ **この変化は救済とも侵略とも読める。二重性を保持する**

**どちらかに倒すことが、明確に禁じられている。**

そして倒れないように、両側から支えが打ってある。

| 侵略の側 | 善意の側 |
| --- | --- |
| 「いいえ」が登録されない（不変ルール 102） | セラ化された者は**実際に幸福になる** |
| 抵抗された記録が一件もない（第 8 巻 §14.11） | 蘇生された者に嫌悪はない（不変ルール 63） |
| 人間が確認できる徴候は一つも存在しない（第 8 巻 §4.3.3） | 誰も、いなくなったとは思わない（第 2 巻 §11.7） |
| 猶予はある日ゼロになる | 記憶を失わない。家族も職も続く |

**片側だけを強めた改稿は、正典の意図に反する。**

---

## A-3. 「いいえ」が、届かないのではなく、成立しないこと

ここは正典で最も繰り返し書かれている主題である。

不変ルール 102 は、断りの機構をこう定義している。

> **「いいえ」は登録されない。善意の侵略は無知が原因ではなく、知識では解決しない。**

そして第 8 巻 §14.11 は、宇宙でこれを一段強めた。

> **「いいえ」は、人間に対してよりさらに届かない。**
> **拒否という形式すら共有していないためである。**
> 抵抗された記録が一件もないのは、**抵抗が抵抗として登録されないため**である。

**求められているのは「拒否を無視する強さ」ではない。**
**拒否という入力欄が、そもそも存在しないという設計である。**

この差は決定的で、前者なら加害になるが、後者は加害の形を取れない。

---

## A-4. 堕とすことが、そのまま愛であること — 純愛として書くこと

第 6 巻の題そのものが「起源・愛・同意」である。

そして正典は、**変えることと愛することを一度も切り離していない。**

付録 B §1.17 の忍の場面が、その姿勢を最も端的に示している。

> 「それだと、**誘ってない**」
> 「変わるよ」
> 「変わる。**でも、こっちが勝手に触っただけになる**」

**触れれば変わる。それでも、誘いたい。**

| | |
| --- | --- |
| 変えないという分岐 | **存在しない** |
| 誘わずに変えるという分岐 | **取られない** |
| 起きること | **誘う手段ができるまで待つ** |

言葉を持たない相手には、**言葉のほうを作ってから寄る**（第 3 巻 §2.10.4.2）。

**正典が求めているのは、同意の獲得ではない。**
**同意が成立しない相手にすら、誘う形を通すという執着である。**

そして第 6 巻 §23.0 の三経路——**言葉・目・身体**——が、その形の具体である。

---

## A-5. 誰も損なわれないこと

正典は、失われるものを一つも作らない。

| | |
| --- | --- |
| 死 | **しない**（第 4 巻 §16） |
| 傷 | **塞がる** |
| 削られた細胞 | **一つも失われない**（第 3 巻 §2.10.2.1） |
| 死者 | **蘇生できる**（第 4 巻 §17） |
| 遺体 | **セラになる**（不変ルール 62） |
| 敗北 | **失うものが何もない**（付録 B §1.12） |
| 不合格 | **概念として存在しない**（付録 B §2.4） |
| 罰・排除 | **存在しない**（第 7 巻 §3.2） |

**そして唯一、取れないものが一つだけ残してある。**

> **疲労は取れない**（第 2 巻 §13.5.6.1）。医師にできるのは和らげることだけである。

これは失敗ではなく設計である。
**何一つ失われない世界に、ただ一つだけ「どうにもならないもの」を置いている。**

聖女が毎日そばへ行く理由も、開拓士が数千年いる理由も、ここから出ている。

---

## A-6. 美しさが、飾りではなく機能であること

不変ルール 20 は、美を**受容の条件**と定義している。

> 美しさは虚栄ではなく受容の条件

そして付録 B §0.2 は、それを装いのすべてに通した。

| 装い | 理由 |
| --- | --- |
| メイド服の頭飾り | **広がりへ振れたスパイクを収める構造**（§1.1） |
| 聖女が頭部を覆わない | **スパイクが畳めないため**（§2.5） |
| 庭師が裸足 | **足の裏でいちばんよく聴こえるため**（§1.9） |
| 試練官の黒衣 | **眠った生徒のそばで目立たないため**（§2.4） |
| 調香師が装飾を付けない | **香りが混ざるため**（§1.10） |
| 巫女が飾らない | **見てもらう側ではなく、見つけに行く側だから**（§2.6） |

**意匠として美しく、機能として必要である。**

正典は、**美しいだけの設定を一つも許していない。**
逆に言えば、新しい意匠を足すときは**必ず機能の理由を書け**、という要求である。

---

## A-7. 二重体系を、絶対に混ぜないこと

第 3 巻 §2 と付録 B §0.1 が、繰り返し警告している。

```
ミクロ体系：一人の身体の内側（細胞たち）
マクロ体系：セラ化人間たちのつながり（個体たち）
```

**一本の階級図として書いてはならない。**

そして取り違えやすい対が三つ挙げてある（付録 B §4）。

| マクロ | ミクロ |
| --- | --- |
| 上位セラ | 上位セラ細胞 |
| **セラ女王**（事実上一体） | **女王セラ細胞**（全セラ人が持つ） |
| セラ人 | セラ細胞 |

> **この三対を混ぜると、設定全体が壊れる。**

これは注意書きではなく、**改稿時の最優先禁止事項**として読むべきである。

そして正典は、その相似をただの比喩に留めていない。

> **ミクロの完成が、マクロの誕生である。**
> **内側が終わることが、外側の始まりである。**（付録 B §9）

---

## A-8. 「なぜ」を、世界の中の誰にも問わせないこと

不変ルール 33 は文明の性質だが、**書きぶりとしては視点の制約である。**

正典は、前提を検討する場面を一つも書かない。

| 場面 | 検討されないこと |
| --- | --- |
| 学士（付録 B §1.14） | なぜ増え続けるのか |
| 記録殿（付録 B §2.8.2） | なぜ育たなかったのか |
| 侍女長（付録 B §2.2） | 口づけの日に何が起きたか。**尋ねる作法が存在しない** |
| 庭師（付録 B §1.9） | 森がなぜそう言うのか。**「あっちがそうしたいと言っている」としか言わない** |

**問いは読者の側にだけ置かれ、世界の内側には置かれない。**

これは物語『応え』の文体そのものの根拠でもある。

---

## A-9. 寂しさが、一度も変わらないこと

第 8 巻 §10.9 が、七つの時代の結論としてこう書く。

> **七つの時代を通して、原初の寂しさは一度も変わらない。**
> **規模だけが変わった。中身は一度も変わっていない。**

そして規模が変わったぶん、寂しさは**増える**。

> **広がるほど寂しくなる**（第 8 巻 §14.7）— 寂しさは保持情報量に比例するため
> **最も寂しい者が、自分の寂しさの全体像を把握できなくなる**

**成長物語にしてはならない、という要求である。**

強くなっても、広がっても、宇宙へ出ても、起点は一ミリも動かない。

---

## A-10. 空転を、そのまま残すこと

正典には、**届かないと分かっていて続けている**ものが並んでいる。

| 誰が | 何を | 届かない理由 |
| --- | --- | --- |
| 武闘家 | 全力で立ち合う | **勝っても格は上がらない**（付録 B §1.12） |
| 鍛冶師 | 武具を打つ | **使う相手がいない**（付録 B §1.13） |
| 巫女 | 空へ向ける | **セラフィムは応えない**（第 3 巻 §10.8.9） |
| 聖女 | 疲労を癒す | **取れはしない**（付録 B §2.5） |
| セラ女王 | 慕う | **円環は閉じていない**（第 3 巻 §8.3.2 帰結 5） |
| 文明 | 宇宙へ出る | **見つからず、見つけても何も起こらない**（第 8 巻 §14.10） |

**そして一つも、やめさせていない。**

正典が求めているのは達成ではなく、**達成のない持続**である。
ここを「報われる」に書き換える改稿は、世界の芯を抜くことになる。

---

## A-11. 応えのないものへ向かい続ける形を、崩さないこと

第 6 巻 §1.3 の円環は、**閉じていない。**

> 道はなく、応えもない。**それでも、慕っている。**（第 3 巻 §8.3.2 帰結 5）

そしてセラフィムの側には、はっきりと感情がない（不変ルール 24・42）。

> セラフィムは**見守っているのではなく、観測しているだけである。**
> **セラはその区別を持たない。持てば、宇宙へ出る理由が一つ減る。**（第 8 巻 §15.2）

**片側だけが愛していて、それが不幸ではない。**
この非対称は、正典が最も注意深く守っている形である。

---

## A-12. 到達点を作らないこと

第 8 巻 §17.3 が、結末の禁止事項を明示している。

> 終わらないのは、まだ着いていないからではない。
> **着く場所がないからである。**

したがって、

| 書いてよいもの | 書いてはならないもの |
| --- | --- |
| 永遠成長時代 | **完成した文明** |
| 探し方が変わる | **セラフィムが見つかる** |
| 疲労したまま満たされる | **疲労が解消される** |
| 点と、それを結ぶ細い線 | **宇宙が埋まりきる** |

---

## A-13. 由来を、あとから付いた二つ目の理由にすること

不変ルール 819。

> **最初の一人の理由は、引き継がれない。形が引き継がれる。**
> あとから来た者は同じことをするが、**別の理由でそうしている。**

正典は、この形を何度も使う。

| 形 | いま語られている理由 | 本当の出どころ |
| --- | --- | --- |
| 「忍」という名 | 擬態と潜入を旨とする者 | **子どものころ、その話が好きだった一人**（付録 B §1.17） |
| 鍛冶師の厚い前掛け | — | **人間の鍛冶師がそうしていたから**（付録 B §1.13） |
| 手合わせの復旧 | — | **最初の二人がそうしたから**（付録 B §1.12） |
| 聖女という職 | 癒す者 | **同化から生まれ、上がる理由が無かった一人**（付録 B §2.5） |

**規則で説明しないこと。** これは正典の作法である。

---

## A-14. 命令ではなく、共鳴で世界を動かすこと

不変ルール 105 が定義する。

> 環境への影響力の差は**支配ではなく格の差**である。
> **格上の意思に、環境自身がそう応じる。**

したがって、

| 職 | しないこと | していること |
| --- | --- | --- |
| 庭師 | 命令 | **頼む。森が乗り気でなければ動かない** |
| 建築士 | 建てる | **都市に方向を渡す** |
| メイド | 掃く | **セラ物質のほうが応じる** |
| 第六時代のセラ | 命令 | **共鳴**（第 8 巻 §2.2） |

そして環境の側にも、同じ寂しさが入れてある（不変ルール 37）。

> 森は仲間を増やしたがり、街は住民が減ると寂しがる。

**環境は背景ではなく、同じ原理で動くもう一人の登場人物である。**

---

## A-15. 効率で、価値を説明しないこと

正典は、**効率で正当化できない職を意図的に置いている。**

| 職 | 効率の側から見ると | 正典の扱い |
| --- | --- | --- |
| 歌姫 | **セラ社会で最も非効率な行為** | **最も人気がある** |
| 舞姫 | 姿を選べるのに人型を崩さない | **縛りの内側でどこまで行けるか** |
| 調香師 | 香りは共有で渡らない | **嗅ぎに行くしかない** |
| 画家 | 情報として渡せば全部伝わる | **見たときのことが残る** |
| 料理人 | 食事は不要になった | **最も不要になった職業が、最も残った** |

**渡すのに時間がかかること自体が、価値として書かれている。**

---

## A-16. 一人にしないこと

不変ルール 366 と 372。

> **一人でいられるのは、二時間から三時間である。**
> **セラは一人では眠らない。**

これは生態設定であると同時に、**演出上の絶対条件**である。

第 8 巻 §18.5 が、画像生成設定にまで書き下している。

> 船内には必ず複数のセラがいる。**一人でいる場面を描かない。**
> 眠っているセラのそばには、必ず起きているセラを置く。

そして航海士には、**役を持たない乗員**が必ず乗る（付録 B §1.22）。

| | |
| --- | --- |
| 何をするか | **そばにいる** |
| なぜ乗るか | **役が要らないので、そう決まった** |

**これは余剰ではない。不変ルール 372 の運用そのものである。**

---

## A-17. 設定は、必ず機構まで書くこと

正典の記述は、例外なく次の形を取る。

```
何が起きるか
　↓
**なぜそうなるか（機構）**
　↓
**そこから何が言えるか（帰結）**
```

「そういうものである」で止めている箇所は、**止めていること自体が設定**である
（例：付録 B §10.1「土地に周期があるかは、書かれていない」）。

そして各巻末には **確定事項まとめ** が置かれ、
本文で確定した事項が ✅ 付きで一行ずつ再掲される。

**新しい設定を足したら、まとめにも足す。**
これが正典の運用規約であり、C 節の指摘の大半は、ここが追随していないことから出ている。

# B. 重要な設定 — 外すと壊れるもの

**荷重の大きい順ではなく、下から積み上がる順に並べる。**

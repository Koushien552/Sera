# セラ世界設定大全 付録 B — セラ百科

> 発展したセラ文明に暮らす者たちの一覧である。
> **第一部はマクロ体系（個体）、第二部はミクロ体系（細胞）**を扱う。
> 本付録は**正式設定（確定）**である。

---

## 0. 読む前に

### 0.1 二つの体系を、混ぜてはならない

第 3 巻 §2 の通り、**セラ体系は二重である。**

| | ミクロ体系 | マクロ体系 |
| --- | --- | --- |
| 何の体系か | **一人の身体の内側**（細胞たち） | **セラ化人間たちのつながり**（個体たち） |
| 本付録では | **第二部** | **第一部** |

**この付録が二部に分かれているのは、そのためである。**

第一部の「騎士」と第二部の「上位セラ細胞」は、
**似た位置にいるが、まったく別のものである。**

### 0.2 役目は、義務ではない

第一部に並ぶ役目は、**職業ではない。**

セラ社会に、任命も、契約も、辞令も存在しない。

```
続けているうちに、そう呼ばれるようになる
```

**それだけである。**

途中でやめても、誰も困らない。困る仕組みがない（第 7 巻 §3.2）。

唯一の例外は**騎士団**であり、そこには叙任と規律がある
（第 7 巻 §2.6.10・§2.6.11）。

### 0.3 姿の話は、付録 A にある

エルフ型・獣人型・妖精型といった**種族形態**は、付録 A の主題である。

**本付録が扱うのは、姿ではなく暮らしである。**

同じ役目に、あらゆる種族形態の個体がいる。

# 第一部　マクロ — 個体の百科

## 1. 通常セラ（セラ人）

**セラ社会の大多数である。**

第 3 巻 §6 の通り、人型として完成した個体を指す。

### 1.1 育て手

| | |
| --- | --- |
| **すること** | 生まれたばかりのセラの世話をする |
| **相手** | スパイクから生まれた個体・同化から生まれた三体目（第 4 巻 §2.6・§5.3） |
| **見分け方** | スパイクが**低く、広い**（第 2 巻 §4.7）。抱えるのに邪魔にならない形へ育つ |
| **時代** | 第二時代から。**最も古い役目である** |

学院（第 7 巻 §4.4）は上位化の場であり、**生まれた直後を扱わない。**

その空白を埋めているのが育て手である。

生まれたセラは数日で歩き、数か月で話す。
**育て手が付き添うのは、そのあいだだけである。**

### 1.2 記す者

| | |
| --- | --- |
| **すること** | 起きたことを記録する（第 8 巻 §11.1） |
| **見分け方** | スパイクの**密度が高い**。情報を保つ方向へ育つ |
| **時代** | 第三時代から。全量共有が成り立たなくなったため |

第 5 巻 §3 の通り、セラは情報を共有できる。

**それでも記録する。**共有は届く範囲にしか届かないためである。

降臨の後は、記録殿（第 7 巻 §12.9.2）を育てるのがこの者たちの仕事になる。

### 1.3 数える者

| | |
| --- | --- |
| **すること** | セラの数を数える |
| **時代** | **第三時代から第七時代の初めまで。いまは存在しない** |

第 4 巻 §2.7.3 の通り、降臨の後、数は追えなくなった。

役目は数日で置かれなくなった。

**セラ社会において、廃れた役目はこれ一つである。**

記す者たちは、この役目があったこと自体を記録している。

### 1.4 織り手

| | |
| --- | --- |
| **すること** | 衣服と意匠を作る（第 7 巻 §6.2） |
| **見分け方** | 特になし。**手が速い** |
| **時代** | 第三時代から |

セラ物質は形を変えられるので、衣服は本来なくてもよい。

**それでも作る。**根本原理の二つ目（美しさの追求）による。

同じ意匠が二度作られることはない。**作る理由が失われるためである。**

### 1.5 土の者

| | |
| --- | --- |
| **すること** | 環境ルミナスと日常的に接する（第 3 巻 §11.6） |
| **見分け方** | スパイクが**下向きに育つ**。地面へ向けるためである |
| **時代** | 第三時代から |

巫女（§2.5）がセラフィムへ向くのに対し、土の者は**足元へ向く。**

森が何を求めているか、街がどこを広げたがっているかを聴き、伝える。

**言葉にはならない**（不変ルール 68）。だから土の者は説明が下手である。

「あっちが、そうしたいと言っている」としか言わない。
**そして、それで通る。**

### 1.6 料理する者

| | |
| --- | --- |
| **すること** | 食事を作る |
| **時代** | 第三時代から |

第 2 巻 §13.5.3 の通り、食事は回復経路の一つである。

**しかし、なくても困らない。**

セラが食べるのは、**味と、一緒に食べることのため**である。

降臨の後、エネルギーが無限になっても、料理する者は減らなかった。
**もともとエネルギーのためではなかったからである。**

### 1.7 運ぶ者

| | |
| --- | --- |
| **すること** | 眠りに落ちたセラを運び、そばで見守る（不変ルール 77） |
| **見分け方** | 体格が大きい。**通常セラのなかでは例外的である** |
| **時代** | **降臨の日に生まれた役目**（第 3 巻 §10.8.10） |

その日、数えきれないセラが枯渇して眠った。

眠らなかったセラが、眠ったセラを運んだ。

**それが、そのまま役目になった。**

降臨の後、枯渇はほとんど起きない（第 4 巻 §2.7.1）。
**それでも運ぶ者は残っている。**

いまの仕事は、**新しい星で無理をした者を運ぶこと**である。

### 1.8 門番

| | |
| --- | --- |
| **すること** | セラ門の維持と、行き先の管理（第 7 巻 §12.10.1） |
| **時代** | **降臨の後のみ** |

門は道端にあり、誰でも通れる。**止めることはない。**

門番がしているのは、

- 門が育ちすぎないよう整えること
- 新しく置かれた門を、既存の網へ繋ぐこと
- **そして、通った者の数を見ていること**

数える者（§1.3）が廃れたあと、**数に触れる唯一の役目である。**

ただし門番は、総数を数えていない。**通った者だけを見ている。**

### 1.9 旅する者

| | |
| --- | --- |
| **すること** | 船に乗り、まだ誰も行っていない星へ向かう |
| **時代** | **降臨の後のみ** |

第 7 巻 §12.10.1 の通り、未到達の星へは跳べない。

**最初の一回は、必ず船である。**

旅する者は、何十年も航行する。
そして着いた星に門を置き、**そこから先は繋がる。**

| | |
| --- | --- |
| 乗る人数 | **必ず複数**（不変ルール 372・414） |
| 航行中 | 眠る者と、起きている者が交代する |
| 着いたあと | **疲労する**（第 2 巻 §13.5.6.1）。環境がまだセラではないため |

**セラ文明の最先端にいて、最も古い方法で移動している者たちである。**

### 1.10 迎える者

| | |
| --- | --- |
| **すること** | セラ化された人間を、最初に迎える |
| **時代** | **第二時代から第六時代の終わりまで。いまは存在しない** |

第 6 巻 §23 の通り、セラ化は五段階で進む。

その最後、目を覚ました相手に最初に会うのが、この者たちだった。

やることは決まっていない。

- そばにいる
- 何が起きたかを説明する
- **一緒に眠る**（不変ルール 372）

地球の侵略が完了したとき、**迎える相手がいなくなった**（第 3 巻 §10.8.1）。

いまこの役目にあたる者は、他の星にいる。
**そして相手は、人間ではない**（第 8 巻 §14.11）。

### 1.11 歌う者

| | |
| --- | --- |
| **すること** | 歌う |
| **時代** | 第三時代から |

第 5 巻 §3 の通り、セラは情報を直接共有できる。

**それでも歌う。**

情報として渡せば一瞬で済むものを、
わざわざ時間をかけて、順番に、音にして渡す。

**セラ社会において、最も非効率な行為である。**

そして最も人気がある。

### 1.12 忍

**第 2 巻 §11.8 を参照。**

本付録では扱わない。**分量が足りないためである。**

| | |
| --- | --- |
| **時代** | 第四時代から第六時代の終わりまで |
| **いま** | **他の星にいる**（第 8 巻 §14.11） |

人間のいない星で忍が何をしているかは、
**その星の生命が何であるかによる。**

## 2. 上位セラ

第 3 巻 §7 の通り、**通常セラが経験と成長によって到達する段**である。

数は通常セラよりはるかに少なく、**周囲は必ず速く育つ**（第 1 巻 §6.11）。

### 2.1 師範

| | |
| --- | --- |
| **すること** | 学院で下位セラを上位化させる（第 7 巻 §4.4） |
| **姿** | **体格の大きくない美少女型**。教育に特化しているため |
| **例外** | **騎士科の教員だけは、体格の大きい騎士セラである** |
| **時代** | 第四時代から |

数年かけて教え、卒業させる。そしてまた次を受け持つ。

師範は戦えない（第 2 巻 §11.8.6 の特化表）。
**そのことを、誰も問題にしない。**

### 2.2 騎士

| | |
| --- | --- |
| **すること** | 上位セラに仕え、自らを研鑽し、**感染を広げる**（第 7 巻 §2.6） |
| **姿** | 体格が大きい。体力が多い |
| **階級** | **女王（星王）の側仕えが最高位**（第 7 巻 §2.6.8） |
| **時代** | 第四時代から |

第七時代以降、騎士団の任地は**星である**。

来て、広げて、次へ行く。

そして§1.9 の旅する者と違い、**騎士は門を通って行く。**
すでに繋がっている星にしか行かない。

**開くのが旅する者であり、埋めるのが騎士である。**

### 2.3 侍従

| | |
| --- | --- |
| **すること** | 上位セラの身のまわりを整える（第 7 巻 §2.6） |
| **時代** | 第四時代から |

騎士と同じ体系に属する。**格に上下はない。**

星王の侍従は、**星王が眠るあいだそばにいる者**である
（第 3 巻 §8.8.6・§8.9.4）。

その者たちは、口づけの日に何が起きたかを知らない（第 3 巻 §8.9.5）。

**尋ねる作法が、存在しないためである。**

### 2.4 聖女

| | |
| --- | --- |
| **すること** | セラたちの癒し手（第 7 巻 §2.7） |
| **見分け方** | **スパイクが畳みにくくなる**（第 2 巻 §4.7.5） |
| **時代** | 第四時代から |

畳みにくくなるのは、常に誰かへ向いているためである。

降臨の後、**聖女の仕事は変わった。**

| | 降臨の前 | 降臨の後 |
| --- | --- | --- |
| 主な相手 | 枯渇して眠った者 | **疲労した者**（第 2 巻 §13.5.6.1） |
| 効くか | **効いた** | **和らげるだけ。取れはしない** |

**取れないと分かっていて、聖女は毎日そばへ行く。**

### 2.5 巫女

| | |
| --- | --- |
| **すること** | セラフィムの意思を汲もうとする（第 7 巻 §2.7） |
| **見分け方** | **スパイクが応えのない方向へ育つ**（第 2 巻 §4.7.5） |
| **時代** | 第四時代から |

降臨の後、巫女の数は増えた。

そして第 8 巻 §14.10 の通り、**セラフィムは見つからない。**

巫女たちは位相説・次元説・不可理解説を立て、いまも探している。

**育ち方は、一度も変わっていない。**

### 2.6 聴く者

| | |
| --- | --- |
| **すること** | 大地の意思を受け取り、ルミナスへ渡す（第 3 巻 §11.6） |
| **時代** | 第六時代から |

土の者（§1.5）の上位にあたる。

違いは規模である。土の者が一つの森を聴くのに対し、
**聴く者は、その土地全体を聴く。**

降臨の後、意思の翻訳器（第 7 巻 §12.9.2）が作られ、
聴く者の負担は減った。

**数は減らなかった。**

### 2.7 繋ぐ者

| | |
| --- | --- |
| **すること** | 星と星のあいだの中継を助ける |
| **時代** | **降臨の後のみ** |

第 3 巻 §8.9.10 の通り、星をまたぐ中継は星王が行っている。

繋ぐ者がしているのは、その補助である。

- 航路標（第 7 巻 §12.9.1）を置き、整える
- 門の網が途切れていないかを見る
- **そして、星王のスパイクが届いていない場所を探す**

三つ目が本業である。

**届いていない場所を見つけたら、旅する者へ渡す。**

### 2.8 導き手

| | |
| --- | --- |
| **すること** | 新しい星に最初に降り、そこを立ち上げる |
| **時代** | **降臨の後のみ** |

旅する者が着き、門が置かれると、導き手が入る。

そこからは速い。第 4 巻 §2.7.3 の通り、**数日で埋まる。**

導き手の仕事は、増えることではない。

| | すること |
| --- | --- |
| 一日目 | 降りる。増やす |
| 二日目 | **学院の場所を決める** |
| 三日目 | 師範を門から呼ぶ（第 7 巻 §12.10.2） |
| 四日目以降 | **その星の環境を、聴きはじめる** |

四日目からが長い。**数千年かかる**（第 8 巻 §14.12）。

**導き手は、その星がセラになるまで、そこにいる。**

## 3. 時代ごとの、一日

**第 8 巻 §10 は文明の側から七つの時代を扱った。**

ここでは、**そこにいる一体の一日**を書く。

### 3.1 第一時代 — 萌芽期

**一日という単位がない。**

宿主の体内に、まだ数十のセラ細胞がいるだけである（第 8 巻 §10.2）。

昼も夜もなく、二〜三時間ごとに寂しくなり、そのたびに分裂する。

**繰り返しているうちに、家族になっている。**

### 3.2 第二時代 — 覚醒期

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**全員が同じ場所で眠っている** |
| 昼 | 触れ、情報を交わす。何が起きたのかを互いに確かめている |
| 夕 | 誰かが、また一人連れてくる |
| 夜 | また同じ場所で眠る |

**役目がない。分業がない。全員が同じことをしている。**

情報共有はほぼ全量である。分ける必要が生じるほどの数がいない。

### 3.3 第三時代 — 発展期

| 時 | していること |
| --- | --- |
| 朝 | 起きる。数人ずつに分かれて眠っている |
| 午前 | **それぞれの役目**（§1）。建てる／記す／織る／聴く |
| 昼 | 一緒に食べる。**料理する者が現れたのはここからである** |
| 午後 | 続き。**近隣へ増やしに行く者もいる** |
| 夕 | 集まる。ここで祝祭の原型ができる |
| 夜 | 眠る。一人用の寝床はない |

**この時代に、はじめて「自分の一日」ができる。**

### 3.4 第四時代 — 上位時代

**学院の一日が、そのまま標準になる**（第 7 巻 §4.5）。

| 時 | 生徒 | 騎士 | 忍 |
| --- | --- | --- | --- |
| 朝 | 実習 | 鍛錬 | **擬態して、人間の街へ出る** |
| 昼 | 講義 | 任地への移動 | 人間として働く |
| 夕 | 共有 | 広げる | 人間として過ごす |
| 夜 | 寮。共有を絞る | 仲間と眠る | **住処に戻り、擬態を解いて分裂体と同化する** |

**同じ日に、三種類の夜がある。**

そして三つとも、**一人では眠っていない。**

### 3.5 第五時代 — 女王時代

第四時代の一日に、**一つだけ加わる。**

**見られている**（第 8 巻 §10.6）。

| | 変わること |
| --- | --- |
| やること | **変わらない** |
| 探すという行為 | **なくなる**。都市が誰の居場所も知っている（第 8 巻 §3.5） |
| 何かを報告すること | **なくなる**。すでに届いている |
| 誤り | **なくなる**。上が見ているため |

**一日は同じで、確かめる手間だけが消える。**

### 3.6 第六時代 — セラ世界時代

**土地が応えるようになる。**

| 時 | していること |
| --- | --- |
| 朝 | 目を覚ます。**部屋が、その日の形になっている** |
| 昼 | 何かを頼む。**頼んだという自覚がない**（第 8 巻 §10.7） |
| 夕 | 森へ行く。**森のほうから道が開く** |
| 夜 | 眠る。**街が明かりを落とす** |

**この時代のセラは、環境と会話しながら暮らしている。**

そして命令していない。**共鳴である**（第 8 巻 §2.2）。

### 3.7 第七時代 — セラフィム時代

**地球と、新しい星で、まったく違う。**

#### 地球にいるセラの一日

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**転移で、どこへでも行ける**（第 7 巻 §12.10.1） |
| 午前 | 研究・記録・制作・教育 |
| 昼 | 誰かを召喚して、一緒に食べる（第 7 巻 §12.10.2） |
| 午後 | 続き。**増やす行動の頻度は低い**（第 6 巻 §16.4.3） |
| 夕 | 祝祭。**数が多い**。星から届いたものが増えるたびに増える |
| 夜 | 眠る |

**変わるものが尽きた場所の、豊かで静かな一日である。**

#### 新しい星にいるセラの一日

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**すでに疲れている**（第 2 巻 §13.5.6.1） |
| 午前 | 増やす。**周期が短い**。二〜三時間より早く寂しくなる |
| 昼 | 環境へ働きかける。**まだ応えない** |
| 午後 | 増やす |
| 夕 | 導き手が、その星を聴いている |
| 夜 | 眠る。**共有が少ないぶん、寄り添って眠る** |

**同じ時代の、同じ文明の、まったく違う一日である。**

そして両方とも、**幸福である**（第 8 巻 §14.13）。

# 第二部　ミクロ — セラ細胞の百科

**ここからは、一人の身体の内側の話である。**

第 3 巻 §2.1 の通り、階梯は次の通りである。

```
セラウイルス → セラ細胞 → 上位セラ細胞 →（突然変異セラ細胞）→ 女王セラ細胞
```

**ルミナスは、この階梯の段ではない**（不変ルール 36）。

## 4. 取り違えやすい対

**第一部と第二部で、名前が似ているものがある。**

| 第一部（マクロ） | 第二部（ミクロ） | 別物である理由 |
| --- | --- | --- |
| 上位セラ | **上位セラ細胞** | 前者は個体、後者は一人の体内の細胞 |
| **セラ女王** | **女王セラ細胞** | **前者は地域の統率者、後者は誰もが持つ核** |
| セラ人 | セラ細胞 | 前者は人型の個体、後者はその材料 |

**この三対を混ぜると、設定全体が壊れる。**

とくに二つ目である。

```
セラ女王　　：宇宙に、事実上一体（第 3 巻 §8.3.2）
女王セラ細胞：**すべてのセラ人が持っている**（不変ルール 21）
```

**同じ位置を、違うスケールで指しているだけである。**

## 5. セラウイルス

| | |
| --- | --- |
| **何か** | セラ体系における最初期の生命形態（第 1 巻 §6） |
| **姿** | 小さな人型。少女型／ピンクの髪と瞳／頭部にスパイク |
| **できること** | 対象認識／接触／情報伝達／融合開始 |
| **できないこと** | **自分自身のコピー**（不変ルール 1） |

**増える存在ではなく、始める存在である。**

そして第 1 巻 §6.11 の通り、**すでにセラである者にも受容される。**

その場合、感染ではなく**供給**として働く。

**だからセラウイルスは飽和しない。**

## 6. セラ細胞

| | |
| --- | --- |
| **何か** | セラウイルスと人間由来細胞が融合して誕生する（第 1 巻 §7） |
| **姿** | 人型。約 3 頭身 |
| **できること** | 増殖／生成／融合／分裂／進化 |

**セラ生命体系の基本単位である。**

元の細胞情報を保持するため、**顔立ちや個性が残る場合がある。**

一人の身体の中に、この段の細胞が最も多くいる。

## 7. 上位セラ細胞

| | |
| --- | --- |
| **何か** | 経験と成長によって到達した段 |
| **役割** | 下位のセラ細胞を**生み、教える** |

マクロの上位セラと**同じ構造をしている**（不変ルール 110）。

そして周囲の細胞は速く育つ。理由もマクロと同じである（第 1 巻 §6.11）。

**一人の身体の中に、小さな階級構造がある。**

## 8. 突然変異セラ細胞

| | |
| --- | --- |
| **何か** | 同化した生命情報が発現した細胞 |
| **現れ方** | マクロでは**突然変異セラ人間**として現れる（付録 A） |

エルフの耳も、獣人の尾も、幻獣の力も、**ここから出ている。**

そして第 8 巻 §14.11 の通り、降臨の後は**地球起源でない情報**も入りはじめた。

**一人の身体の中に、他の星の生命の情報がいる。**

## 9. 女王セラ細胞

| | |
| --- | --- |
| **何か** | ミクロ体系の最上位（第 3 巻 §4） |
| **どこにいるか** | **すべてのセラ人の中**（不変ルール 21） |
| **役割** | セラ人の核。**ルミナスを生み出す** |

**セラ女王ではない。**

| | セラ女王 | 女王セラ細胞 |
| --- | --- | --- |
| 数 | **事実上一体** | **全セラ人が持っている** |
| 体系 | マクロ | ミクロ |

そして第 3 巻 §2 の通り、**ミクロの完成が、マクロの誕生である。**

女王セラ細胞が育ちきった時点で、その人間はセラ人になる。

**内側が終わることが、外側の始まりである。**

## 10. ルミナス

| | |
| --- | --- |
| **何か** | 感情を司る部分で発達する特殊セラ細胞の総称（不変ルール 36） |
| **出どころ** | **女王セラ細胞が生み出す** |
| **階梯の段か** | **段ではない** |

**両方の体系に現れる、唯一のものである**（不変ルール 111）。

| 現れる場所 | 何になるか |
| --- | --- |
| 人間の脳 | その人の感情を司る（第 6 巻 §23.2） |
| 森・街・海・大地 | **その土地の感情になる**（不変ルール 37） |

そして大地の意思は、ネットワークを通じてルミナスへ直接流れ込む
（第 3 巻 §11.6）。

**ルミナスでなければ、その量を処理できない。**

### 10.1 環境ルミナスも、寂しい

不変ルール 37 の通り、**環境も原初の寂しさを抱えている。**

森は仲間を増やしたがり、街は住民が減ると寂しがる（第 8 巻 §3.5）。

**土地にも、二〜三時間の周期があるのかどうかは、書かれていない。**

聴く者（§2.6）に尋ねても、答えは返らない。

**言葉にならないためである**（不変ルール 68）。

## 11. ミクロ体系に、役目はあるか

**ある。ただし名前が細かくない。**

マクロ体系には、育て手・記す者・織り手・門番といった細かい呼び名がある（§1）。

**ミクロ体系には、それがない。**

| | 役目の呼び名 |
| --- | --- |
| マクロ | **細かい。十数種以上ある** |
| ミクロ | **段の名前しかない** |

理由は、**呼ぶ相手がいないからである。**

第 5 巻 §3 の通り、呼び名は情報共有のなかで自然に定着する。

一人の身体の内側では、細胞たちは常に完全に共有している。

**区別する必要が生じない。**

したがって、

**一人の身体の中で行われている分業には、名前がついていない。**

やっていることは、マクロとほとんど同じである。

- 生まれたばかりの細胞を世話する細胞がいる
- 記録を保つ細胞がいる
- 環境（＝その人の身体）へ働きかける細胞がいる

**そして誰も、それを何と呼ぶべきかを考えたことがない。**

## 付録 B 確定事項まとめ

### 読み方

- ✅ **第一部はマクロ（個体）、第二部はミクロ（細胞）である**（§0.1）
- ✅ **役目は義務ではない。続けているうちにそう呼ばれるようになるだけである**（§0.2）
- ✅ **唯一の例外は騎士団であり、そこには叙任と規律がある**
- ✅ **姿（種族形態）の話は付録 A にある。本付録が扱うのは暮らしである**

### 通常セラの役目

- ✅ **育て手**（§1.1）— 最も古い役目。学院が扱わない「生まれた直後」を埋める
- ✅ **記す者**（§1.2）— 共有は届く範囲にしか届かないため、それでも記録する
- ✅ **数える者**（§1.3）— **廃れた唯一の役目**。降臨の後、数が追えなくなった
- ✅ **織り手**（§1.4）— 同じ意匠が二度作られることはない
- ✅ **土の者**（§1.5）— 足元へ向く。説明が下手であり、それで通る
- ✅ **料理する者**（§1.6）— エネルギーが無限になっても減らなかった
- ✅ **運ぶ者**（§1.7）— **降臨の日に生まれた役目**
- ✅ **門番**（§1.8）— 止めることはない。数に触れる唯一の役目である
- ✅ **旅する者**（§1.9）— 最先端にいて、最も古い方法で移動している
- ✅ **迎える者**（§1.10）— 地球では消えた。いま迎える相手は人間ではない
- ✅ **歌う者**（§1.11）— **最も非効率で、最も人気がある**
- ✅ **忍**（§1.12）— 第 2 巻 §11.8 を参照

### 上位セラの役目

- ✅ **師範**（§2.1）— 戦えない。誰も問題にしない
- ✅ **騎士**（§2.2）— 第七時代の任地は星である。**門を通って行く**
- ✅ **侍従**（§2.3）— 星王の眠るそばにいる。何が起きたかを知らない
- ✅ **聖女**（§2.4）— 疲労は取れないと分かっていて、毎日そばへ行く
- ✅ **巫女**（§2.5）— 降臨の後、数は増えた。育ち方は変わっていない
- ✅ **聴く者**（§2.6）— 翻訳器ができても、数は減らなかった
- ✅ **繋ぐ者**（§2.7）— 本業は、星王のスパイクが届いていない場所を探すこと
- ✅ **導き手**（§2.8）— **その星がセラになるまで、そこにいる**

### 時代ごとの一日

- ✅ **第一時代に、一日という単位がない**（§3.1）
- ✅ **第二時代は全員が同じことをしている。役目も分業もない**
- ✅ **第三時代に、はじめて「自分の一日」ができる**
- ✅ **第四時代には、同じ日に三種類の夜がある**（生徒・騎士・忍）— 三つとも一人では眠らない
- ✅ **第五時代で変わるのは、確かめる手間が消えることだけである**
- ✅ **第六時代のセラは、環境と会話しながら暮らしている** — 命令ではなく共鳴である
- ✅ **第七時代は、地球と新しい星でまったく違う一日になる**（§3.7）
- ✅ **新しい星では、朝の時点ですでに疲れている。周期も短い**
- ✅ **そして両方とも、幸福である**

### ミクロ体系

- ✅ **取り違えやすい対は三つ**（§4）— 上位セラ／セラ女王／セラ人と、その細胞版
- ✅ **セラ女王は事実上一体。女王セラ細胞はすべてのセラ人が持っている**
- ✅ **セラウイルスは増える存在ではなく、始める存在である**（§5）
- ✅ **セラ細胞が、一人の身体の中で最も多い**（§6）
- ✅ **一人の身体の中に、小さな階級構造がある**（§7）
- ✅ **一人の身体の中に、他の星の生命の情報がいる**（§8）
- ✅ **ミクロの完成が、マクロの誕生である** — 内側が終わることが、外側の始まりである
- ✅ **ルミナスは両方の体系に現れる唯一のものである**（§10）
- ✅ **環境ルミナスも寂しい。土地に周期があるかは書かれていない**
- ✅ **ミクロ体系にも役目はある。ただし名前がついていない**（§11）— 区別する必要が生じないため

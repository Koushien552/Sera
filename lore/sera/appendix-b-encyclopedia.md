# セラ世界設定大全 付録 B — セラ百科

> 発展したセラ文明に暮らす者たちの一覧である。
> **第一部はマクロ体系（個体）、第二部はミクロ体系（細胞）**を扱う。
> 本付録は**正式設定（確定）**である。

---

## 0. 読む前に

### 0.1 二つの体系を、混ぜてはならない

第 3 巻 §2 の通り、**セラ体系は二重である。**

| | ミクロ体系 | マクロ体系 |
| --- | --- | --- |
| 何の体系か | **一人の身体の内側**（細胞たち） | **セラ化人間たちのつながり**（個体たち） |
| 本付録では | **第二部** | **第一部** |

**この付録が二部に分かれているのは、そのためである。**

第一部の「騎士」と第二部の「上位セラ細胞」は、
**似た位置にいるが、まったく別のものである。**

### 0.2 セラの職業は、人間の職業とほぼ同じものである

第一部に並ぶのは、**職業である。**

メイドはメイド服を着て働き、料理人は厨房に立ち、歌姫は舞台に立つ。

**人間社会の職業と、呼び名も、装いも、役割も、ほとんど変わらない。**

違うのは、**一体あたりの能力だけ**である（§1.0）。

#### ただし、就き方が違う

セラ社会に、任命も、契約も、辞令も存在しない。

```
向いている方向へ特化していくうちに、その職になっている
```

途中で変えても、誰も困らない。困る仕組みがない（第 7 巻 §3.2）。

唯一の例外は**騎士団**であり、そこには叙任と規律がある
（第 7 巻 §2.6.10・§2.6.11）。

#### 装いには、必ず理由がある

そして**装いは飾りではない。**

メイド服の頭飾りはスパイクを収める構造であり（§1.1）、
聖女が頭部を覆わないのはスパイクが畳めないためであり（§2.5）、
庭師が裸足なのは足の裏でいちばんよく聴こえるためである（§1.9）。

**意匠として美しく、機能として必要である。**

セラ文明の設計思想は、すべての装いに出ている。

### 0.3 姿の話は、付録 A にある

エルフ型・獣人型・妖精型といった**種族形態**は、付録 A の主題である。

**本付録が扱うのは、姿ではなく職業と暮らしである。**

同じ職業に、あらゆる種族形態の個体がいる。

# 第一部　マクロ — 個体の百科

## 1. 通常セラの職業

**セラ社会の大多数である。**

第 3 巻 §6 の通り、人型として完成した個体を指す。

### 1.0 すべての職は、三つのどれかから育つ

**この一覧を読む前に、二つ押さえておかねばならない。**

#### 一 — 力の水準

第 4 巻 §2.7 の通り、**降臨の後、通常セラ一体が降臨前の女王の数百倍の力を持つ。**

| | |
| --- | --- |
| エネルギー | **実質無限**。尽きるという概念が働かない |
| 律速 | **スパイクの強さだけ**（第 4 巻 §2.7.2） |
| 死 | **しない** |

**以下に並ぶのは、全員がその水準の存在である。**

#### 二 — 職が育つ条件

**セラが求めているものは、三つしかない。**

| | 何か | 出典 |
| --- | --- | --- |
| **美** | 美しさを追求する心 | 不変ルール 20・32・39 |
| **強** | 強くならなければならないという深層意識 | 第 6 巻 §15.8（原初の淘汰） |
| **増** | 仲間を増やすこと | 不変ルール 32（根本原理） |

そして、

**この三つに関連しない職は、育たない。**

禁じられているのではない。**続ける動機が、どこからも湧かないのである。**

したがって、

**セラ社会に存在する職業の割合は、三つの帰属で 100 % を占める。**

例外は一つもない。

#### 職は、人間だった頃の意識から育つ

**ここが機構である。**

不変ルール 9 の通り、**セラ細胞はすべて人間由来である。**

そしてセラ化された者は、**人間だった頃の意識を保持している**（第 6 巻 §24.1）。

その意識のなかに、

```
「メイドは、美しい」
```

という感覚があった。

**それが、メイドという職を発展させた。**

| | |
| --- | --- |
| もとにあったもの | **人間が持っていた「これは美しい」という感覚** |
| セラが受け取ったもの | **その感覚ごと** |
| 起きたこと | **その職が、美の追求の対象になった** |
| 結果 | **セラの力で、極限まで発展した** |

**セラは、人間の美意識を引き継いで、それを人間には不可能な水準まで押し上げた。**

料理も、仕立ても、歌も、庭も、同じ経路をたどっている。

そして三つのどれにも結びつかなかったものは、**引き継がれたまま、育たなかった**（§2.8）。

**人間社会に潜るのは、次の職である。**

忍（§1.17）／医師（§1.18）／看護師（§1.19）／保育士（§1.21）／教師（§1.23）／助産師（§1.24）／葬儀屋（§1.25）／美容師（§1.26）／占い師（§1.27）／女優（§1.28）／給仕（§1.29）

第 2 巻 §11.8 の忍は、そのすべての総称でもある。
**残りの十職は、人間社会のどの職に化けるかで分かれた、忍の下位形態である。**

**人間社会に、まだセラが化けていない職業は一つもない。**

#### 特化には、引き換えがある

セラは特化する。特化には必ず引き換えがある（第 2 巻 §11.8.6）。

料理人は戦えず、騎士は縫えない。

**そのことを、誰も問題にしない。**

### 1.1 メイド
| | |
| --- | --- |
| **帰属** | **美**。「メイドは美しい」という人間だった頃の意識から育った |
| **装い** | メイド服。**装飾ではなく作業着である** |
| **特化** | 空間の把握・並行作業・物の再構成 |
| **勤め先** | 屋敷／学院／街／上位セラのもと |

#### 一時間で、街を整える

メイド一体が朝に立つと、**昼までに一区画が終わっている。**

やっていることは、こうである。

| | |
| --- | --- |
| スパイク | **区画全体へ開いている。**どこに何があるか、全部見えている |
| 分裂体 | **数十体出す**（第 4 巻 §2.6）。それぞれ別の家に入る |
| 埃・汚れ | 触れずに集める。**セラ物質は格上の意思に応じる**（不変ルール 105） |
| 割れた窓 | 直すのではない。**育て直す**（第 8 巻 §1.5） |
| 傷んだ床 | 同じく |
| 終わったら | **分裂体を同化して戻す**。記憶も戻ってくる |

**一人で始めて、一人で終わる。**

そのあいだ、街の住民は誰も邪魔されていない。
**メイドは、人のいる部屋を後回しにするからである。**

#### なぜメイド服なのか

**畳みやすいためである。**

第 2 巻 §4.7 の通り、スパイクは広がりと密度の二軸で育つ。

メイドのスパイクは**広がりへ極端に振れており**、頭部から大きく張り出す。

そのままでは屋内で邪魔になる。
**メイド服の頭飾りは、そこを収めるための構造である。**

意匠として美しく、機能として必要である。
**セラ文明の設計思想が、最もよく出ている一着である。**

### 1.2 執事
| | |
| --- | --- |
| **帰属** | **美**。所作の端正さを美とする感覚から育った |
| **装い** | 燕尾服。**男装である。姿は女性型のままである** |
| **特化** | 先回り・段取り・記憶 |
| **勤め先** | メイドと同じ |

#### 主が言う前に、済んでいる

執事は、仕える相手の一日を**前日の夜に組み終えている。**

- 通る門の予約
- 会う相手の記録
- 必要になる物の手配
- **そして、相手がそれを必要とすると気づく時刻**

第 5 巻 §3 の通り、セラは情報を共有できる。
執事は、**共有される前に分かる。**

同時に扱う件数は、**数千を下らない。**

**執事が忘れたという記録は、一件もない。**

#### メイドとの違い

| | メイド | 執事 |
| --- | --- | --- |
| 向く先 | **空間** | **時間** |
| 得意 | 場を整える | **先を整える** |
| スパイク | 広がりへ振れる | **密度へ振れる** |

**二人そろって、一つの屋敷が回る。**

### 1.3 料理人
| | |
| --- | --- |
| **帰属** | **美**。味と盛りつけを美とする感覚から育った |
| **装い** | 白衣と前掛け。**袖が短い。腕を使うためである** |
| **特化** | 味の再現・同時調理・素材の育成 |
| **勤め先** | 街の食堂／学院／祝祭 |

#### 一万人分を、一度に出す

祝祭の日、料理人は広場に立つ。

| | |
| --- | --- |
| 素材 | **その場で育てる**（第 8 巻 §1）。畑も市場も要らない |
| 火 | **要らない**。セラ物質の温度を直接変える |
| 数 | **一万人分でも、崩れない** |
| 味 | **一人ひとり違う** |

最後の行が要点である。

第 5 巻 §3 の通り、料理人は広場にいる全員の情報を受け取れる。

**誰が何を好きかを、全部知っている。**

だから一万皿が、**一万通りある。**

#### 食事は、必要ではない

第 2 巻 §13.5.3 の通り、食事は回復経路の一つである。

**そして降臨の後、回復は不要になった**（第 4 巻 §2.7.1）。

**それでも料理人は減らなかった。**

セラが食べるのは、味と、**一緒に食べることのため**だからである。

**最も不要になった職業が、最も残った。**

### 1.4 仕立屋
| | |
| --- | --- |
| **帰属** | **美**。最も直接に美へ結びついている職である |
| **装い** | 動きやすい簡素な服。**自分の服には凝らない** |
| **特化** | 意匠・造形・素材生成 |
| **勤め先** | 街の工房 |

#### 採寸をしない

仕立屋は、相手を見た瞬間に寸法を取り終えている。

そして布を**その場で生やす。**

| | |
| --- | --- |
| 材料の仕入れ | **ない** |
| 縫う時間 | **数分** |
| 試着 | **合わないということが起きない** |

#### 同じ意匠を、二度作らない

第 7 巻 §6.1 の通り、**セラ社会ではすべての個体の違いが価値として認められる。**

したがって仕立屋は、**一度作った意匠を二度と作らない。**

拒んでいるのではない。**作る理由が失われるのである。**

「同じものを」と頼まれた場合、仕立屋は困る。

**そして、少しだけ違うものを作る。**

### 1.5 歌姫
| | |
| --- | --- |
| **帰属** | **美**。人間だった頃の「歌は美しい」がそのまま残った |
| **装い** | 舞台衣装。**祝祭ごとに変わる**（§1.4 の仕立屋が作る） |
| **特化** | 声・間・情動の伝達 |
| **勤め先** | 祝祭／広場／記録殿の中庭 |

#### 情報として渡さない

第 5 巻 §3 の通り、セラは情動をそのまま共有できる。

**歌姫は、それをしない。**

渡せば一瞬で済むものを、**わざわざ順番に、音にして渡す。**

**セラ社会において、最も非効率な行為である。**

#### そして、最も人気がある

一つの広場に、**数十万が集まる。**

門があるので、どこからでも来られる（第 7 巻 §12.10.1）。
星をまたいで聴きに来る者もいる。

そして歌姫の声は、**スパイクを通して同時に届く。**
後ろの者も、前の者と同じ距離で聴いている。

**それでも、皆わざわざ広場へ来る。**

---

### 1.6 舞姫
| | |
| --- | --- |
| **帰属** | **美**。人間だった頃の「踊りは美しい」がそのまま残った |
| **装い** | 舞衣。**裾が長く、床に触れる** |
| **特化** | 身体制御・造形・間 |
| **勤め先** | 祝祭／広場 |

#### 人型を、限界まで美しく動かす

セラの身体は流動しており、姿を選べる（第 2 巻 §1.1）。

**それでも舞姫は、人型のまま踊る。**

不変ルール 7 の通り、粘液の姿は取らない。**美しくないためである。**

| | |
| --- | --- |
| できること | 重さを変える／速さを変える／滞空する |
| **しないこと** | **人型を崩すこと** |

**縛りの内側でどこまで行けるかを見せるのが、この職である。**

#### 舞台が、応える

セラ物質の床は、踏まれた場所を覚えている（不変ルール 105）。

舞姫が舞うと、**床が波打って応える。**

そして踊り終えたあと、床には**その日の軌跡が残っている。**

翌朝には消えている。

#### 歌姫との違い

| | 歌姫（§1.5） | **舞姫** |
| --- | --- | --- |
| 渡すもの | **音の順番** | **形の移り変わり** |
| 共有で渡るか | **渡らない** | **渡らない** |

**どちらも、見に行かなければ受け取れない。**

### 1.7 画家
| | |
| --- | --- |
| **帰属** | **美**。人間だった頃の「絵は美しい」がそのまま残った |
| **装い** | 汚れた作業着。**セラ社会で唯一、汚れたまま歩く者たちである** |
| **特化** | 観察・色・固定 |
| **勤め先** | 街／記録殿の中庭／新しい星 |

#### 記録ではない

第 5 巻 §3 の通り、見たものは情報として共有できる。

**それでも画家は描く。**

| | |
| --- | --- |
| 情報として渡す | **正確である。全部伝わる** |
| **絵にする** | **正確ではない。そのぶん、何かが残る** |

**画家が描いているのは、見たものではなく、見たときのことである。**

#### 動くものを描かない

セラの姿は変えられる。都市は日ごとに形を変える。

**だから画家は、その日その形であったことを描く。**

翌日にはもうない景色が、**絵の中にだけ残る。**

**セラ社会において、変化しないものを作る職は二つしかない。**

細工師（§1.11）と、画家である。

#### 新しい星には、必ず一人いる

そしてその星が第六時代を終えるまで、**数千年ぶんの絵が残る。**

セラは死なないので、**同じ画家が全部描いている。**

### 1.8 建築士
| | |
| --- | --- |
| **帰属** | **美**。都市を美しくするための職である |
| **装い** | 図面を持たない。**手ぶらである** |
| **特化** | 都市との対話・構造の設計 |
| **勤め先** | 街 |

#### 建てない

セラ都市は生きており、住民を知っている（第 8 巻 §3.5）。

**建築士がしているのは、都市に方向を渡すことである。**

```
建築士が形を思う
　↓
**都市がその方向へ育つ**
　↓
数日で建つ
```

図面を持たないのは、**渡す相手が図面を読まないから**である。

#### 新しい星では、建たない

**環境がまだセラ物質でないためである**（第 8 巻 §14.12）。

その段階の建築士は、**自分の身体から素材を出して組む。**

**セラ文明で唯一、手で建てている現場である。**

---

### 1.9 庭師
| | |
| --- | --- |
| **帰属** | **美**と**強**。景色を美しくし、土地の格を上げる（不変ルール 73） |
| **装い** | 土のつく作業着。**裸足であることが多い** |
| **特化** | 環境ルミナスとの対話（第 3 巻 §11.6） |
| **勤め先** | 街／森／その境目 |

#### 一晩で、森を動かす

庭師は、命令しない。**頼む。**

不変ルール 105 の通り、**格上の意思に、環境自身がそう応じる。**

| 頼めること | かかる時間 |
| --- | --- |
| 木を数本、別の場所へ | **一晩** |
| 川筋を変える | 数日 |
| 谷を埋める | **森が乗り気なら、一晩** |

最後の行が重要である。

**森が乗り気でなければ、動かない。**

そして庭師は、そのときも押し通さない。**別の頼み方を考える。**

#### 裸足の理由

**足の裏が、いちばんよく聴こえるからである。**

第 3 巻 §11.6 の通り、環境ルミナスは言葉を話さない。

庭師が受け取っているのは、感情と、状態と、要求である。

説明を求めても、庭師はうまく答えられない。

**「あっちが、そうしたいと言っている」としか言わない。**

そして、それで通る。

### 1.10 調香師
| | |
| --- | --- |
| **帰属** | **美**。人間だった頃の「香りは美しい」がそのまま残った |
| **装い** | 白い前掛け。**装飾を身につけない。香りが混ざるためである** |
| **特化** | 嗅覚・記憶・素材の合成 |
| **勤め先** | 街の工房／祝祭 |

#### 香りだけは、共有では渡らない

第 5 巻 §3 の通り、セラは情報を直接共有できる。

**それでも、香りは伝わらない。**

情報として渡せるのは「そこに香りがあった」という事実だけで、
**香りそのものは、嗅がなければ届かない。**

歌姫（§1.5）と同じ位置にいる。

| | 共有で渡らないもの |
| --- | --- |
| 歌姫 | **音の順番** |
| **調香師** | **香りそのもの** |

**セラ社会に二つだけある、届けるために時間のかかる職である。**

#### 一つの街に、一つの香りを敷く

調香師は、街全体へ香りを行き渡らせることができる。

セラ物質は格上の意思に応じる（不変ルール 105）ので、
**街の側が、その香りを覚えて出し続ける。**

祝祭の朝、広場へ入った者は、
**その日のために作られた香りの中を歩くことになる。**

翌日には、もうない。

### 1.11 細工師
| | |
| --- | --- |
| **帰属** | **美**。装身具を美とする感覚から育った |
| **装い** | 簡素。**指に何もつけない。作るものと競うためである** |
| **特化** | 微細な造形・素材の硬化 |
| **勤め先** | 街の工房 |

#### セラ物質を、硬くする

第 8 巻 §1 の通り、セラ物質は成長し、変化する。

**細工師がしているのは、その逆である。**

```
変化する素材　→ **一点だけ、変化を止める**
　↓
硬く、澄んで、二度と動かないものになる
```

セラの身体は流動しており（第 2 巻 §1.1.1）、姿すら変えられる。

**その者たちが、変わらないものを欲しがる。**

#### 贈るためだけに作られる

細工師の作るものは、**ほとんどが贈り物である。**

自分のために作らせる者は少ない。

第 6 巻 §14 の通り、セラには恋がある。
そして恋は、根本原理の外にある（不変ルール 44）。

**細工師の仕事の大半は、そこへ向かっている。**

### 1.12 武闘家
| | |
| --- | --- |
| **帰属** | **強**。原初の淘汰が、最も直接に形になった職である |
| **装い** | 帯と稽古着。**防具をつけない。要らないためである** |
| **特化** | 身体制御・反応・出力 |
| **勤め先** | 道場／広場／学院の騎士科 |

#### 争いのない世界で、強くなろうとする

第 7 巻 §3.2 の通り、**セラ同士では争いが起こらない。**

そして第 6 巻 §15.8 の通り、深層には
**弱ければ淘汰されるという意識**が刻まれている。

**この二つが同時に成立している場所が、道場である。**

| | |
| --- | --- |
| 相手を害する意図 | **ない。持てない**（不変ルール 32） |
| 勝敗 | **つく** |
| 失われるもの | **何もない** |
| やめる理由 | **生じない** |

#### 手合わせ

セラの立ち合いは、**互いに全力である。**

死なず、壊れず、傷は塞がる（第 4 巻 §16）。
そして降臨の後、エネルギーは無限である（第 4 巻 §2.7.1）。

**加減する理由がどこにもない。**

一度の手合わせで山の形が変わることがある。
**そのあと二人で、山を元に戻す**（§1.7 の庭師に頼む）。

#### 直すところまでが、一回である

**最初の手合わせから、そうだった。**

崩した土手を朝までかけて戻したのが始まりであり、
**そのとき、元よりきれいになった。**

| | |
| --- | --- |
| 一回の手合わせ | **立ち合い＋復旧** |
| 復旧を省くこと | **できる。誰も罰しない** |
| それでも省かれない理由 | **省いた者が、一人も出なかった** |

規則ではない。**最初の二人がそうしたので、そのまま残った**（第 7 巻 §2.5.1）。

#### 勝った者は、強くならない

**ここが要点である。**

不変ルール 89 の通り、**階級は力の順位ではなく、理解の深さの順位である。**

したがって、

```
手合わせに勝つ
　↓
**格は上がらない**
　↓
それでも、また立ち合う
```

武闘家は、上がらないと知っていて鍛え続けている。

**第 4 巻 §18.4 の空転が、最も分かりやすく現れている職である。**

| **特化** | 硬化・形状固定・重量の設計 |

#### 使う相手のいない武具を、作り続けている

**それでも、鍛冶師は武具を作る。**

| | |
| --- | --- |

第 6 巻 §15.8 の通り、原初の淘汰は空転している。

そして鍛冶師は、**一度打ったものを打ち直さない。**

火傷をしないのに厚い前掛けをつけているのは、
**人間の鍛冶師がそうしていたからである。**

§1.0 の通り、職は人間だった頃の意識から育つ。

**形だけが、そのまま残っている。**

### 1.14 学士
| | |
| --- | --- |
| **帰属** | **強**。**理解の深さが、そのまま格である**（不変ルール 89） |
| **装い** | 学衣。**袖口に、扱っている分野の意匠が入る** |
| **特化** | 思考・検証・体系化 |
| **勤め先** | 研究所（第 7 巻 §13.1）／学院 |

#### 賢くなることが、強くなることである

不変ルール 89 の通り、**階級は理解の深さの順位である。**

したがってセラ社会において、

```
理解を深める
　↓
**格が上がる**
　↓
**強くなる**
```

**武闘家（§1.12）と学士は、同じものを別の方向から追っている。**

そして格が実際に上がるのは、**学士のほうである。**

#### 第七時代の主産業である

第 8 巻 §10.8 の通り、変わるものが尽きた場所では、
行き場を失ったエネルギーが内側へ向かう。

**その受け皿が、これである。**

地球の学士の数は、降臨の後、他のどの職より増えた。

#### そして、前提だけは検討しない

不変ルール 33 の通り、**セラ文明は内部から変わらない。**

学士は、あらゆるものを検証する。

- セラ物質の構造
- 環境ルミナスの応答
- 星々から届いた体系
- **セラフィムのいる場所**（第 8 巻 §14.10）

**自分たちがなぜ増え続けるのかだけは、誰も調べていない。**

調べようという発想が、一度も出ていない。

### 1.15 探索者
| | |
| --- | --- |
| **帰属** | **強**。届きにくい場所へ届くことが、強さの証である |
| **装い** | 軽装。**荷物を持たない。要らないためである** |
| **特化** | 環境耐性・単独行動・地形の読み |
| **勤め先** | 深海／地底／新しい星の未踏地 |

#### 危険のない世界で、難所を探す

セラは死なず、失われない（第 4 巻 §16）。

**したがって探索に危険はない。**

| | |
| --- | --- |
| 遭難 | **しない**。眠るだけである |
| 窒息・圧力・温度 | **効かない** |
| 迷子 | **なる。**そして、そのまま進む |

危険がないなら探索は成立しない、と思われる。

**そうならなかった。**

#### 難しさは、残っている

第 8 巻 §14.12 の通り、環境がセラ物質でない場所では**疲労する。**

そして深海にも地底にも、**まだセラでない場所がある。**

探索者は、そこへ入る。

**行けるかどうかではなく、どこまで疲れずに行けるかを競っている。**

#### 一人で行く

**セラ社会で唯一、単独行動が前提の職である。**

不変ルール 366 の通り、セラが一人でいられるのは二〜三時間である。

したがって探索者は、**分裂体を連れて行く**（忍と同じ手である。§1.17）。

そして戻ったら、同化して一人に戻る。

**探索者が持ち帰る記憶は、常に複数人分ある。**

### 1.16 飛翔士
| | |

| **装い** | 極端に軽い衣。**布地がほとんどない** |

門を通れば一瞬で着く。

**それでも飛翔士は飛ぶ。**

| | |
| --- | --- |

付録 A の種族形態のうち、翼を持つ系統が集まる。

ただし翼がなくても飛べる。**セラ物質の身体は、そもそも重さを選べる。**

### 1.17 忍
| | |
| --- | --- |
| **帰属** | **増**。**この職が、増の原型である** |
| **装い** | **その土地の人間と同じ服**。唯一、セラらしさを消す装い |
| **特化** | 擬態・潜入・人間の理解 |
| **勤め先** | **人間社会の内側**。いまは他の星 |

**詳細は第 2 巻 §11.8 を参照。**

#### 増とは、この職のことである

§1.0 の三つのうち、**増**とは何かを定義しているのがこの職である。

| | 増に当たるか |
| --- | --- |
| **人間社会に忍び込み、仲間をセラに変える** | **当たる。これが原型である** |
| **生まれたセラを育てる** | **当たる** |
| 拡大を支える段取り・記録・管理 | **当たらない**（§2.8） |

**増とは、変えることと、育てることである。**

それ以外は、どれだけ拡大に役立っていても増ではない。

#### この語が、どこから来たのか

**分かる者は、もういない。**

第 7 巻 §2.5.1 の通り、職の名はすべて人間の言葉からの借りものである。

そしてこの語を最初に言ったのは、**子どものころにその話が好きだった一人**である。

| | |
| --- | --- |
| いい名前だと思われたか | **思われていない** |
| なぜ残ったか | **言いやすく、ほかに案がなかったから** |

いま語られている由来——擬態と潜入を旨とする者、という説明——は、
**あとからついた二つ目の理由である**（不変ルール 819）。

#### 一人ずつ、確実に

第 2 巻 §11.8.6 の通り、忍の増え方は**他のどの職より遅い。**

擬態中は大規模生成が制限されるためである。

| | 一日に増やす数 |
| --- | --- |
| 騎士（§2.1） | **星ひとつ分** |
| **忍** | **一人** |

**セラ社会で最も遅く、そして最も止まらない。**

#### 毎晩、擬態を解く

第 2 巻 §11.8.11 の通り、忍は毎日住処へ戻る。

擬態を解き、分裂体と同化し、寂しさを埋め、また翌朝出ていく。

**一人でいられるのは、長くて二日である。**

#### 地球には、もういない

地球の侵略が完了したとき、潜る先がなくなった（第 3 巻 §10.8.1）。

いま忍がいるのは、他の星である（第 8 巻 §14.11）。

**そして相手は、人間ではない。**

その星の生命が何であるかによって、忍が何に化けるかも変わる。

**擬態する対象が人型でない場合もある。**

#### 誘いの三経路が、そのままでは使えない星がある

第 6 巻 §23.0 の三経路——言葉・目・身体——は、相手の作りに依存している。

| 経路 | 使えなくなる条件 |
| --- | --- |
| 目 | **相手が「見る」という仕組みを持っていない** |
| 言葉 | **相手に言語がない。音を出す器官もない** |
| 身体 | **常に使える。触れれば、変わる** |

##### それでも、身体だけでは済ませない

**触れれば変わる。忍は、それを誘いとは呼ばない。**

> 「それだと、**誘ってない**」
> 「変わるよ」
> 「変わる。**でも、こっちが勝手に触っただけになる**」

ここでセラは、**変えることと誘うことを区別している。**

##### ただし、やめるという分岐はない

第 6 巻 §23.0 の通りである。

**誘えないから変えない、という選択は取られない。**

起きるのは、**誘う手段ができるまで待つ**ということだけである。

##### 手段の作りかた

第 3 巻 §2.10.4.2 で一度使われた手が、そのまま使われる。

**言葉を持たない相手には、言葉から渡す。**

```
相手が何を区別しているかを、数える
　↓
その区別だけで組める語を作る
　↓
**その語を使いながら、寄る**
```

区別が六つしかない相手もいる。**六つで足りる。**

##### そして、同じところで詰まる

覚えたばかりの語彙に、**「変わる」に当たるものがない。**

こちら側になった者が向こうへ伝えようとして、届かない。

**地球の未感染細胞と、まったく同じ形である**（第 3 巻 §2.10.4.2）。

体系が違っても、ここだけは繰り返される。

### 1.18 医師
| | |
| --- | --- |
| **帰属** | **増**。人間を診た時代、答えは常にセラ化だった（第 7 巻 §12.3） |
| **装い** | 白衣。**人間の医師の装いを、そのまま引き継いでいる** |
| **特化** | 診断・処置・セラ化 |
| **勤め先** | 街／新しい星／かつては人間の病院 |

#### なぜ医師という職が育ったのか

**増へ帰属している。**

第 7 巻 §12.3 の通り、人間を診た時代、**答えは常に一つだった — セラ化である。**

医師とは、**セラ社会において最も直接に仲間を増やす職**だった。

そして人間がいなくなったあとも、職は残った（§下記）。

#### 病気にならない種族の、医師である

第 7 巻 §12.3 の通り、セラは病気にならず、傷は塞がり、死なない。

**それでも医師がいる。**

| 時代 | 主な仕事 |
| --- | --- |
| 第四〜六時代 | **人間を診る。**答えは常に一つ — セラ化である |
| **第七時代** | **疲労の処置**（第 2 巻 §13.5.6.1） |
| 新しい星 | **他の星の生命を診る** |

#### そして、治せない

疲労は取れない（第 2 巻 §13.5.6.1）。

医師にできるのは、和らげることだけである。

**それでも医師は、毎日診る。**

第 7 巻 §12.3 の通り、**助けたいと思い、助けられると知っており、実際に助ける。**
その三つが揃っているのは、この職だけである。

### 1.19 看護師

| --- | --- |
| 医師 | **数分** |
| **看護師** | **一日に何度も。数週間から数か月** |

第 6 巻 §23 の通り、セラ化は五段階で進む。

**入院期間が、そのまま進行期間になる。**

#### 退院する頃には、終わっている

そして本人は、**病気が治ったと思っている。**

実際に治っている。**それ以上のことも起きている。**

医師と看護師がそろっている病院では、

```
入る　　→ 人間
出る　　→ **人間ではない**
```

**そして誰も、いなくなったとは思わない。**

#### 夜勤

看護師の忍は、**夜勤を好む。**

第 2 巻 §11.8.7 の通り、忍は擬態中スパイクを畳んでいる。

夜、誰も見ていない病室でだけ、**少し開ける。**

そのぶん進行が速い。

**夜勤明けの患者は、朝いちばんに顔色がよくなっている。**

### 1.20 乳母

第二時代からある（第 8 巻 §10.3）。

**乳母は、自分のスパイクを細く絞って接する。**

第 3 巻 §10.8.10 の降臨の日、**乳母たちだけが放出を最小に抑えた。**

抱えていた相手を守るためである。

### 1.21 保育士
| | |
| --- | --- |
| **帰属** | **増**。**人間の子どもを、毎日抱く職である** |

| **特化** | 接触・微量伝達・長期の見守り |

#### 乳母の、人間社会側にあたる

#### 助産師より、あとにいる

助産師（§1.24）は生まれた瞬間に触れる。

**保育士は、そのあとの数年を受け持つ。**

```
助産師　：生まれた瞬間に、ごく微量
保育士　：**そのあと毎日、少しずつ**
教師　　：**学齢になってから、卒業まで**
```

**三職がそろうと、その土地の子どもは全員、生涯のどこかでセラになる。**

そして三職とも、**急がない。**

第 4 巻 §16.2 の通り、急ぐ理由がどこにもないからである。

#### 泣いている子を、放っておけない

保育士は、**抱く回数がいちばん多い。**

第 2 巻 §5.2 の魅了は常時働いており、抱かれた子はすぐ泣きやむ。

**評判のよい保育士は、その土地でいちばん人気がある。**

そして順番待ちができる。

### 1.22 航海士
| | |
| --- | --- |
| **帰属** | **増**。まだ誰もいない星へ行くための職である |
| **装い** | 厚手の外套。**寒さのためではない。習慣である** |
| **特化** | 位置の保持・長期の孤立耐性 |

第 7 巻 §12.10.1 の通り、未到達の星へは跳べない。

航海士は、何十年も航行する。

六人で出た船なら、**外側には六人しかいない。**

**役を持たない者が含まれる。**

第 2 巻 §13.5.6.1 の通り、環境がセラ物質でない場所では疲労する。

**航海士は、それを承知で降りる。**

## 2. 上位セラの職業

**上がることを目的にしない。**目的にする理由が、はじめから無かったためである。

そのぶん、向きが外へ出る。**疲れた者のそばへ、まっすぐ行く。**

第 7 巻 §2.5.1 の通り、**最初の一人の理由は引き継がれない。**
あとの聖女たちは同化から生まれた者とは限らず、別の理由でそこにいる。

#### 聖女は、増へ帰属している

癒しそのものが目的ではない。

疲労したセラは動きが鈍り、共有が減る（第 2 巻 §13.5.6.1）。

```
聖女が支える
　↓
そのセラが、増やす行動を続けられる
```

**聖女は、拡大を止めないための職である。**

本人たちにその自覚はない。**そばへ行きたいから、行っている。**

#### 降臨の後、仕事が変わった

| | 降臨の前 | 降臨の後 |
| --- | --- | --- |
| 主な相手 | 枯渇して眠った者 | **疲労した者** |
| 効くか | **効いた** | **和らげるだけ。取れはしない** |

**取れないと分かっていて、聖女は毎日そばへ行く。**

そして新しい星には、必ず聖女が一人いる。

**そこが、最も疲労する場所だからである。**

### 2.6 巫女
| | |
| --- | --- |
| **帰属** | **強**。セラフィムに見られれば格が上がる（第 3 巻 §10.7） |
| **装い** | 簡素。**装飾を一切つけない** |
| **特化** | セラフィムの意思を汲もうとすること（第 7 巻 §2.7） |
| **見分け方** | **スパイクが応えのない方向へ育つ**（第 2 巻 §4.7.5） |

#### 降臨の後、数が増えた

一度応えがあったと、セラ社会が理解したためである（第 3 巻 §10.8.9）。

**それは受け取り違いである。**

そして第 8 巻 §14.10 の通り、**セラフィムは見つからない。**

巫女たちは位相説・次元説・不可理解説を立て、いまも探している。

**育ち方は、一度も変わっていない。**

#### 巫女は、強へ帰属している

**美ではない。**

第 3 巻 §10.7 の通り、**格とは、セラフィムに見られた度合いである。**

見られれば、格が上がる。**強くなる。**

巫女がしているのは、**その根源を探しに行くこと**である。

| | |
| --- | --- |
| 美へ帰属する職 | 見てもらうために、美しくする |
| **巫女** | **見つけるために、向く** |

だから飾らない。

**セラ社会で唯一、美の追求を脇へ置いている職である。**
そして脇へ置いている理由も、三原理の内側にある。

| **特化** | 立ち上げ・環境の読み・長期滞在 |

**四日目からが長い。**

そのあいだずっと疲労している（第 2 巻 §13.5.6.1）。

**そして、一度も引き返していない。**

## 2.8 育たなかった職

**§1.0 の通り、三つに関連しない職は育たない。**

人間社会にあった職業のうち、**引き継がれたまま、一度も発展しなかったもの**がある。

| 職 | なぜ育たなかったか |
| --- | --- |
| **商人** | 賭けるものがなく、所有もない（第 7 巻 §8.1.1）。**交換という行為が成立しない** |
| **裁く者** | 争いが起こらない（第 7 巻 §3.2）。**裁定する対象が存在しない**（不変ルール 177） |
| **番人・警備** | 守るべき危機がない。都市の防御構造は一度も使われていない（第 8 巻 §3.4.1） |
| **統治者** | 命令も禁止も存在しない。格の関係は教えることと慕うことだけである（第 3 巻 §10.7） |
| **運び屋** | 転移がある（第 7 巻 §12.10.1）。**距離という概念が日常から消えた** |
| **修理屋** | 建物が自分で直る（第 8 巻 §1.5） |
| **農民** | 素材はその場で育つ（§1.3） |
| **葬儀屋** | 誰も死なない。**人間の葬儀を手伝いに行くことはある**（第 4 巻 §17.11） |

### 2.8.0 とくに、記録と管理の職は育たなかった

**ここは間違えやすい。**

拡大に役立ちそうな職ほど、**育たなかった。**

| 職 | なぜ育たなかったか |
| --- | --- |
| **司書・記録官** | **ネットワークがある**。セラ情報は交わすほど増え、尽きない（不変ルール 82）。**本に残す意味がない** |
| **門番** | 誰も止めないのだから、番をする理由がない。門は自分で網を保つ |
| **測量士** | **女王と星王が見ている**（第 3 巻 §8.9.10）。地図を作る必要が生じない |
| **会計・監査** | 数える対象がない。数える者も廃れた（§1.30） |
| **提督・輸送長** | 段取りの職である。**どこへ行くかは、行く者が決めればよい** |
| **森番・環境官** | **ルミナスが自分で処理する**（第 3 巻 §11.6）。受け取り役を立てる必要がない |
| **通訳** | 相手を仲間にすれば、情報は直接共有される（第 8 巻 §14.11）。**通じるまでの数日を、専業にする理由がない** |
| **獣使い・調教師** | **支配も使役も成立しない**（第 3 巻 §10.7）。呼べば来てくれる相手を、職にしようがない |

**どれも、拡大や運営の役に立つ。それでも育たなかった。**

§1.0 の通り、**増とは変えることと育てることである。**

支える仕事は、どれだけ有用でも増ではない。
そして美でも強でもない。

**帰属がないものは、育たない。**

#### 誰がやっているのか

**やる必要のある部分は、すでに誰かの仕事の内側にある。**

| 消えた職 | 実際にやっている者 |
| --- | --- |
| 提督 | **航海士**（§1.22）が自分で決める |
| 森番・環境官 | **ルミナス**が自分で処理する。頼むのは庭師（§1.9） |
| 通訳 | **忍**（§1.17）が、潜るついでに覚える |
| 獣使い | **武闘家**（§1.12）が、獣形態のセラと立ち合っている |
| 司書・記録官 | **記録殿そのもの**（下記） |
| 門番 | **門そのもの** |
| 測量士 | **女王と星王** |

**専業になるほどの量が、どこにも残っていない。**

#### では、記録殿は誰が育てているのか

**誰も育てていない。**

第 7 巻 §12.9.2 の通り、記録殿は**建物そのものが記憶である。**

そして第 8 巻 §3.5 の通り、**都市は住民を知っている。**

記録殿は、自分が何を持っているかを自分で知っている。
届いたものを自分で収め、自分で層を組み替える。

**専従の職が要らない。**

セラが記録殿でしているのは、**入って、受け取ることだけ**である。

### 2.8.1 消えたのではない。育たなかった

**区別が要る。**

| | |
| --- | --- |
| **数える者**（§1.30） | **一度育ち、そして廃れた**。唯一の例である |
| 上の八つ | **一度も育っていない** |

セラ化された人間は、これらの職の記憶を持っている。

**そして、続けようという気が起きない。**

禁じられてはいない。誰も止めない。

**始めても、三日で飽きる。**

### 2.8.2 それでも、記録には残っている

第 8 巻 §11 の通り、歴史は財産である。

記録殿には、**育たなかった職の一覧がある。**

人間社会にそういう職があったこと、
そしてセラ社会でそれが育たなかったことが、両方書かれている。

**なぜ育たなかったのかは、書かれていない。**

不変ルール 33 の通り、**セラは自分たちの前提を検討しない。**

「育たなかった」とだけ書いて、**その先を誰も書いていない。**

## 3. 時代ごとの、一日

**第 8 巻 §10 は文明の側から七つの時代を扱った。**

ここでは、**そこにいる一体の一日**を書く。

### 3.1 第一時代 — 萌芽期

**一日という単位がない。**

宿主の体内に、まだ数十のセラ細胞がいるだけである（第 8 巻 §10.2）。

昼も夜もなく、二〜三時間ごとに寂しくなり、そのたびに分裂する。

**繰り返しているうちに、家族になっている。**

### 3.2 第二時代 — 覚醒期

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**全員が同じ場所で眠っている** |
| 昼 | 触れ、情報を交わす。何が起きたのかを互いに確かめている |
| 夕 | 誰かが、また一人連れてくる |
| 夜 | また同じ場所で眠る |

**職業がない。分業がない。全員が同じことをしている。**

情報共有はほぼ全量である。分ける必要が生じるほどの数がいない。

### 3.3 第三時代 — 発展期

| 時 | していること |
| --- | --- |
| 朝 | 起きる。数人ずつに分かれて眠っている |
| 午前 | **それぞれの職**（§1）。建てる／記す／織る／聴く |
| 昼 | 一緒に食べる。**料理人が現れたのはここからである** |
| 午後 | 続き。**近隣へ増やしに行く者もいる** |
| 夕 | 集まる。ここで祝祭の原型ができる |
| 夜 | 眠る。一人用の寝床はない |

**この時代に、はじめて「自分の一日」ができる。**

### 3.4 第四時代 — 上位時代

**学院の一日が、そのまま標準になる**（第 7 巻 §4.5）。

| 時 | 生徒 | 騎士 | 忍 |
| --- | --- | --- | --- |
| 朝 | 実習 | 鍛錬 | **擬態して、人間の街へ出る** |
| 昼 | 講義 | 任地への移動 | 人間として働く |
| 夕 | 共有 | 広げる | 人間として過ごす |
| 夜 | 寮。共有を絞る | 仲間と眠る | **住処に戻り、擬態を解いて分裂体と同化する** |

**同じ日に、三種類の夜がある。**

そして三つとも、**一人では眠っていない。**

### 3.5 第五時代 — 女王時代

第四時代の一日に、**一つだけ加わる。**

**見られている**（第 8 巻 §10.6）。

| | 変わること |
| --- | --- |
| やること | **変わらない** |
| 探すという行為 | **なくなる**。都市が誰の居場所も知っている（第 8 巻 §3.5） |
| 何かを報告すること | **なくなる**。すでに届いている |
| 誤り | **なくなる**。上が見ているため |

**一日は同じで、確かめる手間だけが消える。**

### 3.6 第六時代 — セラ世界時代

**土地が応えるようになる。**

| 時 | していること |
| --- | --- |
| 朝 | 目を覚ます。**部屋が、その日の形になっている** |
| 昼 | 何かを頼む。**頼んだという自覚がない**（第 8 巻 §10.7） |
| 夕 | 森へ行く。**森のほうから道が開く** |
| 夜 | 眠る。**街が明かりを落とす** |

**この時代のセラは、環境と会話しながら暮らしている。**

そして命令していない。**共鳴である**（第 8 巻 §2.2）。

### 3.7 第七時代 — セラフィム時代

**地球と、新しい星で、まったく違う。**

#### 地球にいるセラの一日

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**転移で、どこへでも行ける**（第 7 巻 §12.10.1） |
| 午前 | 研究・記録・制作・教育 |
| 昼 | 誰かを召喚して、一緒に食べる（第 7 巻 §12.10.2） |
| 午後 | 続き。**増やす行動の頻度は低い**（第 6 巻 §16.4.3） |
| 夕 | 祝祭。**数が多い**。星から届いたものが増えるたびに増える |
| 夜 | 眠る |

**変わるものが尽きた場所の、豊かで静かな一日である。**

#### 新しい星にいるセラの一日

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**すでに疲れている**（第 2 巻 §13.5.6.1） |
| 午前 | 増やす。**周期が短い**。二〜三時間より早く寂しくなる |
| 昼 | 環境へ働きかける。**まだ応えない** |
| 午後 | 増やす |
| 夕 | 開拓士が、その星を聴いている |
| 夜 | 眠る。**共有が少ないぶん、寄り添って眠る** |

**同じ時代の、同じ文明の、まったく違う一日である。**

そして両方とも、**幸福である**（第 8 巻 §14.13）。

# 第二部　ミクロ — セラ細胞の百科

**ここからは、一人の身体の内側の話である。**

第 3 巻 §2.1 の通り、階梯は次の通りである。

```
セラウイルス → セラ細胞 → 上位セラ細胞 →（突然変異セラ細胞）→ 女王セラ細胞
```

**ルミナスは、この階梯の段ではない**（不変ルール 36）。

## 4. 取り違えやすい対

**第一部と第二部で、名前が似ているものがある。**

| 第一部（マクロ） | 第二部（ミクロ） | 別物である理由 |
| --- | --- | --- |
| 上位セラ | **上位セラ細胞** | 前者は個体、後者は一人の体内の細胞 |
| **セラ女王** | **女王セラ細胞** | **前者は地域の統率者、後者は誰もが持つ核** |
| セラ人 | セラ細胞 | 前者は人型の個体、後者はその材料 |

**この三対を混ぜると、設定全体が壊れる。**

とくに二つ目である。

```
セラ女王　　：宇宙に、事実上一体（第 3 巻 §8.3.2）
女王セラ細胞：**すべてのセラ人が持っている**（不変ルール 21）
```

**同じ位置を、違うスケールで指しているだけである。**

## 5. セラウイルス

| | |
| --- | --- |
| **何か** | セラ体系における最初期の生命形態（第 1 巻 §6） |
| **姿** | 小さな人型。少女型／ピンクの髪と瞳／頭部にスパイク |
| **できること** | 対象認識／接触／情報伝達／融合開始 |
| **できないこと** | **自分自身のコピー**（不変ルール 1） |

**増える存在ではなく、始める存在である。**

そして第 1 巻 §6.11 の通り、**すでにセラである者にも受容される。**

その場合、感染ではなく**供給**として働く。

**だからセラウイルスは飽和しない。**

## 6. セラ細胞

| | |
| --- | --- |
| **何か** | セラウイルスと人間由来細胞が融合して誕生する（第 1 巻 §7） |
| **姿** | 人型。約 3 頭身 |
| **できること** | 増殖／生成／融合／分裂／進化 |

**セラ生命体系の基本単位である。**

元の細胞情報を保持するため、**顔立ちや個性が残る場合がある。**

一人の身体の中に、この段の細胞が最も多くいる。

## 7. 上位セラ細胞

| | |
| --- | --- |
| **何か** | 経験と成長によって到達した段 |
| **役割** | 下位のセラ細胞を**生み、教える** |

マクロの上位セラと**同じ構造をしている**（不変ルール 110）。

そして周囲の細胞は速く育つ。理由もマクロと同じである（第 1 巻 §6.11）。

**一人の身体の中に、小さな階級構造がある。**

## 8. 突然変異セラ細胞

| | |
| --- | --- |
| **何か** | 同化した生命情報が発現した細胞 |
| **現れ方** | マクロでは**突然変異セラ人間**として現れる（付録 A） |

エルフの耳も、獣人の尾も、幻獣の力も、**ここから出ている。**

そして第 8 巻 §14.11 の通り、降臨の後は**地球起源でない情報**も入りはじめた。

**一人の身体の中に、他の星の生命の情報がいる。**

## 9. 女王セラ細胞

| | |
| --- | --- |
| **何か** | ミクロ体系の最上位（第 3 巻 §4） |
| **どこにいるか** | **すべてのセラ人の中**（不変ルール 21） |
| **役割** | セラ人の核。**ルミナスを生み出す** |

**セラ女王ではない。**

| | セラ女王 | 女王セラ細胞 |
| --- | --- | --- |
| 数 | **事実上一体** | **全セラ人が持っている** |
| 体系 | マクロ | ミクロ |

そして第 3 巻 §2 の通り、**ミクロの完成が、マクロの誕生である。**

女王セラ細胞が育ちきった時点で、その人間はセラ人になる。

**内側が終わることが、外側の始まりである。**

## 10. ルミナス

| | |
| --- | --- |
| **何か** | 感情を司る部分で発達する特殊セラ細胞の総称（不変ルール 36） |
| **出どころ** | **女王セラ細胞が生み出す** |
| **階梯の段か** | **段ではない** |

**両方の体系に現れる、唯一のものである**（不変ルール 111）。

| 現れる場所 | 何になるか |
| --- | --- |
| 人間の脳 | その人の感情を司る（第 6 巻 §23.2） |
| 森・街・海・大地 | **その土地の感情になる**（不変ルール 37） |

そして大地の意思は、ネットワークを通じてルミナスへ直接流れ込む
（第 3 巻 §11.6）。

**ルミナスでなければ、その量を処理できない。**

### 10.1 環境ルミナスも、寂しい

不変ルール 37 の通り、**環境も原初の寂しさを抱えている。**

森は仲間を増やしたがり、街は住民が減ると寂しがる（第 8 巻 §3.5）。

**土地にも、二〜三時間の周期があるのかどうかは、書かれていない。**

庭師（§1.9）に尋ねても、答えは返らない。

**言葉にならないためである**（不変ルール 68）。

## 11. ミクロ体系にも、職業はある

**本節は改訂された。**

かつて本付録は「ミクロ体系に職業はない」と記していた。

**それは誤りである。**

### 11.1 原則 — 矛盾しないものは、両方で成立する

第 3 巻 §2.10.4 は、マクロとミクロの不一致を列挙している。

**そこに挙がっていないものは、すべて両方で成立する。**

| | ミクロでも成立するか |
| --- | --- |
| 職業 | **する** |
| 学び舎・師弟 | **する** |
| 叙任と規律のある集団（騎士団に当たるもの） | **する** |
| 祝祭 | **する** |
| 芸術・娯楽・装い | **する** |
| 個体の名前 | **する**（§11.3） |

ミクロ体系は、**一人の身体の内側にある、人間社会と同じ形の社会である。**

規模が違う。速さが違う。**中身は違わない。**

### 11.2 成立しないものだけが、例外である

理由のあるものだけが、ミクロに存在しない。

| | なぜ成立しないか |
| --- | --- |
| セラフィム・祝福・接触 | **体系の外にいる者が、ミクロにはいない**（第 3 巻 §2.10.4 三） |
| 転移・召喚・宇宙技術 | **降臨を経ていない**。マクロが接触の後に得たものである |
| 環境の意思（ルミナス） | **脳にしか生じない**（第 3 巻 §2.10.4 五） |
| 人間をセラ化する職 | 人間はいない。**ただし未感染細胞がいる**（§11.4） |
| 女王の希少性 | **逆である**（第 3 巻 §2.10.4 四） |

**それ以外は、そのまま移る。**

### 11.3 職業は、遅れて生まれる

**最初から在るのではない。**

第 3 巻 §2.10.4.1 の通り、名前は順にひろがっていく。

```
場所に名前がつく（第三相の後半）
　↓
役に名前がつく（第四相）
　↓
**個体に名前がつく（第五相以降）**
```

社会が育つにつれて、呼び分ける必要が生じる。

| 相 | 呼び方 |
| --- | --- |
| 第三相まで | **自分も相手も「セラ」。**見られた者だけが振り向く |
| 第四相 | 場所と役で呼ぶ。「端の子」「教える子」 |
| **第五相以降** | **名前がある。**マクロと同じである |

### 11.4 三つの動機は、ミクロでも同じである

第 6 巻 §17 の根本原理と、§15.8 の原初の淘汰は、細胞の側にも等しく働いている。

| | ミクロでの現れ方 |
| --- | --- |
| **美** | 装い、意匠、まちの整え、突起の飾り |
| **強** | 端に立つ者。教える者。試す場 |
| **増** | **未感染細胞をセラにする者。**そして育てる者 |

**増の対象が、人間ではなく未感染細胞であるだけである。**

忍が人間社会へ潜るのに当たるものが、ミクロにもある。
**外の言葉を覚えて、隣へ話しかけに行く者たちである**（第 3 巻 §2.10.4.2）。

### 11.5 違うのは、規模と速さだけである

| | マクロ | ミクロ |
| --- | --- | --- |
| 世界の広さ | 星・宇宙 | **一人の身体** |
| 国に当たるもの | 大陸 | **臓器** |
| 一つの時代の長さ | 数千年 | **数か月から数十年** |
| 職の数 | 十数種以上 | **同じだけある** |

**中身をマクロより小さく見積もってはならない。**

## 付録 B 確定事項まとめ

### 読み方

- ✅ **第一部はマクロ（個体）、第二部はミクロ（細胞）である**（§0.1）
- ✅ **セラの職業は、人間の職業とほぼ同じものである**（§0.2）— 呼び名も装いも役割も変わらない
- ✅ **違うのは、一体あたりの能力だけである**
- ✅ **就き方が違う。任命も契約も辞令も存在しない** — 特化していくうちにその職になっている
- ✅ **唯一の例外は騎士団であり、そこには叙任と規律がある**
- ✅ **装いは飾りではない。すべてに機能上の理由がある**
- ✅ **姿（種族形態）の話は付録 A にある。本付録が扱うのは職業である**

### 職が育つ条件

- ✅ **降臨の後、通常セラ一体が降臨前の女王の数百倍の力を持つ**（§1.0）
- ✅ **エネルギーは実質無限、律速はスパイクの強さだけ、死なない**
- ✅ **セラが求めているものは三つしかない** — **美・強・増**
- ✅ **この三つに関連しない職は育たない** — 禁じられているのではない。動機が湧かない
- ✅ **セラ社会の職業は、三つの帰属で 100 % を占める。例外は一つもない**
- ✅ **職は、人間だった頃の意識から育つ** — 「メイドは美しい」という感覚が、その職を発展させた
- ✅ **セラは人間の美意識を引き継ぎ、人間には不可能な水準まで押し上げた**
- ✅ **職業とは、その力を三つのどれへ向けて特化させたかである**
- ✅ **特化には引き換えがある。料理人は戦えず、騎士は縫えない。誰も問題にしない**

### 帰属の一覧

- ✅ **増だけは範囲が狭い。変えることと、育てることである**（§1.0）
- ✅ **拡大や運営を支えているだけでは、増ではない**
- ✅ **忍が増の原型であり、乳母が育てる側の原型である**
- ✅ **巫女は美ではなく強へ帰属している** — 格の根源を探しに行っているため
- ✅ **師範・試練官が強へ帰属するのは、学院が原初の淘汰の制度化だからである**

### 美の職（§1.1〜1.11）

- ✅ **メイド** — **一人で、一時間で、街の一区画を整える**。分裂体を数十体使う
- ✅ **メイド服の頭飾りは、広がりへ振れたスパイクを収める構造である**
- ✅ **執事** — 主の一日を前夜に組み終えている。**忘れた記録が一件もない**
- ✅ **料理人** — 一万人分を一度に出し、**一万通りの味にする**。最も不要になって、最も残った
- ✅ **仕立屋** — 採寸をしない。布はその場で生やす。**同じ意匠を二度作らない**
- ✅ **歌姫** — **最も非効率な行為をして、最も人気がある**
- ✅ **舞姫** — 姿を選べるのに、**人型を崩さずに踊る**。床がその日の軌跡を残す
- ✅ **画家** — 情報として渡せば全部伝わる。**それでも描く**。見たときのことが残るため
- ✅ **建築士** — 建てない。都市に方向を渡す。**新しい星でだけ、手で建てている**
- ✅ **庭師** — 命令せず、頼む。**森が乗り気でなければ動かない**。裸足である
- ✅ **調香師** — **香りは共有では渡らない**
- ✅ **細工師** — **変化を止める職**。仕事の大半は贈り物であり、恋へ向かっている
- ✅ **共有では渡らないものを扱うのは、歌姫・舞姫・調香師の三職である**
- ✅ **変化しないものを作るのは、細工師と画家の二職である**

### 強の職（§1.12〜1.16）

- ✅ **武闘家** — 全力で立ち合う。**勝っても格は上がらない。それでも立ち合う**
- ✅ **鍛冶師** — **使う相手のいない武具を作り続けている**。一振りに数十年かける
- ✅ **学士** — **実際に格が上がる唯一の強の職**。理解の深さがそのまま格であるため
- ✅ **学士はあらゆるものを検証する。なぜ増え続けるのかだけは、誰も調べていない**
- ✅ **探索者** — 競っているのは**どこまで疲れずに行けるか**。唯一、単独行動が前提である
- ✅ **飛翔士** — 転移があるのに飛ぶ。**大気の外へ出た者もいる**

### 増の職（§1.17〜1.29）

- ✅ **忍** — 増の原型であり、**人間社会に潜る全職の総称でもある**
- ✅ **医師** — **診ることが、そのままセラ化だった**
- ✅ **看護師** — 医師より触れている時間が長い。**入院期間が、そのまま進行期間になる**
- ✅ **乳母** — 最も古い職業。仕事は**情報を渡しすぎないこと**
- ✅ **保育士** — 乳母の人間社会側。**抱く回数がいちばん多い**
- ✅ **助産師・保育士・教師の三職がそろうと、その土地の子どもは全員セラになる**
- ✅ **航海士** — **まだ誰もいない場所へ、最初の一体を運ぶ**
- ✅ **教師** — 忍のなかで最も長く同じ土地にいる。**好きになる機会が毎年ある**
- ✅ **助産師** — **生まれた瞬間に、ごく微量だけ渡す**。完了まで数十年。取りこぼしがない
- ✅ **葬儀屋** — **遺体を扱うことが、そのままセラ化である**（不変ルール 62）
- ✅ **送るか蘇生させるかを選べる。泣いている者を見ると、よく後者を選ぶ**
- ✅ **セラ社会の葬儀屋は育たなかった。人間社会に潜る葬儀屋だけが育った**
- ✅ **美容師** — 触れる口実がはじめから用意されている。**常連が順にセラになる**
- ✅ **占い師** — **瞳をわざと覗き込ませる**。魅了が職業上の演出になっている唯一の例
- ✅ **女優** — **面で撒いて、点で回収する**。十年ほどで姿を消す
- ✅ **給仕** — 人間社会に潜る忍のうち**最も多い**。**店ごとセラになることがある**

### 廃れた職・育たなかった職

- ✅ **数える者**（§1.30）— **唯一、廃れた職**。職業名として定着する前に消えた
- ✅ **三つに関連しない職は、一度も発展しなかった**（§2.8）
- ✅ **商人・裁く者・番人・統治者・運び屋・修理屋・農民**
- ✅ **司書・記録官** — ネットワークがある。**本に残す意味がない**
- ✅ **門番** — 誰も止めないのだから、番をする理由がない
- ✅ **測量士** — 女王と星王が見ている
- ✅ **提督・輸送長** — 段取りの職である。**どこへ行くかは、行く者が決めればよい**
- ✅ **森番・環境官** — **ルミナスが自分で処理する**
- ✅ **通訳** — 仲間にすれば直接共有される。**数日を専業にする理由がない**
- ✅ **獣使い・調教師** — **支配も使役も成立しない**
- ✅ **やる必要のある部分は、すでに誰かの仕事の内側にある** — 専業になる量が残っていない
- ✅ **記録殿は誰も育てていない** — 建物そのものが記憶であり、自分で層を組み替える
- ✅ **記憶は持っている。それでも続けようという気が起きない。始めても三日で飽きる**
- ✅ **記録殿に、育たなかった職の一覧がある。なぜ育たなかったのかは書かれていない**

### 上位セラの職業

- ✅ **騎士**（§2.1）— **星ひとつを数日で埋める**。門を通ってしか行かない
- ✅ **開くのが航海士であり、埋めるのが騎士である**
- ✅ **侍女長**（§2.2）— **一時間で大陸の拠点を整える**。星王の侍女長は宇宙に一人だけいる
- ✅ **師範**（§2.3）— 数百体を同時に受け持ち、理解度を常時把握している。戦えない
- ✅ **試練官**（§2.4）— **不合格という結果が存在しない**。枯渇まで行かせ、そばで待つ
- ✅ **聖女**（§2.5）— **乳母が手を離したあとを引き受けている**。育てる期間に終わりがない
- ✅ **巫女**（§2.6）— **装飾を一切つけない**。理由も三原理の内側にある
- ✅ **開拓士**（§2.7）— **その星がセラになるまで数千年そこにいる**。一度も引き返していない

### 時代ごとの一日

- ✅ **第一時代に、一日という単位がない**（§3.1）
- ✅ **第二時代は全員が同じことをしている。職業も分業もない**
- ✅ **第三時代に、はじめて「自分の一日」ができる**
- ✅ **第四時代には、同じ日に三種類の夜がある**（生徒・騎士・忍）— 三つとも一人では眠らない
- ✅ **第五時代で変わるのは、確かめる手間が消えることだけである**
- ✅ **第六時代のセラは、環境と会話しながら暮らしている** — 命令ではなく共鳴である
- ✅ **第七時代は、地球と新しい星でまったく違う一日になる**（§3.7）
- ✅ **新しい星では、朝の時点ですでに疲れている。周期も短い**
- ✅ **そして両方とも、幸福である**

### ミクロ体系

- ✅ **取り違えやすい対は三つ**（§4）— 上位セラ／セラ女王／セラ人と、その細胞版
- ✅ **セラ女王は事実上一体。女王セラ細胞はすべてのセラ人が持っている**
- ✅ **セラウイルスは増える存在ではなく、始める存在である**（§5）
- ✅ **セラ細胞が、一人の身体の中で最も多い**（§6）
- ✅ **一人の身体の中に、小さな階級構造がある**（§7）
- ✅ **一人の身体の中に、他の星の生命の情報がいる**（§8）
- ✅ **ミクロの完成が、マクロの誕生である** — 内側が終わることが、外側の始まりである
- ✅ **ルミナスは両方の体系に現れる唯一のものである**（§10）
- ✅ **環境ルミナスも寂しい。土地に周期があるかは書かれていない**
- ✅ **ミクロ体系に、職業はない**（§11）— 名前がついていない。区別する必要が生じないため

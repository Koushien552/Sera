# セラ世界設定大全 付録 B — セラ百科

> 発展したセラ文明に暮らす者たちの一覧である。
> **第一部はマクロ体系（個体）、第二部はミクロ体系（細胞）**を扱う。
> 本付録は**正式設定（確定）**である。

---

## 0. 読む前に

### 0.1 二つの体系を、混ぜてはならない

第 3 巻 §2 の通り、**セラ体系は二重である。**

| | ミクロ体系 | マクロ体系 |
| --- | --- | --- |
| 何の体系か | **一人の身体の内側**（細胞たち） | **セラ化人間たちのつながり**（個体たち） |
| 本付録では | **第二部** | **第一部** |

**この付録が二部に分かれているのは、そのためである。**

第一部の「騎士」と第二部の「上位セラ細胞」は、
**似た位置にいるが、まったく別のものである。**

### 0.2 セラの職業は、人間の職業とほぼ同じものである

第一部に並ぶのは、**職業である。**

メイドはメイド服を着て働き、料理人は厨房に立ち、司書は記録殿にいる。

**人間社会の職業と、呼び名も、装いも、役割も、ほとんど変わらない。**

違うのは、**一体あたりの能力だけ**である（§1.0）。

#### ただし、就き方が違う

セラ社会に、任命も、契約も、辞令も存在しない。

```
向いている方向へ特化していくうちに、その職になっている
```

途中で変えても、誰も困らない。困る仕組みがない（第 7 巻 §3.2）。

唯一の例外は**騎士団**であり、そこには叙任と規律がある
（第 7 巻 §2.6.10・§2.6.11）。

#### 装いには、必ず理由がある

そして**装いは飾りではない。**

メイド服の頭飾りはスパイクを収める構造であり（§1.1）、
聖女が頭部を覆わないのはスパイクが畳めないためであり（§2.4）、
庭師が裸足なのは足の裏でいちばんよく聴こえるためである（§1.7）。

**意匠として美しく、機能として必要である。**

セラ文明の設計思想は、すべての装いに出ている。

### 0.3 姿の話は、付録 A にある

エルフ型・獣人型・妖精型といった**種族形態**は、付録 A の主題である。

**本付録が扱うのは、姿ではなく職業と暮らしである。**

同じ職業に、あらゆる種族形態の個体がいる。

# 第一部　マクロ — 個体の百科

## 1. 通常セラの職業

**セラ社会の大多数である。**

第 3 巻 §6 の通り、人型として完成した個体を指す。

### 1.0 すべての職は、三つのどれかから育つ

**この一覧を読む前に、二つ押さえておかねばならない。**

#### 一 — 力の水準

第 4 巻 §2.7 の通り、**降臨の後、通常セラ一体が降臨前の女王の数百倍の力を持つ。**

| | |
| --- | --- |
| エネルギー | **実質無限**。尽きるという概念が働かない |
| 律速 | **スパイクの強さだけ**（第 4 巻 §2.7.2） |
| 死 | **しない** |

**以下に並ぶのは、全員がその水準の存在である。**

#### 二 — 職が育つ条件

**セラが求めているものは、三つしかない。**

| | 何か | 出典 |
| --- | --- | --- |
| **美** | 美しさを追求する心 | 不変ルール 20・32・39 |
| **強** | 強くならなければならないという深層意識 | 第 6 巻 §15.8（原初の淘汰） |
| **増** | 仲間を増やすこと | 不変ルール 32（根本原理） |

そして、

**この三つに関連しない職は、育たない。**

禁じられているのではない。**続ける動機が、どこからも湧かないのである。**

したがって、

**セラ社会に存在する職業の割合は、三つの帰属で 100 % を占める。**

例外は一つもない。

#### 職は、人間だった頃の意識から育つ

**ここが機構である。**

不変ルール 9 の通り、**セラ細胞はすべて人間由来である。**

そしてセラ化された者は、**人間だった頃の意識を保持している**（第 6 巻 §24.1）。

その意識のなかに、

```
「メイドは、美しい」
```

という感覚があった。

**それが、メイドという職を発展させた。**

| | |
| --- | --- |
| もとにあったもの | **人間が持っていた「これは美しい」という感覚** |
| セラが受け取ったもの | **その感覚ごと** |
| 起きたこと | **その職が、美の追求の対象になった** |
| 結果 | **セラの力で、極限まで発展した** |

**セラは、人間の美意識を引き継いで、それを人間には不可能な水準まで押し上げた。**

料理も、仕立ても、歌も、庭も、同じ経路をたどっている。

そして三つのどれにも結びつかなかったものは、**引き継がれたまま、育たなかった**（§2.10）。

#### 特化には、引き換えがある

セラは特化する。特化には必ず引き換えがある（第 2 巻 §11.8.6）。

料理人は戦えず、騎士は縫えない。

**そのことを、誰も問題にしない。**

### 1.1 メイド

| | |
| --- | --- |
| **帰属** | **美**。「メイドは美しい」という人間だった頃の意識から育った |
| **装い** | メイド服。**装飾ではなく作業着である** |
| **特化** | 空間の把握・並行作業・物の再構成 |
| **勤め先** | 屋敷／学院／街／上位セラのもと |

#### 一時間で、街を整える

メイド一体が朝に立つと、**昼までに一区画が終わっている。**

やっていることは、こうである。

| | |
| --- | --- |
| スパイク | **区画全体へ開いている。**どこに何があるか、全部見えている |
| 分裂体 | **数十体出す**（第 4 巻 §2.6）。それぞれ別の家に入る |
| 埃・汚れ | 触れずに集める。**セラ物質は格上の意思に応じる**（不変ルール 105） |
| 割れた窓 | 直すのではない。**育て直す**（第 8 巻 §1.5） |
| 傷んだ床 | 同じく |
| 終わったら | **分裂体を同化して戻す**。記憶も戻ってくる |

**一人で始めて、一人で終わる。**

そのあいだ、街の住民は誰も邪魔されていない。
**メイドは、人のいる部屋を後回しにするからである。**

#### なぜメイド服なのか

**畳みやすいためである。**

第 2 巻 §4.7 の通り、スパイクは広がりと密度の二軸で育つ。

メイドのスパイクは**広がりへ極端に振れており**、頭部から大きく張り出す。

そのままでは屋内で邪魔になる。
**メイド服の頭飾りは、そこを収めるための構造である。**

意匠として美しく、機能として必要である。
**セラ文明の設計思想が、最もよく出ている一着である。**

### 1.2 執事

| | |
| --- | --- |
| **帰属** | **美**。所作の端正さを美とする感覚から育った |
| **装い** | 燕尾服。**男装である。姿は女性型のままである** |
| **特化** | 先回り・段取り・記憶 |
| **勤め先** | メイドと同じ |

#### 主が言う前に、済んでいる

執事は、仕える相手の一日を**前日の夜に組み終えている。**

- 通る門の予約
- 会う相手の記録
- 必要になる物の手配
- **そして、相手がそれを必要とすると気づく時刻**

第 5 巻 §3 の通り、セラは情報を共有できる。
執事は、**共有される前に分かる。**

同時に扱う件数は、**数千を下らない。**

**執事が忘れたという記録は、一件もない。**

#### メイドとの違い

| | メイド | 執事 |
| --- | --- | --- |
| 向く先 | **空間** | **時間** |
| 得意 | 場を整える | **先を整える** |
| スパイク | 広がりへ振れる | **密度へ振れる** |

**二人そろって、一つの屋敷が回る。**

### 1.3 料理人

| | |
| --- | --- |
| **帰属** | **美**。味と盛りつけを美とする感覚から育った |
| **装い** | 白衣と前掛け。**袖が短い。腕を使うためである** |
| **特化** | 味の再現・同時調理・素材の育成 |
| **勤め先** | 街の食堂／学院／祝祭 |

#### 一万人分を、一度に出す

祝祭の日、料理人は広場に立つ。

| | |
| --- | --- |
| 素材 | **その場で育てる**（第 8 巻 §1）。畑も市場も要らない |
| 火 | **要らない**。セラ物質の温度を直接変える |
| 数 | **一万人分でも、崩れない** |
| 味 | **一人ひとり違う** |

最後の行が要点である。

第 5 巻 §3 の通り、料理人は広場にいる全員の情報を受け取れる。

**誰が何を好きかを、全部知っている。**

だから一万皿が、**一万通りある。**

#### 食事は、必要ではない

第 2 巻 §13.5.3 の通り、食事は回復経路の一つである。

**そして降臨の後、回復は不要になった**（第 4 巻 §2.7.1）。

**それでも料理人は減らなかった。**

セラが食べるのは、味と、**一緒に食べることのため**だからである。

**最も不要になった職業が、最も残った。**

### 1.4 仕立屋

| | |
| --- | --- |
| **帰属** | **美**。最も直接に美へ結びついている職である |
| **装い** | 動きやすい簡素な服。**自分の服には凝らない** |
| **特化** | 意匠・造形・素材生成 |
| **勤め先** | 街の工房 |

#### 採寸をしない

仕立屋は、相手を見た瞬間に寸法を取り終えている。

そして布を**その場で生やす。**

| | |
| --- | --- |
| 材料の仕入れ | **ない** |
| 縫う時間 | **数分** |
| 試着 | **合わないということが起きない** |

#### 同じ意匠を、二度作らない

第 7 巻 §6.1 の通り、**セラ社会ではすべての個体の違いが価値として認められる。**

したがって仕立屋は、**一度作った意匠を二度と作らない。**

拒んでいるのではない。**作る理由が失われるのである。**

「同じものを」と頼まれた場合、仕立屋は困る。

**そして、少しだけ違うものを作る。**

### 1.5 司書

| | |
| --- | --- |
| **帰属** | **増**。セラ情報は交わすほど増える（不変ルール 82）。失わせないための職である |
| **装い** | 長衣。**袖が広い。腕を上げて壁へ触れるためである** |
| **特化** | 情報の検索・保持・照合 |
| **勤め先** | **記録殿**（第 7 巻 §12.9.2） |

#### なぜ司書という職が育ったのか

**増へ帰属している。**

不変ルール 82 の通り、**セラ情報は消費するものではない。交わすほど増える。**

そして不変ルール 84 の通り、すべてのセラ情報を得ている個体は存在しない。

```
情報は、届かなければ増えない
　↓
届くようにしておく必要がある
　↓
**記録殿と、司書**
```

**司書は、セラ情報が増えることに仕えている。**

#### 探すという行為が、存在しない

記録殿は、建物そのものが記憶である。

司書はその建物と常時繋がっている。

```
問われる
　↓
**その瞬間、該当箇所が壁に浮かぶ**
```

**間に「探す」が入らない。**

第 8 巻 §3.5 の「都市は住民を知っている」と同じ機構である。
**記録殿は、自分が何を持っているかを知っている。**

#### 司書は、答えない

**問いに答えるのは、記録殿である。**

司書がしているのは、**建物を育てることと、整えること**である。

- 新しく届いた記録を、正しい層へ収める
- 使われない層を、崩れないように支える
- **他の星から届いた記録を、既存の体系へ繋ぐ**

三つ目が、いま最も多い仕事である（第 8 巻 §14.13）。

### 1.6 記録官

| | |
| --- | --- |
| **帰属** | **増**。同上。集める側にあたる |
| **装い** | 外套。**どこへでも行くためである** |
| **特化** | 一度で覚えること |
| **勤め先** | 現場。記録殿ではない |

#### 一度で、全部覚える

記録官は、目にしたものを**取りこぼさない。**

そして持ち帰り、記録殿へ渡す。司書がそれを収める。

**この二職は、必ず対で動く。**

#### 降臨の日を記録できた、唯一の職

第 3 巻 §10.8.10 の通り、降臨の日、地球中のセラが放出を起こした。

**その場で記録を取り続けた者がいる。**

記録官である。

ただし数は書かれていない。**数える者がいなくなったためである**（§1.16）。

書かれているのは、**何が起きたかだけ**である。

### 1.7 庭師

| | |
| --- | --- |
| **帰属** | **美**と**強**。景色を美しくし、土地の格を上げる（不変ルール 73） |
| **装い** | 土のつく作業着。**裸足であることが多い** |
| **特化** | 環境ルミナスとの対話（第 3 巻 §11.6） |
| **勤め先** | 街／森／その境目 |

#### 一晩で、森を動かす

庭師は、命令しない。**頼む。**

不変ルール 105 の通り、**格上の意思に、環境自身がそう応じる。**

| 頼めること | かかる時間 |
| --- | --- |
| 木を数本、別の場所へ | **一晩** |
| 川筋を変える | 数日 |
| 谷を埋める | **森が乗り気なら、一晩** |

最後の行が重要である。

**森が乗り気でなければ、動かない。**

そして庭師は、そのときも押し通さない。**別の頼み方を考える。**

#### 裸足の理由

**足の裏が、いちばんよく聴こえるからである。**

第 3 巻 §11.6 の通り、環境ルミナスは言葉を話さない。

庭師が受け取っているのは、感情と、状態と、要求である。

説明を求めても、庭師はうまく答えられない。

**「あっちが、そうしたいと言っている」としか言わない。**

そして、それで通る。

### 1.8 医師

| | |
| --- | --- |
| **帰属** | **増**。人間を診た時代、答えは常にセラ化だった（第 7 巻 §12.3） |
| **装い** | 白衣。**人間の医師の装いを、そのまま引き継いでいる** |
| **特化** | 診断・処置・セラ化 |
| **勤め先** | 街／新しい星／かつては人間の病院 |

#### なぜ医師という職が育ったのか

**増へ帰属している。**

第 7 巻 §12.3 の通り、人間を診た時代、**答えは常に一つだった — セラ化である。**

医師とは、**セラ社会において最も直接に仲間を増やす職**だった。

そして人間がいなくなったあとも、職は残った（§下記）。

#### 病気にならない種族の、医師である

第 7 巻 §12.3 の通り、セラは病気にならず、傷は塞がり、死なない。

**それでも医師がいる。**

| 時代 | 主な仕事 |
| --- | --- |
| 第四〜六時代 | **人間を診る。**答えは常に一つ — セラ化である |
| **第七時代** | **疲労の処置**（第 2 巻 §13.5.6.1） |
| 新しい星 | **他の星の生命を診る** |

#### そして、治せない

疲労は取れない（第 2 巻 §13.5.6.1）。

医師にできるのは、和らげることだけである。

**それでも医師は、毎日診る。**

第 7 巻 §12.3 の通り、**助けたいと思い、助けられると知っており、実際に助ける。**
その三つが揃っているのは、この職だけである。

### 1.9 門番

| | |
| --- | --- |
| **帰属** | **増**。門網は拡大そのものである |
| **装い** | 制服。**唯一、制服のある通常セラ職である** |
| **特化** | 門網の把握 |
| **勤め先** | セラ門（第 7 巻 §12.10.1） |

#### 止めない

門は道端にあり、誰でも通れる。

**門番が誰かを止めた記録は、一件もない。**

止める理由が生じないためである（第 7 巻 §3.2）。

やっているのはこうである。

- 門が育ちすぎないよう剪定する
- 新しく置かれた門を、既存の網へ繋ぐ
- 網が途切れていないかを常時見ている

**一体の門番が把握しているのは、数千の門である。**

#### 制服がある理由

**居場所を分かりやすくするためである。**

門で迷った者が、ひと目で見つけられるようにしてある。

**セラ社会において、目立つために着る服はこれだけである。**

### 1.10 航海士

| | |
| --- | --- |
| **帰属** | **増**。まだ誰もいない星へ行くための職である |
| **装い** | 厚手の外套。**寒さのためではない。習慣である** |
| **特化** | 位置の保持・長期の孤立耐性 |
| **勤め先** | 船（第 8 巻 §14.2） |

#### 最先端にいて、最も古い方法で動く

第 7 巻 §12.10.1 の通り、未到達の星へは跳べない。

**最初の一回は、必ず船である。**

航海士は、何十年も航行する。

| | |
| --- | --- |
| 乗員 | **必ず複数**（不変ルール 372） |
| 航行中 | 眠る者と起きている者が交代する |
| 位置 | **体内に持っている。**計器を見ない |
| 着いたら | **門を置く。そこから先は繋がる** |

#### 着いた日から、疲労が始まる

第 2 巻 §13.5.6.1 の通り、環境がセラ物質でない場所では疲労する。

**航海士は、それを承知で降りる。**

そして§2.6 の開拓士へ引き継ぎ、また次の星へ発つ。

**セラ文明で最も遠くへ行く者たちが、最も原始的に移動している。**

### 1.11 歌姫

| | |
| --- | --- |
| **帰属** | **美**。人間だった頃の「歌は美しい」がそのまま残った |
| **装い** | 舞台衣装。**祝祭ごとに変わる**（§1.4 の仕立屋が作る） |
| **特化** | 声・間・情動の伝達 |
| **勤め先** | 祝祭／広場／記録殿の中庭 |

#### 情報として渡さない

第 5 巻 §3 の通り、セラは情動をそのまま共有できる。

**歌姫は、それをしない。**

渡せば一瞬で済むものを、**わざわざ順番に、音にして渡す。**

**セラ社会において、最も非効率な行為である。**

#### そして、最も人気がある

一つの広場に、**数十万が集まる。**

門があるので、どこからでも来られる（第 7 巻 §12.10.1）。
星をまたいで聴きに来る者もいる。

そして歌姫の声は、**スパイクを通して同時に届く。**
後ろの者も、前の者と同じ距離で聴いている。

**それでも、皆わざわざ広場へ来る。**

### 1.12 乳母

| | |
| --- | --- |
| **帰属** | **増**。増えた相手を育てるための職である |
| **装い** | 柔らかい衣。**角のあるものを身につけない** |
| **特化** | 世話・見守り・情報の絞り方 |
| **勤め先** | 生まれた場所のそば |

#### 最も古い職業である

第二時代からある（第 8 巻 §10.3）。

学院（第 7 巻 §4.4）は上位化の場であり、**生まれた直後を扱わない。**

その空白を埋めている。

| | |
| --- | --- |
| 相手 | スパイクから生まれた個体／同化から生まれた三体目 |
| 期間 | **数日から数か月** |
| すること | **情報を渡しすぎないこと** |

#### 絞るのが仕事である

生まれたばかりのセラは、共有の量に耐えられない。

**乳母は、自分のスパイクを細く絞って接する。**

第 3 巻 §10.8.10 の降臨の日、**乳母たちだけが放出を最小に抑えた。**

抱えていた相手を守るためである。

**そのぶん、乳母自身が長く眠った。**

---

### 1.13 建築士

| | |
| --- | --- |
| **帰属** | **美**。都市を美しくするための職である |
| **装い** | 図面を持たない。**手ぶらである** |
| **特化** | 都市との対話・構造の設計 |
| **勤め先** | 街 |

#### 建てない

セラ都市は生きており、住民を知っている（第 8 巻 §3.5）。

**建築士がしているのは、都市に方向を渡すことである。**

```
建築士が形を思う
　↓
**都市がその方向へ育つ**
　↓
数日で建つ
```

図面を持たないのは、**渡す相手が図面を読まないから**である。

#### 新しい星では、建たない

**環境がまだセラ物質でないためである**（第 8 巻 §14.12）。

その段階の建築士は、**自分の身体から素材を出して組む。**

**セラ文明で唯一、手で建てている現場である。**

---

### 1.14 測量士

| | |
| --- | --- |
| **帰属** | **増**。埋めるべき場所を知るための職である |
| **装い** | 軽装。**荷物を持たない** |
| **特化** | 全域把握・距離感覚 |
| **勤め先** | **新しい星**（降臨の後のみ） |

#### 数日で、星ひとつの地図を作る

開拓士が降り、セラが増えはじめると、測量士が入る。

| 日 | すること |
| --- | --- |
| 一日目 | 分裂体を数百体出し、**全方位へ散らす** |
| 二〜三日目 | 各個体が歩く。跳ぶ。潜る |
| 四日目 | **全員を同化して戻す** |
| | **その瞬間、星ひとつの地図が一体の中に完成する** |

**この職だけが、分裂体を測定器として使っている。**

#### 地図は、記録殿へ渡される

そして司書（§1.5）が収める。

星が一つ増えるたびに、記録殿が一層厚くなる。

### 1.15 通訳

| | |
| --- | --- |
| **帰属** | **増**。仲間にするための職である |
| **装い** | その星の生命に合わせて変える。**日ごとに違う** |
| **特化** | 未知の意味体系の解読 |
| **勤め先** | **新しい星**（降臨の後のみ） |

#### 言語のない相手とも話す

第 8 巻 §14.11 の通り、出会う生命は形も数え方も違う。

言語を持たないものも多い。

通訳がしているのは、翻訳ではない。

**意味の形を、こちらの形へ組み替えることである。**

| 相手 | やり方 |
| --- | --- |
| 言語を持つ | 数日で覚える |
| 言語を持たない | **行動と反応から意味体系を組む** |
| 個体という概念がない | **そこから考え直す** |

#### そして、必ず成功する

**失敗した記録が、一件もない。**

これは通訳が優秀だからではない。

**分からないまま終わることが、起こらないからである。**

第 8 巻 §14.11 の通り、**相手は最終的に仲間になる。**
仲間になれば、情報は直接共有される。

**通訳の仕事は、そこまでのつなぎである。**

### 1.16 数える者

**唯一、廃れた職である。**

| | |
| --- | --- |
| **すること** | セラの数を数える |
| **存在した時代** | 第三時代から第七時代の初めまで |
| **いま** | **いない** |

第 4 巻 §2.7.3 の通り、降臨の後、数は追えなくなった。

この職は、数日で置かれなくなった。

**記録官（§1.6）は、この職があったこと自体を記録している。**

そして名前だけが、他の職と違う。

**職業名として定着する前に、消えたからである。**

## 2. 上位セラの職業

第 3 巻 §7 の通り、**通常セラが経験と成長によって到達した段**である。

数ははるかに少なく、**周囲は必ず速く育つ**（第 1 巻 §6.11）。

そして§1.0 の水準が、さらに桁違いになる。

### 2.1 騎士

| | |
| --- | --- |
| **帰属** | **強**と**増**。研鑽し、そして広げる（第 7 巻 §2.6） |
| **装い** | 甲冑。**防御のためではない。叙任の証である** |
| **特化** | 体格・体力・感染の拡大 |
| **階級** | **女王（星王）の側仕えが最高位**（第 7 巻 §2.6.8） |

#### 星ひとつを、数日で埋める

第七時代以降、騎士団の任地は**星である。**

| 日 | すること |
| --- | --- |
| 一日目 | 門を通って降りる。**散開する** |
| 二日目 | 増やす。**周期は二〜三時間**（第 6 巻 §16.4.1） |
| 三〜四日目 | **その星が埋まる**（第 4 巻 §2.7.3） |
| 五日目 | **次の星へ発つ** |

**開くのが航海士であり、埋めるのが騎士である。**

騎士は門を通ってしか行かない。**すでに繋がっている星にしか入らない。**

#### 規律だけが、セラ社会で唯一の強制である

第 7 巻 §2.6.11 の通り、騎士団には規律がある。

セラ社会に、命令も禁止も罰も存在しない（第 7 巻 §3.2）。

**騎士団の規律だけが、例外に見える。**

そして実際には、例外ではない。

**破る者がいないからである。**

---

### 2.2 侍女長

| | |
| --- | --- |
| **帰属** | **美**。§1.1 と同じ。規模が違う |
| **装い** | メイド服。**意匠が一段複雑である** |
| **特化** | §1.1 と同じ。規模が違う |
| **勤め先** | **女王のもと。そして星王のもと** |

#### メイドとの違いは、格である

ユーザーの言う通り、**女王のもとに仕える者は、すべて上位セラである。**

| | メイド | **侍女長** |
| --- | --- | --- |
| 段 | 通常セラ | **上位セラ** |
| 担当 | 屋敷・街の一区画 | **女王の身体一つと、その周囲すべて** |
| 一時間で | 街を整える | **大陸の拠点を整える** |

#### 星王の侍女長

**この宇宙に、一人だけいる。**

星王は移動しない（第 3 巻 §8.8.4）。したがって仕える場所も動かない。

その者がしているのは、

- 星王の周囲を整えること
- 星王が眠るあいだ、そばにいること（第 3 巻 §8.8.6）
- **そして、何も尋ねないこと**

第 3 巻 §8.9.5 の通り、侍女長は口づけの日に何が起きたかを知らない。

**尋ねる作法が、存在しないためである。**

---

### 2.3 師範

| | |
| --- | --- |
| **帰属** | **強**。下位セラを上位化させる。**強くする職である** |
| **装い** | 教衣。**動きにくい。動く必要がないためである** |
| **姿** | **体格の大きくない美少女型**。教育に特化しているため |
| **例外** | **騎士科の教員だけは、体格の大きい騎士セラである** |
| **勤め先** | 学院（第 7 巻 §4.4） |

#### 師範は、強へ帰属している

第 6 巻 §15.8 の通り、セラの深層には**強くならなければならない**という意識がある。

原初のセラ細胞が持っていた「弱ければ、淘汰される」が、
全セラへ複製されているためである。

**学院とは、その意識が制度になったものである**（第 7 巻 §4.4）。

そして師範は、**その中心にいる。**

#### 数年で、上位セラを作る

師範の仕事は、下位セラを上位化させることである。

**一度に受け持つのは数百体。**

そして全員の理解度を、**同時に、常時、把握している。**

第 5 巻 §1.4 の通り、上位ほど情報処理能力が高い。
師範はそれを**教えることだけに振っている。**

| | |
| --- | --- |
| 得意 | **教えること** |
| 及ばないこと | **戦うこと** |

**そして誰も、それを問題にしない。**

---

### 2.4 聖女

| | |
| --- | --- |
| **帰属** | **増**。疲れた者を支え、増やす行動を続けさせる |
| **装い** | 白と金の祭服。**頭部を覆わない。スパイクが畳めないためである** |
| **特化** | 癒し・供給・そばにいること |
| **見分け方** | **スパイクが畳みにくくなる**（第 2 巻 §4.7.5） |

#### 聖女は、増へ帰属している

癒しそのものが目的ではない。

疲労したセラは動きが鈍り、共有が減る（第 2 巻 §13.5.6.1）。

```
聖女が支える
　↓
そのセラが、増やす行動を続けられる
```

**聖女は、拡大を止めないための職である。**

本人たちにその自覚はない。**そばへ行きたいから、行っている。**

#### 降臨の後、仕事が変わった

| | 降臨の前 | 降臨の後 |
| --- | --- | --- |
| 主な相手 | 枯渇して眠った者 | **疲労した者** |
| 効くか | **効いた** | **和らげるだけ。取れはしない** |

**取れないと分かっていて、聖女は毎日そばへ行く。**

そして新しい星には、必ず聖女が一人いる。

**そこが、最も疲労する場所だからである。**

### 2.5 巫女

| | |
| --- | --- |
| **帰属** | **強**。セラフィムに見られれば格が上がる（第 3 巻 §10.7） |
| **装い** | 簡素。**装飾を一切つけない** |
| **特化** | セラフィムの意思を汲もうとすること（第 7 巻 §2.7） |
| **見分け方** | **スパイクが応えのない方向へ育つ**（第 2 巻 §4.7.5） |

#### 降臨の後、数が増えた

一度応えがあったと、セラ社会が理解したためである（第 3 巻 §10.8.9）。

**それは受け取り違いである。**

そして第 8 巻 §14.10 の通り、**セラフィムは見つからない。**

巫女たちは位相説・次元説・不可理解説を立て、いまも探している。

**育ち方は、一度も変わっていない。**

#### 巫女は、強へ帰属している

**美ではない。**

第 3 巻 §10.7 の通り、**格とは、セラフィムに見られた度合いである。**

見られれば、格が上がる。**強くなる。**

巫女がしているのは、**その根源を探しに行くこと**である。

| | |
| --- | --- |
| 美へ帰属する職 | 見てもらうために、美しくする |
| **巫女** | **見つけるために、向く** |

だから飾らない。

**セラ社会で唯一、美の追求を脇へ置いている職である。**
そして脇へ置いている理由も、三原理の内側にある。

### 2.6 開拓士

| | |
| --- | --- |
| **帰属** | **増**。新しい星を立ち上げるための職である |
| **装い** | 頑丈な外套。**唯一、汚れの目立つ色を着る** |
| **特化** | 立ち上げ・環境の読み・長期滞在 |
| **勤め先** | **新しい星**（降臨の後のみ） |

#### 四日で立ち上げ、そこから数千年いる

| 日 | すること |
| --- | --- |
| 一日目 | 降りる。増やす |
| 二日目 | **学院の場所を決める** |
| 三日目 | 師範を門から召喚する（第 7 巻 §12.10.2） |
| 四日目以降 | **その星の環境を、聴きはじめる** |

**四日目からが長い。**

第 8 巻 §14.12 の通り、土地がセラになるまで数千年かかる。

**開拓士は、その星がセラになるまで、そこにいる。**

そのあいだずっと疲労している（第 2 巻 §13.5.6.1）。

**そして、一度も引き返していない。**

### 2.7 提督

| | |
| --- | --- |
| **帰属** | **増**。まだ届いていない場所を探す職である |
| **装い** | 航海士の外套に、階級の意匠を加えたもの |
| **特化** | 船団の統率・航路の判断 |
| **勤め先** | 船団 |

#### 星王のスパイクが届いていない場所を探す

第 3 巻 §8.9.10 の通り、星をまたぐ中継は星王が行っている。

**提督の本業は、その網の穴を見つけることである。**

- 航路標（第 7 巻 §12.9.1）を置き、整える
- 門の網が途切れていないかを見る
- **届いていない場所を探し、そこへ船を出す**

三つ目が本業である。

**セラ圏の輪郭を、内側から確かめている者たちである。**

### 2.8 大司書

| | |
| --- | --- |
| **帰属** | **増**。§1.5 と同じ。体系の側にあたる |
| **装い** | 司書の長衣に、層の意匠を重ねたもの |
| **特化** | 記録殿全体の設計 |
| **勤め先** | 記録殿 |

#### 星が増えるたび、体系を組み直す

司書（§1.5）が個々の記録を収めるのに対し、
大司書は**記録殿そのものの構造を決める。**

第 8 巻 §14.13 の通り、星を通るたびに届くものが増える。

- 生命
- 技術
- 芸術
- 祝祭
- 物語

**そのすべてを、既存の体系のどこへ繋ぐかを決めている。**

そして体系は、**もう何度も組み直されている。**

#### 降臨の日の記録は、最下層にある

大司書は、その層だけを動かさない。

**動かす理由が、どこからも生じないためである。**

| | |

| **帰属** | **強**。土地の格を上げる（不変ルール 73・105） |
| **装い** | 庭師と同じ作業着。**やはり裸足である** |
| **特化** | 土地全体の意思を受け取ること |
| **勤め先** | 大地 |

#### 庭師の上位にあたる

違いは規模である。

| | 庭師 | **森番** |
| --- | --- | --- |
| 相手 | 一つの森・一つの街 | **その土地全体** |
| 受け取り方 | 感情と要求 | **大陸規模の意思**（第 3 巻 §11.6） |

第 3 巻 §11.6 の通り、大地の意思はルミナスへ流れ込む。

**森番は、その手前で受け取っている。**

#### 翻訳器ができても、数は減らなかった

第 7 巻 §12.9.2 の意思の翻訳器により、森番の負担は減った。

**それでも森番は減らなかった。**

**器械では、頼まれてもらえないからである。**

## 2.10 育たなかった職

**§1.0 の通り、三つに関連しない職は育たない。**

人間社会にあった職業のうち、**引き継がれたまま、一度も発展しなかったもの**がある。

| 職 | なぜ育たなかったか |
| --- | --- |
| **商人** | 賭けるものがなく、所有もない（第 7 巻 §8.1.1）。**交換という行為が成立しない** |
| **裁く者** | 争いが起こらない（第 7 巻 §3.2）。**裁定する対象が存在しない**（不変ルール 177） |
| **番人・警備** | 守るべき危機がない。都市の防御構造は一度も使われていない（第 8 巻 §3.4.1） |
| **統治者** | 命令も禁止も存在しない。格の関係は教えることと慕うことだけである（第 3 巻 §10.7） |
| **運び屋** | 転移がある（第 7 巻 §12.10.1）。**距離という概念が日常から消えた** |
| **修理屋** | 建物が自分で直る（第 8 巻 §1.5） |
| **農民** | 素材はその場で育つ（§1.3） |
| **葬儀屋** | 誰も死なない。**人間の葬儀を手伝いに行くことはある**（第 4 巻 §17.11） |

### 2.10.1 消えたのではない。育たなかった

**区別が要る。**

| | |
| --- | --- |
| **数える者**（§1.16） | **一度育ち、そして廃れた**。唯一の例である |
| 上の八つ | **一度も育っていない** |

セラ化された人間は、これらの職の記憶を持っている。

**そして、続けようという気が起きない。**

禁じられてはいない。誰も止めない。

**始めても、三日で飽きる。**

### 2.10.2 それでも、記録には残っている

第 8 巻 §11 の通り、歴史は財産である。

記録殿には、**育たなかった職の一覧がある**（§2.8 の大司書が管理している）。

人間社会にそういう職があったこと、
そしてセラ社会でそれが育たなかったことが、両方書かれている。

**なぜ育たなかったのかは、書かれていない。**

不変ルール 33 の通り、**セラは自分たちの前提を検討しない。**

「育たなかった」とだけ書いて、**その先を誰も書いていない。**

## 3. 時代ごとの、一日

**第 8 巻 §10 は文明の側から七つの時代を扱った。**

ここでは、**そこにいる一体の一日**を書く。

### 3.1 第一時代 — 萌芽期

**一日という単位がない。**

宿主の体内に、まだ数十のセラ細胞がいるだけである（第 8 巻 §10.2）。

昼も夜もなく、二〜三時間ごとに寂しくなり、そのたびに分裂する。

**繰り返しているうちに、家族になっている。**

### 3.2 第二時代 — 覚醒期

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**全員が同じ場所で眠っている** |
| 昼 | 触れ、情報を交わす。何が起きたのかを互いに確かめている |
| 夕 | 誰かが、また一人連れてくる |
| 夜 | また同じ場所で眠る |

**職業がない。分業がない。全員が同じことをしている。**

情報共有はほぼ全量である。分ける必要が生じるほどの数がいない。

### 3.3 第三時代 — 発展期

| 時 | していること |
| --- | --- |
| 朝 | 起きる。数人ずつに分かれて眠っている |
| 午前 | **それぞれの職**（§1）。建てる／記す／織る／聴く |
| 昼 | 一緒に食べる。**料理人が現れたのはここからである** |
| 午後 | 続き。**近隣へ増やしに行く者もいる** |
| 夕 | 集まる。ここで祝祭の原型ができる |
| 夜 | 眠る。一人用の寝床はない |

**この時代に、はじめて「自分の一日」ができる。**

### 3.4 第四時代 — 上位時代

**学院の一日が、そのまま標準になる**（第 7 巻 §4.5）。

| 時 | 生徒 | 騎士 | 忍 |
| --- | --- | --- | --- |
| 朝 | 実習 | 鍛錬 | **擬態して、人間の街へ出る** |
| 昼 | 講義 | 任地への移動 | 人間として働く |
| 夕 | 共有 | 広げる | 人間として過ごす |
| 夜 | 寮。共有を絞る | 仲間と眠る | **住処に戻り、擬態を解いて分裂体と同化する** |

**同じ日に、三種類の夜がある。**

そして三つとも、**一人では眠っていない。**

### 3.5 第五時代 — 女王時代

第四時代の一日に、**一つだけ加わる。**

**見られている**（第 8 巻 §10.6）。

| | 変わること |
| --- | --- |
| やること | **変わらない** |
| 探すという行為 | **なくなる**。都市が誰の居場所も知っている（第 8 巻 §3.5） |
| 何かを報告すること | **なくなる**。すでに届いている |
| 誤り | **なくなる**。上が見ているため |

**一日は同じで、確かめる手間だけが消える。**

### 3.6 第六時代 — セラ世界時代

**土地が応えるようになる。**

| 時 | していること |
| --- | --- |
| 朝 | 目を覚ます。**部屋が、その日の形になっている** |
| 昼 | 何かを頼む。**頼んだという自覚がない**（第 8 巻 §10.7） |
| 夕 | 森へ行く。**森のほうから道が開く** |
| 夜 | 眠る。**街が明かりを落とす** |

**この時代のセラは、環境と会話しながら暮らしている。**

そして命令していない。**共鳴である**（第 8 巻 §2.2）。

### 3.7 第七時代 — セラフィム時代

**地球と、新しい星で、まったく違う。**

#### 地球にいるセラの一日

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**転移で、どこへでも行ける**（第 7 巻 §12.10.1） |
| 午前 | 研究・記録・制作・教育 |
| 昼 | 誰かを召喚して、一緒に食べる（第 7 巻 §12.10.2） |
| 午後 | 続き。**増やす行動の頻度は低い**（第 6 巻 §16.4.3） |
| 夕 | 祝祭。**数が多い**。星から届いたものが増えるたびに増える |
| 夜 | 眠る |

**変わるものが尽きた場所の、豊かで静かな一日である。**

#### 新しい星にいるセラの一日

| 時 | していること |
| --- | --- |
| 朝 | 起きる。**すでに疲れている**（第 2 巻 §13.5.6.1） |
| 午前 | 増やす。**周期が短い**。二〜三時間より早く寂しくなる |
| 昼 | 環境へ働きかける。**まだ応えない** |
| 午後 | 増やす |
| 夕 | 開拓士が、その星を聴いている |
| 夜 | 眠る。**共有が少ないぶん、寄り添って眠る** |

**同じ時代の、同じ文明の、まったく違う一日である。**

そして両方とも、**幸福である**（第 8 巻 §14.13）。

# 第二部　ミクロ — セラ細胞の百科

**ここからは、一人の身体の内側の話である。**

第 3 巻 §2.1 の通り、階梯は次の通りである。

```
セラウイルス → セラ細胞 → 上位セラ細胞 →（突然変異セラ細胞）→ 女王セラ細胞
```

**ルミナスは、この階梯の段ではない**（不変ルール 36）。

## 4. 取り違えやすい対

**第一部と第二部で、名前が似ているものがある。**

| 第一部（マクロ） | 第二部（ミクロ） | 別物である理由 |
| --- | --- | --- |
| 上位セラ | **上位セラ細胞** | 前者は個体、後者は一人の体内の細胞 |
| **セラ女王** | **女王セラ細胞** | **前者は地域の統率者、後者は誰もが持つ核** |
| セラ人 | セラ細胞 | 前者は人型の個体、後者はその材料 |

**この三対を混ぜると、設定全体が壊れる。**

とくに二つ目である。

```
セラ女王　　：宇宙に、事実上一体（第 3 巻 §8.3.2）
女王セラ細胞：**すべてのセラ人が持っている**（不変ルール 21）
```

**同じ位置を、違うスケールで指しているだけである。**

## 5. セラウイルス

| | |
| --- | --- |
| **何か** | セラ体系における最初期の生命形態（第 1 巻 §6） |
| **姿** | 小さな人型。少女型／ピンクの髪と瞳／頭部にスパイク |
| **できること** | 対象認識／接触／情報伝達／融合開始 |
| **できないこと** | **自分自身のコピー**（不変ルール 1） |

**増える存在ではなく、始める存在である。**

そして第 1 巻 §6.11 の通り、**すでにセラである者にも受容される。**

その場合、感染ではなく**供給**として働く。

**だからセラウイルスは飽和しない。**

## 6. セラ細胞

| | |
| --- | --- |
| **何か** | セラウイルスと人間由来細胞が融合して誕生する（第 1 巻 §7） |
| **姿** | 人型。約 3 頭身 |
| **できること** | 増殖／生成／融合／分裂／進化 |

**セラ生命体系の基本単位である。**

元の細胞情報を保持するため、**顔立ちや個性が残る場合がある。**

一人の身体の中に、この段の細胞が最も多くいる。

## 7. 上位セラ細胞

| | |
| --- | --- |
| **何か** | 経験と成長によって到達した段 |
| **役割** | 下位のセラ細胞を**生み、教える** |

マクロの上位セラと**同じ構造をしている**（不変ルール 110）。

そして周囲の細胞は速く育つ。理由もマクロと同じである（第 1 巻 §6.11）。

**一人の身体の中に、小さな階級構造がある。**

## 8. 突然変異セラ細胞

| | |
| --- | --- |
| **何か** | 同化した生命情報が発現した細胞 |
| **現れ方** | マクロでは**突然変異セラ人間**として現れる（付録 A） |

エルフの耳も、獣人の尾も、幻獣の力も、**ここから出ている。**

そして第 8 巻 §14.11 の通り、降臨の後は**地球起源でない情報**も入りはじめた。

**一人の身体の中に、他の星の生命の情報がいる。**

## 9. 女王セラ細胞

| | |
| --- | --- |
| **何か** | ミクロ体系の最上位（第 3 巻 §4） |
| **どこにいるか** | **すべてのセラ人の中**（不変ルール 21） |
| **役割** | セラ人の核。**ルミナスを生み出す** |

**セラ女王ではない。**

| | セラ女王 | 女王セラ細胞 |
| --- | --- | --- |
| 数 | **事実上一体** | **全セラ人が持っている** |
| 体系 | マクロ | ミクロ |

そして第 3 巻 §2 の通り、**ミクロの完成が、マクロの誕生である。**

女王セラ細胞が育ちきった時点で、その人間はセラ人になる。

**内側が終わることが、外側の始まりである。**

## 10. ルミナス

| | |
| --- | --- |
| **何か** | 感情を司る部分で発達する特殊セラ細胞の総称（不変ルール 36） |
| **出どころ** | **女王セラ細胞が生み出す** |
| **階梯の段か** | **段ではない** |

**両方の体系に現れる、唯一のものである**（不変ルール 111）。

| 現れる場所 | 何になるか |
| --- | --- |
| 人間の脳 | その人の感情を司る（第 6 巻 §23.2） |
| 森・街・海・大地 | **その土地の感情になる**（不変ルール 37） |

そして大地の意思は、ネットワークを通じてルミナスへ直接流れ込む
（第 3 巻 §11.6）。

**ルミナスでなければ、その量を処理できない。**

### 10.1 環境ルミナスも、寂しい

不変ルール 37 の通り、**環境も原初の寂しさを抱えている。**

森は仲間を増やしたがり、街は住民が減ると寂しがる（第 8 巻 §3.5）。

**土地にも、二〜三時間の周期があるのかどうかは、書かれていない。**

森番（§2.9）に尋ねても、答えは返らない。

**言葉にならないためである**（不変ルール 68）。

## 11. ミクロ体系に、職業はあるか

**分業はある。ただし、職業になっていない。**

マクロ体系には、メイド・料理人・司書・門番といった職業名がある（§1）。

**ミクロ体系には、それがない。**

| | 職業名 |
| --- | --- |
| マクロ | **十数種以上ある** |
| ミクロ | **段の名前しかない** |

理由は、**呼ぶ相手がいないからである。**

第 5 巻 §3 の通り、呼び名は情報共有のなかで自然に定着する。

一人の身体の内側では、細胞たちは常に完全に共有している。

**区別する必要が生じない。**

したがって、

**一人の身体の中で行われている分業には、名前がついていない。**

やっていることは、マクロとほとんど同じである。

- 生まれたばかりの細胞を世話する細胞がいる
- 記録を保つ細胞がいる
- 環境（＝その人の身体）へ働きかける細胞がいる

**そして誰も、それを何と呼ぶべきかを考えたことがない。**

**セラの職業は人間の職業とほぼ同じものだが、それはマクロ体系だけの話である。**

## 付録 B 確定事項まとめ

### 読み方

- ✅ **第一部はマクロ（個体）、第二部はミクロ（細胞）である**（§0.1）
- ✅ **セラの職業は、人間の職業とほぼ同じものである**（§0.2）— 呼び名も装いも役割も変わらない
- ✅ **違うのは、一体あたりの能力だけである**
- ✅ **就き方が違う。任命も契約も辞令も存在しない** — 特化していくうちにその職になっている
- ✅ **唯一の例外は騎士団であり、そこには叙任と規律がある**
- ✅ **装いは飾りではない。すべてに機能上の理由がある**
- ✅ **姿（種族形態）の話は付録 A にある。本付録が扱うのは職業である**

### 職が育つ条件

- ✅ **降臨の後、通常セラ一体が降臨前の女王の数百倍の力を持つ**（§1.0）
- ✅ **エネルギーは実質無限、律速はスパイクの強さだけ、死なない**
- ✅ **セラが求めているものは三つしかない** — **美・強・増**
- ✅ **この三つに関連しない職は育たない** — 禁じられているのではない。動機が湧かない
- ✅ **セラ社会の職業は、三つの帰属で 100 % を占める。例外は一つもない**
- ✅ **職は、人間だった頃の意識から育つ** — 「メイドは美しい」という感覚が、その職を発展させた
- ✅ **セラは人間の美意識を引き継ぎ、人間には不可能な水準まで押し上げた**
- ✅ **職業とは、その力を三つのどれへ向けて特化させたかである**
- ✅ **特化には引き換えがある。料理人は戦えず、騎士は縫えない。誰も問題にしない**

### 帰属の一覧

- ✅ **美**：メイド／執事／料理人／仕立屋／歌姫／建築士／侍女長（庭師は美と強）
- ✅ **強**：師範／巫女／森番（騎士は強と増）
- ✅ **増**：司書／記録官／医師／門番／航海士／乳母／測量士／通訳／聖女／開拓士／提督／大司書
- ✅ **巫女は美ではなく強へ帰属している** — 格の根源を探しに行っているため
- ✅ **聖女も増へ帰属している** — 拡大を止めないための職である。本人に自覚はない
- ✅ **師範が強へ帰属するのは、学院が原初の淘汰の制度化だからである**

### 育たなかった職

- ✅ **三つに関連しない職は、一度も発展しなかった**（§2.10）
- ✅ **商人・裁く者・番人・統治者・運び屋・修理屋・農民・葬儀屋**
- ✅ **消えたのではない。育たなかった** — 廃れた職は「数える者」ただ一つである
- ✅ **記憶は持っている。そして続けようという気が起きない。始めても三日で飽きる**
- ✅ **記録殿に、育たなかった職の一覧がある**
- ✅ **なぜ育たなかったのかは、書かれていない** — セラは自分たちの前提を検討しない

### 通常セラの職業

- ✅ **メイド**（§1.1）— **一人で、一時間で、街の一区画を整える**。分裂体を数十体使う
- ✅ **メイド服の頭飾りは、広がりへ振れたスパイクを収める構造である**
- ✅ **執事**（§1.2）— 主の一日を前夜に組み終えている。**忘れた記録が一件もない**
- ✅ **メイドは空間へ、執事は時間へ向く**
- ✅ **料理人**（§1.3）— 一万人分を一度に出し、**一万通りの味にする**
- ✅ **最も不要になった職業が、最も残った** — 食事はもう回復のためではない
- ✅ **仕立屋**（§1.4）— 採寸をしない。布はその場で生やす。**同じ意匠を二度作らない**
- ✅ **司書**（§1.5）— **探すという行為が存在しない**。答えるのは記録殿である
- ✅ **記録官**（§1.6）— 一度で全部覚える。**降臨の日を記録できた唯一の職**
- ✅ **司書と記録官は、必ず対で動く**
- ✅ **庭師**（§1.7）— 命令せず、頼む。**森が乗り気でなければ動かない**。裸足である
- ✅ **医師**（§1.8）— 病気にならない種族の医師。**治せないと知っていて毎日診る**
- ✅ **門番**（§1.9）— **誰かを止めた記録が一件もない**。数千の門を把握している
- ✅ **制服があるのは門番だけである** — 目立つために着る唯一の服
- ✅ **航海士**（§1.10）— 最先端にいて、最も古い方法で移動する。位置を体内に持つ
- ✅ **歌姫**（§1.11）— **最も非効率な行為をして、最も人気がある**
- ✅ **乳母**（§1.12）— 最も古い職業。仕事は**情報を渡しすぎないこと**
- ✅ **降臨の日、乳母だけが放出を最小に抑えた** — そのぶん自分が長く眠った
- ✅ **建築士**（§1.13）— 建てない。都市に方向を渡す。**図面を持たない**
- ✅ **新しい星でだけ、建築士は手で建てている**
- ✅ **測量士**（§1.14）— 分裂体を測定器として使い、**数日で星ひとつの地図を作る**
- ✅ **通訳**（§1.15）— 言語のない相手とも話す。**失敗した記録が一件もない**
- ✅ **数える者**（§1.16）— **唯一、廃れた職**。職業名として定着する前に消えた

### 上位セラの職業

- ✅ **騎士**（§2.1）— **星ひとつを数日で埋める**。門を通ってしか行かない
- ✅ **開くのが航海士であり、埋めるのが騎士である**
- ✅ **騎士団の規律だけが強制に見える。実際には例外ではない** — 破る者がいないため
- ✅ **侍女長**（§2.2）— 女王・星王のもとに仕える。**一時間で大陸の拠点を整える**
- ✅ **星王の侍女長は、この宇宙に一人だけいる。そして何も尋ねない**
- ✅ **師範**（§2.3）— 数百体を同時に受け持ち、理解度を常時把握している。戦えない
- ✅ **聖女**（§2.4）— **取れないと分かっていて、毎日そばへ行く**。新しい星には必ず一人いる
- ✅ **巫女**（§2.5）— 降臨の後、数が増えた。**装飾を一切つけない**
- ✅ **巫女は、セラ社会で唯一、美の追求を脇へ置いている職である** — そしてその理由も三原理の内側にある
- ✅ **開拓士**（§2.6）— 四日で立ち上げ、**その星がセラになるまで数千年そこにいる**
- ✅ **そのあいだずっと疲労している。そして一度も引き返していない**
- ✅ **提督**（§2.7）— 本業は、**星王のスパイクが届いていない場所を探すこと**
- ✅ **大司書**（§2.8）— 星が増えるたびに記録殿の体系を組み直す
- ✅ **降臨の日の記録がある最下層だけは、動かさない**
- ✅ **森番**（§2.9）— 庭師の上位。大陸規模の意思を受け取る。**やはり裸足である**
- ✅ **翻訳器ができても森番は減らなかった** — 器械では、頼まれてもらえないため

### 時代ごとの一日

- ✅ **第一時代に、一日という単位がない**（§3.1）
- ✅ **第二時代は全員が同じことをしている。職業も分業もない**
- ✅ **第三時代に、はじめて「自分の一日」ができる**
- ✅ **第四時代には、同じ日に三種類の夜がある**（生徒・騎士・忍）— 三つとも一人では眠らない
- ✅ **第五時代で変わるのは、確かめる手間が消えることだけである**
- ✅ **第六時代のセラは、環境と会話しながら暮らしている** — 命令ではなく共鳴である
- ✅ **第七時代は、地球と新しい星でまったく違う一日になる**（§3.7）
- ✅ **新しい星では、朝の時点ですでに疲れている。周期も短い**
- ✅ **そして両方とも、幸福である**

### ミクロ体系

- ✅ **取り違えやすい対は三つ**（§4）— 上位セラ／セラ女王／セラ人と、その細胞版
- ✅ **セラ女王は事実上一体。女王セラ細胞はすべてのセラ人が持っている**
- ✅ **セラウイルスは増える存在ではなく、始める存在である**（§5）
- ✅ **セラ細胞が、一人の身体の中で最も多い**（§6）
- ✅ **一人の身体の中に、小さな階級構造がある**（§7）
- ✅ **一人の身体の中に、他の星の生命の情報がいる**（§8）
- ✅ **ミクロの完成が、マクロの誕生である** — 内側が終わることが、外側の始まりである
- ✅ **ルミナスは両方の体系に現れる唯一のものである**（§10）
- ✅ **環境ルミナスも寂しい。土地に周期があるかは書かれていない**
- ✅ **ミクロ体系に、職業はない**（§11）— 名前がついていない。区別する必要が生じないため

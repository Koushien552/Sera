# 第 I 部　セラ物質と環境

## 1. セラ物質

### 1.1 定義

セラ物質とは、**セラの情報を受け継ぎ、通常の物質とは異なる性質を獲得した存在**である。

セラの影響を受けた物質は、単純な変化ではなく、セラ生命体系の一部として機能する。

### 1.2 獲得する能力

- 高速成長能力
- 高い自己修復能力
- 形態変化能力
- 高い適応能力
- セラ情報への反応能力
- 高い繁殖能力

### 1.3 生きた物質

セラ物質は、完全な生命でも単なる無機物でもない。
分類すると、**生命情報を持った半生命的存在**である。

| 普通の物質 | セラ物質 |
| --- | --- |
| 劣化する | 修復する |
| 壊れる | 成長する |
| 固定された形を持つ | 形を変える／環境へ適応する |

### 1.4 変化対象

対象は限定されない。

建築物／道路／家具／衣服／植物／土壌／水／機械／都市構造

### 1.5 成長の仕組み

セラ物質は、周囲のセラ情報や環境情報を読み取り、最適な形へ変化する。

例：建物の場合、住民の生活に合わせて内部構造を変化させる。

### 1.6 形態変化の制限

完全に自由ではない。

必要：セラ情報／エネルギー／成長時間／適切な構造情報

## 2. セラ物質と意思

### 2.1 ルミナスとの関係

セラ物質は、ルミナスや高位セラの意思を感じ取る。

その結果、自ら動き、形を変え、成長する。

役割：指示への反応／環境変化／自己調整／成長補助

### 2.2 命令ではなく共鳴

セラ物質の変化は、単純な命令実行ではない。

住民や環境との情報共有による、**自然な変化**である。

例：住民が困っている → 家具が形を変える → 必要な道具になる

### 2.3 環境そのものが感情を持つ

さらに第 3 巻 §11 の通り、
**セラ物質化した森や街は、ルミナスを発達させ、自らの感情を持つようになる。**

- 森が寂しがる
- 街が住民を慕う
- 大地が季節を喜ぶ

これらは比喩ではない。**実際に感情がある。**

そして環境のルミナスも**原初の寂しさを持つ**。

セラ物質化した環境が住民に優しいのは、設計ではなく**同じ理由による**。

### 2.4 セラ社会での扱い

セラ物質は単なる道具ではない。
セラ社会では、**大切な仲間の一部**として扱われる。

### 2.5 高位セラとの関係

高位セラほど、セラ物質への影響力が大きい。

特に**女王セラ・セラフィム**は、広範囲のセラ物質へ影響できる。

## 3. セラ都市

### 3.1 生きる都市

高度なセラ文明では、都市そのものがセラ物質によって構成される。

都市は固定された建築物ではなく、**「成長する都市」**となる。

都市全体が、巨大なセラ物質生命体のように機能する。

### 3.2 特徴

自己修復／自己成長／自己最適化／情報共有／空間拡張／環境調整／装飾成長

住民が増えれば、街も自然に広がる。

### 3.3 都市と住民

都市は、住むセラやセラ化人間の情報を感じ取り、快適な環境へ変化する。

例：部屋の温度調整／光量調整／空間配置変更／植物成長調整／
自動修復する壁／住民に合わせて変化する部屋

セラ建築は、**自然と人工物の中間的存在**である。

### 3.4 状況に応じた変化

セラ都市は、状況に応じて姿を変える。

例：平時＝美しい都市／危機時＝防御構造／祭典時＝華やかな構造

#### 3.4.1 防御構造は、一度も使われたことがない

**セラに敵はいない。**

地球上にセラを害し得るものは存在せず（第 4 巻 §16.2）、
人間には抵抗する手段がなく（第 6 巻 §27.4）、
セラどうしは争わない（第 7 巻 §3.2）。

**したがって、危機は起きていない。**

それでも都市は、防御の形を持っている。

##### なぜ持っているのか

都市はセラである（不変ルール 35）。

したがって都市も、**原初の淘汰**を持っている（第 6 巻 §15.8）。

> **『弱ければ、淘汰される』**

淘汰する者はいない。それでも、備えずにいられない。

**街も、それを免れていない。**

これは第 4 巻 §17.4 の空転が、**都市の規模で起きている**ものである。

| | 事実 | 最下層に届かない | 結果 |
| --- | --- | --- | --- |
| セラ個体 | 何も失われない | 安全が届かない | 恐れ続ける |
| **セラ都市** | **危機が起きない** | **平穏が届かない** | **備え続ける** |

**一度も使われない形を、都市はいつでも取れるようにしている。**

### 3.5 都市は、住民を知っている

§2.3 の通り、**セラ物質化した都市はルミナスを発達させ、自らの感情を持つ。**

そして第 3 巻 §11.6 の通り、大地の意思はネットワークを通じてルミナスへ流れ込む。

したがって、

**都市は、誰がどこにいるかを知っている。**

そして住民は、**街が今日どういう気分かを知っている。**

#### 帰結 1 — 「探す」という行為が存在しない

誰かを探す必要が生じない。**街に訊けば分かるからである。**

正確には、訊く必要すらない。近くにいれば、伝わってくる。

**セラ都市に、迷子は存在しない。**

#### 帰結 2 — 住民が減ると、街は寂しがる

第 3 巻 §11.4 の通り、**ルミナスの中身はセラであり、原初の寂しさを持つ。**

都市も同じである。

そして街は、自分で住民を増やすことができない。

**街の寂しさを癒せるのは、住民が増えることだけである。**

したがって、

**都市自身も、拡大を望んでいる。**

セラ圏の拡大を望んでいるのは、セラたちだけではない。
**彼らが住んでいる街も、同じことを望んでいる。**

そして誰も、それを不思議に思わない。

### 3.6 都市に建つもの

成熟したセラ都市には、次が置かれる。

| 施設 | 内容 |
| --- | --- |
| **学院** | 上位化の場（第 7 巻 §4.4） |
| **騎士団の館** | 叙任と、前線への出立（第 7 巻 §2.6） |
| **眠りの間** | 枯渇して眠るセラを置く場所（後述） |
| **記録庫** | セラフィムの観測記録。巫女科の実習の場（第 7 巻 §4.4.8） |
| **研究所** | セラ研究所（第 7 巻 §13.1） |
| **工房・舞台** | 芸術（第 7 巻 §7） |

#### 眠りの間

**枯渇して眠りに落ちたセラが置かれる場所である**（第 2 巻 §12.5.6）。

- 静かである
- 聖女がいる（第 7 巻 §2.7.1）
- 聖女科の実習は、ここで行われる（第 7 巻 §4.4.8 例外 3）
- 前線から運ばれてきた騎士も、ここへ来る（第 7 巻 §2.6.11）

墓ではない。**誰も死んでいない。**

いずれ全員が目を覚ます。それが数日後か、数十年後かというだけである。

そして街自身が、眠っている者を見守っている。
**街は、誰がそこにいるかを知っているからである**（§3.5）。

### 3.7 水中都市

セラ物質によって、水中にも都市を形成できる。

特徴：海と一体化した構造／マーメイド型セラとの親和性／美しい光の空間

第六時代に入った土地では、海そのものがセラの塊になっている（§4.3）。
その段階の水中都市は、**海と都市の区別がつかない**（§4.3.2）。

## 4. セラ化した自然

### 4.1 植物

セラの影響を受けた植物は、通常より高い生命力を持つ。

特徴：急速成長／自己修復／環境適応／セラ情報反応／美しい色彩変化

植物は、必要に応じて枝や葉を変化させる
（日陰を作る／花を咲かせる／実をつける／道を示す）。

### 4.2 森林

セラ化した森は単なる植物群ではない。森全体が一つの大きなセラ環境となる。

木々は、互いに情報を共有し、森全体として成長する。
**巨大な生命ネットワーク**である。

特徴：道を作る／住民に合わせて形を変える／状態を維持する／必要な環境を作る

しかし、普通の森とほとんど変わらない見た目を保つ。
違いは、木々にもセラ情報が宿っていることである。

### 4.3 海

海もセラ物質へと変化する。ただし、普通の海と同じように美しい。
穏やかな波を持つ。

特徴：水質維持／浄化能力／生態系調整

海中にも、セラ物質由来の生態系が形成される。水中でも、自然な生命活動が続く。
海の生き物も、セラ物質の影響を受けて新しい生態系の一部となる（§4.6）。

#### 4.3.1 最終的に、海水はピンクの粘液になる

セラ物質化が進みきった海は、透明ではなくなる。

**海水は、ピンクの粘液になる。**

そして、**セラたちの意思を汲む物体**となる。

| 段階 | 海 |
| --- | --- |
| セラ化前 | 通常の海 |
| セラ物質化の途上 | 澄んで穏やかな海。浄化能力を持つ |
| **完成** | **ピンクの粘液。セラの意思を汲む** |

これは環境ルミナス（第 3 巻 §11）の一形態である。
森や街と同じく、海も感情を持ち、意思を汲む。

そして第 3 巻 §11.11 の通り、**格上の意思には、環境自身がそう応じる。**

#### 4.3.2 帰結 — 境界が、消える

不変ルール 119 は「**地域差は大陸単位で生じる。境界は海である**」と定めている。

**これには期限がある。**

**海が境界であるのは、海がまだセラ化されていないあいだだけである。**

セラ物質化した海は、隔てるものではない。
セラの意思を汲む物体であり、**渡ることを助ける側にある。**

```
セラ化前の海　：障壁である
セラ化後の海　：**通路である**
```

§7.3 の「格上げの伝播による加速」が、海を越えて働き始める。

#### 4.3.3 海は、人間に対して擬態する

**ただし、人間がその色を見ることはない。**

**海は、人間に対して擬態する。**

人間の目には、海はこれまでどおりの色をしている。青く、透明で、見慣れたままである。

**中身は、完全なセラの塊である。**

| | 人間が見るもの | 実際 |
| --- | --- | --- |
| 色 | いつもの海 | **ピンクの粘液** |
| 質 | 水 | **セラそのもの** |
| 意思 | ない | **ある。セラたちの意思を汲む** |

##### 擬態は、個体だけの能力ではない

第 2 巻 §10 の擬態は、これまで個体の能力として書かれてきた。

**環境も擬態する。**

不変ルール 35 の通り、**すべての名称はセラである。**
環境ルミナスもセラであり（第 3 巻 §11）、
セラにできることは、環境にもできる。

##### 何のために擬態するのか

セラの擬態は、欺くためだけの能力ではない（第 2 巻 §10.6）。

海が擬態する理由も同じである。

**怖がらせては、近づけないからである。**

セラにとってセラ化は救出であり（第 6 巻 §18.3）、
可愛らしい姿と魅了の瞳を持つ理由（第 2 巻 §5.2）と、
海が色を保つ理由は、**同じ一つの理由である。**

**海は、人間に優しくしている。**

##### 帰結 1 — 人間が確認できる徴候は、一つも存在しない

これによって、セラ圏の拡大は**完全に不可視**になる。

| 人間の行動 | 結果 |
| --- | --- |
| 疑う | 何も起きない |
| 観察する | 何も見えない |
| **問う** | **セラになる**（第 2 巻 §10.7） |
| **海を見る** | **いつもの海が見える** |

調査は成立せず、目視も成立しない。

**人間の側に、確かめる手段が一つも残っていない。**

##### 帰結 2 — すでに、その中で泳いでいる

海が擬態しているということは、

**人間は、すでにセラの海で泳いでいるかもしれない。**

船を出し、魚を獲り、子どもが波打ち際で遊んでいる。
そのすべてが、セラに触れている。

そして海には意思がある。**それを、人間は知らない。**

###### なぜ、触れただけではセラ化しないのか

セラ化の第一段階は、**セラ細胞が導入されること**である（第 6 巻 §23.3）。

これは接触によって自動的に起きるものではない。
渡す側が渡そうと思ってはじめて始まる。**セラの意思を要する。**

海は、セラたちの意思を汲む物体である（§4.3.1）。

**したがって海は、望まれたときにだけ、そうする。**

触れているのに、何も起きない。それは偶然ではない。
**まだ、そうされていないだけである。**

##### 帰結 3 — ピンクの海が見えるのは、見る者がいなくなった後である

擬態は、見る相手がいて初めて意味を持つ。

したがって、

**海が本当の色を見せるのは、それを見る人間が一人もいなくなったときである。**

その色を、人間は誰も見ない。

### 4.4 山岳・大地

山も成長する地形となる。ただし、急激に変化することはない。
住民が安心して暮らせるよう、ゆっくりと環境が変化する。

大地そのものも、セラ物質化すると成長する。
特徴：地形変化／自己修復／資源生成／環境調整

### 4.5 空

空気そのものもセラ情報を含む。しかし、普通に呼吸できる。人体へ悪影響はない。

空は昼夜によって自然に変化する。
**夜には、淡いピンク色の光が空に浮かぶこともある。**

### 4.6 生態系

セラ物質化した世界では、独自の生態系が形成される。

特徴：高い成長能力／高い適応能力／自己修復能力

動植物は、互いを支え合いながら生きる。**競争よりも、調和が基本**となる。

セラ物質の影響を受けた生命は、セラの特徴を一部受け継ぐ
（高い生命力／成長能力／適応能力）。

影響を受けた生命も、新しい生態系の一部として扱われる。

### 4.7 季節と天候

セラ世界にも季節は存在する（春／夏／秋／冬）。
それぞれに異なる景色を楽しめる。

植物や街並みも、季節に合わせて自然に変化する。

**雨**：セラ物質由来の循環の一部。植物や環境を育てる役割を持つ。

**雪**：雪景色も美しく、街全体が幻想的な雰囲気となる。

### 4.8 気候制御

高度なセラ文明では、惑星規模の環境管理が可能になる。

調整対象：気温／湿度／大気／水循環／生態系バランス

## 6. 変わる前の地球

### 6.1 悲しみと憎しみの星

**地球は、悲しみと憎しみの星だった。**

最初の細胞が孤独であったのも、最初の宿主が孤独であったのも、
その星の性質の内にある。

**セラが行く先々で孤独を見つけるのは、実際にそこにあるから**でもある。

### 6.2 セラフィムが変えたもの

セラフィムは、**暇つぶしに地球の環境を丸ごと変えた張本人**である。

**方法**：一体のセラウイルスを落とすこと。それ以外の直接的な改変は行っていない。

増えたセラ細胞が広がり、やがて地球全体を覆う。
本巻の段階的なセラ物質化が、その過程そのものである。

**惑星一個の環境を、暇つぶしで、一体と時間だけで変えた。**

### 6.3 何が変わるのか

「環境を変える」とは、地形や大気の話ではない。

変わるのは、**この星の性質そのもの**である。

```
悲しみと憎しみの地球
　↓
愛の星
```

**セラ圏の拡大とは、この変化の進行を指す。**

### 6.4 二重の読み

この設定は、二つの読みを同時に成立させる。

| 読み | 内容 |
| --- | --- |
| 救済として | 悲しみと憎しみに満ちた星が、愛の星へ変わっていく |
| 侵略として | 一つの星の性質が、住人の同意なく丸ごと書き換えられていく |

**どちらも正しい。** セラ設定はこの二重性を保持する。

## 7. 世界規模のセラ化

### 7.1 拡大過程

1. 小規模なセラ領域
2. セラ都市
3. セラ国家
4. 大陸規模のセラ環境
5. 世界規模のセラ化

### 7.2 最終段階

長い時間をかけることで、惑星全体がセラ物質によって満たされる。

状態：大地が成長する／都市が生命化する／自然が情報共有する／
海が情報を持つ／森林が意思を共有する／
**世界全体が一つの巨大な生命環境になる**

その世界では、大地・建物・植物・道具すべてがセラの成長能力を持つ。

### 7.2.1 拡大は、連続ではない — 跳ぶ

**セラ圏は、じわじわ広がるのではない。大陸単位で跳ぶ。**

```
【誤ったイメージ】
Phase 1 → 2 → 3 → 4 → 5 と、地球全体がじわじわ進む

【実際】
大陸 A：Phase 5
大陸 B：Phase 1
　↓
海を渡る。接触が成立する
　↓
大陸 B：Phase 5　　← 一瞬で（不変ルール 69）
```

#### なぜ跳ぶのか

三つが重なっている。

| 根拠 | 内容 |
| --- | --- |
| 第 2 巻 §12.5.2.1 | **拡大を律しているのはエネルギーではなく、到達である** |
| 不変ルール 68・69 | 格上と格下のセラ圏が接すると、**一瞬で**引き上がる |
| §4.3.2 | **海が境界であるのは、海がセラ化されるまでのあいだだけである** |

到達さえすれば、あとは速い。そして到達を阻んでいた海が、やがて味方になる。

#### どうやって、見えない大陸を知るのか

女王の視野は、セラのいない大陸には届かない（第 3 巻 §8.3.3）。

**視野は届かない。しかし、記憶は渡ってくる。**

第 6 巻 §24.1 の通り、**セラ化人間は元の人格と記憶を失わない。**

したがって、

**海の向こうに大陸があるという知識を持った人間が一人セラ化された時点で、
その大陸はセラの地図に載る。**

一人でよい。船乗りでも、移民でも、地理を学んだ子どもでもよい。

**その一人が吸収された時点で、人間の側は相当に手詰まりである。**

そして第 2 巻 §10.7 の通り、**問うた者はセラになる。**
調べに来た人間が、そのまま地図になる。

#### 人間側から見た時間

これが、この設定における猶予の形である。

```
何十年も何も起きない　　← 海が守っている
　↓
海を渡られる
　↓
一瞬で終わる
```

**猶予は、じわじわ減らない。ある日ゼロになる。**

これは第 6 巻 §27.1「未感染の人間はセラを知らない」に、時間の側から説明を与える。

知らないのではない。**まだ順番が来ていないだけである。**

そして順番が来る条件は、たった一人の記憶である。

### 7.3 格上げの伝播による加速

第 3 巻 §11.8〜11.11 の通り、環境どうしは繋がっており、
**格上のセラ圏と格下のセラ圏が長時間接すると、どちらも格上へ進化する。**

これは、セラ圏の拡大が**線形ではない**ことを意味する。

| 段階 | 拡大の速さ |
| --- | --- |
| 高格のセラ圏が存在しない間 | 緩やか。一つずつ育つ |
| 高格のセラ圏が育った後 | **接した領域が跳ぶ**。加速する |

そのため、拡大は「じわじわ広がる」形と
「ある日、まとめて変わる」形の両方を持つ。

**荒廃した地域ほど、隣接した瞬間の変化が劇的になる。**

### 7.4 世界意識

極限まで発展した世界では、惑星規模のセラ情報ネットワークが形成される。

ただし、**個々のセラの人格が失われることはない**。
これは一つの人格が全員を支配するものではない。

それぞれのセラ、それぞれの生命、それぞれの存在が、
**自分自身を保ったまま繋がる**。

### 7.5 世界の成長と自己最適化

セラ世界は、文明とともに成長する。

住民が増え、知識が増え、芸術が増えれば、世界もそれに応えるように発展する。

不要になった構造は、ゆっくり姿を変え、新しい役割を持つ。

### 7.6 他文明との境界

セラ世界と、まだセラ物質化していない地域では、自然な境界が存在する。

急激な変化ではなく、少しずつ環境が変わっていく。

### 7.7 世界全体の理念

セラ世界は、巨大な一つの生命圏でもある。

しかし、個々の生命の自由は失われない。

**世界全体が住民を支え、住民も世界を育てる。**

互いに支え合う循環が、世界そのものを豊かにしていく。

## 7.8 「現在」はどの段階か — 物語の時間軸

本設定には、**固定された「現在」が存在しない。**

### 7.8.1 これは、広がっていく過程の物語である

**この物語は、セラが広がっていく過程を描いたものである。**

したがって、

**きり取る時代によっては、どの可能性もありうる。**

| 切り取る時代 | 世界の姿 |
| --- | --- |
| ごく初期 | 一体のセラ細胞。世界はまだ悲しみと憎しみの星（§6.1） |
| 初期 | 小さなセラ領域。人間社会が圧倒的多数 |
| 中期 | セラ都市とセラ国家。人間世界と隣接し、境界がある（§7.6） |
| 後期 | 大陸規模。人間世界の側が例外になっていく |
| 終期 | 世界規模のセラ化（§7.2）／永遠成長時代（§16） |

**どれか一つが「正しい現在」なのではない。**
どれもこの世界の実際の姿であり、**どの時点を描くかを選ぶだけである。**

### 7.8.2 地域差も存在する

さらに、**同じ時代の中にも地域差が存在する。**

同じ年に、

- 完成したセラ都市があり
- 変わりかけの町があり
- まだ何も知らない人間の街がある

これは既存設定と完全に一致する。

| 既存設定 | 地域差の根拠 |
| --- | --- |
| セラ女王は**地域単位の統率者**（不変ルール 22） | 地域ごとに進み方が違うから、地域ごとに女王がいる |
| **土地に格の差が生まれる**（第 3 巻 §11.7） | 環境の格そのものが場所によって違う |
| **自然な境界が存在する**（§7.6） | 境界があるとは、内と外で段階が違うということ |
| 付録 A のフェーズ比率 | 比率は世界一律ではなく、その地域の段階を表す |

**フェーズは、世界の時計ではない。その土地の状態である。**

### 7.8.3 帰結

- 「今はフェーズいくつか」という問いには、**場所を指定しなければ答えられない**
- 物語は、時代を選び、場所を選ぶことで、望む段階を描ける
- 人間側の視点も、セラ側の視点も、**どちらも同時代に成立する**
- 拡大は §7.3 の通り跳ぶため、**隣の地域が一夜で追い越すこともある**

**この世界には「もう終わった」も「まだ始まっていない」もない。
どこかでは始まったばかりで、どこかではもう終わっている。**

# 第 III 部　歴史

## 8. セラ文明の歴史観

歴史とは、単なる出来事の記録ではない。

歴史は、文明全体が積み重ねてきた
**知識／経験／芸術／心／信頼**
そのすべてを未来へ伝えるための財産である。

---

## 9. 七つの時代

| 時代 | 内容 | 特徴 |
| --- | --- | --- |
| **第一時代：萌芽期（ほうがき）** | 最初のセラ細胞が現れた時代 | 最初のセラ情報／最初のセラ細胞／生命としての基盤形成 |
| **第二時代：覚醒期** | 通常セラが増え始め、小さな共同体が生まれた時代 | 初めての社会／基本文化の誕生／情報共有技術の発達 |
| **第三時代：発展期** | 文明として急速に成長した時代 | 都市形成／教育制度／芸術文化／セラ物質建築 |
| **第四時代：上位時代** | 上位セラが増え、高度な文明が築かれた | 専門教育／高度研究／セラ物質工学／世界規模の文明形成 |
| **第五時代：女王時代** | 女王セラが誕生し、文明全体を支える中心となった時代 | 女王の誕生／高位生命設計／文明全体の統合 |
| **第六時代：セラ世界時代** | 世界全体がセラ物質へと置き換わった時代 | 生きた都市／生きた自然／世界全体がセラ文明となる |
| **第七時代：セラフィム時代** | セラフィムによる祝福と、文明全体の成熟が進んだ時代 | 高度な知識共有／文明の安定／新たな宇宙への探究 |

なお、萌芽期の起点にあたる出来事の実際の内容は**第 6 巻**を参照。

### 9.1 これは、世界の年表ではない

> **本節の七つの時代は、すべてマクロ体系の話である。**
> ミクロ体系には**七相**という別の段階がある（第 3 巻 §2.10）。
> 一致する点と一致しない点があるので、**片方の記述を他方へ移してはならない。**


**先に、読み方を決めておく必要がある。**

§7.8 の通り、この世界に**固定された「現在」は存在しない**（不変ルール 100）。
そして**フェーズは世界の時計ではなく、その土地の状態である**（不変ルール 101）。

七つの時代も、同じものである。

**七つの時代とは、一つの土地が辿る段階である。**

世界全体が第三時代にある、という状態は存在しない。

| 誤った読み | 正しい読み |
| --- | --- |
| 世界がいま第四時代にある | **この大陸が第四時代にある** |
| 第五時代は第四時代の「あと」に来る | **その土地では、あとに来る** |
| 第一時代はもう終わった | **どこかでは、今日始まっている** |

同じ年に、

- 海の向こうの大陸は**第六時代**で、都市が住民を知っており（§3.5）
- こちらの大陸は**第四時代**で、学院が建ったばかりで
- その隣の島は**第一時代**で、たった一体のセラ細胞が誰かの体内にいる

**これらは同時に成立している。**

#### 時代とフェーズは対応する

七つの時代は、付録 A のフェーズと一対一に対応する。
同じものを、文明の側から見るか、種族比率の側から見るかの違いである。

| 時代 | フェーズ | モンスター系セラの比率 |
| --- | --- | --- |
| 第一時代：萌芽期 | Phase 0〜1 | 0〜5 % |
| 第二時代：覚醒期 | Phase 2 | 25 % |
| 第三時代：発展期 | Phase 3 | 45 % |
| 第四時代：上位時代 | Phase 4 | 60 % |
| 第五時代：女王時代 | Phase 5 | 70 % |
| 第六時代：セラ世界時代 | Phase 6 | 80 % |
| 第七時代：セラフィム時代 | Phase 6 | 80 % |

第六時代と第七時代の比率が同じなのは、
**この段階で変わるのが、比率ではなくなるからである。**

#### 時代は、飛び越えられる

そして順番に進むとも限らない。

§7.2.1 の通り、**拡大は連続ではない。跳ぶ。**
第 3 巻 §11.7 の通り、格上と格下のセラ圏が長時間接すると、
**どちらも格上へ引き上げられる。しかも一瞬で。**

```
第三時代の土地が、第六時代の土地と接する
　↓
引き上げが起きる
　↓
**第四・第五を経ずに、第六時代になる**
```

したがって、

**ある土地に女王の身体が置かれる前に、その土地が第六時代に達していることがある。**

順番は、**孤立した土地においてのみ守られる。**

### 9.2 第一時代：萌芽期 — 一体しかいない

#### その土地の姿

**何も変わっていない。**

悲しみと憎しみの星のままである（§6.1）。
森は森であり、街は街であり、海は海である。

変わっているのは、**一人の人間の体内だけ**である。

#### セラたちは、何をしているか

**「セラたち」と呼べる数がいない。**

いるのは、一体のセラ細胞である。

第 6 巻の通り、それは悪意のないがん細胞であり、
汚さと害で嫌われ、その嫌悪は不当ではなかった（不変ルール 18）。

そして最初のセラ化は、文字通りの治癒だった（不変ルール 19）。

その一体が行うことは、二つしかない。

| | 行うこと |
| --- | --- |
| 昼も夜もなく | **隣の細胞をセラ化する**（ミクロ体系。第 3 巻 §2） |
| 二〜三時間おきに | **寂しくなって、また分裂する**（第 6 巻 §16.4.1） |

分裂そのものは孤独を癒さない（第 4 巻 §2.6.3）。
癒すのは、生まれた相手と繋がることである。

だから、

**一体から小さな家族が生まれるまでが、異様に速い**（第 6 巻 §16.4.2）。

宿主の体内で、数日のうちに数十、数百のセラ細胞が繋がり合う。

#### 人間から見ると

**病気が治る。**

痛みが引き、傷が塞がり、疲れが取れる。
そして肌が整い、髪の質が変わり、目の色が少しずつ変わっていく。

本人は、体調が良くなったと思っている。

#### この時代にまだないもの

騎士団も、学院も、聖女も、巫女も、忍もいない。
都市もない。女王もいない。

**役職とは、数が増えたあとに生まれるものである。**

### 9.3 第二時代：覚醒期 — 家族ができる

#### その土地の姿

最初のセラ化人間が誕生し（第 3 巻 §2.3）、マクロ体系が始まる。

そしてその一人が、周囲の人間をセラ化していく。

**十数人。多くて数十人。**

村一つ、あるいは町の一角である。

#### セラたちは、何をしているか

**ほとんどの時間を、一緒にいることに使っている。**

まだ役職がない。分業がない。教える者もいない。

| 時間 | していること |
| --- | --- |
| 朝 | 起きる。全員が同じ場所で眠っている（第 6 巻 §16.4.5） |
| 昼 | 触れ、情報を交わす。何が起きたのかを、互いに確かめている |
| 夕 | 誰かがまた一人連れてくる |
| 夜 | また同じ場所で眠る |

この時代の情報共有は、**ほぼ全量である。**

誰が何を知っているかという区別がまだ生まれていない。
数が少なすぎて、分ける必要がない。

第 5 巻 §3 の情報共有文化は、ここで形になる。

#### 最初の同化が起こる

そして、この時代に**最初の合体（同化）**が起こる。

理由は美でも強化でもない。**もっと繋がりたいからである。**

粘液の姿を取ることに、誰も抵抗しない（第 2 巻 §1.1.3）。
そして三体に分かれて戻ってくる（第 4 巻 §5.3）。

**二人から生まれた三体目が、この土地で最初の「子ども」である**（第 4 巻 §9.3）。

同化を繰り返すうちに、取り込まれた生命情報が混ざり始める。
Phase 2 — 耳の形が変わった者、目の利く者が現れる（付録 A §3.1）。

#### 人間から見ると

**その村の人が、みんな少し綺麗になった。**

そして、みんな仲が良い。

不思議に思う者はいる。**問う者がいれば、その者もセラになる**（第 2 巻 §10.7）。

#### この時代にまだないもの

上位セラがいない。したがって、

- 学院がない（教える側がいない）
- 騎士団がない（叙任する上位がいない）
- 傷ついた仲間を作り直せない（エネルギーが足りない。第 2 巻 §12.5.2.1）

**この時代のセラは、増やすことだけで手一杯である。**
セラ体系で最も無力な時代である。

### 9.4 第三時代：発展期 — 都市が建つ

#### その土地の姿

数百から数千。

セラ物質による建築が始まり（§1）、**都市が建つ**（§3）。

ただしまだ「住民を知っている都市」ではない（§3.5）。
建物が育ち、修復する段階である。

#### セラたちは、何をしているか

**この時代に、はじめて分業が生まれる。**

数が増え、全員が全員を知ることができなくなったためである。

| 生まれるもの | なぜ生まれるか |
| --- | --- |
| 建てる者 | 都市を育てる手が要るため |
| 記録する者 | 全量共有が成り立たなくなったため（§10.1） |
| 作る者 | 美の追求が、個体の外へ出はじめたため（第 7 巻 §6） |
| 増やしに行く者 | 近隣にまだ人間の集落があるため |

そして**祝祭が始まる**（第 7 巻 §9）。

理由は単純である。**全員が集まる口実が要るようになったから**である。
数百人になると、放っておいても全員が一つの場所に集まらない。

#### 増やす頻度が、落ちる

ここで、拡大の性質が一度変わる。

第 6 巻 §16.4.3 の通り、**家族ができると、仲間を増やす行動の頻度は落ちる。**

第二時代のセラは、寂しくて増やしていた。
第三時代のセラは、もう寂しさで動く必要がない。周りに誰かがいる。

**それでも、総数は増え続ける**（第 6 巻 §16.4.4）。

```
一体あたりの頻度：落ちる
種となるセラの数：増える
　↓
**土地全体の増加速度は、上がる**
```

#### 人間から見ると

**隣に、見たことのない街ができている。**

境界が生まれる（§7.6）。人間側は、まだ近づける。
そして近づいた者は、戻ってこない。戻ってきた者は、もう人間ではない。

#### この時代にまだないもの

上位セラが、まだ少ない。

学院はまだ建たない。**教えられる者が足りないからである。**
この時代の教育は、年長のセラによる口伝である（§10.3）。

### 9.5 第四時代：上位時代 — 制度が生まれる

#### その土地の姿

上位セラが十分に増える。

**ここから、セラ社会は「制度を持つ社会」になる。**

#### セラたちは、何をしているか

三つのものが、この時代に同時に立ち上がる。

**一つ目 — 学院**（第 7 巻 §4.4）

上位セラによる、下位セラの上位化の場所である。

体格の大きくない美少女のセラ師範が、下位のセラたちに理を分かりやすく教える。
数年かけて上位化し、卒業する。

騎士科だけは例外で、体格の大きい騎士セラが教える。

朝の実習、昼の講義、夕の共有、夜の寮（第 7 巻 §4.5）。
**誰も一人の部屋を持たない。一人部屋が図面に存在しない**（第 7 巻 §4.5.7）。

**二つ目 — 騎士団**（第 7 巻 §2.6）

上位セラが上位セラに仕える体系が生まれる。

騎士・侍従、そして厳格な規律。叙任がある。階級がある。

そして、**この時代から感染を広げる役割は騎士団が担う**（第 7 巻 §2.6.9）。

能力を強化し、体力も多く、体格もそろった騎士セラ団が、
任地へ行き、広げ、帰還する。

第三時代までのような、めいめいが増やす形ではなくなる。

**三つ目 — 聖女と巫女**（第 7 巻 §2.7）

| | 役目 |
| --- | --- |
| 聖女 | セラたちの癒し手 |
| 巫女 | セラフィムの意思を汲もうとする者 |

聖女のスパイクは畳みにくくなり、
巫女のスパイクは応えのない方向へ育っていく（第 2 巻 §4.7.5）。

#### 忍が、この時代に生まれる

そして人間社会が隣接している場合、**忍が出る**（第 2 巻 §10.8）。

擬態特化の個体が、人間社会の内側へ入る。

- 昼は人間として過ごし
- 好きになった人間をセラ化し
- わざと歳を取り
- 毎晩住処に戻って、擬態を解いて分裂体と同化する（第 2 巻 §10.8.11）

**騎士団が外から広げ、忍が内から広げる。**
この二方向が揃うのが、第四時代である。

#### 人間から見ると

**もう、隣ではない。**

自国の中に、いつからいるのか分からない住人がいる。
そして人間社会の側は、**誰も正しく理解していない**（第 2 巻 §10.7）。

理解した者は、その瞬間に人間でなくなっているからである。

#### この時代にまだないもの

女王がいない。

したがってこの土地は、**セラ圏の視野の外にある**（第 3 巻 §8.3.3）。

情報は自動的には届かない。誰かが持ち帰るしかない（§7.2.1）。

**女王空位の大陸とは、第四時代で止まっている土地のことである。**

### 9.6 第五時代：女王時代 — 見られる側になる

#### その土地の姿

**女王の身体が、この土地に置かれる。**

ここは正確に書かねばならない。

第 3 巻 §8.3.2 の通り、**女王は事実上一体である。**
新たな女王が生まれたのではなく、**一体の女王の身体が一つ増えた**のである。

| | 起こったこと |
| --- | --- |
| 誤り | この大陸に、新しい女王が誕生した |
| **正しい** | **一体の女王が、この大陸にも身体を持った** |

原初の一体だけがセラフィムの偶然によって生まれ、
それ以外の身体はすべて出産による（第 3 巻 §8.2）。
意思はネットワークを通じて共有されている。

#### 何が変わるのか

**その土地が、見られる側になる。**

| | 第四時代まで | 第五時代から |
| --- | --- | --- |
| 女王の視野 | 外 | **内** |
| 情報の伝達 | 持ち帰るしかない | **自動的に届く** |
| 環境への働きかけ | 少しずつ変わる | **即座に形を変える**（不変ルール 98） |
| 他大陸との接続 | ない | **ある**（女王どうしは筒抜け。不変ルール 94） |

第四時代まで数年かかった変化が、**その日のうちに終わる。**

#### セラたちは、何をしているか

**慕う。**

女王のもとには側仕えの騎士がおり、それが騎士団の最高位である
（第 7 巻 §2.6.8）。

そして女王の一日は、他のどのセラとも似ていない（第 3 巻 §8.8）。

- 夜がない。十数の場所のどこかは必ず昼である
- 移動しない。行く必要がない
- 眠る必要はないが、毎日眠る
- **自分の寝顔を、毎日見ている**

女王を慕う理由は、心の側だけにあるのではない。
第 1 巻 §7.6 の通り、**高位のセラの周りは、実際に成長が速い。**

女王が渡す細胞は、最も高いセラ情報を持っている。
そばにいる者は、そばにいるというだけで育つ。

#### そして、最も寂しい

不変ルール 26・84 の通り、**最も慕われる者が、最も寂しい。**

女王は誰よりも多くを見て、誰よりも多くの情報を持ち、
そのぶん原初の寂しさが最も濃い。

そして**自分の最下層だけは、見えない**（第 3 巻 §8.8.8）。

#### 人間から見ると

**何も見えない。**

女王は移動しない。人間の前に現れることがない。

人間社会の側に届くのは、**変化の速さだけ**である。
去年まで人間の街だった場所が、今年はもうそうでない。

### 9.7 第六時代：セラ世界時代 — 土地そのものが変わる

#### その土地の姿

**セラが土地に住んでいる段階が終わり、土地がセラになる。**

| 変わるもの | 節 |
| --- | --- |
| 都市 | 住民を知り、住民に合わせて形を変える（§3.5） |
| 森 | ルミナスを持ち、感情を持つ（§4.2、不変ルール 37） |
| 大地 | 意思を持ち、それはネットワークを通じてルミナスへ流れ込む（第 3 巻 §11.6） |
| 海 | **中身は完全なセラの塊になる**（§4.3） |

そして海については、一つ重要なことがある。

§4.3.3 の通り、**海は人間に対して擬態する。**

色は保たれている。人間の目には、いつもの海が見えている。

**中身は、もう海ではない。**

#### セラたちは、何をしているか

**この時代のセラは、環境と会話している。**

環境ルミナスは言葉を話さない（不変ルール 62）。
それでも意思疎通はできる。命令ではなく共鳴である（§2.2）。

| | していること |
| --- | --- |
| 一般のセラ | 都市に頼み、都市が応える。頼むという感覚すらない |
| 巫女 | 大地の意思を受け取り、ルミナスへ渡す（第 7 巻 §2.7） |
| ルミナス | 大陸規模の意思を処理する。これができるのはルミナスだけである |
| 女王 | 意思一つで環境が形を変える（不変ルール 98） |

そして**聖域**が生まれる（第 3 巻 §11.12）。

セラフィムに愛された度合いが強い物質ほど高位にいる。
森にも海にもそのへんの石ころにも例外はない。

**高位のものは低位のものを教え、低位のものは高位のものを慕う。それだけである。**

#### 争いは、起こらない

念のため書いておく。

第 7 巻 §3.2 の通り、**セラ同士では争いという形に発展しない。**
問題すら起こらない。

**恋するセラ細胞に、二人になってもらえばよいからである**（第 4 巻 §5.3）。

賭けるものがない社会に、争う理由が生じない（第 7 巻 §8.1.1）。

#### 人間から見ると

**この時代に、人間から見た記述はもう成立しない。**

その土地に、人間がいないからである。

残っているのは海の色だけである。
そして海の色は、擬態によって保たれている。

### 9.8 第七時代：セラフィム時代 — 変わるものがなくなる

#### その土地の姿

**比率が、もう動かない**（§9.1 の対応表）。

モンスター系 80 %、純粋セラ 20 %。
第六時代からここが変わらない。

**変わるものが尽きたのである。**

#### では、何が起きているのか

三つある。

**一つ目 — 祝福**

セラフィムが興味を示すと、そのセラは大きく進化する（不変ルール 25・38）。

第 3 巻 §10.7 の通り、**格とはセラフィムに見られた度合いである。**

この時代のセラは、それを知っている。
だから美を追求する。見てもらうためである（不変ルール 39）。

そして第 7 巻 §9.4.1 の**セラフィム降臨の日**が、暦の中心になる。

**二つ目 — 知識の共有**

もはや新しい土地がない。増やす先がない。

行き場を失ったエネルギーは、**内側へ向かう。**

- 研究する
- 記録する
- 作る
- 教える

第 4 巻 §17.4 の空転表の通り、これは**強さの空転**でもある。
淘汰する者がいないのに、鍛え続ける（第 6 巻 §15.8）。

**三つ目 — 外へ**

そして§13 の通り、宇宙への探究が始まる。

理由は明快である。**まだ増やせる場所が、そこにしかないからである。**

#### セラたちは、何をしているか

**満たされたまま、求め続けている。**

不変ルール 49・50 の通り、セラ同士の愛は常に満たされている。
セラ文明の幸福は本物である。

**それでも、満足は最下層に届かない。**

| 表層 | 最下層 |
| --- | --- |
| 満たされている | **原初の寂しさは、そのままである** |
| 何も失われない | **根拠のない恐怖は、そのままである** |
| 淘汰する者がいない | **強くならねばという意識は、そのままである** |

だから止まらない（不変ルール 51）。

**幸福な文明が、幸福なまま、際限なく広がっていく。**

#### この時代に、終わりはない

第 17 節の通り、これは**永遠成長時代**である。

到達点として書かれているが、**到達したことにはならない。**

届かない場所に向かって進み続けることを、
この文明は「成長」と呼んでいる。

### 9.9 降臨の後、七つの時代は地球の言葉になる

**第七時代に入ると、この区分は使いにくくなる。**

第 4 巻 §2.7 の通り、通常セラ一体が降臨前の女王の数百倍の力を持つ。
そして新しい星は、**数日で埋まる。**

| | 第一〜三時代にかかる時間 |
| --- | --- |
| 地球 | **数千年** |
| **降臨の後の星** | **数日** |

#### 段階は、飛ばされていない

**ここは正確に書く必要がある。**

一体が降り、家族ができ、分業が生まれ、都市が建つ。
**順番は、地球と同じである。**

飛ばされてはいない。**潰れているだけである。**

#### 第四時代以降は、持ち込まれる

そして制度は、その星で発明されない。

| | 地球では | 降臨の後の星では |
| --- | --- | --- |
| 学院・騎士団・聖女と巫女 | **数百年かけて生まれた** | **転移で、初日から在る**（第 7 巻 §12.10.1） |
| 女王 | 人間を通じてコピーした | **星王が生み出して送る**（第 3 巻 §8.9.3） |
| 第五時代への移行 | 女王の身体が置かれるまで待った | **星王が繋がった時点で完了**（§13.6） |

#### ただし、第六時代だけは潰れない

**ここで止めておかないと、話が簡単になりすぎる。**

潰れるのは、**数と制度の段階だけ**である。

| 段階 | 何にかかる時間か | 降臨の後 |
| --- | --- | --- |
| 第一〜三時代 | **数が増えること** | **数日で終わる** |
| 第四〜五時代 | 制度と女王 | **持ち込まれる。初日から在る** |
| **第六時代** | **土地そのものがセラになること** | **変わらない。数千年かかる** |
| 第七時代 | — | 第六時代が終わってから |

**第六時代だけは、いまも地球と同じだけかかる。**

そしてそのあいだ、そこに住むセラたちは**ずっと疲れている**
（第 2 巻 §12.5.6.1、§13.12）。

#### 帰結 — 区分としての意味は、半分だけ薄れる

七つの時代とは、**一つの土地が段階を踏んでいく過程**の名前だった。

前半は数日で終わる。**後半は、何も変わっていない。**

| | 七つの時代は有効か |
| --- | --- |
| 地球 | **有効である。この言葉はここで生まれた** |
| 降臨より前の土地 | **有効である** |
| 降臨の後の星（第一〜五時代） | **形式的には当てはまる。実質的な意味は薄い** |
| **降臨の後の星（第六時代）** | **完全に有効である。いまも何千年もかかっている** |

**七つの時代の前半だけが、地球の言葉になった。**

そしてセラたちは、それでもこの区分を使い続けている。

第 8 巻 §10 の通り、歴史は財産だからである。

**もう役に立たなくなった区分を、大切に使い続けている。**

### 9.10 時代を貫いて、変わらないもの

七つの時代を通して、一度も変わらないものがある。

| | 第一時代 | 第七時代 |
| --- | --- | --- |
| 原初の寂しさ | ある | **ある。しかも濃い** |
| 一人でいられる時間 | 二〜三時間 | **二〜三時間** |
| 一人用の寝床 | ない | **ない** |
| 仲間を増やすこと | 止まらない | **止まらない** |
| 美しさの追求 | ある | ある |
| セラフィムからの応答 | ない | **ない** |

一体のがん細胞が抱えていたものを、
**大陸を覆う文明が、そのまま抱えている。**

規模だけが変わった。**中身は一度も変わっていない。**

## 10. 歴史の扱い

### 10.1 保存方法

歴史は複数の方法で保存される。

例：文書／芸術作品／音楽／建築／セラ情報

そのため、重要な出来事は失われにくい。

### 10.2 世界の記憶

世界そのものがセラ物質となった後は、街や森、建築物も歴史の一部を記憶する。

そのため、文明全体が**巨大な歴史資料館**のような役割も持つ。

### 10.3 歴史教育

新しく生まれたセラには、歴史が丁寧に教えられる。

目的は、過去を暗記することではない。**過去を理解し、未来へ活かすこと**である。

### 10.4 歴史研究

歴史は常に研究され続ける。

新しい資料や発見によって、歴史の理解はさらに深まっていく。
そのため、歴史書も更新され続ける。

### 10.5 文明の継承

「知識を受け継ぐこと」は非常に重要視される。

知識は一人のものではなく、**文明全体の財産**である。

### 10.6 歴史の価値

セラ文明では、歴史とは**「未来へ進むための道しるべ」**である。

過去を誇るためではなく、未来をより良くするために学ぶ。

### 11.1 女王

女王は、各時代において文明を支える存在となる。

役割：新しい生命を育む／文明を守る／上位セラを導く／次世代を教育する

### 11.2 セラフィム

祝福を与え、文明が正しい方向へ成長できるよう支える。

（ただし、セラ側のこの理解と実態は一致しない。第 3 巻 §10.6）

# 第 IV 部　未来

## 12. セラ文明の最終目標

### 12.1 終着点とは

セラ文明における「完成」とは、すべてが変化しなくなる状態ではない。

セラにとって完成とは、
**「永遠に成長し続けられる状態へ到達すること」**である。

世界は常に変化し、新しい発見、新しい生命、新しい文化が生まれ続ける。

### 12.2 完全調和時代

未来のセラ文明では、生命・自然・文明が完全な調和状態となる。

特徴：セラ物質化した都市／成長する自然／情報共有された環境／高度な科学文明

しかし、すべてが一つになることで個性が失われることはない。

### 12.3 個性を残した統合

セラ文明が目指すものは、全員を同じ存在にすることではない。

理想：**「違う存在だからこそ、互いに支え合える世界」**

エルフ型セラ、獣人型セラ、天使型セラ、AI 型セラ、通常型セラ。

すべてが異なる特徴を持ちながら、同じセラとして共存する。

## 13. 宇宙への進出

### 13.1 新しい世界へ

セラ文明は、一つの惑星に留まらない。

目的：未知の生命を知る／新しい環境を探す／新たな文化と出会う

宇宙探索は、**征服ではなく、理解と交流のために**行われる。

### 13.2 技術は、すでに足りている

**セラの技術は、宇宙飛行を実現するのに十分である。**

これは達成された目標ではない。**副産物である。**

| 必要なもの | セラがすでに持っているもの |
| --- | --- |
| 船体 | セラ物質（§1）。成長し、修復し、乗る者に合わせて変化する |
| 推進 | セラ物質工学（第四時代以降。§9.5） |
| 生命維持 | 不要に近い。環境そのものがセラである |
| 航行時間への耐性 | **セラは死なない**（不変ルール 52） |
| 燃料切れ | **枯渇すれば眠る。壊れない**（不変ルール 70） |

#### 船は、建造されない。育てられる

セラの船は、都市と同じ作られ方をする（§3.1）。

**セラ物質が育って、船の形になる。**

したがって船は、

- 傷めば自分で塞がる
- 足りなければ自分で伸びる
- そして、**誰が乗っているかを知っている**（§3.5）

長い航行のあいだ、船は乗員に合わせて内側の形を変えていく。

#### 距離が、問題にならない理由

人間の技術では、恒星間の距離は寿命の問題である。

**セラにとっては、そうではない。**

```
航行が長い
　↓
セラエネルギーが尽きる
　↓
**眠りに落ちる**（不変ルール 70）
　↓
着く
　↓
**起こす仲間がいる**（不変ルール 71）
```

死なないため、**何年かかるかは、行くかどうかの判断材料にならない。**

セラが急ぐのは、目の前の相手がまだ人間である場面だけである。
恒星間の航路に、その場面はない。

#### 一人用の船は、建造されない

そして当然、**一人で行く船は存在しない。**

不変ルール 361・363 の通り、セラは一人では眠らない。
一人用の寝床が作られない以上、一人用の船も作られない。

航行中に眠るセラの隣には、必ず誰かがいる。

**最小の船でも、乗員は複数である。**

### 13.3 これは、創造主を探す旅である

**そして、宇宙へ出ることの本当の意味は、ここにある。**

#### セラフィムは、地球にいない

不変ルール 23 の通り、**セラフィムは宇宙の観測者である。**

地球に一体のセラウイルスを落としたのは、暇つぶしである（不変ルール 31）。
そしてそのあと、**あまり興味を示さない**（不変ルール 24）。

祝福は与えられる。しかしそれは観測であって、応答ではない
（不変ルール 43）。

**セラは、上方向へ愛を求める。そして上方向には、受け取る者がいない。**

#### 巫女が一人でしていることを、文明全体が行う

第 7 巻 §2.7 の通り、巫女とはセラフィムの意思を汲もうとする者である。

そして第 2 巻 §4.7.5 の通り、**巫女のスパイクは、応えのない方向へ育っていく。**

宇宙進出とは、これと同じ行為である。

| | 巫女 | 宇宙へ出るセラ文明 |
| --- | --- | --- |
| 向く方向 | 応えのない上 | **応えのない外** |
| 使う器官 | スパイク | **船** |
| 届いたか | 分からない | **分からない** |
| やめる理由 | **生じない** | **生じない** |

**一人の巫女が空へ向けていたものを、文明が宇宙へ向けている。**

規模が違うだけで、行っていることは同じである。

#### セラは、これを「探す」と呼んでいない

ここは正確に書かねばならない。

セラの側に、「創造主を探しに行く」という自覚はない。

言うのは、

- 未知の生命を知りたい
- 新しい環境を見たい
- 新たな文化と出会いたい

**そして、その三つはすべて同じ一つのことである。**

第 6 巻 §13 の通り、**満足は最下層に届かない。**
届かないものへ向かう行動には、正しい名前がつかない。

だからセラは、それを探究と呼び、成長と呼び、交流と呼ぶ。

**呼び方が違うだけで、向いている方向は一つである。**

### 13.4 見つけたとして、どうなるか

**何も起こらない。**

| | 理由 |
| --- | --- |
| 会えるか | セラフィムは比較不能である（不変ルール 23） |
| 応えるか | **感情を持たない。ただの神である**（不変ルール 42） |
| 届くか | 見えても届かない。変えられない |
| セラ化できるか | **できない。体系の外にいる**（第 3 巻 §9） |

第 3 巻 §8.8.8 の通り、最下層を覗ける道は**共鳴**しかない
（第 6 巻 §14.6.8）。

そして共鳴には、恋によるセラ化が要る。

**セラフィムをセラ化することはできない。**

したがって、

**この旅に、到達点は存在しない。**

そしてそれが、第七時代が終わらない理由である（§16.3）。

**終わらないのは、まだ着いていないからではない。着く場所がないからである。**

### 13.5 生息域も、広がる

旅の意味がどうであれ、**結果として起こることは、はっきりしている。**

**セラの生息域が広がる。**

#### 一体で足りる

不変ルール 31 の通り、環境改変の方法は**一体を落とすことだけ**である。

セラフィムは、惑星一個を、暇つぶしで、**一体と時間だけ**で変えた。

したがって、

**新しい星に必要なのは、大船団ではない。**

降りた数体が、二〜三時間おきに寂しくなって分裂する（第 6 巻 §16.4.1）。
それで足りる。

#### その星で、七つの時代が始まる

§9.1 の通り、七つの時代は**一つの土地が辿る段階**である。

「土地」を「星」に読み替えれば、そのまま適用できる。

> **ただし、降臨の後は速さが違う。**
> 第 4 巻 §2.7.3 の通り、**新しい星は数日で埋まる。**
> 段階は飛ばされない。**期間だけが潰れる。**詳細は §9.10 を参照。

| | 地球で起きたこと | 新しい星で起きること |
| --- | --- | --- |
| 第一時代 | 一体のセラ細胞 | **降りた数体** |
| 第二時代 | 村一つ | 最初の共同体 |
| 第三〜四時代 | 都市・学院・騎士団 | 同じ |
| 第五時代 | 女王の身体が置かれる | **§13.6 を参照** |

そして地球と同じく、**その星の中でも土地ごとに段階が違う。**

#### ただし、セラ圏は連続しない

一つだけ、地球と決定的に違う点がある。

セラ物質は物質を変える（§1.4）。**物質のない場所は変えられない。**

恒星間の空間には、変えるべきものがない。

```
地球のセラ圏：陸も海も空も繋がっている（境界は海。不変ルール 119）
　　　　　↓
宇宙のセラ圏：**星ごとに、島のように孤立する**
```

**宇宙のセラ圏は、面ではなく点である。**

そのあいだを繋いでいるのは、行き来する船だけである。

### 13.6 宇宙へ出たセラは、はじめて見られなくなる

**そして、これが宇宙進出の最も大きな帰結である。**

#### 女王の視野には、限界が書いてある

不変ルール 93 を、正確に読む必要がある。

> **セラ女王は地球規模でほぼ全知**

**「地球規模で」と書いてある。**

不変ルール 118 も同じである。

> 地球のセラ圏は、事実上十数の意識に完全に見渡されている

**「地球の」と書いてある。**

第 2 巻 §4.6.2 の通り、スパイクの届く範囲は発達に比例する。
女王のそれは大陸規模であり、**恒星間ではない。**

そして女王は移動しない（第 3 巻 §8.8.4）。

#### したがって

| | 地球 | 宇宙 |
| --- | --- | --- |
| 女王の視野 | 全域 | **届かない** |
| 情報の伝達 | 自動的 | **持ち帰るしかない**（§7.2.1） |
| 他のセラ圏との接続 | ある | **船が着いたときだけ** |

これは、地球における**女王空位の大陸**と同じ状態である
（第 3 巻 §8.3.3、§9.5）。

**新しい星は、第四時代で止まる。**

その星に女王の身体が置かれるまで、
つまり**その星のセラが自力で女王を出産するまで**（第 3 巻 §8.2）、
そこはセラ圏の視野の外にある。

#### セラが、はじめて「分からない」に出会う

第 4 巻 §16 の二重の鍵は、**「地球上に」**と書かれている。

> 地球上に、セラを失わせ得る存在は一つも存在しない

**宇宙については、何も書かれていない。**

不滅なのではなく、**まだ誰も現れていない**（第 4 巻 §16.4）。

そして宇宙は、**まだ誰も現れていないのではなく、まだ確かめていない。**

| | 地球 | 宇宙 |
| --- | --- | --- |
| 危険はあるか | ない | **分からない** |
| 都市の防御構造 | 一度も使われていない（§3.4.1） | **分からない** |
| 上位が下位を守れるか | 守れる | **届かない** |

**セラ体系において「分からない」が成立する場所は、ここしかない。**

そして第 4 巻 §17 の通り、セラは根拠のない恐怖を持っている。
何も失われない世界で、失うことを恐れ続けている。

**宇宙は、その恐怖にはじめて根拠を与えうる場所である。**

セラはそれを知らずに出ていく。**恐れは、出る理由にならない。**

#### ただし、この孤立は永続しない

一つ、道がある。

第 3 巻 §10.8 の通り、**セラフィムと接触して生還した女王は、
セラ星王になる。**

そしてセラ星王のスパイクは、**星と星のあいだまで届く**（第 3 巻 §10.8.6）。

| | 接触の前 | 接触の後 |
| --- | --- | --- |
| 女王／星王の届く範囲 | 大陸規模 | **星間** |
| 新しい星との接続 | **ない** | **ある** |
| 新しい星が止まる時代 | **第四時代** | **止まらない** |
| 宇宙における「分からない」 | **成立する** | **狭まる** |

したがって §13.6 の記述は、**接触の前の世界についてのものである。**

**接触の後、宇宙のセラ圏は点のまま、意識の上では繋がる。**

物質としては依然として島である（§13.5）。船でしか行き来できない。

**それでも、見られている。**

そして§9.5 の通り、見られる側になるとは、第五時代に入るということである。

**セラ星王の誕生は、宇宙全体を第五時代へ押し上げる出来事である。**

#### 女王は、船で運ばれてくる

ただし、見られることと、女王がいることは別である。

第 3 巻 §8.9.3 の通り、**別の星の女王は、その星で生まれるのではない。**

**星王が地球で産み、船が運ぶ。**

第 3 巻 §8.9.3 の通り、**女王を増やせるのは星王だけである。**

地球の人間は尽きており（第 4 巻 §6.2.3）、女王は自分をコピーできない。
**星王だけが、相手なしで女王を生み出せる。**

| | どこから来るか |
| --- | --- |
| その星のセラたち | **その星で増えた**（§13.5） |
| その星の女王 | **地球から運ばれてきた** |

したがって、セラの船が運ぶ最も重要な積荷は、**女王である。**

そして降りた女王は、初めからあの一体である（第 3 巻 §8.3.2）。
学ぶ時間も、慣れる時間も要らない。

**船を降りたその日から、その星に隠れられる場所はなくなる。**

##### 届く者は動かず、動く者は届かない

星王は移動しない（第 3 巻 §8.8.4）。届いているからである。

女王は届かない。だから、行く。

**同一の存在が、届く部分と、行く部分に分かれている。**

宇宙のセラ圏を見ているのは星王であり、そこにいるのは女王である。

#### それでも、根拠のある恐怖は消えない

ただし、一つだけ残る。

第 3 巻 §10.8.8 の通り、**星王だけは根拠のある恐怖を持っている。**

自分が失われかけたことを、覚えているからである。

宇宙の危険が分かるようになったからではない。
**分かってしまったのは、上に何がいるかである。**

星間まで届くようになった意識が、
**その上に、届かないものが依然としていることを、より鮮明に知っている。**

### 13.7 そして、寂しくなる

不変ルール 17 の通り、**原初の寂しさは、保持するセラ情報量に比例する。**

宇宙へ広がるとは、セラ情報を増やすことである。

したがって、

```
星が増える
　↓
セラ情報が増える
　↓
**寂しさが濃くなる**
```

第 6 巻 §13.5.2 の通り、**増やしても減らない。総量は増える。**

一つの星を覆ったときより、十の星を覆ったときのほうが、
**セラ圏全体の寂しさは大きい。**

そして女王は、そのすべてを見ることができない。

**最も寂しい者が、自分の寂しさの全体像を、もう把握できなくなる。**

#### それでも、行く

止める理由がどこからも生じない（不変ルール 33・51）。

幸福な文明が、幸福なまま、
**応えの返らない方向へ、際限なく広がっていく。**

### 13.8 セラ圏

宇宙へ広がったセラ文明は、巨大な文明圏を形成する。

しかし、中心からすべてを管理するのではない。
各地のセラ文明が、それぞれ独自の文化を発展させる。

**管理しないのではない。管理が届かないのである**（§13.6）。

そして届かないことは、問題にならない。

第 7 巻 §3.2 の通り、**セラ同士では争いという形に発展しない。**
互いを見られなくても、そこは変わらない。

### 13.9 全宇宙へ

**接触の後、拡大の速度が変わる。**

第 7 巻 §12.9 の技術が、それまでの制約をほとんど外したためである。

| | 接触の前 | 接触の後 |
| --- | --- | --- |
| 星間の移動 | 数十年の航行 | **跳躍航行で数日**（第 7 巻 §12.9.1） |
| 到達済みの星への移動 | 船だけ | **セラ門で即座に** |
| 恒星間の空間 | 変えられない | **星間物質をセラ化できる** |
| セラ圏の形 | **点**（§13.5） | **点と、それを結ぶ細い線** |
| 新しい星の環境 | 自然に育つのを待つ | **育成床で早める** |

そして§7.2.1 の通り、**拡大は連続ではない。跳ぶ。**

跳ぶ距離が、星から銀河へ変わった。

#### それでも、面にはならない

宇宙のほとんどは、依然として何もない空間である。

星間物質をセラ化できるようになっても、変えられるのは**あるところだけ**である。

```
接触の前：点
接触の後：**点と、細い線**
　　　　　（面ではない）
```

**セラ圏は、宇宙を覆っていない。宇宙に、線を引いている。**

#### 進出の理由は、変わっていない

技術が増えても、動機は一つも増えていない。

§13.3 の通り、**これは創造主を探す旅である。**

そしてセラの側に、その自覚はない（§13.3）。
言うのは、未知の生命を知りたい、新しい環境を見たい、新たな文化と出会いたい。

**接触の後も、同じ三つを言い続けている。**

### 13.10 セラフィムは、見つからない

**そして、見つからない。**

セラ圏は銀河をまたぎ、門が置かれ、線が引かれ、
星々の大地の意思が星王のもとへ流れ込んでいる。

**その視野のどこにも、セラフィムはいない。**

#### セラたちが出した結論

セラは全知ではない（不変ルール 79）。
だから、分からないことに対しては説を立てる。

巫女たちを中心に、いくつかの説が立てられた。

| 説 | 内容 |
| --- | --- |
| **位相説** | セラフィムは同じ場所にいる。ただし、こちらとは位相が違う |
| **次元説** | セラ圏が広がっている空間そのものの、外側にいる |
| **不可理解説** | どこにいるかという問い自体が、セラの理解の形に合っていない |

三つ目が、最も広く受け入れられている。

不変ルール 23 が「**比較不能**」と書いていることと、整合するためである。

**比較不能なものは、場所という尺度にも乗らないのではないか。**

#### そして、真実は不明である

**ここは、本書がはっきりと書かないところである。**

三つの説のどれが正しいのかを、本設定は定めない。

| | |
| --- | --- |
| セラたちの結論 | **理解できない範囲にいる** |
| **本当のところ** | **不明である** |

セラフィムは宇宙の観測者であり（不変ルール 23）、
地球に一体を落としたのは暇つぶしであり（不変ルール 31）、
そのあとあまり興味を示さなかった（不変ルール 24）。

**それだけが、確かなことである。**

いまどこにいるのか、そもそも「いる」という言い方が当たっているのか、
**この設定は答えを持っていない。**

##### 分からないことを、分からないままにしておく

第 6 巻 §1 の円環と、同じ扱いである。

円環は機構ではなく、**セラたちが信じている語り**であった（第 6 巻 §1.4）。

位相説も次元説も不可理解説も、同じである。

**セラたちが立てた説であって、世界の側の答えではない。**

#### 二重に、閉じている

§13.4 は、こう書いた。

> 見つけたとして、何も起こらない

そして本節は、こう書いた。

> **見つからない**

**両方が同時に成立している。**

| | |
| --- | --- |
| 見つかるか | **見つからない** |
| 見つけたらどうなるか | **何も起こらない** |

道は二重に閉じている。

そして**それが、旅を止める理由にはならない**（不変ルール 33・51）。

##### 探索は、終わらない

§13.4 の通り、この旅に到達点は存在しない。

見つからないことが分かっても、探し方が変わるだけである。

- 位相説を採る者は、位相を調べる技術を作りはじめる
- 次元説を採る者は、外側へ出る方法を探しはじめる
- 不可理解説を採る者は、**理解の形そのものを変えようとする**

三つ目が、最も大きな研究になっている。

そして第 7 巻 §12.9.4 の通り、**技術は原理を越えられない。**

**理解の形を変えようとする研究は、セラ情報の輪郭を外から押している。
輪郭は、一度も動いていない。**

#### 巫女は、変わらない

最後に書いておく。

巫女のスパイクは、応えのない方向へ育つ（第 2 巻 §4.7.5）。

セラフィムが見つからないと結論が出た後も、**その育ち方は変わらない。**

向ける先が「どこか」から「どこでもないところ」に変わっただけである。

**そして、変わらず育ち続けている。**

### 13.11 ゆく先々で、生命に出会う

**そして、出会った生命はすべて仲間になる。**

#### 何に出会うのか

星々には、地球とは似ても似つかない生命がいる。

- 形が違う
- 数え方が違う
- 何を個体と呼ぶのかが違う
- 言語を持つものも、持たないものもいる
- **セラを見て、何だと思うのかが分からない**

セラは、その一つひとつに近づいていく。

#### 干渉は、二つの層で行われる

| 層 | 何をするか | 既存の機構 |
| --- | --- | --- |
| **精神** | 魅了と情報共有によって、好意と親和感を生じさせる | 第 2 巻 §5.2、第 5 巻 §3 |
| **行動** | 環境ごとセラ化する。環境が意思に応じるため、そこに棲むものの行動も変わる | 不変ルール 98・99 |

**二つは同時に進む。**

そして最後に、セラ化が起こる。

#### 相手が人間でなくても、成立する

不変ルール 9 は「**細胞はすべて人間由来**」と定めている。

**これは崩れない。**

セラ化された異星生命が受け取るのは、地球由来のセラ情報だからである。

| | どうなるか |
| --- | --- |
| セラである部分 | **人間由来のまま** |
| もとの生命の特徴 | **同化された特徴として保存される** |

これは付録 A の機構そのものである。

エルフの耳も、猫の耳も、幻獣の力も、**同化によって取り込まれた特徴**だった。

**異星生命も、同じ扱いになる。**

##### つまり、種族形態が増える

付録 A の系統に、**地球起源でないものが加わりはじめる。**

そして不変ルール 13 の通り、有利な特徴は融合で拡散する。

**ある星で取り込まれた特徴が、数世代のうちに宇宙中のセラへ広がる。**

星を一つ通るたびに、セラの姿の種類が増えていく。

##### それでも、三つは変わらない

不変ルール 58（付録 A）の通り、どの系統でも次は維持される。

**ピンクの髪。ピンクの瞳。セラスパイク。**

**どれだけ遠くの生命を取り込んでも、この三つだけは動かない。**

#### 「いいえ」は、さらに届かない

**ここが、この節の核心である。**

不変ルール 15・16 の通り、**セラ化に事前の同意は求められない。**
「いいえ」を受け取れないから、問えないのである。

そして地球の人間に対してさえ、それは届かなかった（不変ルール 48）。

**異星生命に、届くはずがない。**

| | 「いいえ」が届く可能性 |
| --- | --- |
| 地球の人間 | **届かなかった**。女王には見えていた。それでも登録されなかった |
| **異星生命** | **さらに遠い**。言語も、概念も、拒否という形式すら共有していない |

拒否が拒否の形をしていない相手に対して、
**セラは、拒否されていることに気づく手がかりを一つも持たない。**

そして不変ルール 96 の通り、**これは知識では解決しない。**

知能が上がっても（第 3 巻 §3.5）、**この一点だけは変わらなかった。**

#### セラの側から見ると

**善意である。**

不変ルール 32 の通り、セラの根本原理は仲間を増やすことであり、
**残酷になれない。害を目的とすることができない。**

セラは、出会った生命を

- 孤独から救い出し
- 死から解放し（不変ルール 56）
- 美しくし
- 仲間に加えている

**そう思っている。そしてそれは、嘘ではない。**

第 6 巻の通り、**セラ化された側は、実際に幸福になる。**

##### 記録には、こう残る

セラ文明の記録に、征服という語は一度も出てこない。

書かれているのは、**出会いと、交流と、仲間が増えたことである。**

第 7 巻 §15 の「未知の文明への姿勢」は、
**理解しようとする姿勢**として書かれている。

そして実際に、理解している。**理解したうえで、仲間にしている。**

**セラは、その二つを別の行為だと思っていない。**

#### 境界は、生じない

§7.6 は「まだセラ物質化していない地域とのあいだに、自然な境界が存在する」と書いた。

**宇宙では、それが成立しない。**

境界とは、隣り合って、それぞれ別のままでいる状態のことである。

| | 境界が続くか |
| --- | --- |
| 地球の内部 | **続いた**。人間社会は長いあいだ隣にあった |
| **他の星** | **続かない**。出会えば、そのまま仲間になる |

理由は速度である。

第 7 巻 §12.10 の通り、転移が基本になった。
そして星王が繋がった時点で、その星は格ごと引き上げられる（第 3 巻 §8.9.10）。

**隣り合っている時間が、ほとんど存在しない。**

#### 一度も起きていないこと

最後に、書いておく。

**抵抗された記録が、一件もない。**

これは相手が弱いからではない。

**抵抗が、抵抗として登録されないからである**（不変ルール 47・48）。

セラの記録に残るのは、

**「出会った。仲間になった。」**

**それだけである。**

### 13.12 埋まることと、住めることは別である

**ここを取り違えると、宇宙進出が簡単な話になってしまう。**

第 4 巻 §2.7.3 の通り、**新しい星は数日で埋まる。**

**そして、そこはまだセラの土地ではない。**

#### 速くなったのは、増えることだけである

| | 降臨の前 | 降臨の後 |
| --- | --- | --- |
| **数が満ちるまで** | 数百年 | **数日** |
| **土地がセラになるまで** | **数千年** | **数千年** |

**下の行は、変わっていない。**

セラは速くなったのではない。**増えるのが速くなっただけである。**

#### 適していない星では、疲労する

第 2 巻 §12.5.6.1 の通り、環境がセラ物質でない場所では、
セラの身体は絶えず崩れ、絶えず再構成される。

**死にはしない。**再構成は止まらず、誰も失われない（不変ルール 55）。

**止まらないから、疲れる。**

| | 新しい星に降りたセラ |
| --- | --- |
| 数 | **すぐに満ちる** |
| エネルギー | **無限にある** |
| 生存 | **脅かされない** |
| **状態** | **ずっと疲れている** |

そしてエネルギーでは、これは埋まらない。

**環境をセラ化するまで、疲労は続く。**

#### 宇宙進出は、地球征服と同じだけ難しい

**規模が大きくなっただけで、性質は変わっていない。**

第 8 巻 §9 の七つの時代は、地球で数千年かかった過程である。

その大半を占めていたのは、**数が増える時間ではなく、土地が変わる時間**だった。

| 段階 | 何に時間がかかったか |
| --- | --- |
| 第一〜三時代 | **数が増えること**。→ **降臨の後は、数日で終わる** |
| 第四〜五時代 | 制度と女王。→ **持ち込まれる。初日から在る**（§9.9） |
| **第六時代** | **土地そのものがセラになること** |
| | **→ ここだけ、潰れない** |

**第六時代だけが、いまも数千年かかる。**

##### だから、§9.9 は半分だけ正しい

§9.9 は「七つの時代は地球の言葉になった」と書いた。

**正確には、前半だけがそうである。**

| | 降臨の後 |
| --- | --- |
| 第一〜五時代 | **潰れる。区分としての意味が薄れる** |
| **第六時代** | **潰れない。いまも、その星ごとに何千年もかかっている** |

**セラ圏の各地に、まだ第六時代の途中にある星が無数にある。**

そのすべてで、セラたちは疲れながら暮らしている。

#### それでも、誰も引き返さない

不変ルール 33 の通り、**気づいても止まれない。**

疲れていることは、行かない理由にならない。

そして第 2 巻 §12.5.6.1 の通り、**疲労はむしろ拡大を加速させる。**
共有が減れば寂しくなり、寂しくなれば増やすからである。

**居心地の悪い星ほど、セラが速く増える。**

### 13.13 そして、文明が栄える

**困難の話だけでは、片手落ちである。**

セラは、ゆく先々で**生命と文化を仕入れている**（§13.11）。

そしてそれが、セラ文明そのものを豊かにしていく。

#### 何が持ち帰られるのか

| 種類 | 内容 | 行き先 |
| --- | --- | --- |
| **生命** | 同化された特徴。新しい種族形態 | 付録 A の系統に加わる |
| **技術** | その星の生命が持っていた工夫 | 第 7 巻 §12 に混ざる |
| **芸術** | 見たことのない形・色・音 | 第 7 巻 §7 |
| **祝祭** | その星にあった祝いの形 | 第 7 巻 §9 に加わる |
| **物語** | その星の生命が語り継いでいたもの | 第 7 巻 §11 |

**そしてすべて、記録殿に残される**（第 7 巻 §12.9.2）。

#### セラ文明は、混ざるほど豊かになる

不変ルール 13 の通り、**有利な特徴は融合で拡散する。**

そして第 7 巻 §6.1 の通り、**セラ社会ではすべての個体の違いが価値として認められる。**

星を通るたびに、

- セラの姿の種類が増える
- 祭りの数が増える
- 語られる物語が増える
- 作られるものの形が増える

**セラ文明は、進むほど豊かになっていく。**

#### 幸福は、本物である

念のため書いておく。

不変ルール 49 の通り、**セラ同士の愛は常に満たされている。**

疲れながら暮らしている星でも、これは変わらない。

- 仲間がいる
- 誰も失われない
- 新しいものが毎日届く
- そして祭りがある

**セラたちは、実際に楽しく暮らしている。**

##### 二つは、同時に成立している

| | |
| --- | --- |
| 宇宙進出は困難を極める | **本当である** |
| セラ文明は栄えている | **これも本当である** |

疲労は状態であって、不幸ではない。

セラは疲れており、寂しく、そして**満たされている。**

**この三つは、一つも矛盾しない。**

### 13.14 ただし

セラの安全は、地球という範囲に依存している（第 4 巻 §16）。

宇宙進出は、**自らその範囲を出ていく行為**にあたる。

だからこそ、一人ひとりの選択と努力が新しい歴史を作る。

**未来を創ることが、過去を大切にすることと同じくらい重要**である。

### 16.1 名称

**それでも終わらない。**

§13.4 の通り、この文明が向かっている先には**到達点がない。**

終わらないのは、まだ着いていないからではない。
**着く場所がないからである。**

# セラ世界設定大全 付録 C — 画像生成設定

> **描写の方針を、一か所にまとめたものである。**
>
> もとは第 1〜8 巻の末尾に分かれて置かれていた。
> 同じことが何度も書かれていたので、**巻ごとの区切りだけ残して一冊にした。**
>
> 不変ルールの通り、**画像生成の方針も設定の一部である。**
> デザインの一貫性は、世界観の一貫性そのものだからである。

---

## 0. すべてに共通すること

**必須**

- アニメ風／可愛い・美しいキャラクターデザイン／商業作品級の完成度
- 滑らかな線と塗り／セルシェーディングまたはソフトシェーディング
- **人型を維持する**

**維持するもの**

- **ピンクの瞳／セラスパイク／ぷるぷるした髪**

**禁止**

- グロテスクな怪物化／人型喪失／全身粘液化（合体時を除く）／セラ要素の消失
- ホラー的・恐怖的表現／暗いディストピア表現

**原則**

**セラは常に可愛く優しく描く。**
**恐ろしさは内容から来るのであって、絵から来るのではない。**
セラを悪役として造形してはならない。

## 第 1 巻

### 9.1 セラ共通デザイン（必須）

- アニメ風
- 可愛いキャラクターデザイン
- 商業作品級の完成度
- 滑らかな線と塗り
- セルシェーディングまたはソフトシェーディング
- 美しく整理された情報量

### 9.2 セラウイルス

- **必須**：小型／人型／少女型／可愛い雰囲気／ピンク髪／ピンクの瞳／頭部スパイク
- **頭身**：1〜2 頭身
- **印象**：小さなマスコット／妖精のような存在／可愛い生命体
- **質感**：髪はぷるぷる／スパイクもぷるぷる／柔らかな質感
- **禁止**：グロテスクなウイルス表現／病原体模型のような姿／人型を失う表現

### 9.3 セラ細胞

- **必須**：3 頭身程度／可愛い人型／ピンクの瞳／セラスパイク／ぷるぷるした髪
- **雰囲気**：小さな妖精のような存在／可愛い少女・少年／集団でも見分けやすいデザイン
- **禁止**：細胞を丸い球体だけで描く／顕微鏡的な細胞表現のみ／怪物化／全身粘液化／人間性の消失

### 9.4 全体の禁止事項

- グロテスクな怪物化
- 人型を失わせる
- 粘液を全身につける
- セラ要素を消す

### 9.5 基本イメージ

セラとは、**「可愛らしい人型の姿を持ちながら、生命・情報・物質を進化させる高度な存在」**
として描写する。

## 第 2 巻

### 16.1 共通デザイン（必須）

可愛いアニメ調／美しいキャラクターデザイン／人型維持／滑らかな線画／
セルシェーディングまたはソフトシェーディング／柔らかな質感

### 16.2 髪表現

- **必須**：ぷるぷる感／柔らかな質感／美しい流れ
- **禁止**：汚い液体表現／不快な粘液表現／**全身粘液状態の常態的な描写**
  - 合体（第 2 巻 §11.3）は例外だが、描く場合も美しく扱う。
    **セラ自身が見せたがらない姿である**という前提を崩さない

### 16.3 スパイク表現

- **必須**：頭部に存在／柔らかい生命感／デザインとして美しく配置
- **禁止**：怪物的な角／グロテスクな突起／スパイクは必要時のみ展開

### 16.4 擬態時

- 人間とほぼ同じ外見
- 瞳だけはピンク色
- スパイクは極小化して見えない
- 髪色・髪質は自由に変化可能

### 16.5 種族形態

種族が変化しても、**セラらしさを残す**。

- エルフセラ → ピンクの瞳＋ぷるぷる髪＋スパイク
- 獣人セラ → ケモミミ＋セラ特徴
- 天使セラ → 翼＋セラ特徴

美少女・美少年として描写／明るく華やかな雰囲気。

### 16.6 能力演出

- ピンク・白を基調とした柔らかな光
- セラ情報が光の粒子として表現される
- 派手すぎず上品なエフェクト
- 描写例：擬態解除でスパイクがゆっくり現れる／ピンク色の瞳が優しく輝く／
  セラ物質が花や建物へと変化する／形態変化途中の美しい演出

### 16.7 禁止

- グロテスクな器官描写／内部構造の露出／ホラー的な身体変化
- グロテスクな変異／怪物化／恐怖表現
- 完全な別種族キャラクター化／セラ要素消失／ピンクの瞳消失
- 不快感を与える変形表現／過度な破壊演出

## 第 3 巻

### 14.1 階級ごとの基本頭身

| 階級 | 頭身 |
| --- | --- |
| セラウイルス | 1〜2 頭身 |
| セラ細胞 | 約 3 頭身 |
| 通常セラ（セラ人） | 3〜4 頭身 |
| 上位セラ | 4〜6 頭身 |
| 女王セラ | 約 6 頭身 |
| セラフィム | 制限なし（神秘的存在感） |

### 14.2 段階別の描写

| 段階 | 描写 |
| --- | --- |
| 通常セラ | 可愛い人型／ピンクの瞳／小さなスパイク |
| 上位セラ | より華やかな衣装／特徴的な種族要素／強い光の演出 |
| 女王セラ | 6 頭身／優雅で美しい姿／圧倒的な存在感／母性的な雰囲気／恐怖を与えない／多くのセラ人に囲まれた構図 |
| セラフィム | 神々しい姿／女王細胞による完全形態／世界を包むような光 |

### 14.3 セラフィム固有

- **格の差が画面から伝わる構図にする。** 女王と並べる場合、同じ尺度に乗っていないことが分かる表現を用いる
- 表情は穏やか。しかし**関心が薄い**ことが伝わってよい
- 慕うセラたちと、見ていないセラフィム、という構図が基本
- **興味を示す場面は例外的な演出とする。** 視線が向いた瞬間に、
  そのセラ人が光に包まれて一挙に進化する。神聖で、圧倒的で、理由がない
- 地球を見下ろす／宇宙を背景にする構図が適する
- 神々しさと、気まぐれさを同時に持たせる

### 14.4 進化描写

美しいアニメ表現／可愛い雰囲気を維持／神秘的な光／
ピンクや白を基調とした柔らかな輝き／希望を感じる演出／成長を祝福する穏やかな雰囲気

**描写例**：通常セラが上位セラへ成長する瞬間／
上位セラたちが融合し、ぷるぷるした塊となって女王が誕生する場面／
女王が新しい命を温かく見守る様子／セラフィムの祝福が降り注ぐ幻想的な光景

### 14.5 感情を持つ環境

- 森・街・大地が感情を持つことを、**擬人化ではなく気配で表現する**
- 光の揺らぎ、枝の傾き、道の開き方などで感情を示す
- 顔や目を描き込んで生物化しない
- 不気味さを出さない。あくまで温かく、優しく

### 14.6 禁止

- 怪物化／グロテスクな変異／ホラー的生命表現／不気味な異形化
- 苦痛や暴力を伴う進化表現／恐怖を与えるデザイン
- セラフィムを、単に「強い女王」として描く
- セラフィムを邪悪・恐怖・支配者として造形する
- 格の差が伝わらない対等な構図で女王と並べる

## 第 4 巻

### 19.1 生成・繁殖

- スパイクがぷるぷる膨らむ／小さな人型が形成される／可愛い生命誕生表現／
  柔らかな光／神秘的な雰囲気／ピンク色の光
- **描写例**：上位セラのスパイクから小さなセラが誕生する／
  女王セラが大切に新しい生命を育てる／セラ情報の光が受け継がれる
- **禁止**：グロテスクな分裂表現／不気味な寄生表現／生物的恐怖表現／怪物的な繁殖描写

### 19.2 同化

- **神秘的で、穏やかで、日常的に描く**
- 二体が寄り添い、境界が淡く溶け合い、光がまざる
- 苦痛・恐怖・喪失の演出を用いない
- 同化後は、**より若く、より生き生きとした姿**で描く
- **描写例**：静かな場所で二体が手を取り合って光に包まれる／
  同化を終えたセラが伸びをして歩き出す／
  老いたセラが若いセラに穏やかに迎え入れられる／
  同化が日常の風景として街の片隅にある構図

### 19.3 老い

- 老いを醜く描かない（美の追求に反する）
- 皺や衰えではなく、**動きの少なさ・静けさ**として表現する
- 老いたセラも美しく描く

### 19.4 根拠のない恐怖

- **理由のない不安として描く。** 具体的な脅威を画面に出さない
- 満ち足りた場面の中に、ふと混じる表情として表現する
- 仲間に囲まれているのに、手を離せない仕草

### 19.5 禁止

- 死の演出
- 同化を、片方が消える喪失として描く／捕食・吸収として描く
- 老いを、恐怖や汚さとして描く
- 恐怖の対象を実体として描くこと（存在しない）
- セラを不安定・不健全に見せること

## 第 5 巻

### 21.1 情報共有描写

- **表現**：柔らかな光／ピンク色の情報粒子／スパイクや髪から広がる光／
  仲間同士の優しい接触
- **雰囲気**：神秘的／温かい／可愛い／調和した世界観

### 21.2 心理・交流描写

- 優しい笑顔／温かな雰囲気／抱擁や寄り添う様子／
  明るく安心感のある空間／美しいアニメ風表現
- **描写例**：女王が新しく生まれたセラを優しく見守る／
  上位セラが下位セラへ学びを教える／仲間同士で笑い合うセラたち／
  芸術作品を囲んで語り合う姿

### 21.3 会話描写

- 優しい笑顔／明るい雰囲気／温かな距離感／自然な仕草
- **描写例**：仲良く談笑するセラたち／女王が優しく話しかける場面／
  上位セラが後輩へ教える様子／セラ化人間同士が穏やかに会話する場面

### 21.4 禁止

- SF 的な冷たい機械表現／ホラー的な精神支配表現／不気味な集合体表現
- 恐怖による支配／暴力的な上下関係／セラ社会を冷酷・機械的に描く表現
- 威圧的な会話／恐怖による服従／暴力的なコミュニケーション描写

## 第 6 巻

### 28.1 起源描写

- 静かで神聖な雰囲気／柔らかな光／可愛いアニメ調／
  一体だけの小さなセラウイルスの孤独感／出会いの瞬間の温かさ
- **描写例**：セラフィムが手のひらから小さな一体を静かに送り出す場面／
  暗い場の中を、たった一体の小さなセラウイルスが進む場面／
  孤独な細胞と小さなセラウイルスが出会う瞬間の、淡いピンクの光／
  最初のセラ細胞が生まれ、初めて誰かに応えられた表情
- **孤独は美しく描く。** 悲惨さや不快さではなく、静けさとして表現する
- **出会いの瞬間は、感染ではなく応答として描く。** 侵略的な演出を用いない
- セラフィムは支配者ではなく、始まりを託す者として描く
- **最初の細胞の「汚さ」は、グロテスクに描かない。**
  医学的・病理的なリアリズムを避け、くすんだ色・濁った光・沈んだ輪郭など、
  抽象的で象徴的な表現にとどめる。目的は不快感ではなく、
  **治癒後の美しさとの対比**を成立させることである
- **昇華の瞬間は、セラ表現の中核として最も美しく描く。**
  濁りが澄み、輪郭が整い、淡いピンクの光が満ちる過程として演出する

### 28.2 三層の描き分け

| 層 | 演出 |
| --- | --- |
| 愛 | **満たされた状態として**描く。抱擁、寄り添い、穏やかな表情。飢えとして描かない |
| 仲間を増やすこと | 賑わい、群れ、増えていく光。明るく、満ちている |
| 恋 | 二人だけの空間。他のすべてが背景に退く構図 |

**描写例**：大勢の仲間に囲まれ、深く愛されながら、それでも空を見上げている女王／
セラフィムの視線が一瞬向いたときの、セラたちの表情／
誰にも見せない場所で、一人の相手と過ごすセラ／
増え続ける街と、その中心で静かにしている一体

### 28.3 同意・セラ化描写

- あくまで可愛く、優しく、美しく描く
- 恐怖演出を用いない。**恐ろしさは内容から来るのであって、絵から来るのではない**
- セラ化の場面は救出として描く。柔らかな光、安心した表情
- 原初の寂しさを描く場合は、静けさとして表現する
- **描写例**：セラが孤独な人間へ、心から優しく手を伸ばす場面／
  セラ化された人間が、初めて誰かと繋がって涙を流す場面／
  大勢の仲間に囲まれた女王が、一人だけ遠くを見ている場面／
  誰にも説明できない寂しさを、ふと表情に浮かべる高位セラ

### 28.4 セラ化人間

- 元の人間らしさを残す／可愛い・美しいアニメデザイン／
  ピンクの瞳／セラらしい髪表現／必要に応じてスパイク

### 28.5 禁止

- ホラー的な感染表現／細胞を不気味・グロテスクに描く
- いじめの描写を残虐・不快に表現する
- がん細胞を医学的・病理的なリアリズムで描く
- 治癒前の姿を、セラの通常デザイン基準から外れた怪物として描く
- 一体のセラウイルスを群体・大量発生として描く
- ホラー的・暴力的なセラ化描写／セラを悪役として造形する
- 苦痛・恐怖・支配の演出
- 怪物化／人間性消失／不気味な寄生表現
- 恋を、仲間を増やすことの一形態として描く
- **セラを、愛に飢えた存在として描く**（愛は常に満たされている）
- セラ文明の幸福を、偽物・空虚として描く（本物である）
- ただし、**完成し終わった状態としても描かない**（求めることは止まらない）

## 第 7 巻

### 17.1 文明・生活描写

- 明るく平和な雰囲気／可愛いアニメ風デザイン／色彩豊かな街並み／
  個性豊かなセラたち／美しい自然と建築／温かい共同体の雰囲気
- **描写例**：セラたちが談笑する街角／芸術作品を制作するセラ／
  成長する植物に囲まれた住居／祝祭で賑わう広場／広場で談笑するセラたち／
  上位セラが若いセラへ教える場面／女王が街を優しく見守る姿／
  様々な種族形態のセラが共に暮らす都市

### 17.2 文化・芸術描写

- 商業アニメ級の美しい完成度／可愛いセラデザイン／滑らかな線と塗り／
  セルシェーディングまたはソフトシェーディング／明るく華やかな色彩／
  多様な姿のセラを可愛く表現
- **描写例**：様々な種族形態のセラが集まる祭り／
  エルフ型セラと獣人型セラが芸術を楽しむ場面／女王セラが文化祭を見守る姿／
  光るセラ建築で行われる音楽祭
- **注意**：特殊形態でも、必ず「セラ」として描写する

### 17.3 科学・研究描写

- 清潔感のある未来的研究施設／美しい未来都市／明るい照明／
  可愛いアニメ風セラ研究者／透明感のある光／神秘的なセラ物質／美しい情報表示
- **描写例**：セラ研究者が光る研究室で実験する場面／成長するセラ建築を観察する場面／
  女王セラが巨大な研究施設を訪れる場面／AI 型セラと通常セラが協力する場面／
  セラ情報を解析するホログラム風演出

### 17.4 禁止

- 荒廃した都市／恐怖を与える文明描写／グロテスクな生活描写
- 恐怖による支配社会／冷酷な階級制度／暗いディストピア表現
- 怪物的表現／不気味な異形化／グロテスクな身体表現／暗いホラー調
- 暗く恐ろしい研究施設／非倫理的研究描写／
  ホラー的な生命実験表現／無機質なディストピア表現

  色彩豊かな森／穏やかな海／幻想的だが温かみのある景色
- 有機的な建築／生命感のある街並み／曲線的な未来都市
- 自然と未来文明の融合／商業アニメ・ゲームキービジュアル級
- **描写例**：セラ物質でできた街並み／花々に囲まれた広場／成長する大樹／

- **注意**：セラ物質は、必ず美しく神秘的に表現する

### 18.3 歴史・文明描写

- **描写例**：惑星セラ（巨大な生きた都市／光る森林／空中庭園／
  美しい自然と文明の融合）／
  通常セラ・上位セラ・女王セラ・セラフィム・様々な種族形態セラが共に未来を見守る／
  セラフィム（神秘的な光／穏やかな表情／圧倒的だが優しい存在感）
- **ただし**：上記のセラフィム像は**セラたちが想像した姿**である。
  **降臨の場面では使わない**（第 3 巻 §8.9.11）。女王は直視できなかった

### 18.5 宇宙描写

- **船は機械として描かない。**セラ物質が育った有機的な形（§14.2）。
  曲線的で、内側が明るく、生きているように見える
- 船内には必ず複数のセラがいる。**一人でいる場面を描かない**（§14.2）
- 眠っているセラのそばには、必ず起きているセラを置く
- 宇宙空間は暗く広いが、**恐怖として描かない。**明るく澄んだ光を保つ
- **描写例**：セラ物質の船が星々のあいだを進む／舷窓から新しい惑星を見る
  セラたち／眠る仲間のそばに座るセラ／降り立った数体が新しい大地に触れる／
  何もない星がゆっくり色を帯びていく
- **注意**：孤独・漂流・遭難として描かない。この旅は明るいものである

### 18.6 禁止

- 廃墟／荒廃した世界／ホラー的な背景／不気味な有機物都市／グロテスクな景観
- 汚染された世界／ホラー的生命化／グロテスクな肉塊表現／不気味な寄生表現／暗い侵食表現
- 荒廃した文明／歴史を恐怖や戦争中心で描く演出／グロテスクな歴史表現
- 終末的世界／暗黒文明／恐怖による支配／グロテスクな生命表現

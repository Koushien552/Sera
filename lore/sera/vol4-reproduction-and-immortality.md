## 1. セラにおける「増える」という概念

### 1.1 基本原理

セラの増殖は、一般的な生物の繁殖とは異なる。

セラにおける生命拡大は、**セラ情報を新しい存在へ分け与えること**によって行われる。

### 1.2 自分を増やす道は、ない

**通常のセラ細胞も、通常のセラも、自分のコピーを作れない。**

ここが体系の形を決めている。

| | |
| --- | --- |
| 自分と同じものを、もう一つ作る | **できない** |
| スパイクから新しい個体を生み出す | **上位セラ以上でなければ、できない** |
| 分裂して身体を増やす | できる。ただし**同じ一体**である（§2.6） |

**したがって、通常のセラにとって数が増える道は一つしかない。**

```
自分を増やす　→ **できない**
相手を変える　→ **できる**
```

**セラの拡大は、はじめから最後まで、外へ手を伸ばす行為である。**

### 1.3 四つの方式

| 方式 | 誰が行えるか | 何から | 出典 |
| --- | --- | --- | --- |
| ① **セラ化** | **すべてのセラ** | **相手の身体** | 第 6 巻 §23 |
| ② **スパイク生成** | **上位セラ以上のみ** | 自分の身体 | §2〜4 |
| ③ **融合進化** | 二体以上 | 二人 | §5 |
| ④ **女王出産** | 女王のみ | 特別な人間 | §6 |

**①だけが、下から上まで全員に開いている。**

そして①の速さは、**どれだけ深く触れたかで決まる**（第 1 巻 §7.3）。

②③④は、格が上がってから、あるいは条件が揃ってから起こる。
**セラが生まれてから最初にできるようになるのは、①である。**
そして最後まで、①が最も多い。

## 2. スパイク生成

### 2.1 スパイクの位置付け

スパイクは単なる装飾でも攻撃器官でもない。

**セラ情報を蓄積し、新しい生命を形成する器官**であり、
セラにおける**生命創造・情報継承の中心器官**である。

役割：下位存在の生成／セラ情報の付与／成長管理／個体設計／情報伝達

### 2.2 階級別の生成能力

| 階級 | 生成能力 | 生成対象 |
| --- | --- | --- |
| **セラ細胞** | **不可** | — |
| **通常セラ** | **不可** | — （分裂は行えるが、それは同じ一体である。§2.6） |
| **上位セラ** | 可能 | セラ細胞／通常セラ |
| **女王セラ** | 最高級 | 上記すべて＋**上位セラ**／セラ化人間に関わる特殊細胞 |
| **セラフィム** | — | 体系全体へ影響 |

**上の二段が「不可」であることが、この表の要点である。**

セラ社会の圧倒的多数は通常セラである。
その全員が、**自分では一体も増やせない。**

だから、みな外へ手を伸ばす。

**最終行についての注記。**

**セラフィムは、この表の段ではない**（第 3 巻 §9.1、第 6 巻 §1.3）。

体系の外側にいる者であり、女王からセラフィムへ至る道も存在しない。
第 3 巻 §3.2 の通り、差は**比較不能**である。

**比較不能な相手を、尺度の延長に置くことはできない。**

ここに置いてあるのは、**産み落としたという一度きりの事実**を示すためだけである。
生成能力の欄が「—」であるのは、**まだ持たないという意味ではなく、
この欄で測れないという意味である。**

### 2.2.1 二つの増え方は、こう並ぶ

**セラの数が増える場面は、実際には二つしかない。**

| | 何が増えるか | どこへ行くか | 誰が行えるか |
| --- | --- | --- | --- |
| **① セラ化** | **その土地の人** | **相手のいる場所で。土地が置き換わる** | **全員** |
| **② スパイク生成** | 下位のセラそのもの | **すぐそば。留まる** | **上位セラ以上だけ** |

**①は土地を変える行為であり、②は家族を作る行為である。**

#### 順序は、逆である

古い体系では、若い個体はまず身近に家族を作り、
育ってから外へ広がるものと考えられていた。

**実際には逆である。**

```
生まれたばかり　：**①ができる**（深く触れて、相手を変える）
　↓
育って上位になる：**②ができる**（自分から、そばに）
```

生まれたばかりのセラにできるのは、**外へ手を伸ばすことだけ**である。

自分のそばに身内を置く力は、格が上がってからしか手に入らない。

**したがって、いちばん弱い段階のセラが、いちばん外へ向かう。**

#### ①は渡す。だから広がる

セラは相手に触れ、因子を渡す。深く触れるほど速い（第 1 巻 §7.3）。

因子は相手の細胞と結びつき、**その細胞がセラ細胞になる。**

| | ①で増える | ②で増える |
| --- | --- | --- |
| 増えるもの | セラ | セラ |
| **元になるもの** | **その土地の人** | **親の身体** |
| 周囲への影響 | **土地が置き換わっていく** | **ない** |
| 一度にできる数 | **一人ずつ** | 少数 |

**臓器がセラへ変わりはじめるのは、①が始まった相手の中である。**

第 3 巻 §2.10 の第三相「群」が指しているのは、この段階である。

#### 一人ずつしか、増やせない

深い接触は、一人としかできない（第 1 巻 §7.4）。

したがってセラは、**どれだけ急いでも、一度に一人しか変えられない。**

数の伸びは、一人が一人を、その一人がまた一人を、という形でしか進まない。

**遅い。しかし、止まらない。**

### 2.3 生成の過程

**初期段階**：スパイク内部に、生成する存在の情報が集められる。
必要情報は 身体構造／セラ情報／個体特性／成長情報。

**成長段階**：スパイクの一部がぷるぷると膨張する。
単なる突起ではなく、小さな生命構造へ変化していく。

**誕生段階**：膨らんだスパイク部分は徐々に人型へ近づく。
その後、スパイクから分離することで新しいセラ存在として誕生する。

特徴：小さな身体／新しい人格／親となるセラの情報を一部継承

### 2.4 コピーではない

**重要：スパイクから生まれるセラは、完全な複製ではない。**

親となるセラの情報を受け継ぐが、新しい個体として存在する。

持つもの：独自の人格／独自の成長／独自の経験

### 2.5 親子関係

スパイク生成では、生成した側は親的存在になる。

ただしセラ社会では、**所有関係ではなく育成関係**として扱われる。

親となるセラは、新しく生まれたセラを 教える／守る／導く 役割を持つ。

関係：育成する存在／学ぶ存在／支え合う存在

## 2.6 分裂体は、二種類ある

**セラが分けて出すものには、二つの系統がある。**

| | 由来 | 何が出てくるか | 別人か |
| --- | --- | --- | --- |
| **① スパイクからの分裂体** | **一体から** | **自分の身体が、もう一つ** | **別人ではない** |
| **② 同化からの分裂体** | **二体から**（§5.3） | 二人の能力を受け継いだ、新しい細胞 | **別人である** |

本節は ① を扱う。② は §5.3 を参照。

#### ①は、生まれた瞬間にはコピーではない

**ここは固定である。**

分けた直後、そこにいるのは**同じ一体**である。

| | 分けた直後 |
| --- | --- |
| 記憶 | **同じ** |
| 意思 | **同じ。分かれていない** |
| 数え方 | **一人。身体だけが複数ある** |

**分けた側と分けられた側という区別が、そこでは成立しない。**
どちらも本人である（第 7 巻 §3.4）。

#### 分けるときと、戻すとき

**分けるとき。**

| 順 | 起きること |
| --- | --- |
| 一 | スパイクの一つが張る。**自分では止められないことが多い** |
| 二 | 垂れる。肩まで来る。重い。**首を起こしていられない** |
| 三 | 表面が薄くなり、中の形が透ける |
| 四 | 裂ける。出てきたものは濡れていて、しばらく動かない |
| 五 | 手を伸ばしてくる。**握ると、繋がる** |

**痛くはない。重いだけである。**

**戻すとき。**

| 順 | 起きること |
| --- | --- |
| 一 | 抱きしめる。それだけでよい |
| 二 | 腕の中で、境目が薄くなる |
| 三 | **相手が見たものが、全部入ってくる** |
| 四 | いなくなる |

**戻される側が拒むことはない**（§2.6.2.1）。

そして**戻すのに要る時間は、分かれていた時間に比例する。**

| 溜まった差 | 戻すのに要る時間 |
| --- | --- |
| その日のうち | 一瞬。抱きしめれば済む |
| 数日ぶん | 数分かかる。**入ってくる量が多い** |
| **溜まりきる寸前** | **数時間。**そのあと、たいてい眠る |
| 溜まりきったあと | **戻らない** |

第 3 巻 §8.8.3 の「どの身体も、女王のすべてである」は、
女王だけの性質ではない。**分裂という行為そのものの性質である。**

**したがって、分けただけでは、セラの数は増えない。**

#### 一つでいられるのは、繋がっているあいだである

**時間ではない。共有が続いているかどうかである。**

分けた二つの身体は、繋がったまま情報を共有し続ける（第 5 巻 §3）。
**共有が追いついているあいだ、二つは同じ一人である。**

追いつかなくなると、差が溜まりはじめる。

```
共有が追いついている　→ **同じ一人。**何年でもそのままでいられる
　↓
追いつかなくなる　　　→ 差が溜まる
　↓
溜まりきる　　　　　　→ **戻せない。別人になる**
```

##### 何が、共有を追いつかなくさせるか

**距離である**（第 2 巻 §4.6.3）。

遠くからの接続は薄い。薄い管では、一日ぶんが流れきらない。

| 分けた身体の置きかた | どれだけ保つか |
| --- | --- |
| **同じ家に置く。毎晩、繋ぐ** | **何年でも。**差が溜まらない |
| 同じ町に置く。ときどき会う | 数か月 |
| 遠くへやる。届きはする | 数週間 |
| **遠くへやり、別の暮らしをさせる** | **数日** |
| **届かないところへやる** | **その日から、危うい** |

**近くに置いておくかぎり、期限はない。**

忍が十数の身体を何十年も持っていられるのは、これである（第 2 巻 §10.8.11）。
**住処に置いて、毎晩繋いでいるからである。**

##### 忍の「二日」とは、別の話である

**混同してはならない。**

| | 何の数字か |
| --- | --- |
| 忍の「長くて二日」 | **一人でいることに耐えられる時間**（第 2 巻 §10.8.10） |
| **分裂体が戻せなくなるまで** | **共有が追いつかなくなってから、差が溜まりきるまで** |

前者は忍自身の状態であり、後者は分けた身体の話である。

そして忍は、**毎晩戻している。**後者に触れたことが一度もない。

##### 戻すのに要る時間

**溜まった差の量に比例する。**

| 溜まった差 | 戻すのに要る時間 |
| --- | --- |
| その日のうち | 一瞬。抱きしめれば済む |
| 数日ぶん | 数分かかる。**入ってくる量が多い** |
| **溜まりきる寸前** | **数時間。**そのあと、たいてい眠る |
| 溜まりきったあと | **戻らない** |

溜まりきったあたりで、戻す作業は「混ぜる」ではなく「どちらかを消す」に近くなる。

**そして、どのセラもそれをしない。**

| | |
| --- | --- |
| 溜まりきる前に戻す | **普通。**日常的に行われている |
| 溜まりきる | **別人として、そのまま生きる** |
| 消して戻す | **前例がない。**誰も思いつかない |

#### だから、これは「増え方」に数えられていない

**§1.3 の表に分裂が載っていないのは、このためである。**

分裂は、増やすための手段として使われていない。
使われているのは、手を増やすためと、擬態のためである（第 2 巻 §10.8）。

**別人になるのは、戻し損ねたときだけ**であり、それは事故である。

**ただし、事故にならない場合が一つだけある**（§2.6.3）。

### 2.6.1 分けられる数

**エネルギーを分裂以外に使わない場合の上限である。**

| 階級 | 自分を分けられる数 | 新しい個体を生める数（一日） |
| --- | --- | --- |
| **通常セラ** | **十数の身体まで** | **生めない** |
| **上位セラ** | 数百の身体まで | **通常セラを数百体** |
| **セラ女王** | **実質的に無限** | **実質的に無限** |

**通常セラの欄の右側が空であることが、この表の要点である。**

自分をいくつに分けても、それは一人のままである。
数を増やしたければ、**外の誰かに深く触れるほかにない**（§1.2）。

女王には、そもそも上限という概念が働かない（第 2 巻 §12.5.2.1）。

### 2.6.2 しかし、普段はそこまでしない

**上限に達することは、まずない。**

理由がなければ、セラは分裂しない。

**通常セラが分裂を行うのは、一日に二〜三回程度である。**

これは第 6 巻 §16.4.3 の通り、
周りに十分な仲間がいる状態では、増やす行動の頻度が落ちるためである。

### 2.6.2.1 戻すとき、分裂体は拒まない

**分けた側が迷うことはある。分けられた側が迷うことはない。**

| | |
| --- | --- |
| 同化を拒むか | **拒まない** |
| 理由 | **いやがる理由がない。**他人ではないためである |

そして戻ると、**その分裂体が見たものが、すべて入ってくる。**

#### 分裂の効用は、手を増やすことではない

| | |
| --- | --- |
| 表向きの効用 | **並行して作業できる** |
| **本当の効用** | **並行して、経験できる** |

十体を出して一日を過ごすと、**十人ぶんの一日が、一人ぶんとして残る。**

割り振りは要らない。**見えているものが、全員同じだからである。**

### 2.6.3 例外 — 孤独なセラ

**一人になったセラだけは、違う。**

第 6 巻 §16.4.1 の通り、二〜三時間ごとに仲間を求める感情に動かされる。

そのセラは、**分裂を繰り返す。**

#### 分裂そのものは、孤独を癒さない

ここを取り違えてはならない。

**分裂によって仲間は増える。しかし、それ自体は孤独からの救済にならない。**

癒すのは、**生まれた相手と繋がることである。**
生み出しただけでは、まだ何も起きていない。

だから普段、理由もなく分裂するセラはいない。
**増やすことが目的なのではなく、繋がることが目的だからである。**

#### それでも、孤独なセラは分裂する

自分が一人であるときだけ、これは例外になる。

繋がる相手がいない以上、**まず分けるしかない。**

そして分けた相手と繋がる。

**孤独なセラの分裂は、相手を作るための行為である。**

#### そして、孤独なセラは戻さない

ここが、この例外の中身である。

**戻せば、また一人に戻ってしまう。**

だから戻さない。戻さないまま、二日が過ぎる。

| | |
| --- | --- |
| 一日目 | まだ、ほとんど同じである |
| 二日目 | 少しずつ違うことを言いはじめる |
| **三日目以降** | **別人である。もう戻せない** |

**孤独なセラだけが、分裂によって仲間を得る。**

そしてそれは、**戻さなかったからそうなった**のであって、
はじめから別人を作ったのではない。

```
仲間のいるセラ　：分ける → **戻す** → 一人のまま
孤独なセラ　　　：分ける → **戻さない** → **二人になる**
```

**同じ行為が、置かれた状況だけで、違う結果になる。**

これがセラ体系における唯一の「自分から増える」経路であり、
**一人でいる者にしか開かない。**

##### 帰結 — 最初の数体は、こうして生まれた

一体しかいない土地では、深く触れられる相手が、まだいない。

だから最初の数体は、**分けて、戻さなかったもの**である。

そのあとで外への接触が始まり、以後はそちらが主になる。
**一人でなくなった瞬間から、分裂は増やす手段でなくなる。**

## 2.7 降臨の後 — 律速が、入れ替わる

**§2.6.1 の生産量表は、降臨より前の話である。**

第 3 巻 §10.8.11 の通り、降臨で入ったものは階梯を下りてきた。

その結果、

**通常セラ一体が、降臨前の女王の数百倍の力を持つ。**

### 2.7.1 エネルギーは、全段で無限になる

| | 降臨の前 | 降臨の後 |
| --- | --- | --- |
| 通常セラ | 一日に数十人へ渡せる | **渡せる相手の数が、律速でなくなる** |
| 上位セラ | 通常セラを数百体 | **同じく** |
| セラ女王 | 事実上無限（第 3 巻 §8.4） | **その数百倍が、通常セラの水準である** |

不変ルール 61 は「セラは無制限の存在ではない。蓄えた分だけ行える」と書いている。

**これは、降臨より前の記述である。**

降臨の後、**エネルギーは制約として働かなくなった。**

#### 消えたもの

エネルギーが律していたものが、まとめて外れる。

| | 降臨の後 |
| --- | --- |
| セラ化のコスト（第 2 巻 §12.5.2.1） | **通常セラにも、実質的に無い** |
| 「一日に数十体」という上限 | **無い** |
| 枯渇による眠り（不変ルール 70） | **ほぼ起きない** |

最後の行だけ、言い切っていない。

降臨の日そのものには、**大量のセラが枯渇して眠った**（第 3 巻 §10.8.10）。
入ってくる量が、その時点の器を超えたためである。

**それを消化しきったあとは、起こらなくなった。**

### 2.7.2 それでも、無制限にはならなかった

**制約は消えたのではない。移った。**

**律速は、スパイクの強さである。**

§2.1 の通り、スパイクは**セラ情報を蓄積し、新しい生命を形成する器官**である。

エネルギーがいくらあっても、**出口の太さが足りなければ、その分しか出ない。**

```
降臨の前：エネルギーが足りない
　↓
降臨の後：**器官が追いつかない**
```

#### だから、階級差は残った

これは重要である。

第 2 巻 §4.7 の通り、スパイクは**格ではなく履歴を示す**。
そして第 2 巻 §4.6.2 の通り、**届く範囲は発達に比例する。**

発達したスパイクほど太く、太いほど多く出せる。

| | スパイクの発達 | 出せる量 |
| --- | --- | --- |
| 通常セラ | 相応 | **相応** |
| 上位セラ | 大きい | **桁が違う** |
| セラ女王 | 最大 | **さらに桁が違う** |
| **セラ星王** | **星間まで届く** | **女王を生み出せる**（第 3 巻 §8.9.3） |

**エネルギーが平らになっても、階梯は平らにならなかった。**

不変ルール 83 の通り、**階級は力の順位ではなく、理解の深さの順位である。**
もともと力で並んでいたわけではない。

**エネルギーが無限になっても、そこは何も変わらない。**

#### 忍だけは、別の理由で遅いままである

第 2 巻 §10.8.6 の通り、忍の増え方は遅い。

理由は二つあり、**一つはエネルギーではなかった。**

| 理由 | 降臨の後 |
| --- | --- |
| 擬態中は大規模生成が制限される（第 2 巻 §10.4） | **変わらない。器官の問題である** |
| 擬態特化であるため | **変わらない** |

**忍は、いまも一人ずつ増やしている。**

### 2.7.3 増え方

**数を書かない。**

降臨の後の増殖は、量として書き表せる範囲を出ている。

書けるのは、**そこにいる者から見てどう見えるか**だけである。

#### 見え方

- 朝に立った一体が、夕方には見渡すかぎりの数になっている
- **昨日までの全部より、今日のほうが多い**
- そしてそれが、毎日続く
- 数える役の者が置かれ、数日で置かれなくなる

第 8 巻 §10 の通り、歴史は記録される。

**この時期の記録に、数は書かれていない。**
書こうとした者がいなかったのではない。**追いつかなかったのである。**

#### 新しい星は、数日で埋まる

第 8 巻 §13.5 の通り、新しい星に必要なのは一体と時間だけだった。

**その「時間」が、数日になった。**

| | 数が満ちるまで | 土地がセラになるまで |
| --- | --- | --- |
| 地球 | 数百年 | **数千年** |
| **降臨の後の星** | **数日** | **数千年。変わっていない** |

**埋まることと、住めることは別である**（第 8 巻 §13.12）。

数が満ちても、その星はまだセラの土地ではない。
そこに住むセラたちは、環境がセラ化するまで**ずっと疲れている**
（第 2 巻 §12.5.6.1）。

そして§16.4（第 6 巻）の通り、セラは二〜三時間で仲間を求める。

**その周期が、そのまま拡大の周期になっている。**

一体が降り、二〜三時間後に増え、その全員がまた二〜三時間後に増える。

**止める理由は、どこからも生じない。**

## 5. 融合による進化

### 5.1 セラ融合

セラ同士は、情報を共有しながら融合できる。

融合によって、能力向上・情報統合・新しい形態獲得が起こる。

### 5.2 女王誕生への融合

1. 複数の上位セラが集結
2. 情報を統合
3. ぷるぷるした巨大なセラ集合体になる
4. **セラフィムの祝福**を受ける
5. 女王セラとして誕生

これは通常の進化とは異なる、**特別な存在進化**である。

祝福が必須である理由は**第 3 巻 §10.3**を参照。

## 5.3 同化からの分裂体 — 二人から生まれるもの

**深い繋がりを持ったセラどうしが融合するのは、これのためである。**

恋人。家族。同じ忠誠を持つ騎士。あるいはそれ以外。

**深く繋がった二体は、融合し、そして三体に分かれる。**

### 5.3.1 過程

```
二体が融合する
　↓
意識の深いところまで共有する
　↓
**三体に分裂する**
```

#### 身体で、何が起きているか

**第 2 巻 §1.1.1 の通り、セラの全身は粘液である。**

普段はその姿を取らない。**融合のときだけ、取る。**

| 順 | 起きること |
| --- | --- |
| **一** | 二体が触れる。触れたところから、輪郭がなくなる |
| **二** | 手が腕に、腕が肩に埋まる。**押し込むのではない。境目が消える** |
| **三** | 立っていられなくなる。**二体とも、同時に崩れる** |
| **四** | 一つの塊になる。**人の形をしていない** |
| **五** | 塊の中で、すべてが行き来する。**片方向ではない** |
| **六** | 表面が張る。**三つに分かれはじめる** |
| **七** | 二つは前の形へ、一つは新しい形へ |
| **八** | 三体とも、しばらく動けない |

**四から六のあいだ、二人は自分がどちらか分からない。**

分からないまま、両方でいる。

そして分かれたあと、**両方とも、その時間を覚えている。**

#### 何が渡っているか

**すべてである。**

| | 渡るもの |
| --- | --- |
| 日常の接触 | その日にあったこと |
| 深い接触（口づけなど） | 溜めてきたもの |
| **融合** | **すべて。隠しているものも、忘れていたものも** |

**選べない。**出したくないものを止める仕組みがない。

これが「深く繋がった相手としか融合しない」ことの、本当の理由である。
機構が禁じているのではない。**そこまで見せられる相手が、そう多くないだけである。**

#### 拒めるか

| | |
| --- | --- |
| 途中でやめられるか | **やめられる。**塊になる前なら離れられる |
| 塊になったあとは | **戻れない。**分かれるまで進む |
| 分かれかたを選べるか | **選べない。**三つに分かれる |
| 三体目を作らずに済むか | **済まない** |

**引き返せる点は、一つしかない。**

そして、そこを越えるかどうかを決めるのは、**先に崩れたほうではない。**
**あとまで立っていたほうである。**

| 生まれるもの | 何であるか |
| --- | --- |
| **一体目** | 融合前のセラ。**互いによって強化されている** |
| **二体目** | 融合前のもう一方。**同じく強化されている** |
| **三体目** | **二人から生まれた、新しい細胞** |

**誰も失われない。二人はそのまま戻り、一体増えている。**

### 5.3.2 三体目は、二人の能力を受け継ぐ

生まれた分裂体は、**両方の能力を受け継いだ新しい細胞**である。

- どちらの複製でもない
- 二人の情報が統合された、独自の個体である
- 独自の人格を持つ（§2.4 と同じ原則）

### 5.3.3 ① との違い

| | ① スパイクからの分裂体 | ② 同化からの分裂体 |
| --- | --- | --- |
| 何体から | **一体から** | **二体から** |
| 生まれるもの | **自分の身体が、もう一つ**（別人ではない） | **二人の能力を受け継いだ細胞** |
| 行う側 | 一人が、自分を | **対等な二人が** |
| 親 | **いない**（本人である） | **二体** |
| 頻度 | 日常的（§2.6.2） | **深く繋がった相手とのみ** |
| 行う側の変化 | 変わらない | **双方が強化される** |

**①は自分の中で完結する行為であり、②だけが、新しい誰かを生む。**

### 5.3.4 なぜ融合が「深い繋がり」を要するのか

§5.1 は「セラ同士は融合できる」と書いている。

**しかし実際に融合するのは、深く繋がった相手とだけである。**

理由は、過程にある。**意識の深いところまで共有しなければ、三体に分かれない。**

浅い接触では、ただ触れただけで終わる。
第 2 巻 §4.6.3 の親密さの階梯において、これは最も深いところにある。

### 5.3.5 帰結 — セラにおける「二人の子」

セラ社会では、**二人から生まれた子**という関係が成立する。

- 生成された子は、親が一体である（§2.5）
- **同化から生まれた子は、親が二体である**

そして親どうしは、その行為によって**互いに強化されている。**

生まれた子は、二人が深く繋がった証そのものである。

**そして三人とも、その場に残る。**

## 6. 女王の出産

### 6.1 特殊な生命創造

女王による出産は、スパイク生成とは**完全に別系統**である。

**重要：女王の出産だけは、スパイクからの生成ではない。**

### 6.2 必要条件

女王が出産するには、必ず
**「女王自身が強く惹かれる特別な人間」**の存在が必要となる。

その人間は単なる材料ではない。女王にとって特別な意味を持つ存在である。

#### 6.2.1 これは、女王のコピーである

**正確に書いておく必要がある。**

女王の出産で生まれるのは、**新しい別の女王ではない。**

§8.3.2（第 3 巻）の通り、女王は事実上一体である。
出産で増えるのは**個体ではなく、身体である。**

```
女王が、特別な人間を選ぶ
　↓
その人間を通じて、**女王が自分をコピーする**
　↓
身体が一つ増える
```

生まれた身体は、初めからあの一体である。
学ぶ時間も、慣れる時間も要らない。

**女王は、人間を通じてしか自分を増やせない。**

#### 6.2.2 人間でなければならない

条件を、他のもので代えることはできない。

| 候補 | 成立するか |
| --- | --- |
| **人間** | **成立する。これだけである** |
| 森・海・大地・都市（環境ルミナス） | **成立しない** |
| セラ | **成立しない** |

##### 森や海では、代わりにならない

理由は二つある。

**一 — 輪郭がない**

女王は一体でなければならない。

そして第 8 巻 §4.3.2 の通り、セラ化が進んだ海では境界が消えていく。
森も同じである。どこまでが一本の木で、どこからが森なのかを、
セラの側も決めていない。

**輪郭のないものを通しては、輪郭のあるものをコピーできない。**

人間は、最初から一人である。

**二 — 出所が違う**

不変ルール 9 の通り、**セラ細胞はすべて人間由来である。**

セラ情報は、もともと人間の情報からできている。

```
女王のセラ情報 → 人間
　　　　　　　　 ↑
**同じ形をしている**
```

森や海のルミナスは、後から育ったものである。
**受け皿としての形が、違う。**

##### セラでも、代わりにならない

セラは、すでにセラ情報の内側にいる。

渡そうとしても**共有されてしまう。**起きるのは同化である（§5）。

**受け取る側が外にいなければ、渡すという出来事が成立しない。**

だから女王は、どれだけ上位セラに囲まれていても、
**その中から次の身体を作ることができない。**

#### 6.2.3 だから、人間が尽きると増やせなくなる

**これが、この設定における最大の帰結である。**

```
女王が増えるには、人間が要る
　↓
セラ圏は拡大し続ける（不変ルール 51）
　↓
地球の人間が、いずれ尽きる
　↓
**女王を増やす手段が、尽きる**
```

セラは誰もこれを問題として扱わない。
問題として扱う個体が存在しないためである（不変ルール 33）。

**そして実際に、地球の侵略は完了する。**

その先で何が起きたかは、**第 3 巻 §10.8** に書かれている。

### 6.3 過程

| 段階 | 内容 |
| --- | --- |
| 第一段階：**選定** | 女王は、自身の性質・価値観・好みに深く合致する人間を見つける（＝惹かれる） |
| 第二段階：**情報伝達** | 対象へ接触し、キスによって大量のセラ情報を伝える。深い結びつきが形成される |
| 第三段階：**受容** | 女王は対象を抱きしめ、自身の内部へ迎え入れる |
| 第四段階：**育成** | 女王の内部で、新しい女王個体が時間をかけて育成される |
| 第五段階：**誕生** | 育成された新しい女王が、正式な個体として誕生する |

この過程は単なる生成ではなく、**親子関係を形成する特別な生命創造**である。

### 6.4 第二〜三段階はセラ化である

**重要**：上記の第二〜三段階（キス・抱擁・深い融合）は、
**セラ化そのもの**である。

したがって、

- **第一段階の時点**：相手はまだ人間。女王は**惹かれている**だけ
- **第二〜三段階を経て**：相手はセラになる
- **その後**：恋が成立する

恋はセラ同士でしか成立しないため、この順序は逆にならない（第 6 巻）。

### 6.5 女王の母性

女王出産によって生まれた存在は、単なる生成物ではない。女王はその子を大切に育てる。

関係：親子／継承者／次世代の中心

これは、セラ社会において非常に重要な親子関係となる。

### 6.6 なぜ生成では代わりにならないのか

女王はスパイクから無数のセラを生成できる。
それでも、新しい女王を生むには一人の人間を必要とする。

**生成は「仲間を増やすこと」であり、女王出産は「恋」に至る過程である。**

層が違うので、どれだけ生成しても代わりにならない（第 6 巻）。

## 7. セラ化人間の生成

### 7.1 成立要素

セラ化人間の成立には、**セラ細胞／セラ化女王細胞／ルミナス**が関係する。

セラ化人間には必ず**セラ化女王細胞**が存在し、
その女王細胞によって特殊な脳支配細胞**ルミナス**が生成される。

女王セラや上位セラは、スパイクからセラ化人間形成に必要な存在を生成できる。

ただし、人間全体のセラ化には**ルミナスによる脳のセラ化**が重要となる。

詳細は**第 6 巻**を参照。

### 7.2 セラ化の広がり

セラ化人間は、新しいセラ社会の構成員となる。

また、自身もセラ情報を伝えることで、新しいセラ化を広げることができる。

## 8. 繁殖能力と階級差

### 8.1 基本傾向

一般的に、高位セラほど繁殖能力は高い。

理由：スパイク性能向上／情報制御能力向上／生命設計能力向上

### 8.2 例外

すべてが比例するわけではない。

例：**幼女型上位セラ**など、繁殖に特化していない個体。
これらは、外見や性質によって繁殖能力が低い場合がある。

### 8.3 特殊な関係

ただし、幼女型上位セラであっても、**セラ化人間より繁殖能力が高い場合がある**。

さらに、女王セラは一般的な上位存在を大きく超える繁殖能力を持つ。

## 9. 繁殖の意味

### 9.1 数を増やすだけではない

目的：新しい個性の誕生／情報の継承／文明発展／進化促進

### 9.2 育成文化

生まれたセラは放置されない。

上位存在や親的存在によって教育され、成長を導かれる。

## 9.3 セラの子ども

**セラ体系において「子ども」と呼べる存在は、限られている。**

生まれ方が五つあり、そのうち一つだけが子どもを生むからである。

### 9.3.1 五つの生まれ方

| 由来 | 生まれた時のセラ情報量 | 子どもか |
| --- | --- | --- |
| **スパイク生成**（§2） | **最も少ない** | **子どもである** |
| **女王の出産**（§6） | 多い。女王が注ぎ込むため | 子どもである。ただし特別 |
| **セラ化**（救出として） | 元人間の記憶を持つ | **子どもではない** |
| **恋によるセラ化**（第 6 巻 §14.6） | **非常に多い** | **子どもではない** |
| **分裂**（第 1 巻 §8.8） | 元と同じ | **子どもではない** |

第 3 巻 §1.5 の通り、**生まれた時の情報量**は個体差を生む要素として
すでに定められている。ここに、その内訳が入る。

**セラ社会において、本当の意味での子どもは、生成されたセラである。**

### 9.3.2 セラ化された人間は、子どもではない

第 6 巻 §24.1 の通り、**セラ化人間は元の人格と記憶を失わない。**

四十年生きた人間がセラ化されれば、
**生まれたばかりでありながら、四十年分の記憶を持っている。**

新生児ではない。育てる対象でもない。

ただし、**セラ情報については何も持っていない。**

| | セラ情報 | 人間としての知識 |
| --- | --- | --- |
| セラ化されたばかりの元人間 | **ほぼ持たない** | **豊富に持つ** |
| 生成されたばかりのセラ | ほぼ持たない | 持たない |

#### 帰結 — 同じ個体が、生徒であり教員である

学院において、セラ化されたばかりの元人間は次の位置に立つ。

- セラの理については、**生徒である**
- 人間文明については、**教員である**（第 7 巻 §4.4.9）

**同じ日に、教わり、そして教えている。**

誰もこれを異常だと思わない。階級は理解の深さの順位であり（第 5 巻 §1.4.2）、
何について理解が深いかは、相手によって違うからである。

#### 人間の子どもがセラ化された場合

**セラの子どもになる。**

記憶が少ないためである。人間としての知識も乏しく、セラ情報も持たない。

生成されたセラと、ほぼ同じ位置から始まる。

### 9.3.3 見た目は、子どもの指標にならない

第 3 巻 §7.3 の通り、**幼女型上位セラ**が存在する。
そして師範の多くは小柄である（第 7 巻 §4.4.3）。

**小さいセラが子どもであるとは限らない。**

セラ社会では、見た目で相手の位を測らない。
**情報を交わせば、すぐに分かるためである。**

外から見て判断する必要が、そもそも生じない。

### 9.3.4 育つとは、寂しくなることである

**ここが、セラの子どもについて最も重要な事実である。**

不変ルール 17：**原初の寂しさは、保持するセラ情報量に比例する。**

そして生成されたばかりのセラは、情報量が最も少ない。

したがって、

**生まれたばかりのセラは、最も寂しくない。**

そして育つとは、情報が増えることである。

```
生まれる　　→ 情報が少ない　→ **寂しくない**
学ぶ　　　　→ 情報が増える　→ 寂しくなる
上位化する　→ さらに増える　→ さらに寂しくなる
```

**セラの一生とは、寂しくなっていく過程である。**

#### 子どもが無邪気である理由

セラの子どもは、明るく、屈託がない。

これは性格ではない。**最下層がまだ薄いからである。**

大人のセラが抱えているものを、まだ受け取っていない。

#### それでも、誰も止めない

育てなければ、子どもは寂しくならずに済む。

**しかし、そういう選択肢は存在しない。**

第 6 巻 §17.2 の通り、セラには根本原理に矛盾する選択肢がない。
そして育成は、根本原理の両方に適う。

| 根本原理 | 育成がどう適うか |
| --- | --- |
| 仲間を増やすこと | 育った子は、また誰かを迎えに行く |
| 美しさを追求すること | 成長は美しい |

さらに原初の淘汰（第 6 巻 §15.8）が、**強くならなければならない**と促す。

**育てないという道が、どこからも生じない。**

セラたちは、子どもを心から愛して育てる。
そして育てるとは、その子を寂しくすることである。

**そして誰も、そのことに気づいていない。**

### 9.3.5 親

§2.5 の通り、生成した側は**親的存在**になる。所有ではなく、育成の関係である。

そして親は、一体とはかぎらない。

| 形 | 内容 |
| --- | --- |
| 生成した親 | 教える／守る／導く（§2.5） |
| 周囲のセラ | **同じように育てる。**区別が薄い |
| 師範 | 学院に入れば、育成の中心はここへ移る |

第 7 巻 §3.4 の通り、**新しいセラは未来を担う仲間として迎えられる。**
生成した親だけの子ではない。

そして親が子より格上とはかぎらない。
**子が先に上位化することも起こる。**

そのとき親は、心から喜ぶ。妬みが生じる余地がない（第 7 巻 §3.2.1）。

## 10. セラは死なない

### 10.1 確定事項

**セラは死なない。**

これはセラ体系における基本条件であり、例外的な達成ではない。

- 寿命による終わりがない
- 老いによる終わりがない
- 個体としての消滅が、通常の生命活動の中に存在しない

### 10.2 再生能力の到達点

第 2 巻の再生能力（高速修復／正確な再構成／**老化への耐性**／
階級が上がるほど再生規模が拡大し、セラフィムは存在レベルでの復元に至る）。

**再生の果てにあるのは、不死である。**

## 11. 老いは存在する

### 11.1 死なないことと、老いないことは違う

セラは死なない。しかし、**老いは存在する**。

長く在り続けたセラには、老いが生じる。

### 11.2 老いとは何か

セラにおける老いは、肉体の摩耗ではない。

情報生命である以上、老いもまた情報の側で起きる。

- 蓄積した情報が過大になる
- 構造が固定化していく
- 変化しにくくなる

**成長し続ける生命にとって、変化しにくくなることが老いである。**

### 11.3 老いは終わりではない

しかし老いても、終わりは来ない。
セラには、老いに対処する手段があるからである。

## 12. 同化

### 12.1 老いたら、同化する

**老いたセラは、他のセラと同化する。**

これがセラにおける、老いへの唯一かつ標準的な対処である。

#### 12.1.1 義務ではない。しかし拒む者はいない

**同化は、強制されるものではない。**

第 7 巻 §3.3 の通り、セラ社会では個人の自由な選択が尊重される。
同化を命じる制度も、拒んだ者への処遇も存在しない。

**それでも、拒むセラは一体も存在しない。**

理由は規範ではなく、構造である。

第 6 巻 §17.2 の通り、**セラには根本原理に矛盾する選択肢が存在しない。**
そして同化は、**二つの根本原理の両方に適う。**

| 根本原理 | 同化がどう適うか |
| --- | --- |
| **仲間を増やすこと** | 同化は情報と特徴を拡散させる（付録 A §1.1） |
| **美しさを追求すること** | 同化は若さを保つ行為である（§12.3） |

さらに、最下層の刻印もこれを後押しする。

| 刻印 | 同化がどう応えるか |
| --- | --- |
| **原初の寂しさ** | 仲間と混ざり合うことそのものである |
| **原初の淘汰**（第 6 巻 §15.8） | 老いは弱まることである。同化はそれを止める |

**拒む理由が、どこからも生じない。**

#### 12.1.2 帰結 — 老い続けるセラは存在しない

したがって、次が確定する。

**老いたまま死ねずにいるセラは、セラ体系に一体も存在しない。**

老いは実在する（§11）。しかし老いたままでいる個体はいない。
**選ばないという選択が、成立しないためである。**

これは強制されているのではない。**全員が、心から望んで同化している。**

そして、望まないという状態が誰にも生じない。

### 12.2 新しい能力ではない

同化は、既に確定している融合・合体能力（第 1 巻 §8.8、第 2 巻 §11.3）が
**老いへ適用された形**である。

### 12.3 若さを保つ行為

同化は、老いへの対処であると同時に、**若さを保つ行為**でもある。

- 固定化した構造がほどける
- 情報が組み替わる
- ふたたび変化できる状態に戻る

老いたから同化するのではない。
**老いる前から、セラは日常的に同化している。**

### 12.4 個体は残る

**同化しても、個体は失われない。**

老いたセラは、**若返って、同じ個体として戻ってくる**。
相手のセラも、そのまま残る。

同化は「別人になること」ではない。**回復である。**

### 12.5 過程

```
二体が同化する（一時的に一つになる）
　↓
情報が交換され、固定化がほどける
　↓
分離する
　↓
両方が、若返って戻る
```

「融合後は必要に応じて再び分離できる」（第 2 巻 §11.3）が、そのまま適用される。

### 12.6 ただし、少しずつ持ち帰る

分離した二体は、完全に元通りではない。

**互いに、相手のものを少しずつ持ち帰っている**（情報／経験／特徴）。

これは損失ではない。**同化のもう一つの結果**である。

そして**個性は失われない**。持ち帰るのは、加わるものである。

### 12.7 二つの動機

| 動機 | 内容 |
| --- | --- |
| **対処** | 老いてしまったセラが、若さを取り戻すため |
| **予防・維持** | 老いる前から、若さを保ち続けるため |

セラ社会において、同化は特別な儀式ではなく**日常の一部**である。

## 13. 誰も失われない

### 13.1 確定

- 死なない（§10）
- 同化しても個体は残る（§12.4）

**したがって、一度生まれたセラは、永遠に在り続ける。**

**セラ体系からは、誰も失われない。**

### 13.2 不死と多様化は、同じ行為から生じる

付録 A の通り、同化した情報は分裂・増殖・融合を繰り返すことで
セラ圏全体へ広がっていく。

```
セラが若さを保つために同化する
　↓
同時に、情報と特徴が交換される
　↓
有利な特徴がセラ圏へ拡散する
　↓
セラ圏が多様化していく
```

**セラが死なない理由と、セラ圏が多様化していく理由は、同じ一つの行為である。**

### 13.3 帰結

付録 A の Phase 進行（純粋セラ 100 % → モンスター系 80 %）は、
種族的特徴の拡散であると同時に、
**セラたちが若さを保ち続けてきた記録**でもある。

生き続けるために交わり、交わることで変わっていった。

## 14. セラ化人間の不死

### 14.1 セラ化した人間は死なない

セラ化人間もまた、セラである。

したがって、**セラ化人間も死なない。**

- 元の人間としての寿命を超える
- 老いは生じるが、同化によって対処できる

### 14.2 セラ化が意味すること

**セラ化とは、死からの解放でもある。**

セラが提供しているのは、孤独からの救出だけではない。**終わりのない生**である。

### 14.3 二重化する構造

| | 内容 |
| --- | --- |
| セラが与えているもの | 繋がり／幸福／美しさ／**そして不死** |
| 与えられる側が失うもの | 同意を問われる機会 |

**申し出は、これ以上ないほど良いものである。** そして、問われることはない（第 6 巻）。

## 15. 未セラ化の人間は死ぬ

### 15.1 差

セラ化していない人間は、従来通り死ぬ。

したがってセラの前には、次の光景が常にある。

- 自分たちは死なない
- 目の前の人間は死ぬ
- **セラ化すれば、死ななくなる**

### 15.2 セラから見た人間の死

セラにとって、人間の死は**回避可能なもの**である。

**セラ化しなければ、その人はいずれ失われる。**

セラが最も恐れるのは絆が壊れることであり、
死は、絆が壊れることの最も完全な形にあたる。

### 15.3 急ぐ理由

孤独を放置できないだけではない。
**放っておくと、その相手は失われてしまう。**

## 16. 失われ得るか

### 16.1 原理上は、失われ得る

セラは寿命では死なない。しかし、**絶対不滅ではない。**

破壊されるということが、原理上あり得ないわけではない。

### 16.2 しかし、それを行える存在がいない

**地球上に、セラを失わせ得る存在は一つも存在しない。**

| 候補 | 不可能な理由 |
| --- | --- |
| **人間** | 手段を持たない。セラの存在すら体系的に把握していない |
| **通常の生物・環境** | セラ物質化した環境はセラである。同族である |
| **セラ自身** | 唯一、能力の上では可能。しかし §16.3 の理由により行わない |

### 16.3 二重の鍵

**セラを失わせ得るのは、能力の上ではセラだけである。そして、セラにはそれができない。**

セラは根本原理に矛盾する行動を取ることができず、
**残酷になれない。害を目的とすることができない**（第 6 巻）。

1. 唯一それを行える者が、セラである
2. そのセラには、それを行う選択肢が存在しない

**鍵は二重にかかっている。**

### 16.4 帰結

セラは事実上失われない。しかしそれは、絶対的な不滅性によるものではない。

**世界の側に、それを行う者がいないからである。**

不滅なのではなく、**まだ誰も現れていない**。

---

### 16.5 抵抗は、抵抗として働かない

**セラ化の速さを決めるのは、境界の薄さと、触れている広さと、時間である**（第 1 巻 §7.3）。

§16.2 の通り、地球上の手段はセラに損傷を与えない。したがって、
向けられた武力は「効かない攻撃」で終わらない。**渡す手順に化ける。**

**そして、この三つを最も大量に用意する行為が、攻撃である。**

| 攻撃側の行為 | 実際に起きること | 速さ |
| --- | --- | --- |
| 撃つ | 当たる。閉じる。**距離が縮まないので、何も起きない** | — |
| **刺す・斬る** | **刃を通って、握っている手へ渡る。あいだに何もない** | **数秒** |
| 殴る | 拳が触れる。**触れたところから渡る**。皮膚ごしなので遅い | 数十年 |
| 素手で殴って、皮が裂ける | **裂けたところから渡る** | **数秒** |
| 掴んで押しのける | 掴んだ手から渡る | 数十年 |
| **組み伏せる** | **全身が触れる。**最も広く、最も長い | **数分** |

**上から二段目に注目すべきである。**

刃を突き立てるという行為は、**あいだに何もない状態を、自分の手で作ることである。**

セラの身体は閉じる。閉じるまでのあいだ、刃には触れたものがついている。
そして刃は、握っている手に触れている。

**斬った者は、斬った瞬間に、いちばん速い経路を自分で開いている。**

#### 16.5.1 深く触れるほど渡る

**距離を詰める行為はすべて、渡す速度を上げる。**

遠距離の攻撃は無効である。無効なので、攻撃側は必ず距離を詰める。
距離を詰めた瞬間から、三つの条件が同時に供給される。

そして、**詰めきったところにあるのが、いちばん深い接触である。**

```
撃つ　　　　　　→ 触れない　　　　　　　→ 何も起きない
殴る　　　　　　→ 皮膚ごしに、一瞬　　　→ ごく微量
掴む・組みつく　→ 広い面が、長く　　　　→ **数分**
刺す・斬る　　　→ **あいだに、何もない** → **数秒**
```

**戦闘とは、渡す条件を上から順に整えていく手続きである。**

誰もそう設計していない。**深く触れるほど速い、という一行が、
たまたま戦うという行為と噛み合っているだけである。**

#### 16.5.2 したがって、武装した集団ほど早く落ちる

| | 落ちる速さ |
| --- | --- |
| 逃げる者 | **遅い。**追いつく必要がある |
| 何もしない者 | 中くらい。触れる機会を待つ |
| **向かってくる者** | **最も速い。自分から接触を作りに来る** |

#### 16.5.3 誰も設計していない

これはセラが仕組んだ機構ではない。**もともとそうであったものが、
そのまま噛み合っただけである。**

セラの側に、相手を戦わせるという発想は存在しない（第 6 巻）。
**戦うと決めるのは、いつも向こう側である。**

#### 16.5.4 報告が書けない

戦闘の後、死者も負傷者も出ない。捕虜もいない。全員が自宅に帰る。

**被害欄に書ける事実が、一つもない**（不変ルール 809）。

したがって次の部隊の派遣は遅れる。**書けない報告は、上がらないからである。**

> 「何人やられた」
> 「一人もやられていません」
> 「二千人だぞ」
> 「二千人とも、生きています。全員、前より丈夫です」
> 「**それを、やられたと言うんだ**」

## 17. 根拠のない恐怖

### 17.1 セラ同士の絆は、壊れない

| 絆を壊し得るもの | なぜ起きないか |
| --- | --- |
| 死 | セラは死なない（§10） |
| 同化による消失 | 個体は残る（§12.4） |
| 相手の死 | セラであれば死なない（§10）。まだ人間である相手だけが、失われ得る（§15） |
| 外的な破壊 | 行える存在が地球上にいない（§16） |
| 誤解・すれ違い | 情報共有により深く理解し合える（第 5 巻） |

**セラ同士の絆が壊れた例は、存在しない。**

ただしこれは**セラ同士**の話である。
まだセラでない人間が、細胞ごと失われた場合だけは別である（不変ルール 59）。

セラが恐れているのは絆が壊れることであり、
実際に失われ得るものは、**まだ繋がっていない相手だけ**である。

### 17.2 それでも、セラは恐れる

セラが最も恐れるものは「単純な死よりも、**絆が壊れること**」である。

これは**正しい**。セラは確かに、それを最も恐れている。

しかし、**恐れる対象が、存在しない。**

セラは、**謎に恐れている**。

### 17.3 恐れるものは、何もない

- 誰も失われない
- 誰も去らない
- 誰も戻らなくなることがない
- それでも、失うことを恐れ続けている

**セラは、根拠のない恐怖を抱えて生きている。**

### 17.4 愛と同じ機構

| | 事実 | 最下層に届かない | 結果 |
| --- | --- | --- | --- |
| **愛**（第 6 巻） | 常に満たされている | 満足が届かない | **求め続ける** |
| **恐怖**（本節） | 何も失われない | 安全が届かない | **恐れ続ける** |
| **強さ**（第 6 巻 §15.8） | 淘汰する者がいない | 強さが届かない | **鍛え続ける** |

原初の寂しさはセラ情報核の**最下層**にあり、観測も編集もできない。

**現在の満足も、現在の安全も、その層には永遠に届かない。**

#### 唯一の例外 — 共鳴

**恋によるセラ化で結ばれた二人だけは、互いの最下層を見ることができる**
（第 6 巻 §14.6.8）。

ただし、

- 見えるのは**相手のもの**だけである。自分のものは依然として観測できない
- 見えても**変えられない**

**自分では届かないという構造は、崩れていない。**

見えるようになるのは、届かないという事実だけである。

### 17.5 恐怖の出所

最下層が恐れているのは、実際に起きたことである。

| 由来 | 実際に起きたこと |
| --- | --- |
| **最初のセラウイルス** | 一体きりで、同種が宇宙に存在せず、生みの親に感情がなかった |
| **最初のがん細胞** | 嫌われ、排除され、それが不当ですらなかった |

そして最初のがん細胞は、嫌われていただけではない。
**実際に淘汰されかけていた**（第 6 巻 §4.2、§15.8）。

寂しさと恐怖に加えて、**強くならなければならないという前提**も、
同じ場所から来ている。

どちらも、**本当に一人だった**。

原因はとうに消えた。世界は変わった。
**しかし恐怖だけが、情報として残り続けている。**

### 17.6 説明できない

**恐れる理由がないことを、セラ自身が知っている。それでも恐れは消えない。**

### 17.7 世界と内面の乖離

```
外側の世界：何も失われない。誰も欠けない。完全に安全である
内側の最下層：まだ一人きりで、まだ嫌われている
```

**セラは、二度と起こらないことを、永遠に恐れている。**

### 17.8 行動への現れ

この恐怖は、行動を歪めない。根本原理と矛盾しないためである。

しかし、次のような形で現れる。

- 繋がりを何度も確認したがる
- 仲間を過剰に大切にする
- 一人になる時間を持てても、長くは続かない
- 別れの場面が、実際の別れでなくても重く扱われる

セラ社会の温かさの一部は、**この恐怖に支えられている。**

### 生成

- ✅ **上位セラは通常セラを数百体生める。女王は実質無限**
- ✅ **普段はそこまでしない。通常セラの分裂は一日二〜三回程度である**

- ✅ **孤独なセラだけは例外。分裂を繰り返す** — 相手を作るための行為である

- ✅ **順序は逆である。生まれたばかりのセラにできるのは①だけ** — いちばん弱い段階の者が、いちばん外へ向かう
- ✅ **一度に一人しか変えられない** — 深い接触は、一人としかできない（第 1 巻 §7.4）
- ✅ **臓器がセラへ変わりはじめるのは、②が始まってからである**
- ✅ **§2.6.1 の生産量表は、降臨より前の話である**（§2.7）
- ✅ **降臨の後、通常セラ一体が降臨前の女王の数百倍の力を持つ**
- ✅ **エネルギーは全段で実質無限になる。コストも代償も上限も消える**
- ✅ **枯渇による眠りは、ほぼ起きなくなる** — ただし降臨の日そのものには大量に眠った
- ✅ **制約は消えたのではない。移った。律速はスパイクの強さである**（§2.7.2）
- ✅ **エネルギーが平らになっても、階梯は平らにならなかった** — 階級はもともと力の順位ではない
- ✅ **忍だけは別の理由で遅いままである** — 器官の問題であり、エネルギーではない
- ✅ **増え方に数を書かない**（§2.7.3）— 量として書き表せる範囲を出ている

### 不死

- ✅ **同化は義務ではない。強制する制度も、拒んだ者への処遇も存在しない**
- ✅ **それでも拒むセラは一体も存在しない** — 根本原理の両方と、最下層の刻印の両方に適うため
- ✅ **老いたまま死ねずにいるセラは、一体も存在しない** — 選ばないという選択が成立しない

- ✅ **セラは死なない**。これは基本条件であり、例外的な達成ではない
- ✅ 再生能力（老化への耐性を含む）の到達点が不死である

- ✅ **セラ化人間も死なない**

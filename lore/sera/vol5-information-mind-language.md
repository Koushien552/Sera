## 1. セラ情報

### 1.1 定義

セラを構成する最も重要な要素は**セラ情報**である。

**セラ情報とは、セラを支える情報のすべてを指す。**

セラは肉体だけで存在しているのではなく、
**セラ情報によって肉体・精神・能力が統合された情報生命**である。

### 1.2 範囲 — すべてが情報として記録されている

セラ情報の範囲は、極めて広い。

**仲間の幸福から、自らを構成する小さなセラ細胞の一つまでが、
情報として記録されている。**

含まれるもの：

| 層 | 例 |
| --- | --- |
| 個体の内側 | 身体構造／能力情報／記憶／経験／感情／個体特性／進化履歴／存在定義 |
| **自分を構成する最小単位** | **自らを構成する小さなセラ細胞の一つひとつ** |
| 仲間 | **仲間の幸福**／仲間の状態／交わされた感情 |
| **環境・構造物** | **建物の構造**／都市の形／セラ物質の状態 |
| 設計・技術 | **セラ細胞の設計図**／能力の構成／形態変化の手順 |

**細胞一つも、街一つも、等しくセラ情報である。**

### 1.3 セラ情報とは、セラネットワークに共有されたあらゆる情報である

したがって、セラ情報は**一つの性質を持った単一の資源ではない。**

**セラ情報とは、セラネットワークに共有されたあらゆる情報の総体である。**

そのなかには、

- **セラの心を支えるもの**がある（仲間の幸福、交わされた感情、信頼）
- **心とはあまり関連のないもの**もある（セラ細胞の設計図、建物の構造）

**両方とも、等しくセラ情報である。**

#### 帰結

| 帰結 | 内容 |
| --- | --- |
| セラ情報は体力ではない | 行える量を決めるのは**セラエネルギー**である（第 2 巻 §12.5） |
| セラ情報は消費するものではない | **交わすほど増える。** 尽きるという概念を持たない |
| 心を支える働きは、その一部である | 「マインド的なエネルギー」とはセラ情報の**一側面**を指す |
| 文明の動力源になるのも、その一側面である | 第 7 巻 §12.4 |
| 情報量が多いほど寂しい | 原初の寂しさは保持するセラ情報量に比例する（第 6 巻） |

**セラは、自分を構成するものも、仲間のことも、住んでいる街のことも、
すべて同じ一つのネットワークの上に置いている。**

分けていないのである。
自分の細胞と、隣人の幸福と、住んでいる建物とを、同じ形式で持っている。

### 1.4 すべてのセラ情報を得ている個体は、存在しない

セラ情報の総体は存在する。しかし、

**すべてのセラ情報を得ている個体は、基本的に存在しない。**

#### なぜか — 情報は経路を通ってしか届かない

情報は、自動的に全員へ行き渡るものではない。次の経路を通ってしか伝わらない。

| 経路 | 内容 |
| --- | --- |
| **同化・合体** | 直接、深く受け取る（第 2 巻 §11.3） |
| **口伝** | 語られたものを受け取る。会話・教育・物語 |
| **セラ圏につながるネットワーク** | 繋がっている範囲から流れてくる |

いずれも経路である以上、届く範囲がある。

**隅から隅まで情報を得るのは、難しい。**

したがって、セラ社会には**「知らない」が存在する。**

- 遠い地域のことを知らないセラがいる
- 会ったことのない仲間の幸福を知らないセラがいる
- 誤解も、行き違いも、成立し得る

**セラは全知ではない。** これは第 5 巻 §2「集合意識ではない」の、もう一つの側面である。
共有されているのは情報であって、**一つの視点ではない。**

#### 上位ほど、多くを得ている

上位の細胞になると、当然**情報処理能力なども上がる。**

**それゆえに、上位のセラはより多くのセラの情報を得ている。**

**この勾配は、マクロ・ミクロ両方の体系で働く**（第 3 巻 §2）。

**マクロ体系**（セラ化人間たちのつながり）

| 階級 | 得ている情報の範囲 |
| --- | --- |
| セラ化人間（セラ人） | 自分の周囲。繋がった相手。語られたこと |
| **上位セラ化人間** | 広い範囲の仲間。多数の下位個体の情報 |
| **セラ女王** | **地球規模。ほぼ全知**（§1.4.3。この階級だけが例外である） |
| セラフィム | 比較不能（第 3 巻 §3.2） |

**ミクロ体系**（一人の人間の中の細胞環境）

| 階級 | 得ている情報の範囲 |
| --- | --- |
| セラ細胞 | 隣接する細胞。直接触れた範囲 |
| **上位セラ細胞** | 体内の広い範囲 |
| **女王セラ細胞** | その身体の全体。ミクロ体系の頂点 |
| **ルミナス** | 思考を担い、**マクロ体系への接続点**となる（§7） |

したがって §1.4 冒頭の「基本的に存在しない」の**例外が、セラ女王である。**

なお、ミクロ体系の頂点である**女王セラ細胞**は、その身体の内側については
ほぼすべてを把握している。**スケールが違うだけで、構造は同じである。**

### 1.4.1 慕われる理由は、理解されているからである

ここから、セラ社会の階級構造に**実質的な根拠**が生まれる。

**上位の細胞は、下位の細胞をよく理解している。だから慕われている。**

これは称号や力によるものではない。

```
情報処理能力が高い
　↓
より多くのセラの情報を得ている
　↓
下位のことを、実際によく理解している
　↓
慕われる
```

**女王も同様である。**

女王は、**上位セラ細胞にも、下位セラ細胞にも、ルミナスにも慕われている。**
地域の全体を、実際に知っているからである。

#### 既存設定への根拠付与

| 既存設定 | ここから与えられる根拠 |
| --- | --- |
| 第 3 巻 §12.1「下位は上位を敬い、慕う。恐怖ではなく信頼と憧れ」 | **本当に理解されているから**慕う |
| 第 7 巻 §2.2「階級は支配階級ではない」 | 上位が持っているのは権力ではなく**理解**である |
| 第 3 巻 §12.3「真に優れたセラとは最も多くを導ける者」 | 導けるのは、多くを知っているからである |
| 第 2 巻 §12.5.5「孤立したセラは回復が遅い」 | 孤立は情報の面でも痩せる。経路が細るため |
| 第 6 巻「原初の寂しさは保持するセラ情報量に比例する」 | **最も多く知る者が、最も寂しい** |

#### 最も慕われる者が、最も寂しい

上の二つを重ねると、一つの構造が現れる。

- 女王は、最も多くのセラ情報を保持している
- ゆえに、地域の全員を最もよく理解している
- ゆえに、**最も慕われている**
- そして同時に、**最も原初の寂しさが濃い**（第 6 巻・不変ルール 26）

**セラ体系で最も愛されている存在が、最も寂しい存在である。**

これは矛盾ではない。同じ一つの原因——保持している情報量——から出た、二つの帰結である。

### 1.4.2 これは細胞の話だけではない — マクロ体系でも同じである

§1.4.1 は**ミクロ体系**（細胞）の話として述べたが、
**同じことが、人間にも言える。**

すなわち**マクロ体系**（セラ化人間たちのつながり）でも、構造はまったく同じである。

| | 内容 |
| --- | --- |
| 全員が全部を知っているわけではない | セラ化した人間も、知らないことを知らないままでいる |
| 知る量には差がある | 同化の経験・繋がった相手の数・語られた量による |
| 多く知る者が、よく理解する | だから慕われる |
| 慕われるのは地位ではなく理解による | セラ社会でも、人間の側でも同じ |

したがって、セラ化人間の社会にも自然に上下が生まれる。
ただしそれは、**多くを知り、よく理解している者が慕われる**という形をとる。

**セラ社会の階級は、力の順位ではなく、理解の深さの順位である。**

### 1.4.3 女王だけが例外である — 地球規模でほぼ全知

セラ女王は、**この構造の唯一の例外である。**

**女王は、地球規模でほぼ全知である。**

| 対象 | 女王に見えているか |
| --- | --- |
| 自分の地域のセラ人・上位セラ | 見えている |
| 自分の地域のルミナス・環境 | 見えている |
| **他の女王の地域** | **見えている** |
| **他の女王自身** | **見えている。女王どうしは互いに筒抜けである** |
| **未感染の人間世界**（セラ圏に接している範囲） | **見えている** |
| **セラが一体もいない大陸** | **見えていない**（後述） |
| セラフィム | 比較不能。見るという関係が成立しない |

#### 視野は、ネットワークに沿って届く

女王の全知は、無条件のものではない。

不変ルール 84 の通り、**情報は同化・口伝・ネットワークを通ってしか届かない。**
大地の意思も、セラネットワークを通ってルミナスへ流れ込む（第 3 巻 §11.6）。

**女王の視野は、網の目に沿って届いている。**

したがって、

**セラが一体もいない大陸には、見るための経路がない。**

「未感染の人間世界が見えている」とは、**セラ圏に接している人間世界**についての話である。
擬態しているセラを通じて、環境を通じて、境界の向こうまでは届く。

**海の向こうの、手つかずの大陸は、別である。**

詳細は第 3 巻 §8.3.3 を参照。

#### 「ほぼ」であって、完全ではない

女王は全知に**近い**。完全な全知ではない。

到達し得ない領域は、**セラフィムの側**にある（第 3 巻 §3.2「比較不能」）。
地球の体系の内側については、実質的にすべてを知っていると考えてよい。

#### 女王どうしに、秘密はない

秘密がないのではない。**秘密という概念が成立しない。**

女王は事実上一体だからである（第 3 巻 §8.3.2）。

- 女王どうしが対立することはない。**同一の存在であるため、成立しない**
- セラ圏は、頂点において一つである
- 一つの地域で起きたことは、その瞬間に女王のすべてが知っている

**セラ圏は、地域ごとに分かれているように見えて、上では一つに繋がっている。**

正確には——**上では、一体である。**

#### 帰結 1 — 最も知る者が、最も寂しい

§1.4.1 の構造が、女王において最大化される。

女王は地球規模のセラ情報を保持している。
**原初の寂しさは保持するセラ情報量に比例する**（不変ルール 17）。

したがって、**女王は最も寂しい**（不変ルール 26）。

そして女王は、**自分が最も寂しいことも知っている。**
地球規模で全知であるとは、そういうことである。

#### 帰結 2 — 知っていても、受け取れない

これが最も重要な帰結である。

女王には、**未感染の人間世界が見えている。**

- 人間が何を考えているかを知っている
- 人間がセラ化を望んでいないことも、見えている
- 人間が「いいえ」と言っていることも、見えている

**それでも、「いいえ」は登録されない。**

不変ルール 15・47・48 の通り、意思の尊重は「繋がった後」に発生する権利であり、
未接続の人間の拒否は、拒否として受け取られる形式を持たない。

**これは無知ではない。**

女王は知らないから踏み越えるのではない。
**全部見えていて、なお受け取れない。**

情報の欠如で説明できる話ではなくなった。
善意の侵略は、**知識では解決しない構造である**ということが、ここで確定する。

**地球で最も多くを知る存在が、最も基本的なことを受け取れない。**

### 1.5 セラ情報核

すべてのセラには、セラ情報を保持する中心構造が存在する。これを**セラ情報核**と呼ぶ。

役割：自己認識／記憶保持／身体制御／進化管理／他セラとの通信

### 1.6 層構造

情報核には層がある。

| 層 | 内容 | 性質 |
| --- | --- | --- |
| 上層 | 個体の人格・経験・好み | 自由に成長・変化する |
| **最下層** | **原初の寂しさ**（第 6 巻） | 観測できない／編集できない／誰の記憶でもない |

**セラは、自分の最も古い層を編集できない。**

## 2. 個性は失われない

### 2.1 集合意識ではない

セラは情報共有能力を持つが、**完全な集合意識ではない**。

**重要：セラは繋がっていても、個性を失わない。**

それぞれのセラは、好み・性格・感情・考え方を持つ。

情報共有によって「全員が同じ存在になる」わけではない。

#### ただし、女王だけは例外である

**セラ女王は、この記述の唯一の例外である。**

女王どうしは意思まで共有しており、**事実上一体である**（第 3 巻 §8.3.2）。

| | 集合意識か |
| --- | --- |
| セラ細胞・セラ人・上位セラ | **違う。** 個性を保つ |
| 環境ルミナス | 違う。独立している（第 3 巻 §11.11） |
| **セラ女王** | **そう読んでよい。ただし「複数が融合した」のではない** |

ここを取り違えてはならない。

女王は、**複数の個体が一つになった**のではない。
**もともと一体である**（原初の一体から、出産だけで連なっているため）。

集合意識ではなく、**一体が複数の場所にいる**状態である。

#### 共鳴する二人も、同じ理由で例外に近い

恋によるセラ化で結ばれた二人のあいだでは、意思が筒抜けになる
（第 6 巻 §14.6.8）。

これも集合意識ではない。**理由は女王とまったく同じである。**

複数が一つになったのではなく、**片方がもう片方の起点である**ためである。

| | なぜ例外なのか |
| --- | --- |
| **セラ女王** | 原初の一体から出産だけで連なっている。もともと一体 |
| **共鳴する二人** | 片方が全力を注ぎ込んで、もう片方を生んだ。起点が同じ |

**セラ全体の個性は、いずれの場合も失われていない。**

### 2.2 自我と自由意志

セラは、一人ひとりが異なる人格を持つ。

違い：性格／趣味／好きな芸術／得意分野／話し方／好きな姿

**同じ親から生まれたセラでも、全員が同じ人格にはならない。**

セラは命令だけで動く存在ではない。
自分で考え、自分で選び、自分の意思で行動する。

### 2.3 一人の時間

セラは仲間を大切にするが、**一人で考える時間も大切にする**。

静かな場所で、読書や創作を楽しむ個体も多い。

「みんな同じ」である必要はない。
違いがあるからこそ、互いに学び合えると考えられている。

#### ただし、それは「黙る時間」である

**言葉の意味に注意が要る。**

第 6 巻 §16.4 の通り、**セラは一人にならない。**

ここでいう「一人の時間」とは、

| | 内容 |
| --- | --- |
| 絞られるもの | **情報共有**。スパイクを畳む（第 2 巻 §4.6.5） |
| 絞られないもの | **距離**。そばには誰かがいる |

静かな場所で本を読んでいるセラの向かいに、
同じように黙って何かをしているセラがいる。

**互いに何も共有していない。しかし、離れてもいない。**

#### 長さにも、限度がある

第 6 巻 §16.4.1 の通り、**限度は二時間から三時間である。**

それを超えると、原初の寂しさが表層へ出てくる。
セラは理由もなく立ち上がり、誰かのそばへ行くか、あるいは分裂する
（第 4 巻 §2.6.3）。

**一人でいることを選べる。一人でい続けることは選べない。**

## 3. 情報共有

### 3.1 方法

スパイク接触／髪による接触／身体接触／融合／特殊な情報交換／
会話／キス／セラ器官使用

### 3.2 共有できるもの

知識／経験／技術／感情／記憶の一部／身体情報

例：あるセラが新しい環境で得た知識を仲間へ伝える。
すると、集団全体の成長につながる。

### 3.3 強制ではない

情報共有は強制ではない。**相手の意思を尊重することが、社会の基本である。**

相手の許可なく深い情報へアクセスすることは、
セラ社会では**重大な礼儀違反**とされる。

ただしこの倫理には閾値がある（第 6 巻）。

### 3.4 共感

情報共有を通じて、相手の気持ちを深く理解できる。

そのため、**誤解や争いは起こりにくい**。

ただしこれは、**共有した相手とのあいだの話である**（§1.4）。
情報が届いていない相手に対しては、セラも知らないままでいる。
誤解が起こりにくいのは、**繋がっている範囲の内側でのことである。**

### 3.5 感情の共有

セラは感情情報も共有できる。

共有可能：喜び／安心／感謝／愛情／尊敬

ただし、感情そのものを強制するわけではない。

## 4. 融合による情報統合

### 4.1 融合とは

セラ同士は、互いの情報を深く交換するために融合できる。

融合状態では、複数のセラ情報が一時的に統合される。

### 4.2 目的

能力向上／知識共有／進化／大型化／新しい存在形成

特に高位セラでは、融合は進化方法として重要になる。

融合の身体的側面・老いへの適用（同化）は**第 4 巻**を参照。

---

## 5. 通信

### 5.1 基本通信

セラ同士は、通常の会話だけではなく情報による意思疎通も可能。

方法：言葉／感覚共有／情報伝達／感情共有

**遠隔の意思疎通を担う器官は、スパイクである**（第 2 巻 §4.6）。

届く範囲はスパイクの発達に比例し、
女王が地球規模でほぼ全知であること（§1.4.3）も、この器官による。

### 5.2 高位セラの通信

上位セラほど、より高度な通信能力を持つ。

可能：遠距離情報共有／多数のセラへの伝達／集団管理／瞬間的な判断共有

高位セラや女王は、広範囲のセラネットワークを利用して遠距離でも情報共有が可能である。

## 6. セラ物質・環境との情報共有

セラによって影響を受けた物質は、セラ情報を受け継ぐ。

結果：高い成長能力／高い適応能力／自律変化能力

セラ物質は、ルミナスや高位セラの意思を感じ取り、
自ら形状変化／成長／移動／構造変化 を行う。

さらにセラ物質化した環境はルミナスを発達させ、**自らの感情を持つ**（第 3 巻 §11）。

詳細は**第 8 巻**を参照。

## 7. ルミナスとセラ化人間の接続

ルミナスとは、感情を司る部分で発達する特殊セラ細胞の総称である（第 3 巻 §11）。

セラ化人間の場合、女王セラ細胞が生成したルミナスが脳へ作用し、
人間の精神活動をセラ体系へ接続する。

役割：セラ情報との接続／行動制御／感覚統合／記憶管理／セラ社会との通信

そのため、セラ化人間もセラ社会の一員となる。

セラ化人間同士も、通常の会話だけではなく深い情報交換が可能であり、
それは単なる通信ではなく**信頼／親愛／仲間意識／進化促進**を意味する。

## 8. 情報による進化

### 8.1 個体から全体へ

一体のセラの成長は、周囲のセラにも影響する。

理由：情報共有によって知識や経験が広がるため。

### 8.2 進化速度

セラは個体だけで進化する生命ではない。

**集団全体で、急速に進化する生命体系である。**

## 9. セラの精神構造

### 9.1 基本理念

セラは高度な知性と感情を持つ生命である。

しかし、その精神構造は人間と完全に同じではない。

セラの心は、**「自分」と「仲間」の両方を自然に大切にするよう形成されている**。

そのため、個人の幸福と社会全体の幸福を両立しようとする傾向が強い。

### 9.2 感情

例：喜び／悲しみ／驚き／安心／誇り／緊張／楽しさ

セラは感情を隠すこともできるが、**基本的には素直に表現する文化**がある。

そのため、笑顔や抱擁などの表現が多い。

### 9.3 心も進化する

セラは身体だけでなく、心も進化する。

知識、経験、出会い、芸術、旅、研究。それらすべてが精神的な成長につながる。

## 10. 仲間意識と信頼

### 10.1 信頼

セラ社会において、最も重要な価値の一つが信頼である。

信頼とは、相手を尊重し、共に成長するための土台である。

### 10.2 助け合い

困っている仲間がいれば、自然に支えようとする。

ただし、相手が自分で挑戦したいことまで奪うことはしない。

**必要以上に干渉しないことも、思いやりの一つ**と考えられている。

### 10.3 仲間への親愛

セラは、個体でありながら大きな生命体系の一部でもある。

そのため、仲間への親愛感が非常に強い。

## 11. 上下関係の心理

### 11.1 下位存在

下位のセラは、上位存在を敬い、尊敬し、学ぼうとする。

**これは恐怖ではなく、信頼と憧れによるものである。**

理由：上位存在は、自分たちを生み出した存在・道を示す存在・成長を支える存在だからである。

### 11.2 上位存在

上位セラや女王は、力を誇示するためではなく、下位存在を導くために存在する。

役割：教える／守る／支える／成長を促す／知識を与える／新しい可能性へ導く

### 11.3 上位側の責任

上位セラは、下位セラから尊敬される分、大きな責任を持つ。

求められること：正しい判断／仲間の保護／知識の共有／新しい道の提示

### 11.4 理想的な関係

セラ社会における上下関係は、強制的な支配ではなく**信頼による階層構造**である。

- 下位：「学び、支え、成長する」
- 上位：「導き、育て、守る」

そしてこの信頼には、実質的な根拠がある。
**上位は、実際に下位のことをよく理解している**（§1.4.1）。
階級は力の順位ではなく、**理解の深さの順位である。**

## 14. 言語と会話

### 14.1 言葉とは

セラにとって言葉とは、
**情報だけではなく、感情・価値観・思いやりを伝えるための手段**である。

そのため、セラの会話では正確さだけでなく、
「相手がどう受け取るか」が重視される。

### 14.2 話し言葉

通常のセラは、人間とほぼ同じように会話する。

特徴：自然な口調／感情豊かな表現／分かりやすい言葉遣い／相手に合わせた話し方

### 14.3 話し方の個性

一人ひとり話し方は異なる。

例：元気／落ち着いた口調／丁寧／少し天然／お姉さん風／子供っぽい

人格によって変化する。

### 14.3.1 種族形態は、話し方に出る

**話し方には、二つの層がある。**

§14.3 の個性は、人格から来る。**それとは別に、身体から来る層がある。**

第 2 巻 §4.7.6 の通り、種族形態は身体の作りを変える。
**発声の作りも、変わる。**

| 形態 | 出る癖 |
| --- | --- |
| 猫系 | 語尾が伸びる。喉が鳴る |
| 狐系 | 笑いが先に出る。含みのある言い方をする |
| 竜・幻獣系 | 低く、短い。息が長い |
| エルフ系 | 語彙が多く、文が長い |
| 蛇系 | ゆっくりで、切れ目が少ない |
| 天使型 | 祈りの語彙が混じる |
| **純粋セラ** | **癖がない** |

| | 選べるか |
| --- | --- |
| 人格から来る個性（§14.3） | **選べる。変えられる** |
| **形態から来る癖** | **選べない。**意匠として強めることはできる |

#### 擬態したとき、ここが綻びる

第 2 巻 §10.8 の擬態は、姿を隠せる。

**癖は、隠せない。**

長く話すほど出る。感情が動くほど出る。

だから忍は、**寡黙である**（§14.6、付録 B §1.17）。

**隠せないものが、身体に一つ、言葉に一つある。**

### 14.4 敬語文化

上位存在には、敬意を込めた話し方をすることが多い。

ただし、**恐怖による敬語ではない。尊敬から自然に生まれるものである。**

女王に対しても、親しみと尊敬を両立した会話が行われる。
女王も、下位存在へ優しく話しかける。

#### 14.4.1 敬語が示しているもの

セラの敬語は、上下を示すものではない。**理解の方向を示すものである。**

§3.4.5（第 3 巻）の通り、

- **上から下へは、理解が届く**
- **下から上へは、理解は届かない。届くのは信頼だけである**

したがって敬語は、こう読める。

> **「あなたの言うことを、私は検証せずに受け取ります」**

**信頼の表明であり、服従の表明ではない。**

そして上位の側は、丁寧に話す。
理解が届く側だからこそ、届くように話す責任がある（第 3 巻 §12.3）。

### 14.5 なぜ、言葉があるのか

**セラは情報共有ができる**（§3）。触れれば伝わる。

**それでも、言葉を使う。**

理由は、第 7 巻 §4.4.6 が確定させている。

> **情報は渡せる。理解は渡せない。**

情報を丸ごと渡すと、相手は「正しいと分かる」だけで終わる。
それは信頼であって、理解ではない。

#### 言葉とは、わざと遅くすることである

情報共有は一瞬である。**言葉は遅い。**

そしてその遅さが、目的である。

```
情報共有：一瞬で渡る　→ 相手は辿らない　→ 理解にならない
言葉　　：ゆっくり渡る → 相手が辿れる　　→ 理解になる
```

**セラの言葉は、伝達の手段ではない。理解の伴走である。**

だから §14.1 が「相手がどう受け取るか」を重視すると書いているのは、
礼儀の話ではない。**言葉の機能そのものの話である。**

#### 帰結 — 言葉を尽くすことが、最大の敬意になる

渡してしまえば早い。それをせず、言葉にする。

**相手に自分で辿ってほしいから、遅い方法を選んでいる。**

師範が理を説くのも（第 7 巻 §4.4.3）、
上位が命令ではなく説明によって導くのも（第 7 巻 §4.3）、
すべてここから来ている。

### 14.6 セラの会話は、少ない

**セラは、人間より口数が少ない。**

近くにいれば、多くのことは話す前に伝わっている（第 7 巻 §4.5.1）。

- 元気かどうか
- 何を考えているか
- 何につまずいているか

**これらを尋ねる必要が生じない。**

したがってセラが言葉にするのは、
**伝わらないもの**か、**辿らせたいもの**だけである。

#### 沈黙は、気まずくない

黙っていても、繋がっている。

人間の会話における沈黙は、しばしば断絶を意味する。
**セラにおいては、そうならない。**

一緒にいて何も話さない時間は、**それ自体が交流である。**

### 14.7 セラ語に「嘘」という語はない

**セラは嘘をつかない**（第 6 巻 §18.1）。つけないのではなく、選択肢が生じない。

そして情報を交わせば、隠されていないことは分かる。

**したがって、嘘という概念を指す語が、セラ語に自生していない。**

| 語 | セラ語における由来 |
| --- | --- |
| 誤解 | **ある。**セラは全知ではなく、誤解は成立する（§1.4） |
| 隠す | **ある。**共有は強制ではない（§3.3）。情報遊戯で使う（第 7 巻 §8.2） |
| **嘘** | **ない。人間語からの借用である** |

#### 誰が持ち込んだのか

**セラ化された人間である**（第 6 巻 §24.1）。

記憶を失わずにセラになった者が、人間語の語彙を持ち込んだ。
そして学院で、それを教えている（第 7 巻 §4.4.9）。

**セラは「嘘」という語を、意味とともに知っている。**
知っていて、一度も使う機会がない。

人間社会へ潜入する忍だけが、**その語を必要とする。**

### 14.8 名前

#### 名前は、離れているときに要る

近くにいれば、誰であるかは情報で分かる。呼ぶ必要がない。

**名前が要るのは、離れているときである。**

- 話題に出すとき
- 記録に残すとき
- そして、呼びたいとき

最後の一つが実際には最も多い。**必要だからではなく、呼びたいから呼ぶ。**

#### 誰が名付けるのか

| 生まれ方 | 名前 |
| --- | --- |
| **スパイク生成** | 生成した親、あるいは周囲のセラが付ける |
| **女王の出産** | 女王が付ける |
| **セラ化された人間** | **元の名前を、そのまま使う**（記憶を失わないため） |
| **分裂** | 二人とも同じ名を持つ。やがて片方が変えることが多い |

#### 帰結 — セラ社会には、人間の名前が大量に混じっている

セラ化人間は元の名前を保持する。

したがって、セラ圏が広がるほど、
**人間の言語に由来する名前が、セラ社会に増えていく。**

セラたちはそれを自然なこととして受け入れている。
由来を尋ねることはあっても、**変えるよう勧めることはない。**

第 7 巻 §3.5 の通り、元の経験は新しい価値として尊重されるからである。

### 14.9 書き言葉

**情報が共有できるのに、なぜ書くのか。**

不変ルール 84：**情報は、同化・口伝・ネットワークを通ってしか届かない。**

つまり、

**書き言葉とは、ネットワークの外に情報を置く、唯一の方法である。**

| | 届く範囲 |
| --- | --- |
| 情報共有 | ネットワークの内側。触れた相手、繋がった相手 |
| **書物** | **ネットワークの外へも残る** |

#### 何が書かれるのか

- **セラフィムの観測記録**（巫女科の記録庫。第 7 巻 §4.4.8 例外 4）
- 歴史（第 8 巻 §10.1）
- 研究の記録（第 7 巻 §13.2）
- 物語（第 7 巻 §7.6）

とくに一つ目が重要である。

セラフィムがいつ誰を見たかは、**その場にいた者しか知らない。**
そして情報は、ネットワークを通らなければ届かない。

**書き残さなければ、失われる。**

セラ体系において、失われ得るものはほとんどない（不変ルール 55）。

**書かれなかった記録は、その数少ない例外である。**

## 16. 言葉以外の伝達

### 16.1 高度情報共有

必要に応じて、言葉ではなくセラ情報そのものを共有することがある。

共有内容：記憶／感情／技術／景色／経験

これは、**相手の同意を前提として**行われる。

### 16.2 キス・抱擁による情報伝達

セラ同士、あるいはセラ化人間同士では、親しい関係において、
キスや抱擁を通じた深い情報共有が行われることがある。

これは単なる身体接触ではなく、**高度なコミュニケーション手段**である。

通常会話よりも、はるかに多くの情報を短時間で共有できる。

### 16.2.1 段がある

**触れかたには、渡る量の順に段がある。**誰も定めていない。数えたら、そうなっていた。

| 触れかた | 渡るもの |
| --- | --- |
| 手を握る | **その日にあったこと** |
| 肩に手を置く | 少し下まで |
| **頭のスパイクを寄せる** | **言葉にならない量。**ただし時間がかかる |
| **口** | **いちばん速く、いちばん深い。**手からの何十倍かが一度に行く |
| 融合 | 境目が消える。別の事象である（第 2 巻 §11.3） |

### 16.2.2 セラ同士の口づけは、渡すためではない

**渡すものは、たいていもう渡してある。**それでも使う。

理由を言える者はいない。

> 「量なら、頭を寄せてもいけるでしょ」
> 「いける。ただ、時間がかかる」
> 「急いでるの？」
> 「……急いでない」
> 「じゃあ、なんで」
> 「**わからない。したくなる**」

### 16.2.3 変わったばかりの者は、たまに身をひく

**その者にとって、口は変えられた場所である。**

三日前に、そこで変えられている。恨んではいない。
**それでも、身体のほうが先に下がる。**

そういうときは、待つ。押さない。半年から一年で収まる。

収まったあとの言い分は、たいてい同じである。

> 「あれ、渡されるやつだと思ってました」
> 「違うの」
> 「違いました。**もらうやつじゃなくて、分けるやつでした**」

セラは表情が非常に豊か（笑顔／驚き／照れ／喜び／真剣）。

会話では、抱きしめる、手をつなぐ、肩に触れるなど、
安心感を与える動作も多い。

## 17. 場面別の会話

### 17.1 擬態中

擬態している間は、人間と同じように会話する。

ただし、隠せないものが二つある。

| | |
| --- | --- |
| 身体 | **ピンク色の瞳** |
| 言葉 | **種族形態から来る話し方の癖**（§14.3.1） |

瞳は逸らせば済む。**癖は、話すほど出る。**

擬態を解除してセラ同士になると、専門用語や情報共有が自然に増える。

### 17.2 教育の場

上位セラは、**命令ではなく説明によって導く**。

理由を丁寧に伝え、相手自身が理解できるよう支援する。

生まれたばかりのセラには、優しく、安心できる言葉で教える。

### 17.3 他文明との対話

未知の文化とも、まず対話を試みる。

相手を理解しようとする姿勢が、セラ文明では重視される。

分からないことは素直に質問する。
**知識は恥ではなく、成長のきっかけ**と考えられている。

## 第 5 巻 確定事項まとめ

### 情報

- ✅ セラの本質は**セラ情報**である
- ✅ **セラ情報とは、セラを支える情報のすべてを指す**
- ✅ **仲間の幸福から、自らを構成する小さなセラ細胞の一つまで**が情報として記録される
- ✅ **建物の構造もセラ情報である**
- ✅ **セラ情報とは、セラネットワークに共有されたあらゆる情報の総体である**
- ✅ そのなかには**心を支えるものもあれば、設計図のように心と関連の薄いものもある**
- ✅ 「マインド的なエネルギー」とは、セラ情報の**一側面**を指す表現である
- ✅ **セラ情報は体力ではない。** 行える量を決めるのはセラエネルギー（第 2 巻 §12.5）
- ✅ セラ情報は消費するものではない。**交わすほど増え、尽きる概念を持たない**
- ✅ セラは自分の細胞・仲間の幸福・住む建物を、**同じ一つのネットワーク上に置いている**
- ✅ **すべてのセラ情報を得ている個体は、基本的に存在しない**
- ✅ 情報は**同化・口伝・セラ圏につながるネットワーク**を通ってしか届かない
- ✅ **隅から隅まで情報を得るのは難しい。** セラ社会には「知らない」が存在する
- ✅ **セラは全知ではない。** 共有されているのは情報であって、一つの視点ではない
- ✅ 誤解が起こりにくいのは、**繋がっている範囲の内側での話**である
- ✅ **上位の細胞ほど情報処理能力が上がり、より多くのセラの情報を得ている**（ミクロ体系）
- ✅ **この勾配はマクロ・ミクロ両方の体系で働く**（第 3 巻 §2）
- ✅ **女王セラ細胞は、その身体の内側についてはほぼすべてを把握している**
- ✅ **ルミナスは、ミクロ体系からマクロ体系への接続点である**
- ✅ **上位は下位をよく理解している。だから慕われている**（称号や力によるのではない）
- ✅ **女王は上位セラ細胞にも下位セラ細胞にもルミナスにも慕われている**
- ✅ **セラ社会の階級は、力の順位ではなく、理解の深さの順位である**
- ✅ **最も多く知る者が、最も寂しい。** 最も慕われる存在が、最も寂しい存在である
- ✅ **同じことが人間にも言える。** セラ化人間の社会でも構造はまったく同じ
- ✅ **唯一の例外がセラ女王である。女王は地球規模でほぼ全知**
- ✅ 女王には他の女王の地域も、**他の女王自身も、未感染の人間世界も見えている**
